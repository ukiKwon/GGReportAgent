# 이사회 자료 작성 (영업 추진 준비 › 연관 업무 › 이사회 자료 작성) — 기관 상세 7·8단계의 이사회 몫 포함

## 목적·누가 쓰나
- **이사회 자료는 두 단계다. ① 이사회 전: 수익성 분석표(엑셀) 내용을 이사회 자료 내용으로 옮겨(치환) 팀장 결재로 확정한다. ② 이사회 뒤: 담당자가 부장에게 받은 회의 정리본(클로바)으로 회의록을 정리한다** — 회의록의 가치는 '이사회 이후' 정리에 있다 (출처: 사용자 11-20 메모리 board-material-two-stage, Q-2026-11-20-53)
- **이사회 자료 한 건 = 입찰 건 + 그 기관의 이사회 회차. 같은 건·회차로 다시 열면 전에 확인한 기록이 보인다** (출처: 사용자 11-09 권장안 확정 NEXT 57)
- **메뉴는 이름 그대로 '연관 업무' 소제목 아래에 둔다. 기관 상세 7단계 안의 같은 일은 '이사회 자료 준비'라고 부른다** (출처: 사용자 11-27 권장안대로 sessions/2026-11-27_0000_dash.md)
- **쓰는 사람은 그 입찰 건의 담당 영업(배정된 사람만), 결재는 팀장** (출처: 사용자 11-10 handoff/agents/history/2026-11-10_020_사용자답.md)
- **디자이너는 이 메뉴를 보지 않는다** (출처: Q-2026-11-19-64)

## 보는 범위·권한
- **팀장은 자기 팀 건의 이사회 자료를 모두 보고, 부장은 소속 직원·팀의 이사회 자료를 모두 본다. 그 밖에 담당이 아닌 사람에게는 그 기관 작성본이 보이지 않는다. 쓰기는 담당자만 한다** — ~~담당이 아니면 볼 수 없다(담당이 아닌 영업팀장 포함)(11-10)~~ → 폐기(11-27) (출처: 사용자 11-10 → Q-2026-11-27-02, 사용자 11-27)
- **결재자(팀장·부장)는 결재 중인 자료의 모든 내용을 결재 경로로 본다** (출처: 사용자 11-10)
- **영업부장은 어느 상태에서든 반려할 수 있고 '재작성 요구'로 되돌릴 수 있다** (출처: 사용자 11-10)
- **배정된 담당자 전원이 수정할 수 있다** — 작성본은 입찰 건에 속하고 담당자 전원이 함께 쓴다 (출처: 사용자 11-10)
- **표별 확인은 영업팀 담당자만 한다** (출처: 사용자 11-09 NEXT 57)
- **확정된 자료에 대한 모든 행위는 누가(사번)·어느 화면·어느 버튼·언제·어느 자료인지 기록한다** (출처: 사용자 11-10 '잊지마', 00_공통)

## 화면 구성·표시 규칙
- **'수익성 분석표 보기' 팝업은 보기 + 수정이다. 수정은 연결된 이사회 칸에 사유와 함께 반영하고 엑셀 원본은 그대로 둔다** (출처: 사용자 11-09 NEXT 57)
- **표를 확인한 사람·시각은 다시 열어도 보이게 서버에 저장한다** (출처: 사용자 11-09 NEXT 57)
- **수익성 분석표 숫자는 천원 단위이고, 최대 9,999조 원까지 표현하면 된다** (출처: 사용자 11-10)
- **출연금 괄호 안은 예비비다. 두 숫자로 따로 저장하고, 화면·Word에는 '5.00 (1.00)' 그대로 보인다** (출처: 사용자 11-11 권장안 NEXT 66)
- **단위 칸은 숫자만 저장하고, 단위(년·%)는 양식이 붙여 보인다** (출처: 사용자 11-11 NEXT 66)
- **현재가치할인율은 올린 표 '투자가부결정기준' 행 IRR 칸의 숫자를 쓴다(늘 같은 값)** (출처: Q-2026-11-16-104)
- **판단기준 문구는 정해진 문장에 올린 표의 숫자만 넣는다. 출연금 적정성 행은 추가하지 않는다** (출처: Q-2026-11-16-105)
- **각주 문장이 바뀌면, 이미 확정된 자료를 Word로 다시 받을 때 각주가 새 문장이어도 된다(표 안 숫자·문구는 저장된 그대로)** (출처: Q-2026-11-17-07)
- **확정본 Word 내려받기 단추를 둔다** (출처: 사용자 11-11 ⓐ NEXT 66)
- **이사회 목록·첨부 파일명 칸은 왼쪽 정렬** (출처: Q-2026-11-26-17 — 이름 칸 왼쪽 규칙 확대)

## 동작·흐름 규칙
### ① 작성·확정 (이사회 전)
- **기관 상세 4단계에서 수익성 분석표를 올리면 이사회 자료 초안이 자동으로 만들어지고, 표별 확인은 7단계에서 한다** (출처: 사용자 11-25 권장안)
- **[제출]하면 수정할 수 없다. 팀장 결재 중에는 담당자가 회수할 수 있고, 회수하면 다시 작성한다** (출처: 사용자 11-10)
- **팀장 승인이 곧 최종 확정이다. 팀장이 반려하면 다시 작성한다** (출처: 사용자 11-10)
- **반려·재작성 요구 쪽지는 그 건의 담당자 전원에게 간다** (출처: 사용자 11-11 ⓒ NEXT 66)
- **담당에서 빠진 사람이 쓰던 작성본은 새로 추가된 담당자 전원에게 넘기고, 넘긴 사실을 변경 이력에 남긴다** — 작성자 표시만 하고 두는 안은 기각 (출처: 사용자 11-10)
- **의결 결과와 상관없이 팀장 확정이면 7단계 과제는 완료다. 부결은 꼬리표로 표시한다** (출처: 사용자 11-11 NEXT 70)

  - **AI가 쓰는 칸은 '보고 전 사전 설명'·'기대효과' 2칸뿐이다. '기관 현황 덧붙임'·'수익성 덧붙임'은 사람이 쓴다** (출처: 1회차)
  - **AI가 보는 자료 = 확정 전 이사회 자료 + 그 건에 올린 공고 파일. 공고 파일은 AI가 직접 읽고, 사람이 따로 적는 칸은 만들지 않는다** (출처: 1·5회차)

  - **기다리는 동안 창을 연 채 진행 표시를 하고, 다른 칸은 계속 쓸 수 있다(따로 저장 기능은 없음)** (출처: 3회차)
