# 00_공통 — 모든 화면에 걸친 규칙

## 목적·누가 쓰나
- **이 시스템은 지자체·공공기관 금고 입찰을 찾아 제안 준비에서 결재까지 잇는 실무 도구이자 시연 도구다** — 두 목적을 모두 만족해야 한다 (출처: PRODUCT.md, 사용자 08-13)
- **성공 기준은 "임박한 금고 입찰을 한눈에 찾는 것"이다** (출처: PRODUCT.md, 사용자 08-13)
- **데이터는 실측만 쓴다. 출처 없는 값이나 과장된 수치는 화면에 만들지 않는다. 시연에서도 데이터는 실무와 같은 정본을 쓴다** (출처: PRODUCT.md 원칙 1·5, 사용자 08-13)
- **폐쇄망에서 동작한다. CDN·웹폰트 같은 외부 요청은 새로 만들지 않는다** (출처: PRODUCT.md, 사용자 08-13)
- **시각 기조는 밝은 업무 포털이다**(흰 패널·옅은 회색 바탕·1px 선·모서리 2px·그림자 없음). ~~다크 기조~~ → 바뀜(11-19) (출처: PRODUCT.md, 사용자 11-19 시안 A)
- **국민은행 CI 진회색 #545045는 머리 띠·로그인 상단 띠·로그인 카드 윗선 세 곳에만 쓴다**. ~~남색 #052561~~ → 바뀜(11-19) (출처: PRODUCT.md, 사용자 11-19 시안 B)
- **화면 모양(배치·단추 자리·표 구성)이 바뀌는 작업은 적용 전에 HTML 시안을 먼저 보여 주고 사용자가 고른다**. 문구·버그 수정은 예외 — 적용 즉시 사용자 화면이 바뀌기 때문이다 (출처: 사용자 11-26)

## 역할·부서·직책
- **'팀' 이름은 부서 이름이 된다: 영업팀=영업부서, 전산팀=개발부서, 예산팀=재무부서, 사업팀=사업부서** — 실제 조직 단위가 부서다 (출처: NEXT 95, 사용자 11-17)
- **직책 이름은 그대로 둔다**(영업부서 팀장·영업부장 등). 결재·조직 모양도 그대로다 (출처: NEXT 95, 사용자 11-19)
- **새로 만드는 화면 문구와 자동 기록 값에는 부서 이름을 쓴다** (출처: 사용자 11-17, 메모리 project_team-names-become-departments)
- 사업부서는 이름만 바꾼다. 로그인 소속이 아니다 (팀 결정, NEXT 95)
- **예산팀은 화면에 '재무팀'으로 표기한다**(이후 '재무부서') (출처: PRODUCT.md, NEXT 95)
- **디자이너는 영업팀(영업부서) 소속이다** (출처: Q-2026-11-16-85)
- **직급 순서는 부장 < 본부장 < 대표다**. 본부장을 직급 목록에 더하고, 겸직은 역할로 반영한다 (출처: NEXT 110, 사용자 11-23)
- **관리자 = 전산팀원·전산팀장 모두**다. 관리자는 서비스 운영 담당자다 (출처: Q-2026-11-15-23, Q-2026-11-16-39)

## 권한·보는 범위
### 역할별 기본 권한
- **디자이너의 기본값은 '보기'다**: 대략적인 상황(입찰 현황·공고)과 제안서로 작성된 작업까지 본다. 공고 상태 기록 같은 업무 판정·저장은 영업팀·영업팀장·영업부장만 한다 (출처: Q-2026-11-16-85)
- **그 건의 담당으로 지정된 디자이너는 예외로 수치를 모두 본다**(기관 정보 요약의 연도별 예상 금고 잔액·수익 추정 표, Word 내려받기 포함, 감사 기록). 쓰기는 ⑥ 최종 단계(제안서 디자인)만 하고, 확정은 영업이 한다 (출처: Q-2026-11-19-37, Q-2026-11-19-40)
- **디자이너도 현황판의 제안 진행 단계를 볼 수 있다. 수정은 못 한다** (출처: Q-2026-11-17-63)
- **전산팀(개발부서)은 시스템 전체에서 보기 전용이다**. 서버 기관 편집·일괄 업로드를 막는다. 사업계획 수집 요청 처리는 전산팀 업무라 허용한다 (출처: Q-2026-11-19-50, Q-2026-11-19-51)
- **재무부서에 일부 화면을 안 보이는 것은 '화면 정리' 수준이다. 기밀이라서가 아니다**. 그래서 원자료(입찰 현황판·금고 약정 요약)는 막지 않는다 (출처: Q-2026-11-20-28, Q-2026-11-20-35)
- **영업부서가 아닌 직원(디자이너·전산)도 ♥로 자기 관심 기관을 가질 수 있다**. 바뀌는 것은 본인 목록뿐이고 팀 목표에는 영향이 없다 (출처: Q-2026-11-24-104)

### 보는 범위(내 작업 / 팀 작업 / 전체)
- **'내 작업' = 내가 실제 담당인 건만이다**. 남이 대신 담당자를 지정·배정한 건은, 확정한 사람이라도 그 사람의 '내 작업'이 아니다 (출처: Q-2026-11-27-01)
- **담당이 아닌 사람에게 보여야 하는 건은 '팀 작업'에서 보인다** (출처: Q-2026-11-27-01)
- **담당이 아닌 사람이 그 건 안에 들어가 보려면, 기존 담당자가 그 사람을 담당자로 추가해 준다** (출처: Q-2026-11-27-01)
- **부장은 모든 건에 접근한다. 팀장은 자기 팀 건을 모두 본다** (출처: Q-2026-11-27-01)
- ~~'제안서 진행 현황' 기본 내 작업 + 조회 조건 팀 작업·부서 작업, 영업부서원만~~ → 내/팀/부서 조회는 제안 준비 현황으로 옮김(11-24 오후) (출처: Q-2026-11-24-21, NEXT 112·113)
- **관심 기관은 사람마다 따로다(내 ♥ = 나만의 관심 목록). 목표 기관은 팀 단위로 운영한다** (출처: Q-2026-11-24-90, Q-2026-11-24-100)
- **♥는 내 것만 켜고 끈다** (출처: Q-2026-11-24-106)
- ~~다른 사람의 관심 기록(이름·수)을 모두가 본다~~ → '관심 n명'은 필요 없음(11-25) (출처: Q-2026-11-24-106 → 사용자 11-25, Q-2026-11-25-07 해소 답)

## 결재
- **결재 요청 쪽지는 보내지 않는다. 결재함 숫자로만 알린다** (출처: Q-2026-11-23-29)
- **결재함은 사이드바가 아니라 머리 띠 단추다** (출처: 사용자 11-23, nav.js 주석)
- **영업 팀원의 결재자는 관리자가 수동으로 지정한 결재자만 인정한다** — 같은 팀 팀장 원칙을 지키기 위해서다 (출처: Q-2026-11-23-74)
- **팀장 부재 때는 팀장이 '대결 지정'으로 등록한 같은 팀 수석차장이 팀장 자격으로 승인한다**. 신청자가 수석차장이어도 된다 (출처: NEXT 110, 사용자 11-23)
- **팀장 계정이 잠기거나 퇴직 처리되면 대결도 멈춘다. 관리자가 결재자를 다시 지정한다** (출처: Q-2026-11-24-02)
- **건마다 [결재자 변경]은 위로만 된다**(팀장→부장·본부장, 본인·아래 불가, 상신 전에만). 누가·언제·어느 화면·버튼·전후 결재자·사유를 감사 기록에 남긴다 (출처: NEXT 111, 사용자 11-24)
- **결재가 걸리는 일**(화면별 상세는 각 파일)
  - 목표 기관의 넣기·빼기·옮기기·연도 변경 = 팀장 결재. 팀장 본인 = 부장 결재. 부장 = 바로 (출처: Q-2026-11-20-41, Q-2026-11-20-40)
  - [제안 확정] = 결재 없음 (출처: Q-2026-11-24-18)
  - 작성 전 결재(사전준비 승인) = 폐지 (출처: NEXT 118, 사용자 11-25)
  - 개설 신청의 팀장 결재 = 폐지. [담당자 지정] → [사전준비 시작]으로 바로 시작하고 팀장에게 알림만 간다 (출처: 사용자 11-25 · sessions/2026-11-25_0930_ca)

## 감사 기록
- **결재가 모두 끝난(최종 확정된) 건에 대한 모든 행위는 누가(사번)·어느 화면에서·어느 버튼을·언제·어느 자료에 했는지 기록한다** — 사용자가 "잊지마"라고 강조한 필수 요건이다 (출처: NEXT 68, 사용자 11-10)
- '결재 끝난 건'의 감사 범위는 개설 승인 이후다 (팀 권장, NEXT 118)
- **결재 없이 바로 하는 저장도 누가·화면·버튼·이전 값을 남긴다**(공고 상태 기록, 구분·금고 방식 수정 등) (출처: NEXT 30 11-16, Q-2026-11-25-64)

## 표 규칙(모든 표)
- **머리값(헤더)은 무조건 가운데 정렬한다** (출처: 사용자 11-26)
- **금액 칸은 오른쪽 정렬한다. 그 밖의 칸(건수·날짜 같은 비금액 숫자 포함)은 가운데다** — 금액은 자릿수를 맞춰 읽어야 한다 (출처: 사용자 11-26)
- **행 머리인 기관 이름 칸만 왼쪽 정렬한다**. 같은 성격의 표(입찰 결과·준비 현황·이사회 목록·첨부 파일명 등)에도 넓혀 적용한다 — 이름 시작 위치가 줄마다 달라지면 훑기 어렵다 (출처: Q-2026-11-26-17)
- 여러 줄 본문 칸·묶음 제목 줄·이사회 엑셀 원본 표는 예외다(왼쪽/원본) (팀 결정, 메모리 feedback_table-alignment)
- **값이 없어도 머리줄과 빈 행 1줄을 그린다. '없음' 문구만 남는 깡통 화면은 금지한다** — 빈 상태에서도 어떤 열이 채워질지 보여야 한다 (출처: NEXT 128, 사용자 11-26)
- **표 아래 기존 안내 문장은 그대로 둔다** (출처: NEXT 128, 사용자 11-26 "권장대로")
- **빈 값 칸은 '—'로 가운데에 둔다** (출처: NEXT 128, 사용자 승인 11-26)
- **조회 조건(거르기)에 있는 항목은 결과 표의 열로도 보여야 한다** (출처: 사용자 11-26 · sessions/2026-11-26_0921_ca)
- **끝난 건(탈락·협약 완료 등)은 목록에서 숨기지 않고 '상태'로 구분한다** (출처: 사용자 11-26)

## 화면 폭·대상 브라우저
- **업무 PC 브라우저는 Chrome 157·Edge 158이다**. :has를 지원해 대체 처리가 필요 없다 (출처: Q-2026-11-23-66)
- **폐쇄망 브라우저는 Chrome·Edge 105 이상으로 본다**. :has 실측은 필요 없다 (출처: 사용자 11-26·11-27, NEXT 124 ④·132)
- 전제(확인 필요): 사무실 PC 화면 폭 1280px을 기준으로 실측한다. 팀 기준이고 사용자 결정 원문은 없다. Q-2026-11-26-04 질문이 '1280px 사무실 화면'이라고 썼고 사용자가 이의 없이 답했다.
- **사무실 PC에서는 인터넷 링크가 열리지 않는다. 링크는 남기고 옆에 '(인터넷 PC에서 열림)'을 붙인다. 공고문 파일도 함께 들여온다** (출처: NEXT 78 사용자 11-12, Q-2026-11-16-108)

## 데이터 입력 공통
- **입찰 예정일을 사람이 고칠 때는 확정/추정을 같이 고른다. 확정이면 공고 링크·번호를 반드시 받는다** (출처: Q-2026-11-15-10)
- **메모의 공고 번호도 출처로 인정한다**(원문 게재기간이 끝난 확정 7곳) (출처: Q-2026-11-15-14)
- **직접 입력한 '이 기관 금고는 국민은행'은 국민은행 기관 수에 넣지 않는다. 기관 상세에만 '직접 입력'으로 표시한다** — 근거 수준을 지키기 위해서다 (출처: Q-2026-11-16-93)
- **기관 메모는 기관 상세 한 곳에 모은다** (출처: Q-2026-11-25-62)

## 용어집
- **기관 종류 6종**: 지자체·교육청·공공기관·대학·법원·병원(이 순서). 필터는 기본 전부 켠다. 교육청은 따로 구분하고, 재단법인은 '기타'로 빼지 않고 공공기관으로 둔다 (출처: NEXT 82, Q-2026-11-13-02, Q-2026-11-15-20)
- **기관 단위**: 법원만 지원을 따로 두고 나머지는 본사로 접는다. 소속 지역은 본사 주소 시군구다 (출처: NEXT 78, 사용자 11-11)
- **금고 순위 판정**(행안부 표): 일반회계가 속하면 1금고, 나머지는 2금고, 일반회계와 나머지를 한 은행이 모두 맡으면 단수금고 (출처: Q-2026-11-17-37)
- **금고 방식**(목표 기관 칸): 1금고·2금고·단수금고·주거래·기타(이름 칸). 기본은 '-'(빈 값)다 (출처: Q-2026-11-25-64, 사용자 11-26)
- **구분**(목표 기관 칸): 재유치·신규유치·되찾기. '되찾기'는 예전에 국민은행이었다가 다른 은행으로 넘어간 기관이다 (출처: Q-2026-11-19-57)
- **국민은행이 맡은 기관**: 지자체 금고 + 법원 공탁금 보관은행 + 공공기관 주거래은행. 칩으로 구분한다 (출처: Q-2026-11-16-46)
- **데려올 기회**: 다른 은행 금고 중 협약이 1년 안에 끝나는 기관 (출처: NEXT 97 ③, 사용자 11-19)
- **목표 기관**: 올해 노릴 곳. 팀 단위이고, 결재와 성과 판정 대상이다 (출처: Q-2026-11-24-79, Q-2026-11-24-90)
- **관심 기관**: 올해 목표는 아니지만 다음 회차를 노리는 기관 모두. 연도가 없고 개인별(♥)이다 (출처: Q-2026-11-17-67, Q-2026-11-24-90)
- **입찰 건**: 기관 × 입찰 대상. 목표·담당자·결재는 기관이 아니라 입찰 건마다 따로 둔다. 1·2금고 분리 공고는 별개 건이다 (출처: NEXT 125, 사용자 11-26)
