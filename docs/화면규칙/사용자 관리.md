# 사용자 관리

메뉴 위치: 시스템 관리 › 사용자 관리. 공통 규칙은 `00_공통.md`. 초판 2026-11-27(planner C 묶음).

## 목적·누가 쓰나
- **현업 평가는 '꼭 필요'다** (출처: 현업 의견표 11-10)
- **관리자는 전산팀원과 전산팀장 모두다** — 팀장이 막히는 일이 없게 (출처: Q-2026-11-15-23)
- **관리자 = 서비스 운영 담당자** (출처: Q-2026-11-16-39)

## 보는 범위·권한
- **관리자 본인의 역할·직위·결재 등급은 다른 관리자만 바꿀 수 있다** — 역할은 업무 결재 자격이다 (출처: Q-2026-11-16-39)
- **관리자 본인의 정보·상태·결재자도 다른 관리자만 바꾼다** (출처: NEXT 84, 사용자 11-16 결정 반영)
- **관리자가 남의 역할·상태를 바꿔서 결재선이 다시 계산되고, 그 결과 본인 결재자가 간접적으로 바뀌는 것은 허용한다. 이력만 남긴다** (출처: Q-2026-11-16-66)

## 화면 구성·표시 규칙
- **직위 목록에 본부장을 넣는다(부장 < 본부장 < 대표). 겸직은 역할로 나타낸다** (출처: NEXT 110, 사용자 11-23 밤)

## 동작·흐름 규칙
- **영업 팀원의 결재자(팀장)는 관리자가 수동으로 지정한 것만 인정한다. 자동으로 정해진 사람은 개설 신청 때 '관리자에게 결재자 지정 요청' 안내로 막는다** — 같은 팀 팀장만이라는 원칙을 지키기 위해서다 (출처: Q-2026-11-23-74)
- **팀장 계정이 잠기거나 퇴직 처리되면 대결도 같이 멈추고, 관리자가 팀원들의 결재자를 다시 지정한다** (출처: Q-2026-11-24-02)
