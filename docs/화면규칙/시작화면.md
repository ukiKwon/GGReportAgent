- **전산팀도 시작화면을 본다. 수정 관련 단추는 모두 뺀 보기 전용이다** (출처: Q-2026-11-19-32, Q-2026-11-19-50)
- ~~재무팀·관리자는 지도로 시작~~ → 재무(예산팀)는 '이사회 자료 작성'으로 시작(11-19 저녁 사용자 확인 피드백. 장부에는 반영되지 않음, 확인 필요). 관리자(마스터)는 지도로 시작 (출처: Q-2026-11-19-32, NEXT 97 '11-19 0d 저녁')

## 화면 구성·표시 규칙
- **맨 위 숫자 칸 '협약 곧 끝나는 국민은행 금고'에서 '곧' = 1년 안이다** (출처: Q-2026-11-19-07)
- **'다른 은행 금고 협약 종료 1년 안'(데려올 기회) 칸을 둔다** (출처: NEXT 97 ③, 사용자 11-19)
- **'이번 달 마감'은 전 기관을 센다** (출처: Q-2026-11-19-09)
- **1·2금고 은행이 서로 다른 공동 금고는 국민은행이 한쪽이라도 맡으면 국민은행 칸에 센다** (출처: Q-2026-11-19-13)
- **다음 은행이 정해진 곳도 세되, '재유치 확정'·'차기 확정' 태그를 붙여 뒤로 보낸다** (출처: NEXT 97 ③, 사용자 11-19)
- **지난 종료일은 경과 판정 대기로 둔다** (출처: NEXT 97 ③, 사용자 11-19)
- **모든 기관 유형을 포함하고 유형 탭을 둔다** (출처: NEXT 97 ③, 사용자 11-19)
- **오른쪽 패널에는 일정과 결재·확인 대기를 둘 다 둔다**(위아래) (출처: Q-2026-11-17-64)
- **'기관별 입찰 일정' 표**(사용자 11-26)
  - 날짜를 두 칸으로 나눈다: 공고(예정)일·협약 종료일. 여기에 '공고까지' 칸을 둔다 — '남은 날'이 모호했다 (출처: NEXT 126, 사용자 11-26 · sessions/2026-11-26_1400_b3)
  - 단계는 공고 전·공고 중·공고 종료 3값이다. 공고 종료는 맨 아래로 보낸다 (출처: 같음)
  - 추정 날짜는 숫자 + '추정'으로 표시한다 (출처: 같음)
  - '공고 확인 필요'와 결과 표시를 더한다. '공고 확인 필요'는 오른쪽 '공고 경과 판정' 목록과 똑같은 기준이다 (출처: 같음)
  - 관심 기관 [편집]·거르기는 만들지 않는다. 항상 전체를 보인다. 기관 분류 탭은 그대로 둔다 (출처: 같음)
- **'오늘 할 일' = 지금의 기관별 일정 표 + 이유 한 줄(규칙 문장)이다** (출처: NEXT 129, 사용자 11-26)
- **AI 기능은 이 PC(Ollama) 시범으로 먼저 하고, 운영에서는 사내 AI 연결 전까지 끈다** (출처: NEXT 129, 사용자 11-26)
