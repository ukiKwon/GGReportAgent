# 결재함

메뉴 위치: 사이드바가 아니라 머리 띠 [결재함 n] 단추. 결재선·대결·결재 등급 같은 공통 결재 규칙은 `00_공통.md`. 초판 2026-11-27(planner C 묶음).

## 목적·누가 쓰나
- **내가 처리할 결재를 받는 곳이다** (출처: Q-2026-11-23-28)
- **현업 평가는 '보류'이며, 지금대로 두고 늘리지 않는다** (출처: 사용자 1차 답 11-10)
- **재무팀장은 결재함(머리 띠)으로 결재한다. '제안서 작성·관리' 묶음은 열지 않는다** (출처: Q-2026-11-23-27)

## 보는 범위·권한
- **디자인 1차본 확인 요청은 그 기관 담당 영업의 결재 팀장 1명(부재 시 그날의 대결자)의 결재함에만 뜬다. 다른 영업팀장은 찾아서도 승인·반려할 수 없다** (출처: NEXT 108, Q-2026-11-23-58)
- **디자인 검토는 자기 팀 것만 결재할 수 있다** (출처: 사용자 11-27 "디자인검토는 자기팀것만 결재할수있도록 하자" — fb 세션, 설계 중·미적용)

## 화면 구성·표시 규칙
- **결재함은 머리 띠의 쪽지함 왼쪽 [결재함 n] 단추로 둔다. 사이드바 '제안서 작성·관리' 아래 결재함 항목은 없앤다** (출처: Q-2026-11-23-26, handoff/sessions/2026-11-19_1930_0d.md 11-23)
- **단추 옆 숫자는 내가 처리할 결재만 센다** (출처: Q-2026-11-23-28)
- **'누구 결재 대기'에 쓰는 직책 이름은 부서 이름이 바뀌어도 그대로 둔다** (출처: Q-2026-11-19-27)

## 동작·흐름 규칙
