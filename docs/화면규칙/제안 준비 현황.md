## 보는 범위·권한
- **조회 범위는 [내 작업]·[팀 작업]·[부서 작업]이고 기본은 '내 작업'** (출처: Q-2026-11-24-21, NEXT 113)
- **'내 작업' = 내가 실제 담당자인 건만이다. 남이 담당자로 지정·배정한 건은 확정한 사람의 '내 작업'이 아니다** (출처: Q-2026-11-27-01)
- **담당이 아닌 건을 봐야 하면 '팀 작업'에서 본다** (출처: Q-2026-11-27-01)
- **담당자가 아닌 사람이 그 건 상세에 들어가려면 기존 담당자가 그 사람을 담당자로 추가해 준다** (출처: Q-2026-11-27-01)
- **영업팀장은 자기 팀 건을 모두 보고, 영업부장은 소속 직원·팀의 건을 모두 본다** — ~~영업부장은 모든 건~~ → 소속 직원·팀 전부(11-27) (출처: Q-2026-11-27-01, Q-2026-11-27-02)
- **영업팀원은 자기가 담당자로 지정된 건만 상세를 연다** (출처: 사용자 11-25 '지금처럼 담당자만' sessions/2026-11-25_0930_ca.md, Q-2026-11-25-30 → Q-2026-11-27-01로 해소)
- **팀원 한 명의 건만 고르는 이름 거르기는 두지 않는다. 팀장은 '팀 작업'에서 눈으로 찾는다** (출처: Q-2026-11-24-44, Q-2026-11-24-56)
- **표의 손 체크 값(위원회 진행 상황·날짜)과 체크한 사람 이름은 영업부서 전원이 본다** (출처: Q-2026-11-19-79)
- **손 체크는 그 건의 담당 영업이 한다** — 가결위(재무)·출심위(사업부)처럼 다른 부서가 관여하는 칸도 같다 (출처: Q-2026-11-19-71)
- **담당이 정해지기 전 줄('개설 전')은 읽기 전용이라 손 칸을 체크하지 않는다** — 담당이 정해지기 전에 위원회가 열리는 일은 거의 없다 (출처: Q-2026-11-24-12, NEXT 102 결정 A)

## 화면 구성·표시 규칙
- **한 줄 = 입찰 건(기관 × 입찰 대상)이다. 한 기관에 주제가 다른 공고가 여러 개면 줄도 여러 개다** (출처: 사용자 11-26 NEXT 125, A안 시안 handoff/agents/history/2026-11-26_입찰대상_목록_시안/index.html)
- **'입찰 대상' 칸을 둔다. 다루는 범위 = 주거래은행·금고 + 자금관리 금융기관 + 법인카드** (출처: 사용자 11-26 NEXT 125)
- **1금고·2금고는 분리 공고로 보아 별개의 건(별개 줄)이다** (출처: 사용자 11-26 15시 반 NEXT 125)
- **공고명(RFP명)도 보인다** (출처: 사용자 11-26 16시 전 NEXT 125)
- **열 머리 '기관'을 누르면 기관 이름으로 정렬된다** — 그래서 A안(한 줄 = 입찰 건)이 낫다 (출처: 사용자 11-26 16시 전 NEXT 125)
- **목록 열 = 기관 · 입찰 대상 · 공고명 · 마감 · 담당 · 단계, 그 뒤에 체크리스트 칸** (출처: NEXT 125 — 사용자 답을 시안에 반영한 열 구성)
- **공고가 나기 전에 시작한 건에는 '아직 입찰 공고 전' 태그·표식을 붙인다** (출처: Q-2026-11-25-04)
- **손 칸 값은 V·△·-·빈칸이고, 날짜는 자동으로 들어간다** (출처: Q-2026-11-19-70, Q-2026-11-20-02)
- **'제출서류' 칸** — ~~서류 전체 확인 한 칸을 담당이 체크(11-20)~~ → 빠진 서류가 0건이면 사람 확인 없이 자동 V(11-23). RFP 서류 대조 화면이 생기기 전까지는 손 체크를 유지한다 (출처: Q-2026-11-20-20, Q-2026-11-20-31, Q-2026-11-23-41. 11-27 새 요구는 기관 상세 11단계·NEXT 133)
- **결과발표 칸에 예전 방식의 '완료·진행' 체크가 남은 건: 진행 중인 건은 '추가확인'으로 표시하고 담당자가 칸을 눌러 선정·탈락(또는 대상 아님·비움)을 고르면 표시가 사라진다. 이미 중단·취소로 끝난 건은 '추가확인'을 띄우지 않고 예전에 체크한 날짜만 회색으로 남기며, 실적 집계에는 선정·탈락 어느 쪽에도 넣지 않는다** (출처: 사용자 11-27 시안 `handoff/agents/history/2026-11-27_결과발표_재선택_시안/index.html` 2번 ①·3번 가, Q-2026-11-27-17 — 적용 6c781be5, 용어 '추가확인' 3a767b81)
- **제안서 제출과 협약식 값은 이 화면에서 등록한다. 협약식이 '대상 아님'이면 결과발표(선정)를 협약 완료로 본다** (출처: 사용자 11-25 sessions/2026-11-25_0930_ca.md, NEXT 120)
- **끝난 건(탈락·중단·입찰 없음 등)도 숨기지 않고 상태로 구분한다. 거르기에 쓰는 항목은 표의 열로도 보인다** (출처: 사용자 11-26 — 메모리 feedback_filter-shown-as-column, 00_공통 적용)
- **표는 머리값 가운데, 기관 이름 칸만 왼쪽, 나머지 칸은 가운데** (출처: Q-2026-11-26-17 — 준비 현황까지 넓힘)
