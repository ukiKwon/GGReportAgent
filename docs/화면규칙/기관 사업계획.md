# 기관 사업계획 (기관·입찰 현황 › 기관)

## 목적·누가 쓰나
- **제안을 준비할 때 쓰는 화면이다** (출처: Q-2026-11-16-01)
- **원자료는 기관 홈페이지 공개자료다** (출처: Q-2026-11-16-02)
- **언론 보도를 모은 '구정 현황' 같은 자료는 넣지 않는다** (출처: Q-2026-11-16-96)
- **홈페이지에서 사업계획을 못 찾은 기관은 관련 뉴스 기사를 정리해 대신 준비한다** — 기관 특성상 사업계획이 없을 수 있다 (출처: Q-2026-11-20-63, NEXT 107)

## 보는 범위·권한
- **메뉴는 영업팀·전산팀 전원에게 보인다. 예산팀(재무)은 제외한다** (출처: Q-2026-11-17-25)
- **예산팀에게는 기관 상세 아래 '사업계획' 요약 칸도 숨긴다**(메뉴 결정과 맞춤) (출처: Q-2026-11-17-32)
- **디자이너는 보기만 한다** (출처: Q-2026-11-16-85 — 디자이너 기본값)
- **전산팀은 보기 전용이지만 사업계획 수집 요청 처리는 허용한다** (출처: Q-2026-11-19-50)
- **관심 기관은 직원 개인의 영역이다. 결재 없이 각자 넣고 뺀다** (출처: Q-2026-11-20-14)

## 화면 구성·표시 규칙
- **기본은 모든 기관을 보인다. [목표/관심]은 정렬이다 — 누르면 목표·관심 기관이 맨 위로 간다** (출처: Q-2026-11-20-13)

## 동작·흐름 규칙
- **영업부서가 자료 없는 기관 여러 곳을 한 번에 수집 요청할 수 있다**(처음 전체 세팅 때, 목표·관심 기관 최신 확인 때) (출처: Q-2026-11-19-04)
- **흐름**: [수집 요청] → 전산 담당에게 목록·알림 → 처리 화면에서 중복을 뺀 뒤 [실행] (출처: Q-2026-11-17-47)
- **밖으로 보내는 값은 기관 ID·이름이다** — 사업계획이 누락된 기관이라 관심 기관 노출 문제가 없다 (출처: Q-2026-11-17-52)
- **최근에 자료를 받은 기관도 요청은 실행한다. 이전 사업계획 출처는 메인 도메인만 기록·확인한다(전체 URL 아님). 처리 화면에서 같은 요청은 하나로 합친다** (출처: Q-2026-11-17-53)
- **새 자료가 들어오면 그 요청은 자동으로 끝난다** (출처: Q-2026-11-17-55)
- **사업계획 수집만 외부 프로그램을 직접 부르는 예외다**(인터넷 PC 시험용, 내부망에서는 꺼짐) (출처: Q-2026-11-17-48)
- **정기 처리 주기는 주 최대 1회(목요일)이고, 필요하면 수시로도 한다** (출처: Q-2026-11-20-60)
- **반입 파일의 '수집자' 칸에는 사번이 아니라 수집 프로그램 식별자를 적는다. '누가'는 업로드한 관리자 사번으로 남긴다** (출처: Q-2026-11-16-09)
- 처리 쪽 규칙(실행 권한·반입자 기록)은 [사업계획 수집 요청](<사업계획 수집 요청.md>)에 있다
