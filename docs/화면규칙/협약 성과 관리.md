# 협약 성과 관리

메뉴 위치: 협약·관계 관리 › 세 번째 항목. 공통 규칙은 `00_공통.md`. 초판 2026-11-27(planner C 묶음).

## 목적·누가 쓰나
- **화면 제목은 '협약 성과 관리'이고, 협약·관계 관리의 세 번째 메뉴다** (출처: Q-2026-11-20-17)
- **목표 기관이 협약을 따냈는지를 연도별로 판정해 보여 준다** (출처: Q-2026-11-20-17)

## 보는 범위·권한
- **영업부서 전원이 본다** (출처: Q-2026-11-20-17)
- **디자이너·개발부서도 조회할 수 있다. 담당자 이름은 붙이지 않는다** — 이름이 붙으면 사실상 개인별 성과표가 된다 (출처: Q-2026-11-20-29·Q-2026-11-20-36, Q-2026-11-27-04 사용자 11-27)
- **디자이너·개발부서의 수정·등록은 막는다. 막는 방법은 코드가 아니라 메뉴 관리·권한 관리 화면의 설정이다** (출처: Q-2026-11-27-04, 사용자 11-27)
- **재무부서에 보이지 않는 것은 화면 정리 차원이지 기밀이라서가 아니다** — 그래서 입찰 현황판·금고 약정 요약까지 막지는 않는다 (출처: Q-2026-11-20-28·Q-2026-11-20-35)

## 화면 구성·표시 규칙
- **연초나 결과를 기다리는 동안 처음 열면, 결과가 몇 곳 났고 몇 곳 남았는지를 먼저 보인다** (출처: Q-2026-11-23-31)
- **표는 성공한 기관을 맨 위에 둔다** (출처: Q-2026-11-20-43)
- **연중에 목표에서 뺀 기관은 따로 표시한다** (출처: Q-2026-11-20-17)
- **성과는 '재유치·신규' 두 가지로 센다. 되찾기를 따로 세지 않는다** (출처: Q-2026-11-23-45)
- **표의 '제안 진행' 칸은 제안을 확정한 해를 목표 연도로 보고 맞춘다(근사)** (출처: Q-2026-11-20-24)

## 동작·흐름 규칙
- **판정 근거는 금고 약정 기록이다. 국민은행 약정 기록이 있으면 달성이다** (출처: Q-2026-11-20-17·Q-2026-11-20-39)
- **성공 = 1금고·2금고 모두, 그리고 입찰 없이 국민은행 약정이 연장된 경우까지** (출처: Q-2026-11-20-16)
- **목표에 넣은 연도로 센다. 2026 목표면 2026년에 협약을 달성한 기관만 성과다** (출처: Q-2026-11-20-17·Q-2026-11-20-23)
- **입찰 공고가 나지 않아 넘어간 목표는 실패로 세지 않는다** (출처: Q-2026-11-20-23·Q-2026-11-20-30)
- **다른 은행에 진 기관은 다음 해 관심 기관으로 넘긴다** (출처: Q-2026-11-20-39, 11-26 유지 Q-2026-11-26-14)
- ~~달성하지 못한 목표는 다음 해 목표로 자동으로 넘긴다~~ → 자동 이월을 없앤다(11-26). 기관 입찰은 3·4년 단위다 (출처: Q-2026-11-20-39 → Q-2026-11-26-14)
- **'RFP 협약 개시일' 입력란은 남긴다. 이 화면이 약정이 몇 년 입찰의 결과인지, 대기·미등록인지를 가를 때 이 날짜를 쓴다. 입력 자리는 기관 상세 팝업이다** (출처: Q-2026-11-26-16)
