# 화면 규칙집 — 색인

사용자의 결정을 화면별로 모아 둔 정본이다(사용자 11-27 "내 결정들은 기획 에이전트가 모두 알고 정리해 놔야 한다, 정확히는 화면별 규칙을").
- 파일 이름 = 메뉴 이름(`frontend/js/nav.js` nav.CATEGORIES). 메뉴 이름이 바뀌면 파일 이름도 바꾸고 여기 링크를 고친다.
- 모든 화면에 걸친 규칙(역할·부서·직책·권한·보는 범위·결재·감사·표·화면 폭·브라우저·용어)은 [00_공통](<00_공통.md>)에 있다. 화면 파일은 공통 규칙을 되풀이하지 않는다.
- 규칙 한 줄 형식: `- **규칙** — 이유 (출처: Q-…/NEXT n/사용자 MM-DD)`. 나중 답이 앞 답을 바꾸면 `~~옛 규칙~~ → 바뀜(MM-DD)`으로 남긴다. 미확정은 각 파일 '열린 질문' 절에 질문 id만 적는다.
- 코드가 지금 어떻게 동작하는지는 적지 않는다. 사용자 결정만 적는다. 팀 결정은 "(팀 결정)"으로 따로 표시한다.
- 갱신 절차: 사용자 답 → 메인이 질문 장부(`handoff/questions.json`)에 기록 → planner가 갱신안(보고 8절) → 메인이 이 폴더에 반영·커밋.
