## 동작·흐름 규칙
- **업무 순서: RFP로 기관 요청 조건 확인 → 제안 내용 사내 승인 → 수익성 분석 최종 확정 → 이사회 안건 작성** — 수익성 분석이 자주 바뀌어 안건은 확정 뒤에 쓴다(미리 준비는 가능) (출처: NEXT 59 사용자 답 11-09 Q1)
