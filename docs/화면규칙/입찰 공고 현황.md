# 입찰 공고 현황 (기관·입찰 현황 › 입찰 공고)

## 목적·누가 쓰나
- **전국 공고(Q1: 공고가 떴나)와 경과를 확인·기록하는 화면이다. 목록 형식으로 Q2도 본다** (출처: Q-2026-11-25-38 안 A)
- **시장 전체 공고 상태 목록(지도의 목록판) + 공고 상세 자료다** (출처: NEXT 30 '역할 재정의', 사용자 11-16 오후)
- **실제 업무 화면이다. 영업팀이 공고 상태와 의견을 실제로 기록한다** (출처: Q-2026-11-16-11)
- **입찰 현황판과 나눠서 유지한다. 이름은 '입찰 공고 현황' 그대로다**. ~~'공고 상태 기록'~~ 철회(11-16) (출처: Q-2026-11-16-10, Q-2026-11-16-14, Q-2026-11-16-23)

## 보는 범위·권한
- **팀 공용이다. 영업팀이 처리하면 전산팀 같은 다른 팀에도 공유된다(조회). 수정은 영업팀만 한다** (출처: NEXT 30, 사용자 11-09 ④)
- **공고 상태 저장은 영업팀·영업팀장·영업부장만 한다. 디자이너는 공고 확인(보기)만 한다** — 상태를 적으면 미처리 목록에서 빠지는 업무 판단이 되기 때문이다 (출처: Q-2026-11-16-85)

## 화면 구성·표시 규칙
- **한 줄 = 입찰 회차다. 유찰 뒤 재공고는 같은 건의 2차 공고로 보고, 한 줄 안에 이력으로 쌓는다** (출처: Q-2026-11-16-12)
- **예정일이 지났는데 공고를 확인하지 못한 회차도 한 줄로 둔다** (출처: NEXT 30, 사용자 11-16)
- **담당자가 고르는 상태는 공고 진행 중 / 공고 종료 / 지연·재공고 대기 / 입찰 없음(연장·지정)이다. '입찰 없음'을 고르면 그 회차를 바로 닫는다** (출처: NEXT 30 사용자 11-09 ③, Q-2026-11-16-79)
- **근거(원문·주소) 대신 '담당자 의견'과 '담당자명'만 받는다** (출처: NEXT 30, 사용자 11-09 ⑥)
- **담당자명은 그날 확인해 적은 사람이다(로그인 사용자가 자동으로 들어감)** (출처: Q-2026-11-16-13)
- **이 화면에 경과 건을 따로 강조하는 패널을 둔다** (출처: NEXT 30, 사용자 11-09 ②)
- **예정일이 지난 기관은 이 화면에서만 본다(지도에서는 뺀다)** (출처: Q-2026-11-25-39)
- **공고 상세 자료는 지금은 공고번호·원문 링크·접수 기간·출처까지 보인다. 공고문 PDF 보기와 배점표는 현업 의사결정 질문으로 넘겼다** (출처: Q-2026-11-16-36)
- **'다가오는 기관별 공고현황' 막대**: 월별 입찰 예정 막대를 없애고 이것으로 바꾼다. 5줄(지자체·공공기관(교육청 포함)·법원·대학·병원) × 1개월 내 / 1~3개월 / 3~6개월 / 공고 확인 어려움. '다가오는' 것만 보이므로 날짜 미상·6개월 초과·공고 중은 뺀다 (출처: 사용자 11-23 · sessions/2026-11-23_1700_b0, Q-2026-11-23-63, Q-2026-11-23-64 — 장부 답은 '사용자 답 반영(b0)'뿐)
