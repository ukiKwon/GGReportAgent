# 랜딩 페이지

위치: 로그인 앞 첫 화면(메뉴 밖). 공통 규칙은 `00_공통.md`. 초판 2026-11-27(planner C 묶음).

## 목적·누가 쓰나
- **'랜딩 페이지'는 지금 기능과 앞으로의 AI/AX를 포트폴리오처럼 소개하는 새 첫 화면이다. 로그인 화면을 다듬는 일이 아니다** (출처: 사용자 11-26, 메모리 project_landing-page-term)
- **사내 시연용이다** (출처: 사용자 승인 계획 11-26, handoff/sessions/2026-11-26_1112_c3.md)
- **첫 접속 → 랜딩 → [로그인] → 기존 로그인 화면 순서다** (출처: 사용자 승인 계획 11-26)

## 보는 범위·권한
- **로그인 전에 보이는 화면이므로 실제 자료가 아닌 가상 자료로 보인다** (출처: 사용자 승인 계획 11-26 '예시 화면(가상 자료)')

## 화면 구성·표시 규칙
- **위쪽은 AI/AX의 완성 모습을 '예시 화면'으로, 아래쪽은 제안 준비 현황 칸 순서의 업무 흐름을 움직이는 예시로 보인다. 인상 강한 AI를 위에 둔다** (출처: 사용자 승인 계획 11-26)
- **AI 장면은 7가지다: ① 오늘 할 일(남은 일정 우선순위, 시작화면) ② 공고문 평가표 읽기 ③ 제안서 속 다른 기관 언급 찾기·사용자 확인 ④ '지자체 계획 확인하기' 배경지식 ⑤ 이사회 발표 대본 ⑥ 요약서·협력 과제 초안 ⑦ 회의록 정리·지식 검색** — 이 목록은 앞으로의 AI 개발 방향이기도 하다 (출처: 사용자 11-26, 메모리 project_landing-page-term, NEXT 129)
- **AI가 제안서를 대신 쓰는 장면은 넣지 않는다** (출처: 사용자 11-26, NEXT 127)
- **'업무 흐름'에서 화면을 보여야 하는 곳은 실제 화면을 기준으로 캡처하거나, 예상되는 기능 화면을 움직임으로 잘 표현한다** (출처: 사용자 11-27, handoff/sessions/2026-11-27_1d_랜딩.md)
- **승인된 시안이 화면 기준이다** (출처: 사용자 11-26 "맘에 들고… 이대로 진행", 시안 handoff/agents/history/2026-11-26_랜딩페이지_시안/index.html)

## 동작·흐름 규칙
- **상세 AI 기능이 실제로 생기면 그 장면만 바꾼다** (출처: 사용자 11-26, NEXT 127)
- **랜딩과 실제 기능이 다른 세 곳(③ [고침] 동작, ②④ 원문 쪽수, ⑤ 장별 대본)은 실제 기능을 랜딩에 맞춰 만든다. 랜딩 문구는 그대로 둔다** (출처: NEXT 129, 사용자 11-26 저녁 "A안대로")
- **랜딩·로그인·메뉴 화면마다 자기 주소(`#/…`)를 둔다. 지금은 `#` 방식이고, 운영 배포 때 경로 방식을 다시 정한다** (출처: NEXT 135, 사용자 11-27)
