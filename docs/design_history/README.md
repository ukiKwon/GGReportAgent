# docs/design_history/ — 화면 디자인 전/후 이력

- **`index.html`** 한 파일에 화면 변경마다 전/후 비교 장(`section.ch`)이 쌓입니다(최신이 위, 목차 링크 포함). 브라우저로 열어 봅니다.
- **규칙**: 화면(마크업·CSS·문구·메뉴)이 바뀌는 커밋마다 새 장을 더합니다. 장마다 ①왜 ②전 ③후(대비 숫자·모의 화면) ④날짜·커밋을 적습니다. `design-reviewer`가 커밋 전에 장이 추가됐는지 확인하고, 빠졌으면 메인이 더합니다(CLAUDE.md 5절).
- 모의 화면은 실제 화면을 단순화한 그림이며 토큰 값만 같게 맞춥니다. 정확한 모습은 앱에서 확인합니다.
- 근거: `handoff/agents/design-reviewer/` 보고서, `DESIGN.md`.
