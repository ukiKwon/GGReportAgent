## [사내 공용 LLM API 관련 — 담당: AI/정보화 부서]

### 1. 사내 공용 LLM API의 호출 규격이 OpenAI 호환입니까?

- **여쭙는 이유**: 시스템이 문서 요약·검증에 LLM을 호출합니다. OpenAI 호환
  (`POST /v1/chat/completions`, JSON 스키마 구조화 출력 지원)이면 어댑터를 얇게
  구현할 수 있고, 독자 규격이면 요청/응답 변환 계층을 추가로 설계해야 합니다.
- **구체 확인 사항**:
  - ⓐ 엔드포인트 URL 형식 (예: `https://llm.내부도메인/v1/chat/completions`)
  - ⓑ 인증 방식 (Bearer 토큰 / API Key 헤더 / 사내 SSO 연동 등)
  - ⓒ 구조화 출력(JSON schema 강제) 지원 여부
  - ⓓ 사용 가능한 모델 이름 목록과 컨텍스트 길이

### 2. 사내 API가 임베딩(embedding) 엔드포인트를 제공합니까?

- **여쭙는 이유**: 현 시스템의 문서 검색은 "전문검색 + 의미(벡터) 검색"
  하이브리드입니다. 임베딩 API가 **없으면 의미 검색을 포기하고 전문검색
  단독**이 되며, 검색 품질이 현 시스템보다 낮아집니다 — 이 경우 품질 저하를
  감수할지 사전 합의가 필요해 미리 여쭙습니다.
- **구체 확인 사항**: 임베딩 엔드포인트 유무, 있다면 모델명·차원 수·호출 규격.

## [Oracle DB 관련 — 담당: DBA]

### 3. Oracle Text를 사용할 수 있습니까?

- **여쭙는 이유**: 한글 전문검색 구현이 두 갈래로 갈립니다 —
  Oracle Text `CONTEXT` 인덱스(표준적, 운영 이관 깔끔) vs. Java 인메모리
  색인(Oracle Text 불가 시 폴백). **설계가 통째로 갈리는 항목**이라 가장
  먼저 확인이 필요합니다.
- **구체 확인 사항**:
  - ⓐ Oracle Text 설치·라이선스 사용 가능 여부
  - ⓑ 한글 형태소 렉서(`KOREAN_MORPH_LEXER`) 사용 가능 여부
  - ⓒ 인덱스 생성 권한을 애플리케이션 계정에 줄 수 있는지
- **답변**:

### 4. Oracle 버전은 무엇입니까? (11g / 19c / 23ai)

- **여쭙는 이유**: 11g면 `IDENTITY` 컬럼과 일부 JSON 함수를 쓸 수 없습니다.
  현 스키마는 애플리케이션이 PK를 생성하는 방식이라 영향이 크지는 않지만,
  DDL 작성 전에 버전을 못 박아야 재작업이 없습니다.

## [WAS/인프라 관련 — 담당: 인프라/미들웨어]

### 5. WebLogic 버전은 무엇입니까? (12.2.1.x / 14.1.1 / 기타)

- **여쭙는 이유**: 12.2.1.x는 Servlet 3.1, 14.1.1은 Servlet 4.0입니다. 실시간
  진행 표시(SSE)는 둘 다 가능하지만 `weblogic.xml` 설정과 프록시 타임아웃
  값이 버전에 따라 달라집니다.
- **답변**:

### 6. eGovFrame 표준 템플릿의 `web.xml`/공통 필터에 `async-supported`가 켜져 있습니까?

- **여쭙는 이유**: 시스템의 대화 화면과 작업 진행 표시가 SSE(Server-Sent
  Events)를 씁니다. 표준 템플릿의 공통 필터 체인에 `async-supported=true`가
  빠져 있으면 **SSE가 필터 단계에서 막혀** 해당 화면이 동작하지 않습니다.
  템플릿 커스터마이징 가능 여부도 함께 알려주시면 좋습니다.

### 7. WAS 앞단에 웹서버(Oracle HTTP Server, Apache 등)를 두는 구성입니까?

- **여쭙는 이유**: SSE는 앞단 프록시의 **응답 버퍼링과 유휴 타임아웃**에 특히
  취약합니다(버퍼링이 켜져 있으면 실시간 표시가 멈추고, 타임아웃이 짧으면
  진행 중 연결이 끊깁니다). 구성에 따라 프록시 설정 변경 요청이 필요합니다.
- **구체 확인 사항**: 웹서버 유무·종류, 프록시 버퍼링/타임아웃 설정 변경을
  요청할 수 있는 창구.
