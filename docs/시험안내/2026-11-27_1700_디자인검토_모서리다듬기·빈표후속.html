모서리 다듬기 (팝업·패널·단추·칩)

Ctrl+F5이 커밋 · 8080 Ctrl+F5 뒤
어디서해 볼 것기대 결과확인
아무 팝업이나 패널 (예: 결재 요청 창)팝업을 열고 모서리를 본다팝업·패널은 살짝 둥글고(6px), 단추·입력칸·칩은 조금 덜 둥글다(4px). 팝업 머리 아랫선이 연한 회색

선택된 탭 밑줄 곧게

Ctrl+F5이 커밋
어디서해 볼 것기대 결과확인
시작화면 → '기관별 입찰 일정' 탭탭을 눌러 본다, 선택된 탭 밑줄의 양 끝을 본다밑줄 양 끝이 휘지 않고 곧게 끊긴다

이사회 자료 — 옆줄 있는 상자 모서리

Ctrl+F5이 커밋
어디서해 볼 것기대 결과확인
이사회 자료 작성 → 목록 행 열기 → '작성' 탭 위 편집줄편집줄의 왼쪽 모서리를 본다왼쪽 굵은 색 줄 쪽 모서리는 각지고, 오른쪽 모서리만 둥글다
이사회 자료 → 같은 행 → '회의록' 탭 '대외비·참고용' 안내안내 상자의 모서리를 본다왼쪽 굵은 색 줄 쪽 모서리는 각지고, 오른쪽 모서리만 둥글다

표 카드·사례 카드 모서리 6px

Ctrl+F5이 커밋
어디서해 볼 것기대 결과확인
이사회 자료 → 표가 든 카드카드 모서리를 본다모서리가 6px로 둥글다
로그인 화면 → 오른쪽 사례 카드카드 모서리를 본다모서리가 6px로 둥글다

범례 작은 네모 3개 (거의 각진 2px)

Ctrl+F5이 커밋
어디서해 볼 것기대 결과확인
입찰 공고 현황 → '다가오는 기관별 공고현황' 범례범례 작은 네모 3개를 본다네모가 거의 각진 모양(2px)으로 보인다

빈 표 후속 — 없는 말로 검색 시 빈 줄 높이·안내 문구

Ctrl+F5이 커밋
어디서해 볼 것기대 결과확인
예상 공고현황 → '전체 입찰건' 창검색칸에 없는 말을 넣어 검색한다머리줄 아래 빈 줄 높이가 다른 줄과 같다(전에는 얇았음)
같은 창, 표 아래본다'조건에 맞는 입찰건이 없습니다. 검색어를 지우세요.' 문구가 보인다
같은 창, 검색칸검색어를 지운다안내 문구가 사라지고 목록이 다시 채워진다
