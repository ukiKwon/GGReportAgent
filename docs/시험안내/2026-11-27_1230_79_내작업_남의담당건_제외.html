'내 작업'에서 다른 직원이 담당인 건 숨김

Ctrl+F5e3306f88 · 79 세션 · 서버는 이미 재기동됨(7e2fc7b1 이후 빌드) — 화면 새로고침만 하면 됨
바뀐 규칙: '내 작업'에는 ①내가 지금 담당자인 건 ②아직 사전준비를 시작하지 않은 건 중 내가 확정한 건 ③끝난 건 중 내가 예전에 담당이었던 건만 나옴. 내가 확정만 하고 다른 사람이 담당을 맡은 건은 '내 작업'에 나오지 않고 '팀 작업'·'부서 작업'에서 봄. 그 건을 열어 보려면 지금 담당자가 나를 담당자로 추가해 주면 되고, 추가되면 바로 '내 작업'에 나옴.
어디서해 볼 것기대 결과확인
김영업 로그인 → 메뉴 '제안 준비 현황' → 위쪽 [내 작업]목록을 본다사립학교교직원연금공단(김영업이 확정, 담당은 이영업)이 목록에 없어야 함
같은 계정(김영업) → 제안 준비 현황 → [팀 작업]사립학교교직원연금공단을 찾는다보여야 함(김영업과 이영업이 같은 팀일 때. 다른 팀이면 [부서 작업]에서 보임)
이영업 로그인 → 제안 준비 현황 → [내 작업]사립학교교직원연금공단을 찾아 연다목록에 보이고 평소처럼 열려야 함
(선택) 이영업 → 사립학교교직원연금공단 → 1단계 '담당자 지정'에서 김영업을 담당자로 추가. 실제 자료가 바뀌므로 시험 뒤 되돌릴지 먼저 정하고 할 것추가한 뒤 김영업 로그인 → [내 작업]을 본다김영업 [내 작업]에 그 건이 나타나고 열려야 함
김영업 로그인 → 제안 준비 현황 → [내 작업]김영업이 확정만 하고 아직 사전준비를 시작하지 않은 건이 있으면 그 건을 찾는다(없으면 건너뜀)그 건은 [내 작업]에 그대로 보여야 함
