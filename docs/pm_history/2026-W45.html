2026-W45 11-02 ~ 11-08

이사회 자료 '작성 모드'가 나왔다. 수익성 분석표를 올리면 초안이 채워지고, 매핑 확정·붙임 5·행·열 편집까지 들어갔다

한 일

  • PC 초기화 뒤 개발 환경을 다시 세웠다(주 중에 다른 PC 한 대도 새로 세팅). 이사회 양식 편집 화면을 끝냈다
  • 이사회 자료 작성 모드: 엑셀을 올리면 칸이 채워지고, 원본과 다른 값·합계 차이를 보여 주며, 수정 사유를 적고, 표를 복사할 수 있다. 서버와 화면 모두 완성
  • 사용자가 말로 설명한 수익성 분석표 구조와 매핑표를 받아 매핑을 확정했다. 여러 칸 합산·억원 환산·괄호 병기 같은 새 기능을 서버에 넣었다
  • 붙임 5(세부 수익성 분석표, 26행×9열)를 추가했고, 워드에서 새 쪽 한 장에 들어가게 맞췄다(사용자가 Word로 확인)
  • 양식의 행·열을 넣고 빼는 기능과 되돌리기를 만들었다. '잠김'은 없애고 안내 문구로 대신했다
  • 작성 모드 화면 다듬기: 영역 층 구분과 그림자, 선택한 칸 강조, 클릭한 칸이 가려지지 않게 보정, 오류 상자에서 바로 권한 신청으로 가는 버튼
  • 일하는 방식 정비: 에이전트 모델 배치, 쓰기 권한은 작업 한 건씩만, 올리기 전 보안·PM·정리 담당 점검(PUSH-GATE). 할 일 목록과 운영 규칙 문서를 줄여 다시 정리했다
  • 보안 후속: 쓰기 경로 감시 장치가 node가 없을 때 그냥 통과시키던 문제를 고쳤다. 서버 전체 테스트를 저장소 안에서 다시 돌려 통과를 확인했다

  • 11-02 메뉴별 DB 설계 방향 7건 확정(기관 정보의 기준은 DB, 기관은 ID와 별칭으로 식별 등)
