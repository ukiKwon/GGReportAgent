2026-W46 11-09 ~ 11-15 · 진행 중

(진행 중) 보안 구멍 3건을 막고 보고서 저장 문제를 해결했다. 작성 모드 화면 오류를 고치는 중이고, 경과 건 팝업 요건이 새로 들어왔다

한 일

  • 에이전트 보고서가 일부만 저장되던 원인을 찾아 고쳤다(보고 본문이 다른 자리에 담겨 있었음). 내용 없는 보고서 11건을 지웠고, 이후 에이전트 8건이 빠짐없이 1건씩 저장되는 것을 확인했다
  • 보안 패치: 업로드한 엑셀이 개인정보 검사에서 서버를 오래 붙잡는 문제를 막았고, 너무 큰 파일은 읽기 전에 개수를 세어 거부하게 했다(NEXT 48 ①②). 샘플 엑셀 3개를 실제 화면에 올려 정상 동작을 확인했다
  • 업로더가 한글(HWPX) 문서를 읽을 때 외부 내용을 끌어올 수 있던 위험(XXE)을 막았고, 실패 메시지에 내부 정보가 드러나지 않게 했다
  • 작성 모드에서 원본 패널이 스크롤할 때 위로 기어오르던 문제와 버튼이 가려지던 문제를 고쳤다. 독립 검증을 통과했고 저장(커밋)했다
  • 경과 건 팝업 요건을 받았다. 기획 분석 결과, 공고 상태 칸이 없어 팝업만 만들면 같은 건이 계속 뜬다. 그래서 '데이터 정정 → 상태 칸 → 하루 1회 팝업' 순서를 권장했다
  • 검증 중에 서버가 브라우저 캐시를 막지 않아, 배포 뒤에도 옛 화면이 돌 수 있는 위험을 새로 찾았다

결정·요건 변경

  • 11-09 입찰 공고 예정일이 지난 건이 있으면 영업팀 담당자에게 팝업으로 알리고 확인을 받기로 함. 기존 입찰 공고 현황 화면과 연결 — 사용자 신규 요건. 세부 6개 질문은 답 대기
