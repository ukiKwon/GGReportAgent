# docs/pm_history/ — PM 주간 이력

- **`index.html`** 한 파일에 주 단위 이력이 이어져 있습니다(최신 주가 위). 브라우저로 열어 봅니다.
- **갱신 규칙**: 매주 금요일 `pm` 에이전트가 그 주(월~일)의 한 일·결정·요건 변경·숫자·열린 채 넘어간 것을 정리하면, 메인이 `index.html` 맨 위(목차 바로 아래)에 `<section class="week" id="YYYY-Www">`를 추가하고 목차 링크를 더합니다. 맨 아래 "열린 항목·답 대기 질문" 표도 그날 기준으로 고칩니다. 금요일에 세션이 없으면 다음 세션 첫 작업으로 합니다.
- **쓰는 말**: 비개발자가 읽는 업무 언어로 쓰고, 근거가 없는 내용은 적지 않습니다(기록이 없으면 "기록 없음").
- **근거 자료**: `handoff/`의 날짜별 summary, `done.md`, `NEXT.md`, `handoff/agents/` 보고서.
- 2026-07-22 ~ 2026-11-09 구간은 2026-11-09에 한 번에 정리했습니다. 2026-09-14 ~ 10-18은 기록 파일이 없어 "기록 없음"입니다.

규칙 본문: [`CLAUDE.md`](../../CLAUDE.md) 4절. 폴더 안내: [`handoff/README.md`](../../handoff/README.md).
