# 금고은행 입찰 히트맵 대시보드 — 기능 확장 설계 문서

- **작성일**: 2026-07-25
- **상태**: 확정 (브레인스토밍 승인 완료)
- **위치**: `dashboard/`
- **선행 스펙**: `docs/superpowers/specs/2026-07-23-treasury-bid-dashboard-design.md`
  (초기 대시보드 설계). 본 문서는 그 위에 얹는 **2차 기능 확장**을 다룬다.
- **선행 작업(같은 날 오전)**: 자리표시자 네모 지도를 **실제 행정경계 GeoJSON**(전국 17시도·
  서울 25구·경기 42시군, kostat 2018 → 표준코드 remap + 간소화)으로 교체하고, 지역 드릴인/
  fly-to/오버레이/탭2 카드 드릴인 버그를 수정·검증 완료. 본 확장은 그 위에서 진행한다.

---

## ① 목적 / 범위

현업 사용자가 **입찰 정보를 직접 입력·관리**하고, 랭킹을 **관심도/유형별로** 살펴보며,
선택한 기관을 지도에서 **즉시 식별**할 수 있도록 대시보드를 확장한다.

**이번 세션 범위**
- 데이터 스키마 개편(입찰주기·지난입찰일·수정일·관심기관 추가, confidence 자동유도)
- CSV 템플릿 다운로드/업로드(라이브러리 없음)
- 랭킹 패널 개편(반응형 높이 · 정렬 토글 · 유형 필터 · ♥관심 · 더보기 팝업+검색)
- 선택 기관 지도 물결(ripple) 효과

**범위 밖(요구사항으로 보존)**
- **입찰정보 확인 Agent** — 폐쇄망에서 공고/외부를 확인해 데이터 파일을 생성하고 특정
  경로에 저장하면 대시보드가 그대로 읽는 구조. 선행 스펙의 "(4) 에이전트화"에 해당하며,
  외부검색/동기화 제약은 그 별도 프로젝트에서 다룬다. **본 대시보드는 "정해진 데이터
  파일을 읽어 표시한다"까지만 책임**지므로, 훗날 agent를 붙여도 대시보드 수정이 필요 없다.

## ② 데이터 스키마 (코드=영문 키, 화면=한글 라벨)

| 코드 키 | 화면 라벨 | 값 / 비고 | 필수 |
|---|---|---|---|
| `name` | 기관명 | | ✅ |
| `type` | 기관구분 | 지자체 / 대학병원 / 공공기관 / 공기업 | ✅ |
| `region` | 지역코드 | 표준코드(11 서울·41 경기·28 인천 …) | ✅ |
| `term` | 입찰주기 | **1~10년** (정수 년) | ⛔ |
| `lastBid` | 지난 입찰일 | YYYY-MM-DD. 추측 계산 기준 | ⛔ |
| `contractEnd` | 입찰예상일 | 아래 유도 규칙 참조 | ⛔ |
| `confidence` | (입찰예상일 뒤 괄호) | **자동 유도** `확정`/`추측`/`미상` | (유도) |
| `lng` / `lat` | 경도 / 위도 | 점 마커(지자체 외)만 필요 | ⛔ |
| `sources` | 출처 | 근거 URL 등(선택). 잡음 문구 금지 | ⛔ |
| `updatedAt` | 수정일 | YYYY-MM-DD. 최초등록도 이 범주 | (자동) |
| `interest` | 관심기관(♥) | boolean. localStorage 관리 | (자동) |

### 입찰예상일 · confidence 유도 규칙 (핵심)

confidence는 **사용자가 직접 고르지 않고 앱이 유도**한다(사용자 혼란 방지):

1. `contractEnd`(확정 입찰일)가 입력돼 있으면 → **확정**, 표시 `2026-12-03(확정)`
2. 아니고 `lastBid`와 `term`이 있으면 → `contractEnd = lastBid + term년`으로 **계산**,
   → **추측**, 표시 `2024-12-05(추측)`
3. 둘 다 없으면 → **미상**, 표시 `미상`

임박도 색(6개월/1년/2년/2년+/미상)은 위에서 확정된 **유효 입찰예상일**(확정이든 추측이든)로
계산한다. 미상은 회색 + `?` 글리프(기존 규칙 유지).

### 무결성 검증

- 필수 = `name`·`type`·`region`. 누락 시 `!` 글리프 + 팝오버 강조(기존 규칙 유지).
- `sources`는 더 이상 필수가 아니다(사용자가 직접 관리). `!` 유발 조건에서 제외.

## ③ CSV 템플릿 (다운로드/업로드, 라이브러리 없음)

폐쇄망 오프라인 전제 → **순수 JS CSV 파싱**, 외부 라이브러리 없음.

- **다운로드**: 상단바 "CSV 템플릿 내려받기" → **한글 헤더** + 예시 1행 CSV.
  - 컬럼: `기관명, 기관구분, 지역코드, 입찰주기, 지난입찰일, 확정입찰일, 경도, 위도, 출처, 수정일`
  - **UTF-8 BOM** 부여 → 엑셀에서 한글 안 깨짐.
- **업로드**: "CSV 업로드" → 파싱 → 한글 헤더 ↔ 영문 키 매핑 → 레코드화 →
  localStorage 반영 → 재렌더. `수정일` 미기입 행은 업로드일로 자동 설정.
- **파싱 규칙**: 헤더 행 기준 매핑, 따옴표로 감싼 값/쉼표 포함 값 처리, 빈 셀은 미입력.
  잘못된 행은 버리지 않고 `!`로 살려 표시(기존 원칙).
- **기존 "institutions.js 내보내기"** 버튼은 유지(현재 화면 상태 → JS 파일).
- **파일 경로 연동**: 시작 시 `data/institutions.js`를 읽는 기존 구조 유지 → 향후 agent가
  이 파일을 생성·교체하면 그대로 반영(별도 작업 불필요).

## ④ 랭킹 패널 개편

- **반응형 높이**: 뷰포트 높이에 비례한 `max-height`(작은 화면이면 짧게) + 내부 스크롤.
- **정렬 토글 2종** (패널 헤더):
  - **임박순**: 유효 입찰예상일 임박 순, 미상은 뒤로(기존).
  - **관심도순**: ♥ 지정 기관 먼저(그 안에서도 임박순) → 미지정 기관은 아래에 임박순.
- **유형 필터(범례 토글)**: 지자체·대학병원·공공기관·공기업 4종 토글 → 랭킹에서 해당
  유형만 표시. 지도 마커 유형 필터와 **연동**(하나의 상태 공유).
- **카드 ♥ 토글**: 기관 단위 관심 지정/해제(localStorage). **기존 ★관심지역(지역 단위)과는
  별개 레벨** — 이름/색/저장 키를 분리해 혼동 방지.
- **"더 보기"**(리스트 끝) → **팝업 모달**:
  - **전체 입찰건 표**(한글 컬럼: 기관명·기관구분·지역·입찰예상일·입찰주기·수정일 등)
  - **검색**(기관명/지역/유형 부분일치) + 컬럼 정렬
  - 행 클릭 → 팝오버 상세(기존) 및 지도 물결 연동.

## ⑤ 물결(ripple) 효과 — SVG/CSS 직접 구현

- 랭킹 카드 또는 지도 마커에서 **선택**된 기관의 마커 위치에, **잔잔히 확산·페이드하는
  SVG 원**(반복)을 그린다. Canva 미사용(이 세션 도구 미노출 + 라이브 SVG 인터랙션엔 부적합).
- 기존 hover 하이라이트(`.hi`, 흰 테두리)와 **병행**. 선택 해제/지역 이탈 시 정리.
- 구현: 마커 레이어에 `<circle>` + SMIL(`animate` r/opacity) 또는 CSS keyframes. 성능상
  동시 1~소수 개만 활성.
- **검증 가능성**: 로컬 http 서버 + 브라우저로 사용자가 직접 클릭해 물결을 확인할 수 있게 한다.

## ⑥ 관심(關心) 두 레벨 구분

| 레벨 | 표식 | 대상 | 저장 | 용도 |
|---|---|---|---|---|
| 관심지역 | ★ | 지역(시도) | localStorage(기존) | 탭2 핀바 재정렬 · 지도 외곽선 글로우 |
| 관심기관 | ♥ | 개별 기관 | localStorage(신규) | 랭킹 "관심도순" 정렬 |

두 개념은 서로 독립. 키/색/아이콘을 분리한다.

## ⑦ 기존 코드 영향 범위 (dashboard/)

- `data/institutions.js` — 신규 스키마 예시 데이터(SAMPLE 표기 유지, 잡음 문구 제거).
- `js/logic.js` — confidence 유도 + 추측일 계산(lastBid+term), 정렬(관심도순), 검증 완화,
  CSV 파싱/직렬화 순수 함수. (node `--test`로 TDD)
- `js/store.js` — 관심기관(♥) 상태 + 유형필터 공유 상태.
- `js/export.js` — CSV 템플릿 생성 + CSV 다운로드/업로드(파싱). 기존 JS 내보내기 유지.
- `js/render.js` — 랭킹 반응형/정렬토글/유형필터/♥/더보기 팝업, 물결 효과, 한글 라벨 표시.
- `js/app.js` — 신규 컨트롤 와이어링.
- `index.html` — 상단바(템플릿/업로드/정렬토글/유형범례) + 더보기 모달 마크업.

## 후속 (본 문서 범위 밖, 요구사항 보존)

- **입찰정보 확인 Agent** — 폐쇄망에서 입찰 공고/이력을 확인해 ②스키마 형식의 데이터
  파일을 생성하고 정해진 경로(`data/institutions.js` 등)에 저장 → 대시보드가 읽음.
  외부검색/동기화/스케줄 제약을 포함해 **별도 spec→plan 사이클**로 진행. 창의적 설계가
  필요하므로 착수 시 모델 변경을 사용자에게 제안할 것.
