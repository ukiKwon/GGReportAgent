  6부 15장이며 8~13장(4부)이 시스템 현황 서술이다.
- **왜 열어두나**: 본문에 **그 시점의 실측값이 박혀 있다** — 자치구 25/25·신뢰도
  평균 79·테스트 **635/166**·로드맵 8행·"남은 제한 두 가지". 아래가 바뀌면 두 파일을
  **함께** 고쳐야 한다(한쪽만 고치면 두 스킨이 갈라진다):
  - [[항목 6 AWS EC2 데모 배포|항목 6]](EC2 실기동)이 끝나면 → 13장 로드맵 1·6행, 15장 결정 2번.

  - [[항목 9 WebLogic Java 이관|항목 9]](WebLogic 이관)가 착수되면 → 13장 로드맵 7행, 15장 결정 3번.
- **테스트 수치**: `py -3.14 -m pytest agent server collector -q --collect-only`와
  `node --test frontend/test/*.test.js`로 다시 재서 넣을 것. 코드 규모는
  `find {server,agent} -name '*.py' -not -path '*/tests/*' | xargs wc -l`(백엔드)와
  `find frontend -name '*.js' -not -path '*/test/*' | xargs wc -l`(화면) 기준이다 —
  **기준을 바꾸면 과거 수치와 비교가 깨지므로 이 기준을 유지할 것.**
- ✅ **2026-08-06 1차 갱신 완료** (출처: `[[2026-08-06|2026-08-06_summary.md]]`). 8/5 스냅샷 이후
  들어간 **계획 I(역할·결재 라인·권한관리)** 가 통째로 빠져 있어 라이트·다크 두 파일에
  같은 5곳을 고쳤다:
  - 테스트 수치 3곳 **635/166 → 739/204**, 코드 규모 1곳
    **백엔드 7,400 → 8,100줄 · 화면 2,600 → 3,700줄**(2026-08-06 실측).
  - 10장 기능 표: `디자이너 전용 뷰` 행이 사실과 달라져(계획 I에서 **작업함**으로
    일반화, 노출 조건도 소속이 아니라 메뉴 권한) 문구를 고치고 **`결재함`·`권한 관리`
    2행을 신설**했다(표 9행 → 11행). 결재 라인 `팀원 → 팀장 → 디자이너 → 영업부장`을
    결재함 행에 적었다.
  - 11장 제한 ②에 **2026-08-06 컨텍스트 실측(4회) 결과**를 한 문장 보강 — 설정 탓이
    아니라 모델의 성질임이 확인됐으므로 사람 검수 필수 근거가 강해졌다([[항목 5 gpt-oss-120b 실호출이 아직 검증되지 않았다|항목 5]] 참조).
