(AI/정보화 · DBA · 인프라)별로 묶느라 순서를 바꿨다.

| 번호 | 설계 §7 | **문의서(회신이 오는 기준)** |

## 답에 따라 바뀌는 것 (문의서 번호 기준)

| # | 항목 | 답에 따라 바뀌는 것 |
|---|---|---|
| 1 | LLM API 호환 규격 | 어댑터 구현 방식 (비호환이면 변환 계층 추가) |
| 2 | 임베딩 제공 여부 | **없으면 벡터 검색 포기** → 검색 품질 저하 사전 합의 |
| 3 | Oracle Text | 전문검색 1안(Oracle Text)/2안(Java 인메모리) 분기 — **최우선 확인** |
| 4 | Oracle 버전 | DDL 작성 방식 (11g 제약) |
| 5 | WebLogic 버전 | `weblogic.xml`·프록시 타임아웃 값 |
| 6 | async-supported | 꺼져 있으면 SSE(대화·진행표시)가 막힘 |
| 7 | 앞단 웹서버 | SSE 버퍼링·타임아웃 대응 필요 여부 |
