# docs/samples

사용자가 화면에서 이사회 자료 작성 모드를 시험할 때 쓰는 수익성 분석표 엑셀. 구조(1. 수익성 요약 / 2. 세부 산출표 / 3. 투자 및 출연금 적정성 검토, 단위 백만원)는
`handoff/agents/history/2026-11-02_수익성분석표_구조_사용자설명.md`(사용자 구술)를 따랐다. **실제 사본이 오면 교체한다.**

| 파일 | 용도 |
|---|---|
| `수익성분석표_빈양식.xlsx` | **사용자가 직접 입력해 볼 빈 양식.** 노란 칸에만 입력(평잔·마진율·비용 등 218칸), 흰 칸(소계·계·총수익·요약·현가·NPV·IRR)은 엑셀 수식(321개)으로 자동 계산. 입력 후 저장해 화면에서 올린다. |
| `수익성분석표_샘플_가짜값.xlsx` | 값이 전부 **가짜**로 채워진 시험용(수식 없음, 값만). 서버 테스트·재현용. |
| `GenBlankProfit.java.txt`, `GenProfitSample.java.txt` | 위 두 파일의 생성기(POI). `.java`로 바꿔 poi-ooxml 클래스패스로 컴파일해 실행한다. |

- 시트 이름은 `수익성분석`. 구분 열(1~4열)은 위 단계 칸이 여러 행에 걸쳐 병합된다.
- 2026-11-05 생성. 값은 실제 숫자·내부 기준값이 아니다. 법인세율 26.4%·할인율 3.31%는 구술 문서에 있는 값을 수식에 썼다.
- ⚠️ 이 양식은 구술을 보고 만든 것이라 실제 양식과 다를 수 있다(구분 칸 병합, 소계 글자, 3-1 '값' 행 이름 등). 다른 점은 알려 주면 반영한다.

- `수익성분석표_샘플_머리글다름.xlsx` — 가짜값 샘플에서 행 이름 2개("총비용 현가(B)", "순이익(NPV)")만 바꾼 시험용. 머리글이 다른 엑셀을 올렸을 때의 화면 확인용.
