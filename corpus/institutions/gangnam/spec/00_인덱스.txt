[자체검증 2] 분야별 예산합 = 총액 확인 → ★불일치, 차액 병기
=================================================
강남구 2026년도 총 세출예산(spec/01): 14,804억원
  · 일반회계 14,362억원 + 특별회계 442억원 = 14,804억원 ✓ (회계별 합계 = 총액 일치)
  · 전년 대비 +7.8%(+1,067억원)

★그러나 "분야별 예산합 = 총액" 검증은 성립하지 않는다.
강남구는 5개 분야별 예산 배분액을 공개하지 않았고, 사업별 예산액이 확인된 것은
56건 중 4건뿐이기 때문이다.

본 조사에서 사업별 편성예산액이 확인된 4건:
  · 1-3 공동주택 시설개선          21억원 (또는 21.7억원 — spec/02에 두 수치 병기)
  · 2-5 중소기업육성기금 융자     400억원
  · 2-6 강남사랑상품권            950억원
  · 2-7 공공배달상품권            125억원
  합계: 21 + 400 + 950 + 125 = 1,496억원 ✓ (조사자 산출, 강남구 발표 합계 아님)

★차액: 14,804 - 1,496 = 13,308억원 ✓ — 총 세출예산의 89.9%
즉 강남구 2026년 예산의 89.9%는 어느 사업에 배분되었는지 공개 자료로 확인할 수 없다.

★추가 주의(회계 성격 차이): 위 1,496억원 중 400억원(2-5 중소기업육성기금 융자)은
기금 융자 재원으로, 일반회계 세출예산과 회계 성격이 다를 가능성이 있다.
이를 제외하면 확인 금액 1,096억원(총액의 7.4%), 차액 13,708억원(92.6%)이 된다.
두 계산을 모두 병기한다. 어느 쪽도 강남구가 발표한 수치가 아니라 조사자 산출이다.

분야별 예산 확인율:
  1분야 1/5 = 20.0% / 2분야 3/15 = 20.0% / 3분야 0/16 = 0.0% /
  4분야 0/12 = 0.0% / 5분야 0/8 = 0.0%
  전체 4/56 = 7.1%

금액 정보 확인 수준 3단 구분(spec/08):
  · 사업별 편성예산액(총사업비) 확인: 4건 / 56건 = 7.1%
  · 개인·업체 단위 지원 단가만 확인: 13건 / 56건 = 23.2%
  · 금액 정보 전무:                  39건 / 56건 = 69.6%
  · 검증: 4 + 13 + 39 = 56 ✓ / 7.1 + 23.2 + 69.6 = 99.9%(반올림 오차) ✓
