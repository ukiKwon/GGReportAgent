================================================================================
[송파구] 01. 구정현황 개요
================================================================================
작성기준일 : 2026-07
조사방법   : 공개자료 조사(송파구청 홈페이지, 송파구의회 회의록, 서울재정포털,
             언론 보도자료). 라이브 크롤링·비공개 자료 미사용.
주의       : 본 문서의 모든 수치는 공개 발표된 원문을 그대로 옮긴 것이며,
             확인되지 않은 항목은 "확인 불가"로 명시한다. 추정 항목은 "(추정)"을
             병기한다.

--------------------------------------------------------------------------------
1. 구정 기본 현황
--------------------------------------------------------------------------------
- 자치구명 : 서울특별시 송파구
- 구청장   : 서강석 (2026년 예산 확정 보도자료 기준)
- 구정 슬로건 / 비전 : "구민을 주인으로 섬기는 명품도시"
- 구정 기조 : "섬김행정"
  ※ 위 비전·기조는 2026년도 예산 확정 보도자료에 직접 인용된 표현이다.
     별도의 "민선 O기 구정 4개년 계획" 문서 원문은 공개 검색으로 확보하지
     못했다 → 해당 문서 기반의 전략체계(전략목표/실행과제 트리)는 **확인 불가**.

- 인구·면적·행정동 수 : 본 조사에서 공식 통계 원문을 직접 확인하지 못함 → 확인 불가
  (수치를 추정으로 채우지 않는다.)

--------------------------------------------------------------------------------
2. 2026년도 예산 총괄
--------------------------------------------------------------------------------
- 2026년도 예산 총액 : **1조 3,040억 원**
- 2025년도 예산 총액 : 1조 2,394억 원
- 증감 : 약 +645억 원 / +5.21%

  ▶ 검산 주의(수치 불일치 병기)
    13,040억 − 12,394억 = 646억 이나, 구 발표문은 "645억 원 증가(5.21%)"로
    표기한다. 이는 발표 총액이 억 단위 반올림값이기 때문으로 **추정**되며,
    본 문서는 발표 원문(645억)과 단순 차감값(646억)을 **병기**한다.
    → 임의로 한쪽에 맞추지 않는다.

--------------------------------------------------------------------------------
3. 장(章) 구조 — 송파구 자체 발표 분류를 그대로 사용
--------------------------------------------------------------------------------
송파구가 2026년도 예산 확정 보도자료에서 스스로 사용한 5개 분야 구분을 그대로
본 spec의 장 구조로 채택한다. (타 자치구의 분야 분류를 이식하지 않는다.)

  1장. 복지·보건·일자리·소상공인      8,040억 원   (spec/02)
  2장. 안전·교통·환경·도시기반시설    1,521억 원   (spec/03)
  3장. 문화·예술·체육                   225억 원   (spec/04)
  4장. 교육                              291억 원   (spec/05)
  5장. 일반행정                        2,962억 원   (spec/06)
  --------------------------------------------------------------
  분야별 합계                        13,039억 원
  구 발표 총액                       13,040억 원
  차액                                    1억 원

  ▶ 차액 1억 원은 각 분야 발표값의 억 단위 반올림 누적오차로 **추정**된다.
    조작하여 맞추지 않고 그대로 병기한다.

  ▶ 1장 비중 : 구 발표문은 "전체의 62%"라 표기. 실제 8,040/13,040 = 61.66%.
    한 보도매체는 "61.7%"로 표기. → 발표 원문(62%)과 계산값(61.66%)을 병기한다.

--------------------------------------------------------------------------------
4. 분야별 성격 요약
--------------------------------------------------------------------------------
- 1장(복지·보건·일자리·소상공인) : 예산의 약 62%가 집중된 최대 분야.
  민생·돌봄·지역경제가 한 분야로 묶여 발표된 것이 송파구 분류의 특징이다.
  (타 구는 복지와 일자리·경제를 분리 발표하는 사례가 많다.)
- 2장(안전·교통·환경·도시기반시설) : 폐기물·공원·주차장·마을버스·도로 지하공동
  탐사 등 도시관리 중심.
- 3장(문화·예술·체육) : 225억으로 5개 분야 중 최소. 석촌호수·한성백제 등
  송파 고유 자산 기반 축제·시설 운영이 핵심.
- 4장(교육) : 291억. 학교교육경비 지원 + 영유아 영어교육이 발표된 대표사업.
- 5장(일반행정) : 2,962억으로 1장 다음 규모. 복합청사 신축(풍납2동·마천1동·
  송파2동) 등 대형 건축 투자가 포함되어 규모가 큰 것으로 **추정**된다.
  (일반행정 내 사업별 예산 배분표 원문은 확보하지 못함 → 확인 불가)

--------------------------------------------------------------------------------
5. 본 조사의 한계 (반드시 함께 읽을 것)
--------------------------------------------------------------------------------
(1) 개별 사업 단위 예산액은 대부분 **확인 불가**하다.
    송파구가 공개 발표한 것은 "분야별 총액 + 분야별 대표사업명"까지이며,
    사업별 세부 예산은 예산서 원문(PDF)·서울재정포털 상세조회에서만 확인
    가능한데 본 조사에서는 해당 원문 데이터를 직접 확보하지 못했다.
    → 사업별 예산 칸은 "확인 불가"로 두고 추정치를 넣지 않는다.
(2) 연차별(다년도) 예산 배분표 역시 원문 미확보 → 확인 불가.
(3) 소관 부서명은 대부분 추정이며 "(추정)" 표기를 반드시 병기했다.
(4) 따라서 본 spec은 "송파구가 스스로 공개한 범위"의 정확한 기록이며,
    그 범위를 넘는 정밀도를 주장하지 않는다.
