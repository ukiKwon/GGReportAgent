■ 자체 검산 (1) — 예산 총액  ★ 완전 검산 불가
================================================================================
  총 예산(구 발표)     : **1조 1,456억 원**
    (구의회 확정 정확 표기 : 1조 1,456억 5,195만 원)
    일반회계 11,233 + 특별회계 223 = **11,456** → **일치** ✅

  ▶ **장별 예산합 = 총액 검산은 원천적으로 수행 불가능하다.**
    사유 : 구가 **사회복지(6,928억)와 보건(310억) 2개 분야만 총액을
    발표**했고, 안전·지역경제·문화체육·교육·도시발전 5개 분야는
    **분야 총액을 발표하지 않았다.**

    구 발표 분야 총액 확인분 : 6,928 + 310 = **7,238억**  (총예산의 63.18%)
    나머지                    : 11,456 − 7,238 = **4,218억** → **분야별
                                배분 확인 불가**

  ▶ 각 장 파일의 "확인 합계"는 **보도자료가 예시한 개별 사업의 단순 합**
    일 뿐이며 분야 총액이 아니다. 참고용으로만 병기한다 :
      1장 개별합(1-1~1-5)   3,643억   ← 분야 총액 6,928억의 52.6%
      2장 확인 합계            20.7억
      3장 확인 합계           279.5억  (성격 상이한 값의 합 — 인용 금지)
      4장 확인 합계            19.1억
      5장 확인 합계(원안)     137.3억
      6장 확인 합계            28.2억
      ------------------------------------
      단순 총합             4,127.8억  ← **총예산 11,456억의 36.0%에 불과**
    ★ 이 4,127.8억을 어떤 형태로든 "강동구 예산"으로 인용하면 **오류**다.

  ▶ 증가율 표기 불일치 (병기, 조작하지 않음)
      전년 대비 증액 **486억**
      보도 표기 : "**4.4%** 증액"(헤럴드경제·코리아타임뉴스)
                  "**4.43%** 증가"(시정일보)
      ▶ 두 값 모두 병기. 통일하지 않는다.
      ▶ 역산 전년 예산 = 11,456 − 486 = **10,970억** — 이는 **역산값**이며
        구 발표 2025년 예산액 원문은 확인 불가.

  ▶ 사회복지 비중 검산
      6,928 / 11,456 = **60.47%** (본 조사 계산값)
      ★ 구가 비중을 % 로 발표한 자료는 **확인 불가**. 60.47%를
        "구 발표 비중"으로 인용하면 오류다.
