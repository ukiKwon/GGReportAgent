================================================================================
[강동구] 03. 2장 — 안전 · 도시기반시설 : 사업목록 및 예산
================================================================================
장 총액 : **구가 분야 총액을 발표하지 않았다 → 확인 불가**
          아래 소계는 확인된 개별 사업의 단순 합일 뿐이며,
          **강동구 안전·도시기반시설 분야 예산 총액이 아니다.**

★ 구는 2026년 본예산 보도자료에서 이 분야를 "안전" 키워드로 강조하며
  **신규 사업 중심**으로 예시했다. 계속사업(도로유지보수 등)은 포함되지 않았다.

--------------------------------------------------------------------------------
【2-1】 횡단보도 물고임 정비
--------------------------------------------------------------------------------
 예산      : **1억 원**  (신규사업)
 담당부서  : 도로과 **(추정)** — 부서 존재는 홈페이지에서 확인
 내용      : 강우 시 횡단보도 물고임 구간 정비. 보행 안전 개선.
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)

--------------------------------------------------------------------------------
【2-2】 노면 하부 공동(空洞) 탐사
--------------------------------------------------------------------------------
 예산      : **2억 원**  (신규사업)
 담당부서  : 도로과 **(추정)**
 내용      : 지반침하(싱크홀) 예방을 위한 노면 하부 공동 탐사.
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)

--------------------------------------------------------------------------------
【2-3】 고덕3교 내진보강
--------------------------------------------------------------------------------
 예산      : **2억 5,000만 원**  (신규사업)
 담당부서  : 도로과 **(추정)**
 내용      : 교량 내진 성능 보강.
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)

--------------------------------------------------------------------------------
【2-4】 산사태 취약시설 정비
--------------------------------------------------------------------------------
 예산      : **3,000만 원**  (신규사업)
 담당부서  : 확인 불가 (공원녹지 소관 부서 **추정**, 부서명 미확인)
 내용      : 산사태 취약지 정비.
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)
 비고      : 2026년 강동구 신규 예시사업 중 **최소 금액** 항목.

--------------------------------------------------------------------------------
【2-5】 고덕로 가공배전선로 지중화
--------------------------------------------------------------------------------
 예산      : **7억 9,000만 원**
 담당부서  : 도로과 **(추정)**
 내용      : 고덕로 구간 전선 지중화.
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)
 ★ 확인 불가 : 총사업비, 사업 기간(다년 여부), 한전 등 분담 구조.
   7.9억은 **2026년 편성분**이며 총사업비가 아닐 가능성이 높다(지중화
   사업의 통상 구조상) — 단, 이는 **추정**이며 근거자료 없음.

--------------------------------------------------------------------------------
【2-6】 양지2마을 도시기반시설 조성
--------------------------------------------------------------------------------
 예산      : **7억 원**
 담당부서  : 확인 불가
 내용      : 양지2마을 일대 도시기반시설 조성.
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)
 ★ 확인 불가 : 총사업비, 사업 범위, 대상 세대수, 사업 기간.

    2-2 노면 하부 공동탐사          2.0억
    2-3 고덕3교 내진보강            2.5억

    ---------------------------------------
    확인된 개별 사업 합계        **20.7억 원**

  ■ 사업 건수 : **6건** (2-1 ~ 2-6)
  ■ 개별 사업 예산 확인 : **6건 / 6건 (100%)** ← 6개 장 중 유일하게 전건 확인
  ■ 담당부서 실제 확인 : **0건 / 6건** (전부 추정)

  ★★ 20.7억을 "강동구 안전 예산"으로 인용하면 **명백한 오류**다.
     이는 보도자료가 예시한 신규사업 6건의 합일 뿐이며, 도로·교통·재난
     분야의 계속사업 예산은 전혀 포함되어 있지 않다.
