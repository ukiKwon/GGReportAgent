================================================================================
[강동구] 05. 4장 — 문화 · 체육 : 사업목록 및 예산
================================================================================
장 총액 : **구가 분야 총액을 발표하지 않았다 → 확인 불가**
          아래 소계는 확인된 개별 사업 예산의 단순 합이며 분야 총액이 아니다.

★ 구 보도자료는 이 분야를 **생활 밀착형 시설·프로그램 중심**으로 예시했다.
  대규모 문화시설 운영비·축제 예산 등은 예시되지 않아 확인 불가다.

--------------------------------------------------------------------------------
【4-1】 공공도서관 개관시간 연장
--------------------------------------------------------------------------------
 예산      : **10억 4,000만 원**
 담당부서  : 문화예술과 **(추정)** — 부서 존재는 홈페이지에서 확인
 내용      : 관내 공공도서관 개관시간 연장 운영.
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)
 비고      : 4장 예시사업 중 **최대 금액** 항목.
 ★ 확인 불가 : 대상 도서관 수·관명, 연장 시간대, 인력 운영 방식.

--------------------------------------------------------------------------------
【4-2】 강명저류지 피클볼장 조성
--------------------------------------------------------------------------------
 예산      : **2억 원**
 담당부서  : 확인 불가 (체육 소관 부서 **추정**, 부서명 미확인)
 내용      : 강명저류지 부지에 피클볼장 조성.
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)
 ★ 확인 불가 : 면수, 준공 시점, 총사업비.

--------------------------------------------------------------------------------
【4-3】 강일 테니스장 정비
--------------------------------------------------------------------------------
 예산      : **4,000만 원**
 담당부서  : 확인 불가
 내용      : 강일 테니스장 정비.
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)

--------------------------------------------------------------------------------
【4-4】 유소년스포츠센터 풋살장 개선
--------------------------------------------------------------------------------
 예산      : **1억 3,000만 원**
 담당부서  : 확인 불가
 내용      : 유소년스포츠센터 풋살장 시설 개선.
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)
 ★ 확인 불가 : 시설 소재지, 운영 주체(직영/위탁).

--------------------------------------------------------------------------------
【4-5】 고덕강일2지구 다목적체육관 건립 용역
--------------------------------------------------------------------------------
 예산      : **1억 9,000만 원** (용역비)
 담당부서  : 확인 불가
 내용      : 고덕강일2지구 다목적체육관 건립을 위한 **용역**.
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)
 ★★ 중요 : 1.9억은 **용역비**이며 **체육관 건립 총사업비가 아니다.**
   총사업비·착공시점·연면적은 전부 **확인 불가**. 1.9억을 건립비로
   인용하면 **명백한 오류**다.
 ▶ 사업 단계 : **건립 전 용역 단계** — 즉 향후 다년 사업으로 확대될
   가능성이 있는 항목이나, 확정된 다년 계획은 확인 불가.

--------------------------------------------------------------------------------
【4-6】 이동식 물놀이장 운영
--------------------------------------------------------------------------------
 예산      : **3억 1,000만 원**
 담당부서  : 확인 불가
 내용      : 이동식 물놀이장 운영(하절기 사업 **추정**).
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)
 ★ 확인 불가 : 설치 장소 수, 운영 기간, 이용 대상.

================================================================================
■ 4장 소계 및 검산
================================================================================
    4-1 공공도서관 개관시간 연장     10.4억
    4-2 강명저류지 피클볼장           2.0억
    4-3 강일 테니스장 정비            0.4억
    4-4 유소년스포츠센터 풋살장       1.3억
    4-5 고덕강일2지구 다목적체육관    1.9억  (용역비)
    4-6 이동식 물놀이장 운영          3.1억
    ------------------------------------------
    확인된 개별 사업 합계         **19.1억 원**

  ■ 사업 건수 : **6건** (4-1 ~ 4-6)
  ■ 개별 사업 예산 확인 : **6건 / 6건 (100%)**
  ■ 담당부서 실제 확인 : **0건 / 6건** (전부 추정 또는 확인 불가)

  ★ 19.1억을 "강동구 문화·체육 예산"으로 인용하면 **오류**다.
    문화시설 운영비·도서관 운영비 본체·체육시설 위탁운영비 등은
    이 목록에 포함되어 있지 않다.

  ★ 원 보도자료의 문화·체육 나열에는 **천호자전거거리 특화사업(5,000만 원)**
    도 포함되어 있었으나, 본 spec은 상권 성격을 고려해 **3장(3-8)에 배치**
    했다. 이는 **본 조사의 배치 판단**이며 구 공식 분류가 아니다.
    → 원 보도자료 기준 문화·체육 나열 합계는 19.1 + 0.5 = **19.6억**.
      두 값을 병기한다.

■ 본 장의 확인 불가 항목 총괄
================================================================================
 1. 문화·체육 **분야 예산 총액** (구 미발표)

 3. 전 사업의 담당부서 (6건 전부)
 4. 시설별 위치·규모·준공 시점
 5. 구립 문화시설·체육시설 운영 예산 전반
 6. 지역 축제 예산 (보도자료에 예시 없음)
