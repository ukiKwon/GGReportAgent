================================================================================
[강동구] 05. 검증 결과 — plan 문서 자기 검증
================================================================================
본 문서의 목적 : plan/00~04에 기재된 **모든 인용(spec/NN)이 spec 원문과
실제로 일치하는지 직접 대조**하고, 과장·오인용·중복을 찾아내어 등급을
낮추고 수정권고를 남긴다. **자기가 쓴 제안을 비판적으로 재검증하는 것이
이 파일의 존재 이유**다.

검증 방법 : plan/01~04의 인용 1건씩을 spec/00~09 해당 위치와 문자 대조.
등급 기준 :
  A = 근거가 구청 원문('확인됨')이고 인용 정확, 중복 없음, 즉시 협의 가능
  B = 근거는 확인되나 일부 데이터 부재 또는 인용 보완 필요
  C = 근거가 부분확인·2차 출처이거나 중복 가능성이 있어 사전 확인 필수
  D = 근거 데이터가 결정적으로 부족하거나 과장이 발견되어 재설계 필요

【발견 1】★★ **plan/00 배경3의 "3대 축이 모두 선점되었다"는 과장이다**
  · 문제 서술 : plan/00 배경3 및 plan/03 공통전제 —
    "**소상공인 금융의 3대 축(융자·보증·지역화폐)이 모두 선점되어 있다**"
  · spec 원문 대조 결과 :
    - 융자(육성기금) : spec/04 3-2 — **단독 취급기관 명시. 선점 사실.** ✅
    - 보증(특별신용보증) : spec/04 3-1 — **복수 은행 협약. 선점 사실.** ✅
    - 지역화폐 : **여기가 문제다.**
      · 배달앱 전용 상품권(**25억**)만 특정 은행 플랫폼 기반이다
        [spec/04 3-4].
      · 그러나 **금액이 8배 큰 강동사랑상품권(200억)** 의 발행·정산
        대행 구조는 **확인 불가**다 [spec/04 3-3, plan/00 배경3에도
        "확인되지 않은 3개 영역" 중 하나로 스스로 기재].
  · **판정 : plan/00 배경3은 자기모순이다.** 같은 절에서 강동사랑상품권
    정산 구조를 "미확인 영역"으로 분류해 놓고, 동시에 "지역화폐 축이
    선점되었다"고 서술했다. **지역화폐 축은 25억 부분만 선점 확인**이며
    200억 부분은 미확인이다.
  · **수정권고** : "3대 축이 모두 선점"이라는 표현을
    "**융자·보증 2개 축은 선점 확인, 지역화폐는 배달앱 부분(25억)만
    선점 확인이며 본체(200억) 정산 구조는 미확인**"으로 정정할 것.
    협의 자리에서 "지역화폐도 다 뺏겼다"고 말하면 사실과 다르다.

【발견 2】★★ **정비사업 아카데미가 "예정"이 아니라 이미 개최되었을 수 있다**
  · 문제 서술 : plan/03 FN-4 (2), plan/04 3단계 —
    "**2026년 7월 정비사업 아카데미는 이미 예정된 행사이므로**"
  · spec 원문 : spec/07 6-5 — "**2026년 7월 개최 예정**"
  · **판정** : 본 spec·plan의 작성 시점이 **2026년 7월**이다.
    따라서 "예정"은 **작성 시점 기준 이미 종료되었을 가능성**이 있다.
    이를 "앞으로 열릴 행사"로 전제한 로드맵은 시점 오류일 수 있다.
  · 동일 성격의 시점 문제 2건 추가 발견 :
    - spec/04 3-1 특별신용보증 **2차 거점 현장접수 2026-07-01~02** → 종료
    - spec/04 3-4 강동땡겨요상품권 **2026-07-01 발행 회차** → 개시됨
  · **수정권고** : "예정"으로 기재된 모든 항목에 **"작성 시점 기준 종료
    여부 확인 필요"** 를 병기하고, plan/04 0단계에 **(11) 2026년 7월
    정비사업 아카데미 개최 여부 및 차기 회차 일정 확인**을 추가할 것.

【발견 3】★ **FN-1의 "담보력 부재 트랙"은 기존 제도와 실질 중복이다**
  · 문제 서술 : plan/03 FN-1 (2) — "담보력 부재 사업자 대상 트랙 —
    보증서 담보 또는 신용 기반 별도 트랙"
  · spec 원문 대조 : spec/04 3-1 특별신용보증이 **정확히 그 역할**이며,
    이미 **복수 시중은행 협약 + 서울신용보증재단 강동센터 상시 접수 +
    거점 현장접수**까지 운영 중이다.
  · **판정** : FN-1 (2)는 **기존 제도와 정면 중복**이다. plan/03 본문에
    "중복 회피 설계가 전제"라고 단서를 달았으나, **단서만으로는 중복이
    해소되지 않는다.**
  · **수정권고** : FN-1 (2)를 **삭제하거나**, "특별신용보증 **한도
    7,000만(우대 1억)을 초과하는 구간**" 으로 **범위를 명시적으로 축소**
    할 것. 현재 서술 그대로 제안하면 "이미 있는 걸 왜 또" 라는 반응을
    받는다.

【발견 4】★ **IT-2에서 금리를 2.7%만 단독 인용했다 (병기 누락)**
  · 문제 서술 : plan/02 IT-2 연계 근거 — "금리 변동 약 **2.7%**
    (2026-06-10 기준)"
  · spec 원문 : spec/04 3-1은 **2.7%(구 원문, 6/10 기준)와
    2.5%(언론, 1/28 기준)를 병기**하도록 명시하고 있으며,
    spec/00 병기항목 C에도 등재되어 있다.
  · **판정** : 병기 규칙 위반. 단일 값 인용은 **변동금리를 고정값처럼
    보이게 하는 오인용**이다.
  · **수정권고** : IT-2 근거란에 **"2.7%(2026-06-10 기준) / 2.5%
    (2026-01-28 기준) — 변동금리이므로 조회 시점 기준 재확인 필요"**
    로 병기 수정. 진단 창구가 금리를 표시한다면 **조회 시점 명시가
    필수 기능**이 된다(기능 요건으로 격상 권고).

【발견 5】**FN-1 (5) 대환 트랙은 구청 연계 근거가 사실상 없다**
  · 문제 서술 : plan/03 FN-1 (5) — "대환 수요 대응 트랙 —
    구 제도가 명시적으로 금지하는 영역이므로 소관이 명확히 구분"
  · spec 원문 : spec/04 3-2 — 육성기금 자금용도 "**타 대출 대환,
    여유자금 확보 불가**" ✅ 인용 자체는 정확하다.
  · **판정** : 인용은 정확하나 **논리가 약하다.** "구가 안 한다"는 것이
    "구와 협력할 근거"가 되지는 않는다. 대환 여신은 **어느 은행이나
    상시 취급하는 일반 상품**이며 강동구 사업과의 연계성이 없다.
    이는 **구청 협업 제안이 아니라 일반 영업**이다.
  · **수정권고** : FN-1 (5)를 **구청 협업 제안에서 제외**하고, 굳이
    남긴다면 "구 제도 이용 불가 사유 안내 시 참고 정보로 제공되는
    일반 여신"으로 성격을 격하 표기할 것.
