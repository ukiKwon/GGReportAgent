# 강남구 민원 채널 현황 및 2026년 민원 통계 정리

조사일 기준: 2026년 7월 25일
근거: 강남구청 종합민원 > 민원현황 통계 페이지(gangnam.go.kr/site/stats/minwon.do,
기준월 2026년 06월), 강남구청 종합민원 > 민원신청·서비스 > 구청장에게바란다 페이지
(contents/chairman001), 강남구청 자유게시판(게시판 ID B_000057), 국민신문고 연계 안내

[★조사 방법상의 중요한 한계 - 먼저 명시]
종로구 조사(giganlist/jongno/spec/08)는 "구청장에게 바란다" 게시판의 2026년 실제
게시글 15건을 전수 열람해 민원 유형을 분류할 수 있었다. 강남구는 그것이 불가능하다.
이유는 다음과 같으며, 모두 실제 확인된 사실이다:

1. 강남구 "구청장에게 바란다"는 2025년 9월 24일(수)부터 국민권익위원회가 운영하는
   국민신문고로 연계되어 운영된다(구청 페이지 안내 문구 그대로:
   "2025.09.24.(수)부터 국민권익위원회에서 운영하는 국민신문고로 연계하여 운영합니다").
2. 민원 신청 시 "국민신문고 본인인증(비회원인증)으로 로그인"해야 하며, 기존 강남구청
   홈페이지 로그인과 연동되지 않는다.
3. 페이지는 3개 탭으로 구성된다: ①구청장에게 바란다(신청용) ②(구)구청장에게 바란다
   (이전 게시글) ③나의 민원 보기. 즉 2025년 9월 이후 접수된 민원은 "나의 민원 보기"
   방식으로 본인만 조회 가능하며, 제3자가 전체 게시글 목록을 열람할 수 없는 구조다.
4. 따라서 강남구의 2026년 개별 민원 원문·제목·답변 내용은 확인 불가다.
   ★이는 민원이 없다는 뜻이 아니라 열람 권한 구조상의 한계다.

대신 강남구는 종로구에 없는 자료를 제공한다: 구청 공식 민원현황 통계 페이지에서
분야별 민원 접수 건수를 월별·분기별로 집계해 공개하고 있다. 본 파일은 개별 민원
열람 대신 이 통계를 1차 자료로 사용한다. 표본이 아니라 구청 공식 집계 전수다.

[★1-3] 2열·3열 컬럼 라벨에 관한 검증 - 중요
자동 추출 과정에서 2열이 "전년도 동일월/동일분기", 3열이 "증감율"로 라벨링되어
넘어왔으나, 조사자가 산술 검증한 결과 그 라벨은 성립하지 않는다:
- 3열 값 = 2열 ÷ 1열이 9개 분야 전부에서 소수점 첫째자리까지 정확히 일치한다.
  · 일반행정 21÷79 = 26.6% ✓ / 기획경제 8÷96 = 8.3% ✓ / 복지생활 38÷1,114 = 3.4% ✓
  · 도시환경 83÷1,961 = 4.2% ✓ / 안전교통 249÷4,819 = 5.2% ✓ / 미래문화 20÷65 = 30.8% ✓
  · 보건 84÷1,853 = 4.5% ✓ / 동행정 14÷141 = 9.9% ✓ / 기타 19÷763 = 2.5% ✓
  · 2분기도 동일: 106÷185 = 57.3% ✓ / 958÷15,470 = 6.2% ✓ 등 9개 전부 일치
- 만약 2열이 진짜 "전년도 동일월"이라면, 예컨대 안전교통은 249건 → 4,819건으로
  1,835% 폭증한 것이 되어 "증감율 5.2%"와 모순된다. 따라서 원래 라벨은 오독이다.
- 결론: 2열은 1열(총 접수건)의 부분집합이고, 3열은 그 비율이다. 처리중(미완료) 건수와
  미처리율일 가능성이 높으나, 컬럼의 정확한 명칭은 확인안됨(추정).
  ★본 조사는 1열(민원 접수건)만 신뢰할 수 있는 값으로 사용하며, 2·3열은 라벨 불명
  상태로 원본 수치만 보존한다. 2·3열을 근거로 한 주장은 plan에서 사용하지 않는다.

  10. 조치부탁합니다!!! 감사합니다 (2026-07-14)
- 유형 분류(위 10건 기준, 조사자 분류):
  · 직원 칭찬·감사 글: 4건 (3·8·9번, 그리고 10번도 감사 표현 병기) - 40%
  · 타 지자체·단체의 홍보성 게시글: 4건 (2·4·5·6·7번 중 중복 제외) - 40%
  · 실질적 개선 요구·민원성 글: 2건 (1번 "조금더 발전됬으면", 10번 "조치부탁합니다") - 20%
- ★해석 주의: 이 10건은 최신순 10건일 뿐이며 4,646건의 표본으로 볼 수 없다.
  또한 자유게시판은 강남구의 공식 민원 접수 창구가 아니다(공식 창구는 국민신문고 연계).
  따라서 위 유형 분류는 "공개 게시판에서 관찰 가능한 글의 성격"일 뿐, 강남구 민원의
  실제 유형 분포를 뜻하지 않는다. 실제 유형 분포는 1-4의 구청 공식 통계를 근거로 해야 한다.
- 특기: 타 지자체 축제·공모전 홍보글이 절반 가까이를 차지해, 이 게시판이 주민 소통
  기능보다 외부 홍보 게시 창구로 활용되는 경향이 관찰된다(관찰 사실이며 평가는 아님).

  정확히 이 지점이다

[조사자 코멘트]
강남구 민원 데이터의 성격은 종로구와 정반대다. 종로구는 개별 민원 원문 15건을 읽을 수
있었지만 전체 규모를 알 수 없었고, 강남구는 분기 32,602건이라는 전체 규모와 분야별
분포를 정확히 알 수 있지만 개별 내용을 하나도 읽을 수 없다. 따라서 강남구에 대한
민원 기반 제안은 "개별 민원 사례 인용"이 아니라 "분포의 구조적 불균형"을 근거로
설계해야 한다(plan/00 참고).
