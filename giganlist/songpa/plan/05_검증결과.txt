[송파구] plan/05. 검증 결과
================================================================================
검증일   : 2026-07
검증대상 : plan/00 ~ plan/04 (제안 10건 : IT-1~IT-5, FN-1~FN-5)
검증방법 : plan 문서의 모든 spec 인용을 **spec 원문과 1:1 대조**하여
           인용 오류·과장·오인용을 색출. 발견 시 등급을 낮추고
           수정권고사항에 명시.
검증성격 : **자기 자신이 작성한 plan을 비판적으로 재검증**하는 문서다.
           방어가 아니라 결함 색출이 목적이다.

■ 타당성 등급 정의
--------------------------------------------------------------------------------
  A : 근거 spec이 '확인됨'이고, 인용이 정확하며, 중복 위험이 낮음
  B : 근거 spec이 '확인됨' 또는 강한 외부근거이나, 중복 위험 또는
      설계 전제의 불확실성이 존재
  C : 근거 spec이 '부분확인'이거나, 핵심 전제가 '확인 불가'
  D : 근거가 '확인안됨'을 포함하거나, 정량 산정 자체가 불가능

[정정-1] spec 자체의 오류 — 담당부서를 '확인'으로 과대 표기 ★
  발견 위치 : spec/02 [1-5] 송파사랑상품권 발행
  최초 기재 : "담당 : 경제진흥과 (송파구 홈페이지 경제 분야 소관으로 확인)"
  실제 확인 : 홈페이지에서 경제진흥과가 문의처로 명시된 것은 **[1-8]
              소상공인·기업 지원금 안내 페이지**이며, **상품권 사업의
              소관 부서를 명시한 페이지는 확인하지 못했다.**
  판정 : **확인되지 않은 것을 "확인"으로 표기한 오류**. 이 프로젝트의
         최상위 원칙(데이터 조작 금지) 위반에 해당한다.
  조치 : spec/02 [1-5] 담당을 **"경제진흥과 (추정)"** 으로 하향 정정하고,
         정정 이력을 spec 원문에 명시적으로 기록함. (조치 완료)
  파급 : plan/01의 FN-5 '담당(추정)'은 원래부터 (추정) 표기였으므로
         plan 측 수정은 불필요. 다만 spec/00 검산5의 "담당부서 확인율
         2/35"는 이 정정으로도 변동 없음(1-5는 애초에 2건에 미포함).

[정정-2] 경쟁 금융기관의 기존 진입 사실 누락 ★★ (중대)
  발견 위치 : spec/02 [1-5] 및 plan/03 FN-5
  최초 기재 : "송파땡겨요상품권이 병행 발행됨(배달앱 연계 상품권)" 이라고만
              기술하고, 해당 배달앱의 운영 주체를 확인하지 않았다.
  실제 확인 : "땡겨요"는 **타 금융기관(신한은행)이 운영하는 배달앱**이며,
              송파구를 포함한 서울시 6개 자치구에서 서비스된다.
              즉 송파구 지역사랑상품권 라인업에 **경쟁 금융기관과 공동
              브랜딩된 상품권이 이미 존재**한다.
  판정 : FN-5(상품권 협력) 제안이 **경쟁사가 이미 진입한 영역**이라는
         핵심 사실을 누락한 채 작성되었다. 이는 제안의 실현 가능성 판단을
         왜곡하는 **중대한 누락**이다.
  조치 : ① spec/02 [1-5]에 경쟁 금융기관 사실을 원문 추적 목적으로 기록
         ② FN-5 등급을 하향 (아래 개별 판정 참조)
         ③ bank_ideas_draft.txt에서는 브랜드명 미사용 원칙에 따라
            "타 금융기관 운영 배달 플랫폼 연계 상품권"으로 표기
  ★ 단 과장 방지 : 송파구와 해당 은행 간 **협약의 존재·형태·기간은
    확인 불가**다. "송파구가 이미 타행과 협약했다"고 단정하지 않는다.
    상품권 명칭에 앱 브랜드가 포함되어 있다는 **사실**만 확정적이다.

[정정-3] 인용 과장 미수 사례 (사전 차단됨 — 기록 목적)
  대상 : plan/03 FN-2 — 소상공인 융자 조건
  위험 : 조사 중 "최대 5억 원 / 이차보전 1.8%" 수치가 검색되었으나 이는
         **서울특별시** 중소기업육성자금 기준이며 송파구 기준이 아니다.
  차단 : spec/02 [1-8]에서 명시적으로 경고했고, plan/03 FN-2에서도
         "송파구 값으로 전용하지 않는다"고 재차 명시했다.
  판정 : 오류 발생 없음. 그러나 **가장 실수하기 쉬운 지점**이므로
         향후 편집자가 이 수치를 송파구 값으로 되살리지 않도록 경고 유지.

[정정-4] 인용 과장 미수 사례 2 (사전 차단됨)
  대상 : plan/03 FN-5, plan/02 IT-3 — 상품권 60억
  위험 : 60억은 **2026년 설 명절 회차 발행규모**이며 연간 발행액이 아니다.

  차단 : spec/02 [1-5], spec/00 병기항목 E, plan/01 FN-5, plan/02 IT-3,

[정정-5] 오독 유발 수치의 차단 (사전 차단됨)
  대상 : 정비사업 41곳 vs 단계별 실적 합 31곳
