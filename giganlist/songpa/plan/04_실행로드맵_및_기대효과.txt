================================================================================
[송파구] plan/04. 실행 로드맵 및 기대효과
================================================================================
근거자료 : giganlist/songpa/spec/00 ~ spec/09, plan/00 ~ plan/03

--------------------------------------------------------------------------------
■ 로드맵을 읽기 전 필수 고지
--------------------------------------------------------------------------------
아래 일정은 **제안자가 설계한 가상 일정**이며, 송파구의 실제 예산편성
일정·계약 일정과 대조하지 않았다. 송파구 다년도 사업계획 원문을 확보하지
못했기 때문이다(spec/01 5절 (2) : 연차별 예산 배분표 확인 불가).
따라서 로드맵은 **협의 시작점을 위한 초안**이지 확정 일정이 아니다.

================================================================================
1. 실행 로드맵
================================================================================

【0단계】사전 협의 (D+0 ~ D+2개월)
  목적 : spec에서 '확인 불가'로 남은 항목을 실측으로 메우는 단계.
         이 단계 없이 1단계로 진입하면 제안 전체가 추정 위에 서게 된다.
  필수 확인 항목 (spec/00 '확인 불가 항목 총괄'에서 직접 도출) :
    ① 소상공인 융자(spec/02 1-8)의 한도·이자율·이차보전율·취급 금융기관
       → FN-2 설계의 전제
    ② 특별신용보증(spec/02 1-9)의 협약기관·출연금 규모
       → FN-3 설계의 전제
    ③ 지역상품권(spec/02 1-5)의 **연간** 발행규모·운영 대행사·정산 구조·
       계약 잔여기간 → IT-3, FN-5 실행 가능 여부를 좌우
    ④ 소상공인 종합지원센터(spec/08 1-7 '확인안됨')의 실재 여부·소재지
       → IT-2가 신설인지 통합인지를 결정
    ⑤ 옴부즈만 권고에 대한 송파구 이행계획(spec/09) → IT-4 중복 여부
    ⑥ 정비사업 조합별 금융기관 선정 현황(spec/07 4절) → FN-1 경쟁 강도
    ⑦ 청년 멘토링 참가자 규모(spec/02 1-13) → FN-4 규모 산정
    ⑧ **청년 취·창업 멘토링의 계속사업 여부** — 본 사업은 2026-08-27
       종료 예정이며 2027년 이후 지속 여부가 확인되지 않았다
       (spec/02 1-13). 단년도 사업이면 IT-5·FN-4는 대상 모집단이
       소멸하므로 **두 제안의 존립 조건**이다.
    ⑨ **서울시 청년 금융지원 제도 목록 실사** → FN-4 중복 여부 판정
       (현재 중복 여부가 '확인 불가' 상태 — plan/03 FN-4 한계)
    ⑩ **서울페이플러스(서울Pay+) 앱의 현행 기능 범위** — 상품권 구매·
       조회·정산 중 어디까지를 서울시 공통 인프라가 수행하는지.
       IT-3·FN-5의 **존립 조건**이며, 병행 상품권이 타 금융기관 운영
       플랫폼과 공동 브랜딩되어 있다는 점(spec/02 1-5)도 함께 확인할 것.
  ※ ⑧⑨⑩은 plan/05 검증에서 **누락으로 지적되어 추가된 항목**이다
    (plan/05 불일치-3, 최우선 조치 2).
  산출물 : 확인 불가 13개 항목(spec/00) 중 최소 7개 해소, 추정예산 재산정

【1단계】근거 강도 최상위 항목 우선 착수 (D+2 ~ D+8개월)
  대상 : **IT-2 + FN-2 + FN-3** (소상공인 패키지)
  선정 사유 : 근거 사업(spec/02 1-8, 1-9, 1-10~1-12)이 spec/08에서
              **전부 '확인됨'** 이고, 담당부서(경제진흥과)도 부분 확인된
              유일한 묶음이다(plan/01 근거 spec 확인등급 분포).
              불확실성이 가장 낮은 지점부터 시작하는 것이 합리적이다.
  내용 : IT-2 통합 신청창구 구축 → FN-2 이차보전 매칭 협약 →
         FN-3 보증 출연 협약. IT-2가 FN-2·FN-3의 신청 채널이 되므로
         순서를 지켜야 한다.

【2단계】현안 대응 및 규모 사업 (D+6 ~ D+18개월, 1단계와 일부 병행)
  대상 : **IT-4 (악취 모니터링) + FN-1 (정비사업 금융)**
  · IT-4 : 옴부즈만 권고(spec/09)가 이미 존재하므로 정책적 명분이 확보된
    상태다. 단 BTO 사업자(운영계약 2032년까지 — spec/09) 협조가 선행
    조건이므로 착수 시점을 1단계보다 늦춘다.
  · FN-1 : 41개 단지(spec/07 2절)라는 규모는 크지만 조합별 데이터가
    전무해 설계를 시작할 수 없다. 0단계 ⑥ 해소 후 착수.

【3단계】확장 및 연계 (D+12 ~ D+24개월)
  대상 : **IT-1, IT-3, IT-5, FN-4, FN-5**
  · IT-1은 FN-1의 3자 협의 채널이 가동된 이후에 구축해야 실효가 있다.
  · IT-5 ↔ FN-4는 수료 이력 데이터로 연결되므로 동시 추진.
  · IT-3 ↔ FN-5는 상품권 계약 구조 확인(0단계 ③) 결과에 전적으로 의존.

2. 기대효과
================================================================================
■ 정량 기대효과를 제시하지 않는 이유 (정직성 고지)
  본 제안서는 "○○% 개선", "연 ○억 원 절감" 형태의 정량 기대효과를
  **제시하지 않는다.** 이유는 다음과 같다 :
    · 개별 사업 예산 확인율 0/35(spec/00 검산4) → 절감액 산정 기준 없음
    · 민원 건수 통계 확인 불가(spec/09) → 민원 감소율 산정 기준 없음
    · 청년·소상공인 모집단 규모 확인 불가(spec/01 5절, spec/02 1-13)
      → 수혜자 수 산정 기준 없음
  기준 없이 산출한 정량 효과는 조작이므로, **정성 효과 + 측정 가능한
  KPI 설계**로 대체한다.

■ 정성 기대효과

  [구청 관점]
  (1) 소상공인 지원제도 5종의 접근 경로 단일화 (IT-2)
      — 현재 확인되는 것은 안내 페이지 1개이며, 통합 신청창구 및
        종합지원센터는 확인되지 않는다(spec/08 1-7)
  (2) 인허가 원스톱 서비스(520종·만족도 93% — spec/07 7-1)로 확립한
      행정 브랜드를 경제·환경 분야로 확장. 2026 K-브랜드 어워즈 K-도시
      부문 대상(spec/07 1절)의 서사와 일관됨
  (3) 옴부즈만 권고 3건 중 ①기술진단·②악취 포집 기준 개정에 대한
      상시 데이터 기반 확보 (IT-4, spec/09)
  (4) 41개 단지 정비사업(spec/07 2절)의 진행 투명성 제고 — "지원행정"
      기조의 가시화

  [구민 관점]
  (5) 담보력이 없어 구 융자 요건(담보능력 보유 — spec/02 1-8)을 충족하지
      못하던 사업자에 대한 보증부 대안 확보 (FN-3)
  (6) '자금 소진 시까지' 선착순 구조(spec/02 1-8)로 인한 지원 공백기의
      연계 트랙 확보 (FN-2)
  (7) 평일 오후·단일 장소·9주 연속 참석이라는 청년 멘토링의 구조적 제약
      (spec/02 1-13) 완화 (IT-5)
  (8) 악취 기준 초과를 사후 민원이 아니라 사전 알림으로 인지 (IT-4)

  [금융기관 관점]
  (9) 자치구 단위로 이례적 규모인 41개 단지 정비사업(spec/07 2절)에
      단계 초기부터 접점 확보
  (10) 상품권 가맹점 약 3만 개(spec/02 1-5) 규모의 소상공인 접점
  (11) 청년 멘토링 수료자라는 검증된 모집단 접근 (IT-5 → FN-4)

3. KPI (측정 가능한 지표만)
================================================================================
■ KPI 설계 원칙 : **현재 값(baseline)이 확인 가능한 지표만 채택**한다.
  baseline이 확인 불가인 항목은 "baseline 확인 불가" 를 명시하고,
  목표치를 임의로 쓰지 않는다.

  KPI-1  IT-2 통합창구를 통한 5종 지원제도 신청 건수
         baseline : **확인 불가** (현행 신청 건수 미공개)
         → 1차년도는 목표치 없이 **측정 체계 구축 자체를 목표**로 한다

  KPI-2  IT-2 이용 만족도
         비교 기준 : 인허가민원 원스톱 서비스 93%(spec/07 7-1)
         ★ 단 이 93%는 **인허가 민원 한정 수치이며 구 발표 기준**이다
           (spec/07 7-1). 경제 분야 목표치로 그대로 전용하는 것은
           부적절하므로 **참고값**으로만 사용한다

  KPI-3  FN-2 이차보전 매칭 적용 여신 실행 건수 및 금액
         baseline : 0 (신규 사업이므로 baseline이 명확한 유일한 지표)

  KPI-4  FN-3 보증 출연액 대비 보증공급액 (보증배수)
         baseline : **확인 불가** (현행 출연금·협약기관 미확인 — spec/02 1-9)

  KPI-5  IT-4 악취 측정 기준 초과 발생 건수 (월별)
         baseline : **확인 불가** — 옴부즈만이 "기준 초과 사례 확인"이라고만
         밝혔을 뿐 초과 횟수·수치는 공개되지 않았다(spec/09 민원사안 A)
         → 측정 시작 첫 3개월을 baseline 확립 기간으로 설정

  KPI-6  IT-1 플랫폼 조합원 활성 이용자 수
         baseline : 0. 단 41개 단지의 조합원 총수가 확인 불가하므로
         (spec/07 4절) **비율 목표(예: 조합원의 O%)는 설정 불가**

  KPI-7  IT-5 온라인 수강 인원 / 오프라인 대비 증가분
         baseline : **확인 불가** (2026년 멘토링 참가자 수 미확인 —
         spec/02 1-13)

  KPI-8  FN-5 상품권 가맹점 정산 소요일수 단축분
         baseline : **확인 불가** (현행 정산 구조 미확인)

  ▶ **KPI 8개 중 baseline이 확인된 것은 2개(KPI-3, KPI-6)뿐**이다.
    이는 본 제안서의 근본적 한계이며, 0단계 사전 협의에서 baseline을
    확보하지 못하면 성과 측정 자체가 불가능하다.

================================================================================
4. 리스크
================================================================================
[R-1] **추정예산 전면 재산정 리스크 — 최대 리스크**
  plan/01의 모든 추정예산은 송파구 예산서 근거가 전혀 없다
  (spec/00 검산4 : 개별 예산 확인율 0/35). 실제 협의 시 자릿수 단위로
  달라질 수 있다.
  완화 : 0단계에서 예산 실측 후 재산정. 그 전까지 대외 제시 금지.

[R-2] 상품권 기존 계약 존속 리스크
  IT-3·FN-5는 현행 운영 대행사·정산 구조·계약 잔여기간이 확인 불가한
  상태의 제안이다(spec/02 1-5 범위 밖). 기존 계약 존속 시 즉시 실행 불가.
  완화 : 0단계 ③ 최우선 확인.

[R-3] BTO 사업자 협조 리스크
  IT-4의 대상 시설은 BTO 민간투자 방식이며 운영계약이 **2032년까지**
  존속한다(spec/09). 사업자 협조 없이 시설 내 센서 설치가 불가능할 수 있다.
  완화 : 시설 외부(주거지 인접부) 측정으로 1단계 설계, 구조적으로
        9개 자치구 공동 사안임을 활용해 서울시 차원 협의 병행.

[R-4] **인허가 주체–금융기관 관계의 공정성 리스크 (중대)**
  구청은 정비사업 인허가 주체다(spec/07 7-2 단계별 인가 실적). 구청이
  특정 금융기관을 조합에 연결하는 형태가 되면 공정성 문제가 발생한다.
  완화 : FN-1의 구청 역할을 **협의 채널 제공·교육**에 엄격히 한정.
        IT-1 플랫폼에서 특정 금융상품을 노출하지 않고 자금 '유형'만 안내.

[R-5] 서울시 사업과의 중복 리스크
  · IT-1 : 서울시 '정비사업 정보몽땅'(cleanup.seoul.go.kr)이 이미 존재
  · FN-4 : 서울시 청년 금융지원 제도 다수 존재 (구체적 중복 여부는
    **확인 불가** — plan/03 FN-4 한계)
  완화 : 송파구 특화 레이어로 한정 설계. plan/05에서 중복여부 판정.

[R-6] 확인안됨 42.9%가 초래하는 설계 리스크
  spec/08 기준 35건 중 15건(42.9%)이 '확인안됨'이다. 제안 설계 시
  전제한 사업 내용이 실제와 다를 가능성이 상존한다.
  완화 : 근거가 '확인됨'인 IT-2·FN-2·FN-3을 1단계로 배치한 것이
        이 리스크에 대한 구조적 대응이다.

[R-7] 담당부서 오지정 리스크
  담당부서 확인율 2/35(5.7%)(spec/00 검산5). plan/01의 '담당(추정)'이
  실제 소관과 다를 경우 협의 창구 자체가 잘못 설정된다.
  완화 : 확인된 부서는 문화예술과 문화진흥팀·관광진흥과 관광기획팀 2곳과
        경제진흥과(부분)뿐이다. 경제진흥과 관련 제안(IT-2·IT-3·FN-2·
        FN-3·FN-5)부터 접촉하는 것이 실패 확률이 낮다.

[R-8] 민원 데이터 부재 리스크
  2026년 민원 통계가 확인 불가하므로(spec/09), 제안의 수요 근거를
  민원으로 뒷받침할 수 없다. 특히 **금융·경제 관련 민원 동향은 전혀
  확인되지 않았다**(spec/09 3절 (4)). FN 계열 제안의 수요 근거는
  민원이 아니라 제도 구조 분석에 의존한다.
