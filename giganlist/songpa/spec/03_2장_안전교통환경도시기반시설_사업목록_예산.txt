[송파구] 03. 2장 — 안전·교통·환경·도시기반시설 : 사업목록 및 예산
================================================================================
장 총예산 : 1,521억 원 (2026년도)
장 구분 근거 : 송파구 2026년도 예산 확정 보도자료의 자체 분야 구분
구 발표 취지 : "쾌적한 환경 조성을 통해 도시 경쟁력을 높이는" 분야로 서술

--------------------------------------------------------------------------------
■ 중요 고지
--------------------------------------------------------------------------------
1장과 동일하게 사업별 예산액은 공개 발표 범위를 벗어나므로 대부분 확인 불가다.
확인된 것만 기재한다.

--------------------------------------------------------------------------------
■ 사업 목록
--------------------------------------------------------------------------------

[2-1] 폐기물 처리
  - 예산      : 확인 불가
  - 담당      : 청소·자원순환 소관 부서 (추정)
  - 내용      : 생활폐기물 수집·운반·처리. 자치구 예산에서 통상 큰 비중을
                차지하는 경상 사업으로 **추정**되나 편성액 원문 미확인.
  - 연차구분  : 계속사업
  - 출처      : 2026년 예산 확정 보도자료

[2-2] 공원시설 정비
  - 예산      : 확인 불가
  - 담당      : 공원녹지 소관 부서 (추정)
  - 내용      : 관내 공원 시설물 정비.
  - 연차구분  : 계속사업
  - 출처      : 2026년 예산 확정 보도자료

[2-3] 대로변 계절 꽃·정원 조성
  - 예산      : 확인 불가
  - 담당      : 공원녹지 소관 부서 (추정)
  - 내용      : 구 발표문 인용 — "대로변을 계절마다 꽃과 정원으로 가꿔 구민이
                생활권 안에서 일상적 행복을 느끼도록 한다".
  - 연계 확인 : 송파구는 "정원도시" 조성을 목표로 **마을정원사 양성 프로그램**을
                운영 중이며, 2025년 이후 약 300명을 양성한 것으로 보도 확인됨.
                ※ "약 300명"은 보도 표현이며 시점 기준(누계 시점)이 명확히
                  특정되지 않았다 → 정확한 기준일 확인 불가.
  - 연차구분  : 계속사업
  - 출처      : 2026년 예산 확정 보도자료 / 마을정원사 관련 보도

[2-4] 공영주차장 시설물 정비
  - 예산      : 확인 불가
  - 담당      : 교통 소관 부서 / 송파구시설관리공단 (추정)
  - 내용      : 공영주차장 시설물 정비.
  - 관련 확인 : 송파구 공영주차장 운영 홈페이지가 별도 존재
                (songpagongdanpark2.or.kr) → 시설관리공단 위탁 운영으로 추정.
  - 연차구분  : 계속사업
  - 출처      : 2026년 예산 확정 보도자료 / 공영주차장 홈페이지

[2-5] 마을버스 노선 활성화
  - 예산      : 확인 불가
  - 담당      : 교통 소관 부서 (추정)
  - 내용      : 마을버스 노선 활성화·조정. 노선 연장 운행 및 노선 조정 계획이
                지역매체·구의회 도시건설위원회에서 다루어진 정황 확인됨.
                다만 구체적 노선번호·연장구간·재정지원 규모는 원문 미확인 →
                **확인 불가**.
  - 연차구분  : 계속사업 (재정지원금 성격으로 추정)
  - 출처      : 2026년 예산 확정 보도자료 / 송파구의회 제328회 도시건설위원회

[2-6] 보도 및 노면 하부 공동(空洞) 탐사
  - 예산      : 확인 불가
  - 담당      : 도로 소관 부서 (추정)
  - 내용      : 보도·차도 하부의 지하 공동(싱크홀 위험구간) 탐사.
                구 발표문에서 교통 편의·안전 항목으로 함께 서술됨.
  - 연차구분  : 계속사업 여부 확인 불가
  - 출처      : 2026년 예산 확정 보도자료
