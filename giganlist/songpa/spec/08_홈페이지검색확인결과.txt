================================================================================
조사일   : 2026-07
조사대상 : spec/02~06에 등재된 1~5장 사업 **총 35건**
조사방법 : 송파구청 공식 홈페이지(www.songpa.go.kr) 및 구 산하·수탁기관
           공식 사이트, 송파구의회 회의록 시스템(council.songpa.go.kr)에서
           각 사업의 실재 여부를 교차확인

--------------------------------------------------------------------------------
■ 판정 기준 (셋 중 하나로만 분류)
--------------------------------------------------------------------------------
확인됨   : 송파구청 공식 홈페이지(또는 구 공식 하위 사이트)에서 **해당 사업
           고유의 페이지·공고·안내**를 직접 확인함
부분확인 : 구 산하기관·수탁기관 사이트, 구의회 회의록, 공약지도 등에서
           **간접적으로만** 확인되거나, 사업명이 아닌 상위 항목으로만 확인됨
확인안됨 : 위 경로에서 해당 사업 고유의 게시물을 찾지 못함

  ★★ "확인안됨"의 의미 — 반드시 읽을 것 ★★
  확인안됨은 **본 조사의 검색 한계**를 뜻하며, 사업이 취소되었거나 존재하지
  않는다는 뜻이 **결코 아니다**. 자치구 홈페이지는 예산사업 단위로 페이지를
  운영하지 않는 경우가 많고, 다수 사업은 부서 내부 집행으로만 존재한다.
  이 구분을 "미추진"으로 오독해서는 안 된다.

■ 조사 한계 및 정직한 자기평가
--------------------------------------------------------------------------------
(1) 확인안됨 42.9%는 낮지 않은 수치다. 이를 축소·미화하지 않는다.
    주요 원인은 (a) 송파구 홈페이지 내부 검색 결과가 외부 검색엔진에 충분히
    색인되지 않고, (b) 2·4·5장 사업 상당수가 홈페이지에 사업 단위 페이지를
    갖지 않는 유형이기 때문으로 **추정**된다.
(2) 개별 사업 **예산액은 35건 전부 확인 실패**(부분확인 1건 = 5-4 설계공모
    공고 기준값 제외). 즉 예산 확인율은 사실상 **0/35**이며,
    본 spec에서 검증 가능한 예산 수치는 "분야별 총액 5개 + 총액 1개"뿐이다.
(3) 담당부서명이 실제 확인된 사업은 **2건뿐**(3-6, 3-7)이며, 나머지는 전부
    "(추정)"이다. plan 문서에서 '담당(추정)'을 사실처럼 인용하지 말 것.
(4) 본 조사는 공개 검색 기반이며, 구청 내부 시스템·예산서 PDF 원문·
    정보공개청구 자료는 사용하지 않았다.
