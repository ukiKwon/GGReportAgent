================================================================================
[강동구] 06. 5장 — 교육 : 사업목록 및 예산
================================================================================
장 총액 : **구가 분야 총액을 발표하지 않았다 → 확인 불가**
          아래 소계는 확인된 개별 사업 예산의 단순 합이며 분야 총액이 아니다.

★ 본 장은 **2026년 예산 심의에서 실제로 감액된 사업이 포함된 장**이다
  (5-2). 예산액 인용 시 감액 사실을 함께 표기하지 않으면 오류가 된다.

--------------------------------------------------------------------------------
【5-1】 지속 가능한 교육환경 조성
--------------------------------------------------------------------------------
 예산      : **129억 원**
 담당부서  : 교육지원과 **(추정)** — 부서 존재는 홈페이지에서 확인
 내용      : 교육환경 조성 사업. **세부 내역은 구 보도자료에 제시되지
             않았다 → 확인 불가.**
 출처      : 헤럴드경제 / 코리아타임뉴스 (수치 일치)
 ★★ 주의 : 129억은 **묶음 항목**으로 보이며, 통상 자치구의 "교육경비
   보조금"(학교 지원) 성격을 포함할 가능성이 있으나 **확인 불가**다.
   특정 세부사업(예: 학교 시설 개선)의 예산으로 인용하면 **오류**다.
 ★ 확인 불가 : 세부 사업 구성, 지원 대상 학교 수, 단위학교 지원 한도.

--------------------------------------------------------------------------------
【5-2】 더 베스트 강동 교육벨트 (심리-교과 융합 교육과정)  ★ 감액 사업
--------------------------------------------------------------------------------
 편성(원안) 예산 : **8억 3,000만 원**
 심의 결과       : **반액 감액** — 대상을 **고등학교로 한정**하는 조건으로
                   감액 의결
 담당부서        : 교육지원과 **(추정)**
 출처            : 헤럴드경제 / 코리아타임뉴스 — "삭감된 주요 사업" 항목에
                   「더 베스트 강동교육벨트 심리–교과 융합 교육과정
                   (반액 감액, 고등학교로 한정)」으로 명시
 ★★ 인용 규칙 (엄수)
   · **8.3억은 감액 전 원안 편성액**이다. 확정 집행액이 아니다.
   · "반액 감액" 후 확정액은 산술적으로 약 4.15억으로 **추정**되나,
     **구·구의회가 발표한 확정 금액은 확인 불가**다.
     → 본 spec은 **4.15억이라는 수치를 확정액으로 기재하지 않는다.**
   · 이 사업은 spec/01 5절의 "역점사업 삭감 수용" 맥락에 해당한다.
 ★ 확인 불가 : 감액 후 확정 예산액, 사업 내용 상세, 참여 학교 수,
   추경을 통한 복원 여부.

--------------------------------------------------------------------------------
【5-3】 미취업 청년 어학 및 자격시험 응시료 지원사업
--------------------------------------------------------------------------------
 예산      : **확인 불가**
 담당부서  : 일자리정책과 **(추정)** — 홈페이지 「경제/기업/일자리/동물」
             분야에 게시된 사업이나 소관 팀은 미확인
 확인된 내용 :
   · 대상 : **미취업 청년 만 19세 ~ 39세**
   · 내용 : 어학 및 자격시험 **응시료 지원**을 통한 취업 준비 경제적 부담 완화
 출처      : 강동구청 「미취업 청년 어학 및 자격시험 응시료 지원사업」
             (gangdong.go.kr/web/newportal/contents/gdp_005_008_014)
 ★ 확인 불가 : 예산액, 1인당 지원 한도, 연간 지원 인원, 신청 기간.
 비고 : 구 보도자료의 교육 분야에는 포함되지 않았으나, 청년 교육·취업
        준비 지원 성격이므로 본 spec에서 5장에 배치했다.
        ★ **본 조사의 배치 판단**이며 구 공식 분류가 아니다.

--------------------------------------------------------------------------------
【5-4】 청년도전지원사업 (강동)
--------------------------------------------------------------------------------
 예산      : **확인 불가**
 담당부서  : 확인 불가 (**서울청년센터 강동** 연계 **추정**)
 확인된 내용 :
   · 대상 : **18~34세** 청년
   · 프로그램 : **단기 5주 / 중기 15주 / 장기 25주**
 출처      : 복지포털(welfarehello) 「2026 서울 강동 청년도전지원사업」
 ★★ 출처 등급 주의 : 위 내용은 **구청 공식 페이지에서 직접 확인되지
   않았다**(제3자 정책 안내 사이트 기준). 따라서 **구 공식 사업 조건으로
   단정 인용하지 않는다.**
 ★★ 사업 귀속 주의 : "청년도전지원사업"은 **고용노동부 국가사업 명칭**이며,
   강동구는 **수행기관 성격**일 가능성이 높다(**추정**). **강동구 고유
   사업으로 표기하면 오류**다.
 ★ 확인 불가 : 예산액, 수행기관 정확 명칭, 참여 인원, 강동구 부담분.
