================================================================================
[강동구] 08. 홈페이지 검색 확인 결과
================================================================================
목적 : spec/02~07에 기재한 **37건 전체**를 강동구청 공식 홈페이지에서
       교차 확인한 결과.

■ 판정 기준 (셋 중 하나로만 분류)
  · **확인됨**   : 구청 홈페이지에서 **해당 사업 자체의 페이지 또는 공고
                   원문**을 찾아 내용을 직접 확인함
  · **부분확인** : 해당 사업이 속한 **메뉴·게시판·분야 카테고리는 확인**했으나
                   사업 자체의 페이지·예산·조건은 확인하지 못함
  · **확인안됨** : 구청 홈페이지에서 관련 근거를 찾지 못함

■★★ 반드시 먼저 읽을 것
  **"확인안됨"은 검색 한계를 뜻하며, 사업의 부존재나 취소를 뜻하지 않는다.**
  본 조사는 구청 홈페이지의 공개 페이지·게시판만을 대상으로 했으며,
  다음은 조사 대상에서 제외되었다 :
    · 예산서 원문(PDF) 내부 텍스트 — 「연도별예산서」 게시판(b_057) 존재는
      확인했으나 첨부 PDF 본문은 미열람
    · 서울재정포털 강동구 상세 데이터 — 페이지 존재만 확인
    · 로그인·검색 폼 기반 동적 페이지
  ▶ 즉 **확인안됨 비율이 높은 것은 강동구의 문제가 아니라 본 조사의
    접근 범위 한계다.** 이를 구의 정보공개 부실로 해석하면 오류다.

  ★ 또한 강동구 홈페이지는 www / welfare / culture / dong / english /
    chinese 등 **다수 서브도메인이 동일 콘텐츠를 서빙**한다(검색 결과로
    확인). 따라서 URL 서브도메인으로 소관 분야를 판정하지 않았다.

    확인안됨  : 25 / 37 = **67.6%**

■ 확인 과정에서 발견한 **오류·불일치** (spec 본문에 반영 완료)
================================================================================
 (1) **특별신용보증 협약은행 수 불일치**
     구 홈페이지 원문 **2곳** vs 언론보도 **4곳** → spec/04 3-1에 병기.
 (2) **중소기업육성기금 한도 표기 불완전**
     언론 "업체당 최대 2억" vs 구 원문 "**제조·건설·중기업 2억 /
     그 외 업종 1억**" → spec/04 3-2에 병기. 언론 표기만 인용하면
     비제조업 소상공인에 대해 **2배 과대 안내**가 된다.
 (3) **특별신용보증 금리 불일치**
     구 원문 **2.7%(2026-06-10 기준)** vs 언론 **2.5%(2026-01-28 기준)**
     → 변동금리 기준일 차이로 **추정**되나 확인 불가. 병기.
 (4) **취급 금융기관 분류 오류 — 본 조사가 스스로 정정한 사항**
     spec/04 최초 작성 시 중소기업육성기금을 "취급 금융기관 미확인 영역"
     으로 분류했으나, 홈페이지 원문 확인 결과 **특정 시중은행 지점이 단독
     취급기관으로 명시**되어 있었다 → 분류를 정정하고 경쟁 기진입 항목에
     추가했다.
 (5) **서울시 사업의 구 사업 오인 위험 — 구청이 직접 경고**
     게시글 154532는 본문에 "**이는 강동구 사업과 별개인 '서울시'
     중소기업육성자금 사업입니다!**"라고 **구청이 직접 명시**하고 있다.
     → 서울시 조건(최대 5억 / 이차보전 1.8% / 융자규모 2조 4,000억)을
       강동구 값으로 전용하는 것은 **구청 스스로가 경고한 오류**다.
       본 spec은 이를 준수했다.
