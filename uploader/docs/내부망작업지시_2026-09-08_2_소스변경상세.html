1왜 자바까지 바뀌나 — TypeHandler

MyBatis의 resultMap은 자바 필드와 DB 컬럼을 잇는 번역표이고, TypeHandler는 그 번역표가 값을 어떻게 바꿀지 정하는 규칙입니다. 표준이 요구하는 값(문자열 시각·2자리 코드)과 자바가 쓰는 값이 다르므로, 변환을 세 클래스에 가두어 도메인·서비스·화면·테스트를 지켰습니다.

TypeHandler자바가 쓰는 값DB 에 들어가는 값
LocalDateTimeStringTypeHandlerLocalDateTime'20260908103000'
ClassificationStatusTypeHandler"UNCLASSIFIED"'01'
InstitutionCategoryTypeHandler"지방자치단체"'01'
규칙 두 개만 지키면 됩니다
  1. resultMap 과 #{...} 양쪽에 적는다. 두 코드 핸들러가 모두 자바 String 을 다뤄 자동 등록을 쓸 수 없습니다. 한쪽만 적으면 읽기나 쓰기 중 한 방향만 변환돼 조용히 어긋납니다.
  2. SQL 에 직접 박은 값은 코드로 적는다. TypeHandler 는 파라미터와 결과에만 걸립니다. SET 분류상태구분 = '04' 자리에 'DELETED' 를 적으면 오류 없이 0건이 바뀝니다.
