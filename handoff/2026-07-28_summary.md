- **범례가 테마와 따로 놀던 버그** — 범례가 `🔴🟠🟡🔵⚪` 이모지 하드코딩이라, `🎨 지도 색상`
  으로 색을 바꿔도 **범례만 옛 색으로 남았다**. 테마 색 스와치로 교체해 해소.
- **레이아웃 깨짐** — `기관 분류선택` 제목을 넣자 상단바가 두 줄이 되면서
  `#map-stage { height: calc(100vh - 120px) }`의 120px 가정이 무너져 **지도와 우하단 범례가
  화면 밖으로 30px 밀렸다**. 매직넘버를 걷어내고 body flex 채움으로 교체.
- **innerHTML 주입 경로** — 범례 스와치 색이 localStorage에서 오므로 style 속성에 그대로
  끼우지 않고 hex 정규식 검증(`render._safeColor`)을 거치게 함.

### 알아두면 좋은 것

- **`getBBox()`는 요소 로컬 좌표를 반환한다.** 라벨은 `<text>` 자체에 transform이 걸려 있어
  `getBBox().x/y`가 전부 0 근처로 나온다 — 겹침 검증 스크립트를 처음에 이걸로 짰다가
  "모든 쌍이 겹침"이라는 잘못된 결과를 봤다. 구현은 `data-x/data-y` + bbox 크기를 쓰므로
  정상이었고, 검증은 `getBoundingClientRect()`로 다시 재야 맞다.
- Chrome 확장의 스크린샷이 **뷰포트 오른쪽을 잘라낸다**(1552px 뷰포트인데 1512px만 캡처).
  우하단 범례는 캡처에 안 잡히므로, DOM 좌표로 확인하거나 임시로 `left`로 옮겨 캡처했다.
- 브라우저 자동화 탭에서 `setTimeout` 체감 시간이 실제보다 길게 나온다(백그라운드 스로틀).
  타이밍은 상수값(`ZOOM_MS`/`HOLD_MS`)으로 확인하고, 체감은 사용자 육안에 맡길 것.
