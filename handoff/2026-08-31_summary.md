### 판단 3가지 (근거와 함께)

1. **시각 타입을 `TIMESTAMP`로 했다** — 본체의 `007_uploader.sql`은 같은 열을
   `VARCHAR2(40 CHAR)` ISO 문자열로 둔다. 007은 uploader 테이블을 **본체 스키마에
   합칠 때**(단계 6)의 초안이라 본체 규약(설계 §5)을 따른 것이고, 이번 것은 uploader
   **단독** 정본이다. 도메인이 `LocalDateTime`을 쓰므로 문자열로 두면 코드를 고쳐야
   한다. **두 파일을 의도적으로 공존시키고 서로를 가리키는 주석을 남겼다.**
2. **IDENTITY가 아니라 시퀀스** — Mapper의 oracle 분기가 `..._SEQ.NEXTVAL`을 부르고,
   11g에서도 그대로 돌아 Oracle 버전 회신을 기다릴 필요가 없다.
3. **주석을 푸는 대신 `databaseId` 분기** — 주석 방식은 ⓐ 배포 때 사람이 풀어야 하고
   ⓑ 테스트가 못 봐서 조용히 낡는다. 본체 `kgi-ggreport-web`이 이미 같은 방식을 쓰고
   있어 그대로 맞췄다. **유일한 차이는 H2 처리** — 본체 테스트 H2는 `MODE=Oracle`,
   uploader는 `MODE=MySQL`이라 `resolve()`가 서로 다른 방언을 돌려준다(코드에 주석).

### 함께 잡은 버그 1건

### 추가 (같은 세션) — `@Scheduled` → CommonJ TimerManager, 항목 18 완결

사용자가 "workmanager가 뭐하는 건데?" 하고 물어서 먼저 설명하고 진행했다.
**설명 과정에서 중요한 분기를 잡았다** — 본체의 WorkManager 배선을 그대로 가져올 수
없다는 것이다.

- `commonj.work.**WorkManager**` = "지금 백그라운드로 **한 번** 돌려줘"
  → 본체 오케스트레이터가 쓰는 것(Task 4.2, `a63154b`)
- `commonj.timers.**TimerManager**` = "**5분마다 반복**해서 돌려줘"
  → uploader 의 재분류가 필요한 것

`@Scheduled(cron)` 은 반복이므로 **후자**가 맞다. 본체 코드를 그대로 복사했으면
1회성 API 로 반복을 흉내 내는 잘못된 구조가 됐을 것이다.

#### 만든 것 (커밋은 아래 참조)

| 클래스 | 역할 |
|---|---|
| `job/BackgroundScheduler` | "지연 뒤 한 번 실행" 인터페이스 |
| `job/TimerManagerScheduler` | CommonJ TimerManager (리플렉션 + 동적 프록시) |
| `job/LocalScheduler` | 자바 표준 스케줄러 폴백 (외부망·테스트 전용) |
| `job/ReclassificationTrigger` | cron 으로 다음 시각 계산 → **매번 재예약** |
| `config/SchedulerConfig` | JNDI 조회 성공 여부로 둘 중 하나를 고른다 (재작성) |
| `WEB-INF/web.xml` | **신규** — `timer/uploaderTM` + `jdbc/uploaderDS` resource-ref |

#### 판단 3가지

1. **"한 번 돌고 다시 예약"으로 반복을 만든다.** TimerManager 는 cron 을 모르고 고정
   주기(ms)만 받는다. ms 주기를 따로 두면 `reclassification.cron` 과 **두 벌**이 되어
   조용히 갈린다. 그래서 주기의 근거를 cron 한 곳에 두고 매 실행 뒤 다음 시각까지의
   지연을 계산해 1회성 예약을 다시 건다(Spring `CronExpression` 사용).
2. **다음 예약은 `finally` 에서 건다.** 한 번 실패했다고 반복이 멈추면 증상이
   "미분류가 계속 쌓인다"로만 나타나 원인을 찾기 어렵다.
3. **`@Bean` 에 `destroyMethod` 를 명시하지 않았다.** 기본값이 추론이라
   `shutdown()` 이 있는 `LocalScheduler` 만 정리되고 `TimerManagerScheduler` 는
   건너뛴다. 이름을 박으면 후자에서 기동이 깨지고, **그건 내부망에서만 터진다.**
