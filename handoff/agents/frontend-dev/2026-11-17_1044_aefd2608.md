  - 새 인자 `kbCardHtml(kb, o)`: `o.empty`가 true면 와플·범례·안내 없이 `국민은행 금고 자료를 불러오지 못했습니다. 화면을 새로 고치세요.` 한 줄만 냅니다.
- **B** 새 순수 함수 `dash.moveNote(view, ovView, inList)`(`dash.ovEmpty` 바로 위).
  - 목록에 없으면 `이 기관은 경과 목록에서 빠졌습니다.`를 냅니다.
  - 같은 보기면 빈 문자열을 냅니다.

  - `recDone`(약 1130줄)은 저장 안내를 띄운 뒤 `Promise.resolve(n.load()).then(...)`에서 `#db-flash`에 `o.msg + ' ' + note`를 다시 씁니다.
  - 붙이는 조건은 다섯 가지입니다. 화면이 열려 있고, 같은 저장 요청이고, 선택 기관이 그대로이고, 경과 탭이고, flash가 그사이 바뀌지 않았을 때입니다.

### 3. 지시와 다르게 판단한 것
- **N-1 시험을 DOM으로 못 썼습니다.** `onRecChange`는 `host`·`M`이 있어야 도는데, 이 저장소의 시험은 `mount`를 못 돌립니다. 대신 소스 정규식으로 `if (changed && it) recSync(it)` 연결만 고정했습니다. 이력 재요청을 직접 증명하는 시험은 아닙니다. `qa-verifier`가 D-2로 화면에서 확인해야 합니다.
- **자료가 비었는지는 `kbCount`가 아니라 호출부에서 판단합니다.** `kbCount` 반환 모양을 바꾸면 기존 `deepStrictEqual` 시험 3곳이 깨져서, `kbboard.js`가 `KB_VERIFIED`가 배열이 아니거나 비었는지 보고 `{empty}`를 넘기게 했습니다.
- **P3-8 안내는 경과 탭에서만 붙습니다.** 목록이 다른 탭이면 붙이지 않습니다. 선택 기관을 `selItem()`으로 못 찾거나 `it.overdue`가 false면 "경과 목록에서 빠졌습니다."를 씁니다.
- **N-3은 `error`·`denied`만 새 문구입니다.** `idle`·`loading`은 이력 쪽 `불러오는 중` 상태가 따로 있어 건드리지 않았습니다. 지도 팝업의 `recordBriefHtml`(dmRecState)도 건드리지 않았습니다.
- **D의 링크 줄은 `<p class="db-empty">` 안에 `.hb-src` 블록을 넣은 모양입니다.** 약정 입력 버튼이 있는 `bk-foot` 아래에 붙으므로, 화면에서 위치가 어색하면 알려 주세요. 그 위치는 `bankcontract.js` 안쪽이라 제가 못 고칩니다.
- 상세 줄의 sr-only ", 새 탭"은 `kbb.srcHtml`이 이미 넣습니다.

  - 1280폭에서 와플 카드 안내가 약 3줄인지.
