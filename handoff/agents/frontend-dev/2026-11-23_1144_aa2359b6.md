## 5. 위험·되돌리는 법
- noResult는 rate_denominator 누락 시 0으로 읽혀 '결과 없음'으로 보인다(서버가 보내는 필드라 현재 문제 없음).
- barHtml·barNoteHtml 둘 다 ''이면(목표 5곳 미만 등) 기존처럼 #rs-bar가 비어 숨는다.
- keep-all은 .rs-band 안에만 건다(칸 minmax(0,1fr), 880px 이하 2열이라 영향 작음).
- 되돌리기: 세 파일을 git checkout. 단, git status에 index.html이 이미 M(다른 작업)이라 경로 지정 커밋이 남의 변경을 쓸어 담지 않게 주의(메모리 feedback_pathspec-commit-sweeps-worktree).
