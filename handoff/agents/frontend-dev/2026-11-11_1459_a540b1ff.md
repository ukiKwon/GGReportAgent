### 3. 규격·지시와 다르거나 내가 판단한 것
- 과제 번호: 서버 view에 `sort_no`가 없어 배열 순서(1부터)를 번호로 씁니다. 서버가 `sort_no`를 주면 바꾸는 편이 낫습니다.
- 현황판 기본 화면: 지시에 없던 안전장치로, `root.dashboard.mount`가 없으면 첫 화면을 지도에 둡니다. 9f 본체가 들어오기 전에 영업 계열이 "준비 중" 화면에서 시작하지 않게 하기 위해서입니다.
- 현황판 노출은 지시대로 map 키가 켜진 전원입니다. 둘러보기(guest)도 사이드바에서는 보입니다. 첫 화면 기본값은 영업 계열에게만 적용됩니다.
- 개설 신청자·영업팀 전원 열람은 서버 필드를 폴백 포함으로 처리했습니다.
  - `can_view`가 없으면 열 수 있다고 보고, `false`면 행을 `aria-disabled`로 표시합니다.
  - 404 문구는 "…개설 전에는 영업팀 전원, 승인 대기 중에는 신청자도 봅니다"로 바꿨습니다.
  - `open_request.nominees`·`comment`가 없으면 지명 줄을 그리지 않습니다.
  - `tasks[].done_rule`이 없으면 T3·T5는 규격의 하드코딩 문구를 씁니다.
- 신청 회수: 확인 줄 없이 바로 `POST /approval-requests/{id}/cancel`을 부릅니다. 성공 문구와 버튼 id `withdraw`는 규격 표에 없어 내가 정했습니다(문구 "개설 신청을 회수했습니다.").
- 중단(`[중단…]`) 머리 버튼은 일반 버튼입니다. 빨간 테두리(`.pp-danger`)는 모달의 [중단하기]에만 입혔습니다(규격 §6-A 그대로).
- 지도 팝오버: 숨긴 칸(이름·지역코드·구시군코드·경도·위도) 중 필수 항목이 비어 있으면 '원본 정보' 안에 "누락된 칸: …" 한 줄을 더했습니다. 데이터 결함이 가려지지 않게 하려는 것입니다. 현재 필수 필드는 name·type·region뿐이라 경도·위도는 실제로 알리지 않습니다.
- 입찰 예정일 라벨은 지도의 기존 `logic.confidenceLabel`을 그대로 써서 '(추정)'입니다(team.js의 '예상'과 다름).
- 팝오버 안 버튼 클릭은 `stopPropagation`합니다. 문서의 '바깥 클릭' 핸들러가 DOM에서 빠진 버튼을 바깥으로 보고 팝오버를 닫는 문제를 피하려는 것입니다.
- 확인 줄은 `.bd-confirm`(다른 세션 CSS) 대신 내 `.pp-confirm`을 새로 만들었습니다. 결합을 피하려는 것입니다.
- 서버 호출 헤더:
  - `X-Screen-Id`·`X-Button-Id`는 `PrepUiIds`에 있는 값만 보냅니다.
  - 첨부 버튼(올리기·내려받기·무효·확정본 지정·해제)과 첨부 목록은 허용값이 없어 `X-Button-Id`를 보내지 않습니다(서버에서 UNKNOWN 기록).
  - 지도에서의 제안 확정은 허용값에 지도 화면이 없어 `prep_list` + `confirm`으로 보냅니다.
- 내려받기: 링크는 `X-Emp-No` 헤더가 안 붙어 401이 될 수 있어, `fetch`로 받은 blob을 내려받습니다.
- 첨부 목록은 활성 담당자·영업부장만 서버가 허용하므로 그들만 요청합니다. 그 밖은 T3 카드에 파일 영역을 그리지 않습니다.
- 목록 정렬은 규격 임시안(단계 순 → 가나다) 그대로입니다.

### 4. 위험
- `index.html`에 9f와 내가 같이 손댔습니다. 양쪽 블록이 공존하는지는 grep으로 확인했고, 커밋 시 두 블록 모두 들어가는지 메인이 확인해 주세요.
- `app.js`의 `applyHome()`은 `paintTabs`(메뉴 응답)마다 호출되지만 `pendingHome`은 한 번만 소비합니다. 이미 다른 탭을 연 상태이면 건드리지 않습니다.
- `#pp-modal`은 공용 닫기에서 빠졌습니다. 닫기와 포커스 복귀는 prep.js가 처리합니다.
- 서버 변경 전에는 `can_view`·`nominees`·`done_rule`이 없는 응답으로 폴백 문구가 보입니다(위 3 참고).
- 실제 화면은 못 봤습니다. 키보드 포커스 이동과 팝오버 위치는 qa-verifier나 design-reviewer의 Playwright 확인이 필요합니다.
