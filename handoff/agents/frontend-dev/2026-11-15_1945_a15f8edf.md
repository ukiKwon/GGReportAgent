## 2. 규격과 달라진 점
1. 새 파일 `instedit.js`를 만들었습니다. 순수 규칙을 node로 시험하려면 app.js와 분리해야 했습니다.
2. 모달을 여는 동작(`open_edit`)은 서버로 가는 요청이 없어 헤더를 보내지 않습니다. PUT은 `institution_edit` + 묶음별 버튼 ID만 보냅니다. `from`은 받기만 하고 쓰지 않습니다. 감사 기록에 '어디서 열었는지'가 남지 않으니 필요하면 백엔드 이관입니다.
3. 기본 정보 묶음에서 '수정일'(`updatedAt`) 칸을 뺐습니다. 규격 6-C의 칸 목록에 없어서입니다.
4. 파일 모드(서버 없음)에서는 입찰 예정일 묶음을 출처 칸 없이 이 PC에만 저장하는 모양으로 둡니다. 서버 모드인데 서버에 없는 기관은 입찰 예정일·운영 상태 묶음 대신 안내 한 줄만 보입니다. 둘 다 규격 밖의 보완입니다.
5. 저장이 끝나면 포커스를 그 묶음의 첫 입력칸으로 보냅니다. 저장 중 버튼이 disabled가 되며 포커스가 사라지는 것을 막기 위해서입니다.
6. 현황판 선택 상태를 위해 `findItem`/`renderPane`/`pruneSelection`/`refreshData`/`onClick` 등 지시한 범위(`paneHtml`·`renderList` 부근) 밖의 줄도 고쳤습니다. `doConfirm` 계열은 피했습니다.
7. `confirmed` 칸이 서버 값이 되면서 내보내기(`export.js`)가 만드는 `window.institutions` JSON에 `_inst`·`_bid` 같은 내부 칸이 섞입니다. `bidCaseId` 등은 이미 섞이고 있었습니다. 필요하면 별도 항목으로 처리해야 합니다.

## 4. design_history 전/후 장 문안
(규격 §전/후 문안 그대로)
- **전:** 360px 1열에 13칸. '입찰예상일' 칸과 확정 여부(이 PC에만 저장)가 따로 논다. 저장하면 `서버 저장 실패 (400)` 팝업만 뜨고 이유가 없다. 공고가 있는 기관은 공고 날짜가 칸에 들어가 있어 손대지 않아도 실패할 수 있다.
- **후:** 560px 2열, 세 묶음(입찰 예정일 / 운영 상태 / 기본 정보)마다 저장 버튼. '추정 / 공고로 확정'을 고르고, 확정이면 공고 링크나 번호를 적어야 저장된다. 왜 안 되는지가 칸 바로 아래 글자로 나온다(대비 약 7.7:1). 확정 날짜 옆에는 출처 호스트(예: g2b.go.kr)가 보이고, 개원 예정일이 지난 법원은 현황판 '개원 확인 필요 n곳'에 모인다.
- **왜:** 서버가 "날짜를 확정하려면 근거를 남긴다" 규칙을 세웠는데 화면이 그 규칙을 몰라 저장이 막혔기 때문이다.

화면 캡처는 못 만들었습니다. 메인이 `docs/design_history/index.html`의 `section.ch`로 추가할 때 시안은 규격 시안 HTML을 쓰면 됩니다.

## 5. 컴파일·실행이 의심되는 곳
- `instedit.js`의 `ie.open` 전체는 DOM 전용이라 시험에 안 걸립니다. 브라우저에서 직접 확인이 필요합니다.
  - 모달 열기, 날짜를 지웠을 때 [공고로 확정] 비활성화, Esc와 [닫기]의 확인 상자, Tab 가두기.
  - 저장 중 버튼 문구와 저장 뒤 포커스.
  - `<details>` 접힘 안의 포커스, [기관 정보 변경]에서 운영 상태 첫 라디오로 가는 포커스.
  - 지도 상세의 [편집] 버튼으로 열었다 닫을 때 포커스 복귀(`opener`가 이미 사라졌을 수 있음).
- 유니코드 정규식 `/^[\p{L}\p{N}][\p{L}\p{N} _.\/()\-]{0,49}$/u`는 node 22와 최신 브라우저에서는 동작합니다. 폐쇄망의 구형 브라우저에서는 확인이 필요합니다.
- `dashboard.js` 개원 확인 필요 흐름
  - 목록은 `store.loadData()`(서버 행)에서 모읍니다. 그래서 서버 모드이고 서버가 `open_check_needed=true`를 내려 줄 때만 보입니다.
  - 그 목록에서 행을 고르면 `itemForRec`로 항목을 만들고, 접으면 선택도 풉니다. 실제 서버 데이터로 한 번 눌러 봐야 합니다.
- CSS는 `.ie-note:empty`·`.ie-err:empty`로 빈 줄을 숨깁니다. `role="alert"` 문단은 처음엔 비어 있다가 글이 들어올 때 읽히도록 미리 두었습니다. 스크린리더 동작은 직접 확인이 필요합니다.
