## 2. 근거 요약
- 서버는 `GET /institutions/{id}/head/docx?ref_no=N`이다.
  - 쿼리 이름은 `ref_no`이고, 정규식 `[0-9]{1,2}`와 1~20만 받는다. 생략하면 1이다.
  - 응답은 `Content-Disposition: attachment; filename="head_info.docx"; filename*=UTF-8''기관장정보_{기관}_{YYYYMMDD}.docx`다. 한글 이름은 `filename*`에만 있으므로 그것을 풀어 쓴다.
  - 오류 코드와 화면 문구:

| 코드 | 의미 | 화면 문구 |
|---|---|---|
| 400 `UI_ID_REQUIRED` | 화면·버튼 식별자 없음 | 화면 오류 문구 |
| 400 `BAD_VALUE` | ref_no 범위 밖 | 칸 오류 "1~20 사이 숫자를 넣으세요." |
| 401 | 사번 없음 | `hc.TEXT.login` |
| 403 | 영업 계열 아님 | `hc.TEXT.role` |
| 404 `FEATURE_OFF` | 기능 꺼짐 | `hc.TEXT.off` |
| 그 밖의 404 | 서버에 없는 기관 | `hc.TEXT.notfound` |
| 409 `HEAD_EMPTY` | 확정된 현 기관장 없음 | 규격 문구 |
| 5xx | 감사 기록 실패 등 | 규격 문구 |
| 연결 실패 | 응답 없음 | `hc.TEXT.network` |

- 권한은 서버 기준이다. `run()`이 영업팀·영업팀장·영업부장이 아니면 403으로 막고 감사에 DENIED를 남긴다(`:476`).
  - 화면은 `hc.gate`를 통과한 영업 계열에게만 카드를 그리므로 따로 판정하지 않는다.
  - 카드가 `ok`일 때만 버튼이 생긴다. `none`·`denied` 등에는 버튼이 없다(`cardHtml`은 `ok`에서만 호출).
- 재사용 검토:
  - blob→a[download] 구현은 `board-material.js:1154`, `board.js`, `plans.js`, `prep.js` 등에 인라인으로 흩어져 있고 공용 함수가 없다. `export._download`는 텍스트 전용이다.
  - `board-material.js`의 `docxFileName`은 `board-material.js`가 `headcard.js`보다 먼저 로드되지만(`index.html` 2887 < 2893), 기본 이름이 '이사회자료-확정본.docx'로 고정이다. node 시험에서는 `require`도 안 된다.
  - 그래서 같은 정규식을 headcard 안에 작게 둔다. 중복 정리는 이관 메모로 넘긴다.
- 클릭은 `dashboard.js:1645`·`:1808`의 `[data-hc]` 위임이 `hc.onPaneClick`으로 넘긴다. 새 단추도 `data-hc`만 달면 dashboard.js 변경 없이 동작한다.
- 번호 입력 줄은 `V.dl`(상태)에 보관한다. `repaint`가 카드를 다시 그려도 열린 줄·입력값·오류가 사라지지 않는다. `fresh()`가 기관별로 초기화한다.

## 5. 규격과 다르거나 덧붙인 판단
1. **버튼 이름은 규격대로 "워드 내려받기"**를 쓴다. 지시문의 "Word 내려받기"가 아니다. 규격 6-6과 design_history 전/후 문안이 "워드"이기 때문이다. 바꾸려면 E3 문자열 한 곳이다.
2. **기관 이름**: 규격은 미리보기에 「강남구」를 넣는다. 그러나 `headEnv`·`dmHeadEnv`에 기관 이름이 없다. 선택 패치 3-C로 `instName`을 넘기면 보이고, 아니면 「」 없이 "참고자료 N. 기관장 정보"로 나온다. 서버가 만드는 실제 문서 제목에는 영향이 없다.
3. **줄 상태를 `V.dl`에 둔 이유**: 규격은 "펼친다"만 말한다. 사진 불러오기·다시 읽기가 `repaint`로 카드를 다시 그리면 DOM에만 둔 입력 줄은 사라진다. 그래서 상태를 두었다. 번호 칸 입력 중에는 카드를 다시 그리지 않고 제목만 `textContent`로 바꾼다.
4. **409 뒤 조용한 재조회**: 규격에 없는 추가다. 409면 카드가 낡았다는 뜻이라 `refresh(true)`로 읽는다. 기관장이 비었으면 카드가 `none`이 되어 단추도 사라진다. 이때 재조회 감사는 `refresh` 버튼 ID로 남는다. 원치 않으면 `.catch` 안의 해당 한 줄을 지운다.
5. **400 `UI_ID_REQUIRED`·401·404(FEATURE_OFF 구분)** 문구는 규격 표에 없어 기존 `hc.TEXT`를 재사용해 더했다.
6. **번호 칸 키 동작**: Enter는 내려받기, Esc는 접기다. 규격에는 없고 접근성 보강이다. 키 이벤트는 `document` 위임이라 `dashboard.js`는 건드리지 않는다. 지도 팝업의 Esc 닫기와 겹치는지는 실화면 확인이 필요하다(아래 위험).
7. **공용 함수**: 위 2절대로 만들지 않고 headcard에 같은 규칙의 작은 구현을 두었다.

## 6. 위험·되돌리는 법
- **`repaint` 동기성**: `docxOpen` 직후 `focusPane`이 새 DOM을 찾아야 한다. `renderPane()`이 동기면 문제없다. 비동기면 포커스가 입력 칸으로 안 간다. 실화면에서 한 번 확인한다.
- **Esc 충돌**: 지도 상세 팝업이 `document` keydown으로 Esc를 닫는다면 번호 칸 Esc가 팝업까지 닫을 수 있다. 그러면 `docxCancel` 뒤 `e.stopPropagation()`을 더한다.
- **받기 직후 repaint**: 지도 팝업(`dmRepaint`)이 `#dm-box` 전체를 다시 그리는 경우에도 상태는 `V.dl`에 있어 줄은 유지된다.
- **서버 쪽**: 감사 기록은 응답 전에 남는다(`HEAD_DOCX`). 화면은 파일이 오지 않으면 성공 문구를 내지 않는다.
- **되돌리기**: E1~E8과 CSS 덩어리를 역순으로 되돌린다. 한 커밋으로 묶으면 `git revert` 한 번이다. `dashboard.js` 3-C는 별도 커밋이다.

## 7. 이관 메모

- [이관: 개발] blob 내려받기 코드(`a[download]`+`createObjectURL`+revoke)가 `board-material.js:1154`, `board.js:1811`, `board-write.js:2185`, `plans.js:822`, `prep.js:1281`, `plancollect.js:408`, `admin.js:830`에 따로 있다 — 공용 함수 하나(`logic.js` 또는 새 파일)로 모으는 정리 — 지금은 범위 밖이라 headcard에 `hc.saveBlob`을 두었다 — 디자이너 파일 내려받기 fetch→blob(규격 7절)도 같은 공용 함수를 쓰면 된다.
- [이관: 디자인] 규격 6-6 CSS는 그대로 쓰되 `.hc-ref` 안 [내려받기]에 `db-next`(강조 단추)를 썼고, 번호 칸을 13px로 했다(규격 12px) — 확인 요청 — 시험(12px 미만 금지)과 입력 가독성 기준.
- [이관: 디자인] 닫힌 뒤 성공 줄("워드 파일을 내려받았습니다.")이 언제까지 남아야 하는지 — 지금은 다시 펼치거나 기관을 바꿀 때까지 남음 — 규격에는 "줄을 접고"만 있고 성공 줄 수명이 없다.
- [이관: 디자인] 규격 7절 design_history 전/후 장 문안 중 ②는 그대로 쓸 수 있다("카드 아래 [워드 내려받기] → 참고자료 번호·문서 제목 미리보기 → .docx(확정 값만)"). 메인이 적용 뒤 추가한다.
