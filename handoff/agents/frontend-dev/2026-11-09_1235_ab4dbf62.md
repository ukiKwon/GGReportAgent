### 3. 지시에서 벗어난 판단
- **새 파일 `frontend/js/overdue.js`와 `frontend/test/overdue.test.js`를 만들었다.** 지시문의 읽기 목록에는 없었다. `render.js`가 이미 큰 데다 판정(logic)과 DOM을 분리하려고 했다. 허용 경로(`frontend/js/*.js`, `frontend/test/*.js`) 안이다.
- **'하루 1회'를 이렇게 해석했다.** 로그인할 때마다 팝업을 띄우고, '오늘 더 이상 보지 않기'를 누르면 그날(자정까지)은 숨긴다. 디자이너가 가정한 가)안이다. 페이지를 새로 고쳐 기존 세션으로 들어갈 때는 띄우지 않는다. 로그인 시점만 본다.
- **'오늘' 날짜가 두 가지다.** 건너뛰기 키는 실제 현재 날짜, 기준일 표시는 `render.state.today`(페이지 로드 시점)다. 자정을 넘겨 켜 둔 화면에서는 둘이 다를 수 있다.
- **마스터 계정에도 팝업이 뜬다.** `nav.isSales`가 마스터를 영업 계열로 취급하기 때문이다.
- **도킹 패널을 접거나 펼칠 때 전국 지도를 다시 그린다.** 도킹 폭이 바뀌면 지도가 옛 폭으로 남기 때문이다. 줌 상태는 초기화된다. 창 폭이 도킹 경계를 넘을 때도 같다. `drawNational`을 호출만 했고 지도 렌더 코드는 고치지 않았다.
- **패널 열림은 도킹일 때만 localStorage에 기억한다.** 서랍과 쌓기는 항상 접힌 채 시작한다.
- 지연·처리됨 탭은 0건과 "상태 기록 기능은 준비중입니다."만 보인다. 상태 칸은 빈 `span`이다.
- 행을 눌러도 아무 일도 없다(정적 목록). 기획의 '지도에서 보기' 질문은 미정이라 넣지 않았다.
- 이름 `.ov-star`의 색 `#d8c47a`는 시안 그대로다. 기존 `.region.watched`가 쓰는 색이라 새 색은 아니다.
- `#ov-sub` id를 추가했다(시안에는 클래스만 있었다).
- `app.js:416`의 '추정' 변경은 지시 ⑦의 일부다.

### 4. 확인이 필요한 점(브라우저 실측 필요, 시안과 같은 CSS이지만 렌더는 못 봤다)
- 1440에서 `#map-stage` 폭이 700 이상인지(시안 실측 778), 패널이 360인지.
- 1365에서 서랍으로 바뀌는지, 929에서 서랍이 범례 위·모달 아래인지.
- 탭 4개가 한 줄에 들어가는지.
- 드릴인(예: 서울 클릭) 시 도킹 패널이 사라지고 지도가 왼쪽으로 쏠리지 않는지. `drawRegion`이 폭을 재기 전에 `syncLayout`이 먼저 실행된다.
- 로그인 직후 팝업의 Tab 순환, Esc, 포커스 복귀. 열기 직전 포커스가 숨은 로그인 버튼이면 사이드바 '전국 지도' 항목으로 간다.
- 사이드바 배지가 `drawNav`의 DOM 재생성 뒤에도 남는지.
- 실제 데이터에서 경과 건수: 디자이너 스냅샷은 23건, 날짜 미상 185건이다.
