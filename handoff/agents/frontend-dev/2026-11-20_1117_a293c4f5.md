# 기관장 '생년월일' 화면 패치 (frontend-dev)

## 1. 대상·방법·못 본 것
- **읽은 곳**: 규격 `handoff/agents/design-reviewer/2026-11-20_1059_a3661836.md`(파일 있음). `frontend/js/headcard.js` 전체. `frontend/test/head-card.test.js` 필요한 부분. `frontend/index.html` 2258-2358 CSS. `errtext.js`. 서버 `InstitutionHeadService`의 BIRTH_DATE 줄(372, 573, 602, 882).
- **못 본 것**: 화면과 Playwright(MCP 연결 실패), 서버 실제 응답. 아래 사실은 서버 코드로 확인했다.
  - 후보 `candidates[].value`와 `head.fields.BIRTH_DATE.value`는 같은 `valueOf(i)`다. 날짜 문자열로 온다.
  - 후보 머리의 `items[]`는 같은 `valueOf` 모양이라고 가정했다. 후보 머리 요약(`candidateHeadRow`)의 BIRTH_DATE 항목도 같은 `valueHtml`을 쓰게 했다.
- 이 패치로 NAME·POSITION 외 기존 id는 바뀌지 않는다. 바뀌는 구조는 출처 이름 칸 `<label>`이 `<div class="hc-fld">`로 감싸지는 것뿐이다. 이 칸의 id나 selector를 쓰는 시험은 없다(`src_title`은 headcard.js에서만 쓴다).

## 2. 요구 요약
- 카드에는 생년월일이 나오지 않는다. 편집 팝업의 입력 칸, 후보·확정·후보 머리 행의 `1965-03-02 (만 61세)`, 출처 이름 안내, 이월 안내, NAME·POSITION 무효 확인 문구가 대상이다.
- **중요 발견**: `buildItemBody`는 kind가 'date'일 때만 `b.date`를 만든다. kind 'birth'는 `b.value`로 가서 서버에 날짜가 가지 않는다. 그래서 패치 3으로 `date`로 보내게 한다.

## 5. 위험·되돌리는 법
- **`valueText(it, today)` 시그니처 변경**: today를 생략하면 날짜만 나오고 기존 호출은 그대로다. 호출자는 headcard.js 내부뿐이다(grep으로 확인).
- **출처 이름 칸이 `div.hc-fld`로 감싸짐**: 2열 그리드에서 셀 높이가 안내 문단만큼 커져 같은 줄 옆 칸(출처 종류)과 높이가 달라질 수 있다. 화면 확인이 필요하다(Playwright가 안 되어 못 봤다). 어긋나면 `.hc-form .hc-fld { align-self:start }`를 더한다.
- **이월 안내가 자주 뜰 수 있다**: 권한대행 '아니오'도 확정 항목으로 남으므로, 이름·직위를 무효 처리해 빈 머리가 되면 대부분 안내가 뜬다. 규격 그대로 구현했다.
- **서버 INVALID_DATE 메시지**: 서버가 메시지를 비워 보내면 범위 문구로 대체한다(패치 11 주의 참고). 메시지에 입력값이 없다는 전제는 규격에서 가져왔다.
- **출처 제목 서버 거절(INVALID_TEXT)**: 지금처럼 상단 상태줄에 나온다. 서버 표지가 생기면 `showBirthErr`와 같은 방식으로 `{pre}-st-e`를 더한다.
- **되돌리는 법**: headcard.js, index.html의 CSS 4줄, 시험 파일을 `git checkout`으로 되돌린다. 서버나 데이터에는 영향이 없다. `handoff/NEXT.md`와 다른 파일은 건드리지 않는다.
