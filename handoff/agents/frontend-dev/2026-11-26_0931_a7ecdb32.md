## 2. 요구 요약과 팀 결정
- 12개월 칸 `td.ln`·머리 `th.ln`·범례(`goalFootHtml`)·함수 3개(`laneWindow`·`laneGeom`·`laneCellHtml`)와 보조 함수(`monthPos`·`dayNo`·`dayIso`·`round3`, 모두 lane 전용)·CSS·미디어쿼리를 지운다.
- **단추 자리 결정: 목표 표 맨 끝에 '동작' 칸(`<td class="act">`, 머리는 sr-only '동작')을 둔다.**
  - 근거 1: 관심 탭 표가 이미 '맨 끝 동작 칸 + `.hb-wacts`'로 같은 종류의 단추([목표로 옮기기…]·[관심에서 빼기…])를 놓고 있어 한 화면 안에서 규칙이 하나다.
  - 근거 2: 열 수(8)가 그대로라 `colspan="8"`·`ncol`·`nth-child(7)` 규칙과 시험(`colspan="8"/"9"`, `<td` 7개)이 변하지 않는다.
  - 근거 3: 준비 단계 칸(132px)에는 단추 둘(약 200px)이 들어가지 않고, NEXT 120이 단계 칸을 두 줄로 바꿔 거기에 단추를 더 얹기 어렵다. 설명회 칸 56px은 자리 표시 칸이라 합치지 않았다.
  - 단추 순서·이름·조건(보기 전용 없음, 결재 중 없음, 지난해 목표는 [관심 기관으로…] 없음, 옛 서버 noWatch는 [관심 기관으로…] 없음)은 그대로다.
- ③ 목표 밖 입찰 종료 줄('사실만' 칸)은 같은 동작 칸에 sr-only 문장 '올해 입찰이 끝난 기관'만 둔다. 보이는 글자 '올해 입찰 끝남'은 마감까지 칸의 '입찰 종료'+근거와 같은 말이라 뺐다. 보기 전용·결재 중 줄도 같은 sr-only만 둔다.
- 입찰 종료가 아닌 줄의 동작 칸은 빈 `<td class="act"></td>`다. 레인이 주던 읽기 문장은 마감까지 칸의 sr 문장이 이미 같은 정보를 준다.
- ④ 열 폭 재배분(1280px 기준)
  - 기관 열은 `width:auto`(나머지를 받음), 준비 단계 148→132, 동작 칸 140(1440px 이상은 250), 금고 방식·구분·마감까지·은행·설명회는 그대로.
  - 계산(스크롤바 없음/있음): 1280px 기관 열 159/142, 고르기 열 켜면 127/110. 1440px 기관 열 209.
  - 준비 단계 132는 NEXT 120의 두 줄 칸(라벨 한 줄, 막대+n/5+지연 칩 한 줄 약 106px)이 들어가는 폭이다. 120 적용 전 잠깐은 한 줄이라 '지연' 칩이 붙은 줄에서 라벨이 더 잘린다. 120을 바로 이어 적용하면 문제없다.
  - 880px 이하 `.hb-tt min-width`는 856→990(기관 150 + 고정 열 840). 이 폭은 어차피 미지원이다.
  - 동작 칸 폭은 한국어 12px 글자 폭 추정(두 단추 약 100·116px)이라 실측 때 확인이 필요하다.

    const dim = new Date(Date.UTC(y, m, 0)).getUTCDate();
