## 2. 규격·지시와 다른 점 (소스 기준으로 판단한 것 포함)

1. **`rules_ack:true`는 저장 요청에만 싣습니다.** 미리보기에는 싣지 않았습니다. 수칙 체크는 저장 단계에서 하는 것이라 체크 전에 true를 보내면 사실과 다르기 때문입니다. 미리보기에도 싣고 싶으면 `buildForm`의 `if (digest)` 한 줄을 바꾸면 됩니다.
2. **`probe`에 선택 인자 `{isAssignee}`를 더했습니다.** 6-2의 5xx 처리("020 `viewer.is_assignee`")를 위해서입니다.
3. **`ctl.onCount`를 더했습니다.** 저장·삭제 뒤 탭 건수를 갱신하는 콜백이며 `board-material`의 `build()`에서 겁니다. `msg`는 `board.js`에서 `#bd-m-msg`에 쓰는 함수로 넘깁니다.
4. **원본 파일명은 보내지 않습니다.** 서버가 확장자만 보므로 `<칸>.txt`라는 고정 이름으로 append합니다. 화면의 `.txt` 검사는 실제 파일명으로 합니다.
5. **미리보기 후 무효화에 제목·회의일도 포함했습니다.** 서버 digest가 제목을 포함하는지 알 수 없어서, 바꾸면 409가 나는 일을 미리 막았습니다.
6. **새 미리보기를 받으면 수칙 체크를 풉니다.** 가리지 않기로 고른 말은 응답에 없어도 목록에 남겨 풀 수 있게 했습니다.
7. **고치기 저장 뒤 글은 서버 재조회 없이 보낸 글로 바꿉니다.** `rev_no`만 응답 값으로 갱신합니다.
8. **할 일 완료자는 `me().name`과 현재 시각으로 표시합니다.**
9. **문구를 몇 개 더했습니다.** 규격 표에 없는 것들입니다.
   - "고친 내용을 저장했습니다."
   - "공개할 사람을 고르거나 사번을 입력하세요."
   - "공개범위에 추가했습니다."
   - "이미 같은 기한으로 공개되어 있습니다."
   - 사람 목록 실패 안내
10. **일부는 스타일 속성으로 직접 지정했습니다.** CSS 덩어리에 없는 부분입니다. 수칙 목록 `list-style`, 잡음 묶음 `ul` 초기화, 편집기 `grid-column`, 구간 밖 건수 `margin-left`가 해당합니다. CSS에 넣고 싶으면 알려 주세요.
11. **서버 코드와 규격이 어긋난 곳은 없었습니다.** 응답 모양은 `{detail: …}`, 공개범위 GET은 배열, 업로드 오류는 `code/slot/line/kinds`로 확인했습니다.

## 3. `index.html`에 넣을 텍스트

**(a) script 줄**
- 앞 줄: `<script src="js/board-write.js"></script>`
- 뒤 줄: `<script src="js/board-material.js"></script>`
- 그 사이에 `<script src="js/board-minutes.js"></script>`를 넣습니다. 로드 순서는 board-minutes, board-material, board 입니다.

**(b) CSS**
- 앞 줄: `.bd-m-ap-msg { margin:0 0 8px; font-size:12px; color:var(--muted); }`
- 뒤 줄: `.ap-card .ap-review-btn { border-color:var(--accent-color); }`
- 그 사이에 규격 6-7의 CSS 덩어리 전체(`/* ── 이사회 회의록(047) … */`부터 `@media print {…}`까지)를 그대로 넣습니다.
- 한 줄을 더 넣습니다(`:has()` 대체. JS가 선택된 label에 `on` 클래스를 답니다).
  `.mn-src label.on { background:color-mix(in srgb, var(--accent-color) 16%, transparent); color:var(--fg); font-weight:600; }`
- 두 앵커는 e4가 편집 중이라 줄 번호는 믿지 말고 위 문장으로 찾으세요.

## 5. 화면 확인 절차 (index.html 반영 후)

1. 담당 영업팀 계정(예 김영업)으로 이사회 자료를 엽니다.
2. 4번째 탭 '회의록'이 보이는지 봅니다(올릴 수 있으니 보여야 합니다). [회의록 올리기]로 들어가 `.txt` 원문을 고르고 [미리보기]를 누릅니다.
3. 미리보기에서 가림 칩과 '가린 곳' 문장이 보이는지, 수칙에 체크하기 전에는 [저장]이 꺼져 있는지 확인합니다. 파일을 바꾸면 "내용이 바뀌었습니다" 안내가 뜨는지도 봅니다.
4. 저장하면 상세로 들어가고 탭 숫자가 1 늘어야 합니다.
5. 같은 계정으로 '원문 펼치기'와 구간의 '원문 보기'를 눌러 봅니다.
6. 영업팀장 계정에서는 할 일을 체크해 봅니다. 고치기는 영업부장·등록자 계정에서 합니다.
7. 영업부장 계정으로 공개범위(사람 고르기와 사번 입력), 변경 이력, 삭제를 확인합니다.
8. 회의록이 없고 올릴 수 없는 계정에서는 탭이 숨겨져야 합니다.
9. 기능이 꺼진 서버(404)에서도 탭이 숨겨지고 오류가 뜨지 않아야 합니다.
