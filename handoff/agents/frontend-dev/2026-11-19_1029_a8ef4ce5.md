## 2. 원인·요구 요약과 결정
- **현재 상태.** 1단계에서 `:root` 일부만 밝은 값으로 바뀌었다. 아래는 모두 남아 있다.
  - 바탕 `#f4f5f7`, 옛 반경(3~25px 직접 값)
  - 9~11px 글자
  - 버튼 hover 그림자와 떠오름
  - `#626d81`, 옛 다크 muted 빗금
  - `.08em` 자간
- **지도 강조(6절 B): 덮개 층 `g.sel-ring-layer`로 한다. CSS 임시안은 쓰지 않는다.**
  - 근거 1: `.raise()`는 선택 면을 같은 `<g>`의 맨 끝으로 옮긴다. 면, 빗금, 라벨 순서인 전국 지도(render.js 259~323줄)에서는 선택 면 자신의 라벨까지 덮을 수 있다. 시도 지도(region-layer)에서도 이웃 면과 `▲n` 라벨을 덮는다. 이 부분은 코드 읽기로 추정한 것이고 실제 클릭은 재현하지 못했다.
  - 근거 2: 임시안은 포커스 외곽선이 절반 가려지는 문제가 그대로 남는다.
  - 근거 3: 면의 `selected` 클래스는 상태로 그대로 둔다. 그래서 `showOnMap` 중복 판정(render.js:977), `clearSelection`, 기존 테스트(map-detail.test.js:343·358·359)가 안 깨진다. 덮개 경로만 추가하고 `.raise()` 3곳을 뺀다. render.js 약 45줄과 CSS 몇 줄이다.
  - 근거 4: 링에 `vector-effect:non-scaling-stroke`를 더했다(디자인 규격 밖 추가). 전국 지도 줌 ×8에서 링이 40px로 굵어지는 것을 막는다.
- **관심 구(`.region.watched`)는 CSS만으로 한다.** 규격이 허용한 방식이다. 단점은 이웃 면이 외곽선 절반을 가릴 수 있다는 것이다. 1.5px 점선이고 선택·포커스 링이 우선이라 감수한다.
- **지시와 다르게 안 한 것(디자인 확인 요청)**
  1. 시안 A는 사이드 메뉴 바탕을 `--panel2`로 바꾸면서 `.nav-cat:hover`·`.nav-item:hover`(`--panel2`)를 그대로 뒀다. 바탕과 같은 색이라 hover가 안 보인다. 두 hover를 `var(--bg)`(#e9ecf0)로 고치는 패치를 넣었다.
  2. 시안은 `.rank-card:hover`와 `.db-row:hover`의 3px 밀기를 말하지 않았다. "transform 없음" 취지에 맞춰 같이 뺀다(M10). 새 테스트가 hover의 `transform`을 금지하므로 필수 패치다.
  3. 로그인 입력칸은 48/44px 그대로 두고 버튼만 40px로 한다(규격 그대로). 나란한 높이 불일치는 디자인 판단 사항이다.
  4. `#aeb5bf`, `#eef1f5`, `#fafbfc`, `#dfe6f3`, `#052561`은 규격의 리터럴을 그대로 썼다. 새 변수는 만들지 않았다.
- **이관 항목 답**
  - 세종·제주 `tabindex` null은 **의도된 것**이다(render.js:267~269 주석: 경계 없는 지역은 눌러도 동작이 없다). 결함이 아니다.
  - JS 직접 반경 값 "3곳"은 부정확했다. 실제로는 `frontend/js/login-hero.js:245`의 `rx: 8` 한 곳이다(→ `rx: 2`). `prep.js:428`의 `rx="1"`은 자물쇠 아이콘이라 유지한다. app.js와 render.js에는 반경 값이 없다.
  - 테마 창 문구는 M17에서 고친다.

### C. 일괄 스크립트 (반경 ≥3px → `var(--r)`, 9~11px → 12px)

- 저장 위치는 호출자가 정한다(예: 스크래치패드의 `apply-97s2.js`).
- **먼저 `--dry`로 돌려 목록을 본다.**
- 건너뛰는 곳: kbboard `.hb-*` 구간(마커 주석 사이), 글자는 예외 선택자(`.label`, `.lg-gu-label`, `.nav-count`, `#notify-badge`, `.ov-stamp`)다.

```js
// 사용: node apply-97s2.js <절대경로>/frontend/index.html [--dry]
'use strict';
const fs = require('fs');
const file = process.argv[2], dry = process.argv.indexOf('--dry') >= 0;
let src = fs.readFileSync(file, 'utf8');
const sStart = src.indexOf('<style>'), sEnd = src.indexOf('</style>');
const hbA = src.indexOf('국민은행 상태 현황판(kbboard.js) 시작'), hbB = src.indexOf('국민은행 상태 현황판 끝');
if (sStart < 0 || sEnd < 0 || hbA < 0 || hbB <= hbA) throw new Error('마커를 못 찾음');
const KEEP_FONT = [/(^|[\s,>+~])\.label(?![\w-])/, /\.lg-gu-label/, /\.nav-count/, /#notify-badge/, /\.ov-stamp/];
let nR = 0, nF = 0; const logR = [], logF = [], kept = [];
const style = src.slice(sStart, sEnd).replace(/([^{}]+)\{([^{}]*)\}/g, function (m, sel, body, off) {
  const bracePos = sStart + off + sel.length;            // '{' 위치로 구간 판정(앞 주석이 섞인 선택자 때문)
  if (bracePos >= hbA && bracePos < hbB) return m;      // fa 담당 kbboard 묶음
  const selClean = sel.replace(/\/\*[\s\S]*?\*\//g, '').trim().replace(/\s+/g, ' ');
  let nb = body;
  nb = nb.replace(/(border-radius\s*:\s*)([^;}]+)/g, function (mm, p, v) {
    let nv = v.replace(/var\((--r(?:-lg|-sm)?)\s*,\s*[\d.]+px\)/g, 'var($1)')
              .replace(/(^|[\s:])(\d+(?:\.\d+)?)px/g, function (x, pre, n) { return parseFloat(n) >= 3 ? pre + 'var(--r)' : x; });
    if (nv !== v) { nR++; logR.push(selClean.slice(0, 60) + '  ' + v.trim() + ' -> ' + nv.trim()); }
    return p + nv;
  });
  if (KEEP_FONT.some(function (re) { return re.test(selClean); })) {
    if (/font-size\s*:\s*(9|10|11)px|font\s*:[^;}]*?(?<![\d.])(9|10|11)px/.test(body)) kept.push(selClean.slice(0, 60));
  } else {
    nb = nb.replace(/(font(?:-size)?\s*:\s*[^;}]*?)(?<![\d.])(9|10|11)px/g, function (mm, p, n) {
      nF++; logF.push(selClean.slice(0, 60) + '  ' + n + 'px -> 12px'); return p + '12px';
    });
  }
  return nb === body ? m : sel + '{' + nb + '}';
});
src = src.slice(0, sStart) + style + src.slice(sEnd);
console.log('반경 변경 ' + nR + '곳, 글자 변경 ' + nF + '곳');
console.log('--- 글자 예외로 남긴 규칙 ---\n' + kept.join('\n'));
if (process.argv.indexOf('--list') >= 0) console.log(logR.join('\n') + '\n' + logF.join('\n'));
if (!dry) { fs.writeFileSync(file, src, 'utf8'); console.log('저장함'); } else console.log('(--dry: 저장 안 함)');
```

# Design System: 금고은행 입찰 현황 히트맵

> **범위.** `frontend/` 전용(PRODUCT.md와 같다). 저장소의 나머지 산출물은 이 체계의 대상이 아니다.
> 2026-11-19 교체: 다크 크롬 + 파스텔 지도(2026-08-14)를 폐기하고 **밝은 업무 포털**(KRDS 참고)로 확정했다. 사용자가 시안 A(남색 머리 띠)를 골랐다(11-19).

## 개요 — 밝은 업무 포털, 지도가 주인공

작업 영역은 옅은 회색 바탕(`--bg` #e9ecf0) 위의 **흰 패널**과 1px 선이다. 모서리는 한 가지(2px), 그림자와 유리(블러)와 떠오름은 없다. 채도는 두 곳만 가진다: 지도(임박도 5단 섞기)와 상태 색. 상호작용 색은 파랑 하나(`--accent-color` #0b50d0)이고, 지도 위 선택·포커스는 색이 아니라 검정+흰색 두 겹 선이다.

**남색 예외(#052561) 3곳 — 이 셋만, 작업 영역 안에는 쓰지 않는다:** ① 머리 띠(`header`) ② 로그인 상단 띠(`.lg-top`) ③ 로그인 카드 윗선 3px. 머리 띠 위의 글자·단추·로고·포커스 링은 흰색이다(포인트 파랑은 남색에 묻힌다).

## 색

- **중립(이름 동결):** `--bg` #e9ecf0 / `--panel` #fff / `--panel2` #f6f7f9 / `--line` #c3c9d1(행 구분) / `--line-strong` #6d7882(부품 테두리, 흰·회색 바탕에서 3.8~4.5:1) / `--fg` #1e2124 / `--muted` #464c53(바탕 #e9ecf0 위 7.3:1).
- **리터럴 3개(변수 없음):** 패널 외곽 `#aeb5bf`(지도 판·경과 패널·순위 패널·로그인 카드), 패널 머리 `#eef1f5`(`.rank-head`·`.ov-head`), 지도 판 바탕 `#fafbfc`. 남색 위 보조 글자 `#dfe6f3`.
- **상태 5색(크롬):** `--red` #bd2c0f / `--orange` #8a5c00 / `--yellow` #6b6000 / `--blue` #0a65ab / `--gray` #5c6670. 칩은 색 글자 + 1px 같은 색 테두리 + 18% 틴트(채운 면 없음).
- **지도 섞기 6색 + 준비중:** 6개월 안 위주 #e8606b, 1년 안 #f0a6a9, 섞임 #cf9ad8, 1~2년 #7397d8, 2년 넘음 #4f72b8, 날짜 미상 #7c8699, 준비중 #c3cad9(빗금). `render.DEFAULT_THEME`가 정본이고 테마 창에서 바꿀 수 있다. 점수·바닥 규칙·▲n 규칙은 기존과 같다(6개월 안·경과 +2, 6~12개월 +1, 1~2년 −1, 2년 넘음 −2, 평균 → 5단, 1년 안 기관이 있으면 보라 아래로 내려가지 않음, 라벨에 ▲n).
- **포인트색:** `--accent-color`는 활성 메뉴 막대, 포커스 링(작업 영역), 선택 행, 주버튼, 물결 링에 쓴다. 테마 창 '물결·화면 강조색'이 바꾼다. 지도 면의 선택·포커스 외곽선에는 쓰지 않는다.

### 이름 규칙
- **채도 독점:** 크롬은 무채색 + 남색 3곳. 크롬의 상태 색은 글자·1px 테두리·18% 이하 틴트로만, 채운 포화 면은 없다.
- **변수 이름 동결:** `:root`의 `--bg --panel --panel2 --line --line-strong --fg --muted --red --orange --yellow --blue --gray --accent-color --ripple-duration --mono --shadow --r --r-lg --r-sm`은 값만 바꾼다(JS 생성 마크업이 이름으로 참조). `--shadow:none`은 그림자 끄기 스위치로 남는다.
- **경과 도장:** 예정일이 지나 처리 안 된 항목은 중립 잉크 칩(`--fg` 바탕, 11px 모노 700, 시계 글리프 + D+n)이다. 색조가 없어서 임박(`--red` 윤곽 + 삼각 + D-n)과 색·모양·글자로 다르다.

## 글자

한글 시스템 서체만(폐쇄망, 웹폰트 없음): Malgun Gothic / Segoe UI. 숫자·날짜·D-day는 Consolas(`--mono`)로 열을 맞춘다. 단계: 제목 16/700, 절 제목 15/700, 소제목 14/700, 본문 13, 컨트롤·캡션 12. 자간은 제목류 −0.01em뿐, 확장 자간(+0.08em)은 쓰지 않는다. 계층은 굵기·색·간격으로 만든다.

**최소 12px.** 예외는 둘뿐이다: ① SVG 지도 라벨(`.label .sub` 10px, `.label .tri` 11px, 880px 이하 10px — 라벨 충돌 방지 결정) ② 숫자 칩(`.nav-count`, `#notify-badge`, `.ov-stamp` 11px/700 모노). 로그인 표면만 큰 글자 예외(슬라이드 문구 40px·D-day 64px·카드 제목 26px)를 가지며 로그인 미니 지도 라벨 `.lg-gu-label`은 11px이다.

## 배치

전체 화면 고정 flex 열: 머리 띠(남색) → 컨트롤 띠 → 티커 띠 → 활성 화면. 왼쪽 업무 메뉴(248px, `--panel2` 바탕, 활성 항목은 흰 바탕 + 안쪽 3px 포인트 막대 + 700), 위쪽 화면 탭(연 화면 최대 10개; 활성 탭은 흰 바탕 + 위 2px 포인트 막대, 닫기 24×24). 지도 화면은 지도 판(flex 2)과 순위 패널(flex 1)로 나뉜다. 880px 이하에서 구조가 접힌다(숨기지 않는다).

## 높이감·모양

- **그림자·유리·떠오름 없음.** `box-shadow`는 막대·윤곽용(`inset … 0`, `0 0 0 1px`)만 쓰고 블러가 있으면 안 된다. `backdrop-filter`와 hover 이동(`translate`·`scale`)은 쓰지 않는다. 모달 막은 `rgba(19,20,22,.5)` 단색. 움직임은 색 전이 200ms, 화면 첫 진입 한 번(`fadeUp`), 지도의 물결·깜빡임뿐이다(감소 설정이면 모두 끈다).
- **모서리는 `var(--r)` 2px 하나.** `--r-lg`, `--r-sm`도 2px(이름 호환). 직접 px 값을 쓰지 않는다. 원(50%)은 점 두 곳(타임라인 점, 알림 점)만 예외.
- 빗금(45도, 4px 주기)은 '준비중/추정' 질감이다. 마커 모양 규칙(지자체=면, ■ 교육청, ▲ 공공기관, ⬟ 대학, ◆ 법원, ● 병원)은 그대로다.

## 컴포넌트

- **단추:** 흰 바탕, 1px `--line-strong`, 2px, 12px. hover는 `--panel2` + 테두리 `--muted`(이동·그림자 없음). 비활성은 .55 이하. 머리 띠 안에서는 투명 바탕 + 반투명 흰 테두리 + 흰 글자(hover 흰 14% 바탕).
- **채운 주버튼 예외 3곳:** 대화 보내기, 시스템 관리 사용자 등록(`button.primary`), 로그인 제출(`.lg-primary`, 높이 40px, 2px 모서리). 그 밖에 채운 주버튼은 없다.
- **입력:** 흰 바탕, 1px `--line-strong`, 2px, 12px, 포인트 캐럿·`accent-color`. 포커스는 전역 2px 포인트 링.
- **탭·세그먼트:** 각진 2px. 활성은 포인트 16% 틴트 또는 흰 바탕 + 포인트 막대.
- **칩·배지:** 12px(숫자 칩만 11px), 1px 테두리, 2px 모서리, 18% 틴트.
- **카드·패널:** 흰 `--panel`, 1px 선(`--line-strong`/`--line`, 지도류 `#aeb5bf`), 2px, 그림자 없음.
- **로그인 표면:** 앱 크롬이 아니라 문 앞 표면. 남색 상단 띠 + 흰 카드(윗선 3px 남색). 슬라이드 규칙(6초 반복, 이전·다음·점·재생 줄, hover·포커스·탭 숨김·960px 이하 정지, reduced-motion이면 정지)과 `login-slides.js` 출처 규칙은 기존과 같다.
- **아이콘:** 인라인 SVG 획 글리프(12×12 눈금, 1.2~1.4, `currentColor`). 이모지·문자 아이콘 없음(예외: 마커의 `!`, 티커 `·`, 이동 단추 `←`).

## 지도 판 (대표 화면, 두 겹 규칙)

지도 판 바탕 `#fafbfc`, 구 경계 `#6d7882` 1px, 라벨은 짙은 잉크 + 밝은 후광. 면 색은 섞기 6색이다.
