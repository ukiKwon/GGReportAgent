1. 고친 곳은 `frontend/index.html`의 `<style>` 안 규칙 5개입니다. `.hb-*` 구간은 건드리지 않았습니다. 줄 번호는 수정 전 기준입니다.
- `.ad-table th, .ad-table td`(1727)
  - 전: `padding:7px 10px; text-align:left; white-space:nowrap`
  - 후: `padding:7px 10px; text-align:center; vertical-align:middle; white-space:nowrap`
  - 바로 위에 주석 `/* 표 머리·칸 가운데 정렬(사용자 11-26) — 여러 줄 본문 칸·묶음 제목 줄만 왼쪽 */`을 추가했습니다.
- `.ad-ops`(1733)
  - 전: `text-align:right`
  - 후: `text-align:center`
  - flex가 아니라서 `justify-content`는 손대지 않았습니다.
- `.ap-changes th:first-child { text-align:left; }`(1706)
  - 규칙을 삭제했습니다. 바로 위 `.ap-changes th, .ap-changes td { text-align:center }`는 그대로 둡니다.
- `.ad-grid tbody th`(1759)
  - 전: `text-align:left`
  - 후: `text-align:center`
- `.ad-table td.tm-t-reason`(1374)
  - 전: `white-space:normal; word-break:keep-all; overflow-wrap:anywhere; max-width:32em;`
  - 후: 맨 앞에 `text-align:left; vertical-align:top;`을 더했고 나머지 값은 그대로입니다.
  - 위에 주석 `/* 여러 줄 사유는 왼쪽·위 — 표 가운데 정렬 예외(사용자 11-26) */`을 추가했습니다.
  - 이 규칙의 선택자 특이도가 공통 규칙보다 높아서 예외가 이깁니다.

2. 새 시험은 `frontend/test/table-center.test.js`입니다. 주석을 제거한 CSS를 정규식으로 검사하며 4건입니다.
- `.ad-table` 규칙에 `text-align:center`와 `vertical-align:middle`이 있고 left는 없다.
- `.ap-changes th:first-child` 규칙이 없다.
- `.ad-ops`와 `.ad-grid tbody th`가 center다.
- `tm-t-reason`이 left와 top이다.

3. 시험 실행은 main이 합니다. PATH에 `/c/dev/node/node-v22.23.4-win-x64`를 더한 뒤 아래 명령을 실행합니다. 기대 결과는 새 시험 4건 통과, 전체 통과입니다.
`node --test frontend/test/table-center.test.js` 그다음 `node --test "frontend/test/*.test.js"`
기존 시험 중 `.ad-table`의 `text-align:left`나 `.ap-changes th:first-child`를 묶는 곳이 있으면 깨질 수 있습니다. 그런 곳은 검색하지 않았으니 전체 실행 결과로 확인해 주세요.

4. 지시에서 벗어나 판단한 것
- `.ad-perms`(5번)는 고치지 않았습니다. 1729줄 `.ad-perms td, .ad-perms thead th:not(:first-child)`는 이미 center이고 첫 열 left 규칙은 따로 없습니다. 첫 열 머리는 이제 공통 규칙으로 center가 됩니다.
- 6번(`.ap-tc`, `.pp-files`)은 지시대로 확인만 하고 건드리지 않았습니다.
- 9번 확인 결과, `.bd-table`과 `.bd-w-srctbl`은 `.ad-table` 클래스를 쓰지 않아 공통 규칙이 새지 않습니다.
- 다만 `board-material.js:434`의 이사회 자료 목록 표 `bd-l-tbl`은 `ad-table`을 함께 씁니다. 이 표는 index.html 221줄에서 이미 가운데 정렬(사용자 11-20)이라 값은 같습니다. 세로 가운데만 새로 적용됩니다.
- 테스트 파일명은 지시대로 `table-center.test.js`입니다.
