## 2. 원인·요구 요약과 판단 근거
- 현재 정의: `nav.js:92-96`. `scan` 소제목은 기관·입찰 공고 둘뿐이고, 현황판·지도·지역별·사업계획이 모두 '기관' 아래에 있다.
- **함정 1, 소제목이 통째로 사라진다.** `nav.js:251`의 `showSubs`는 "보이는 중분류 2개 이상, 각각 2항목 이상"이어야 켜진다. '대시보드' 소제목에는 입찰 현황판 하나뿐이라, 영업팀 화면에서 소제목이 전부 꺼진다. `scan` 분류에만 `soloSubs: true`를 주고, 한 항목짜리 소제목도 허용하게 한다.
- **함정 2, 순서가 뒤집힌다.** `build`는 중분류 안에서 구현 항목(live)을 준비중 항목(soon)보다 앞에 둔다. '기관 사업계획'(soon)을 '전국 지역별'(live)보다 앞에 두려면 `front: true`를 줘야 한다.
- '공고 자동 수집'은 `soon()` 7번째 인자 `onlyRoles`로 `['전산팀','전산팀장']`을 준다.
  - 기존 관례(제안팀 구성·배정의 `onlyRoles`)대로 마스터는 제외된다(`nav.roleIn`은 마스터면 false).
  - 서버 키 AND 조건(`withKey`)은 걸지 않는다. 지금도 키가 없고, 화면 자체가 '준비중' 안내뿐이다.
  - 결과적으로 영업팀·영업팀장·디자이너에게는 숨겨진다. 지금은 영업 계열 일반 규칙으로 보인다. 의도한 변경이다.
- 메뉴 이름 문구 판단:
  - 메뉴 이름을 가리키는 것은 바꾼다. `portal.js:51`의 `[전국 지도]`, `prep.js`·`prepboard.js`의 '전국 지도 열기', `dashboard.js`의 '전국 지도' 링크·버튼, `dashboard.js:1552`의 부제.
  - 지도 자체를 설명하는 문장은 그대로 둔다. 근거는 화면은 여전히 지도이기 때문이다. 해당하는 것은 `render.js:332`·`972`·`994`·`1140`의 주석, `app.js:745`의 "없으면 전국 지도"(마스터가 여는 화면 설명), `overdue.js:4·145·278`의 지도 다시 그리기 설명이다.
  - `overdue.js:5·213·220·344`와 `app.js:882`의 주석은 사이드바 항목 이름을 가리키므로 바꾼다. 동작 코드는 `id 'map'`과 `NOTICE_ID`로 찾기 때문에 영향이 없다.
- 요구사항 파악 문서(`docs/요구사항 파악/*`, `tools/req-review/*`)는 지난 날짜 파일이라 고치지 않는다. `tools/req-review/template.html`은 다음 캡처 때 메인이 맞추면 된다(이관 메모 참조).

## 4. 서버 판단
- **서버 변경 없음을 권고한다.**
  - 서버 메뉴 키는 `map` 하나이고 이름과 묶인 권한은 없다. 권한은 키로만 정해진다.
  - 프런트 `admin.menuColumns`(`admin.js:257`)와 권한 표(`admin.js:710`)는 이름을 nav 항목 라벨에서 가져온다. 서버 라벨 '전국 지도'는 nav에 없는 키의 예비 이름으로만 쓰인다.
  - `/menus`의 label을 바꾸면 골든 `golden/api/04_menus_default.json:11`·`05_menus_team_lead.json:11`과 라벨을 비교하는 서버 시험이 같이 깨질 수 있다. 얻는 것이 없다.
- 전산팀 전용 노출도 서버에서 맞출 필요가 없다.
  - '공고 자동 수집'은 서버 키도 API도 없는 준비중 안내 화면이다.
  - `Menus.java` 머리 주석대로 메뉴 권한은 화면 노출 제어이지 보안 경계가 아니다.
- 서버를 맞추고 싶다면(권고하지 않음):
  - `Menus.java:38`의 `"전국 지도"`를 `"지역별 공고현황"`으로 바꾼다.
  - 골든 04·05의 label을 같이 바꾼다.
  - 서버 시험을 `mvn -q -o test`로 돌린다.
  - 백엔드 담당 확인이 필요하다.

## 6. 위험·되돌리는 법
- **소제목 규칙 변경**: `soloSubs`는 `scan`에만 켠다. 권한이 적어 항목이 줄어든 계정(예: 둘러보기)도 한 항목짜리 소제목이 보이는 것이 부작용이다. 눈에 거슬리면 `soloSubs`를 지우면 된다. 그러면 소제목이 전부 사라지므로 '대시보드' 소제목을 쓰려면 이 방법이 유일하다.
- **'전국 지도' 문구가 시험 밖에 남아 있을 가능성**: `dashboard.js`·`bankcontract.js`·`noticerec.js`는 '전국 지도' 문자열 grep으로만 확인했다. 줄바꿈된 문장은 놓쳤을 수 있다.
- **열어 둔 탭 이름**: 탭 이름이 항목 라벨에서 오므로 새로 열면 새 이름이다. id는 같아 연결은 끊기지 않는다.
- **'공고 자동 수집'이 영업 계열에게서 사라지는 점**: 지시대로이지만 눈에 띄는 변화다.
- 되돌리기: `nav.js`·시험·문구 파일을 `git checkout`하면 원상태가 된다. 서버를 안 건드려서 DB나 골든과는 무관하다.
