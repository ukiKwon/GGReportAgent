**1. 바꾼 곳**
- 두 파일 안에서 바꾼 위치만 적고, 행 번호는 다시 찾으라고 하셔서 선택자로 적습니다.
- 지시 1) `.pt-tab`의 반경을 `var(--r) var(--r) 0 0`으로 바꿨습니다.
- 지시 2) 옆줄 상자 8개의 반경을 `0 var(--r) var(--r) 0`으로 바꿨습니다. 대상은 `.bd-m-return`, `.bd-m-lock`, `.bd-m-warn`, `.bd-m-decide`, `.mn-mark`, `.mn-rules`, `.mn-stale`, `#legend .lg-card`입니다. 반경 선언은 모두 규칙 안에 직접 있어서, 공통 규칙은 건드리지 않았습니다.
- 지시 2·3) `.bd-editbar`는 `0 var(--r-lg) var(--r-lg) 0`으로 바꿨습니다.
- 지시 3) `.bd-card`와 `.lg-cards li`는 `var(--r-lg)`로 바꿨습니다. `#login-view li`는 실제 선택자가 `.lg-cards li`입니다.
- `.bd-w-card`는 반경 선언이 없고 padding만 덮어씁니다. 그래서 `.bd-card`의 반경을 그대로 물려받습니다.
- 지시 4) `.db-kq-leg .kq-s`에 `border-radius:var(--r-sm)`를 추가했습니다.
- 시험은 `frontend/test/board-write-focus.test.js`의 "CSS 전환" 시험 바로 앞에 새 `test`로 넣었습니다. 위 모든 값을 `rule()`이나 정규식으로 단언합니다.
