**폭 값 근거**
- 가장 긴 글자는 '2027 목표'다. 12px 기준으로 mono 숫자 4자 약 29~31px + 공백 약 3px + 한글 2자 24px = 약 56~58px이다.
- '나의 관심'은 한글 4자 + 공백 = 약 51px이다.
- 여기에 좌우 padding 12px과 border 2px을 더하면 약 70~72px이다. 그래서 min-width:72px로 잡았다.
- border-box라 72px는 테두리까지 포함한 폭이다. 같은 파일의 .pl-wait 폭 72px(자리 맞춤)과도 일치한다.
- text-align:center로 짧은 '나의 관심'(약 51px)을 가운데에 둔다. 두 칩 모두 72px에서 넘치지 않는다.
- mono 폭이 7.8px을 넘는 폰트면 '2027 목표'가 72px를 넘을 수 있다. min-width라 늘어나기만 하고 깨지지는 않는다. 실제 렌더에서 두 칩 폭이 같은지 한 번 확인하는 것을 권한다.

**묶음 머리·토글 판단**
- 묶음 머리 '목표·관심 n곳 (목표 8 · 관심 4)'은 그대로 둔다. 머리 안에서 '목표'·'관심'은 분류 이름을 같은 급으로 나열한 말이라 '나의'를 붙이면 어색하다. 시험 단언(test:759·761·762)도 그대로 유지된다.
- 토글 '목표·관심 먼저'와 요약 줄·일괄 요청 버튼 '목표·관심 n곳 수집 요청'도 그대로 둔다. 같은 분류 이름이고, 바꾸면 단언 5곳 이상이 연쇄로 바뀐다.
- 확인 창 구분 칸은 칩과 같은 말이어야 사용자가 같은 대상으로 인식한다. 그래서 패치 B로 맞췄다.
- 칩 라벨을 함수 하나로 합치는 방안도 있었다. 칩은 mono 마크업이고 구분 칸은 텍스트라 얽히는 부분이 늘어, 이번엔 글자만 바꿨다.
