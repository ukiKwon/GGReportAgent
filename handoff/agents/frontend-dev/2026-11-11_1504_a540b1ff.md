후속 수정 4건을 반영했습니다. 테스트는 실행하지 못했으니 메인이 `node --test "frontend/test/*.test.js"`로 돌려 주세요.

바꾼 파일은 `frontend/js/prep.js`와 `frontend/test/prep.test.js`입니다.

① **헤더 id**
- 서버 `PrepUiIds` 값 구분을 확인했습니다. 화면 id는 `map_popover`, 버튼 id는 `attach_upload`·`attach_download`·`attach_void`·`t3_set`·`t3_clear`·`open_prep`입니다.
- 지도 제안 확정은 `map_popover`+`confirm`으로 보냅니다.
- 첨부 올리기·내려받기·무효, 확정본 지정·해제는 `prep_detail` + 위 버튼 id로 보냅니다. 내려받기 요청에도 헤더를 붙였습니다.
- `open_prep`은 아직 안 보냅니다. [사전준비 열기]는 서버 호출이 없어서입니다.

② **영업팀장 첨부**
- 영업팀장(담당자·영업부장이 아니어도)에게 T3 파일 영역을 그리고 첨부 목록을 요청합니다.
- `attachActions(row, viewer, meEmp, role)`에 `role` 인자를 더했습니다. 무효 처리는 `영업팀장` 또는 (올린 본인이면서 `viewer.is_assignee`)일 때만 보입니다. 확정본 행에는 여전히 안 그립니다.
- 서버 viewer에는 영업팀장 플래그가 없어 로그인 역할로 판단합니다.

③ `NAME_FIX` 임시 치환을 지우고 서버 상태명을 그대로 씁니다. 상태명이 비면 기본 이름으로 대신합니다.

④ 영업팀장 읽기 전용
- 영업팀장이 가끔 못 보는 이유는 서버의 `can_*` 플래그가 꺼져서입니다. 이 경우 과제 체크 버튼은 안 그려지고, 과제 목록 위에 읽기 전용 안내가 한 번 나옵니다.
- 끝 노드 버튼은 꺼진 상태와 이유 문구로 그려집니다.
- 영업팀장은 서버가 `can_cancel`을 true로 주면 [중단…]이 그대로 보입니다.
- 실제 화면은 못 봤습니다.

테스트는 `attachActions`에 영업팀장·비담당 업로더 경우를 더했습니다. `stateBadge` 기대값과 목록 fixture는 서버 상태명 그대로로 바꿨습니다. 새 소스 단언은 허용 id 6개 전송, `map_popover`+`confirm`, `NAME_FIX` 없음입니다.

지난 신청 요약(`past_open_requests`류)은 지시대로 손대지 않았습니다.
