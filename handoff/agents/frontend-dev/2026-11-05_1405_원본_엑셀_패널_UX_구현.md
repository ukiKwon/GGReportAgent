엑셀 원본 패널 개선을 파일에 반영했지만, 테스트는 한 번도 못 돌렸습니다(Bash가 없어서 실행하지 못했습니다). 테스트 기대값은 손으로 계산해 맞춰 두었습니다. 실제 화면(1440×900, 929px, 360px 미만)은 열어 보지 않았습니다.

**고친 파일**
- `frontend/js/board-write.js`
  - 순수 함수는 `bw.sourceHtml` 바로 위(약 873~960행)에 추가했습니다.
    - `mergeSources`: 같은 시트의 표를 격자 하나로 합칩니다. 범위는 합집합, 좌표는 재계산하고 표 태그 범위도 같이 돌려줍니다. 시트가 다르면 시트별 하나입니다.
    - `srcKind`: 문장 칸과 숫자 칸을 가릅니다.
    - `ownsCell`, `srcHasSel`: 원본 칸이 지금 선택된 양식 칸에 해당하는지 판정합니다.
    - `centerAxis`, `centerScroll`: 가운데 스크롤 계산입니다. 이미 완전히 보이면 현재 값을 그대로 돌려줍니다.
    - `alignScroll`: 표 점프 좌표 계산입니다.
    - `stackMode`: 원본 패널이 360px 미만이면 세로 배치로 판정합니다.
    - `gridClass`: 접힘, 넓게, 기본 중 어느 클래스를 쓸지 정합니다.
  - `bw.sourceHtml`은 다시 썼습니다.
    - 패널 머리 `.bd-w-srchead`는 스크롤 영역 밖에 고정합니다. 머리에는 파일명(말줄임, title), [넓게 보기](`aria-pressed`), [원본 접기], 표 점프 버튼, [선택 칸으로](선택이 없으면 disabled)가 있습니다.
    - 스크롤 영역은 `#bd-w-srcbody` 하나이고, `tabindex=0`, `role=region`, `aria-label="엑셀 원본 표, 방향키로 스크롤"`을 줬습니다.
    - 표 점프 버튼의 접근 이름은 "C-2 표 원본으로 이동" 형식입니다. 선택 칸이 속한 표의 버튼에는 `aria-current="true"`를 붙입니다.
    - 표 시작 행의 행번호 th에 표 태그를 넣었습니다.
    - 문장 칸은 `td.is-text`이고 title에 전체 문장이 들어갑니다.
    - 선택 칸이 있는 행의 행번호 th에는 `is-srcrow`를 붙입니다.
  - `freshUi`에 `wide:false`를 추가했고, `writeHtml`은 `bw.gridClass`를 씁니다(1107행 부근).
  - 컨트롤러에 `measureSrc`, `srcMetrics`, `scrollSrcTo`, `jumpSrc`를 추가했습니다(1128행 부근).
    - `measureSrc`는 `--bd-scroll-top`과 `--bd-status-h`를 `#bd-root`에 설정하고, 좁으면 `is-stack` 클래스를 토글합니다.
    - `scrollSrcTo`는 `#bd-w-srcbody` 안에서만 `scrollTop`/`scrollLeft`를 직접 계산해 움직입니다. 페이지 스크롤은 건드리지 않습니다.
    - `jumpSrc`는 표의 시작 칸을 `[data-tstart]`로 찾아 그 행과 열을 고정 머리 바로 아래로 맞춥니다.
  - `applySel`은 `scrollIntoView` 대신 `scrollSrcTo`를 씁니다. 선택이 바뀔 때 `is-src`, 행번호 `is-srcrow`, 점프 버튼 `aria-current`, [선택 칸으로] disabled도 함께 바꿉니다.
  - `draw`는 `#bd-w-srcbody`의 `scrollTop`/`scrollLeft`를 보존하고 `measureSrc`를 호출합니다. `drawStatus`와 resize에서도 `measureSrc`를 호출하고, 페이지 scroll에서는 `requestAnimationFrame`으로 모아 호출합니다.
  - `act`에 `srcwide`, `srcjump`, `srcsel`을 추가했습니다. `srcwide`는 다시 그리지 않고 클래스와 `aria-pressed`만 바꿉니다. 그래야 열 비율 전환 애니메이션이 보입니다.
- `frontend/index.html`의 CSS(약 263~305행)
  - `.bd-w-grid.is-wide`는 2:3입니다. 전환 애니메이션은 `prefers-reduced-motion`에서 없앴습니다.
  - `.bd-w-src`는 flex 세로 구조이고, max-height는 `calc(100vh - var(--bd-scroll-top) - var(--bd-status-h) - 16px)`입니다. `--bd-bar-h`는 기존 값을 그대로 씁니다.
  - 표는 `border-collapse:separate`로 바꿨습니다. 스크롤해도 테두리가 사라지지 않게 하려는 것입니다. thead와 행번호 th는 sticky이고, 교차칸은 `z-index:3`입니다.
  - 숫자 칸은 현행(오른쪽·mono·nowrap)입니다. 문장 칸은 왼쪽 정렬, `max-width:14em`, 말줄임입니다.
  - 매핑 안 된 칸은 `--muted`, `td[data-key]`는 `--fg`입니다. 틸 변수는 기존 `--accent-color`를 썼고, 새 CSS 변수는 추가하지 않았습니다(`--bd-scroll-top`, `--bd-status-h`는 지시하신 이름입니다).
  - 원본 패널이 360px 미만이 되는 좁은 화면과 900px 이하에서는 원본이 세로 배치로, 아래쪽 고정 창(`max-height:40vh`, status 줄 위)이 됩니다.

**지시에서 벗어난 판단**
1. `td`마다 `data-st`는 계속 붙입니다. 매핑 안 된 칸에는 그 칸을 덮는 표의 ref를 넣습니다. `data-key`는 매핑된 칸에만 붙습니다.
2. 합친 격자에서 한 원본 칸을 양식 칸 둘 이상이 가리키는 경우를 위해 `data-own="표|키 표|키"` 속성을 추가했습니다. 소유자가 둘 이상일 때만 붙고, 없으면 선택 칸이 하이라이트되지 않는 문제를 막습니다.
3. 표 점프 버튼 이름은 "(표 이름) 표 원본으로 이동"으로 정했습니다. 지시의 "…"가 무엇인지 몰라서 정한 것입니다.
4. 좁은 화면 세로 배치는 JS(`is-stack`, 패널 너비 360px 미만 판정)와 CSS(900px 이하)를 같이 썼습니다.
5. 같은 시트 안에서 범위가 멀리 떨어진 표도 합집합 격자 하나로 합칩니다. 지시대로 했고, 빈 칸이 많아질 수 있습니다.
6. 표 태그는 표 시작 행의 행번호 th 안에 인라인으로 넣었습니다. 같은 행에서 시작하는 표가 둘이면 행번호 열이 조금 넓어집니다.
7. 문장 칸 글꼴은 `font-family:inherit`(mono 아님)로 했습니다. 지시에 없던 선택입니다.

**위험과 되돌리는 법**
- `grid-template-columns` 전환 애니메이션은 Chrome 계열에서만 확인한 지식에 의존합니다. 지원이 없으면 전환이 즉시 일어날 뿐입니다.
- 패널 높이는 페이지 스크롤 때마다 다시 계산합니다(rAF로 모음). 성능이 문제면 scroll 리스너 한 블록만 빼면 됩니다.
- `border-collapse`를 바꿔서 표 테두리 모양이 조금 달라집니다. design-reviewer 대조가 필요합니다.
- 되돌릴 때는 `git checkout`으로 `board-write.js`와 `index.html`을 원복하고 새 테스트 파일을 지우면 됩니다.
