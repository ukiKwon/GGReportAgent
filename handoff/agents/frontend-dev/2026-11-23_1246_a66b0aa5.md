### 2. 원인

- 단추 폭은 .hb-tag(2036행)가 12px 글자에 패딩 2px 6px 2px 8px와 테두리를 더해 정해진다. 아래는 추정치다.

  - '다음 회차 목표로…' 약 119px
  - 단추 두 개 합 + 단추 사이 간격 6px + 칸 좌우 패딩 8px = 약 245px
- 일정 칸은 고르기 칸(32px)이 생기기 전 약 226px이었으니, 그때도 약 19px 모자랐다. f61fb157로 칸이 약 194px이 되면서 잘림이 눈에 띄게 커졌다.

- 단추 위치는 12개월 막대가 없는 입찰 종료 줄 전용이다(closedActsHtml).

### 4. 구현안
frontend/index.html에서 한 가지 일만 하는 패치다.

패치 1: 2216행의 .hb-acts 규칙을 바꾼다.
```
old:
  .hb-tt td.ln .hb-acts { position:absolute; inset:0; display:flex; align-items:center; justify-content:flex-end; gap:6px; padding:0 8px; }
new:
  .hb-tt td.ln .hb-acts { position:absolute; top:0; bottom:0; right:0; display:flex; align-items:center; justify-content:flex-end; gap:4px; padding:0 6px 0 0; white-space:nowrap; }   /* 입찰 종료 줄 단추 둘(약 233px)이 일정 칸(1280px에서 약 194px)보다 넓어, 비어 있는 왼쪽 설명회 칸까지 넘쳐 나가게(실사용 버그 11-23) */
  .hb-tt td.ln:has(.hb-acts) { overflow:visible; }
  .hb-tt tr:has(.hb-acts) > td.mut > [aria-hidden="true"] { visibility:hidden; }   /* 단추가 덮는 설명회 칸의 '—'는 숨긴다(sr-only 문장은 그대로) */
```
- 두 단추 모두 투명 바탕이라 아래 칸 색(hover·지연·고른 줄)이 그대로 보인다. 숨긴 '—' 외에는 겹칠 내용이 없다.
- :has()는 이미 쓰는 color-mix와 같은 세대의 브라우저에서 동작한다. 폐쇄망 사무실 PC의 Chrome 버전은 모른다. 확인이 필요하다(아래 열린 질문).
- 줄이 '고름 + 입찰 종료'일 때 고르기 칸과는 위치가 멀어 겹치지 않는다.

패치 2(선택, 실측에서 12개월 칸이 180px 미만일 때만): 디자인 규격의 단계 칸 대비책이다.
```
old:
  .hb-tt col.c-bank { width:124px; } .hb-tt col.c-stg { width:148px; } .hb-tt col.c-brf { width:56px; }
new:
  .hb-tt col.c-bank { width:124px; } .hb-tt col.c-stg { width:148px; } .hb-tt col.c-brf { width:56px; }
  .hb-tt.sel col.c-stg { width:132px; }   /* 고르기 칸이 앞에 서면 12개월 칸이 약 194px로 줄어, 단계 칸에서 16px를 돌려받는다(design 11-23 P2-1) */
```
- 지금 추정은 194px로 180px 이상이라 필요 없을 가능성이 크다. 단계 칸 라벨이 말줄임될 수 있어 실측 후에만 적용한다.
