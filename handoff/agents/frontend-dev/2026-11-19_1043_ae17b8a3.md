## 2. 원인/요구 요약
- A. `kbboard.js:636`에서 `closed: out ? null : …`로 목표 밖 줄의 입찰 종료 판정을 끈다. `kbb.closedBasis`(528)는 서버 근거 두 종류(공고 현황, 시작 전 약정)만 쓰므로 그대로 쓸 수 있다.
  - `goalCtx`(1372)에는 snap이 없어서 `snap:`을 더한다.
  - 현황판은 `noticerec` 구독(2201)으로 다시 그려지므로 snap이 늦게 와도 줄이 갱신된다.
- B. `goalTableHtml` caption(926~933)은 `rows.length + out.length`를 '목표 기관'으로 센다. 거르기 전 `nGoal`·`nOut`을 `renderGoals`(1479)에서 넘긴다.
- C. `stagesHtml`(744)은 목표 밖 줄을 세면서도 그 사실을 말하지 않는다.
- D. `openPop`(2055)은 `#hb-root`에만 inert를 건다.
- E. `index.html` 1808~1811의 `.off`·`.unk`에는 바탕이 없어서 월 세로선이 글자를 가로지른다.
- F. `renderOurs` 1301의 canAdd에 '다음도 국민은행'과 올해 입찰 종료 조건이 없다.

테스트를 가능하게 하려고 순수 함수 세 개를 새로 둔다: `kbb.popCanAdd`, `kbb.inertBehind`, `kbb.inertRelease`. 현재 테스트에는 DOM 하네스가 없다.

  // 이미 inert인 요소(다른 화면이 건 것)는 건너뛰고, 건 것만 돌려준다. 풀 때는 그 목록만 푼다.
  kbb.inertBehind = function (node, stop) {
    const done = [];
    while (node && node !== stop && node.parentNode) {
      const par = node.parentNode;
      Array.prototype.slice.call(par.children || []).forEach(function (s) {
        if (s === node || (s.hasAttribute && s.hasAttribute('inert'))) return;
        s.setAttribute('inert', ''); done.push(s);
      });
      node = par;
    }
    return done;
  };
  kbb.inertRelease = function (list) { (list || []).forEach(function (s) { if (s && s.removeAttribute) s.removeAttribute('inert'); }); };

## 5. 위험·되돌리는 법
- **단계 줄 높이(C)**: `.hb-stgs .why { grid-column:2 / -1 }`는 5개 버튼 아래 둘째 줄로 내려간다. `.hb-stgs`는 높이가 36px에서 약 50px이 되고, 버튼이 위 테두리에 붙는다. 이 사실은 읽는 것만으로는 확정할 수 없다.
  - 1280·1100·880 폭에서 `.hb-tp`(`calc(100vh - 296px)`) 높이가 맞는지 실측해야 한다.
  - 어긋나면 `.hb-stgs`에 `padding-block` 보정이나 `.hb-tp` 계산을 14px 줄이는 CSS 패치가 따로 필요하다. 이는 디자인 판정 사항이다.
- **`--rowbg` 선언 3개**: `:root` 변수 이름 동결 규칙에는 걸리지 않는다. 표 칸에 붙는 지역 변수이고 새 색도 없다. 다만 기존 "새 변수 0개" 단언 2곳을 '`--rowbg` 3개만 허용'으로 바꾼다. 디자인과 호출자가 이 예외를 승인해야 한다.
- **closedIdsNow의 범위(F)**: `closedIdsNow()`(1730)는 `snap.byId`의 키만 돈다. `gs.sum`에만 시작 전 약정이 있고 snap에 없는 기관은 숨김에서 빠진다. 같은 기관이 추가 창(`computeWarn`)에서는 막힌다.
  - 필요하면 1732줄 `Object.keys(snap.byId)` 뒤에 `Object.keys(gs.sum || {}).forEach(…)`로 같은 판정을 한 번 더 돌리면 된다. 규격 밖이라 이번 패치에는 넣지 않았다.
- **목표 밖 입찰 종료 줄**: 구분 칸에는 여전히 [목표에 넣기]가 있다. 규격에 없다. 눌러도 추가 창이 'progress' 문구로 안내한다.
- **inert**: `app.js`의 `setBehindInert`가 이미 header·shell을 inert로 건 상태에서 이 팝업이 열리면 건너뛰므로, 닫을 때 `app.js`가 건 것은 그대로 남는다. 반대로 `app.js`가 팝업이 열린 중에 inert를 걸고 풀면 형제 inert가 섞일 수 있다. 현재 그런 경로는 보지 못했다. 실제 DOM 재측정(nav·header inert=true, 닫은 뒤 모두 false)이 필요하다.
- **되돌리기**: 패치 단위로 되돌린다. A는 `closed: out ? null : …`로 복원, D는 `$('hb-root')` 두 줄 복원, E는 CSS 4줄을 빼고 1809~1811을 원래대로 돌리면 된다. 새 테스트 파일은 삭제하면 된다.
