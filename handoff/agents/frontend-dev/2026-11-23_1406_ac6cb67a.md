## 지시와 다르게 판단한 것
- **P3-4 조건 변수**: 지시는 `def.tag==='REGAIN'`이었습니다. `pickRec` 안에는 `def`가 없어서 `m.tag === 'REGAIN'`을 썼습니다. `pickInst(m, rc, '')`가 `m.tag`에 `def.tag`를 넣으므로 의미는 같습니다.
- **hover 시험**: 정규식으로 CSS 문자열만 확인합니다. 실제 hover 렌더는 확인하지 못했습니다.
- **추천 근거 중복 시험**: 소스 문자열 단언뿐입니다. 동작 시험이 아닙니다.
- **tagList 대체 목록 시험**: 클로저 안 함수라 소스 문자열로 확인합니다.
