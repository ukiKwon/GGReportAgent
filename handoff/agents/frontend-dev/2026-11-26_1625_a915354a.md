## 2. 원인과 근거
**열 폭**: 1280 화면의 표 폭 W는 약 627입니다(12% = 75px에서 역산). 좌우 여백 8px을 뺀 값이 내용 폭입니다.

|---|---|---|---|
| 이름 | 28 → 29% | 173.8 | 가변 |
| 단계 | 13 → 11% | 61 | '공고 중' 칩 약 53 |
| 공고(예정)일 | 16 → 14% | 79.8 | '2026-06 추정' 약 76, YYYY-MM-DD 66, 머리 약 78 |

| 현 금고 은행 | 12 → 18% | 104.9 | 98.5(실측), 머리 약 78 |

- **16%로는 부족합니다.** 내용 폭이 92px이라 98.5px이 여전히 잘립니다. 최소 17%인데 여유가 0이라 18%로 정했습니다.
- 은행이 3곳 이상이면 `' 외 N'`이 붙어(`portal.js` `bankText`, 81줄) 약 125px이 됩니다. 이 경우만 은행 칸을 두 줄로 허용합니다.
- **긴 이름 처리**
  - 칩이 없으면 이름을 최대 두 줄(18px × 2 = 36)로 보입니다.
  - 칩이 있고 한 줄에 안 들어가면 칩만 아랫줄로 내립니다(이름 24 + 칩 16 = 40).
  - 이름 혼자서도 칸보다 길고 칩까지 있으면 이름은 말줄임입니다.
  - 모든 경우 행 40px이 유지됩니다.
- **`.pt-dd-est`**: CSS 문법과 우선순위에 문제가 없습니다. `index.html` 2621줄 `font:400 12px var(--mono)`를 덮는 규칙이 없고, `portal.js` 468줄 마크업도 맞습니다. 고치지 않습니다.
  - Consolas에는 한글이 없어 '약'은 Malgun Gothic으로 보이고 `D-17`만 Consolas입니다.
  - qa(`2026-11-26_1354_aa95a56e.md`)의 "Malgun Gothic"은 `td`를 쟀거나 옛 화면을 본 것일 수 있습니다. 확인하지 못한 추정입니다.
  - 재확인은 `getComputedStyle(document.querySelector('.pt-dd-est')).fontFamily`가 Consolas로 시작하는지 보면 됩니다. 추정 줄이 화면에 있어야 합니다.
