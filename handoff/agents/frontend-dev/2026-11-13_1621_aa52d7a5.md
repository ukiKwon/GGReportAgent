### 패치 B. 팝업 제목과 빈 후보 절 (`headcard.js`)
B-1. `hc.candCount` 아래에 제목 함수를 추가한다.
```
old:
  hc.candCount = function (d) { return ((d && d.candidates) || []).length + ((d && d.candidate_heads) || []).length; };
new:
  hc.candCount = function (d) { return ((d && d.candidates) || []).length + ((d && d.candidate_heads) || []).length; };
  // 편집 팝업 제목: 확정된 기관장이 없으면 '기관장 추가', 있으면 '기관장 정보 편집'(ok↔none 전환 때 repaintModal이 다시 쓴다)
  hc.modalTitle = function (view) { return hc.isEmptyHead(view && view.data) ? '기관장 추가' : '기관장 정보 편집'; };
```
B-2. `modalHtml`의 제목을 바꾼다.
```
old: '<h3 id="hc-m-title" tabindex="-1">기관장 정보 편집</h3>' +
new: '<h3 id="hc-m-title" tabindex="-1">' + esc(hc.modalTitle(view)) + '</h3>' +
```
B-3. `modalListsHtml`에서 none이고 후보가 0건이면 후보 절을 그리지 않는다(양식이 맨 위로 올라온다).
```
old:

    out += '<section class="hc-m-sec" aria-labelledby="hc-s1">
new:
    const cands = d.candidates || [], heads = d.candidate_heads || [];
    if (!cands.length && !heads.length && hc.isEmptyHead(d)) return '';   // 기관장도 후보도 없으면 '0건' 절을 숨겨 양식이 맨 위에 온다
    out += '<section class="hc-m-sec" aria-labelledby="hc-s1">
```
- 두 번째 `old` 줄은 631행 `out += '<section class="hc-m-sec" aria-labelledby="hc-s1">…` 줄의 앞부분이다. 편집 도구에서는 `const cands = d.candidates || [], heads = d.candidate_heads || [];` 한 줄을 old로 잡고 아래에 한 줄을 끼우면 된다.
- ok 상태(기관장이 있음)에서는 후보가 0건이어도 기존처럼 절이 남는다.

B-3의 연쇄 영향: 후보 0건·none일 때 `#hc-m-lists`가 빈 div가 된다. 이 경우 확정 항목·사진 절은 원래 `h && !isEmptyHead` 조건 때문에 안 그려졌으므로 추가로 사라지는 것은 없다.

B-4. `repaintModal`이 전환 때 제목을 함께 바꾼다.
```
old:
    const l = q('#hc-m-lists');
    if (l) l.innerHTML = hc.modalListsHtml(V, M, envNow());
new:
    const l = q('#hc-m-lists');
    if (l) l.innerHTML = hc.modalListsHtml(V, M, envNow());
    if (switched) { const t = q('#hc-m-title'); if (t) t.textContent = hc.modalTitle(V); }
```
- `textContent`만 바꾸므로 `tabindex`와 포커스에는 영향이 없다.
- 제목은 전환 때만 바꾼다. 후보 확정·기각 등 같은 상태의 재그림에서는 제목이 그대로다.
- none 상태에서 후보를 모두 처리해 0건이 돼도 `repaintModal`이 `l.innerHTML`을 다시 계산하므로 절이 사라진다.

## 5. 위험·되돌리는 법
- 위험은 낮다. 문구와 모달 제목 표시뿐이고 요청 본문·버튼 ID·서버 메시지는 그대로다. 줄끝과 `esc`도 유지했고 새 문자열은 모두 상수다.
- B-3 때문에 none·후보 0건 모달에서는 `#hc-m-lists`가 빈 div가 된다. 스크린리더용 `aria-labelledby="hc-s1"` 참조도 함께 사라지므로 깨진 참조가 없다.
- 되돌리는 법: 패치 A는 문구 4곳, B는 3곳(함수·`modalHtml`·`modalListsHtml`)과 `repaintModal` 한 줄이라 개별로 되돌릴 수 있다. `git checkout`으로 두 파일을 되돌려도 된다.
- CSS 변경은 없다. 제목과 양식 순서는 DOM 순서 그대로다(`#hc-m-lists`가 비면 양식이 맨 위로 온다).

- `hc.TEXT.none`의 "아직 등록되지 않았습니다"도 "아직 추가되지 않았습니다"로 맞출까요? 맞추면 206행 단언도 같이 바꿔야 한다. 이번 패치는 지시 문구("…등록하세요")만 바꿨다. 상태 서술이라 '등록'을 유지하는 편이 자연스럽다는 것이 내 의견이다.
