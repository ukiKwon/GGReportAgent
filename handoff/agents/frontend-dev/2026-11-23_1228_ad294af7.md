1. 고친 곳
- `frontend/js/prep.js` 932행 아래에 모듈 변수 `let reqSeq = 0;`을 새로 두었다. `seq`와 `listSeq`가 이 카운터 하나를 같이 쓴다.
- 1006행 근처: `S.seq += 1`을 `S.seq = ++reqSeq`로 바꿨다.
- 1074행 근처: `++S.listSeq`를 `S.listSeq = ++reqSeq`로 바꿨다.
- 1143행 근처: `++S.seq`를 `S.seq = ++reqSeq`로 바꿨다.
- `S.seq`와 `S.listSeq`를 쓰는 곳은 grep으로 모두 확인했고 위 세 곳이 전부다. `token !== S.seq`와 `token !== S.listSeq` 비교는 그대로 두었다.
- `freshState()`의 `seq: 0, listSeq: 0` 초기값도 그대로 두었다. 계정 전환 직후 아직 요청이 없을 때만 0이고, 이후 토큰은 항상 `reqSeq`에서 나오므로 옛 응답과 겹치지 않는다.
- `frontend/test/prep.test.js`에 소스 문자열 확인 시험 1건을 추가했다("요청 번호: 모듈 카운터 reqSeq…"). `reqSeq` 선언, 토큰 세 곳의 형태, 예전 `++S.seq`·`S.seq += 1`이 없음을 확인한다. `mount()` 안쪽이라 동작 시험은 구조상 어려워 소스 문자열로 했다.
