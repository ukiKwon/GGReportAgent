  - 두 화면 숫자가 어긋나지 않게 포털 ①도 같은 계산(`dash.model`)을 씁니다.
  - `/notice-rounds/current`(noticerec.snap)는 두 곳에만 씁니다: 공고 경과 판정 대기 계산, '입찰 끝남' 판정.
  - 지시하신 뜻이 "notice-rounds의 값으로 마감을 세라"였다면 알려 주세요. 그 응답에 마감일 칸이 있는지 확인이 필요합니다.
- **②·④는 039에 institutions.js·행안부 값을 보완합니다.** 호출자 메시지의 data-auditor 발견: 039 시드는 0건이고 institutions.js에는 약정 종료일이 없습니다. 그래서 보완 없이는 두 칸이 거의 0이 됩니다.
  - 종료일은 `kbb.contractEnd`를 그대로 씁니다. 우선순위는 039 직접 입력 > lofin-2026 > nonmuni contractExpiry 입니다. 한 기관이 두 숫자로 갈리지 않습니다.
  - 현황판 '협약 종료 1년 안' 묶음과 같은 규칙입니다. 다른 은행 줄에도 같은 순서를 적용합니다.
- **039의 `lines_now`에는 시작 전 약정 줄도 들어 있습니다.** `closedBasis`가 `term_from > today` 줄을 '약정 확정'으로 봅니다.
  - 포털은 현재 줄(`term_from ≤ 오늘`)과 시작 전 줄(`term_from > 오늘`)을 나눕니다. 시작 전 줄의 은행이 곧 '다음 금고 은행'입니다.
  - 현재 줄만으로 국민은행 여부·종료일을 판정합니다. 시작 전 줄의 `term_to`로 종료일이 오염되지 않게 하려는 것입니다.
- **확정 규칙은 `P.groupOf` 한 함수와 `P.CFG`로 분리했습니다.**
  - 공동 금고는 국민은행이 어느 한쪽이라도 맡으면 ②, 아니면 ④입니다. 두 칸에 중복으로 세지 않습니다.
  - 종료일이 이미 지난 기관은 숫자에서 빼고 `buckets.past`로 보냅니다. 대기 패널 '공고 경과 판정'에 합쳐 셉니다.
  - 숫자 칸은 모든 기관 유형을 포함합니다. 유형 탭은 표만 거릅니다.
- **KB_NEXT 기관은 ④에 셉니다.** 지금 금고가 다른 은행이고 2027년부터 국민은행인 곳입니다.
  - 사용자 확정 "다음 은행이 정해진 곳도 숫자에서 빼지 않는다"를 적용했습니다. 현황판은 '협약 예정'으로 따로 빼지만 포털은 세고 태그를 붙입니다.

test('③ approvalKpi: 결재자는 처리할 건수(받은 결재 can_decide + 작업물), 결재 권한 없으면 내가 올려 대기(PENDING)', function () {
  const inbox = ok({ items: [{ can_decide: true }, { can_decide: false }, { can_decide: true }] });
  const mine = ok({ items: [{ status: 'PENDING' }, { status: 'APPROVED' }, { status: 'PENDING' }, { status: 'PENDING' }] });
  assert.deepStrictEqual(portal.approvalKpi({ perms: ok({ can_approve: true }), inbox: inbox, mine: mine }, '영업팀'),
    { mode: 'decide', n: 2, status: 'ok', partial: false });
  assert.deepStrictEqual(portal.approvalKpi({ perms: ok({ can_approve: true }), inbox: inbox, mine: mine, appr: ok({ items: [{}, {}, {}] }) }, '영업팀장'),
    { mode: 'decide', n: 5, status: 'ok', partial: false });                                           // 팀장은 /approvals 합산
  assert.deepStrictEqual(portal.approvalKpi({ perms: ok({ rank_can_approve: false, can_approve: false }), inbox: inbox, mine: mine }, '디자이너'),
    { mode: 'mine', n: 3, status: 'ok', partial: false });
  // 영업팀(팀장·부장 아님)은 /approvals 결과를 합치지 않는다
  assert.strictEqual(portal.approvalKpi({ perms: ok({ can_approve: true }), inbox: inbox, appr: ok({ items: [{}, {}] }) }, '영업팀').n, 2);
  assert.deepStrictEqual(portal.sourcesFor('영업팀'), ['bank', 'perms', 'inbox', 'mine', 'assign']);
  assert.ok(portal.sourcesFor('영업부장').indexOf('appr') >= 0 && portal.sourcesFor('디자이너').indexOf('appr') < 0);
});

function cssBlock() {
  const h = src('index.html');
  const a = h.indexOf('첫 화면(portal.js) 시작'), b = h.indexOf('첫 화면 끝');
  assert.ok(a > 0 && b > a);
  return h.slice(a, b).replace(/\/\*[\s\S]*?\*\//g, '');
}

### 8080에서 확인할 점 (호출자 실측)
서버를 쓰므로 한 세션만, 열람만 합니다. 사번 로그인이 필요합니다.
