### 1. 고친 파일·부분
- `frontend/js/board.js`
  - 약 106행: `board.unitText(u)` 순수 함수를 추가했다. 맨 `'억원'`이나 `'단위: 억원'`은 `'(단위: 억원)'`으로 보정한다. `(` 또는 `（`로 시작하면 그대로 쓰고, 비면 `''`을 돌려준다.
  - `tableHtml` caption: `'(단위: ' + unit + ')'`로 한 번 더 감싸던 것을 `esc(board.unitText(tb.unit))`로 바꿨다. 서버 값 `"(단위: 억원)"`이 한 번만 찍힌다.
  - `labelIn`(약 650~700행):
    - 행 머리는 그 행의 구분(header) 칸 전부를 바깥→안쪽 순서로 `' › '`로 잇는다. 같은 칸(rowspan·colspan 병합)과 같은 글자는 한 번만 넣는다. 구분 칸이 없으면 기존처럼 그 행 첫 칸을 쓴다. 열 머리는 그대로 뒤에 붙는다. 예: `표 · 비용 › 영업점 › 자동화기기 운영(j) · 사업초기`.
    - 머리글 행(r=0)이 아닌 행의 구분 칸 입력은 `<표 제목> · <바깥 › … › 자기 글자> 구분 이름`이 된다. 예: `표 · 비용 › 영업점 › 인건비 구분 이름`.
    - `cellLabels`는 `labelIn`을 쓰므로 편집 중 aria-label 재동기화도 같은 규칙을 따른다.
- `frontend/js/board-write.js` 약 322행: `buildState`가 `parts`의 각 부품 칸도 `t.srcIndex`에 같은 양식 칸 key로 등록한다.
  - 다른 시트의 부품은 건너뛴다.
  - 이미 다른 칸이 차지한 자리는 덮지 않는다.
  - 대표 `source`가 없고 `parts`만 있어도 등록한다.
  - `owners`와 `data-own` 강조는 기존 로직을 그대로 쓴다.
- `frontend/index.html` CSS: 기존 변수만 썼다.
  - `.bd-table th .bd-cell-in { min-width:12em }` — 구분 입력란이 잘리지 않게 했다.
  - `.bd-w-tables .bd-table { min-width:520px }` — 넓게 보기에서 왼쪽 표가 눌리지 않게 했다. 감싸는 `.bd-table-wrap`의 `overflow-x:auto`로 가로 스크롤이 생긴다.
  - `.bd-w-tables .bd-table th/td { word-break:keep-all }` — 한글 단어 단위로 줄바꿈한다.
- `frontend/test/board-write-parts.test.js`
  - 227행대 단위 테스트를 실제 서버 값 `"(단위: 억원)"` 기준으로 바꿨다. `(단위:`가 한 번만 나오는지, 맨 값·`'단위: '` 접두 값·null 보정을 확인한다.
  - `parts` 부품 칸의 `srcIndex`·`owners` 등록 테스트를 추가했다.
- `frontend/test/board-edit.test.js`: 새 테스트 `cellLabel: 다단 구분(C-5 모양)…`을 추가했다. 규칙이 바뀌어도 기존 테스트의 기대값은 그대로 유지돼서(손으로 따라가 확인) 기존 테스트는 고치지 않았다.

### 3. 지시에서 벗어난 판단
- 구분 입력란 aria-label에 표 제목을 앞에 붙였다(`표 · … 구분 이름`). 표마다 유일하게 하기 위해서이며, 지시 예시(`수익 › …`)에는 제목이 없다. 필요하면 제목 접두를 빼면 된다.
- 머리글 행(r=0)의 구분 칸 입력은 기존 라벨(표 제목만)을 유지했다. 경로를 붙이면 `구분 › 2025년`처럼 어색해서다.
- `parts`의 부품 칸이 대표 칸과 같은 자리를 다른 key가 차지하면 덮지 않는다. `srcIndex`가 위치당 key 하나인 기존 구조를 유지했다.
- 최소 폭 520px(리터럴)과 12em은 새 변수 없이 쓴 값이다.

### 4. 이관 메모
- 이관 없음. 서버·`unit` 형식은 건드리지 않았다.
- 화면(CSS·문구)이 바뀌었으므로 커밋 전에 design-reviewer 규격 대조와 playwright 시각 확인을 권한다. 대상은 넓게 보기 421px 문제와 구분 입력란 131px 문제다.
