## 3. 지시와 다르게 판단한 것
- `#bd-src-note`는 요소를 재사용하지 않고 "빈 요소 → 30ms 뒤 텍스트 채움" 방식으로 구현했습니다. `popHtml`이 팝업 전체를 `innerHTML`로 다시 그려서, 요소를 그대로 둘 수 없었습니다. `popEditHtml`의 출력 HTML은 그대로라 기존 테스트는 영향이 없습니다.
- `.bd-src-note:empty`의 숨김 방식을 바꿨습니다(위 aria 보조). 지시에 없던 변경입니다.
- 행 트랙의 편집 영역 몫은 규격 §6④ 파일을 직접 읽지 않고 지시문 숫자(40%, 50%)만 따랐습니다.
