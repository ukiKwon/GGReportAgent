# 웹 표 편집·워드 붙여넣기 가능성 (frontend-dev, 2026-10-30)

> frontend/ 전체를 contenteditable·execCommand·clipboard·colspan/rowspan 키워드로 검색한 결과. 실제 화면은 열지 않았고, (2)(3)은 알려진 플랫폼 동작 지식이다(Win10 LTSC 2019 실물 미확인).

## 1. 현황
표 편집기·contenteditable·그리드 입력·클립보드 코드 **모두 없음**. 읽기 전용 표만 있음(`admin.js:313-314` `ad-grid`는 정적 마크업이라 재사용 불가). 이사회 자료는 `nav.js:27-28` 구현 예정 항목뿐(테스트 `nav.test.js:91-97`).

| 사용자 정의 양식 | 최소안 | 병합 지원안 |
|---|---|---|
| 기능 | 행·열 수, 셀 텍스트, 헤더 행, 고정 라벨 잠금, 행·열 추가·삭제 | + 셀 선택, 병합·분할, 좌표 재계산 |
| 규모 | 약 300~400줄 | 500~700줄 이상 |
| 위험 | 낮음(`esc()`) | 중간 이상(병합 좌표 버그) |
→ 결정: 이번에는 만들지 않고 양식 사본은 POI 코드 생성(backend 보고서 참조). 웹 표 편집기는 병합 패턴이 확인된 뒤 필요 시 최소안부터.

## 2. 웹 표 → 워드 붙여넣기
| 방법 | 평가 |
|---|---|
| A. 선택+`execCommand('copy')` | 폐쇄망 http에서도 동작, deprecated지만 아직 동작 |
| B. `copy` 이벤트에서 `clipboardData.setData('text/html'/'text/plain')` | 서식 제어 정확, A로 트리거(권장 조합) |
| C. `navigator.clipboard.write` | https/localhost에서만 존재 → `http://서버IP`에서는 `undefined`. 단독 사용 불가, 있을 때만 점진 개선 |

한계: 워드는 CSS를 일부만 이해 → 인라인 style/속성으로(CSS 변수 `var()`는 실제 색상값으로 풀어서). 워드패드는 HTML 표 붙여넣기가 깨질 수 있음(불확실). 엑셀로 붙이면 병합은 유지, 셀 서식은 달라질 수 있음. 직렬화는 `logic.js` 순수 함수로 두면 테스트 쉬움, 모든 셀 텍스트 `esc()`.

## 3. 워드패드 .docx
.docx 저장은 지원한다고 알려져 있으나 **표를 만들거나 편집하는 UI가 없음**(사용자가 확인: 표 못 만듦). Win11 24H2 이후 워드패드 제거 대상. → 표 포함 양식 사본을 워드패드로 만드는 흐름은 성립하지 않음.

## 4. 이관 메모
- [기획] 대상 PC에 MS 워드가 있는지, 병합이 필요한 양식 사례
- [백엔드] 사용자 정의 양식을 서버 저장할지 로컬(`store.js`)만 쓸지(이번엔 해당 없음)
- [디자인] 편집 UI 규격은 편집기를 만들게 될 때
- [구현 메모] 복사는 B+A 기본, 폐쇄망 http 환경에서 워드 붙여넣기 최소 표본을 먼저 시험
