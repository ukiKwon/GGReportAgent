## 5. 위험·되돌리는 법
- **moveState 시그니처 변경**
  - `moveState(kind, m)`를 `moveState(m)`로 바꿨습니다. 호출처 두 곳(`paintMove`, `submitMove`)과 `kbboard-c54.test.js:334~336` 시험은 이미 위 패치에 넣었습니다.
  - 다른 호출처가 남아 있는지는 grep으로 확인했고, 위 두 곳이 전부입니다.
  - 더 안전하게 하려면 `moveState(kind, m)`를 그대로 두고 `towatch` 판정만 지워도 됩니다. 시험 수정은 줄어듭니다.
- **입구 없는 NEXT**
  - 코드는 `tc.setOp`가 NEXT를 받지 않으므로, `kbboard.js`가 NEXT를 만들 일이 생기면 빈 동작('')이 됩니다. 새 NEXT 입구는 막혀 있습니다.
  - 결재함 옛 카드는 `cardOpName`·`OP_LONG`이 남아 있어 그대로 읽힙니다.
- **프런트 상수 제거와 서버 표**
  - `moveWatch` 상수를 지워도 서버 `TargetUiIds`는 건드리지 않습니다. 서버 쪽 정리는 하지 않습니다.
- **되돌리기**: 패치 전체가 `kbboard.js`, `tchange.js`, 시험 5개 파일이라 `git checkout -- <파일>` 또는 `git revert`로 한 번에 되돌립니다.

## 6. 이관 메모
- `[이관: 개발: 백엔드]` 서버 버튼 ID 표(`TargetUiIds`)와 감사 기록에서 `move_to_watch`가 아직 쓰이는지 확인 — 쓰이지 않으면 서버에서 정리할지 결정 — `kbb.BTN.moveWatch`를 프런트에서 지웠기 때문.
- `[이관: 기획]` 서버 낱말 '제외' 통일(이번 범위 밖) — 기다리는 것 없음. 호출자 지시대로 건드리지 않았다는 기록만 남깁니다.
