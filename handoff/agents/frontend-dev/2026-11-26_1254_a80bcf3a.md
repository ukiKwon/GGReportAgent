B5. 정렬. `P.sortRows = function` 바로 앞에 삽입
```js
  function cmp(a, b) { return a < b ? -1 : (a > b ? 1 : 0); }
  function isDone(r) { return r.stage === 'done'; }
  function isCheck(r) { return r.stage === 'pre' && typeof r.ndays === 'number' && r.ndays < 0; }
  function tie(a, b) { return cmp(a.nsort, b.nsort) || ((a.nest ? 1 : 0) - (b.nest ? 1 : 0)) || cmp(a.ndate, b.ndate) || nameCmp(a, b); }
  // 표 기본 순서: 공고 확인 필요 → 공고(예정)일 순 → 공고 종료(최근 공고 먼저, 날짜 없음 끝).
  P.tableOrder = function (rows) {
    return rows.slice().sort(function (a, b) {
      if (isDone(a) !== isDone(b)) return isDone(a) ? 1 : -1;
      if (isDone(a)) return cmp(b.ndate, a.ndate) || nameCmp(a, b);
      return ((isCheck(a) ? 0 : 1) - (isCheck(b) ? 0 : 1)) || tie(a, b);
    });
  };
  // 30일 패널 순서(태그 줄은 뒤).
```

## 5. 위험·되돌리는 법, 불확실한 점
되돌리기는 위 세 파일의 해당 덩어리를 역패치하면 됩니다. `index.html`에 다른 세션의 미커밋 변경이 있으므로 `git checkout`은 쓰지 마세요.

사양에 없어 제가 정한 것 (확인 필요)
1. **접수 중인 공고에 결과 태그가 있는 경우**(유찰 뒤 재공고 등)는 '공고 중'으로 두고 태그만 보입니다. 태그만으로 내리면 살아 있는 마감이 묻힙니다.
2. **재유치·차기·신규 확정 태그**도 '입찰 끝남'처럼 공고 종료로 내립니다(시안의 마구청 기준). 접수 중 공고만 예외입니다.
3. **공고 종료 줄의 날짜**는 확인된 지난 공고일만 보이고, 없으면 '—'입니다. 확정 예정일이 있어도 태그가 붙으면 날짜가 비어 보입니다.
4. **공고 종료 묶음 순서**는 시안처럼 최근 공고일 먼저입니다. 열 정렬을 하면 묶음 안에도 그 정렬이 적용됩니다.
5. **열 정렬 중 머리 문구**는 '○○ 오름차순, 공고 종료는 맨 아래'입니다. '협약 종료일' 열도 시안대로 정렬 가능하게 했습니다.

알아둘 동작
- **확인 필요 줄이 많을 수 있습니다.** 협약 종료가 약 6개월 안이고 공고 기록이 없는 곳은 모두 맨 위로 옵니다. 그 안에서는 오래 지난 순입니다.
- **사람이 '공고 진행 중'·'지연·재공고 대기'로 기록한 곳**도, 협약 종료일만 있는 줄이면 '공고 전 / 공고 확인 필요'로 보입니다. `IN_PROGRESS`·`DELAYED` 기록은 `bankBuckets` 태그에 반영되지 않기 때문입니다.
- **오른쪽 '공고 경과 판정'의 D+n과 표의 D+n이 다를 수 있습니다.** 표는 '종료일 − 6개월'이고, 대기 줄은 `effectiveBid`(주기 계산 포함) 또는 종료일 기준입니다. 주기 예정일이 이미 지난 곳이 표에서는 '약 D-n'일 수도 있습니다.
- **협약 종료 1년 밖이거나 은행을 모르는 곳**의 지난 예정일은 지금처럼 표에 넣지 않습니다.
- **같은 달 안의 D-n 순서**: 추정은 그 달 1일로 정렬합니다. 같은 달 확정일보다 위에 오면서 D-n은 더 클 수 있습니다.
- **줄 수 변화**: 탭 건수와 '○곳'은 새로 넣은 공고 종료 줄만큼 늡니다. 띠 거르기의 ②④ 결과와 이번 달 마감 결과는 그대로입니다.
- **200줄 상한**을 넘으면 맨 아래의 공고 종료 묶음부터 잘립니다. 묶음 머리의 'N곳'은 자르기 전 수입니다.
- **좁은 열**: 12%인 은행 칸은 긴 이름이나 '외 n'이 말줄임됩니다. 1280px 폭 실측이 필요합니다.
