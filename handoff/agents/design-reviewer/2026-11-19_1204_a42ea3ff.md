## 3. 구현자가 규격 밖으로 정한 4건 — 판정

**(1) `:first-child` → `:first-of-type`/`nth-of-type`: 승인. 규격 쪽 버그를 바로잡은 것입니다.**
- 제 규격 뼈대에서 이미 띠의 첫 자식이 h3.sr-only였으니 `:first-child`는 처음부터 틀린 선택자였습니다.
- h3는 `.sr-only`(position:absolute, 1394줄)라 그리드 칸을 차지하지 않습니다. `nth-of-type(3)`은 셋째 단추를 정확히 고릅니다.

**(2) 기관 유형 탭 줄 36px, 활성 = 흰 바탕 + 아래 2px 포인트 막대: 승인.**
- DESIGN.md 95줄이 탭 활성을 "포인트 16% 틴트 **또는** 흰 바탕 + 포인트 막대"로 허용하므로 계약 안입니다.
- 위쪽 화면 탭(흰 바탕 + 위 2px 막대)과 같은 문법이라 오히려 일관됩니다.
- 남는 것은 높이입니다. 목록 패널의 고정 크롬이 머리 40 + 탭 36 + (거르기 32) + thead 40 + 바닥 32 = 148–180px입니다. 1280×800에서 행이 약 8줄 남습니다(추정). 8080 실측 대상입니다.

**(3) 다음 금고 은행 태그 네 모양: 수정 필요(P2). 사용자 요구 때문에 커밋 전에 고칩니다.**
- 지금 '재유치 확정'은 --fg 테두리 + 700 + **6% 바탕**입니다. 흰 바탕 대비 #f1f1f1 정도라 바탕 차이가 거의 보이지 않습니다.
- '차기 확정'은 --fg 테두리 + 700 + **왼쪽 4px 막대**라서 오히려 이쪽이 더 무겁게 보입니다. 사용자가 강조하라고 한 것은 재유치 확정입니다.
- 왼쪽 굵은 막대는 이 제품에서 '활성 메뉴·선택 행'의 문법(DESIGN 82·121줄)이라 뜻이 겹칩니다.

**(4) 일정 줄 칩 '접수 마감' / 표 단계 칩 '공고 중': 승인. 규격에 적은 그대로입니다.**

## 6. 규격

**① 빈 알림 줄 숨기기**(index.html 포털 구간 끝, `/* 첫 화면(포털) 끝 */` 앞)
```css
#pt-err:empty, #pt-flash:empty { display:none; }
```
- `flash('')`가 `textContent=''`로 비우므로 `:empty`가 맞습니다.
- 낭독기는 role=status 요소가 display:none에서 다시 나타날 때 첫 알림을 놓칠 수 있습니다. 안전하게 하려면 `#pt-flash`를 `.sr-only`처럼 보이지 않게 두지 말고, `:empty`일 때만 `padding:0; border:0`으로 높이를 0으로 만드는 쪽을 권합니다. 이 경우 간격 12px 하나는 남고, 그것은 허용합니다.
```css
#pt-err:empty { display:none; }
#pt-flash:empty { padding:0; border:0; margin-top:-12px; }   /* 간격 하나를 되돌려 띠~본문 12px */
```

**② 표 이름 칸 — 태그가 잘리지 않게, 누르는 높이 24px**
- rowHtml: `<th scope="row"><span class="pt-cell"><button class="pt-nm" …>…</button>{tagChip}</span></th>`
```css
.pt-tt .pt-cell { display:flex; align-items:center; gap:6px; min-width:0; }
.pt-tt .pt-nm { display:block; flex:0 1 auto; min-width:0; min-height:24px; line-height:24px; white-space:nowrap; }   /* 기존 all:unset·overflow·ellipsis 줄 뒤에 */
.pt-chip.tag { flex:none; margin-left:0; }   /* 기존 margin-left:6px 대체 — 간격은 .pt-cell gap */
```
- 칩 안에 낭독용 다음 은행: `재유치 확정<span class="sr-only">, 다음 금고 은행 국민은행</span>`. nextBank가 없으면 생략합니다.
- 일정 줄(`.pt-row`)은 `.t`가 flex:1·min-width:0이라 이미 괜찮습니다. 거기서도 `.pt-chip.tag`에 `flex:none`이 걸리면 됩니다.

**③ 태그 네 모양 — 색 없이 강약 = 재유치 > 신규 > 차기 > 끝남**

| 태그 | 테두리 | 글자 | 바탕 | 글리프 |
|---|---|---|---|---|
| 재유치 확정 kept | 1px --fg | 700 --fg | `color-mix(in srgb, var(--fg) 10%, var(--panel))` | 앞에 체크 9px |
| 신규 확정 won | 1px --fg | 700 --fg | 없음 | 앞에 체크 9px |
| 차기 확정 next | 1px --line-strong | 400 --fg | 없음 | 없음 |
| 입찰 끝남 ended | 없음 | 400 --muted | 없음 | 없음(지금 그대로) |

```css
.pt-chip.tag.kept { border-color:var(--fg); font-weight:700; background:color-mix(in srgb, var(--fg) 10%, var(--panel)); }
.pt-chip.tag.won  { border-color:var(--fg); font-weight:700; }
.pt-chip.tag.next { border-color:var(--line-strong); font-weight:400; }      /* 왼쪽 4px 막대 삭제 */
.pt-chip.tag.ended{ border-color:transparent; color:var(--muted); padding:0 2px; }
.pt-chip.tag .gph { width:9px; height:9px; margin-right:3px; flex:none; }
```
```html
<svg class="gph" viewBox="0 0 10 10" aria-hidden="true" focusable="false"><path d="M1.5 5.3l2.4 2.4L8.6 2.6" fill="none" stroke="currentColor" stroke-width="1.6"/></svg>
```
- 왜 체크인가: 이 화면의 글리프 낱말은 삼각(임박)·시계(경과)입니다. 체크는 '확정'에만 붙어 뜻이 겹치지 않습니다. 반전 칩은 경과 도장과 겹쳐서 쓰지 않습니다. 새 색·새 변수는 0입니다.
- 왜 차기를 약하게 하나: 차기 확정은 '이미 다른 은행으로 정해져 할 일이 없는 곳'이라 뒤로 보내는 정보입니다. 사용자가 강조를 요구한 것은 재유치입니다.

**④ 대기 묶음 권한 없음** — `grp(title, n, st, body, failNote, deniedNote)`. 결재 = `결재함 권한 없음`, 경과 판정 = `기관 정보 열람 권한 없음`, 배정 = `배정 목록 권한 없음`.

## 8. 이관 메모

- **[이관: 개발] 감사 화면 이름**
  - 결정할 것: 서버 허용 목록에 `home_portal`을 넣고 `P.SCREEN`을 바꿀지.
  - 디자인이 기다리는 것: 감사 기록이 '어느 화면에서 눌렀는지'를 사실대로 남기는 것. 지금은 첫 화면에서 [제안 확정]을 눌러도 '입찰 공고 현황'에서 누른 것으로 기록됩니다. 사용자가 "누가·어느 화면·어느 버튼, 잊지마"라고 한 항목이라 **커밋 전 반영을 권합니다**. 최소한 NEXT에 열린 항목으로 남겨야 합니다.
