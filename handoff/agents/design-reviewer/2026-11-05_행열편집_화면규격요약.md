# 이사회 양식 편집 — 행·열 조작 화면 규격 요약 (design-reviewer, 2026-11-05)

사용자 결정: '잠김' 폐지(값 칸은 예시값, 안내 문구로 대체). 행 추가/삭제/삽입 + 열 추가/삭제/삽입 모두 필요(구분 머리가 2열로 쪼개진 템플릿 때문). 새 행·열의 값 칸은 공란. 핵심은 머리 문구.

## 1. 안내 문구 (잠김 대체)
- 편집 막대(#bd-editbar) 바로 아래, 양식 이름 줄 위, **화면에 한 번만**. 기존 .bd-legend 대체.
- 문구: "표 안의 숫자는 예시입니다. 실제 값은 [이 양식으로 작성]에서 엑셀을 올리면 채워집니다." / "여기서는 표 제목, 행·열 이름, 행과 열의 구성을 고칠 수 있습니다. 틸 배경 칸은 작성할 때 엑셀 값이 들어가는 자리입니다."
- .bd-edit-guide { margin:8px 0; padding:8px 12px; font-size:12px; line-height:1.5; color:var(--muted); border:1px solid var(--line); border-radius:8px; background:var(--panel) }, 견본 .bd-swatch 12×12 r4(.bd-mapped 와 같은 배경).
- 매핑 칸: 잠김 배지 삭제, 값 글자만, title '작성할 때 엑셀 값이 들어가는 칸', tabindex·aria-readonly 제거(일반 td). removeConfirmText 의 '엑셀 값이 들어가는 칸 N개가 함께 빠집니다'는 유지.

## 2. 조작 UI — 손잡이 + 펼침(disclosure)
- 행마다 손잡이 1개(행의 **왼쪽** 여백 칸 td.bd-gut, 32px, sticky left:0), 열마다 손잡이 1개(머리 행 **위** 여백 줄 tr.bd-colbar, 높이 32px). 손잡이 수는 펼친 격자(gridOf) 기준(표 B '구분' colspan2 → 열 손잡이 2개).
- 손잡이 .bd-handle: 24×24, 인라인 SVG 세로/가로 점 3개(r1.2, currentColor; 문자 ⋯ 금지), color var(--muted), 호버 background var(--panel2)+border var(--line-strong), [aria-expanded=true] border var(--accent-color)+13% 틸 틴트. 들어올림 없음.
- 메뉴 항목(각 3개): 행 '위에 행 삽입' · '아래에 행 삽입' · '행 삭제' / 열 '왼쪽에 열 삽입' · '오른쪽에 열 삽입' · '열 삭제'. 동사는 엑셀식 삽입/삭제(표는 '빼기' 유지).
- 패턴: aria-expanded + aria-controls, 패널 role="group" aria-label, 안의 일반 <button> 3개. role=menu 금지. 한 번에 하나만 열림. 패널은 .bd-table-wrap 밖(카드 .bd-card-edit position:relative 직속 absolute, 손잡이 아래 4px). 표 가로 스크롤/창 크기 변경 시 닫힘. Esc 는 닫고 손잡이로 포커스, Enter/Space 로 열면 첫 켜진 항목으로 포커스.
- 대상 표시(메뉴 열림/손잡이 포커스·호버): 그 행·열 칸에 box-shadow inset 0 0 0 1px color-mix(accent 55%) (배경 틴트 금지 — 매핑 칸 틸 10%와 구별).

## 3. 동작
- 삽입: 즉시 반영, 확인 줄 없음. 새 행·열의 **머리 칸**은 빈 입력 placeholder '행 이름'/'열 이름', 포커스 즉시 이동. 알림 aria-live=polite "'예비비' 아래에 행을 삽입했습니다. 행 이름을 입력해 주세요."
- 새 값 칸은 **공란**(0 아님), 빈 td 안에 sr-only '빈 칸'. 첫 값 열보다 왼쪽에 넣은 새 열(구분 쪼개기)은 본문 칸도 '행 이름' 입력(th).
- 삭제(엑셀 연결 칸 없는 행·열): 확인 없이 즉시 삭제, 알림 + [되돌리기] 링크 버튼.
- 삭제(엑셀 연결 칸이 있는 행·열): 카드 안 인라인 확인 줄(board.confirmHtml 재사용): "'예비비' 행을 삭제할까요? / 이 행에는 작성할 때 엑셀에서 값이 채워지는 칸이 N개 있습니다. 삭제하면 작성할 때 이 값들이 문서에 들어가지 않습니다. / 저장하기 전에는 실제 양식이 바뀌지 않습니다." 버튼 [행 삭제] [그대로 두기], **첫 포커스 [그대로 두기]**, 닫으면 해당 손잡이로 포커스. 삭제 대기 칸은 빨강 테두리 + 8% 빨강 배경.
- 삭제 후 포커스: 올라온 행(열)의 손잡이, 마지막이면 위 행.
- 보호: 머리 행은 '행 삭제'·'위에 행 삽입' 끔('아래에 행 삽입' 허용). 본문 행 1개면 행 삭제 끔, 열 1개면 열 삭제 끔, 행 이름 열이 1개뿐이면 그 열 삭제 끔. 꺼진 항목은 disabled 대신 aria-disabled="true"(포커스 가능), 이유 문구 2번째 줄 11px muted: '머리 행은 삭제할 수 없습니다.' / '행이 하나뿐이면 삭제할 수 없습니다.' / '열이 하나뿐이면 삭제할 수 없습니다.' / '행 이름 열이 하나뿐이면 삭제할 수 없습니다.'
- 병합: 삽입 위치가 병합 칸 **안쪽**이면 그 칸의 rowspan(열이면 colspan)+1, 경계면 늘리지 않음. 병합 칸이 걸친 행/열 삭제 시 span-1, 병합 칸이 **시작하는** 행/열을 삭제하면 내용은 다음 행/열로 옮겨 span-1. 병합 만들기/풀기는 범위 밖.
- 새 행/열은 카드 배지 '행·열 바뀜'(.bd-badge), 변경 건수는 표마다 1건.
- aria-label: 행 손잡이 "'예비비' 행 편집"(이름 비면 "3번째 행 편집"), 열 손잡이 "'총기대수익' 열 편집"(병합 아래 하위 열은 "'구분' 1/2번째 열 편집"), 머리 입력 "<표 제목> · 2번째 열 이름"/"… · 3번째 행 이름".

## 4. 되돌리기·상태·오류
- 편집 막대 오른쪽 [되돌리기](행·열 조작이 쌓였을 때만 켜짐, aria-label '되돌리기: …' 마지막 동작), 여러 단계(불변 상태 스택), 저장하면 스택 비움, 행·열 조작만 대상(글자 입력은 브라우저 기본). 전역 Ctrl+Z 단축키 금지.
- 알림: 편집 막대 안 <span id="bd-rowcol-msg" aria-live="polite"> 12px muted, 5초 뒤 비움([되돌리기] 링크 있으면 유지). "'예비비' 행 삭제를 되돌렸습니다."
- 검증 오류(고치러 가기 연결): "2번째 표에 이름이 빈 행이 있습니다." / "… 빈 열이 있습니다."
- 최대 크기(서버 limits: 표당 행 40·열 12·칸 300, 양식 칸 800): 삽입 항목 aria-disabled + "표 하나에 행은 최대 40개까지 넣을 수 있습니다." 류.

## 5. 좁은 폭
- 행 손잡이 칸 sticky left:0 background var(--panel) z-index:1. 머리 입력 min-width:6em. 560px 이하 메뉴 패널은 카드 폭 100%(좌우 12px), 버튼 세로, 높이 32px.

## 6. 공통
- 디자인 계약: 10–16px 타입 램프, 틸 단일 강조, 새 CSS 변수 금지, 브라우저 confirm() 금지(인라인 확인 줄).
