## 2. 한 줄 총평
'오류처럼 보이는' 원인은 막대보다 **요약 띠의 0 묶음**이 더 크다. 실측해 보면 막대가 숨겨진 뒤에도 띠에 이런 글이 남는다.
- `재유치·신규 0 ÷ (재유치·신규 0 + 타은행 유치 0)`: 0으로 나누는 식처럼 보이고, 두 줄로 꺾이며 `0)`만 따로 떨어진다.

**가장 큰 기회**: 결과가 0건일 때 요약 띠에 '아직 없음' 상태를 따로 주고, 막대 자리에 한 줄 안내를 둔다. 새 상자나 새 차트는 만들지 않는다.

## 4. 우선순위 이슈
**P1 — 결과 0건일 때 요약 띠가 오류처럼 읽힌다**
- **근거**: results.js `bandHtml`의 달성률 칸은 `rate`가 없어도 `results.formula(s)`를 그대로 붙인다(248행). 협약 내역 칸은 `0곳`을 굵은 글자 색 `--fg`로 낸다(252–254행). 실측 화면은 `rs-targetonly-sim.png`.
- **왜 문제인가**: 사용자는 0÷0과 0이 줄줄이 이어진 모양을 계산 실패로 읽는다. 막대를 숨겨도 이 인상은 남는다.
- **수정**: 6-A 규격.

**P2 — 막대가 사라진 자리를 설명하지 않는다**
- **근거**: `#rs-body > div:empty{display:none}`(index.html 2744행). 2026에서 2027로 바꾸면 66px 높이의 상자가 말없이 사라지고 거르기 줄이 위로 올라온다.
- **왜 문제인가**: 같은 화면에서 해를 바꿔 본 사용자는 "막대가 고장났나"를 묻게 된다.
- **수정**: 6-B 한 줄 안내.

**P2 — 결과가 적고 대기가 많으면 꺾쇠 이름표가 상자 밖으로 나간다**
- **근거**: 재유치 1·대기 30일 때 꺾쇠 길이는 35px이다. '달성률 계산 1곳' 이름표(폭 87px)가 가운데 정렬(`translateX(-50%)`)이라 **상자 왼쪽 테두리보다 9px 밖**에 그려졌다(wrapL 268 / labelL 259). 3곳(87px 꺾쇠)일 때는 정상이다.
- **수정**: 6-C.

**P2 — 처음 열 때 막대 폭이 실제 상자와 어긋난다**
- **근거**: 2026 첫 화면에서 막대가 상자 오른쪽 끝보다 약 130px 짧게 끝났다(`rs-2026.png`). 연도를 바꾸면 끝까지 찬다(barR 17px). `barWidth()`가 `#rs-bar.clientWidth`를 재는데, 비어 있는 `#rs-bar`는 display:none이라 **clientWidth가 0이다(실측)**. 그래서 대체값 990을 쓰게 된다.
- **왜 문제인가**: 창이 좁으면 반대로 막대가 상자 오른쪽 밖으로 넘칠 수 있다(못 봄).
- **수정**: 폭을 늘 보이는 형제 요소(`#rs-body` 또는 `#rs-band`)의 clientWidth에서 잰다. 개발로 넘긴다.

**P3 — 공식 줄이 꺾인다**
- **근거**: 2026에서도 `…타은행 유치 1)`의 `유치 1)`이 다음 줄로 떨어진다(칸 폭 약 255px).
- **수정**: 공식 문장을 `재유치·신규 11 ÷ 12곳`처럼 줄이는 방안이 있지만, 이건 문구 정책이라 기획으로 넘긴다. 디자인만으로는 `.s`에 `word-break:keep-all`을 걸어 '유치 1)'가 함께 넘어가게 한다.

## 5. 문구 / 접근성
**문구**
- 결과 0건일 때 막대 자리 문장: **"입찰 결과가 나면 여기에 구성 막대가 그려집니다. 지금은 12곳 모두 결과 대기입니다."**
  - 확인 필요가 섞이면: "지금은 결과 대기 9곳, 확인 필요 3곳입니다."
  - 표현은 기존 띠 문구 '결과가 난 곳'에 맞춰 '결과가 나면'으로 통일했다.
- 달성률 칸(결과 0건): 값은 `—`이고, 보조 줄 두 개는 "결과가 난 곳이 아직 없습니다"와 "결과가 나면 계산합니다"다. **0÷0 공식 줄은 빼고**, 결과가 1건 이상일 때만 공식을 보인다.
- 협약 내역 칸(결과 0건): 값은 `0곳`을 `.v.mut`(--muted)로 쓴다. 보조 줄 두 개(재유치/신규, 1금고/2금고)는 "결과가 나면 셉니다" 한 줄로 바꾼다. 0곳은 사실이므로 지우지 않고 무게만 낮춘다.

**접근성**
- 안내 줄은 평범한 `<p>`로 둔다. role=status나 alert는 붙이지 않는다. 연도를 바꿀 때 읽어 주는 일은 이미 `rs-live`의 '달성률 아직 없음'이 한다. 같은 말을 두 번 읽히지 않게 한다.
- 대비(DESIGN.md 값 기준): `--muted` #464c53은 흰 패널 위에서 약 8.6:1, `--bg` 위에서 7.3:1이다. 12px 안내 줄로 충분하다.
- 막대가 없어도 같은 정보는 띠('결과 미확정 12곳')와 표에 있다. 색 단독 전달 문제는 없다.

## 6. 규격·시안
### 시안 비교 (결과 0건, 목표 12곳)
```
A. 비움 + 띠 정리 (현재 숨김 유지)
┌달성률────────┬목표 기관────┬협약 내역────┬결과 미확정──┐
│ —            │ 12곳         │ 0곳(회색)    │ 12곳         │
│ 결과가 난 곳이│ 재유치·신규 0│ 결과가 나면  │ 결과 대기 12 │
│ 아직 없습니다│ 타은행 유치 0│ 셉니다       │ 달성률에 넣지│
│ 결과가 나면  │              │              │ 않습니다     │
│ 계산합니다   │              │              │              │
└──────────────┴──────────────┴──────────────┴──────────────┘
[결과] (전체 12) (결과 대기 12) ...

B. A + 한 줄 안내 (권장)        ← 상자 없이 12px 회색 글 한 줄
┌ 띠 (A와 같음) ─────────────────────────────────────────────┐
└────────────────────────────────────────────────────────────┘
입찰 결과가 나면 여기에 구성 막대가 그려집니다. 지금은 12곳 모두 결과 대기입니다.
[결과] (전체 12) ...

C. 진행선 (권장하지 않음)
┌────────────────────────────────────────────────────────────┐
│ 결과 확정 0 / 12곳                                         │
│ ▕                                                    ▏ 4px │
└────────────────────────────────────────────────────────────┘
```
- **C를 권장하지 않는 이유**: 0%로 비어 있는 진행선은 '멈춘 작업'으로 읽혀, 오류 인상을 다시 만든다. 결과가 섞이면 구성 막대로 바뀌어야 하므로 같은 자리에 차트 두 종류가 번갈아 나온다. 같은 정보(결과 미확정 12곳)도 띠에 이미 있다.
- **B를 권장하는 이유**: 해를 바꿔도 "막대가 어디 갔나"의 답이 그 자리에 있다. 새 상자가 없어 '빈 그래프'처럼 보일 여지가 없고, 새 토큰도 쓰지 않는다.

### 6-A. 띠 상태 (조건: `!(rate_denominator > 0)` 이고 `target_n > 0`)
- 달성률: 기존 `.v.mut` `—`를 그대로 쓴다. `.s` 두 줄은 위 문구로 쓰고 formula는 넣지 않는다.
- 협약 내역: `.v.mut`, `.s` 한 줄 "결과가 나면 셉니다".
- 목표 기관·결과 미확정: 지금 그대로 둔다.

### 6-B. 안내 줄 (조건: `target_n > 0`, `!truncated`, `!(den > 0)`)
- `#rs-bar` 안에 `<p class="db-why rs-bar-note">…</p>`를 넣는다. CSS: `.rs-bar-note{margin:0;font-size:12px;color:var(--muted);line-height:1.5;word-break:keep-all}`. 상자·테두리·배경은 없다.
- 목표가 5곳 미만이거나, 결과가 있는데 분류가 한 가지뿐이라 숨기는 경우에는 안내 줄을 두지 않는다. 표가 바로 아래에 짧게 보이고, 띠가 숫자를 다 말해 준다.

### 6-C. 좁은 꺾쇠
- `m.span < 96`이면 `.rs-brace`에 `l` 클래스를 붙이고 `.rs-brace.l span{left:0;transform:none}`로 둔다. 96은 실측 이름표 폭 87px에 여유를 더한 값이다. 결과 칸이 늘 막대 왼쪽 끝에서 시작하므로 왼쪽 정렬은 항상 상자 안에 들어온다.

### 6-D. 칸 1개 / 대기 압도
- 칸이 1개뿐일 때(예: 모두 결과 대기, 또는 모두 재유치)는 지금처럼 그리지 않는다. 100% 한 칸은 띠의 숫자를 되풀이할 뿐이다.
- 대기가 압도하는 경우(1 대 30)는 지금 모양을 유지한다. 6px 최소 폭과 범례 이동이 잘 동작한다. 6-C만 고치면 된다.
