## 4. 고칠 것

### P2-A. 사진 캡션 칩이 두 줄로 쪼개진다
- **근거**: 부산(LOCAL_ONLY) 캡션 높이 35px. 칩을 nowrap으로 둔 폭은 106.6px, 표식은 margin 4px + 6.6px로 합계 117.2px. 0.2px가 넘쳐 꺾입니다(`hc-12`).
- **수정** (`frontend/index.html`, 카드 블록):
  ```css
  .hc-cap .pop-unk { white-space:nowrap; }
  .hc-cap .hc-fnref { margin-left:2px; }
  ```
  페이지 안에서 적용해 보니 캡션이 **35 → 17px(한 줄)**이 됐습니다.

### P2-B. 미리보기 제목에 「기관명」이 빠져 실제 파일과 다르다
- **근거**:
  - 화면 미리보기는 '참고자료 1. 기관장 정보'입니다(`hc-13`).
  - 서버 제목은 `HeadDocBuilder.java:67` `"참고자료 " + refNo + ". 「" + instName + "」 기관장 정보"`입니다.
  - 미리보기는 "받기 전에 한 번 보여 준다"가 목적인데, 보여 준 제목과 받은 파일 제목이 다릅니다.
- **수정**: frontend-dev 1913 보고서의 선택 패치 **3-C**(`dashboard.js`의 `headEnv`·`dmHeadEnv`에 `instName` 추가)를 적용합니다. dashboard.js를 다른 세션이 쥐고 있으면 그 세션이 끝난 뒤에 합니다.

### P3-A. 출처 제목 안의 날짜가 하이픈에서 끊긴다(6-3 잔여)
- **근거**: 동작 각주 1, '2026-' / '07-01부터'(`hc-11`).
- **수정**: `hc.srcHtml`에서 제목을 이스케이프한 뒤 날짜만 묶습니다. `esc(title).replace(/\d{4}-\d{2}-\d{2}/g, '<span class="hc-nb">$&</span>')`(링크 안·밖 둘 다), CSS는 `.hc-nb { white-space:nowrap; }`.
- **조건**: 이스케이프한 뒤에 바꿔야 안전합니다.

### P3-B. 각주 둘째 줄이 번호 아래로 들어간다
- **근거**: 각주 2줄째가 x=290으로, 번호와 같은 열에서 시작합니다.
- **수정**:
  ```css
  .hc-fn { padding-left:12px; text-indent:-12px; }
  .hc-fn sup { display:inline-block; width:8px; margin-right:4px; text-indent:0; }
  ```

### P3-C. 사진 실패·불러오는 중일 때 낭독이 두 번
- **근거**: `photoHtml` 233–234행. 틀은 `sil('사진을 불러오지 못했습니다')`(role=img + aria-label)이고 캡션도 같은 문장입니다. 11-15 P3-1과 같은 패턴입니다.
- **수정**: 두 가지 모두 `sil('')`로 바꿉니다(캡션이 말하므로).

### P3-D. 접힌 상태의 `aria-controls="hc-ref"`가 없는 id를 가리킨다
- 낭독 영향은 작습니다. 접혔을 때는 속성을 빼거나, 빈 `.hc-ref` 자리를 늘 두는 방법이 있습니다. 급하지 않습니다.

### 계약
- DESIGN.md '글자' 절에 '기관장 카드 큰 숫자 28px(카드 하나에 숫자 하나) 예외' 한 줄이 필요합니다. 규칙 문서라 메인이 직접 씁니다.

## 5. frontend-dev 이관 5건에 대한 의견
1. **`.hc-fns{display:none}` 안전망 생략**: **수용**. 마크업에서 완전히 뺐고, 시험(`css.indexOf('.hc-fns') < 0`)이 되살아남을 막습니다. 죽은 규칙을 두지 않는 편이 낫습니다.
2. **'(출처표시)' 괄호를 카드에서만 뗌**: **수용**.
   - 괄호가 붙은 이름은 `KOGL1` 하나뿐입니다(LICENSE_NAMES 47행). 다른 유형의 조건이 사라지는 일은 없습니다.
   - 출처 표시 의무는 각주 원문이 지킵니다. 편집 팝업은 전체 이름 그대로입니다.
   - 단, 모르는 코드의 칩은 위 P2-A 수정이 함께 들어가야 '한 줄'이 됩니다.
3. **불러오는 중·실패 캡션 여러 줄**: **수정 후 수용**.
   - 불러오는 중은 잠깐 지나가는 상태이니 `사진 불러오는 중…` + 표식만 둡니다(약 110px, 한 줄). 이용 조건은 사진이 뜬 뒤 보이면 됩니다.
   - 실패는 행동 안내가 필요하므로 `사진을 불러오지 못했습니다. [새로 고침]으로 다시 시도하세요.` + 표식으로 두고, `· 이용 조건`은 뺍니다(사진이 없으니 의미가 없음). 3–4줄은 드문 오류 상태라 허용합니다.
   - P3-C(sil 라벨 비우기)를 함께 합니다.
4. **[내려받기]에 db-next, 번호 칸 13px**: **수용**.
   - 실측: `.hc-ref button`(0,1,1)이 `.db-next`(0,1,0)를 이겨 글자 12px, 높이 29px로 옆 [취소]와 같습니다. 남는 것은 파랑 테두리뿐이고, `.hc-cand`와 같은 '주 행동' 표시입니다.
   - 번호 칸 13px은 `.hc-lab input` 13px, `.hc-facts dd` 13px과 같아 숫자 가독용으로 맞습니다.
5. **성공 줄 수명(다시 펼치거나 기관을 바꿀 때까지)**: **수용**.
   - 실측(흉내): 성공 줄은 꼬리 아래 `--panel2` 띠에 12px 한 줄(35px)로, 카드 흐름을 밀지 않습니다.
   - 규격의 '접고 단추로 포커스'는 지켜졌습니다(1100–1102행). 사라지는 타이머는 두지 않는 편이 낫습니다(읽기 전에 없어지는 문제).
   - 덧붙일 것 하나: [새로 고침]을 누를 때도 `dl.ok = ''`로 지우면 '방금 받은 파일'이 언제 일인지 헷갈리지 않습니다. 선택 사항입니다.

- [이관: 개발] `dashboard.js` 3-C(`instName` 전달)를 언제 적용할지 정해야 합니다. P2-B 미리보기 제목이 이것을 기다립니다. 근거: `headcard.js:1072`만 `env.instName`을 읽고, 넘기는 곳이 없습니다.

- [이관: 데이터] 부산 사진 출처 제목에 작업 메모('공공누리 표시 없음 — 로컬 작업용, 인물 사진인지 사람이 확인')가 그대로 각주로 노출됩니다. 각주가 출처 원문을 그대로 보여 주는 이상 이 제목이 사용자에게 보입니다(`hc-12` 각주 3). 값을 고칠지는 데이터 담당이 판단합니다.
