# 이사회 자료 '작성' 화면 MVP(1단계) 규격 (design-reviewer, 2026-11-02)

> 메인이 design-reviewer 응답 본문을 저장했다(에이전트는 읽기 전용). 근거: `handoff/agents/planner/2026-11-02_이사회자료_작성_착수기획.md`, 10-30 규격 2건, DESIGN.md, board.js·index.html `.bd-*`. 서버 화면은 열지 않았고 대비는 토큰 hex 계산값.

## 1. 총평
보기·양식 편집의 틀(고정 상태 줄, 인라인 확인 줄, 카드, 칩)을 이어 쓰면 새 요소가 거의 없다. 최대 위험은 값 칸 틸 표시(`.bd-mapped`)를 작성 모드에서 끄지 않으면 표 전체가 틸이 되어 선택 링이 묻히고 One Teal 규칙이 깨지는 것.

## 2. 우선순위 이슈
- P1 틸 범람: `#bd-root.is-write .bd-mapped { background:none; border-bottom:0 }`.
- P1 `--orange` 의미 겹침(수정됨·주의·결재): 수정됨=코너 삼각형+"원본 …" 보조 줄, 주의=`render.ICONS` 경고 삼각형+문구. 색만으로 구분 금지.
- P1 파일 고르기 키보드 접근: `.btn-like` label + `display:none` input은 포커스 불가 → 진짜 `<button>` + 시각적으로 숨긴 input `.click()`. 끌어다 놓기는 보조.
- P2 개인정보 거부 시 위치 모름: 문구로 보완, 시트 이름 노출 여부는 이관.
- P2 '확인 필요'/'미확인' 혼동: 필터 아래 정의 한 줄 상시 표시.
- P2 수정 칸 보조 줄 대비(`--muted` on 주황 18% ≈ 4.1:1) → `color-mix(in srgb, var(--muted) 70%, #ffffff)`(≈6.1:1).
- P3 거른 칸은 opacity 대신 글자색 `--muted`(≈5.7:1).

## 3. 모드 공존
- 모드 `view | edit | write`, 동시에 하나.
- 보기 버튼 순서: `[이 양식으로 작성]` `[워드 내려받기]` `[양식 편집]`/`[양식 복제하여 편집]`.
- `[이 양식으로 작성]`은 tasks 쓰기 권한 있을 때만. 없으면 `.bd-hint` "자료 작성은 업무 수정 권한이 있어야 할 수 있습니다."
- 기본 양식도 작성 가능(막힌 건 양식 수정이지 작성이 아님).
- 작성 모드: `#bd-form` 비활성, 위쪽 `#bd-docx` 숨김(워드 버튼은 작성 줄에 하나).
- 작성 줄 `#bd-writebar`(= `.bd-editbar` 스타일): `자료 작성 중 · {양식 이름} v{n} · 원본 {파일명}(저장 안 됨)` `[엑셀 바꾸기]` `[초안 워드 내려받기]`(중립+틸 테두리, 화면 유일) `[작성 끝내기]`.
- 작성 중 `[양식 편집]` 직행 불가.

## 5. 좌우 대조·필터·체크
- 그리드 `minmax(0,3fr) minmax(0,2fr)`, gap 14px. 오른쪽 sticky(top=작성 줄 높이), 자체 스크롤, `--panel`, 1px `--line-strong`, 8px.
- 패널 머리 "엑셀 원본 · {파일명}"(12px) `[원본 접기]`(aria-expanded).
- 원본은 값을 가져온 범위만: 범위 캡션 "수익성분석 시트 · B4:G12"(mono 11px muted), 열 문자·행 번호 th(mono 11px muted), 값 mono 12px 우측.
- 칸 상태: 미확인=기본 / 확인됨=오른쪽 위 SVG 체크 10px(`color-mix(var(--blue) 70%,#fff)`) / 수정됨=`--orange` 18% 틴트 + 6px 삼각형 + "원본 1,234" 11px 보조 줄 / 읽지 못함=`outline:1px dashed var(--red); outline-offset:-3px` + "읽지 못함" / 주의=ICONS 경고 10px `--orange` / 선택=2px 틸 outline(offset -2px) / 호버=1px dashed 틸(호버 전용 정보 없음).
- 선택 시 양쪽 하이라이트(왼쪽·원본 칸 틸 2px 링, 원본 칸 틸 13% 틴트), 원본 `scrollIntoView({block:'nearest'})`, 원본 칸 클릭 시 왼쪽 짝 선택.
- 하단 상태 줄(aria-live polite): "B 수익성분석 · 순이익 2026 = 1,230 │ 원본 수익성분석 시트 F8 = 1,234 │ 수정됨 `[원본 값으로]` `[확인]`(aria-pressed)". 읽지 못함은 이유 표시("수식의 계산 결과가 파일에 저장돼 있지 않습니다. 엑셀에서 한 번 저장한 뒤 다시 올리거나 직접 입력하세요.").
- 필터 `.wf-chip`+aria-pressed, group aria-label "칸 거르기": `[전체 48] [수정됨 3] [확인 필요 2] [미확인 45]`, 정의 줄 "확인 필요: 읽지 못했거나 주의가 붙은 칸 · 미확인: 아직 확인 표시를 하지 않은 칸". 행 숨기지 않음(병합 보존), 비해당 칸 글자 `--muted`·키보드 건너뜀, 해당 0개 표는 "B 수익성분석 — 해당 칸 없음"으로 접음.
- 일괄 확인 없음. m에 읽지 못한 칸 포함, 빈 칸은 값 넣은 뒤 확인(기획 확인).

## 6. 작업 소실 안내
1. 작성 줄 둘째 줄 상시: "이 작업은 저장되지 않습니다. 새로고침하거나 창을 닫으면 확인·수정한 내용이 사라집니다."
2. 빈 상태 문구에도 포함.
3. 화면 안 이탈은 인라인 확인 줄(안전 버튼 포커스, 0건이면 바로): "확인 12칸과 수정 3칸이 사라집니다. 작성을 끝낼까요?" `[작성 내용 버리기]` `[계속 작성]` / "새 엑셀로 바꾸면 확인 12칸과 수정 3칸이 사라집니다." `[바꾸고 새로 채우기]` `[그대로 두기]`.
4. 브라우저 이탈은 `beforeunload` 기본창(1건 이상일 때만) — `confirm()` 금지의 유일한 예외로 기록.
5. 세션 만료 시: "작업 시간이 지나 올린 파일 정보가 사라졌습니다. 같은 엑셀을 다시 올리면 값이 다시 채워집니다. 확인·수정 표시는 다시 해야 합니다."

## 7. 접근성·키보드
- 보고서 표 `role="grid"`, roving tabindex, aria-selected. 칸 이름 예 "순이익, 2026년, 1,230, 수정됨, 원본 1,234, 미확인".
- 키: 방향키 / Space 확인 토글 / Enter·F2 고치기(Enter 확정, Esc 취소) / Ctrl+↓↑ 필터 다음·이전 / Esc 선택 해제.
- 원본 패널 `role="table"`, Tab 순서 제외.
- 탭 순서: 작성 줄 → 요약 → 필터 → `확인했음` → 보고서 표 → 원본 접기 → 상태 줄 버튼.
- 포커스 2px 틸(≈7.4:1), 오류 빨강 ≈5.8:1(계산). 진행 막대·스크롤 이동은 reduced-motion에서 끔.

## 8. 문구 원칙
- 금지어: 매핑, mapped, JSON, 파싱, 캐시, 세션, tasks, 시트!셀 표기. 대신 "값을 가져온 범위", "파일에 저장된 마지막 값", "수익성분석 시트 F8".
- 활동 전체 = 검수, 칸 하나 = 확인. 결재 용어는 2단계에서 결재함과 맞춤.
- 오류 문구 = 원인 한 문장 + 할 일 한 문장.

## 9. 계약 위반 위험
틸 범람(`.is-write` 처리) · 채운 주버튼 금지 · 10–16px · 경고는 ICONS SVG · 틴트 18% 이하 · 새 `confirm()` 금지(`beforeunload`만 예외) · DESIGN.md Components에 인라인 확인 줄 표준 + "작성 모드 칸 상태 5종" 추가.

## 10. 이관 메모
- [기획] 값 수정 시 칸 확인·`확인했음` 해제 여부 / 읽지 못한 빈 칸의 m 포함·"빈 칸으로 둠" 허용 / 개인정보 거부 때 시트 이름 노출·오탐(13자리 금액) 문의처 / tasks 메뉴 화면 표시 이름.
- [백엔드] 업로드 응답을 오류 종류별로: 구조 불일치 이유 목록(기대·실제), 파일 거부 사유 코드, 개인정보 종류·건수만, 칸별 실패 이유 코드, 주의 목록(외부 연결·숨김·합계), 칸별 원본 시트·셀·표시값, 범위별 원본 값 표, 크기 한도 N·세션 만료 시각 노출 여부.
- [백엔드] 초안 워드를 서버 세션 값 vs 화면 현재 값(수정 포함)으로 만들지 — 화면 값 전송 권장.
- [프런트] mode 'write' 추가, `actionsHtml`·`#bd-docx` 숨김 분기, board-edit.test.js:552 클래스 문자열 비교 영향. 다른 탭 다녀와도 작성 DOM·상태 유지 확인(아니면 사이드바 이탈 확인 줄). 파일 고르기 `<button>`+숨긴 input(기존 CSV `.btn-like`는 별도 항목).
- [데이터] 원본 패널은 표시값 그대로, 재계산·보정 없음, 합계 불일치는 경고만.

## 11. 디자인 열린 질문
- 표 단위 "이 표 모두 확인" — 권장: 두지 않음.
- 진입 버튼 이름 `[이 양식으로 작성]`(권장) vs `[자료 작성]`.
- 수정 칸 "원본 1,234" 보조 줄 — 칸 안(권장, 행 높이 증가) vs 상태 줄에만.
