## 6'. '재유치 확정' 태그 — 국민은행 색 변수 하나를 쓰는 구조

**근거**: `index.html:2092`의 `.pt-chip.tag.kept`는 잉크 테두리, 700, `--fg` 10% 바탕입니다. `.won`(2093행)과는 회색 10% 바탕 하나만 달라 눈에 잘 띄지 않습니다. 글리프 ✓는 `portal.js:370`, 문구는 `P.TAG_TEXT`에서 옵니다.

**변수 1개 추가(`:root`, `index.html:15-23`)**
```css
--bank-kb:#ffbc00;   /* 국민은행 색 — KB Yellow Positive, PANTONE 130 C, RGB 255/188/0
                        출처 https://www.kbfg.com/kor/about/corporate/ci.htm (Color System 메인 컬러) */
```
- 이름은 예시대로 `--bank-kb`로 했습니다. fa 세션의 은행별 변수 이름과 다르면 합칠 때 이름만 바꾸면 됩니다.
- 기존 동결 변수 목록(DESIGN.md 71행)의 이름은 건드리지 않고, 변수를 하나 더하기만 합니다.

**칩 규격**
```css
.pt-chip.tag.kept { background:var(--bank-kb); color:var(--fg); border-color:#545045; font-weight:700; }
```
- 테두리 `#545045`는 CI의 KB Dark Gray(PANTONE 411 C, RGB 84/80/69)입니다.
- 노랑 면은 흰 바탕 대비 1.69밖에 되지 않습니다. 그래서 칩의 경계는 테두리가 맡습니다.
- 테두리를 변수로 둘지(예: `--bank-kb-edge`)는 fa 세션과 합칠 때 정해도 됩니다. 지금은 리터럴 하나로 둡니다.

**대비(WCAG)**

| 측정 | 값 | 기준 |
|---|---|---|
| 글자 `--fg` #1e2124 / `--bank-kb` | 9.59 | 글자 4.5 이상 ✓ |
| ✓ 글리프(currentColor) / `--bank-kb` | 9.59 | 3 이상 ✓ |
| 테두리 #545045 / 흰 바탕(패널) | 8.04 | 테두리 3 이상 ✓ |
| 테두리 #545045 / 행 hover 바탕(포인트 6%) | 7.5 이상 | ✓ |
| 채움 `--bank-kb` / 흰 바탕 | 1.69 | 경계 역할은 하지 않음(테두리가 대신 맡음) |

**다른 태그와의 단계**(kept만 바꾸고 나머지는 그대로)
- 재유치 확정: 노랑 채움 + 다크그레이 테두리 + 700 + ✓. 채운 면은 이 칩 하나뿐입니다.
- 신규 확정(`.won`): 흰 바탕 + 잉크 테두리 + 700 + ✓. 채움이 없어 구분됩니다.
- 차기 확정(`.next`): `--line-strong` 테두리, 400. 굵기로 구분됩니다.
- 입찰 끝남(`.ended`): 테두리 없이 muted. 테두리 유무로 구분됩니다.
- 경과 도장 `.ov-stamp`(잉크 채움, 흰 글자)와는 바탕 명도가 반대라 섞이지 않습니다.
- 뜻은 문구 '재유치 확정'이 함께 전하므로 색만으로 전하는 것이 아닙니다.

**계약 영향**
- DESIGN.md의 "칩은 채운 면 없음 / 채도 독점" 규칙에 명시 예외를 더해야 합니다.
- 문안 제안: "국민은행 색 `--bank-kb`(#FFBC00, KB CI) — 국민은행이 다음에도 금고인 표시에만 채움으로 쓴다(시작화면 '재유치 확정')."
- 2번 지도 선택을 노랑 대신 파랑으로 권한 근거(노랑 = 국민은행 한 뜻)는 그대로 유지됩니다.

**전/후 장 ④(시작화면 분량만)**
- 전: '재유치 확정' = 잉크 테두리 + 회색 10% 바탕. '신규 확정'과 바탕 농도만 달랐습니다.
- 후: KB 옐로 채움(`--bank-kb`), 잉크 글자 9.59, 다크그레이 테두리(흰 바탕 대비 8.04).
- 왜: 사용자 요청 "눈에 띄게, 국민은행 색으로".

**이관 메모(교체)**
- [이관: 개발] 이 칩의 `--bank-kb`와 fa 세션의 은행별 색 변수를 합칠 때 이름·값을 하나로 맞춰야 합니다. 디자인 쪽 값은 #FFBC00, 테두리는 #545045입니다. 테두리를 변수로 둘지도 그때 정합니다.
- [이관: 기획] '신규 확정'(다른 은행에서 국민은행으로 바뀜)도 국민은행 색 계열에 넣을지는 앞 보고서와 같이 열려 있습니다. 디자인 기본값은 넣지 않는 것(채움 없음 유지)입니다.
