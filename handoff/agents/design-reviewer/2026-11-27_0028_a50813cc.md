## 2. 한 줄 총평과 가장 큰 기회
기다림이 4~8분이다. 그래서 **사람이 쓰던 흐름을 끊지 않는 것**이 화면의 전부다.
- 가장 큰 기회는 진행·도착 표시를 본문이 아니라 **창 머리 아래 고정 줄(`.dlg-note`) 한 곳**에 두는 것이다.
- 초안은 칸을 건드리지 않고 칸 아래 **점선 상자**에서만 기다리게 한다.
- 'AI 표시'는 반짝이 아이콘이나 보라색이 아니라 **글자와 점선**으로 한다. 점선은 이미 `.bs-auto`(자동으로 들어가는 값)와 `.dlg-cf`가 '사람이 아직 손대지 않은 것'의 뜻으로 쓰고 있다. 채도 독점 규칙도 지킨다.

### 4-3. 포커스·키보드
- [AI 초안 만들기]를 누르면 포커스는 단추에 그대로 둔다(단추가 aria-disabled로 바뀌어도 포커스는 남는다).
- [그만두기]를 누르면 포커스는 묶음 단추로 간다.
- [초안 보기]를 누르면 처음으로 온 초안 상자의 제목 `h3[tabindex=-1]`로 포커스를 옮기고 `scrollIntoView({block:'nearest'})`.
- [칸에 넣기]·[뒤에 붙이기]·[버리기]·[되돌리기]·[알림 닫기]를 누르면 포커스는 그 칸 textarea로 간다. 넣었을 때는 커서를 넣은 글 끝에 둔다.
- 확인 상자는 dlg.js 그대로 쓴다. 첫 커서는 [계속 작성]이다.

## 5. 문구 전문
말투는 기존 대본 창을 따른다. 근거로 삼은 기존 문구:
- `scriptBusy` '만드는 중…'
- `scriptErr401` '로그인이 풀렸습니다. 다시 로그인한 뒤 만드세요.'
- `scriptErr500` '…잠시 뒤 다시 누르고, 계속되면 개발부서에 알려 주세요.'
- `scriptAutoNote` '값이 없거나 볼 수 없으면 숫자를 지어내지 않고 〔… 확인 필요〕로 남깁니다.'
- `scriptBoardDraft`의 '확정 전'
- 상태 줄 공식 '{무엇}을 못 했습니다. {원인}. {할 일}.'
- dlg.js '닫으면 입력한 내용이 사라집니다.'

### 5-2. 고정 줄 `#bs-ai-line`
- 만드는 중: `AI 초안을 만드는 중입니다(⟨2분 10초⟩ 지남). 보통 4~6분, 길면 8분 걸립니다. 다른 칸은 계속 적으세요.` + [그만두기]
- 8분 넘음: `8분이 지났습니다. 곧 끝나지 않으면 멈춥니다.` + [그만두기]
- 도착(2칸): `AI 초안 2칸이 왔습니다(⟨5분 12초⟩). 칸 아래 초안을 읽고 [칸에 넣기]를 눌러야 대본에 들어갑니다.` + [초안 보기]
- 도착(1칸): `AI 초안이 1칸만 왔습니다(⟨5분 12초⟩). 기대효과는 비어 왔습니다. 칸 아래 이유를 보세요.` + [초안 보기] (빈 칸 이름은 실제 칸 이름)
- 전부 빔: `두 칸 모두 비어 왔습니다. 칸 아래 이유를 보세요.`
- 그만둠: `AI 초안 만들기를 그만두었습니다. 적은 내용은 그대로입니다.`
- Word 성공(창 유지 시): `대본 Word를 내려받았습니다. 칸에 넣지 않은 AI 초안은 Word에 들어가지 않았습니다.`

| BUSY (동시 1건) | AI 초안을 만들지 못했습니다. 다른 요청이 지금 AI를 쓰고 있습니다. 몇 분 뒤 다시 누르세요. |
| COOLDOWN (60초) | AI 초안을 만들지 못했습니다. 방금 요청해서 1분쯤 지나야 다시 만들 수 있습니다. 잠시 뒤 다시 누르세요. |
| 시간 초과 | AI 초안을 만들지 못했습니다. 8분 안에 끝나지 않아 멈췄습니다. 잠시 뒤 다시 누르거나 칸에 직접 적으세요. |
| 연결 안 됨 (503·연결 실패) | AI 초안을 만들지 못했습니다. AI에 연결되지 않았습니다. 이 PC의 AI 프로그램이 켜져 있는지 확인한 뒤 다시 누르고, 계속되면 개발부서에 알려 주세요. |
| 401 | 로그인이 풀렸습니다. 다시 로그인한 뒤 만드세요. (기존 문구 그대로) |
| 403 | AI 초안을 만들지 못했습니다. 담당 영업과 영업부장만 만들 수 있습니다. |
| 404 | 기존 `scriptErr404` 문장에서 '대본 Word'만 'AI 초안'으로 바꾼다. |
| 409 (상태 밖) | AI 초안을 만들지 못했습니다. 이 건은 지금 단계에서 만들 수 없습니다(확정·중단·개설 대기). 창을 닫았다가 다시 여세요. |
| 500·그 밖 | AI 초안을 만들지 못했습니다. 서버에서 오류가 났습니다. 잠시 뒤 다시 누르고, 계속되면 개발부서에 알려 주세요. |

'다른 사람이 만드는 중'은 일부러 '다른 요청'으로 썼다. [그만두기] 뒤 서버가 아직 돌고 있으면 막는 쪽이 본인일 수 있다(7절 이관 참고).

### 5-4. 칸별 사유 (사유 상자 본문, `empty_reasons`)
같은 자료면 같은 글이 나온다. 그래서 숫자·개인정보·빈 답 사유에는 '다시 누르세요'를 쓰지 않는다.

| 코드 | 문구 |
|---|---|
| NO_BASIS | 근거로 쓸 자료가 없어 비웠습니다. 요약서나 이사회 자료를 채운 뒤 다시 만들거나 직접 적으세요. |
| NUMBER_NOT_IN_BASIS | 자료에 없는 숫자가 나와 비웠습니다. 직접 적으세요. |
| PII | 개인정보로 보이는 글이 섞여 비웠습니다. 직접 적으세요. |
| EMPTY_OUTPUT | AI가 빈 답을 돌려주었습니다. 직접 적으세요. |

### 5-5. 초안 상자·근거 줄
- 상자 제목: `AI 초안`(sr-only로 ', 보고 전 사전 설명'처럼 칸 이름을 덧붙임)
- 칩: `사실 확인 필요`(언제나), `확정 전 자료 기준`(`basis.draft`일 때)
- 글자 수: `⟨384⟩자`
- 한도 초과: `붙이면 1,000자를 넘습니다(칸 ⟨720⟩자 + 초안 ⟨384⟩자). 칸의 글을 줄인 뒤 다시 누르세요.` / `붙이면 12줄을 넘습니다. 칸의 줄을 줄인 뒤 다시 누르세요.`
- 넣은 뒤 표시 줄: `AI 초안을 넣은 칸입니다. 초안이므로 발표자가 사실을 확인하고 고쳐 씁니다.` + [되돌리기]
  - 랜딩 '초안, 발표자가 고칩니다'와 '사실 확인 필요'를 한 문장으로 합쳤다.
- 근거 줄: `근거 자료: 기관 정보, 요약서(확정 전), 이사회 자료(확정), 공고 파일 1개`
  - 쓰지 않은 자료는 뺀다. 아무것도 없으면 이 줄을 생략한다.
- 공고 파일 줄 (근거 줄 바로 아래 한 줄, 여러 개면 이름 최대 2개 + '외 n개'):
  - 없음: `건에 올린 공고 파일이 없어 공고 내용은 쓰지 않았습니다.`
  - 스캔본: `공고 파일 '⟨이름⟩'은 스캔본이라 글자를 읽지 못했습니다.`
  - 형식: `공고 파일 '⟨이름⟩'은 읽을 수 없는 형식입니다.`
  - 시간 초과: `공고 파일 '⟨이름⟩'을 읽다가 시간이 다 되어 쓰지 않았습니다.`
  - 지금 서버(사유 코드 없이 `notice: NONE`만 옴): `공고 파일 내용은 이번 초안에 쓰지 않았습니다.`

### 5-6. 닫기 확인 (`dirtyText`)
- 만드는 중: `AI 초안을 만드는 중입니다. 닫으면 만들던 초안이 사라지고, 다시 만들면 처음부터 기다려야 합니다.`
- 넣지 않은 초안 있음: `칸에 넣지 않은 AI 초안이 있습니다. 닫으면 초안이 사라집니다(저장되지 않음). 칸에 적은 글은 남습니다.`
- 단추는 dlg.js 고정 [버리고 닫기][계속 작성]이다. '계속 작성'은 만드는 중일 때 약간 어색하지만 받아들일 만하다. dlg.js에 `keepText` 선택 인자를 더할지는 프런트 판단으로 넘긴다.

### 6-3. 접근성
- **진행 알림**:
  - 경과 시간은 보이는 줄에서 1초마다 바꾸되, 그 줄은 live가 아니다.
  - `#bs-ai-sr`(role=status, polite)는 다음 때만 바꾼다.
    - 시작: 'AI 초안을 만들기 시작했습니다. 4~6분 걸립니다.'
    - 2·4·6·8분: '⟨n⟩분 지났습니다. 아직 만드는 중입니다.'
    - 도착·전부 빔·오류·그만둠: 5절의 문장과 같다.
  - 매초 읽게 하면 다른 칸을 적는 동안 스크린리더가 계속 말을 끊는다.
  - 오류도 polite로 둔다(alert로 하면 입력 중에 끊긴다). 창 전체 오류 `#bs-err` 규칙과는 구분한다.
- **`aria-busy`는 textarea에 걸지 않는다.** 칸은 그동안에도 쓸 수 있다.
- 묶음 단추는 만드는 중에 `aria-disabled`로 두고 Tab이 닿게 한다. 눌러도 아무것도 하지 않는다(중복 요청 방지는 JS로).
- 줄 안 단추는 높이 24px로, 기존 `.dlg-err button`과 같다. 터치 기준(44px)에는 못 미치지만 데스크톱 폐쇄망 업무 창이고 기존 규칙과 같다.
- **색만으로 전하지 않는다.** '확정 전 자료 기준'은 글자로 쓴다. AI 여부도 'AI 초안' 글자와 표시 줄로 전한다.
- 창을 닫을 때(확인 후 '버리고 닫기')는 진행 중인 요청을 끊는다(AbortController). 닫힌 창에 늦게 도착한 응답은 버린다. 지금 `onScriptGo`의 `S.script !== sc` 검사와 같은 방식이다.

## 7. DESIGN.md에 더할 절 문안 ('컴포넌트' 절, '날짜 이름표' 다음)

> - **공통 AI 초안 표시(사용자 11-27, NEXT 129 — 발표 대본 '보고 전 사전 설명·기대효과'가 첫 사례):** AI는 칸을 대신 채우지 않고 **칸 아래 초안 상자**에 내놓는다. 사람이 [칸에 넣기]를 눌러야 칸에 들어간다. 입구는 그 기능이 쓰는 칸들의 묶음 머리 아래에 **보통 단추 하나**([AI 초안 만들기], 채움 없음)를 둔다. 한 번에 오는 칸은 단추를 나누지 않는다. 권한이 없거나 기능이 꺼졌거나 단계 밖이면 단추와 이유 줄을 모두 그리지 않는다. 기다리는 동안 창은 열려 있고 다른 칸은 계속 쓸 수 있다. 진행은 창 머리 아래 고정 줄(`.dlg-note`) 한 곳에 '…만드는 중입니다(n분 n초 지남). 보통 a~b분…' + [그만두기]로 쓴다. 경과 시간은 `--mono`이고, 회전 표시·진행 막대·움직임은 쓰지 않는다. 스크린리더용 `role=status`는 시작·2분마다·끝에만 바꾼다. 도착해도 포커스를 옮기지 않고 줄에 [초안 보기]를 둔다. 초안 상자는 1px **점선** `--line-strong` + `--panel2` 바탕, 제목 'AI 초안'(13/600), 칩 '사실 확인 필요'(무채, 언제나)와 '확정 전 자료 기준'(`--orange` 글자·테두리·10% 틴트, 확정 전 자료를 썼을 때만), 본문 13px 읽기 전용, [칸에 넣기][버리기] + 글자 수로 짓는다. 칸에 글이 있으면 단추 이름이 [뒤에 붙이기]로 바뀌어 빈 줄 하나를 두고 붙인다. **바꾸기는 없다.** 넣은 직후에는 [되돌리기]를 준다. 칸 한도를 넘으면 넣지 않고 상자 안에 한 줄로 알린다(단추는 막지 않음). 넣은 칸 아래에는 'AI 초안을 넣은 칸입니다. 초안이므로 발표자가 사실을 확인하고 고쳐 씁니다.' 표시 줄이 남는다. 비어 온 칸은 같은 상자에 사유 한 줄(근거 없음·자료에 없는 숫자·개인정보·빈 답)을 쓴다. 요청 전체 실패(사용 중·잠시 뒤·시간 초과·연결 안 됨)는 고정 줄에 한 번만 '{무엇}을 못 했습니다. {원인}. {할 일}.'로 쓴다. 같은 자료면 같은 글이 나오므로 다시 만들기 도움말에 그 사실을 쓰고, 숫자·개인정보·빈 답 사유에는 '다시 누르세요'를 쓰지 않는다. 근거는 묶음 단추 아래 한 줄('근거 자료: …(확정 전)')로 쓰고, 읽지 못한 파일은 이름과 이유를 한 줄에 쓴다. 넣지 않은 초안이 있거나 만드는 중에 닫으려 하면 `dlg` 닫기 확인을 띄운다(초안은 저장되지 않음). AI 흔적은 시스템 기록에만 남기고 산출 문서(Word 등)에는 표시하지 않는다.
> - 하지 말 것(AI 초안): 칸에 자동으로 넣기, 사람이 쓴 글 덮어쓰기, 도착 시 포커스 가로채기, 경과 시간을 매초 읽게 하기, 반짝이·별 아이콘·보라/그라데이션 같은 'AI 색', 회전 표시, 같은 자료로 다시 만들면 다른 글이 나올 것처럼 쓰는 문구.

- **후**: 묶음 머리 아래 [AI 초안 만들기]. 4~6분 동안 창 위 고정 줄에 경과 시간이 보이고, 2칸 아래에 점선 초안 상자가 생긴다. [칸에 넣기]를 눌러야 들어간다.
- **숫자**: 주황 칩 5.0:1(18% 틴트였다면 4.2:1이라 10%로 낮춤), 본문 15:1, 줄 안 단추 24px.
- **왜**: 사람이 쓴 글을 지우지 않고, 6분 기다리는 동안 다른 칸 작성을 막지 않기 위해서다.
