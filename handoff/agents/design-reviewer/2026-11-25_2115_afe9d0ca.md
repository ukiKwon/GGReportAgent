## 4. 우선순위 이슈
P0·P1 없음. 커밋을 막을 정도는 아니지만, **P2 세 건은 이번 커밋에 같이 넣기를 권한다.**

- **P2-1 — 일괄 수정 성공 알림이 "구분·메모를 수정했습니다"라고 말한다**
  - 근거: `tchange.js` 70 `tc.editResultText`. 띠 [수정하기]는 구분만 보내고 memo 키는 빼서 보낸다(`kbboard.js` 3238·3324, `tchange.js` 206).
  - 왜 문제인가: 하지 않은 일을 했다고 알린다.
  - 수정: `'목표 기관 ' + n + '곳의 구분을 수정했습니다. 결재 없이 반영되고 기록에 남습니다.'`
- **P2-2 — `tc.APPROVAL_NOW_MSG` 끝 문장 "구분·메모는 결재 없이 바로 바뀝니다."**
  - 근거: `tchange.js` 29. 메모를 바꿀 입구가 이제 없다.
  - 수정: 끝 문장을 `구분은 결재 없이 바로 바뀝니다.`로 바꾼다. 앞부분은 규격 그대로다.
- **P2-3 — DESIGN.md 96행(계약)이 화면과 어긋난다**
  - 근거: 아직 "동작 입구 3곳 … 고른 기관 띠 [수정하기…] = 두 칸(바로 반영 / 결재 요청)"이다.
  - 수정: 6절 아래 교체 문안으로 바꾼다(메인 반영).
- **P3-1 — "구분·메모도 고칠 수 없습니다"류가 남았다**
  - 근거: `tc.dlgHint` 59(삭제 상자 안내), `tc.toWatchHint` 413, `tc.PAST_EDIT_MSG` 30.
  - 수정: 각각 `구분도 고칠 수 없습니다`, `구분도 고칠 수 없습니다`, `지난해 목표는 구분을 고칠 수 없습니다.`
  - `toWatchFact`의 "구분과 메모는 그대로 옮겨집니다"는 **사실이므로 둔다.**
- **P3-2 — [수정] 단추의 보내는 중 글이 다른 동사를 쓴다**
  - 근거: `kbboard.js` 3281. 실행 단추는 `수정`인데 보내는 중 글은 `저장하는 중…`이다.
  - 수정: `수정하는 중…`(같은 동작은 같은 이름).
- **P3-3 — `tc.TOWATCH_GONE` 뒤에도 상자가 열린 채 [결재 요청]이 살아 있다**
  - 근거: `kbboard.js` 3409. 오류를 쓰고 `loadGoals()`만 부른다.
  - 왜 문제인가: 다시 눌러도 같은 오류가 반복된다.
  - 수정: refresh 경로(3421~3427)와 같게, 다시 읽은 뒤 상자를 닫는다. 문구는 팝업 `#dm-err`(또는 상태 줄)에 쓰고 머리 줄을 다시 그린다.
- **P3-4 — 409 ALREADY_WATCH 문구의 행동 안내가 모호하다**
  - 근거: `tchange.js` 455 "목표는 그대로 두거나, 내 관심에서 먼저 빼 주세요."
  - 왜 문제인가: "그대로 두거나"는 할 일이 아니다. 같은 함수 안에서도 "~주세요"와 "~하세요"가 섞여 있다.
  - 수정안: `이미 내 관심 기관에 들어 있어 옮길 수 없습니다. 옮기려면 내 관심 탭에서 먼저 빼고 다시 시도하세요.` 업무 의미가 맞는지는 기획 확인이 필요하다(7절).
- **P3-5 — 삭제 상자 '기타 사유' 칸에 개인정보 안내가 연결되어 있지 않다**
  - 근거: `tchange.js` 440. `#tc-bd-etc`에 `aria-describedby`가 없다.
  - 수정: 안내 `<span>`에 id(예: `tc-bd-etch`)를 주고 칸에서 `aria-describedby`로 잇는다.

## 5. 문구 / 접근성
- 용어: [관심 기관으로…]를 머리·일정 칸·안내(`kbboard.js` 1208)·`APPROVAL_NOW_MSG` 4곳에서 같은 이름으로 쓴다. 통일됨.
- 띠의 [삭제하기]와 상자 제목 "목표에서 빼기 — n곳"·질문 "빼도록"은 이름이 다르다. 사용자가 정한 단추 이름이고 제목이 뜻을 풀어 주므로 이대로 둔다.
- 결재 중 칩(`.hb-pend`)은 전역 규칙이라 팝업 안에서도 스타일이 먹는다(`index.html` 2444). 대비 약 6.3:1(규격의 계산값). 자물쇠 글리프와 '결재 중' 글자로 뜻을 전하므로 색만으로 전달하지 않는다.
- 꺼진 머리 단추는 전역 `button:disabled` opacity .55다. `#db-cf`와 같아 규격대로다. Tab 가두기가 꺼진 단추를 건너뛰는 점은 규격에서 이미 알고 받아들였다.
- 띠의 꺼진 단추는 `aria-disabled`이고 글자는 `--muted`, 테두리는 `--line`이다. opacity를 쓰지 않아 DESIGN 94와 맞는다. 대비는 실측하지 않았다.
