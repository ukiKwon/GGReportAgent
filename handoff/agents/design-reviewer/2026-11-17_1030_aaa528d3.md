**확인 방법**: Playwright로 8080 화면을 1280×900에서 열람만 했습니다. 송파문화재단 상세의 빈 절, 하남시청(지자체)의 변경 창, 빈 [약정 추가] 폼을 실제로 열어 봤습니다. 직접 입력이 있는 상세 절은 페이지 안에서 `bankcontract.sectionHtml`에 가짜 데이터(이름 '담당A')를 넣어 그려 확인했습니다. 저장·지우기는 누르지 않았습니다.

**주의**: 다른 세션이 같은 브라우저와 서버를 함께 쓰고 있었습니다. 페이지가 두 번 저절로 새로고침되었고, 제가 열어 둔 폼이 닫혔습니다. 변경 창 목록에는 `입력 <script>홍</script>` 같은 시험 줄이 잠깐 보였는데, 이스케이프는 정상이었습니다. 확인할 때 GET으로 받아 보니 lines는 0건이었습니다.

### ① 규격과 어긋난 곳
- **P2-a 약정 시작·끝이 다른 줄로 갈라짐** (실측, `89_bank_after_form_empty_1280.png`)
  - 지자체에서 맡는 회계가 '선택 안 함'이면 [맡는 회계 | 약정 시작] / [약정 끝 | 빈칸]으로 흐릅니다. 규격은 시작=왼쪽, 끝=오른쪽입니다.
  - 고칠 CSS: `#ie-bank #ie-bk-from-l { grid-column:1; }`
- **P2-b 약정 기간 placeholder가 잘림**
  - 글자 폭은 215px인데 입력칸 안쪽 폭은 195px라 끝 20px가 잘립니다.
  - 고칠 문구: `2023 / 2023-01 / 2023-01-01`
- **P2-c 빈 상태 안내가 버튼과 서로 다른 말을 함** (`dashboard.js:783`·`771`)
  - 지금은 "약정 기록을 모으면 … 보입니다" 옆에 [금고 약정 입력] 버튼이 있습니다.
  - 고칠 문구: 783은 can_edit일 때 `금고 약정을 입력하면 출처와 함께 여기에 보입니다.`, can_edit=false면 `금고 약정은 영업팀이 입력합니다.`만 둡니다. 771은 `…약정 기간은 금고 약정을 입력하면 함께 보입니다.`
- **P2-d '수집 기록과 다름'이 중간에서 줄바꿈됨** ("수집 기록 / 과 다름", 실측)
  - 고칠 CSS: `#db-bank .db-chk { white-space:nowrap; }`
- **P2-e 입력자 표지 문구 `(로그인 확인 전)`**
  - 지금 보는 사람의 로그인 상태처럼 읽힙니다. 괄호도 규격(` · ` 꼬리)과 다릅니다.
  - 대안: ` · 이름 대조 전`. 정확한 의미는 기획 결정 대기입니다(아래 질문).
- **P3**
  - 겹침 경고 줄은 `맡는 회계` 다음이 아니라 `약정` 줄 바로 아래로 옮깁니다.
  - '2027년부터' 줄은 순위가 사라지므로 dd 앞에 `1금고 · `를 붙입니다.
  - `#ie-bank:focus{outline:none}` 때문에 응답이 오기 전에는 포커스가 보이지 않습니다. `outline:2px solid var(--accent-color); outline-offset:2px`를 권합니다.
  - placeholder #757575 / 입력 바탕 #0d1117은 4.1:1입니다. 앱 전체 기존 값이라 이번 범위는 아닙니다.

**규격대로 된 것**:
- 칩은 pp-neutral·pp-cancel 재사용, 글자 크기는 11·12·13px만 씁니다.
- 출처 종류 라디오 4개가 486px 안에 한 줄로 들어갑니다(P2-3 해소).
- 저장 버튼은 필수 칸이 다 차기 전까지 disabled(투명도 .55)입니다.
- `저장하려면: 은행, 금고 순위, 약정 끝, 출처 종류, 확인일` 안내가 나옵니다.
- [작성 취소], [고치기]·[지우기] 버튼은 62×28px이고, 은행 셀렉트에 틸 포커스 링이 보입니다.
- 묶음은 운영 상태 다음, 기본 정보 앞에 있습니다.
