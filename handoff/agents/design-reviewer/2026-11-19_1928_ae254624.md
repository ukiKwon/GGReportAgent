# 기관장 카드(.hc-*) 디자인 진단: 줄바꿈·위계·간격

## 1. 대상·방법·못 본 것
- **방법**: `frontend/js/headcard.js`(cardHtml·factsHtml·listHtml·photoHtml·srcHtml)와 `frontend/index.html`의 `.hc-*` CSS(2183–2261줄)를 읽었습니다. Playwright로 localhost:8080에 들어가 직접 보고 쟀습니다. 별도 브라우저 컨텍스트에 sales.member(김영업)로 로그인해 **열람만** 했습니다.
  - 입찰 현황판 → 동작구청(사진 없음)·부산광역시(사진 있음)·가평군청(기관장 없음)
  - 전국 지도 → 서울 → 마포구청 상세 팝업
  - 쓰기 버튼은 누르지 않았습니다. 시작할 때 뜬 '공고 예정일 지난 건' 안내의 [닫기]만 눌렀습니다.
- **폭**: 이 PC의 브라우저 배율이 0.9라서 창 크기를 보정해 CSS 폭 1280·1440·1920을 맞췄습니다(캡처 이미지는 0.9배 크기). 기관 상세는 폭이 고정된 팝업(`.modal-box.dm-box`, 720px)이고 카드 폭은 세 폭 모두 **658px**입니다. 화면 폭에 따라 줄바꿈이 달라지지 않습니다. 줄바꿈은 **내용 길이**가 정합니다.
- **[워드 내려받기] 자리 확인**: 실제 단추는 아직 없습니다. 페이지 안에서만 단추 2개(워드 내려받기, 확정 대기 후보 2건 보기)를 임시로 끼워 넣어 쟀고, 서버에는 아무것도 보내지 않았습니다.
- **못 본 것**:
  - 화면에서 보지 못한 상태: 권한대행 배지, '공고 진행 중' 띠, 입찰 D-day 띠, 학력·경력 5건 이상(접기), 사진 불러오기 실패, 실제 확정 대기 후보.
  - 편집 팝업(#hc-modal)은 열지 않았습니다(이번 범위 밖).

## 2. 한 줄 총평
뼈대(큰 숫자 띠 → 사람 → 날짜 3칸 → 학력·경력 → 꼬리)는 맞습니다. 그런데 **같은 출처 문장이 카드 한 장에 3~6번 되풀이**되고, 그 밑줄 링크들이 이름보다 눈에 띕니다. 들쭉날쭉한 줄바꿈도 대부분 이 되풀이된 출처 문장에서 납니다.
**가장 큰 기회**: 출처를 카드 아래 각주 목록 하나로 모으면(이미 날짜 3칸에 쓰는 방식을 카드 전체로 넓히기), 카드 높이가 대략 25–30% 줄고 불규칙한 줄바꿈도 대부분 사라집니다.

- 날짜 3칸 + 각주 표식: 같은 출처를 하나로 모으는 장치가 이미 있습니다. 이것을 넓히면 됩니다.

## 4. 우선순위 이슈

### P1-1. 같은 출처가 띠와 각주 1에 글자 그대로 두 번 나온다
- **근거**: `cardHtml`의 띠 줄(`'만료일 ' + mono(big.date) + ' ' + hc.srcHtml(big.src)`)과 `factsHtml` 각주 1이 같은 TERM_END 출처를 다시 그립니다.
  - 동작구: 띠 2줄 + 각주 2줄이 같은 문장입니다("2026 지방선거 서울 구청장 당선인 보도(한국금융신문·시정일보 일치) — 임기는 공직선거법상…").
  - 캡처 `hc-01`, `hc-08`. 띠 높이 96px 중 36px가 이 출처 줄입니다.
- **왜 문제인가**: 띠의 역할은 큰 숫자 하나입니다. 그런데 밑줄 링크 2줄이 숫자 바로 밑에서 시선을 나눕니다. 80px 아래에서 같은 문장을 다시 읽게 됩니다.
- **수정 방향**: 띠에는 `만료일 2030-06-30 기준` + 각주 표식만 둡니다(6-2). 출처 원문은 각주에 한 번만 둡니다.

### P1-2. 학력·경력 항목마다 같은 출처 줄이 붙는다
- **근거**: `listHtml`의 `li`가 값 + `<br>` + `hc.srcHtml(it.source)`로 그립니다.
  - 마포구: 3건 모두 "기관 누리집 · 마포구청장 소개 · 확인 2026-11-13".
  - 부산: 5건 모두 같은 출처. 항목 한 건이 39px(2줄)이고, 그중 1줄이 되풀이입니다(`hc-03`).
- **왜 문제인가**: 밑줄 링크 5개가 세로로 쌓여 이 칸에서 가장 눈에 띄는 요소가 됩니다. 정작 경력 내용(장관·국회의원)이 묻힙니다.
- **수정 방향**: 항목 값 옆에는 각주 표식만 둡니다. 출처는 카드 아래 각주 목록에서 날짜 칸과 번호를 함께 씁니다(6-1).

### P2-1. 한 낱말 안에서 줄이 끊긴다
- **근거**: 측정값 `.hc-fn {word-break:normal; overflow-wrap:anywhere}`, `.hc-src`도 같습니다.
  - 동작구 각주: "시정일보 일**/**치)" (`hc-01`)
  - 부산 각주: "확인 2026-**/**11-13", 날짜 한가운데서 끊김 (`hc-03`)
  - 마포구 각주: "확인**/**2026-11-13" (`hc-08`)
- **왜 문제인가**: 한글 낱말과 날짜가 잘려 읽기가 멈춥니다. 이번 요청의 '불규칙 개행'에 그대로 해당합니다.
- **수정 방향**: `.hc-fn`·`.hc-src`·`.hc-items`에 `word-break:keep-all; overflow-wrap:break-word`를 줍니다. `확인 날짜`는 한 덩어리로 묶어 `white-space:nowrap`을 줍니다(6-3).

### P2-2. 사진 캡션이 5줄로 길어지고 내부 코드가 보인다
- **근거**:
  - 부산 캡션: "사진 · LOCAL_ONLY · 부산광역시 단체장 소개(공공누리 표시 없음 — 로컬 작업용, 인물 사진인지 사람이 확인)". 132px 칸에서 5줄(`hc-03`).
  - `hc.licenseLabel`은 모르는 코드면 `str(cd)`를 그대로 돌려줍니다.
  - 캡션 왼쪽 끝(x=402)이 사진 틀 왼쪽 끝(x=410)보다 7.5px 밖에 있습니다. 틀은 가운데, 캡션은 왼쪽 정렬이라 어긋납니다.
- **왜 문제인가**: 사진 칸이 길어져 학력 칸 시작이 밀립니다. 코드 이름은 사용자가 알 수 없는 내부 용어입니다.
- **수정 방향**:
  - 캡션은 `이용 조건 + 출처 표식` 한 줄로 줄이고 출처 원문은 각주로 보냅니다. 공공누리 출처표시 의무는 각주가 지킵니다.
  - 모르는 코드는 `이용 조건 미확인` 칩으로 보입니다.
  - 캡션은 틀과 같은 117px 폭으로 가운데 정렬합니다.

### P2-3. 꼬리 줄이 경우에 따라 1줄 또는 2줄로 꺾인다 — [워드 내려받기]와 충돌
- **근거**: 지금 꼬리 높이는 50px(1줄, 콘텐츠 영역 624px).
  - 확정 대기 후보 단추와 [워드 내려받기]를 함께 넣으면 86.9px로 늘어납니다. 단추 묶음만 다음 줄 오른쪽으로 떨어집니다(`hc-10`).
  - 후보 단추가 없으면 한 줄에 남습니다. 결국 기관마다 꼬리 모양이 달라집니다.
- **왜 문제인가**: 기관을 옮겨 다닐 때 단추 위치가 바뀌어 손이 헤맵니다. 6-6 규격이 말한 '꼬리 아래 펼침 줄'도 어디에 붙을지 정해지지 않습니다.
- **수정 방향**: 꼬리를 늘 두 줄로 고정합니다. 1줄은 정보 글, 2줄은 [후보 보기](왼쪽)와 [워드 내려받기][새로 고침][기관장 편집](오른쪽)입니다. 펼침 줄은 3번째 줄 전체 폭을 씁니다(6-4).

### P2-4. 같은 팝업 안에 [편집]이 둘이다
- **근거**:
  - 팝업 머리 `[제안 확정][편집][×]`: 기관 편집.
  - 카드 꼬리 `[새로 고침][편집]`: 기관장 편집.
  - 캡처 `hc-01`·`hc-08`에서 두 단추가 한 화면에 함께 보입니다.
- **왜 문제인가**: 어떤 편집인지 단추 이름만으로는 알 수 없습니다. 화면 낭독기로는 같은 이름 단추가 둘로 들립니다.
- **수정 방향**: 카드 단추 이름을 `기관장 편집`으로 바꿉니다. 편집 팝업 제목('기관장 정보 편집')과도 맞습니다.

### P2-5. 날짜를 복사하면 각주 번호가 붙어 나온다

- **왜 문제인가**: 영업 담당자가 날짜를 제안서에 붙여 넣으면 `2026-07-011`이 들어가 틀린 날짜가 됩니다.
- **수정 방향**: 각주 표식과 sr-only 꼬리표에 `user-select:none`을 줍니다(6-3).

## 5. 문구 / 접근성

**문구**
- `LOCAL_ONLY`(사진 캡션): 코드 노출입니다. 모르는 코드는 `이용 조건 미확인`으로 보입니다.
- 카드 꼬리 `편집` → `기관장 편집`.
- 각주 낭독: 지금은 "출처 1: 출처: 언론 보도…"로 '출처'를 두 번 읽습니다. 보이는 글 `출처:`를 빼고 각주 머리에 `출처` 소제목을 한 번만 둡니다(6-1).
- `출처 9건`: 보이는 출처는 1~2종인데 숫자는 9입니다. 항목 수를 센 값으로 보입니다. 각주를 모으면 각주 수와 숫자가 달라 더 헷갈립니다. `출처를 단 항목 9건`으로 바꾸거나, 각주 수를 보이게 합니다(8절 질문).

**접근성**
- 단추 높이 29px(꼬리)로 24px 기준은 넘습니다.
- 띠의 `role="group" aria-label` 처리는 좋습니다.
- 날짜 칸의 `aria-describedby`는 포커스를 받지 않는 dd에 붙어 있어 대부분의 낭독기가 읽지 않습니다. sr-only `(출처 n)`이 실제 전달 수단이므로 남깁니다(복사만 막기).

## 6. 규격(프런트가 그대로 옮길 수 있게)
범위는 `.hc-*`와 `headcard.js` `cardHtml`·`factsHtml`·`listHtml`·`photoHtml`·`srcHtml`뿐입니다. dm-*·hb-*·#edit-modal은 건드리지 않습니다.

### 6-1. 출처를 카드 각주 목록 하나로 모은다(구조 변경)
- `factsHtml`의 각주 모으기(`srcKey`로 같은 출처 하나로)를 **카드 전체**로 넓힙니다. 번호를 매기는 순서는 다음과 같습니다.
  1. 임기 만료(띠) = 날짜 칸 TERM_END와 같은 번호
  2. 날짜 3칸
  3. 학력
  4. 경력
  5. 사진
- 값 옆에는 `<sup class="hc-fnref" aria-hidden="true">n</sup><span class="sr-only">(출처 n)</span>`만 둡니다(지금 날짜 칸과 같은 형태).
- 각주 목록 `.hc-fns`는 날짜 칸 아래에서 **학력·경력 아래, 꼬리 위**로 옮깁니다.

```
┌ hc-band ─────────────────────────────────────────┐
│ 임기 3년 7개월 남음                               │
```

## 7. 이관 메모
