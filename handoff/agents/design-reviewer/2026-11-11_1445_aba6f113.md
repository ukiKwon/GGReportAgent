  - 경과 묶음은 `aria-expanded`가 있는 disclosure 버튼 + 별도 listbox입니다. Tab으로 들어갑니다.
  - [제안 확정] → 확인 줄에서 [확정하기]로 포커스가 이동합니다. Esc·[취소]를 누르면 [제안 확정]으로 돌아옵니다.
  - 검색 입력은 기본 동작 그대로입니다.
- **구조**
  - `#db-root section[aria-label="입찰 현황판"]`
  - 띠의 각 칸은 `section aria-labelledby`(h2)입니다.
  - 상세는 `section aria-labelledby="db-name"`, 섹션 머리는 h3입니다.
  - 확인 줄은 `role="group" aria-labelledby`입니다.
  - 선택이 바뀔 때 상세 전체를 aria-live로 읽히지 않습니다(↑↓마다 낭독 폭주). 성공·오류만 `role=status`/`role=alert`로 읽힙니다.
- **움직임**: 행 hover는 3px 슬라이드(랭킹 패널과 같음)이고, `prefers-reduced-motion`이면 끕니다. 새 진입 애니메이션은 없습니다(One Entrance Rule).
