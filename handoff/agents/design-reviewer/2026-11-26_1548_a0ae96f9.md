## 2. 한 줄 총평
지금은 같은 "0건" 상태가 세 가지 모양으로 그려진다. ① 표를 지우고 문장만(대다수) ② 표 안에 colspan 안내 줄(현황판·시작화면·사용자 관리 등) ③ 머리 줄만 있고 행이 0개(전체 입찰건·내 권한).
**가장 큰 기회**: 공통 함수 하나(`tblEmpty.rowHtml`)로 ①과 ③을 "머리 줄 + 빈 행 1줄 + 표 아래 안내 한 줄"로 맞추는 것. 안내 문장은 위치만 옮기고 글은 그대로 두므로, 문구를 확인하는 시험 대부분은 그대로 통과한다.

## 3. 규격 (권장안 하나)

**모양**
- 머리 줄(thead)은 그대로 둔다.
- tbody에 `tr.tb-empty` 1줄을 넣는다. 칸은 **열 수만큼의 td**로 만든다. colspan으로 합치지 않아야 세로 칸 선과 colgroup 열 폭이 살아서 "표 규격"이 보인다.
- **빈 행의 칸은 글자 없이 비운다.** '—'을 쓰지 않는 이유: 이 시스템에서 '—'은 "기록은 있는데 그 칸 값이 없음"이라는 뜻이다(board-material.js:874 빈 메모, 곧 바뀔 team 배정 이력의 빈 사유, 현황판의 근거 없는 칸). 한 줄 전체가 '—'이면 값이 다 빠진 실제 기록 1건으로 읽힌다.
- 스크린리더: 첫 칸에만 `<span class="sr-only">비어 있음</span>`을 둔다. 문구는 instsummary.js:893의 기존 선례와 같다. 표 탐색으로 "1행 1열 비어 있음"이라고 읽힌다.
- 높이: 그 표의 td 여백 + 한 줄. `::after{content:"\00a0"}`로 줄 높이를 만든다. sr-only만 있는 칸은 높이가 0이 되기 때문이다. 두 줄짜리 행 표(.hb-tt 준비 단계 등)도 빈 행은 한 줄로 둔다.
- 정렬: 열 규칙(금액 오른쪽, 사유 왼쪽·위)과 상관없이 가운데·세로 가운데로 둔다. 빈 행은 값이 아니므로 102행과 충돌하지 않는다. 열별 nth-child 규칙이 이기지 않게 `!important`를 쓴다(`.ad-empty`에 선례가 있다).
- 빈 행에는 hover·선택 색, cursor:pointer, tabindex, data-id를 주지 않는다. 행 클릭 위임이 `tr[data-id]`를 찾는 표는 이 행을 자연히 건너뛴다.
- 선택(체크) 열은 빈칸으로 두고, 머리의 '모두 선택' 체크는 숨기거나 끈다(cr-table은 이미 그렇게 한다).

**안내 문장**
- 지금 있는 문장은 **글을 바꾸지 않고 표 바로 아래** `p.tb-empty-note`(12px `--muted`, 왼쪽) 한 줄로 옮긴다. 단추([조건 지우기]·[회의록 올리기] 등)는 같은 줄 끝에 붙인다.
- 표가 `.tm-tbl-wrap`·`.ib-scroll` 같은 감싸개 안에 있으면 감싸개 바깥 아래에 둔다.

**범위 밖 (빈 표로 그리지 않음)**
- 불러오는 중·오류·권한 없음·오프라인·"사용자를 선택하세요" 같은 선택 전 상태. 빈 표는 "0건이라는 사실"을 말하므로, 모르는 상태를 0건으로 보이게 하면 근거 없는 표시가 된다(PRODUCT 원칙 1). 이 상태들은 지금 문장을 그대로 둔다.
- 줄 안에 단추가 있는 기존 colspan 안내 줄(.hb-tt·.pt-tt·.rs-tt)은 유지한다. 이미 표와 1행이 있고, DESIGN 102행이 .hb-tt 빈 상태 칸을 명시하고 있다. 단추가 없는 colspan 줄(사용자 관리·감사 기록·대결)은 이번에 새 모양으로 바꾼다.

## 4. 공통 도우미 + CSS

**새 파일 `frontend/js/tblempty.js`**
- errtext.js처럼 작은 공용 모듈로 둔다. dlg.js는 창 전용이라 넣지 않는다.
- `index.html`에서 `<script src="js/dlg.js">` **바로 다음 줄**(현재 4684행 앞)에 넣는다. 화면 모듈이 IIFE 위쪽에서 `root.tblEmpty`를 미리 잡아 두기 때문이다. errtext.js는 4699행이라 workflow.js(4687) 등보다 늦게 실린다.
- 쓰는 쪽은 team.js:16과 같은 패턴을 쓴다: `const tblEmpty = isNode ? require('./tblempty.js') : root.tblEmpty;`

```js
(function (root) {
  'use strict';
  // 빈 표 한 줄 (DESIGN '빈 표'). 머리 줄은 호출하는 쪽이 그대로 그린다.
  const tblEmpty = {};
  const MAP = { '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' };
  function esc(s) { return String(s == null ? '' : s).replace(/[&<>"']/g, function (c) { return MAP[c]; }); }
  tblEmpty.SR = '비어 있음';

  // colCount = 머리 줄 실제 열 수(선택 칸·sr-only '동작' 칸 포함). opts: { sr, cls }
  tblEmpty.rowHtml = function (colCount, opts) {
    const o = opts || {}, n = Math.max(1, Math.floor(Number(colCount)) || 1);
    let h = '<tr class="tb-empty' + (o.cls ? ' ' + esc(o.cls) : '') + '"><td><span class="sr-only">' + esc(o.sr || tblEmpty.SR) + '</span></td>';
    for (let i = 1; i < n; i++) h += '<td></td>';
    return h + '</tr>';
  };

  // 표 아래 안내 한 줄. text는 esc, actionHtml은 호출 쪽이 조립한 단추 HTML만(사용자 값 금지).
  tblEmpty.noteHtml = function (text, actionHtml, opts) {
    if (!text && !actionHtml) return '';
    const id = opts && opts.id ? ' id="' + esc(opts.id) + '"' : '';
    return '<p class="tb-empty-note"' + id + '>' + esc(text) + (actionHtml ? ' ' + actionHtml : '') + '</p>';
  };

  // DOM으로 표를 만드는 화면(board-minutes·instsummary)용
  tblEmpty.rowEl = function (doc, colCount, opts) {
    const o = opts || {}, n = Math.max(1, Math.floor(Number(colCount)) || 1);
    const tr = doc.createElement('tr'); tr.className = 'tb-empty' + (o.cls ? ' ' + o.cls : '');
    for (let i = 0; i < n; i++) {
      const td = doc.createElement('td');
      if (i === 0) { const s = doc.createElement('span'); s.className = 'sr-only'; s.textContent = o.sr || tblEmpty.SR; td.appendChild(s); }
      tr.appendChild(td);
    }
    return tr;
  };
  tblEmpty.noteEl = function (doc, text) {
    const p = doc.createElement('p'); p.className = 'tb-empty-note'; p.textContent = text || ''; return p;
  };

  if (typeof module !== 'undefined' && module.exports) module.exports = tblEmpty;
  else root.tblEmpty = tblEmpty;
})(typeof self !== 'undefined' ? self : this);
```

**CSS** (index.html 공통부, `.ad-empty`(1764행) 근처)
```css
table tr.tb-empty > td { text-align:center !important; vertical-align:middle !important; cursor:default; }
table tr.tb-empty > td::after { content:"\00a0"; }   /* 빈 칸도 보통 행 한 줄 높이 */
.tb-empty-note { margin:6px 0 0; font-size:12px; color:var(--muted); text-align:left; }
```
