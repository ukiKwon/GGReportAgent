## 2. 한 줄 총평과 가장 큰 기회
- **총평**: 각진 원인은 "2px 하나"라는 값보다, 팝업부터 6px 견본까지 **모든 층이 같은 2px에 같은 진한 1px 선(#6d7882, 흰 바탕 위 4.49:1)**을 쓴다는 데 있다. 상자 안에 상자가 들어가도 층이 구분되지 않는다.
- **가장 큰 기회**: 변수 이름을 그대로 두고 값만 3단으로 바꾸는 것이다(`--r-sm` 작은 표식 / `--r` 컨트롤 / `--r-lg` 틀·팝업). 선언의 대부분이 이미 `var(--r*)`를 쓰므로 `:root` 한 줄과 선택자 약 60곳만 바꾸면 끝나고, 되돌리기는 `:root` 한 줄이면 된다.
- 이번 일은 좁은 범위의 감사라 휴리스틱 점수는 매기지 않았다.

**잘 된 점**
- 하드코딩이 거의 없다. 변수를 안 쓴 값은 10곳뿐이고, JS 인라인 radius는 0건이다.

## 4. 원인 진단 — 모서리 말고 각져 보이게 하는 것 (범위: 각짐)
1. **틀 선이 진하다.** 패널·팝업·카드 테두리가 `--line-strong` #6d7882이고, 흰 바탕 대비가 **4.49:1**이다(직접 계산). 패널(흰색)과 바탕 #e9ecf0의 차이는 1.19:1밖에 안 돼 선이 필요하기는 하다. 하지만 4.5:1은 도면 선 굵기로 읽힌다. 비교값은 `--line` #c3c9d1 1.63:1, 지도류 #aeb5bf 2.07:1이다. 단추·입력칸은 WCAG 1.4.11(컨트롤 경계 3:1) 때문에 `--line-strong`을 유지해야 하고, **틀(패널·팝업)만** 낮출 여지가 있다. 다만 DESIGN.md 100행이 카드·패널에 `--line-strong`과 `--line`을 모두 허용하므로 계약 안에서 고를 수 있다.
2. **층 구분이 없다.** 팝업 → 확인 상자 `.dlg-cf`(3232, 점선) → 단추가 모두 2px에 같은 선이다. 높이를 그림자 없이 선 하나로만 나타내므로(DESIGN 87행, 유지) 반경이 위계를 대신 말해 줘야 하는데, 지금은 그러지 못한다.
3. **팝업 머리 아랫선이 이중으로 보인다.** `.dlg-bar`(3218)가 `border-bottom:1px solid var(--line-strong)`이다. 바깥 틀 선과 같은 진한 선이 위쪽 52px 아래를 한 번 더 가로질러 상자가 이중으로 보인다. 머리 회색 #f6f7f9와 본문 흰색의 차이(1.07:1)는 `--line`만으로도 충분히 구분된다.
4. **점선 상자가 진한 선이다.** `.dlg-cf` 3232, `.db-hint` 2049, `.bs-auto` 1722, `.db-confirm` 2099, `.hc-confirmbox` 2829, `.pp-end` 1524, `.bd-w-drop` 515가 1px `--line-strong` 점선에 2px 모서리다. 반경을 키우면 점선이 곡선을 따라 돌아 조금 누그러진다. 색은 그대로 둔다.
5. **3px 옆줄 + 반경**(감지기 border-accent-on-rounded 계열). 대상은 283, 290, 300, 306, 315, 361, 366, 422, 1011(`border-left:3px`)이다. 감지기가 짚은 border-top 3px 2건은 로그인 카드 패턴이며 config.json 216–231에서 의도로 처리돼 있다. 반경이 4px를 넘으면 옆줄 끝이 휘어 보인다. **B안에서 특히 두드러진다.**

## 5. 수정안 (변수 이름은 그대로, 값만 바꾸고 선택자를 다시 짝짓는 방식)

### 공통 규칙 (세 안 모두 같음)
- `--r-sm` = **작은 표식**: 높이나 폭이 12px 이하인 견본·막대·진행선·`mark`·스크롤 막대. 2px로 고정한다. 4px 이상이 되면 높이 2–8px 막대가 알약 모양이 되는데, 알약 모양은 DESIGN 147행에서 금지다.
- `--r` = **컨트롤**: 단추·입력·select·칩·배지·탭·세그먼트 안쪽·메뉴 항목, 그리고 틀 안에 든 카드나 상자.
- `--r-lg` = **틀과 떠 있는 것**: 팝업·모달·바탕 위에 바로 놓인 패널·띠·메뉴 상자·말풍선·표 틀·지도 판.
- 원 50%는 지금의 점 2곳(랜딩 포함 3곳)만 쓴다.
- **표**
  - 칸(th/td)은 언제나 0이다.
  - `border-collapse:collapse`인 표 자체에 radius를 주면 무시된다. 그래서 **표는 둥글게 하지 않고 표를 담는 틀만 둥글게** 한다.
  - 틀은 `overflow:hidden` 또는 `auto`로 둔다. `auto`도 둥근 안쪽 가장자리에서 잘리므로 sticky 머리 배경도 함께 잘린다.
  - `separate`로 바꿀 필요는 없다.
  - `.ad-grid`(칸마다 선)는 틀 없이 각진 상태로 둔다.
  - 확인할 곳은 `.rs-tp`(3119)다. `overflow`가 없어서 머리 배경이 모서리에 닿으면 각이 삐져나온다. 이렇게 될 경우 `overflow:hidden`을 더한다.
- **띠 칸**: `.pt-band`·`.hb-band`·`.rs-band`의 자식 칸이 배경이나 `inset` 막대(예: `.pt-k[aria-pressed]`의 -3px 막대)를 그리면, 바깥 모서리에서 각이 1px쯤 삐져나올 수 있다. 띠에 `overflow:hidden`을 더한다. 적용 후 확인할 것.

### A안 — 절제 (권장)
`--r-sm:2px; --r:4px; --r-lg:6px;`
- 단추·입력·칩·탭은 4px, 팝업·패널·메뉴·말풍선·표 틀은 6px, 견본·막대는 2px이다.
- 틀 안의 카드는 4px(바깥 6 > 안쪽 4로 겹침이 자연스럽다).
- 세그먼트는 바깥을 `--r-lg`(6), 안쪽을 `--r`(4)로 한다. 패딩 3px이라 동심원에 가깝다(6−3=3≈4).
- 18–24px 칩에 4px는 높이의 1/5–1/6이라 알약이 되지 않는다.
- 3px 옆줄 끝의 휨이 거의 보이지 않는다.

### B안 — 부드럽게
`--r-sm:2px; --r:6px; --r-lg:10px;`
- 칩(18–20px)에 6px는 높이의 약 1/3이라 알약에 가깝다. 칩만 따로 4px로 두려면 새 변수가 필요한데, 새 변수는 금지다(DESIGN 72, `board-rowcol.test.js:637`).
- `.pt-tab`(32px, 아래 inset 2px 밑줄)의 밑줄 끝이 휜다. `.pt-tab`을 `var(--r) var(--r) 0 0`으로 바꿔야 한다.
- 3px 옆줄 9곳이 눈에 띄게 휜다.
- 그림자 없는 1px 틀에 10px 팝업이면 소비자 앱 인상이 난다.

### C안 — 현행 + 팝업만
`--r-sm:2px; --r:2px; --r-lg:6px;`
- 팝업만 바꾸는 안이지만, 실제로는 `--r-lg`를 이미 쓰는 **큰 패널 8곳**(`.pnl`·`.db-card`·`#map-stage`·`#rank-panel` 등)도 함께 6px가 된다. 그래서 정확히는 "팝업 + 큰 패널"이다.
- `.dlg`(3214)·`.hb-menu`·말풍선을 `--r-lg`로 다시 짝짓기만 하면 된다. 고칠 곳이 가장 적다(약 5줄).
- 단추·표·칩의 각짐은 그대로 남는다. 사용자가 짚은 "표나 기타 버튼"은 해소되지 않는다.

### 은행 업무 포털(KRDS 계열)과의 적합성, 권장 이유
- 공공·금융 업무 포털은 절제된 4–8px 반경이 흔하다. 다만 KRDS 정확한 토큰 값은 이 저장소에 근거 문서가 없어 확인하지 못했고, 수치로 인용하지 않는다.
- **A를 권장하는 이유**
  1. 40px 행·12px 글자의 촘촘한 표 화면에서 4/6은 각을 빼면서도 정밀한 인상은 지킨다.
  2. 반경 3단이 층(표식 < 컨트롤 < 틀)을 나타내므로, "모든 것에 한 반경"인 SaaS 카드 키트 인상을 피한다.
  3. 칩·밑줄 탭·3px 옆줄에 부작용이 없다.
  4. 되돌리기가 `:root` 한 줄이다.
- **함께 할 것(권장, 선택)**: 4-3의 `.dlg-bar` 아랫선을 `--line`으로 바꾼다. 틀 선 색 전체를 바꾸는 것은 이번 범위 밖으로 남긴다(질문 8-2).

### 예외
- **랜딩**(`#landing-view`, `--ld-r`)은 자기 토큰이 따로 있어 영향이 없다. 다른 세션이 맞출지 정한다.
- **로그인**(`#login-view` `.login-card` 743, `.lg-primary` 755, `.lg-dot` 784)은 `--r`을 쓰므로 자동으로 바뀐다. `.lg-dot`(높이 6px)은 `--r-sm`으로 옮겨야 알약을 피한다.
- **지도**: SVG에는 반경이 없다. 판 `#map-stage`(930)와 `#rank-panel`(1028)은 `--r-lg`라 6px가 된다. 판 테두리만 둥글어지고 안의 그림은 `overflow:hidden`으로 잘린다. 지도를 각지게 두려면 이 두 곳을 `--r-sm`으로 옮긴다.
- **현황판**(`.hb-*`)과 다른 세션 구역(`.pp-*`·`.pb-*`·`.isf-*`·`.bd-*`)은 `:root` 값을 바꾸는 순간 함께 바뀐다(파일을 고치지 않아도). **적용 전에 그 세션들에 알리는 일이 필요하다.**

4. **입력**: text, select, date를 한 줄 툴바로(단추와 높이를 나란히 비교).
5. **칩**: `.pt-chip` 보통, `.pt-chip.tag.kept`(KB 옐로), `.pt-chip.tag.won`(초록), `.ad-badge.warn`.

**탭 넷(현행 / A / B / C)**: 같은 마크업에 `:root` 변수만 바꾼다. 각 탭 위에 값 한 줄을 적는다.
```css
/* 현행 */ :root{--r-sm:2px;--r:2px;--r-lg:2px}
/* A    */ :root{--r-sm:2px;--r:4px;--r-lg:6px}
/* B    */ :root{--r-sm:2px;--r:6px;--r-lg:10px}
/* C    */ :root{--r-sm:2px;--r:2px;--r-lg:6px}

.dlg,.pnl,.pt-pane,.hb-menu,.tip{border-radius:var(--r-lg);overflow:hidden}
button,input,select,textarea,.chip,.badge,.mn-card,.bd-m-warn{border-radius:var(--r)}
```

- 색은 `:root` 값(--bg #e9ecf0, --panel #fff, --panel2 #f6f7f9, --line #c3c9d1, --line-strong #6d7882, --fg #1e2124, --muted #464c53, --accent-color #0b50d0)을 그대로 쓴다.
- 글꼴은 `"Malgun Gothic"`으로 대신한다(KB 글꼴 파일은 시안 한 파일에 넣지 않음).
- 1280px 화면 기준으로 둘씩 나란히 보는 비교가 좋다(현행↔A).

### DESIGN.md 고칠 문장
- **3행**: '2px 모서리'를 '3단 모서리(2/4/6px)'로.
- **58행**: '모서리는 한 가지(2px)'를 '모서리는 세 단 — 작은 표식 2px, 컨트롤 4px, 틀·팝업 6px'로.
- **89행 전체**를 다음으로 바꾼다.
  > **모서리는 변수 세 단만 쓴다.** `--r-sm` 2px = 12px 이하 표식(견본·막대·진행선·mark·스크롤 막대), `--r` 4px = 컨트롤과 틀 안의 카드·상자(단추·입력·칩·배지·탭·세그먼트 안쪽·메뉴 항목), `--r-lg` 6px = 바탕 위에 놓인 틀과 떠 있는 것(팝업·모달·패널·띠·메뉴 상자·말풍선·표 틀·지도 판). 직접 px 값은 쓰지 않는다. 표 칸(th/td)은 0이고 표 자체에 반경을 주지 않는다 — 둥근 틀이 `overflow:hidden/auto`로 자른다. 원(50%)은 점 두 곳만 예외.
- **94·97행**: '2px'를 '`--r` 4px'로.
- **95행**: 로그인 제출 '2px 모서리'를 '`--r` 4px'로.
- **98행**: '각진 2px'를 '안쪽 `--r` 4px, 묶음 바깥 `--r-lg` 6px, 밑줄 탭(`.ap-tabs`)은 0'으로.
- **99행**: '2px 모서리'를 '`--r` 4px'로.
- **100행**: '2px'를 '바탕 위 `--r-lg` 6px, 틀 안 `--r` 4px'로.
- **126행**: '색 견본 반경 2px'를 '`--r-sm` 2px'로.
- **frontmatter 40행**: `rounded: r: "2px"`를 `sm: "2px", r: "4px", lg: "6px"`로. 47행 `tab-item-active rounded "2px 2px 0 0"`도 4px로.

### design_history 전/후 장 (적용 커밋 때 필요 — 문안)
- **전**: 모든 모서리 2px 한 값. 팝업·패널·단추·칩·견본이 같은 반경에 같은 진한 선(#6d7882, 흰 바탕 4.49:1)이라 상자 안에 상자가 겹쳐도 층이 보이지 않고 각져 보였다.
- **후**: 3단. 견본·막대 2px / 단추·입력·칩·탭 4px / 팝업·패널·메뉴 6px. 팝업 머리 아랫선을 연한 선(#c3c9d1, 1.63:1)으로 낮춰 이중 테두리를 없앴다.
- **숫자**: 팝업 2→6px, 단추 2→4px, 칩 2→4px(높이 18–24px의 1/5–1/6, 알약 아님), 견본 2px 그대로.
- **왜**: 사용자 11-27 "팝업·표·버튼이 너무 각진 느낌".

## 8. 이관 메모
