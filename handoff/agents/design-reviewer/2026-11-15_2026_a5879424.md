  - 쓰기 동작은 하지 않았습니다.
  - 체크박스 2개는 DOM에 임시로 복제해 폭만 재고 바로 지웠습니다.

## 2. 한 줄 총평 + 가장 큰 기회
- **총평**: 7종 확장 자체는 폭·색 문제가 없습니다. 다만 **지금도 마커 모양이 종류(kind)가 아니라 원래 type 문자열로 정해져 필터와 어긋나 있습니다.**

- **가장 큰 기회**: `markerShape`를 kind 기준으로 바꾸고 이번 7종 확장과 한 번에 끝내는 것입니다.
  - 그러면 "글리프 = 마커 모양 = 필터 칸"이 1:1이 됩니다.

## 3. 잘 된 점

## 4. 우선순위 이슈

**P1 — 마커 모양과 필터 칸이 어긋남(지금 있는 결함)**
- **근거**
  - `render.js` drawMarkers는 `logic.markerShape(r.type)`로 원래 type 문자열을 넘깁니다.
  - `logic.markerShape`의 map에는 '교육청'과 '지방공기업'이 없어서 둘 다 기본값 diamond로 떨어집니다.
  - 실측(둘러보기) 결과:

    | type → 필터 칸 | 그려지는 모양 | 곳 수 |
    |---|---|---|
    | 교육청 → 공공기관 | diamond | 16 |
    | 지방공기업 → 공공기관 | diamond | 8 |
    | 법원 → 법원 | diamond | 97 |

  - "법원"을 끄면 ◆ 24개가 그대로 남습니다(계산값 diamond 24).
- **왜 문제인가**: 사용자는 "법원(◆)을 껐는데 ◆가 남아 있다"고 보게 됩니다. 범례(필터 글리프)를 믿을 수 없게 됩니다.
- **수정 방향**: `markerShape`의 입력을 kind로 바꿉니다(`markerShape(logic.kindOf(r.type))`, 또는 함수 안에서 kindOf를 먼저 부르기). 표는 6절에 있습니다.

**P1 — 법원◆와 '종류를 모르는 유형'◆가 같은 모양**
- **근거**: `markerShape`의 기본값이 `'diamond'`입니다. 그리고 `visibleMarkers`는 kind가 null이면 항상 표시합니다.
- **수정 방향**: 모르는 유형은 "기타" 모양을 씁니다(6절).
  - 지금 kind가 null인 레코드는 **0건**입니다(실측: 7개 type 모두 kind가 있음). 그래서 실제 화면에는 영향이 없고 미래 방어용입니다.

**P2 — DESIGN.md 계약이 실제와 어긋남(drift)**
- **근거**: `DESIGN.md` 393–396행은 "▲ public agency, ■ public enterprise, ● university hospital, ⬟ university"라고 적혀 있습니다.
  - 법원◆이 빠져 있습니다.
  - ■ 공기업은 이미 공공기관으로 접혔습니다.
  - 병원 이름도 옛 이름입니다.
- **수정 방향**: 7종 적용 커밋에서 6절의 대체 문단으로 바꿉니다(메인이 고칩니다).

**P3 — 필터 라벨의 누르는 영역 높이 19px**
- **근거**: 실측한 label 상자는 높이 19px이고, input은 13×13입니다.
- **판단**: 24px에 못 미치지만 라벨 전체가 클릭 영역이고, 항목 사이 가로 간격이 14px입니다. 이번 범위에서는 고치지 않고 기록만 합니다.

## 6. 규격

**① 마커 모양 표**: `logic.markerShape(kind)`의 입력을 kind로 바꾸고, `render._shapePath`에 square·bar를 추가합니다.

| 종류(kind) | 모양 | `_shapePath` 정의(s=8 기준) | 필터 글리프 `.fsw`(12×12, 획 1.4, fill 없음) |
|---|---|---|---|
| 지자체 | 면(마커 없음) | — | 그대로 `<rect x="1" y="3" width="10" height="6"/>`, class `fsw fill` |
| 교육청 | **■ 정사각** | 한 변 14(±7). 같은 반지름 8이면 면적이 다른 모양보다 커 보여 7로 줄입니다. `M-7,-7 h14 v14 h-14 Z` | `<rect x="2" y="2" width="8" height="8"/>` |
| 공공기관 | ▲ | 그대로 | 그대로 |
| 대학 | ⬟ | 그대로 | 그대로 |
| 법원 | ◆ | 그대로 | 그대로 |
| 병원 | ● | 그대로(circle r=8) | 그대로 |
| 기타 | **가로 막대**(18×10, 모서리 2) | `M-9,-5 h18 v10 h-18 Z`. 모서리 둥글림이 path로 번거로우면 각진 사각형도 됩니다. | `<rect x="1" y="3.5" width="10" height="5" rx="1"/>` |
| (kind null, 모르는 유형) | 기타와 같은 가로 막대 | markerShape 기본값을 `'diamond'`에서 `'bar'`로 바꿉니다 | — |

- **기타를 막대로 고른 이유**: 비율이 1:1이 아닌 유일한 실루엣이라 16px에서도 다른 모양과 섞이지 않습니다. 다른 후보는 각각 뜻이 겹칩니다.
  - ▼: 이 제품의 ▲ = 임박(시세 상승) 어휘와 반대 뜻이 됩니다.
  - ＋: 병원·추가 버튼과 겹칩니다.
  - ★: 관심 기관 아이콘과 겹칩니다.
  - 육각형: 16px에서 ⬟·●와 구분되지 않습니다.
- **막대 안 표시 확인**: 막대 높이가 10이라 마커 안의 `!`(10px 굵게)와 날짜 미상 경고 삼각(±3.8)이 들어갑니다. hatch 패턴은 path에 그대로 씌우면 됩니다.
- **지자체 글리프와 헷갈릴 우려**: 지자체는 채운 10×6, 기타는 획만 10×5입니다. 지자체에는 "(면)" 글자가 붙어 있어 구분됩니다. 지도에서 지자체는 마커가 아니라 면이라 지도 위 충돌은 없습니다.
- **변경 없는 것**: 색(fill = `render.markerColor(urgency)`), 테두리 `#0f1420`, hatch. **새 색 토큰은 0개**입니다.

**② 필터 마크업**(`index.html` #type-filter, 1안 순서): 기존 5개 사이에 아래 2줄을 넣습니다. CSS는 바꾸지 않습니다.
```html
<!-- 종류 정본 7종(logic.TYPE_KINDS) — 값은 logic.kindOf로 판정. 글리프 = 지도 마커 모양(logic.markerShape(kind)): 지자체=면, ■, ▲, ⬟, ◆, ●, 막대 순 -->
<label><input type="checkbox" data-type="지자체" checked>…기존…지자체(면)</label>
<label><input type="checkbox" data-type="교육청" checked><svg class="fsw" viewBox="0 0 12 12" aria-hidden="true"><rect x="2" y="2" width="8" height="8"/></svg>교육청</label>
<label><input type="checkbox" data-type="공공기관" checked>…기존…</label>
<label><input type="checkbox" data-type="대학" checked>…기존…</label>
<label><input type="checkbox" data-type="법원" checked>…기존…</label>
<label><input type="checkbox" data-type="병원" checked>…기존…</label>
<label><input type="checkbox" data-type="기타" checked><svg class="fsw" viewBox="0 0 12 12" aria-hidden="true"><rect x="1" y="3.5" width="10" height="5" rx="1"/></svg>기타</label>
```
- `wireFilters`는 데이터가 없는 종류를 끄고 비활성화합니다. 재단 6곳의 type이 바뀌기 전(번들·시드 적용 전)에는 "기타"가 회색 비활성으로 보입니다. 정상 동작이니 순서상 문제는 없습니다.

**③ 지도 색 섞기(NEXT 78)와의 관계**: 충돌이 없습니다.
- 마커 색은 임박도 색 그대로이고, 면 색 섞기는 enabledTypes(kind)만 봅니다.
- 기본이 전부 켬이라 오늘 색은 그대로입니다.
- 교육청을 끄면 시도 면 색이 달라지는데, 이는 기획 보고서 §4④에서 예상한 동작입니다.

**④ DESIGN.md 393–396행 대체 문안**(메인이 적용합니다)
> Map marker silhouettes keep a fixed shape per institution kind (`logic.markerShape(logic.kindOf(type))`) — 지자체 = filled polygon face (no marker), ■ 교육청, ▲ 공공기관, ⬟ 대학, ◆ 법원, ● 병원, ▬ 기타 (also any unknown type) — mirrored 1:1 by the `.fsw` stroke glyphs in the control strip, in the same order as `logic.TYPE_KINDS`.
