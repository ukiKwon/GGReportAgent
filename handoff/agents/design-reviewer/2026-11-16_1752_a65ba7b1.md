## 4. 우선순위 이슈

**P1-1 공고 진행 절과 금고 절이 서로 다른 말을 함**

## 5. 문구 / 접근성

**문구**
- 절 제목은 '현재 금고 은행'을 그대로 둡니다. 출처 표지는 **'직접 입력'**과 **'수집'** 두 낱말로 고정합니다. '수동'·'MANUAL'·'origin'은 쓰지 않습니다.
- 입력자 줄: `입력 {editor_name} · {saved_at 날짜 YYYY-MM-DD}`. '검증됨·확인됨·인증' 낱말은 어느 경우에도 쓰지 않습니다. 그래서 emp_verified=true와 시안 A가 같은 모양이 됩니다.
- '확인일'은 출처를 본 날짜(명사)라서 금지 대상이 아니라고 판단했습니다. 출처 줄에서는 `2026-11-10 확인`이 아니라 **`확인일 2026-11-10`** 형태로 써서 상태어처럼 읽히지 않게 합니다.
- 담당자 확인 안내: `담당자 확인은 기관 부서명만 적습니다. 담당자 이름·전화번호는 적지 않습니다.` 서버가 PII·전화를 422로 막으므로 미리 알립니다.
- 오류 문구는 서버 문구를 그대로 씁니다(설계 6절).
- 화면 고정 문구:
  - 201: `금고 약정을 저장했습니다.`
  - 200 NO_CHANGE: `바뀐 내용이 없어 저장하지 않았습니다.`
  - 409 STALE: 서버 문구 + `최신 기록을 불러왔습니다. 확인한 뒤 다시 저장하세요.`
  - 지우기 완료: `금고 약정을 지웠습니다. 지운 기록은 이력에 남습니다.`
- 현황판 숫자 미포함 안내는, 직접 입력 CURRENT 은행이 KB국민은행이고 수집값(c.kb)이 없을 때만 씁니다: `직접 입력한 약정은 입찰 현황판 '국민은행이 맡은 기관' 수에 넣지 않습니다.`

**접근성(수치)**
- 대비(계산): --muted #98a1af / --panel #181e29 **6.4:1**, --orange #d9a05b / --panel **7.3:1**, --fg / --panel2 12:1 이상. 새 색은 없습니다.
- '수집 기록과 다름'은 색만으로 전달하지 않습니다. 주황 글자 + 낱말로 씁니다.
- '만료' 칩은 회색 테두리 + 낱말이고, 빨강은 쓰지 않습니다. 빨강은 임박도 전용입니다.
- 폼:
  - 모든 입력은 `<label>` 안에 둡니다. 필수 칸은 라벨 끝에 `(필수)` 글자 + `aria-required="true"`를 붙입니다.
  - 출처 종류를 바꿔 숨긴 칸은 `hidden`으로 빼서 탭 순서에서도 빠지게 합니다.
  - 오류는 기존 `#ie-bank-err role=alert`로 냅니다. 해당 칸에는 `aria-invalid` + `aria-describedby="ie-bank-err"`를 답니다.
  - maxlength는 서버 한도와 맞춥니다: 기타 은행 30, 부서 50, 비고 100.
- 지우기 확인은 인라인 `role=group`(기존 `hc-confirmbox` 패턴)으로 만들고, 열리면 [그대로 두기]에 포커스를 둡니다.
- 상세 [금고 약정 입력]으로 창을 열면(`focus:'bank'`) 그 묶음을 `scrollIntoView` 하고 첫 컨트롤에 포커스를 줍니다. 닫으면 opener 버튼으로 돌아갑니다(기존 closeNow).
- escape 대상: bank_name_etc·checked_dept·note·editor_name·src_no는 모두 `esc()`, 링크는 `logic.safeHttpUrl` → `esc` → 새 창(기존 `ie.srcInner` 재사용).

3. CURRENT도 수집값도 없고 PAST만 있으면 가장 최근 PAST 한 줄을 '만료'로 그립니다.
4. 아무것도 없으면 기존 '미확인' 갈래를 그립니다.

  - 시안 B(자기신고 표지)는 emp_verified=false일 때만 끝에 ` · 본인이 등록한 이름`을 붙입니다(11px muted, 칩 아님). 정확한 의미와 문구는 기획 확인 대기입니다.
