## 4. 우선순위 이슈
- **P2. 링크에 스타일을 주지 않으면 거의 보이지 않습니다.**
  - 근거: `.db-foot`에는 `a` 규칙이 없고(index.html 1590–1592행), 전역 `a` 규칙도 없습니다.
  - 왜 문제인가: 브라우저 기본 파랑 #0000ee는 패널 #181e29 위에서 **1.78:1**입니다.
  - 수정 방향: 6-1의 `.hb-src a` 규칙을 함께 넣습니다.
- **P2. 와플 아래 문구가 데이터와 어긋나게 됩니다.**
  - 근거: 지금 문구는 "미확인은 '아님'이 아니라 '아직 모름'입니다."(dashboard.js 593행)입니다. data-auditor 판단은 243곳 전부를 표와 맞출 수 있고 국민은행이 아닌 곳이 227곳이라는 것입니다.
  - 왜 문제인가: 사실을 알면서도 '모름'이라고 말하게 됩니다.
  - 수정 방향: 6-2 규격으로 바꿉니다.
- **P3. P3-8(저장한 행이 목록에서 사라짐) — 안내가 필요합니다.**
  - 근거: 저장한 뒤 `n.load()`로 목록을 다시 그리면 그 행이 지금 보기에서 빠지고, 상세는 열린 채 남습니다(dashboard.js 1093–1097행). 반면 보기를 직접 바꿀 때는 상세를 닫습니다(1119행). 같은 '빠짐'인데 두 경우가 다르게 움직입니다.
  - 왜 문제인가: 사용자는 왼쪽 목록에서 선택된 행이 사라진 것을 저장 실패나 오류로 읽기 쉽습니다.
  - 수정 방향: 6-3 문구를 저장 완료 메시지 뒤에 붙입니다.
- **P3. `footHtml`이 `s.muni`를 보지 않습니다.**
  - 근거: kbboard.js 62–64행에서 '지자체는 …' 문장을 항상 씁니다.
  - 지금은 `OURS_SCOPE.muni`가 코드 상수 true뿐이고 사용자가 끄는 필터가 없어서 실제로 생기지는 않습니다.
  - 그래도 출처 링크를 넣는 김에 muni가 false면 지자체 문장과 출처 줄을 같이 빼는 조건을 둡니다(6-1).
- **P3. 새 탭으로 열린다는 정보가 화면 읽기 프로그램에 전달되지 않습니다.**
  - 앱 전체의 외부 링크 5곳이 모두 그렇습니다.
  - 이번 링크에는 sr-only로 ", 새 탭"을 넣고(6-1), 나머지 4곳은 같은 규칙으로 다음에 맞추도록 이관합니다.

## 5. 문구 / 접근성
**문구**
- 출처 이름은 사용자가 아는 공문 이름 '행안부 금고지정 현황'을 링크 글자로 씁니다. 사이트 이름 '지방재정365'는 링크 글자에 넣지 않습니다. 각주가 지금 쓰는 말과 같아야 찾기 쉽습니다.
- 'FSL409'·'curl' 같은 내부 용어는 화면에 나오지 않습니다.
- 와플 범례 '확인/미확인'을 '국민은행/다른 은행'으로 바꿉니다. 목록의 '2027년부터' 묶음과 겹치지 않도록 기준일을 문장에 반드시 같이 적습니다(data-auditor 제한 1).
- P3-8 안내의 보기 이름은 탭 글자 그대로 대괄호로 씁니다: [미처리], [지연·재공고 대기], [처리됨]. 앱에서 버튼 이름을 [기록 저장]처럼 적는 관례와 같습니다.

## 6. 규격

### 6-1. 현황판 각주 출처 링크 (kbboard.js `footHtml`)
**자리:** 지금 문장 안의 '행안부 금고지정 현황(2026.1.1. 기준)의'를 빼고, 각주 **마지막 줄에 출처 한 줄**을 따로 둡니다.
- 문장 중간에 링크와 '(인터넷 PC에서 열림)'을 넣으면 "(…)(인터넷 PC에서 열림)의 1·2금고"처럼 괄호가 겹칩니다.
- 출처를 끝에 따로 두면 각주를 읽는 순서(규칙 다음 출처)와도 맞습니다.

**모두 켰을 때(현재 기본) — `kbb.footHtml(undefined, 7)`의 새 기대값:**
```
지자체는 1·2금고, 법원은 공탁금 보관은행, 공공기관은 주거래은행 칸으로 셉니다. 2027년부터는 지정 결과 공고·기사로 확인한 곳입니다. 은행 칸이 빈 법원·공공기관 <b>7</b>곳은 세지 않았습니다.<span class="hb-src">지자체 출처: <a href="https://www.lofin365.go.kr/portal/LF8310000.do?curPage=1&amp;ntcaClsDvCd=FSL409" target="_blank" rel="noopener noreferrer">행안부 금고지정 현황(2026.1.1. 기준)<span class="sr-only">, 새 탭</span></a> <span class="db-why">(인터넷 PC에서 열림)</span></span>
```
**법원·공공기관을 껐을 때 — 79행 기대값:**
```
지자체는 1·2금고만 셉니다. 법원·공공기관은 아직 세지 않습니다.<span class="hb-src">지자체 출처: …(위와 같은 링크)…</span>
```
**규칙**
- `s.muni === false`이면 '지자체는 …' 문장과 `.hb-src` 줄을 둘 다 넣지 않습니다. 비지자체 기관에는 이 표가 근거가 아니기 때문입니다(data-auditor 제한 2). 이 경우의 문장은 기획 확인이 필요하며, 지금 화면에서는 생기지 않습니다.
- 주소는 상수 하나(`kbb.LOFIN_FSL409_URL` 같은 이름)로 두고 `logic.safeHttpUrl`과 `esc`를 거칩니다. 빈 값이면 링크와 '(인터넷 PC에서 열림)'을 빼고 글자만 남깁니다(plans.js 114행과 같은 방식).
- 테스트에 하나를 더합니다: `assert.ok(on.indexOf('우리') < 0)`처럼 `muni:false`일 때 `'금고지정'`이 없는지.

**CSS (index.html, kbboard 블록 1726행 아래)**
```css
.hb-src { display:block; margin-top:6px; }
.hb-src a { color:var(--fg); text-decoration:underline; text-decoration-color:var(--accent-color); text-underline-offset:3px; }
```
- 글자 크기는 `.db-foot`의 12px을 물려받고 새 색은 없습니다. `.db-foot a` 전체에 걸지 않고 `.hb-src`로 범위를 좁힙니다. `.db-foot`는 입찰 공고 현황 목록과 같이 씁니다.
- 폭 계산: 1280폭에서 목록 칸은 약 560px, 안쪽은 약 520px입니다. 출처 줄은 약 385px이라 **한 줄**에 들어갑니다. 각주 전체는 지금보다 1줄 늘어납니다.

### 6-2. 와플 카드 문구 (지금 `dash.kbCardHtml`·`dash.waffleHtml` 자리)
data-auditor 문안("국민은행 금고 없음 227곳 / 전체 243곳 (일반·특별·기금 …)")을 카드 크기에 맞게 나눕니다.
- 숫자 227은 따로 보이지 않습니다. 243에서 16을 빼면 되고, 칸 수로 보입니다.
- '1금고 5·2금고 11' 줄은 넣지 않습니다. 목록 머리 요약(`summaryHtml`, '1금고 n · 2금고 n')과 겹칩니다.

```html
<section class="db-card" aria-labelledby="db-t1"><h2 id="db-t1">국민은행 금고 약정</h2>
<p class="fig">지자체 <b>243</b>곳 중 국민은행 <b>16</b>곳</p>
<div class="waf" role="img" aria-label="지자체 243곳 중 국민은행이 금고를 맡은 곳 16곳, 2026년 1월 1일 기준">…칸…</div>
<p class="lg"><span><i class="k"></i>국민은행</span><span><i></i>다른 은행</span></p>
<p class="note">행안부 금고지정 현황(2026.1.1. 기준)에서 회계 하나라도 국민은행이 맡은 지자체입니다. 2027년부터 바뀌는 곳은 목록의 '2027년부터' 묶음에 있습니다.</p></section>
```
- 숫자는 모두 계산값(`kbCount`의 total·confirmed)이고 243·16을 코드에 박지 않습니다. CSS는 바꾸지 않습니다(.fig 13px, b는 16px 고정폭 숫자, .lg·.note 12px).
- 오른쪽 카드 안쪽은 약 370px(계산값)입니다. 안내 문장은 약 3줄이고, 와플 27칸 폭은 294px입니다.

**상태별 모양**
- 국민은행 금고 자료가 비어 있음(`KB()`가 비었거나 없음): fig 자리에 "국민은행 금고 자료를 불러오지 못했습니다. 화면을 새로 고치세요."만 둡니다. 와플·범례·안내는 넣지 않습니다. 이유: 0곳 와플을 그리면 근거 없이 '모두 다른 은행'이라고 말하게 됩니다.
- 기관 목록을 받는 중: 기존 `db-state` 문구 "불러오는 중입니다…"를 씁니다.

**테스트 기대값:** 카드에 `'지자체 <b>243</b>곳 중 국민은행 <b>16</b>곳'`, `'다른 은행'`, `'2026.1.1. 기준'`이 있고 `'아직 모름'`은 없어야 합니다.
