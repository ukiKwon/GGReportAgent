## 2. 한 줄 총평 + 가장 큰 기회
- 엑셀 머리줄을 그대로 옮긴 2단 머리 표(가로 스크롤, 기관 이름 열 고정)에 **칸 메뉴 4값**, **칸 정보 줄**, **상세는 같은 자리에서 바꿔 보기(← 대시보드로)** 를 붙이면 계약 범위 안에서 된다.
- **가장 큰 기회**: 행 하나를 왼쪽에서 오른쪽으로 읽으면 "이 기관이 어디까지 왔는지"가 보이게 하는 것. 완료 칸은 파랑 10% 틴트, 진행 칸은 주황 10% 틴트로 칠하고 글리프 모양을 함께 둔다(색만으로 전하지 않는다). 그러면 27칸을 하나씩 읽지 않아도 진행 경계가 보인다.

## 3. 잘 된 점(계약 쪽)
- 날짜를 서버가 KST로 정하고(`marked_on`) `done_date`는 무시한다. 그래서 화면에 날짜 입력칸이 필요 없고, 사용자 답 "날짜 입력 없음"과 맞는다.

### 5-2. 접근성 수치(계산값, 실측 아님)
- 표: `<table role="grid" aria-labelledby="pb-title" aria-rowcount aria-colcount>`.
  - Tab 정지는 표 안에서 **하나**(roving tabindex).
  - 행 20개 × 29칸이면 버튼이 580개다. 모두 Tab에 넣으면 키보드 사용자가 표를 지나갈 수 없다.
- 표 안 키
  - ←→↑↓: 칸 이동
  - Home/End: 행의 처음·끝
  - Ctrl+Home/End: 표의 처음·끝
  - Enter·Space: 손 칸이면 메뉴를 열고, 이름 칸이면 상세를 연다.
  - 이동한 칸은 `scrollIntoView({block:'nearest',inline:'nearest'})`로 보이게 한다. 스크롤 상자에 `scroll-padding:64px 0 0 176px`을 둬서 고정 머리·고정 열 밑으로 숨지 않게 한다.
- 손 칸: `<td role="gridcell"><button class="pb-mk" aria-haspopup="menu" aria-expanded="false" aria-label="청주시 이사회 사무국: 완료, 2026-11-20 김영업 체크">`.
- 자동·공고·잠긴 칸: `td role="gridcell" tabindex="-1" aria-readonly="true"`. aria-label에 '자동, 시스템이 채움'을 넣는다.
- 머리: 묶음은 `th scope="colgroup" colspan`, 하위 칸은 `th scope="col"`, 이름은 `th scope="row"`.
- 메뉴: 기존 `.hb-menu` 문법(`role="menu"` + `menuitemradio aria-checked`)을 그대로 쓴다.
  - ↑↓·Home/End로 움직이고, 1–4로 바로 고르고, Enter·Space로 고른다.
  - Esc·Tab·바깥 클릭이면 저장 없이 닫고 포커스는 칸 버튼으로 돌아간다.
  - 열면 현재 값 항목에 포커스를 둔다.
- 알림: 저장 성공은 `#pb-live`(sr-only, `role="status"`). 실패는 `#pb-err`(`role="alert"`, 보이는 줄). 칸 정보 줄은 화면용이라 live로 두지 않는다(화살표마다 읽히면 소음).
- 대비(흰 바탕 기준)
  - 완료 글리프 `--blue` #0a65ab: 6.1:1, 파랑 10% 틴트 위 5.2:1
  - 진행 글리프 `--orange` #8a5c00: 5.8:1, 주황 틴트 위 5.1:1
  - 날짜 `--muted` #464c53: 틴트 위 7.5:1 이상
  - 이름 링크 `--accent-color` #0b50d0: 약 6.6:1
  - 포커스 링 2px 포인트 파랑, 안쪽(offset −2px): 고정 열·틴트 위에서도 링이 칸 안에 그려져 잘리지 않는다.
- 터치 대상: 손 칸 버튼 60×44px. 메뉴 항목 높이 약 28px(.hb-menu와 같음, AA 24px 이상).
- 색 단독 금지: 상태는 글리프 모양(체크·세모·가로줄)과 이름(aria)이 전하고 틴트는 보조다. 끝난 행은 칩 '확정 취소' 글자로 알린다. 흐림(opacity)을 쓰지 않는다(대비가 떨어진다).
- 줄인 움직임: 새 움직임이 없다.

## 6. 규격

### 6-1. 배치(1280×800 기준 계산)
```
[대시보드 — 제안 확정한 기관의 …]                                         (.tm-head)
[기관 이름 검색____] [담당자 ▾] [☐ 취소·중단한 건도 보기]     기관 12곳  불러온 시각 10:32 [새로 고침]   (.pb-bar)

```
- 작업 영역 폭은 1280 − 메뉴 248 − 여백 28 ≈ 1004px. 고정 이름 열 176px을 빼면 칸 영역이 약 828px이다. 공고 104px + 손·자동 칸 60px로 **약 13칸이 한 화면에 보이고** 나머지는 가로 스크롤이다. 표 전체 폭은 176 + 104 + 28×60 = **1960px**.
- 머리 두 줄
  - 1행 28px: 묶음 이름. 묶음이 없는 열은 `rowspan=2`, 아래 맞춤.
  - 2행 36px: 하위 칸 이름. 12px 2줄, `word-break:keep-all`. 예: '협약서 / (법률)'.
  - 모두 `position:sticky`(top 0 / 28px).
- 열 순서는 서버 `columns[]` 순서다(엑셀 B→AB, 사용자 답 '영업추진 흐름'). 묶음의 첫 칸과 묶음 머리에는 왼쪽 1px `--line-strong` 구분선을 둔다. 나머지 열 사이 선은 `--line`이다.
- 이름 열: `position:sticky; left:0`. 오른쪽 1px `--line-strong` 선이 그림자를 대신한다(그림자 금지).
  - 1줄: 기관 이름. 13px/700, `can_view`면 링크 단추, 아니면 글자.
  - 1줄 뒤: '내 담당' 칩(`can_check`) 또는 '확정 취소' 칩(`ended`).
  - 2줄: '담당 …' 12px `--muted`, 말줄임.
- 칸 높이 44px. 안에 글리프 14px, 그 아래 날짜(12px 모노 `--muted`). 날짜 형식은 올해면 `MM-DD`, 다른 해면 `YYYY`. 전체 날짜는 칸 정보 줄과 메뉴 머리에 나온다.
- 880px 이하: `.pb-bar`가 줄바꿈되고, 표는 같은 규칙으로 스크롤한다(구조를 숨기지 않는다).

### 6-2. 칸 종류별 모양
| kind / 상태 | 모양 | 누름 |
|---|---|---|
| NOTICE | `.wf-badge.pp-neutral` 칩, `notice_status_name`(색 매핑 없음 — 공고 상태 4종 색 의미는 정한 적 없음) | 안 됨(gridcell 읽기 전용) |
| AUTO | 상태 글리프 + 날짜. 머리 2째 줄 '자동'. hover·커서 변화 없음 | 안 됨 |
| MANUAL, can_check | `<button class="pb-mk">`, hover `--fg` 6% | 메뉴 |
| MANUAL, can_check=false | 같은 모양, 버튼 아님 | 안 됨(칸을 고르면 정보 줄만) |
| DONE | 체크 글리프 `--blue`, 칸 바탕 `--blue` 10% | |
| IN_PROGRESS | 세모 글리프 `--orange`, 칸 바탕 `--orange` 10% | |
| NA | 가로줄 글리프 `--muted`, 바탕 없음 | |
| NONE | 비움 | |
| 저장 중 | 고른 값을 바로 그리고 칸 안 1px 점선(`--line-strong`, offset −4px), `aria-busy`. 그 칸만 다시 누를 수 없다(다른 칸은 됨) | |
| 저장 실패 | 이전 값으로 되돌리고 칸에 안쪽 2px `--red` 테두리. `#pb-err`에 원인·할 일. 다음 저장이 성공하거나 새로 고치면 지운다 | |
| 끝난 행 | 글자·글리프 `--muted`, 틴트 없음, 모든 칸 읽기 전용 | |

- `saved:false`(같은 값)는 메시지 없이 메뉴만 닫는다.
- 성공하면 응답 `cell`로 그 칸만 바꾼다(`rev_no`·`marked_on`·`by_name`). 표 전체를 다시 불러오지 않는다.

### 6-4. 상태 화면
- **처음 불러오기**: 머리(열 목록)가 응답에서 오므로 표 자리에 `<p class="wf-empty">불러오는 중…</p>`을 둔다. `#pp-board aria-busy="true"`.
- **새로 고침**: 표는 그대로 두고 단추만 '새로 고치는 중…'으로 바꾼다. 끝나면 스크롤·포커스를 유지하고 시각을 바꾼다.
- **빈 상태·거른 결과 없음·오류·권한 없음·file·로그인**: 표 자리 하나에 `.wf-empty`와 단추를 둔다(5-1 문구).
- 거르기(이름·담당자)는 화면에서만 걸러서 다시 부르지 않는다. 체크박스는 `include_ended=true`로 다시 부른다.
