## 3. 결정별 규격

### A. 이름 [제안 확정] → [제안 사전준비], 확정은 현황판에서만
- **버튼 이름**: 현황판 툴바, 그리고 현황판에서 연 상세 팝업(screen==='bid_board')의 주버튼 이름은 **[제안 사전준비]**다.
  - '이 기관의 제안 사전준비로 간다'는 명사형이다. 그래서 시작 전(확정 후 이동)과 진행 중(바로 이동) 두 경우를 같은 이름으로 덮는다.
- **확인 상자의 실행 동사**: **[확정하고 이동]**.
  - '사전준비 시작'은 쓰지 않는다. 사전준비가 실제로 시작되는 때는 다음 화면에서 담당자를 정한 뒤이므로 사실과 다르다.
- **공고 전 경고**: 굵은 질문형 경고(EARLY_ASK '아직 공고 확인 전입니다. 계속 진행하시겠습니까?')와 [계속 진행] 버튼 분기는 **없앤다**. 대신 상자 안의 평문 한 줄로 낮춘다.
  - 이유 ①: 목표 기관이 이미 팀장 결재를 거쳤다.
  - 이유 ②: 같은 동작의 이름이 둘(확정하기/계속 진행)로 갈리면 안 된다.
  - 다만 '공고 전'은 데이터에 근거한 사실이므로 알리기는 남긴다.
- **다른 화면**(지도 팝업·입찰 공고 현황 목록 칸·포털 상세) **세 상태**:

| 상태 | 모양 | 문구 | aria |
|---|---|---|---|
| 목표 아님(관심 포함) | 보통 테두리 단추(채움 아님) | **목표에 넣기…** | aria-haspopup="dialog", aria-label="{기관} 목표에 넣기" |
| 목표 넣기 결재 중 | 단추가 아니라 잠금 칩(`.hb-pend`와 같은 모양: 잠금 SVG+글자) | **목표 결재 중** | 칩 뒤 sr-only ". 목표 기관 결재가 진행 중이라 다시 요청할 수 없습니다" |
| 목표 기관 | 칩 `목표 기관`(앞에 체크 SVG `CK` 재사용, 18% 틴트 없는 회색 칩) + 보통 단추 | 칩 **목표 기관** · 단추 **입찰 현황판에서 열기** | 단추 aria-label="{기관} 입찰 현황판에서 열기" |
| 사전준비 중 | 지금의 [사전준비 열기] 그대로 | — | — |

- '[목표 기관 +]'와 '✓'는 **문자 아이콘 금지**(DESIGN.md 105) 위반이다. 그래서 '목표에 넣기…'를 쓴다. 이 문구는 kbboard.js 285·859에 이미 있다(용어 일관).
- 체크 표시는 SVG를 쓴다.
- [입찰 현황판에서 열기]를 누르면 현황판을 열고 그 줄로 스크롤해 체크박스에 포커스를 준다.
  - 현황판에 고른 기관이 0곳이면 그 줄을 골라 둔다. 그러면 [제안 사전준비]가 바로 켜진다.
  - 이미 고른 기관이 있으면 고르기는 바꾸지 않는다. 남의 선택을 조용히 지우지 않기 위해서다.
- **순서**(지도 팝업): [♥ 관심] 다음에 [목표에 넣기…]를 둔다. 개인 동작이 먼저, 결재 동작이 나중이다. 가장 무거운 동작을 오른쪽 끝에 둔다.

### B. 툴바 [제안 사전준비]
**위치**: .hb-top 안, `#hb-ours-btn` 다음, `#hb-add` 바로 앞에 둔다. 채운 [목표 기관 추가]는 오른쪽 끝에 남긴다.

**마크업**
```html
<button type="button" id="hb-prep" aria-haspopup="dialog" aria-disabled="true" aria-describedby="hb-prep-why" title="표에서 기관 하나를 고르면 켜집니다." hidden>제안 사전준비</button><span id="hb-prep-why" class="sr-only">표에서 기관 하나를 고르면 켜집니다.</span>
```

**CSS**: 채운 버튼은 쓰지 않는다. 채운 예외 4곳에 넣지 않고 테두리 버튼으로 간다(DESIGN.md 95 "화면당 하나").
```css
#hb-prep { height:32px; padding:0 14px; font-size:12px; }               /* 기본 단추: 흰 바탕·1px --line-strong — #hb-add와 높이만 맞춤 */
#hb-prep[aria-disabled="true"] { opacity:.55; cursor:default; }
#hb-prep[aria-disabled="true"]:hover { background:var(--panel); border-color:var(--line-strong); }
.hb-top #hb-prep[hidden] { display:none; }
```
- `disabled` 대신 `aria-disabled`를 쓴다. 꺼져 있어도 Tab으로 닿아 이유를 들을 수 있게 하기 위해서다. #hb-ours-btn과 같은 방식이다.
- 꺼진 상태에서 누르면 아무것도 실행하지 않는다. 대신 이유 문장을 상태 줄(#hb-flash, 일반색)에 한 번 쓴다.

**상태 표**: paintSel()에서 함께 칠한다. 대상 = `gs.sel.ids[0]`.

| 조건 | hidden | aria-disabled | 이유 문장(#hb-prep-why·title) | 누르면 |
|---|---|---|---|---|
| 확정 권한 역할 아님(영업팀·영업팀장 밖)·보기 전용·서버 미연결 | true | — | — | — |
| 0곳 | false | true | 표에서 기관 하나를 고르면 켜집니다. | 상태 줄에 이유 |
| 2곳 이상 | false | true | 기관을 하나만 고르세요. 지금 {n}곳을 골랐습니다. | 〃 |
| 1곳, 관심 기관 | false | true | 관심 기관은 목표 기관이 된 뒤에 시작합니다. | 〃 |
| 1곳, 목표, 판정 wait | false | true | 제안 진행 상황을 확인하는 중입니다. | 〃 |
| 1곳, 목표, closed/past/nobid/delayed | false | true | dash.CONFIRM_WHY[act] 그대로 | 〃 |
| 1곳, 목표, confirm(공고 전 포함) | false | false | {지역} {기관명}을 확정하고 제안 준비 현황으로 갑니다. | 확인 상자 |
| 1곳, 목표, open(이미 진행) | false | false | {기관명}은 사전준비 중입니다. 누르면 그 화면으로 갑니다. | 바로 goPrep, aria-haspopup 제거 |

- 이유 문장에 기관 이름을 넣는다. 고른 줄이 탭·연도·거르기 때문에 화면 밖에 있을 수 있다(selStatusHtml의 '이 화면 밖 n곳'). 이름 없이 누르면 엉뚱한 기관을 확정할 수 있다.

**확인 상자**: `dlg.confirm`, DESIGN.md 103 형식. 첫 포커스는 [취소]다. 상자를 쓰는 이유는 기관을 고른 자리(표 아래 띠)와 단추(맨 위)가 멀기 때문이다. 상자가 기관 이름을 다시 보여 주는 것이 오조작 방지의 핵심이다.
```text
제목: 제안 사전준비 — {지역} {기관명}
본문 1: {기관명}을 제안 대상으로 확정합니다.
본문 2: 확정하면 [영업 추진 준비 › 제안 준비 현황]의 이 기관 화면으로 넘어갑니다. 그 화면에서 담당자를 정하면 사전준비가 시작되고, 영업팀장에게 알림이 갑니다.
(공고 전일 때만) 본문 3: 아직 입찰 공고 전인 기관입니다. 공고가 나면 일정을 다시 확인하세요.
본문 4: 담당자를 정하기 전까지는 확정한 사람과 영업팀장이 취소할 수 있습니다.   ← 서버 규칙 확인 전까지 넣지 않음(7절 이관)
아래: [취소] [확정하고 이동]
보내는 중: [확정하고 이동]을 disabled로 바꾸고 글자는 '확정하는 중…'
```
- **성공**: 메뉴를 열고 goPrep으로 그 기관 상세로 간다. 도착한 화면의 상태 줄에는 prep.js T.okConfirm 문구가 뜬다.
  - 새 문구: **'{기관}을 제안 확정했습니다. 담당자를 정하면 사전준비가 시작됩니다.'**
  - 지금 문구 '다음은 [개설 신청]입니다'는 없어진다.
- **PREP_ALREADY_ACTIVE**: 오류 문구 없이 바로 goPrep한다.
- **실패**: 현황판 상태 줄(#hb-flash, 오류 role=alert)에 '{기관}을 제안 확정하지 못했습니다. {원인}. 잠시 뒤 다시 시도하세요.'를 쓴다. 권한 오류 문구는 '제안 사전준비를 시작할 권한이 없습니다({status}). 로그인 사번과 권한을 확인하세요.'다.
- **현황판에서 연 상세 팝업(bid_board)**: 주버튼은 [제안 사전준비]다. 펼침 상자(db-confirm)는 그대로 두고 위 본문 1~3과 [확정하고 이동][취소]로 문구만 맞춘다. 팝업 위에 팝업을 겹치지 않는다.
  - dashboard.js 1034·1060의 '개설 신청 전까지는…' 문장은 본문 2로 바꾼다. 1571(입찰 공고 현황 doConfirm)은 A에 따라 경로 자체가 없어진다. 1938의 대체 문구는 '{기관}을 제안 확정했습니다. [영업 추진 준비 › 제안 준비 현황]에서 담당자를 정하세요.'로 바꾼다.
- **줄마다 있던 [제안 확정](kbboard.js 306)은 없앤다.** 입구가 셋(줄 단추 → 팝업, 팝업, 툴바)이 되고 확인 방식도 둘로 갈리기 때문이다. 단계 칸 act==='confirm' 자리는 다음 마크업으로 바꾼다.

- **파일 모드 배너**(kbboard.js 1622·1623, dashboard.js 1120·1121): '[제안 확정]'을 '[제안 사전준비]'로 바꾼다.

### C. 구분 칩 메뉴 = 구분만, 빠지는 동작의 새 입구
**메뉴 규격**(kbb.menuHtml)
```html
<div class="hb-menu" role="menu" aria-label="구분 고르기" aria-describedby="hb-menu-sug">
  <div class="mh" id="hb-menu-sug">자동 제안: 재유치 도전 — {근거}</div>      <!-- def.tag 있을 때만. 없으면 aria-describedby도 뺀다 -->
  <button type="button" role="menuitemradio" aria-checked="true" data-tag="RETAIN" tabindex="-1"><span>재유치 도전</span>{CK}</button>
  …
</div>
```
- **'자동 제안' 머리 줄은 유지한다.** 남는 유일한 선택(구분)의 근거라서다.
  - 지금은 role 없는 div라 화살표로 움직이면 낭독되지 않는다. 그래서 `aria-describedby`로 메뉴 열 때 한 번 읽히게 한다.
- `judgeText`(달성 판정일)는 메뉴에서 뺀다. 협약 개시일과 같은 묶음이므로 아래 [수정하기…] 창으로 옮긴다.
- 구분선·'결재 필요' 머리글·메모·개시일·옮기기·빼기 항목은 모두 없앤다.
- aria-label은 '목표 기관 동작'·'내 관심 기관 동작'에서 **'구분 고르기'** 하나로 바꾼다. 메뉴에 동작이 남지 않으므로 이름이 사실과 맞아야 한다.
- 관심 줄 메뉴도 구분만 둔다.

**새 입구 비교**

| 안 | 내용 | 판정 |
|---|---|---|
| ① 띠에 [결재 요청…] 단추 추가 | 띠 단추 2개 | ✗ 7163e0a9의 띠 축소와 E(오른쪽 끝 하나)에 어긋남 |
| ② [수정하기…] 창의 줄마다 '동작' 칸에 바로 반영과 결재를 섞음 | 한 번 보내기에 결재·바로 반영이 섞임 | ✗ 사유 칸·보내기 이름([수정하기]/[결재 요청])이 줄마다 달라 헷갈림 |

### D. 구분을 바꾸면 그 줄 자동 체크(목표 줄만)
- **조건**: 구분 저장이 **성공한 뒤에만** 체크한다. 이미 체크돼 있으면 그대로 둔다(풀지 않는다). 20곳 한도면 체크하지 않고 CAP_MSG를 띄운다. 관심 줄·결재 중 줄은 체크하지 않는다.
- **피드백**: 띠 등장만으로는 **부족하다**.
  - 0곳→1곳일 때는 띠가 올라오는 움직임이 신호가 된다. 1곳 이상일 때는 숫자만 바뀌어 눈에 띄지 않는다.
  - 자동으로 고른 줄이 다음 일괄 동작에 섞이거나, B의 [제안 사전준비]를 '2곳'으로 꺼 버리는 일이 생긴다. 이유를 한 번 말해야 한다.
  - 띠 숫자 문장에 이유 한 줄을 붙인다. `gs.selMsg`를 재사용하되 **주황(.lim) 대신 일반 글자색 클래스를 쓴다**(경고가 아니라 알림이므로).
  ```html
  <span class="sr-only">구분을 바꾼 노원구청을 골라 두었습니다. 고른 목표 기관 2곳</span>
  <span aria-hidden="true">고른 목표 기관 <b>2</b>곳</span><span class="note" aria-hidden="true">구분을 바꾼 노원구청을 골라 두었습니다</span>
  ```

  ```css
  .hb-selbar .note { color:var(--muted); font-weight:400; }   /* 대비 #464c53 on 12% 파랑 틴트 ≈ 8.5:1 */
  ```
  - 이 알림은 다음 고르기 조작 때 지운다(지금 selMsg와 같음).
  - 포커스는 메뉴를 닫은 뒤 구분 칩으로 돌아간다(지금과 같음). 체크박스로 옮기지 않는다.
