## 4. 우선순위 이슈

**P1-1. 사용자 1순위가 화면 뼈대에 없다 (전)**
- 근거: 1280×800 실측. `#hb-notice` 305×632px에 "지금 공고가 난… 없습니다" 한 문장뿐이다. 가장 넓은 열은 `#hb-ours` 350px(협약 중인 기관 — 사용자가 후순위로 지정)다.
- 왜 문제인가: 사용자 11-17 "현황이 눈에 안 들어오면 현황판 기능을 잃은 것"에 그대로 해당한다.
- 수정 방향: 6절 배치로 바꾼다(요약 띠 → 목표 표 → 접힌 협약).

**P1-2. planner안의 타임라인과 표가 같은 행을 두 번 그린다**
- 근거: 높이 예산. 머리 30 + 타일 100 + 타임라인(N행) + 표 머리 40 + 표(N행) + 협약 40을 합치면, 목표 8곳만 돼도 800 높이를 넘는다.
- 왜 문제인가: 같은 기관을 두 그림에서 눈으로 맞춰 봐야 한다(인지 부하).
- 수정 방향: 타임라인을 **표의 7번째 열(12개월 레인)**로 합친다. 오른쪽 '현 금고 은행' 막대는 요약 띠의 4번째 칸으로 옮긴다. '준비 단계 누적 막대'는 뺀다. 건수가 적어 표의 단계 열이 같은 정보를 더 정확히 준다.

**P1-3. 빈 상태 후보에 이미 다음 회차가 정해진 기관이 섞인다**
- 근거:
  - 현재 화면에서 '종료 1년 안 8곳' 중 광진·노원·도봉·동대문 줄에 '다음도 국민은행' 칩이 있다.
  - 회차 소식에 "2026 회차 국민은행 수성(기사 2026-11-04)"이 있다.

**P2-1. planner의 `●●●○○ 3/5`는 DESIGN.md 금지 사항이다**

- 수정 방향: 30×4px 진행 막대 + `3/5` mono 11px로 바꾼다(6절).

**P2-2. 1단계의 '설명회 기록 n/N' 타일은 늘 0이다**

*누르는 크기*
- 태그 칩 높이 24px(실측, WCAG 2.2 24px 충족), 행 높이 40px

*표 구조*
- 진짜 `<table>`을 쓴다. `<caption class="sr-only">2026 목표 기관 7곳, 마감 가까운 순</caption>`.
- 기관 칸은 `<th scope="row">` 안에 이름 버튼을 둔다(상세 팝업을 연다).
- 묶음 머리는 `<th scope="rowgroup" colspan="7">`.
- 행 전체를 버튼으로 만들지 않는다. 행 안의 태그 버튼과 중첩되면 안 되기 때문이다.

*레인*
- 그림은 `aria-hidden`이다. 같은 칸에 sr-only 문장을 둔다. 예: `공고 2026-11-20부터 접수 마감 2026-11-29까지` / `추정 공고 2027-06` / `12개월 밖, 2028-01 추정`.
- 월 머리 숫자도 `aria-hidden`이고, 열 이름은 `12개월 일정 2026.11~2027.10`.

*색 단독 전달 없음*
- 지연: 빨강 8% 행 + `지연` 글자 칩
- 마감 30일 안: 빨강 + `마감` 글자 + 숫자
- 추정: 빗금 + 점선 + `추정` 글자

*태그 메뉴*
- `aria-haspopup="menu"`·`aria-expanded`, 메뉴는 `role="menu"`, 항목은 `menuitemradio`(`aria-checked`) + 구분선 + `menuitem` '목표에서 빼기…'.
- ↑↓ 이동, Enter·Space 선택, Esc는 닫고 칩으로 포커스를 돌린다.

*대화창*
- 기존 `modal-box tm-modal-box` + `role="dialog" aria-modal="true" aria-labelledby`를 쓴다.
- 닫으면 연 버튼으로, 빼기 뒤에는 다음 행 이름(없으면 [목표 기관 추가])으로 포커스를 옮긴다.

*접기*
- 협약 구획은 `<details>/<summary>`로 만든다. 요약 줄 안 제목은 `<h3>`이다.

### 6-D. 타임라인 구현 방법 = CSS 퍼센트 위치(인라인 SVG 쓰지 않음)

**이유**
- 글자 크기와 선 굵기가 폭에 따라 늘었다 줄었다 하지 않는다. SVG는 viewBox가 늘어나면 11px 글자와 1px 테두리가 같이 변한다.
- 지금 테스트처럼 HTML 문자열을 비교하는 방식에 맞는다.
- 칸 안에 sr-only 문장을 바로 둘 수 있다.
- `≤1279px`에서 열 하나만 숨기면 된다.

**순수 함수 (`kbboard.js`, 테스트 가능)**
- `kbb.laneWindow(today, goalYear)`:
  - 시작 = max(이번 달 1일, 목표 연도 1월 1일)
  - 끝 = 시작 + 12개월
- `kbb.laneGeom(fromISO, toISO, est, win)`:
  - 반환 `{ left%, width%, off:'before'|'after'|null }`. 날짜(일) 기준 비례로 계산한다.
  - 확정은 공고일~접수 마감일이다. 공고일이 없으면 마감일 앞 7일로 그리고, 그 사실을 sr 문장에 쓰지 않는다. → 이 7일 대체 규칙은 [이관: 기획] 확인 대상이다.
  - 추정은 그 달 하나 폭(8.333%)이다.
  - `now` = 오늘의 비율이다.

**색 규칙**
- 빨강은 '확정 마감 30일 안'과 '지연'에만 쓴다. 그 밖의 막대는 무채색이다.
- 지도의 4~5단 임박도 색은 이 표에 가져오지 않는다. 12개월 안에서는 거의 전부 빨강·주황이 돼 의미를 잃기 때문이다.

### 6-E. 상호작용

**① [목표 기관 추가] 대화창** (`modal-box tm-modal-box`, 제목 `목표 기관 추가`)
- `기관 (필수)`: `role="combobox"` 입력. 2자부터 결과를 최대 8개 보인다.
  - 각 결과: `서울 광진구청 · 국민은행 단수 · 협약 종료 2026-12-31`
  - 이미 목표에 있는 기관은 `aria-disabled` + `이미 2026 목표`
- `목표 연도 (필수)`: 올해·내년 select, 기본값 올해(planner 3-1 B)
- `구분 (필수)`: 라디오 두 개. 자동으로 미리 고르고 근거를 한 줄로 보인다.
  - 국민은행이 현 금고일 때: `광진구청은 지금 국민은행이 금고라 '재유치 도전'을 골랐습니다. 바꿀 수 있습니다.`
  - 은행 미상: 미리 고르지 않고 `현 금고 은행 자료가 없어 직접 고릅니다.`
- `메모 (선택)`: 100자, 글자 수 `0/100`, 안내 `개인정보를 적지 마세요.`
- 버튼: [취소] [목표에 넣기]
  - 기관과 구분이 차기 전에는 [목표에 넣기]가 disabled이고, 이유를 `tm-why`에 보인다: `기관을 고르세요.`
  - 성공하면 알림을 띄우고 새 행의 이름 버튼으로 포커스를 옮긴다.

**② 구분 칩 → 메뉴** (유리 팝오버, 반경 12px)
- 맨 위 설명 줄(항목 아님, 11px `--muted`): `자동 제안: 재유치 도전 — 지금 국민은행 협약 중`
- `재유치 도전` ✓ / `신규유치 도전` / ── / `목표에서 빼기…`
- 구분을 고르면 바로 저장한다(되돌리기 쉬움, 감사 기록의 버튼 이름 = '구분 바꾸기'). 저장 중에는 칩에 `aria-busy`를 둔다.

**③ 목표에서 빼기 대화창** (제목 `목표에서 빼기 — 서울 광진구청`)

### 6-F. 2단계 '설명회 기록' 입력 창 초안

- **여는 곳**: 설명회 칸이 `—` 대신 [기록]이 된다(영업부서). 기록이 있으면 `3곳`(mono) + 11px `11-20`.
- **제목**: `설명회 경쟁사 기록 — 서울 광진구청`
- **칸**
  - `설명회 날짜 (필수)`: date
  - `참석 은행 (필수, 1곳 이상)`: BANK 코드표 체크 상자 격자(3열). 국민은행은 목록에서 빼고 안내 `국민은행은 경쟁사 수에서 뺍니다.`
  - `은행별 참석 인원 (선택)`: 체크한 은행마다 숫자 칸. 안내 `세지 못했으면 비웁니다. 짐작한 수는 적지 않습니다.`
  - `메모 (선택, 200자)`
  - 출처 고정 줄: `출처: 담당자 현장 확인 · 입력 김영업`
- **회차**: 열린 회차가 있으면 `2026 회차에 연결됩니다`. 없으면 문구를 보이지 않는다.
- **버튼**: [취소] [기록 저장]
- **고치기**: 같은 창을 판 이력과 함께 연다. 맨 아래 `이전 기록 2건 보기` 접기.
