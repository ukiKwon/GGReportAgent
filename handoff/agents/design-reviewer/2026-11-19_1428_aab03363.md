- **제목 버튼**(`index.html:2444` h1 안). h1은 유지하고 안쪽에 버튼을 둔다.
```html
<h1><button type="button" id="brand-home" class="brand-home" aria-label="기관영업지원 시스템, 시작화면으로 가기">
  <svg …(기존 그대로)…></svg>기관영업지원 시스템</button></h1>
```
```css
body > header .brand-home { all:unset; box-sizing:border-box; display:inline-flex; align-items:center; gap:9px;
  min-height:32px; padding:4px 8px; margin:-4px -8px; border-radius:var(--r); cursor:pointer;
  font-size:16px; font-weight:700; letter-spacing:-.01em; color:#fff; transition:background .2s; }
body > header .brand-home:hover { background:rgba(255,255,255,.14); }          /* 머리 띠 단추 hover와 같음 */
body > header .brand-home:focus-visible { outline:2px solid #fff; outline-offset:2px; }   /* 머리 띠 포커스 규칙 */
body > header .brand-home[aria-current="page"] { cursor:default; }
body > header .brand-home[aria-current="page"]:hover { background:transparent; }
```

- **고정 탭 `.stab.home`**(`index.html:159-167`, `app.js:674-677`)
```css
.stab.home { flex:none; max-width:none; padding:7px 12px; gap:6px; }
.stab.home + .stab { margin-left:5px; }          /* 고정 탭 뒤 간격 3→8px: 닫을 수 있는 탭 무리와 떼어 놓는다 */
.stab.home .stab-ico { flex:none; width:12px; height:12px; color:currentColor; }
```
  - 닫기(×) 자리는 **비우지 않고 없앤다**. 대신 라벨 **앞**에 집 글리프(12×12 인라인 SVG 획, `aria-hidden`, `<path d="M1.5 6.2 6 2.2l4.5 4M3 5.2V10h6V5.2" fill="none" stroke="currentColor" stroke-width="1.3"/>`)를 둔다.
  - 오른쪽 여백은 12px로 왼쪽과 대칭이다. 오른쪽 24px이 비면 "×가 사라졌다(오류)"로 보이므로 비운 자리를 남기지 않는다.
  - 활성 모양은 다른 탭과 같다(흰 바탕 + 위 2px 포인트 막대).
  - `title`은 '시작화면 (닫을 수 없음)'으로 한다. 스크린리더용으로 `aria-describedby`나 sr-only 텍스트 '고정 탭'을 붙인다.
- **(기존 접근성 문제, 같은 곳)** `.stab-x`는 `<span role="button">`인데 tabindex가 없어 키보드로 닫을 수 없다(`app.js:677`). 탭 div도 `role="tab"`뿐이고 tabindex가 없다. 고정 탭을 다루는 김에 함께 고치기를 권한다(P2).

- **전산팀 보기 전용**(사용자 결정 전달분): 고치는 단추는 **비활성으로 남기지 말고 아예 그리지 않는다**. 대신 `.pt-top`의 `.meta` 앞에 `보기 전용` 칩을 둔다(`.pt-chip`과 같은 모양, muted 글자 8.10 on panel2). 누르면 다른 화면으로 넘어가는 칸(띠 4칸, 이름)은 이동이지 수정이 아니므로 남긴다. 어느 단추가 '고치는 것'인지는 이관 메모로 넘긴다.
