### 훅이 짚은 두 가지
1. **side-tab**: `.q`는 문제가 아닙니다. 1px 테두리가 사방에 둘러져 있고 왼쪽 띠가 없으니 훅이 잘못 짚은 것입니다. `.warn`(66줄·152줄의 주의 상자 2곳)은 실제로 해당합니다(왼쪽 3px 띠 + 모서리 4px 둥글림). 심각도는 P3이고 고치기 쉬워서 고치는 쪽을 권합니다. 노란 배경은 그대로 두니 주의 상자라는 것은 계속 보입니다.
   - old: `.warn{background:var(--warnbg);border-left:3px solid var(--warn);padding:8px 12px;border-radius:4px;margin:10px 0}`
   - new: `.warn{background:var(--warnbg);border:1px solid var(--warn);padding:8px 12px;border-radius:6px;margin:10px 0}`
2. **skipped-heading**: 실제 문제입니다(P2). 13번 슬라이드에서 h2 바로 뒤에 h4가 나오고, h3("짧게 확인할 것")은 그 뒤에야 나옵니다. 스크린리더로 제목을 따라가면 단계가 하나 빠집니다. 일반 h3 규칙은 파란색·14.5px라서 결정 카드 제목에는 아래처럼 따로 덮어씁니다.
   - old: `.q h4{margin:0 0 6px;font-size:15px}` → new: `.q h3{margin:0 0 6px;font-size:15px;color:var(--fg)}`
   - 본문 5곳(229·234·238·242·245줄): `<div class="q"><h4>` → `<div class="q"><h3>`, 같은 줄의 `</h4>` → `</h3>`. 파일 안의 h4는 이 5곳뿐입니다(grep으로 확인).

### 그 밖의 이슈(심각한 순)
1. **P1 슬라이드 제목·안내 문장과 실제 상태가 맞지 않음**(226·227줄): 결정 1·2·5가 답을 받았는데 제목은 "오늘 결정받을 것", 안내 문장은 "이미 답을 받은 것은 뺐습니다"입니다. 발표장에서 "이미 답한 것을 왜 또 묻나"라는 혼선이 생깁니다. 문구는 제가 바꾸지 않았고 메인이 정할 일입니다. 모양 쪽 제안만 드리면, 답 받은 카드에 `class="q done"`을 붙이고 `.q.done .opt:not(.rec){color:var(--mut)}`로 고르지 않은 선택지를 흐리게 하면 남은 결정 3이 눈에 띕니다.
2. **P2 인쇄 때 다크 모드 색이 따라옴**(5·40줄): 인쇄에도 `prefers-color-scheme:dark`가 그대로 적용됩니다. 브라우저는 기본으로 배경을 인쇄하지 않으므로, 다크 모드 PC에서 인쇄하면 흰 종이에 밝은 회색 글자(#e6ebf2)가 찍혀 거의 안 보입니다. `@media print{...}` 안 맨 앞에 아래 줄을 넣습니다. `:not(#p)`로 우선순위를 다크 규칙보다 높게 잡았습니다.
   - `:root:not(#p){--bg:#fff;--fg:#1c2330;--mut:#5b6678;--card:#fff;--line:#dde2ea;--acc:#1f6feb;--soft:#eef4ff;--ok:#1a7f37;--warn:#9a6700;--warnbg:#fff8e5;color-scheme:light}`
   - 부록(details)은 접힌 채로 인쇄되어 내용이 빠집니다. 인쇄하기 전에 손으로 펼쳐야 합니다(CSS로는 열 수 없음).
3. **P2 목차를 누르면 슬라이드 제목이 상단 목차에 가려질 수 있음**(추정, 13·16줄): 목차 단추 15개의 폭 합이 약 1,340px라서 960px 안에서 2줄로 접힙니다. 그러면 상단에 붙은 목차 높이가 약 77px인데 `scroll-margin-top:56px`라서 제목 윗부분이 경계에 걸립니다. 125%로 확대하면 3줄이 되어 제목이 가려집니다.
   - old: `scroll-margin-top:56px` → new: `scroll-margin-top:104px`
4. **P3 화면 공유 때 표 글자가 작음**: 표는 13.5px, 출처 줄·코드는 12.5px입니다. 화면 공유는 받는 쪽에서 축소되어 보입니다. 코드는 그대로 두고 발표자가 **Ctrl + 로 125%** 확대하는 방법을 권합니다. 1280폭에서 125%면 본문 폭 960px + 여백 32px가 들어가는 화면 폭 1,024px 안에 맞습니다(계산값).
5. **P3 부록 B 표 머리칸 폭**(285줄): "보고서(11-10~13 / 11-16~20 / 11-23)" 머리칸이 `th.num`의 줄바꿈 금지(nowrap) 때문에 약 330px를 차지합니다(추정). 그만큼 "한 일" 칸이 좁아집니다.
   - old: `<th class="num">보고서(11-10~13 / 11-16~20 / 11-23)</th>` → new: `<th class="num" style="white-space:normal">보고서<br>(11-10~13 / 11-16~20 / 11-23)</th>`

참고로 대비는 계산상 모두 기준을 넘습니다. 파란 강조색(#1f6feb, 흰 바탕) 4.6:1, 회색 보조 글자(#5b6678) 5.8:1, 초록(#1a7f37) 약 5.1:1로 모두 AA(4.5:1) 이상입니다.
