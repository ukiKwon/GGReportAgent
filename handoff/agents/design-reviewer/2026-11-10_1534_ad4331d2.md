## 4. 우선순위 이슈 — 차단(P1) 없음, 아래는 권장 수정

**P2-1 목록 항목의 포커스 링이 좌우에서 잘린다**
- 근거: `.tm-item` focus는 `outline 2px teal, offset 2px`이다(실측). 그런데 부모 `#tm-list { overflow:auto }`(index.html:835)가 링의 좌우 2–4px를 자른다. 요소 스크린샷 `dr-04-focus.png`에서 위·아래 선만 보인다. 같은 이유로 `1건` 카운트도 목록 오른쪽 끝에 붙어 있다.
- 왜 문제: 키보드 사용자가 볼 때 선택 테두리(같은 틸)와 포커스 링이 구분되지 않는다.
- 수정: 6-1 규격.

**P2-2 게이트 문구만 해요체다**
- 근거: 앱 JS 전체에서 해요체 종결(`있어요/않았어요/상태예요`)은 workflow.js에만 6곳 있다(grep). 같은 화면의 빈 상태 "서버에 등록된 기관이 없습니다"와 배정 모달의 "…처리되지 않았습니다"는 합니다체다.
- 또 힌트가 "영업부장만 **승인**할 수 있어요"인데, `aria-describedby`로 **반려** 버튼에도 붙는다.
- 수정: 5-1 문구 표.

**P2-3 '담당자'가 두 화면에서 다른 값이다**
- 근거: 영업팀 김영업으로 [제안서 진행 현황]을 열면 노원구 행의 담당자 열이 "-"이다(`dr-11`). 같은 기관의 [제안팀 구성·배정]은 담당자 3명이다(`dr-13`). 진행 현황의 담당자는 workflow overview의 `assignees`(작업 담당)이고, 배정 화면은 입찰 건 배정이다.
- 왜 문제: 같은 단어가 다른 뜻을 가진다. 사용자는 배정이 반영되지 않았다고 읽는다.
- 방향: 이관(기획). 결정 전 임시안은 진행 현황 열 머리를 `작업 담당`으로 바꾸는 것이다(문구만, 되돌리기 쉬움).

**P2-4 결재 카드 제목의 기관명과 배정 목록의 기관명이 다르다**
- 근거: 결재 카드는 "담당자 변경 — 노원구"(`dr-10`), 배정 목록과 상세는 "노원구청"(`dr-03`)이다. 진행 현황 표도 "노원구"다.
- 왜 문제: 결재자가 카드를 보고 배정 화면에서 같은 건을 찾을 때 이름이 다르다.
- 방향: 이관(개발·데이터). 결재 제목이 기관 마스터 이름을 쓰는지, 입찰 건 이름을 쓰는지 정해야 한다.

**P3-1 모달 결재 경로 안내 줄바꿈**
- 근거: "…결재 진행 / 을 볼 수 있습니다."에서 조사 '을'이 다음 줄 첫머리로 떨어진다(`dr-05`). `.tm-note`가 `word-break:normal`이다(실측).
- 수정: `.tm-note { word-break:keep-all; }`. 사유 셀에는 이미 쓰고 있다.

**P3-2 배정 이력의 모든 행에 '자기신고'**
- 근거: 사번으로 로그인한 계정이 처리한 3행이 모두 자기신고다. 로그인 화면이 "비밀번호는 프로토타입은 확인하지 않습니다"라서 정직한 표시다.
- 왜 문제: 모든 행에 붙어 있으면 구분하는 신호가 되지 못한다.
- 방향: 현행 유지. 신원 확인이 들어오면 자연히 해소된다(8번 질문).

**P3-3 범위 밖 기존 어긋남**
- 진행 단계 칩의 '🛑' 이모지(`workflow.js:362·381`)가 DESIGN.md "No emoji in chrome"(465행)과 어긋난다. 오늘 바뀐 곳은 아니다.
- 로그인 배경 `img/login-bg.jpg`가 404다(콘솔). 오늘 변경과는 무관하다.

**P3-4 '결재 요청' 소제목** (화면에서는 못 봄)
- `.ap-sec` 12px muted 600으로 '제안서 작업물 결재'와 같은 모양이라 규격과 맞다.
- 이름이 짝을 이루지 않는다('결재 요청' ↔ '제안서 작업물 결재'). 다음에 다듬을 후보로 `권한·담당자 변경 결재`를 둔다. 지금은 바꾸지 않아도 된다.

## 6. 규격

**6-1. 포커스 링 잘림 수정 (P2-1)**
```css
/* 왼쪽 정렬(268px 시작선)은 그대로, 링이 들어갈 4px 여유만 만든다 */
#tm-list { width:278px; padding:0 4px 4px; margin-left:-4px; }   /* box-sizing:border-box 전제 → 내용 폭 270px 유지 */
@media (max-width:880px) { #tm-list { width:auto; margin-left:0; } }
```
- 대안: `.tm-item:focus-visible { outline-offset:-3px }`. 선택 테두리와 겹쳐 이중선이 되므로 권하지 않는다.

## 7. 이관 메모

**기획**
- [이관: 기획] '담당자'의 뜻을 하나로 정한다. 진행 현황 표의 담당자(작업 담당)와 입찰 건 배정 담당자 중 무엇을 보일지 — 디자인이 기다리는 것: 열 머리 문구와 값의 원천 — 근거: 노원구가 진행 현황에서는 "-", 배정 화면에서는 3명(`dr-11`·`dr-13`).

**개발·데이터**
- [이관: 개발] 결재 요청 제목의 기관명 원천 — 디자인이 기다리는 것: 결재 카드와 배정 목록이 같은 기관명을 쓰는 것 — 근거: 카드 "담당자 변경 — 노원구" vs 목록 "노원구청".
