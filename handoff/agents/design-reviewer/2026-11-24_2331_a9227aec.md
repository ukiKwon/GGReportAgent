## 3. 우선순위 이슈

**P1-1. 묶음 머리와 기관 행이 구분되지 않음 (사용자 피드백 2)**
- **근거(실측)**:
  - 이름 글자가 같습니다. `.rk-gn`과 `.rank-card b`가 둘 다 13px/700입니다.
  - 바탕 차이가 사실상 없습니다. 머리 `--panel2` #f6f7f9와 흰 행의 대비는 약 1.07:1입니다.
  - **기관 행에 마우스를 올리면 바탕이 `--panel2`로 바뀌어 머리와 똑같아집니다**(index.html `.rank-card:hover`).
  - 구분선도 같습니다. 머리 아래 선과 행 사이 선이 둘 다 `--line`입니다.
  - 들여쓰기가 없습니다. 머리와 행이 모두 padding-left 14px입니다.
  - 둘째 줄도 둘 다 12px muted 요약입니다.
- **왜 문제인가**: 사용자는 "창원시"를 기관 하나로 읽습니다. 묶음을 눌러 지도에서 시군구 전체를 고르는 동작도 기관 행과 같아 보입니다.
- **수정 방향**: 6절 규격을 따릅니다.
  - 머리는 `--bg` 띠, 14px/700, 위아래 `--line-strong` 선
  - 기관 행은 14px 들임과 1px `--line` 세로선
  - 묶음 사이 구분은 머리 위 강한 선 하나로
  - 미리보기에서 효과를 확인했습니다(`dr-115-after-preview.png`).

**P2-1. 툴팁 꼬리의 '…은 색에서 뺌' (사용자 피드백 1)**
- **근거**: `render.js` 535행. 문구는 "빠진 것" 이름만 늘어놓고 "그래서 색이 무엇으로 정해졌는지"는 말하지 않습니다.
  - 예: 진주시는 합계 3건인데 색은 2년 이상 1건만으로 진파랑입니다.
- **수정 방향**: '뺌'을 쓰지 않고 **색을 정한 건수를 긍정형으로** 적습니다. 줄을 없애는 것보다 낫습니다. 없애면 "알 수 없음 2건인데 왜 진파랑인지"를 설명할 곳이 사라집니다.
  - 수는 `info.dated`(색 계산에 들어간 건수, logic.js 567~584행)를 그대로 씁니다.
  - 문구는 5-1절에 있습니다.

**P2-2. '가장 임박' 줄 삭제 (사용자 피드백 1)**
- **근거**: `render.js` 520~524행.
- **수정 방향**: 툴팁에서만 지웁니다. `info.imminent`는 ▲와 면 클릭 대상(`render.js` 428~434행)에 계속 쓰이므로 `logic` 쪽은 건드리지 않습니다.
  - 블록 조건은 `if (im || buckets.length)`에서 `if (buckets.length)`로 바꿉니다.
  - 517행 주석도 고칩니다.
  - 쓰는 곳이 없어지면 `#region-tip .rt-l` 규칙(index.html 951행)을 지웁니다. 다른 곳에서 쓰는지 grep으로 확인한 뒤에 지웁니다.

**P3-2 (qa). `.rk-grp.on` 3px 막대가 행 hover와 `.hi` 바탕에 가려짐 — 확인했습니다**
- **근거**: `dr-115-before-on-hover.png`. 마우스를 올린 '창원시청' 행 구간에서 파란 막대가 끊깁니다.
- **원인**: 부모의 `inset box-shadow`는 자식의 바탕 아래에 그려집니다.
- **수정 방향**: 몸통 막대를 `.rk-grp.on::before`(absolute, z-index:1)로 옮깁니다.
  - 머리의 `inset` 막대는 **남깁니다**. 머리는 sticky z-index:1이고 DOM에서 뒤에 있어서 `::before`를 덮기 때문입니다.
  - `::before`를 z-index 2로 올리면 안 됩니다. 스크롤할 때 `.rank-head`(z-index 2)를 뚫고 올라옵니다.
  - 미리보기에서 hover 상태와 `.hi` 상태 모두 막대가 이어지는 것을 확인했습니다.

**P3-5 (qa). 전국 `mixAriaLabel`의 '6개월 안'과 툴팁의 '6개월 미만'**
- **판단: '미만'으로 맞추면 틀립니다.** 두 수는 다른 양입니다.
  - aria의 `info.urgent`는 0~6개월 누적이고, 지도 ▲n과 같은 수입니다(범례 render.js 160행 "6개월 안 공고 예정 기관 수").
  - 툴팁의 '6개월 미만'은 `within6 − within1`, 즉 30일~6개월 구간입니다(logic.js 627행).
  - 이름만 맞추면 같은 이름 아래 다른 숫자가 나옵니다.
- **수정 방향**: aria를 **범례와 같은 말**로 맞춥니다. `'6개월 안 ' + n + '건'`을 `'6개월 안 공고 예정 ' + n + '건'`으로 바꿉니다(render.js 467행, 463행 주석의 예시도).
  - '안'은 그대로 둡니다. 누적이라는 뜻을 담고 있어서입니다.

**P3-6 (새로). 묶음 머리 단추가 '선택됨'을 화면에서만 보여줌**
- **근거**: `selectGroup`(render.js 1206행)이 `.on` 클래스만 붙입니다. 상태는 `_rankStatus` 안내로만 전해집니다.

  - 해당 위치는 `_rkBuildGroup`, `selectGroup`, `clearSelection`, 1019행의 복원부입니다.

## 4. 문구 / 접근성

**문구**
- 툴팁 꼬리 문구는 5-1절에 있습니다. '뺌'·'제외'를 쓰지 않고, 기존 빈 상태 문구 "켠 종류의 기관이 없습니다"와 같은 '-습니다'체로 씁니다.
- 전국 aria는 '6개월 안 공고 예정 n건'으로 범례와 같은 말을 씁니다.
- 묶음 이름 '시·군·구 미확인'의 가운뎃점은 기존 명칭이라 그대로 둡니다.

**대비(실측과 계산)**
| 요소 | 바탕 | 대비 |
|---|---|---|
| 머리 띠 `--bg` #e9ecf0 | 흰 행 | 1.18:1 (현 #f6f7f9는 1.07:1). 구조 신호이고 들여쓰기·선과 함께 쓰므로 3:1 대상이 아님 |
| 머리 글자 `--fg` | `--bg` | 13.6:1 |
| 요약 `--muted` | `--bg` | 7.3:1 |
| 포커스 링 `--accent-color` | `--bg` | 5.8:1 (3:1 이상) |
| `.on` 머리 | 기존 13% 틴트 | 바꾸지 않음 |

**그 밖의 접근성**
- 세로 가는 선(`--line`, 흰 바탕 약 1.6:1)은 장식입니다. 소속은 들여쓰기·머리 띠·`section aria-labelledby`가 전하므로 색 하나로만 뜻을 전하는 경우가 아닙니다.
- 타깃 크기: `.rk-rest-btn`은 높이 28px로 24px 이상입니다. 들여써도 폭이 약 300px라 문제없습니다.
- 움직임: 새로 생기는 움직임은 없습니다.

## 5. 규격

### 5-1. 툴팁 (`render.tipHtml`, render.js 517~535행)
```js
// 입찰 예정 시기: 겹치지 않는 구간(0건 숨김). '가장 임박' 줄은 뺐다(사용자 11-24) — ▲·면 클릭용 info.imminent는 그대로.
const buckets = logic.tipBuckets(info);
if (buckets.length) {
  h += '<div class="rt-sec">' + kv('입찰 예정 시기', null, 'rt-t');
  buckets.forEach(function (b) { h += kv(b.label, b.n); });
  h += '</div>';
}
// 꼬리: 예정일 경과·합계 + 지도 색을 정한 건수(info.dated = 색 계산에 들어간 건수). 전부 들어갔으면 줄 없음.
const dated = info.dated || 0;
const note = dated === 0 ? '지도 색을 정할 건이 없어 회색입니다'
  : (dated < info.total ? '지도 색은 ' + info.total + '건 중 ' + dated + '건으로 정했습니다' : '');
h += '<div class="rt-sec rt-foot">' + (info.overdue ? kv('예정일 경과', info.overdue) : '') + kv('합계', info.total) +
  (note ? '<div class="rt-mu">' + note + '</div>' : '') + '</div>';
```
- 예: 진주시는 "합계 3건 / 지도 색은 3건 중 1건으로 정했습니다"가 됩니다.
- 이제 쓰이지 않는 `out`과 `waitN` 계산은 지웁니다.
- 시험 `frontend/test/map-rankgroup.test.js` 103·108·118·120행이 옛 문구를 확인하고 있어 함께 바꿔야 합니다.

### 5-2. 묶음 목록 CSS
`index.html`의 '시군구 묶음 목록 시작'~'끝' 사이에서 아래 선택자를 바꾸거나 더합니다. 나머지 줄(`.rk-gs`, `.rk-rest-btn::before` 등)은 그대로 둡니다.

```css
/* 묶음 = 머리 띠(--bg, 14/700, 위아래 --line-strong) + 14px 들인 기관 행(1px --line 세로선). 묶음 사이 구분은 머리 위 선 하나 */
#rank-panel { --rank-head-h:45px; }
.rk-grp { position:relative; border-top:1px solid var(--line-strong); }          /* border-bottom 삭제 */
.rk-grp:first-child { border-top:0; }                                            /* .rank-head 아래 선과 겹치지 않게 */
.rk-grp > :last-child, .rk-rest > .rank-card:last-child { border-bottom:0; }     /* 다음 머리 위 선과 2겹이 되지 않게 */
.rk-gh { position:sticky; top:var(--rank-head-h); z-index:1; margin:0; font:inherit;
         background:var(--bg); border-bottom:1px solid var(--line-strong); }      /* --panel2 → --bg, 아래 선 --line → --line-strong */
.rk-gbtn, .rk-gstatic { /* 기존 + */ padding:8px 14px 7px; row-gap:1px; }
.rk-gbtn:hover { background:color-mix(in srgb, var(--fg) 6%, var(--bg)); }      /* 기준 바탕만 --bg로 */
.rk-gn { font-size:14px; font-weight:700; letter-spacing:-0.01em; }             /* 13 → 14 (DESIGN 소제목 단계) */
.rk-gt { font:700 13px var(--mono); }                                            /* 12 → 13 */
/* 기관 행을 묶음 아래에 매단다 — 들임 14px + 세로선. hover(--panel2)가 더는 머리 바탕과 같지 않다 */
.rk-grp > .rank-card, .rk-rest > .rank-card { margin-left:14px; padding-left:12px; border-left:1px solid var(--line); }
.rk-rest-btn { /* 기존 + */ margin-left:14px; width:calc(100% - 14px); padding-left:12px; border-left:1px solid var(--line); }
/* 선택 묶음(P3-2): 몸통 막대는 ::before로 — 자식 hover·.hi 바탕에 가려지지 않게. 머리 막대는 기존 inset 그대로 */
.rk-grp.on { box-shadow:none; }
.rk-grp.on::before { content:""; position:absolute; left:0; top:0; bottom:0; width:3px;
                     background:var(--accent-color); z-index:1; pointer-events:none; }   /* z-index 2 금지 — .rank-head를 뚫는다 */
.rk-grp.on .rk-gh { background:color-mix(in srgb, var(--accent-color) 13%, var(--panel)); box-shadow:inset 3px 0 0 var(--accent-color); }  /* 그대로 */
```
- `@media screen and (max-width:880px) { .rk-gh { position:static; } }`는 그대로 둡니다. 들여쓰기 14px도 좁은 화면에서 유지합니다.
- 상태별 모양:

| 상태 | 머리 | 기관 행 |
|---|---|---|
| 기본 | `--bg` 띠 | 흰 바탕 + 세로선 |
| hover | fg 6% 섞인 `--bg` | `--panel2`(기존) |
| 포커스 | 2px 포인트 링, offset −2px(기존) | 기존 |
| `.on` | 13% 틴트 + 3px 막대 | `::before` 3px 막대가 위에서 아래까지 이어짐 |
| `.hi` | — | 기존 13% 틴트 + 2px inset(세로선 안쪽) |
| 미확인 묶음 | 같은 띠, hover 없음(`span`) | 같음 |

## 6. design_history 전/후 문안 (전/후 장 필요)
`docs/design_history/index.html`에 이번 변경(묶음 목록 A·B와 이번 후속)의 장이 없습니다. 아래 문안으로 한 장을 더해 주세요.
- **전**:
  - 오른쪽 목록에서 시군구 이름(창원시)과 기관 이름(창원시청)이 같은 13px 굵은 글자, 같은 2줄, 거의 같은 바탕(#f6f7f9 대 흰색, 대비 1.07:1)이었습니다.
  - 기관 행에 마우스를 올리면 바탕이 머리와 똑같아졌습니다.
  - 지도 툴팁 맨 아래는 "알 수 없음은 색에서 뺌", 위에는 '가장 임박' 줄이 있었습니다.
- **후**:
  - 시군구 머리는 한 단계 진한 회색 띠(#e9ecf0, 흰 행 대비 1.18:1)와 14px 굵은 글자, 위아래 진한 선으로 바뀝니다.
  - 기관 행은 14px 안으로 들여 가는 세로선에 매달립니다.
  - 선택한 시군구의 파란 막대가 행에 마우스를 올려도 끊기지 않습니다.
  - 툴팁의 '가장 임박' 줄은 사라지고, 꼬리는 "지도 색은 3건 중 1건으로 정했습니다"처럼 색을 정한 건수를 말합니다.
- **왜**: 사용자 11-24 피드백입니다. "시군구가 기관과 똑같은 목록 항목으로 보여 구분이 안 된다", "'뺌'이라는 말은 빼자".
