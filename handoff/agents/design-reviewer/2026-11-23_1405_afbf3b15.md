## 웹 접근성 진단 — frontend/ (KWCAG 2.2 기준)

**어떻게 봤나**: 코드만 읽었습니다(index.html·js/*.js 표본). Playwright 브라우저는 다른 세션이 쓰고 있어서("Browser is already in use") 실제 화면을 열지 못했습니다. 그래서 화면 낭독기로 직접 들어보기, 실제 키보드 순회, 렌더된 색으로 대비 재기는 하지 못했습니다. 대비는 CSS 색 값으로 계산했습니다. 공통 틀로 아직 안 옮긴 팝업 6개(kbboard·prep·instedit·headcard·bd-m-rw·bd-src)는 자세히 보지 않았습니다.

### 한 줄 총평
기본기는 사내 시스템치고 높은 편입니다. 인증 심사 기준(33개 항목)으로 보면 **4~5개 항목에서 지적이 예상됩니다.** 대부분 고치는 크기가 작거나 중간입니다. 가장 효과가 큰 한 가지는 **"본문 바로가기" 링크와 '열어 둔 화면' 탭의 키보드 지원**입니다.

### 잘 된 점
1. **문서 기본 틀이 갖춰져 있습니다**: 문서 언어 한국어 지정(`lang="ko"`), 머리 띠·업무 메뉴·본문 영역 구분(header / `nav aria-label="업무 메뉴"` / `main`), 앱 이름 제목(h1) (index.html:2, 3013, 3040, 3041).
2. **글자 대비가 넉넉합니다**: 회색 글자(#464c53)는 흰 바탕에서 약 8.6:1, 상태 색(빨강 #bd2c0f, 주황 #8a5c00, 노랑 #6b6000, 초록 #1d6f3a)도 모두 4.5:1 이상입니다. 안 읽은 쪽지·결재 배지의 흰 글자도 빨강 위에서 약 5.6:1입니다. 키보드 포커스 표시도 화면 전체에 두께 2px로 들어가 있습니다(index.html:37).
3. **전국 지도를 키보드와 화면 낭독기로 쓸 수 있습니다**: 지역마다 키보드로 이동하고 이름을 읽어 주며, Enter로 들어갑니다(render.js:269–273, 545, 581–583). 같은 내용을 '전국 지역별' 표로도 볼 수 있어 지도를 대신할 수단이 있습니다. 지도 모양 아이콘은 읽히지 않게 숨겼고, 유형 구분은 색만이 아니라 모양(■□△⬠◇○)으로도 합니다.
4. **탭과 메뉴의 상태를 알려 줍니다**: 결재함·회의자료·대시보드·은행 현황판 탭은 선택 상태를 알려 주고 좌우 화살표로 옮겨 다닙니다. 업무 메뉴는 펼침 상태와 현재 위치를 알려 줍니다(app.js:825, 838, 846). 읽기 중심으로 상태를 알리는 곳이 26개 파일 179군데입니다.
5. **입력 오류 안내가 잘 되어 있습니다**: 틀린 칸을 표시하고, 오류 문장을 칸과 연결하고, 첫 틀린 칸으로 포커스를 옮깁니다(instedit.js:458–469). 필수 칸 표시(*)도 화면 낭독기에 따로 알려 줍니다(쪽지함 index.html:3317–3327). 움직임 줄이기 설정을 곳곳에서 따르고, 로그인 화면의 넘어가는 그림에는 멈춤 단추가 있습니다.

### 권장 순서 상위 5개
1. **본문 바로가기 링크** — 화면 맨 앞에 숨겨 두었다가 키보드 포커스가 오면 보이는 링크(`href="#main"`)를 둡니다. 크기가 작고 심사 지적이 확실한 항목입니다.
2. **'열어 둔 화면' 탭을 단추로 바꾸기** — 탭을 `<button role="tab">`로 만들고 선택 상태(aria-selected)와 좌우 화살표 이동을 넣습니다. [×]도 진짜 단추로 바꿉니다. 결재함 탭(approvals.js:484–494)과 같은 방식을 그대로 쓰면 됩니다.
3. **이름 없는 입력 칸 3개에 칸 이름 붙이기** — 대화 입력, 메모, 파일 선택.
4. **임박 TOP5 띠에 멈춤 단추** — 로그인 그림의 멈춤 단추 모양을 다시 쓰거나, 반복 움직임 자체를 없앱니다.
5. **화면마다 창 제목과 제목(h2) 맞추기** — 예: "결재함 – 기관영업지원 시스템". 결재함·내 정보·작업함의 머리 글을 h2로 바꿉니다.
