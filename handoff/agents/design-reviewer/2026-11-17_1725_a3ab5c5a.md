**접근성 규격**
- **탭**: `.ap-tabs` 재사용. `role=tablist aria-label="목록 종류"`, 버튼 `role=tab aria-selected aria-controls="hb-ts"`, ←/→로 이동. `#hb-ts`는 `role=tabpanel aria-labelledby=<선택 탭>`.
- **정렬 머리**: 정렬된 열의 `<th>`에만 `aria-sort="ascending|descending"`을 붙이고, 다른 열에는 속성을 두지 않는다. th 안에 `<button type="button" class="hb-sort">`. 처음 상태는 '마감까지' ascending.
  - 정렬하지 않는 열: 설명회, 12개월 일정.
  - sr-only caption을 갱신한다: `2026 목표 기관 5곳 중 3곳, 마감까지 오름차순`.
- **건수**: `#hb-cnt role=status aria-live=polite`. 입력 디바운스 150ms 뒤 한 번만 바뀐다.
- **제안 진행 단계 버튼**: `aria-pressed`. 한 번에 하나만 눌린다. 같은 버튼을 다시 누르면 꺼진다. 0곳 단계는 `disabled`.
- **입찰 종료 줄의 동작 버튼**: 레인 칸의 `aria-hidden` 그림 **밖**에 둔다. 1279px 이하에서 레인이 숨으면 같은 동작을 구분 메뉴 항목(`관심 기관으로…`, `다음 회차 목표로…`)으로도 준다. 메뉴에는 폭과 상관없이 항상 둔다.
- **필터 select가 켜졌을 때**: 테두리를 `color-mix(in srgb, var(--accent-color) 55%, #626d81)`로 바꾼다. 선택·상호작용이므로 틸 규칙 안이다. 같은 뜻을 건수 `3 / 5곳`이 글자로도 전한다.
- **협약 중인 기관 팝업**
  - `role=dialog aria-modal=true aria-labelledby`, 열린 동안 뒤 `#hb-root`는 inert, Esc로 닫고 닫으면 여는 버튼으로 포커스가 돌아온다.
  - 줄의 기관 이름을 누르면 팝업을 닫고 기관 상세를 연다. 모달을 겹쳐 쌓지 않는다. 상세를 닫으면 [협약 중인 기관]으로 포커스가 돌아온다.
- **대비**(실측·계산)
  - 실측: 패널 위 muted 6.41:1, fg 13.45:1, `.hb-tag` 테두리 #626d81 3.20:1(비글자 3:1 통과).
  - 계산: 주의 상자 제목(orange 72%+흰색 #e4bb89) 대 8% 주황 바탕 약 8.2:1, 같은 바탕 위 muted 약 5.6:1.
- **누르는 크기**: `.hb-tag`·단계 버튼은 높이 24px 이상, 툴바 칸은 28px.

- **표 패널 높이**: `height: clamp(280px, calc(100vh - 296px), 960px)`(지금은 −330px).
- **720 높이**: 패널 시작 y=282, 높이 424, 줄 영역 424−44−40−37 = 303 → **줄 7개**, 스크롤 0.
- **800 높이**: 504 → 줄 영역 383 → **줄 9개**. 지금과 같은 줄 수를 지킨다.
- **덜어낸 것**: 협약 구획(54px), 띠의 '관심 기관 N' 칸(planner 3-1 안). 관심 수는 탭 이름표 `관심 2`가 같은 시선 줄에서 말하고, 띠 4칸은 '올해 성과'만 남긴다. 띠에 5칸째를 넣으면 칸마다 폭이 20% 줄어 은행 막대 2단이 깨진다.
- **≤1279px**: 레인과 범례가 숨는다(지금과 같음). 툴바는 `flex-wrap` → 2줄(약 80px)이 될 수 있다. 이때 줄은 720 높이에서 6개다.
- **≤880px**: 띠는 2×2, 제안 진행 줄은 가로 스크롤(`overflow-x:auto`)한다. 표 패널은 `height:auto`(지금과 같음).

### 6-3. 요약 띠 안 '제안 진행' 줄

- 안쪽 grid: `88px repeat(5, minmax(0,1fr))`, padding `0 16px`, gap 6px.
- **단계 버튼**(`button.hb-sb`): 높이 28, 반경 8, 1px `--line` 테두리, 투명 바탕. 내용은 다음 순서다.
  - 단계 번호: 11px mono muted. 실제 순서이므로 번호를 허용한다.
  - 이름: 12px fg, 말줄임.
  - 수: **16px mono 700 fg**, 오른쪽 정렬.
  - 아래쪽 3px 막대: `::after`, 폭 = 수/최댓값, 색 `color-mix(in srgb,var(--fg) 55%,var(--panel))`. 새 색 없음.
- **상태별 모양**
  - hover: 바탕 6% 틸.
  - 눌림(`aria-pressed=true`): 13% 틸 바탕 + 틸 1px 테두리.
  - 0곳: `disabled`, 수를 muted로.
  - 승인 대기 2단계(gate)는 이름만 다르고 모양은 같다.
- **불변식(개발에 전달)**: **버튼의 수 = 누르면 표에 남는 줄 수**. 수는 `dash.stageCounts`가 아니라 표 줄 모델(goalRows+outRows의 `r.stage`)로 센다.
- **자료가 없을 때**(prepOk 아님): 버튼 5개를 `disabled`로 두고 수 자리에 '—'. 이름표 옆 11px muted로 BAND_MSG의 같은 이유(`제안 진행 자료를 불러오지 못해 판정하지 않습니다` 등)를 띠 3번 칸과 같은 말로 쓴다.
- 누르면 목표 탭으로 옮긴다(관심 탭에는 단계가 없다). 툴바에 `단계: 사전준비 ×` 칩(`.hb-tag`, 11px)을 보이고, ×로도 끈다.

### 6-5. 정렬 머리
- **목표 탭에서 정렬하는 열**: 기관(가나다) · 구분 · 마감까지(기본 ↑, 지금 `sortGoals` 규칙) · 현 금고 은행 · 준비 단계(단계 번호). 설명회·12개월 일정은 정렬하지 않는다.
- **planner의 '협약 종료일·넣은 날' 정렬은 목표 탭에서 빼기를 권한다.** 보이지 않는 열로 정렬하면 순서가 왜 그런지 알 수 없다. 협약 종료일 정렬은 관심 탭의 열이 맡는다.
- **버튼 모양**(`.hb-sort`): `all:unset`, th의 11px muted를 이어받는다. 정렬된 열은 fg + 700.
  - 아이콘: 8×8 SVG 쉐브론(↑/↓, stroke 1.4, currentColor). 정렬 안 된 열은 위아래 쌍 쉐브론, muted 55%.
  - 포커스: 2px 틸, offset 2. 높이는 th 아래 맞춤을 유지하고 버튼 min-height 24.
- 같은 열을 다시 누르면 방향이 바뀐다. 묶음(목표 / 목표 밖 준비)은 깨지 않고 묶음 **안에서** 정렬한다.
- '입찰 종료' 줄은 마감까지 오름차순에서 맨 아래(미상 다음)에 둔다. 올해 손쓸 일이 끝난 줄이기 때문이다.

### 6-9. 추가 창(목표 기관 추가 / 관심 기관 추가)
- 맨 위에 `fieldset` **넣을 곳 (필수)** 라디오 2개: `목표` / `관심 기관(연도 없음)`. 제목 `h3`가 따라 바뀐다(`목표 기관 추가` ↔ `관심 기관 추가`). 관심이면 '목표 연도' 줄을 숨긴다.
- **검색 결과 줄의 표시**(`.sub` 뒤)
  - `· 이미 2027 목표` / `· 이미 관심 기관` → `aria-disabled`(지금 taken 규칙을 넓힘).
  - `· 올해 입찰 종료` → 고를 수 있다. 관심이나 다음 회차로 넣을 수 있기 때문이다.
- **이미 걸린 기관을 고르려 할 때**(클릭·Enter): `#hb-a-pick`(aria-live=polite)에 중복 알림 두 문장(5절 표)과 [관심 탭에서 보기] 또는 [목표 표에서 보기] 링크 버튼(창을 닫고 그 줄에 포커스)을 띄운다. 서버 409도 같은 문장으로 바꿔 보인다.
- **입찰 종료 주의 상자**(`.hb-warn`, 서버가 아는 근거, 넣을 곳=목표·연도=올해일 때)
```

│ 근거: 입찰 공고 현황 2026-09-30 공고 종료. 올해 목표로는 넣을 수 없습니다. │

│ 정보가 틀리면 '입찰 공고 현황'에서 고쳐 주세요. [입찰 공고 현황 열기] │

```
  - 모양: `--orange` 1px 테두리 + `color-mix(in srgb,var(--orange) 8%,transparent)` 바탕, 반경 8, padding 10px 12px, gap 6.
  - 제목: 12px 700 `color-mix(in srgb,var(--orange) 72%,#fff)` + `render.ICONS.warn` 12px.
  - 본문: 12px fg. 바로가기 줄: 11px muted.
  - 이때 [목표에 넣기](`#hb-a-go`)는 disabled이고, `#hb-a-why` = `올해 입찰이 끝나 올해 목표로는 넣을 수 없습니다.`
  - 상자 안 두 버튼이 실제 저장 버튼이다(한 번에 저장한다). '입찰 공고 현황 열기'는 창을 닫고 `openNotice(key)`.
  - **제안 진행 중 예외**(planner 3-2): 같은 상자를 쓰되 제목을 `올해 입찰이 끝난 것으로 기록되어 있습니다`로 바꾸고 막지 않는다. 본문 끝에 `이 기관은 제안을 진행 중이라 올해 목표로 넣을 수 있습니다.`를 더한다.
- **화면만 아는 근거**: 같은 상자의 **muted 판**(테두리 `--line-strong`, 바탕 없음, 제목 fg)에 5절 '화면만 아는 근거' 문구와 바로가기 줄을 둔다. 막지 않고 버튼 2개도 없다.

### 6-10. 협약 중인 기관 팝업
- `modal-box` 폭 `min(720px, 92vw)`, 내부 스크롤 `max-height: 76vh`. 머리 줄(sticky)은 `협약 중인 기관 27곳` h3 14px + 아래 12px muted `협약 종료 1년 안 8곳 · 그중 목표 0곳`(oursHeadHtml 재사용) + 오른쪽 [닫기].
