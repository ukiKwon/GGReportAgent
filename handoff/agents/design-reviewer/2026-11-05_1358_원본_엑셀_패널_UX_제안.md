## 5. 우선순위 이슈
- **P1 자동 스크롤 칸이 화면 밖이나 상태 줄 아래에 놓임** (근거는 위 측정 y 907).
  - 대조 작업의 핵심 동작이 겉으로는 동작하는데 결과가 보이지 않습니다.
  - 수정:
    - 패널 높이를 실제로 보이는 영역에 맞춥니다.
    - 스크롤은 패널 안에서만, 가운데 정렬로 합니다(render.js 670–672의 방식처럼 `scrollTop`과 `scrollLeft`를 직접 계산). 페이지 전체가 따라 움직이면 안 됩니다.
- **P1 같은 시트를 겹치는 범위로 4번 그림.** 길이가 2.5배가 되고, 같은 H72가 두 군데 나와 어느 것이 강조인지 찾아야 합니다. 수정: 시트별로 격자 하나를 그립니다(규격 6-1).
- **P1 행·열 머리와 패널 머리가 고정되지 않아 기준점 소실.** 숫자만 보여서는 맞는 칸인지 판단할 수 없습니다. 수정: 고정 머리글(6-2).
- **P2 좌우 비율 고정 3:2, 929px에서 원본 235px.** 수정: '넓게 보기' 토글(6-4). 좁은 화면 처리 방향은 6-6.
- **P2 매핑된 칸과 아닌 칸의 구분이 없음** (440칸 중 48칸만 대상). 수정: 매핑 안 된 값은 muted로 표시(6-3).
- **P3 문장 라벨의 오른쪽 정렬, 긴 라벨이 열을 341px로 늘림.** 수정: 숫자가 아닌 칸은 왼쪽 정렬하고 최대 너비에서 말줄임(6-3).

## 6. 규격
**6-1 구조**
```
aside#bd-w-src (sticky, 높이 = 보이는 영역)
 ├ .bd-w-srchead  (패널 안 sticky top:0, 스크롤 안 됨)
 │   [엑셀 원본 · 파일명(말줄임)]          [넓게 보기] [원본 접기]
 │   표 위치: [A] [B] [C-2] [C-3] [C-4]  [선택 칸으로]
 └ #bd-w-srcbody  (스크롤 영역, tabindex=0, role=region)
     시트 캡션: 수익성분석 시트 · A54:K93   ← 시트별로 1개
     table.bd-w-srctbl (thead sticky, 행번호 th sticky left)
```
- 시트별로 격자 1개를 그립니다. 범위는 그 시트에 속한 표 범위의 합집합입니다.
- 표 범위의 시작 행 머리(th)에 작은 표 태그(`B`, `C-2`)를 둡니다. 11px mono, muted, 1px `--line-strong` 테두리, 8px radius.

**6-2 고정 머리글과 높이**
```css
.bd-w-src { display:flex; flex-direction:column; overflow:hidden;
  max-height: calc(100vh - var(--bd-scroll-top) - var(--bd-bar-h) - var(--bd-status-h) - 16px); }
.bd-w-srchead { flex:none; position:sticky; top:0; z-index:2; background:var(--panel);
  padding-bottom:6px; border-bottom:1px solid var(--line); }
#bd-w-srcbody { flex:1 1 auto; min-height:0; overflow:auto; }
.bd-w-srctbl thead th { position:sticky; top:0; z-index:1; background:var(--panel2); }
.bd-w-srctbl tbody th[scope=row] { position:sticky; left:0; z-index:1; background:var(--panel2); min-width:3ch; }
.bd-w-srctbl thead th:first-child { left:0; z-index:3; }
```
- `--bd-scroll-top`과 `--bd-status-h`는 `measureBar()`가 `--bd-bar-h`와 같은 방식으로 재서 넣습니다. 구현 방식은 개발 판단입니다.
- 스크롤은 `#bd-w-srcbody` 하나만 합니다. 지금은 aside 전체가 스크롤합니다.
- 고정 머리와 선택 칸 외곽선이 겹치지 않게 `td.is-src`에 `scroll-margin: 28px 0 0 40px`(머리 높이와 행번호 너비)를 줍니다.

**6-3 칸 모양**
- 숫자 칸(값이 숫자 형식): 현행대로 오른쪽 정렬, mono, nowrap.
- 문장 칸: `text-align:left; max-width:14em; overflow:hidden; text-overflow:ellipsis;`. 전체 문장은 `title`로 제공합니다. 표시용 축약일 뿐 값은 바꾸지 않습니다.
  - 추정 효과: C-2 기준 A·B열 678px → 약 340px. 측정값이 아니라 추정입니다.
- 매핑 안 된 칸은 `color:var(--muted)`, 매핑된 칸(`td[data-key]`)은 `var(--fg)`입니다. 대비 추정: muted #8b94a3와 panel #151a22는 약 5.7:1로 AA 통과입니다.
- 선택 칸: 현행 `.is-src`(틸 2px와 13%)를 유지합니다. 같은 행의 행번호 th에 `box-shadow: inset 2px 0 0 var(--accent-color)`를 더해 고정된 행 머리에서도 어느 행인지 보이게 합니다.

**6-4 넓게 보기 토글**
- `<button type="button" data-w="wide" aria-pressed="false">넓게 보기</button>`
- 누르면 `.bd-w-grid.is-wide { grid-template-columns:minmax(0,2fr) minmax(0,3fr); }`가 됩니다. 1920px에서 원본은 약 970px로 추정됩니다.
- 이름은 그대로 두고 `aria-pressed`만 바꿉니다(토글 패턴). 상태는 이 화면 메모리에만 둡니다(저장소에 쓰지 않는다는 board-write 원칙).
- 전환 시 200ms 비율 전환. reduced-motion이면 즉시 바꿉니다.

**6-5 동작과 키보드**
- **양식 칸 선택:** 원본 칸을 패널 안에서 **가로·세로 가운데**로 스크롤합니다. 이미 완전히 보이면 움직이지 않습니다. 페이지 스크롤은 건드리지 않습니다.
- **표 점프 버튼 [C-2]:**
  - 그 표 범위의 첫 행을 고정 머리 바로 아래, 첫 열을 행번호 오른쪽에 맞춥니다.
  - 그 표 태그의 접근 이름은 "C-2 Ⅱ. 명목가치 수익성 원본으로 이동"입니다.
  - 지금 선택 칸이 속한 표 버튼은 `aria-current="true"`로 두고 13% 틸 틴트를 줍니다.
- **[선택 칸으로]:** 선택이 없으면 disabled입니다. 누르면 위 가운데 정렬을 다시 합니다. 사용자가 원본을 직접 스크롤해 길을 잃었을 때 되돌아오는 길입니다.
- **`#bd-w-srcbody`:** `tabindex="0"`, `role="region"`, `aria-label="엑셀 원본 표, 방향키로 스크롤"`.
  - 지금 aside의 tabIndex는 -1이라 키보드로 원본을 스크롤할 수 없습니다.
  - 포커스 링은 전역 틸 2px, offset -2px(안쪽)입니다.
- **원본 td는 탭 순서에 넣지 않습니다.** 주 작업은 왼쪽 grid의 방향키 이동이고, 원본은 그 결과를 보여 주는 곳입니다. 원본 칸 클릭 선택(현행)은 마우스용 보조로 유지합니다.
- **점프 목록은 버튼 5개와 [선택 칸으로] 1개입니다.** 표가 많아지면 1행 가로 스크롤(`flex-wrap:nowrap; overflow-x:auto`)로 처리합니다. 셀렉트로 바꾸지 않습니다. 표 이름이 좌측 카드의 'A', 'C-2' 표기와 같아서 눈으로 대응하기 쉽기 때문입니다.

**6-6 좁은 화면**
- 지금 900px 기준은 뷰포트 기준이라, 사이드바(248px)를 뺀 929px에서 원본이 235px까지 줄어듭니다.
- **원본 패널 너비가 360px 미만이 되는 지점에서 세로 배치로 바꿉니다** (`@container`, 또는 뷰포트 기준을 약 1180px로).
  - 세로 배치에서는 원본을 양식 위가 아닌 **아래쪽 고정 창**(`max-height:40vh`, 상단 경계 1px `--line-strong`)으로 둡니다.
  - 정확한 구현은 상태 줄과의 겹침 처리를 포함해 개발이 결정합니다.

## 7. 문구 / 접근성 목록
- **문구:**
  - '넓게 보기'(토글, aria-pressed)
  - '표 위치:'(점프 목록 레이블, 12px muted)
  - '선택 칸으로'
  - 시트 캡션: '수익성분석 시트 · A54:K93'(현행 형식 유지)
  - 기존 '원본 접기/펼치기'는 유지합니다.
- **접근성:**
  - 스크롤 영역 키보드 접근: 현재 불가 → `tabindex=0`과 region.
  - 고정 머리글로 행·열 문맥 유지.
  - 선택 행 표시를 행 머리에도 둬서 색 단독 전달을 보완(외곽선, 행 머리 막대, 상태 줄 문장 3중).
  - 축소 보기는 쓰지 않아 10px 이상 유지.
