## 4. 우선순위 이슈

**P2-1 `teamUnresolved` 용어가 섞여 있고 기존 문구와 다르다**
- **근거**: `prepboard.js:43` `'결재선(소속 팀장)이 지정되지 않아 내 건만 보입니다. 관리자에게 결재자 지정을 요청하세요.'`
- **왜 문제인가**:
  - 한 메시지 안에서 '결재선'과 '결재자'가 섞입니다.
  - '내 건'은 이 화면 어디에도 없는 말입니다. 화면은 '내 작업'·'내 담당'을 씁니다.
  - '관리자'도 다른 화면의 같은 상황 문구와 다릅니다. 다른 화면은 `prep.js:141`·`team.js:80`에서 '시스템 관리자에게 상위 결재자 지정을 요청하세요'라고 씁니다.
  - '보입니다'는 팀 작업 단추가 눌린 상태에서 무엇이 나오는지 흐리게 말합니다.
- **수정 문안(그대로 교체)**:
```js
teamUnresolved: '상위 결재자(소속 팀장)가 지정되지 않아 팀 작업에 내가 담당한 기관만 나옵니다. 시스템 관리자에게 상위 결재자 지정을 요청하세요.',
```
  - 뒤에 scopeNote가 이어 붙는 지금 구조(`scopeNoteText` 261줄)는 그대로 둡니다.
  - 시험 248줄 이후의 기대 문자열도 함께 바꿉니다.

**P2-2 결재선 없는 팀원이 0건이면 '팀에 … 없습니다'가 사실과 다르다**
- **근거**:
  - `emptyModel`(282줄)은 team이면 늘 `T.emptyTeam`('팀에 개설 승인이 끝난 기관이 없습니다…')을 씁니다.
  - team_resolved:false면 서버는 팀이 아니라 나 혼자만 거릅니다.
- **왜 문제인가**: 팀원 기관이 실제로 있어도 '팀에 없다'고 단정합니다. 바로 위 안내 줄('팀 작업에 내가 담당한 기관만 나옵니다')과도 어긋납니다.
- **수정**:
```js
// T에 추가
emptyTeamSolo: '내가 담당한 기관 중 개설 승인이 끝난 곳이 없습니다. 개설 전 기관은 내 작업에서 봅니다.',
// emptyModel 282줄
if (scope === 'team') return { kind: 'none', text: f.teamResolved === false ? T.emptyTeamSolo : T.emptyTeam, actions: [{ act: 'scope-mine', label: T.seeMine }] };
// paintTable 506줄
pb.emptyModel(B.data.rows.length, rows.length, { q: B.q, scope: B.scope, teamResolved: B.teamResolved })
```
  - 시험 1건을 더합니다: `emptyModel(0,0,{scope:'team',teamResolved:false}).text === T.emptyTeamSolo`

**P3-1 마우스를 올린 세그먼트 단추의 오른쪽 테두리가 옆 단추에 덮인다**
- **근거**:
  - `.pb-sc { margin-left:-1px }`(1460)로 단추가 1px 겹칩니다.
  - 공통 `button:hover { border-color:var(--muted) }`(44)가 테두리 색을 바꾸지만, z-index는 눌린 단추와 포커스에만 있습니다(1463·1464).
  - 그래서 눌리지 않은 단추에 마우스를 올리면 오른쪽 1px이 다음 단추 테두리 밑에 깔립니다.
- **수정(한 줄 추가)**:
```css
.pb-sc:hover { position:relative; z-index:1; }
```
  - 눌린 단추(z-index 1, 포인트 테두리)와 나란히 있을 때는 소스 순서상 뒤 단추가 위에 옵니다. 실측에서 거슬리면 눌린 단추를 z-index 2로 올립니다.

**P3-2 (적어 두기만) 첫 불러오기 동안 '내 작업'이 눌려 보였다가 팀장·부장은 응답 뒤 다른 단추로 바뀐다**
- 규격 6-4의 '역할을 모르면 내 작업'대로라 결함은 아닙니다.
- 응답 `scope_default`를 쓰지 않는 것도 첫 요청이 scope 없이 가는 구조라 문제없습니다.
- 실측에서 깜빡임이 눈에 띄면 그때 다룹니다.

## 5. 문구 / 접근성
- 낭독기:
  - 범위를 바꾸면 `#pb-live`(role=status)가 "팀 작업, 기관 n곳"을 읽습니다. n은 검색으로 거른 뒤의 수라 화면 수와 같습니다.
  - 내 작업일 때 안내 줄은 `textContent=''`와 `hidden`으로 함께 비웁니다(487줄). 그래서 `aria-describedby`가 숨은 옛 문장을 읽는 일이 없습니다.
  - 계정이 바뀌면 `pb.reset`이 `paintScope`를 부릅니다.
- 선택 상태는 색만으로 전하지 않습니다(포인트 테두리 + 16% 틴트 + 굵게 + aria-pressed). 새 hex나 새 변수는 없습니다.
- 글자 크기는 모두 12px 이상입니다(세그먼트 12, 안내 줄 12). 10–16px 범위 안입니다.
- 검색 결과 없음 문구는 받침에 맞게 와/과를 고릅니다(시험 276·277).
- 고칠 문구는 P2-1·P2-2 두 건입니다.
