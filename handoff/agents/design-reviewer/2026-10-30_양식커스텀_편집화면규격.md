# 이사회 자료 양식 커스텀 1단계 — 편집 화면 규격 (design-reviewer, 2026-10-30)

> 소스 읽기 기반. 실제 화면·대비·타깃 크기는 측정하지 않았다. 대화에서 받은 보고서의 핵심 요약이며 원문 전체는 아니다.

## 구성안 (권장: A 변형)
| 안 | 평가 |
|---|---|
| **A. 같은 화면 `보기 / 양식 편집` 모드 전환(권장)** | 편집 결과가 곧 작성 화면의 문서. 권한 없으면 `[양식 편집]` 버튼을 그리지 않음. 저장 단위는 양식 전체(새 버전 1개) |
| B. 별도 편집 화면 | 메뉴 키·nav/menus 골든 영향 |
| C. 카드 안 상시 인라인 편집 | 실수 편집·저장 시점 모호 |

## 상호작용
- **표 추가**: 인라인 패널에서 '수익성 분석표에 있는 표' 미리 정의 목록 고르기(새 빈 표·다른 양식 복사는 이번 제외). 기본은 맨 아래에 추가, 포커스는 새 카드의 제목 입력.
- **삭제**: 중립 버튼 + `confirm()`. 엑셀 값 칸이 있는 표면 "엑셀 값이 들어가는 칸 N개가 함께 빠집니다" 덧붙임. 표 1개 이상 필수(마지막은 삭제 불가).
- **순서**: 위/아래 버튼(드래그 제외). 이동 후 포커스 유지, 상태줄 `aria-live`.
- **편집 대상**: 양식 이름, 표 제목, 머리글, 고정 문구. 표 주석(※)은 이번에 읽기 전용.
- **매핑 칸**: 입력 대신 읽기 전용 + 텍스트 `잠김`, 범례 한 줄 "틸 배경 칸은 엑셀 값이 들어가는 칸입니다. 개발자만 연결을 바꿀 수 있습니다." 서버도 변조 요청 거부해야 함. 카드 머리의 A/B/C-2 라벨은 읽기 전용 식별자.

## 상태 화면
권한 없음(버튼 없음+힌트) / 편집 중 고정줄 `양식 편집 중 · v3 기준` / `● 저장 안 한 변경 N건`+카드 뱃지 `변경됨`·`추가됨`·`순서 바뀜`(작성 값 수정의 `수정됨`과 구분) / 저장 중 / 성공(`새 버전 v4로 저장했습니다. 앞으로 새로 만드는 건부터 적용됩니다.`) / 실패(입력 유지, `role="alert"`) / 충돌 409(`다른 사람이 먼저 v4로 저장했습니다.` → `[최신 내용 보기]`만) / 새 버전 안내 `confirm()` 2문장(결재 중인 건은 상신 때 버전 유지) / 결재 중 건 안내.

## 문구·접근성
화면에 `매핑`·`mapped`·`JSON` 같은 내부 용어 금지. `새 버전으로 저장`은 채운 주버튼이 아닌 중립 버튼+틸 테두리. 키보드: 카드 단위 `section`, Tab 순서(제목→위→아래→삭제→칸), `이 표 칸 건너뛰기`, 매핑 칸은 포커스 가능하고 `aria-readonly`. 색 단독 금지(뱃지 텍스트+막대, `잠김` 텍스트).

## 기존 화면과의 일관성 이슈
채운 주버튼 금지 계약, `--orange` 의미 3중(주의·결재·수정됨 → 텍스트로 구분), 틸 이중 사용(매핑·선택), 편집 모드에서 카드 머리 높이가 커져 모드 전환 시 화면이 뜀(스크롤 유지), `board.FORMS` 하드코딩 → 서버 목록으로 교체.

## 사용자에게 남긴 질문
표 추가 위치(맨 아래 vs 삽입 지점), 뱃지 이름 `변경됨`, 새 버전 확인 `confirm()` 유지, 표 주석 읽기 전용 여부.

## 이관
기획: 편집 권한자 정의·표시 수위, 같은 표 중복 허용 여부(백엔드는 금지 제안), 이전 버전 되돌리기 포함 여부, 동시 편집 규칙, 결재자용 읽기 전용 보기(영업부장, 별도 항목). 백엔드: 저장/버전/충돌 응답/매핑 칸 서버 보호. 프런트: 편집 상태 모델, 편집용 렌더 변형, 포커스 규칙, `canEdit` 필드 수신.
