### 접근성 P2: dlg.line에서 role을 글보다 먼저 정한다
지금 `dlg.line`은 `textContent`를 먼저 바꾸고 role을 status에서 alert로 바꾼다. 내용과 역할이 동시에 바뀌면 화면낭독기가 오류를 놓칠 수 있다. 순서를 바꾼다.
```js
  dlg.line = function (node, text, isErr) {
    if (!node) return;
    node.setAttribute('role', text && isErr ? 'alert' : 'status');
    const c = String(node.className || '').split(/\s+/).filter(function (x) { return x && x !== 'st-err'; });
    if (text && isErr) c.push('st-err');
    node.className = c.join(' ');
    node.textContent = text || '';
  };
```
