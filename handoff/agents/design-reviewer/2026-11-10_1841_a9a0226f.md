# 기관 임박도 지도 시안 v2: 전국 → 시도 확대 흐름 (design-reviewer, 2026-11-10)

## 먼저 알려야 할 사고: 8080 탭을 덮어씀
- 같은 Playwright 브라우저를 다른 세션이 함께 쓰면서 "현재 탭"을 8080 탭(4번)으로 바꿨습니다. 그 사이 제가 보낸 최종 시안 쓰기 한 번이 **탭 4(localhost:8080)의 화면을 시안 HTML로 덮어썼습니다.**

- 그 뒤로 탭 4는 건드리지 않았습니다. 다른 세션이 그 탭을 쓰고 있었다면 새로고침이 필요합니다.
- 이후 검증은 탭 2(about:blank)에서만 했고, 매번 주소를 먼저 확인했습니다.

## 1. 무엇을 어떻게 봤나
- **이번 반영 지시**: ① 전국은 B안 시도 칸 유지 ② 시도를 누르면 그 시도로 날아가 확대 ③ 원 크기는 확대 단계별 ④ 네이버식 단계 묶음 ⑤ "← 전국" 버튼 ⑥ C안(면 + 원)은 확대 화면 안에서.
- **확대 효과 기준**: 현행 지도의 `render.flyZoomTo`(render.js:226~241)와 옛 시안의 `#cloud-overlay`·`#breadcrumb`(index_3.0_taste.html:117~122, 456~458)를 읽고 같은 동작을 따랐습니다.
  - 시도 경계를 화면의 90%로 맞추는 확대, 750ms
  - 구름 덮개 0.7s
  - 왼쪽 위 "← 전국" + 지역 이름(mono)
- **1280×800에서 실제로 본 것**(직전 판):
  - 전국 시도 칸: 겹침 0
  - 서울 칸을 눌러 ×14.0(동네 단계)으로 확대, 포커스가 "← 전국"으로 이동
  - "← 전국"으로 돌아가면 포커스가 서울 칸으로 복귀
  - 경기 칸을 눌러 ×4.2(시도 단계): 원 54 + 묶음 12
- **그 판에서 찾아 고친 결함 3가지**(아래 최종본에 반영):
  1. 범례가 "지금 단계 전국"으로 잘못 표시됨
  2. 칸 단위로 묶어서 이웃 묶음끼리 맞닿음
  3. 묶음 옆 D-n 글자가 다른 묶음 숫자와 겹침("2D-4")
- **최종본 검증 범위**: 바뀐 묶음 로직만 따로 시험했습니다. 가짜 점 60/150/300개에서 맞닿은 묶음 0쌍, 묶음 아래 깔린 낱개 0개, 총 개수 보존을 확인했습니다. 최종본 전체 화면은 위 사고 때문에 다시 캡처하지 않았습니다. **메인이 저장한 뒤 한 번 열어 확인해야 합니다**(오류 0인지, 경기 확대 화면).
- **스크린샷**: `c:\github\GGReportAgent\.playwright-mcp\2026-11-10_기관표식v2_전국.png`, `..._v2_서울.png`, `..._v2_경기.png`(직전 판)
- **못 본 것**: 실제 geo 폴리곤(시안은 육각 격자로 대신함), ≤880px 화면, 스크린리더 낭독.

## 2. 흐름 정리 (시안 그대로)
1. **전국**
   - 지자체 면은 100% 색으로 칠합니다.
   - 시도 칸 17개를 지도 좌우 기둥에 위도 순으로 놓고 지시선으로 잇습니다.
   - 칸 문구: "서울 기관 69 / ▲ D-30 이내 6". 30일 이내가 있으면 칸 테두리와 지시선이 붉습니다.
   - 휠·끌기는 막습니다. 칸이나 지도의 시도 면을 누르면 확대합니다.
2. **확대**: 750ms 동안 배율은 로그로, 화면 중심은 직선으로 보간하고(cubic in-out) 구름 덮개를 0.7s 씌웁니다. 확대가 끝나면 화면 기준 8px 세밀 격자로 면을 다시 깝니다.
3. **시도 화면(C안 적용)**
   - 고른 시도의 지자체 면은 50%, 다른 시도는 16%.
   - 건물 기관은 크기 원이고, 원 크기는 **확대 단계**에 따라 정해집니다:

     | 단계 | 배율 | D-30 | D-90 | D-180 | 그 외 점 |
     |---|---|---|---|---|---|
     | 시도 | ×2.4~ | 24px | 16px | 10px | 6px |
     | 시군 | ×5~ | 28px | 18px | 12px | 7px |
     | 동네 | ×10~ | 32px | 20px | 13px | 8px |

     상한은 지름 32px입니다.
   - 범례 표는 지금 단계의 지름을 "지금 단계 시군: 원 지름 28·18·12·7px"처럼 보여 줍니다.
4. **네이버식 묶음**
   - 화면 48px 안에 4곳 이상이면 숫자 묶음으로 보입니다. 지름은 28~44px로 기관 수에 따라 커집니다.
   - 닿는 묶음은 합치고, 묶음 아래 깔린 낱개는 묶음에 흡수합니다.
   - 묶음 테두리는 안에서 가장 이른 기관의 단계를 따릅니다: 30일 이내는 빨강 2.2px + 옆에 D-n, 180일 이내는 빨강 1.2px, 그 밖은 회색 1px.
   - 묶음을 누르면 해당 기관들이 화면의 50%를 채우도록 확대합니다(최소 ×1.8배씩).
   - ×12부터는 묶음 없이 모두 낱개로 그립니다.
5. **돌아가기**: "← 전국" 버튼 또는 Esc. 600ms 축소 + 구름 덮개 후 시도 칸으로 돌아갑니다.
6. **목록**: 오른쪽 "전국 임박순 / 서울 임박순" 목록(버튼). 누르면 그 기관이 낱개로 보이는 배율(×12 이상)로 날아가 틸 물결로 표시합니다. 키보드 사용자가 지도를 쓰는 길입니다.
7. **레이어**: "지자체 (면) / 건물 기관 (원)" 토글은 두 화면 모두에 적용됩니다.

## 3. 측정 (직전 판, 같은 가짜 300곳)
- **전국**: 시도 칸 17개 겹침 0, 칸 97×48px로 24px 기준 충족.
- **경기 ×4.2**: 원 54 + 묶음 12. 겹친 원·묶음 0/24, 누르기 어려운 원 6/24, 겹친 D-n 0.
  - 1차 시안(A안 전국)은 45/61 겹침, 61/61 누르기 어려움이었습니다. 확대와 묶음으로 크게 줄었습니다.
- **서울 ×14**: 원 104, 겹침 4/24, 누르기 어려움 9/24, D-n 1.
  - 서울은 가짜 데이터가 아주 밀집해 동네 단계에서도 일부가 남습니다. 목록이 대체 경로입니다.

## 4. 남은 디자인 이슈
- **P2. 확대 중 면이 거칠어 보임**: 날아가는 750ms 동안은 전국용 큰 육각이 커지며 보입니다. 끝나면 세밀 격자로 바뀝니다. 실제 화면은 geo 폴리곤(벡터)이라 이 문제가 없습니다. 시안만의 한계입니다.
- **P2. 시도 칸 지시선 교차**: 전남·충북 지시선이 다른 선과 교차합니다. 실제 시도 중심점으로 바꾸면 달라지므로 구현 때 다시 봐야 합니다.
- **P2. 묶음 안의 30일 이내 기관**: 숫자 묶음 안에 들어가면 그 기관의 원은 사라지고, 묶음 테두리와 D-n만 남습니다. "30일 이내는 늘 낱개로 둔다"로 바꿀지는 아래 질문 2입니다.
- **P3. 용어 정리**: 툴팁·목록은 "예정일 경과"로 맞췄습니다(기존 경과 패널 용어).

## 5. 규격 (구현용)
- **단계 경계**: ×2.4 / 5 / 10. 묶음 해제 ×12. 묶음 반경 48px, 4곳부터 묶음. 최대 배율 ×16.
- **원**: 180일 이내 원은 파스텔 단계색 채움 34% + 1.6px 테두리 + #0f1420 3.2px 후광. 누르는 영역은 반지름 ≥12px(점은 ≥7px).
- **묶음**:
  - 원: rgba(24,30,41,.9), 반지름 14+min(8, 2·log2 n)
  - 숫자: 12px mono 700 #e2e7ee
- **D-n**:
  - 원·묶음: 11px mono 700 #f5c1c3 + #0f1218 3px 후광. 자리는 오른쪽→왼쪽→위→아래, 임박한 기관이 먼저.
  - 지자체 면: 잉크 #141922 + #eef2f8 후광, "대전 D-21".
- **면 투명도**: 전국 1 / 고른 시도 0.5(원 켜짐 시) / 다른 시도 0.16 / 면 끔 0.06.
- **"← 전국"**: 유리 스타일(rgba(24,30,41,.86) + blur 8px + 흰색 8% 테두리), r10, 6px 14px, 12px 글자. 옆 지역 표시는 12px mono.
- **미상 링**: #98a1af로 상향 반영(1차 보고서 P2).

function inView(i) { var s = scr(i.b); return s[0] > -30 && s[0] < W + 30 && s[1] > -30 && s[1] < H + 30; }
function rectHit(p, q) { return p.x < q.x + q.w && q.x < p.x + p.w && p.y < q.y + q.h && q.y < p.y + p.h; }
function rectCircle(q, c) { var nx = clamp(c.x, q.x, q.x + q.w), ny = clamp(c.y, q.y, q.y + q.h), dx = c.x - nx, dy = c.y - ny; return dx * dx + dy * dy < c.r * c.r; }
function dist(a, b) { return Math.hypot(a[0] - b[0], a[1] - b[1]); }
function makeGroup(members) {
  var x = 0, y = 0, minD = null;
  members.forEach(function (o) { x += o.s[0]; y += o.s[1]; if (o.i.d !== null && o.i.d >= 0 && (minD === null || o.i.d < minD)) minD = o.i.d; });
  return { n: members.length, s: [x / members.length, y / members.length], minD: minD, members: members, r: 14 + Math.min(8, Math.log(members.length) / Math.LN2 * 2) };
}
/* 네이버 지도식 단계 묶음: 화면 48px 안에 4곳 이상이면 숫자 묶음. 닿는 묶음은 합치고, 묶음 아래 깔린 낱개는 흡수. ×12부터는 모두 낱개 */
function clusterize(items) {
  GROUPS = []; clustered = {};
  if (V.k >= UNCLUSTER) return items;
  var n = items.length, nb = items.map(function () { return []; });
  for (var a = 0; a < n; a++) for (var b = a + 1; b < n; b++) if (dist(items[a].s, items[b].s) < GRAD) { nb[a].push(b); nb[b].push(a); }
  var order = items.map(function (_, i) { return i; }).sort(function (a, b) { return nb[b].length - nb[a].length; });
  var used = {}, gs = [];
  order.forEach(function (a) {
    if (used[a]) return;
    var m = [a].concat(nb[a].filter(function (b) { return !used[b]; }));
    if (m.length < GMIN) return;
    m.forEach(function (b) { used[b] = 1; });
    gs.push(makeGroup(m.map(function (b) { return items[b]; })));
  });
  var singles = items.filter(function (_, i) { return !used[i]; });
  function mergeOnce() {
    for (var i = 0; i < gs.length; i++) for (var j = i + 1; j < gs.length; j++) {
      if (dist(gs[i].s, gs[j].s) < gs[i].r + gs[j].r + 4) { gs[i] = makeGroup(gs[i].members.concat(gs[j].members)); gs.splice(j, 1); return true; }
    }
    return false;
  }
  while (mergeOnce()) { /* 닿는 묶음이 없을 때까지 */ }
  singles = singles.filter(function (o) {
    for (var g = 0; g < gs.length; g++) if (dist(o.s, gs[g].s) < gs[g].r + 2) { gs[g].members.push(o); return false; }
    return true;
  });
  GROUPS = gs.map(function (g) { return makeGroup(g.members); });
  GROUPS.forEach(function (g, k) { g.members.forEach(function (o) { clustered[o.i.id] = k; }); });
  return singles;
}

function drawMarkers(list, RR) {
  var items = list.map(function (i) { return { i: i, s: scr(i.b), r: RR[i.tier] }; });
  var singles = clusterize(items);
  singles.sort(function (a, b) { return (ORDER[a.i.tier] - ORDER[b.i.tier]) || ((b.i.d === null ? 9e9 : b.i.d) - (a.i.d === null ? 9e9 : a.i.d)); });
  var selPos = null;
  singles.forEach(function (o) {
    var i = o.i, g = el('g', { transform: 'translate(' + o.s[0].toFixed(1) + ',' + o.s[1].toFixed(1) + ')' }, mkL);
    if (BIG[i.tier]) { el('circle', { r: o.r, 'class': 'halo' }, g); el('circle', { r: o.r, 'class': 'disc', fill: P[i.band], stroke: P[i.band] }, g); }
    else if (i.tier === 'dot') el('circle', { r: o.r, 'class': 'dot', fill: P[i.band] }, g);
    else el('circle', { r: o.r, 'class': i.tier }, g);
    el('circle', { r: BIG[i.tier] ? Math.max(o.r, 12) : Math.max(o.r, 7), 'class': 'hit', 'data-id': i.id }, g);
    if (i.id === V.sel) selPos = { s: o.s, r: o.r };
  });
  GROUPS.forEach(function (gr, n) {
    var hot = gr.minD !== null && gr.minD <= 30, warm = gr.minD !== null && gr.minD <= 180;
    el('circle', { cx: gr.s[0].toFixed(1), cy: gr.s[1].toFixed(1), r: gr.r.toFixed(1), 'class': 'gb', stroke: warm ? P.red : '#98a1af', 'stroke-width': hot ? 2.2 : warm ? 1.2 : 1, 'stroke-opacity': hot ? 1 : .75, 'data-g': n }, grL);
    var t = el('text', { x: gr.s[0].toFixed(1), y: (gr.s[1] + 4).toFixed(1), 'text-anchor': 'middle', 'class': 'gn' }, grL); t.textContent = gr.n;
    if (V.sel && clustered[V.sel] === n) selPos = { s: gr.s, r: gr.r };
  });
  /* D-n 글자: 30일 이내 낱개 원 + 30일 이내를 품은 묶음. 임박한 순서로 오른쪽, 왼쪽, 위, 아래 */
  var obst = singles.filter(function (o) { return BIG[o.i.tier]; }).map(function (o) { return { d: o.i.tier === 't1' ? o.i.d : null, x: o.s[0], y: o.s[1], r: o.r }; })
    .concat(GROUPS.map(function (g) { return { d: g.minD !== null && g.minD <= 30 ? g.minD : null, x: g.s[0], y: g.s[1], r: g.r }; }));
  var labs = obst.filter(function (o) { return o.d !== null; }), placed = [], hidden = 0;
  labs.sort(function (a, b) { return a.d - b.d; }).forEach(function (o) {
    var txt = dd(o.d), w = txt.length * 6.2 + 4, h = 13, x = o.x, y = o.y, r = o.r;
    var cands = [[x + r + 4, y - h / 2, 'start'], [x - r - 4 - w, y - h / 2, 'end'], [x - w / 2, y - r - 4 - h, 'middle'], [x - w / 2, y + r + 3, 'middle']];
    var pick = null;
    for (var n = 0; n < cands.length && !pick; n++) {
      var q = { x: cands[n][0], y: cands[n][1], w: w, h: h };
      if (!placed.some(function (p) { return rectHit(p, q); }) && !obst.some(function (c) { return c !== o && rectCircle(q, c); })) pick = cands[n];
    }
    if (!pick) { pick = cands[0]; hidden++; }
    placed.push({ x: pick[0], y: pick[1], w: w, h: h });
    var tx = pick[2] === 'start' ? pick[0] + 2 : pick[2] === 'end' ? pick[0] + w - 2 : pick[0] + w / 2;
    var t = el('text', { x: tx.toFixed(1), y: (pick[1] + h - 3).toFixed(1), 'text-anchor': pick[2], 'class': 'dlab' }, lbL); t.textContent = txt;
  });
  /* 측정 */
  var pts = singles.map(function (o) { return o.s; }).concat(GROUPS.map(function (g) { return g.s; }));
  var ov = 0, hard = 0;
  obst.forEach(function (a) {
    var isOv = false, isHard = false;
    obst.forEach(function (b) { if (a !== b && Math.hypot(a.x - b.x, a.y - b.y) < Math.max(a.r, b.r)) isOv = true; });
    if (a.r < 12) pts.forEach(function (p) { var dd2 = Math.hypot(a.x - p[0], a.y - p[1]); if (dd2 > 0.01 && dd2 < 24) isHard = true; });
    if (isOv) ov++; if (isHard) hard++;
  });
  if (selPos) { [1, 2, 3].forEach(function (n) { el('circle', { cx: selPos.s[0], cy: selPos.s[1], r: Math.max(selPos.r + 2, 6), 'class': 'ring r' + n }, selL); }); }
  return { singles: singles.length, groups: GROUPS.length, big: obst.length, ov: ov, hard: hard, lab: hidden };
}

/* 확대·이동: 현행 지도의 flyZoomTo(750ms, 경계의 90%로 맞춤) + 구름 덮개 700ms를 그대로 따른다 */
var anim = 0, settle = 0;
function ease(t) { return t < .5 ? 4 * t * t * t : 1 - Math.pow(-2 * t + 2, 3) / 2; }
function animateTo(k, tx, ty, ms, done) {
  cancelAnimationFrame(anim);
  if (RM.matches) { V.k = k; V.tx = tx; V.ty = ty; render(); if (done) done(); return; }
  var k0 = V.k, x0 = V.tx, y0 = V.ty, t0 = performance.now();
  /* 배율은 로그로, 화면 중심은 직선으로 보간해 "누른 곳으로 날아가는" 느낌을 낸다 */
  var c0 = [(W / 2 - x0) / k0, (H / 2 - y0) / k0], c1 = [(W / 2 - tx) / k, (H / 2 - ty) / k];
  function step(t) {
    var p = Math.min(1, (t - t0) / ms), e = ease(p);
    V.k = Math.exp(Math.log(k0) + (Math.log(k) - Math.log(k0)) * e);
    var cx = c0[0] + (c1[0] - c0[0]) * e, cy = c0[1] + (c1[1] - c0[1]) * e;
    V.tx = W / 2 - cx * V.k; V.ty = H / 2 - cy * V.k; render();
    if (p < 1) anim = requestAnimationFrame(step); else if (done) done();
  }
  anim = requestAnimationFrame(step);
}

function fitBox(r, fill, kmin, kmax) {

  return { k: k, tx: W / 2 - cx * k, ty: H / 2 - cy * k };
}

## 7. 이관 메모
- [이관: 개발] **Playwright 브라우저 분리**: 세션마다 브라우저를 따로 쓰거나 별도 isolated context를 쓰도록 바꿔야 합니다. 다른 세션이 현재 탭을 바꾸는 바람에 이번에 8080 탭을 덮어썼습니다.
- [이관: 개발] **구현 범위**:
  - 현행 `flyZoomTo`/`loadRegionGeoWithRetry` 드릴다운 흐름에 시도 칸(전국)과 시도 안의 원·묶음 층을 얹는 방식이 됩니다.
  - 시안의 육각 격자는 버리고 실제 geo 폴리곤을 씁니다.
  - 기존 8개 이상 클러스터 배지(render.js:417~423)는 이번 묶음 방식으로 대체합니다.
- [이관: 기획] 1차 보고서 이관 항목은 그대로 유효합니다:
  - 기관 종류 코드와 구역형/건물형 분류
  - D-180과 182 경계
  - 경과 건 표시 크기
  - 좌표 확보 방법
  - 시도 칸 기준을 좌표로 계산할지, 주소의 시도 코드로 할지
