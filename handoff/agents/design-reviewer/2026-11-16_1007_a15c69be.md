## 기관 사업계획 화면 1: 규격 보충 (기획 데이터 정의 반영, 11-16)
**방법**: 앞 보고서 규격에 덧붙이는 보충이다. 화면은 여전히 열어 보지 못했다(Playwright 연결 실패). 새 토큰은 없고 기존 클래스만 쓴다.

**앞 보고서에서 바뀌는 곳 3개**
- 5절 "예산 변환·합계는 화면이 하지 않는다" → 하위사업 합 **계산값** 하나만 허용한다(아래 C). 다른 변환·합계는 여전히 하지 않는다.
- 5절 "쪽수가 하나도 없으면 열을 뺀다" → 25구는 쪽수가 있다. 쪽 열은 항상 둔다. 대신 URL이 없다(아래 A).
- 5절의 "미기재" 칩 → 아래 예산 상태 4종 문구로 바꾼다. 6절의 원천 종류 4개 → 7개로 늘린다.

**배지 모양 규칙 하나 (새로 고정)**: 테두리 모양이 뜻의 종류를 나눈다. 같은 행에 여러 배지가 붙어도 서로 섞이지 않게 하기 위해서다. 빨강은 계속 쓰지 않는다.
- **점선 칩 `.pop-unk`** = 아직 확인 못 함. 미확인 관례를 그대로 쓴다.
- **실선 외곽 `.wf-badge.pp-cancel`**(--muted 글자, 바탕 없음) = 사실로 끝난 것. 기간 지남, 폐기.
- **주황 `.wf-badge.gap`** = 다시 확인할 때가 됐다. 오래됨에만 쓴다.
- **중립 `.wf-badge.pp-neutral`** = 종류 이름. 원천 종류, "사업계획 N건".

**A. 출처 (URL 없음)**
- 문서 카드의 출처 줄은 hc.srcHtml 순서를 지킨다. URL이 있으면 링크와 .db-why "(인터넷 PC에서 열림)"을 둔다.
- URL이 없으면 제목을 링크 없이 글자로 두고, 그 뒤에 `.pop-unk` "출처 URL 없음"을 붙인다.
  - 예: "4개년계획 · 민선8기 공약 실천계획 · 확인 2025-02-10 [출처 URL 없음]"
- 카드 아래 .db-why: "원문 쪽수로 대조하세요."
- 사업표의 쪽 열(44px, mono)은 "42쪽"으로 쓴다. 쪽이 없는 행은 .pop-unk "미확인"이다.
- 낭독용 이름: 칸에 `aria-label="원문 42쪽"`.

**B. 기간 지남·폐기 (행은 지우지 않는다)**
- 사업 행은 원래 자리에 그대로 둔다. 숨기기 토글도 두지 않는다.
- 사업명 칸에서 사업명 뒤에 `.wf-badge.pp-cancel` "기간 지남" 또는 "폐기"를 붙인다.
- 행 글자는 --fg 대신 --muted로 낮춘다. 대비는 --muted/--panel 약 6.4:1이다.
- opacity와 취소선은 쓰지 않는다. 취소선은 인용할 글을 읽기 어렵게 하고, opacity를 쓰면 대비가 4.5 아래로 떨어진다(DESIGN 규칙).
- 문서 전체가 기간 지남이면 카드 1줄 원천 칩 옆에 "기간 지남"을 붙이고, 카드 아래 .db-why를 둔다: "2022년에 끝난 계획입니다. 누리집에 새 계획이 있는지 확인하세요."

**C. 예산 (원문 단위, 상태 4종)**
| 상태 | 칸 모양 | 낭독 |
|---|---|---|
| 금액 | mono 오른쪽 정렬 "1,200" + 단위(백만원/억원/천원). 문서 안 단위가 같으면 열 머리 "예산(백만원)"에만 쓴다 | "1,200 백만원" |
| 금액·계산값 | mono 값 + 아래 줄 .db-why 11px "계산값". 상위사업에만 쓴다 | "하위사업 합계 계산값 3,400 백만원" |
| 확인안됨 | .pop-unk "확인안됨" | 같은 글자 |
| 원문에 없음 | .pop-unk "원문에 없음" | 같은 글자 |
| 해당없음 | 칩 없이 .db-why "해당없음" (사실이라 점선을 쓰지 않는다) | 같은 글자 |
- 원문의 '-'와 빈칸은 0으로 바꾸지 않는다. 데이터 상태 그대로 위 표의 글자로 보인다.
- 계산값은 하위사업의 단위가 모두 같을 때만 낸다. 단위가 섞였으면 "확인안됨"으로 둔다. 이 판정은 개발로 넘긴다.
- 장 머리에는 예산 합계를 두지 않는다. 계산값을 더 늘리지 않기 위해서다.

**D. 확인 상태 4종 (확인됨 / 부분확인 / 확인안됨 / 미조사)**
- 문서 카드 .db-dl에 "확인 상태" 칸을 두고 건수로 요약한다. 예: "확인됨 18 · 부분확인 3 · 확인안됨 2 · 미조사 1"(숫자 mono). 지금 문서 확인 상태 하나만 있다면 그 상태 칩 하나를 둔다.
- 사업 행에는 확인됨이 아닐 때만 사업명 뒤에 .pop-unk 칩을 붙인다("부분확인" / "확인안됨" / "미조사"). 확인됨은 기본값이라 표시하지 않아 표를 조용히 둔다.
- '확인안됨'은 점선이고 '폐기'는 실선이라 모양과 글자 둘 다 다르다. 확인안됨 행은 글자를 --muted로 낮추지 않는다. 폐기처럼 보이면 안 되기 때문이다.
- 카드 아래 안내(.db-why, 확인안됨이 1건 이상일 때): "'확인안됨'은 원문에서 아직 대조하지 못한 사업입니다. 폐기된 사업이 아닙니다."

**E. 목록 행 상태 배지 (5절 대체)**
- 자료가 없으면 "자료 없음" 하나만 단다(.pop-unk).
- 자료가 있으면 "사업계획 N건"(pp-neutral)을 단다. 이어서 해당할 때만 두 배지를 이 순서로 붙인다.
  - "기간 지남"(pp-cancel): 계획의 마지막 해가 올해보다 앞일 때.
  - "오래됨"(gap 주황): 확인일이 12개월을 넘었을 때.
- 배지는 최대 3개다. .meta가 줄바꿈되므로(flex-wrap) 300px 안쪽에서는 둘째 줄로 내려가도 된다. 말줄임은 쓰지 않는다.
- 목록 상태 필터(전체 / 자료 있음 / 자료 없음)는 그대로 둔다. 오래됨·기간 지남 필터는 더하지 않는다. 선택지 4개를 넘기지 않기 위해서다.
- 문구 수정: 앞 보고서의 "확인 오래됨"을 **"오래됨"**으로 바꾼다. 기획 정의에 맞춘다. 문서 카드 경고 줄은 그대로 둔다: "확인 2024-03-02 뒤로 12개월 넘게 다시 확인하지 않았습니다."

**F. 원천 종류 7종**: 4개년계획 / 주요업무계획 / 예산서 / 공약이행 / 홍보물 / 회의록 / 기타. 모두 같은 pp-neutral 칩으로 쓴다. 홍보물·회의록에 낮은 신뢰를 색으로 붙이지 않는다. 신뢰 등급은 정의되지 않았고, 근거 없는 판정이 되기 때문이다.

**G. 와이어프레임 바뀐 줄** (앞 그림에서 해당 줄만)
```
│ 2027-03-01 추정 [사업계획 2건][기간 지남][오래됨] │
│ 민선8기 공약 실천계획 [공약이행][기간 지남]       │
│ 출처: 4개년계획 · 실천계획 · 확인 2025-02-10 [출처 URL 없음] │
│ 확인 상태  확인됨 18 · 부분확인 3 · 확인안됨 2 · 미조사 1 │
│ 3   청년 창업 지원 [확인안됨]   …        3,400 계산값  42쪽 │
│  3-2 공간 조성 [폐기]           …          원문에 없음  43쪽 │
```

**이관 메모**
- [이관: 개발] 계산값은 하위사업 단위가 모두 같고 금액 상태일 때만 합한다. 하위에 확인안됨이 섞이면 계산하지 않고 "확인안됨"으로 둔다. 디자인은 이 규칙이 확정되기를 기다린다.
- [이관: 기획] 확인 상태가 문서 단위인지 사업 단위인지, 둘 다인지. D의 카드 요약 모양이 이 답에 따라 갈린다.
- [이관: 기획] '기간 지남'을 사업 단위에도 매기는지(사업별 기간이 있는지). 기획안에는 사업별 기간이 대부분 없다고 되어 있다. 문서 단위만이면 B의 행 배지는 '폐기'에만 쓴다.

**전/후 장**: 앞 보고서의 문안에 다음을 더한다. "출처 URL이 없는 자료는 'URL 없음'과 원문 쪽수로 대조하게 함. 0으로 보일 뻔한 '-'를 '원문에 없음'으로 구분함."
