# 이사회 자료 '작성' MVP 보강 규격 — 툴팁·수정 확인·복사·주의·합계·사유 (design-reviewer, 2026-11-02)

## 총평
새 요소 6개 모두 기존 부품 재사용(팝오버 글래스·인라인 확인 줄·`.wf-chip`·18% 틴트·`render.ICONS`). 최대 위험: `--orange`가 수정됨·주의·머리글 주의·합계 차이 4뜻 → **모양(아이콘·위치)을 다르게 + 문구 필수**.

## 1. 출처 툴팁(호버·키보드 포커스 공통)
- 원칙 양립: 툴팁 = 하단 상태 줄의 **사본**(툴팁에만 있는 정보 0개) → "호버 전용 정보 없음" 유지.
- 문서에 하나 `<div id="bd-tip" role="tooltip">`. DESIGN Popover: glass `rgba(21,26,34,.92)`+blur 10px+1px 흰 알파 테두리, 12px radius, 최대 폭 280px, padding 8px 10px, `--shadow`, 화살표 없음.
- 내용 순서: ① "B 수익성분석 · 순이익 · 2026"(12px) ② "수익성분석 시트 F8"(12px mono) ③ "표시 1,234 · 원래 값 1,233.6"(같으면 "표시 1,234"만) ④ 조건부 11px: 수정됨 "수정함 1,230 · 사유 반올림 맞춤" / 합계 칸 "표시 합 3,579 · 합계 3,580 · 차이 +1" / 읽지 못함 "읽지 못함: 수식 계산 결과가 파일에 없습니다" / 출처 없음 "엑셀에서 가져오지 않은 칸입니다".
- 위치: 칸 위 4px·왼쪽 정렬, 위 공간 < 작성 줄+8px면 아래로, 가장자리 8px 안, 원본 패널 가리지 않는 쪽.
- 지연: 호버 500ms 뒤, 벗어나면 100ms 유예(툴팁 위로 이동 허용, WCAG 1.4.13). 키보드 선택 400ms 머문 뒤.
- 닫힘: 포커스·호버 이탈, 첫 Esc는 툴팁만(두 번째 Esc 선택 해제), 입력 중·확인 줄 표시 중 숨김, 스크롤 시 닫힘.
- aria: 보일 때만 칸에 `aria-describedby="bd-tip"`. 칸 이름은 기존대로. reduced-motion이면 페이드 없음(기본 120ms opacity).
- 원본 패널 칸의 반대 방향 툴팁: P3, 1단계 제외 권장.

## 2. 수정 확인 줄(Q5)
- 언제: 원본 값 있고 아직 '수정됨'이 아닌 칸을 처음 고치려 할 때(Enter·F2·더블클릭·숫자 입력 — 숫자로 시작했으면 그 글자는 버림). 수정된 칸·읽지 못함·출처 없음은 묻지 않고 하이라이트만.
- 위치: 하단 상태 줄 자리 교체, `--panel2` 배경, 위 1px `--line-strong`, padding 10px 14px, 상태색 없음(질문이므로).
- 원본 패널: 해당 셀 `scrollIntoView({block:'center'})`(reduced-motion이면 auto), 2px 틸 링+틸 13% 틴트, 접혀 있으면 잠시 펼치고 [취소] 시 다시 접음.
- 문구(12px, 숫자 mono): ① "순이익 2026 값은 수익성분석 시트 F8에서 가져왔습니다. 표시 1,234 · 원래 값 1,233.6" ② 관련 합계 있을 때만 "이 칸이 들어간 합계: 순이익 합계 2026 — 표시 합 3,579 · 합계 3,580 · 차이 +1"(맞으면 "…합계는 지금 맞습니다.") ③ 확인한 칸이면 "고치면 이 칸의 확인 표시가 해제됩니다."
- 버튼: `[그래도 고치기]` `[취소]`(기본 버튼, 채운 주버튼 금지), **처음 포커스 [취소]**. Esc·[취소] = 닫고 칸으로, 값 그대로. [그래도 고치기] = 입력창 열고 전체 선택, 이번 작업 동안 그 칸은 다시 묻지 않음.
- role: `role="group" aria-label="고치기 전 확인"`, [취소]에 문구 describedby. `confirm()` 금지.

## 3. 복사 버튼(Q2)
- [모든 표 복사]: 작성 줄 `[엑셀 바꾸기] [모든 표 복사] [초안 워드 내려받기] [작성 끝내기]`(틸 테두리는 초안 워드만).
- [이 표 복사]: 각 표 카드 머리 오른쪽 끝, 작은 기본 버튼 12px(칩 다음).
- 빼는 것: 화면 상태 표시(틴트·체크·삼각형·보조 줄·사유). 값 = 화면 현재 값.
- 안내: 버튼 옆 `<span role="status">`(12px `--muted`), 다음 복사·작성 끝까지 유지.
- 문구: 표 하나 "‘B 수익성분석’ 표를 복사했습니다. 워드에서 Ctrl+V로 붙여 넣으세요." / 전체 "표 6개를 제목·주석과 함께 복사했습니다. 워드에서 Ctrl+V로 붙여 넣으세요." / 덧붙임 "확인하지 않은 칸 3개 / 합계 차이 1곳 / 머리글 주의 표 1개가 그대로 들어 있습니다."(복사는 막지 않음) / 실패(alert) "복사하지 못했습니다. 이 화면에서 복사가 막혀 있으면 [초안 워드 내려받기]로 받아 주세요."

## 4. 머리글 '주의' 표 배너(Q4)
- 표 카드 안 표 바로 위 전폭, 1px `--orange` 테두리+8% 틴트, 8px radius, padding 8px 12px, 왼쪽 ICONS 경고 12px.
- 제목(12px/700) "이 표는 머리글이 양식과 달라 위치대로 값을 채웠습니다." 본문 "값이 맞는 자리에 들어갔는지 모든 칸을 원본과 하나씩 확인해 주세요." 차이 목록(mono 11px) "양식 ‘구분’ · 엑셀 ‘항목’ (수익성분석 시트 B5)" 최대 3줄, 넘으면 "외 2개 더 보기"(aria-expanded).
- 카드 머리 칩 "주의 · 남은 칸 12"(18% 틴트, 11px), 표 전 칸 필터 '확인 필요', 요약 줄 "주의 n건 ▸"에 "머리글이 다른 표 1개" 합침.
- 다 확인하면 칩 "주의 · 모두 확인함"(`--muted` 글자, `--line` 테두리), 배너는 유지(결재자 설명용). 별도 alert 없음(요약 줄 status가 알림). 시트 없음 전체 중단은 기존 '양식 불일치' 상자.

## 5. 합계 차이(Q6)
- 차이 = 합계 칸 표시값 − 구성 칸 표시값 합(부호 필수 "+1"/"−2", 0이면 미표시).
- 합계 칸: 주의 모양(ICONS 경고 10px `--orange`), 칸 안 보조 줄 없음, 수치는 툴팁·상태 줄 "표시 합 3,579 · 합계 3,580 · 차이 +1".
- 구성 칸: 합계 칸 선택 중이거나 확인 줄이 언급할 때만 `box-shadow: inset 0 -2px 0 color-mix(in srgb, var(--orange) 55%, transparent)`.
- 카드 머리 칩 "합계 차이 1", 요약 줄 "합계가 맞지 않는 곳 2곳 ▸"(누르면 다음 합계 칸), 필터 '확인 필요'에 포함.
- 재검산: 수정 확정마다 상태 줄 live(polite) "순이익 합계 2026: 차이 +1 → 0, 이제 맞습니다." / "…+1 → +2". 자동 보정 없음.

## 6. 수정 사유 선택(Q6)
- 언제: 그 칸 첫 수정을 Enter로 확정한 직후 1회, 포커스는 사유 그룹 첫 항목. 고르면 칸으로, Esc는 "선택 안 함". 이후 변경은 상태 줄에서.
- UI: 상태 줄 안 `role="radiogroup" aria-label="수정 사유"`, `.wf-chip` 4개 [반올림 맞춤] [원본 값과 다르게 가져옴] [원본 오류] [기타] ('매핑 오류'는 내부 용어라 화면명 변경).
- 기본값 미선택·필수 아님(권장) — 요약 줄 "사유를 고르지 않은 수정 2칸" + '확인했음' 옆 비차단 안내.
- [기타]만 한 줄 메모(필수, 최대 100자, 80자 넘으면 "83/100" 카운터), 자리표시 "예: 본부 확정치로 맞춤", 빈칸이면 "기타 사유를 적어 주세요".

## 7. 기존 규격 변경점
1 §5 호버 원칙 유지 + "툴팁은 상태 줄 사본" 조항 2 §5 상태 줄에 원래 값·합계 차이·사유 그룹·확인 줄 교체 3 §4 '양식 불일치'는 시트 없음만, 머리글 차이는 표 배너로 4 §3 작성 줄에 [모든 표 복사], 카드 머리에 [이 표 복사]·칩 2종 5 필터 정의 "확인 필요: 읽지 못했거나, 주의가 붙었거나, 합계가 맞지 않거나, 머리글이 다른 표의 칸" 6 §7 Esc 순서 툴팁 닫기→선택 해제, 첫 수정 진입은 확인 줄 경유 7 §4 '검수 완료'에 비차단 안내 2종(합계 차이 남음·사유 없는 수정).

## 8. 계약 위반 위험
`--orange` 4뜻 → 모양 분리(수정됨=코너 삼각형, 주의·합계=ICONS 경고, 머리글=배너+칩), 색 단독 금지. 틸은 선택·포커스만. 채운 주버튼 금지, 틴트 ≤18%(배너 8%), 글자 10–16px, `confirm()` 금지, 툴팁 280px·12px radius. DESIGN.md Components 추가: 출처 툴팁(상태 줄 사본)·표 단위 주의 배너·작성 모드 칸 상태(합계 차이 포함).
