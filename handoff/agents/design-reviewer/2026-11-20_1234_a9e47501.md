## 4. 우선순위 이슈(규격과 다른 곳)

**P0·P1: 없음**

**P2-1. 표 머리가 고정되지 않습니다**
- **근거**: `index.html` 2583줄 `.rs-tt thead th`에 `position:sticky`가 없습니다. 규격 6-6은 ".hb-tt 문법(…sticky 머리…)"이고, 현황판 1885줄 `.hb-tt thead th { position:sticky; top:0; z-index:1; … }`에는 있습니다.
- **왜 문제인가**: 목표 기관은 최대 2,000행입니다. 스크롤을 내리면 '결과·근거·제안 진행' 열을 구분할 수 없습니다.
- **수정**: 2583줄에 `position:sticky; top:0; z-index:1;`을 더합니다. 1169px 이하에서는 `.rs-tp { overflow-x:auto }`가 sticky 기준 상자가 됩니다. 현황판이 같은 폭에서 어떻게 하는지 맞춰 보고, 같은 한계면 그대로 둡니다.

**P2-2. '확정 금고 은행' 열이 규격 최소 200px보다 좁아 은행 둘이면 잘립니다**
- **근거**: 2578–2579줄 열 폭 합은 210+72+190+84+160+100=816입니다. 990−2(테두리)−816 ≈ **172px**(계산값)이고, 규격 6-1은 "나머지(≥200)"입니다. "1금고 국민은행"+10+"2금고 농협은행"은 12px에서 약 190px, 패딩 20을 더하면 약 210px이라 말줄임됩니다.
- **왜 문제인가**: 성공 판정의 핵심 사실이 잘립니다. 대체로 둔 `title`은 마우스로만 보이고, td에 포커스가 가지 않아 키보드 사용자는 볼 수 없습니다.
- **수정 (둘 다 하기를 권합니다)**:
  - ① `c-evd` 160→150(규격 값), `c-res` 190→180. "신규 성공" 칩 약 75 + 6 + "목표 구분 기준" 약 76 + 패딩 20 = 약 177이라 180이면 들어갑니다. 이러면 은행 열이 약 192px이 됩니다.
  - ② 은행 칸만 두 줄을 허용합니다. `.rs-tt td.c-bank-cell { white-space:normal; line-height:16px; }`(행 40px 안에 두 줄이 들어감). rowHtml의 해당 td에 클래스 하나를 더하면 됩니다.

**P2-3. 같은 대상을 부르는 이름이 문구마다 다릅니다**
- **근거**: results.js 21–27줄
  - DENIED_MSG: "영업부서와 **전산 계열**만"
  - TRUNC_MSG: "**개발부서**에 알려 주세요"
  - LIMIT_MSG: "**담당자**에게 알려 주세요"
- **왜 문제인가**: 한 화면에서 같은 대상을 세 가지로 부릅니다. 사용자 결정(전산팀=개발부서, 11-17)과도 어긋납니다.
- **수정**:
  - DENIED_MSG → "협약 성과 모아 보기는 영업부서와 개발부서만 볼 수 있습니다."
  - LIMIT_MSG → "집계할 약정 기록이 너무 많습니다. 개발부서에 알려 주세요."
  - 서버 detail이 우선이므로 서버 문구도 같은지 확인이 필요합니다(이관).

**P3-1. 링크 색이 저장소 관례와 다릅니다**
- **근거**: 2545줄 `.rs-link { color:var(--accent-color) }`. 저장소의 링크는 `color:var(--fg); text-decoration-color:var(--accent-color); text-underline-offset:3px` 꼴입니다(1826·1852·2297·2382·2460줄). 테마 창이 accent를 바꾸므로 글자 대비도 보장되지 않습니다.
- **수정**: `.rs-link { … color:var(--fg); text-decoration:underline; text-decoration-color:var(--accent-color); text-underline-offset:3px; }`

**P3-2. 포커스 규칙이 두 번 적혀 있습니다**

**P3-3. 꺾쇠 내림선이 규격보다 1px 짧습니다**
- **근거**: 2550줄 `.rs-brace { height:4px; box-sizing:border-box; border-top 1px }`라 내림선이 3px입니다. 규격은 4px입니다.

**P3-4. '연중에 뺀 곳' 제목 이름에 설명문이 섞입니다**
- **근거**: results.js 349–351줄. h3 안에 `.db-why` "목표 기관 수와 성공률에 넣지 않았습니다."가 들어 있어, 제목 목록에서 긴 문장으로 읽힙니다.

**P3-5. 알 수 없는 결과 코드가 '결과 없음'과 같은 모양입니다**

**P3-6. 고대비 모드에서 막대 범례 색 견본이 구분되지 않습니다**
- **근거**: 2608줄. forced-colors에서는 채움이 사라져 재유치·신규·실패·대기 막대 칸이 같은 실선이 됩니다. 칸 안 숫자와 aria-label이 있어 정보는 남지만, 범례 견본은 구분이 안 됩니다.
- **수정 (선택)**: 범례 li는 이미 글자 라벨을 가지므로 그대로 둬도 됩니다. 기록만 남깁니다.
