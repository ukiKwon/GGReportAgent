# 이사회 자료 작업 화면 규격 (design-reviewer, 2026-10-30)

> 소스 읽기 기반(PRODUCT.md·DESIGN.md·nav.js·index.html·approvals.js). 실제 화면·양식은 보지 않았다. 계약: 변수명 동결, 10~16px 타입, 틸 단일 악센트, 채운 주버튼은 `#ch-send` 외 금지, 숫자 `--mono`, 외부 자원 금지, 바닐라 JS.

## 1. 핵심
화면의 가치는 "자동 입력"이 아니라 **재검수가 빠르고 틀리기 어렵다**는 것. 값과 엑셀 원본 영역을 눈으로 잇는 장치가 중심.

## 2. 구성안 비교
| 안 | 내용 | 평가 |
|---|---|---|
| A 좌우 분할 | 보고서 표 60% | 엑셀 원본(읽기 전용 HTML 표) 40% | 직관적·빠름. 폭 부족(1280px에서 본문 약 1000px) |
| B 매핑표+팝오버/드로어 | 표 전폭, 호버=팝오버·클릭=드로어 | 가독성 최고, 클릭 많음 |
| C 단계형 | 업로드→검수→결재 | 검수↔수정 왕복에 불리, 기존 화면과 불일치 |

**권장: A 기본 + 원본 패널 접이식**(접으면 B 동작). 1280px 이상만 고려하므로 기본 펼침. 880px 이하는 위아래 배치.

```
이사회 자료 [양식 ▼]  원본 파일명(저장 안 됨) [엑셀 바꾸기]   [상태칩] [결재 요청]
섹션 탭: A 재산상 이익제공·기부안 | B 수익성분석 | C 붙임 | D 세부
[필터: 전체|수정됨|확인 필요|미확인]  검수 12/48 확인  [원본 접기]
┌ 보고서 표(60%, 편집 가능) ┬ 엑셀 원본(40%, 읽기 전용) ┐
└ 하단 상태줄: 선택 D12 = 1,234 | 원본 1,234 | 수정됨→1,230 [원본값으로]
```

## 3. 상태 화면
| 상태 | 표현 |
|---|---|
| 빈 상태 | 점선 드롭 영역+파일 버튼. "수익성 분석 엑셀을 올려 주세요 / 원본 파일은 저장되지 않습니다." |
| 업로드 중 | 진행 줄+단계 문구+취소. reduced-motion 정지 |
| 양식 불일치 | 상단 `--red` 배너 `role="alert"`, 이유 목록, [다른 파일 선택][양식 다시 선택]. 값 채우기 안 함 |
| 일부 매핑 실패 | 빈 칸+빨간 점선+"읽지 못함", [확인 필요] 필터, 건수 요약 |
| 수정됨 | `--orange` 18% 틴트+코너 삼각형+아래 "원본 1,234" 보조줄(색 단독 금지) |
| 읽기 전용(결재 중) | 편집 불가, 원본 대조는 유지, 칩 "결재 중 · 팀장 대기", 회수 버튼 |
| 반려 후 | 편집 재개, 반려 사유 인용 |
| 새로고침 | 원본 패널 사라짐 → 처리 방식은 스냅샷 보관 결정(출처 목록은 유지) |

## 4. 상호작용·접근성
- 호버=미리보기, 클릭=고정(핀)+양방향 하이라이트, 더블클릭/Enter/F2=수정(선택과 수정 분리). 호버 전용 정보 없음, 터치는 탭=선택.
- 표 `role="grid"`, roving tabindex, 방향키·Enter·Esc·Ctrl+Z, `aria-describedby`로 원본 위치, 상태줄 `aria-live="polite"`.
- 색 단독 금지: 수정=코너 마크, 확인 필요=점선, 선택=2px 링(틸). 틸 의미는 선택/상호작용만. 대비 4.5:1은 구현 후 측정.

## 5. 문구
화면 머리 "이사회 자료 작성 — 수익성 분석 엑셀을 올리면 양식에 값이 채워집니다". 상시 안내 "원본 엑셀은 저장되지 않습니다". 수정 안내 "합계가 맞지 않으면 직접 고칠 수 있습니다. 고친 칸은 ‘수정됨’으로 표시되어 결재자도 볼 수 있어요." 결재 확인 "수정된 값 3칸이 포함됩니다. 결재 요청할까요? 팀장 → 부장 순서로 결재됩니다." 용어는 승인/반려/대기(`approvals.js`와 통일). "매핑"·"파싱" 같은 내부 용어 금지, 섹션 이름만.

## 6. 기존 화면과 일관성 이슈
1. `button.primary`는 이미 쓰이지만 DESIGN.md는 `#ch-send` 단독 → [결재 요청]은 중립 버튼+상태칩(틸 테두리) 권장
2. "수정됨"에 `#e0b44c`(오프토큰) 쓰지 말고 `--orange`+18% 틴트
3. `.soon-box h2` 20px는 램프 이탈(기존 이슈)
4. 섹션 탭은 결재함 `.ap-tabs` 재사용
5. 보고서 표는 `.ad-grid` 계열+숫자 `--mono` 우측 정렬, 원본 표는 A,B,C/1,2,3 머리
6. 값 팝오버는 지도용 `#popover`와 별도 요소(같은 글래스 스타일)
7. 결재선 칩·라벨은 결재함 함수 재사용
8. `soon`→`live` 전환 시 메뉴 키 필요, `nav.test.js`·`menus.test.js` 영향

## 7. 사용자 답변 반영(2026-10-30)
값별 확인 체크 필요(검수 n/m), 1280px 이하 없음(원본 패널 기본 펼침), 결재는 전체 단위([결재 요청] 하나, 섹션별 아님).

## 8. 이관 메모
- [기획] 볼 수 있는 팀·역할 / 결재자 화면에 "수정됨 n칸" 요약 필수 여부
- [개발] 재접속·결재자 화면의 원본 패널 범위(출처 목록+값 스냅샷), 시트명/셀 주소 메타, 병합·서식 표현, 워드 다운로드 방식, 수정 이력 저장
- [데이터] 화면은 엑셀 값을 임의 보정·재계산하지 않음(합계 자동 재계산은 기획 결정)
