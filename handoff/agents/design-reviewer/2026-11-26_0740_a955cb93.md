## 5. 문구·접근성
- **'정하지 않음'과 '구분 미정'**
  - 칩 낭독·메뉴 항목·추가 창 라디오는 '정하지 않음'이다. 고르는 행동이라 '정하지 않음'이 맞다.
  - 거르기 '구분 미정'과 띠 '미정 n'은 상태를 세는 말이라 짧은 '미정'이 맞다.
  - 두 말이 같은 상태를 가리키지만 행동과 상태로 나뉘어 있어 허용한다. 바꿀 필요 없음.
- **참고 안내 수정안**: 사실 다음에 판단을 두고, '후보'를 뺀다.
  - 지금 국민은행이 금고인 기관: '참고: 광진구청은 지금 국민은행이 금고입니다. 은행 기록으로는 재유치 도전에 해당합니다. 구분은 직접 고르세요.'
  - 되찾기: '참고: ○○은 {연도}년까지 국민은행이 금고였고 지금은 {은행} 금고입니다. 은행 기록으로는 되찾기 도전에 해당합니다. 구분은 직접 고르세요.'
- **editLine 수정안**
  - 하나만 바뀜: '재유치 도전 → 신규유치 도전' / '금고 방식 정하지 않음 → 1금고'
  - 둘 다 바뀜: '구분 재유치 도전 → 신규유치 도전 · 금고 방식 정하지 않음 → 1금고'
- 바꿀 필요 없는 문구: `EDIT_NONE`('바뀐 내용이 없습니다. 표에서 구분이나 금고 방식을 고르면 켜집니다.'), `EDIT_NOPERM`, 띠 '금고 방식 바뀜 n곳 — [수정하기]로 저장', 결과 문장('…구분·금고 방식을 수정했습니다…'). 원인과 할 일이 다 있다.
- **접근성**
  - 칩 이름은 '금고 방식: 정하지 않음'('-'는 aria-hidden)이다. 메뉴는 role=menu에 aria-label '금고 방식 고르기', 항목은 menuitemradio에 aria-checked다. 구분 메뉴와 같은 틀이라 Esc·포커스 복귀도 같은 동작을 한다(코드로만 확인, 실제 키 조작은 못 함).
  - 칩 높이는 min-height 24px로 WCAG 2.5.8 최소에 맞다.
  - 목표가 아닌 줄은 '—'를 보여 주고 '목표가 아니어서 금고 방식 없음'으로 읽는다. 좋다.
- **대기 알림이 점선뿐인 것: 조건부 적절.**
  - 색만으로 전하는 것이 아니다. 점선이라는 모양 차이와 틸 테두리가 함께 있다. 금고 방식을 바꾼 줄은 자동으로 골라져 체크가 켜지고, 띠에 '금고 방식 바뀜 n곳'이 나온다. 낭독문은 '바뀔 금고 방식 … 저장 전입니다. 지금 저장된 금고 방식은 …'이다.
  - 약점은 둘이다. 1px 점선과 실선은 12px 칩에서 차이가 작다. title은 마우스에서만 보인다.
  - '바뀜' 꼬리표(약 28px)는 92px에 들지 않고, 칸을 넓히면 P1이 더 나빠진다. **지금 형태를 승인한다.**
  - (b)가 적용되면 1440px 이상에서는 폭이 남는다. 그때 꼬리표를 넣는 것은 다음 단계로 미룬다.
