**권장(사실 근거, 결정은 기획·사용자)**: 행정표준 기관코드를 기본 번호로 하되, 개편 시 바뀌는 점은 별칭·이력 표로 보완한다.

- 이유 둘은 통합·개편에서 이전기관코드가 비어 있는 경우(목포시, 광산구, 미추홀구)가 확인돼 자동 연결을 믿을 수 없기 때문이다. 개편 때 옛 코드를 새 코드에 잇는 별칭 표가 따로 필요하다.
- 알리오 apbaId와 지방공기업 이름은 이 표에 붙이는 보조 칸으로 둔다.

**기관 하나 = 번호 하나 규칙(제안)**: 모든 종류에 통하는 단일 칸은 없다.

- 최상위기관코드는 종류 루트(광역 코드, B000000, 1000000, 9740000)일 뿐이다.
- 종류별로 "기관코드 자기 값 + 존폐여부=0 + 차수 조건"으로 고른다.

| 종류 | 선택 조건 |

| 광역 | 차수 1, `02`·`01` |
