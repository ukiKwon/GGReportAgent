# data-auditor 보고서 (자동 보존)

> SubagentStop 훅이 에이전트의 최종 메시지를 그대로 저장했다(2026-11-20 1504 KST, agentId ae878e87acd212aa2). 에이전트 출력이므로 사용자 결정이 아니다. 지시 내용·주제는 이 파일에 없다 — 필요하면 handoff/NEXT.md 항목이나 커밋 메시지로 찾는다.

---

## 이 조사의 범위와 한계
- 18명 전원을 조회했다. 값은 실제로 연 URL에서 확인한 것만 적었다. 못 찾았거나 못 연 것은 null로 두고 note에 이유를 적었다.
- 시작·끝 년-월이 나온 항목은 거의 없다. 대부분 홈페이지가 기간을 싣지 않고 위키백과에도 기간이 적은 인물이 많았다. 월까지 나온 항목만 from/to에 넣었다.
- 연도만 나온 항목은 from_year에 넣었다. 끝 연도만 있는 경우(예: 충북대 1982~1986)는 스키마에 to_year 칸이 없어 note에 적었다.
- kind에는 위키백과를 OTHER로 썼다. 기존 레코드는 위키백과를 PRESS로 표기하고 있어 호출자가 통일해야 한다.
- 선관위(data.nec.go.kr) 후보자 페이지는 접속 거부와 HTTP 400으로 열지 못했다. NEC 출처는 하나도 쓰지 않았다.
- 검색 결과 요약에만 나온 값은 직접 열어 확인한 것이 아니므로 값으로 쓰지 않았다. note에 "미확인 단서"로만 적었다.
- 생년월일은 대부분 위키백과 한 곳만 확인했다. 확인한 곳이 둘 이상이면 note에 적었다.
- 변경 후보 하나는 항목 note에 있다. 최원철 id 372는 레코드가 "제10대 공주시장"인데 위키백과 문서는 제15대(민선 8기)·제16대(민선 9기)로 적었다.
- 박수현 생년월일은 날짜가 서로 달라 비워 두었다. 검색 결과 요약에 따르면 일부 자료는 음력 날짜만 적어 1964-08-14로 쓴다고 한다. 위키백과 문서에는 음력·양력 표기가 없다.

## 요약
- **생년월일 채움 15명**
  - 선관위는 직접 열지 못했다.
  - 이장섭은 중부매일 기사와 위키백과, 엄승용은 보령시 홈페이지, 최영일은 순창군 홈페이지로 확인했다.
  - 나머지 12명은 위키백과 단일 출처다.
- **연도만 채움 3명**
  - 박수현(1964): 음력·양력 혼재 가능성이 있어 날짜를 비웠다.
  - 유승광(1962): 나무위키 단일 출처다.
  - 김홍열(1963): 나무위키 단일 출처이고 날짜가 1월 1일이라 의심스럽다.
- **생년월일 확인 못 함 1명**: 서영학(여수시장). 열어 본 기사 셋 모두 생년이 없다.
- **동명이인 주의**: 위키백과에서 권익현은 1961년 문서, 김홍열은 1966년 문서(통합진보당 출신)를 따로 구분해야 한다. 김홍열 문서는 청양군수가 아니어서 쓰지 않았다.
- **항목 시작·끝**: 월까지 확인된 항목은 모두 직접 읽은 문서에서 가져왔다. 홈페이지가 기간을 싣는 곳은 홍성·순창·보령 정도다.

## 호출자에게
- 나무위키 출처 4건(유승광, 김홍열 생년·경력)은 신뢰도가 낮다. 기록에 넣을지 호출자가 판단해야 한다.
- 최원철 id 372는 레코드가 "제10대 공주시장"이고 위키백과는 제15·16대다. 이 항목을 고칠지 호출자가 정한다.
