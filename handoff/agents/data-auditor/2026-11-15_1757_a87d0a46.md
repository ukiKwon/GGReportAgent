### 1. 대상·방법·못 본 것
- 대상: `kgi-ggreport-web/src/main/resources/db/mysql/029_seed_institutions_all.sql`, `frontend/data/institutions.js`, `frontend/data/institutions_nonmuni.js`.

- 방법: SQL 415행을 전부 읽고, 묶음의 레코드 목록(이름·orgCode·g2bCode·코드 배열)을 검색으로 추출해 대조했습니다.
- 실행 도구(Bash)가 없어 생성기·테스트를 돌리지 못했습니다. 그래서 두 가지는 **확인 못 함**입니다.
  - lg-/nm- 해시 id 값(sha1 10자)을 직접 재계산하지 못했습니다. 이름·행 수로만 대조했습니다.
  - SQL 머리말의 원본 해시(institutions.js e77d6405d141, nonmuni 266646cacbbf)가 현재 파일과 같은지 확인하지 못했습니다. 다만 건수가 맞고, 날짜 값을 표본으로 맞춰 본 것(contractEnd 4건, 법원 lastBid·term 다수, 전북대병원 등)은 모두 일치했습니다.
- 살아 있는 DB는 보지 못했습니다. 사용자가 화면에서 추가한 행이나 029 이전에 있던 행("DB만 있음")은 확인 못 함입니다. 코드상 시드 SQL로 들어가는 기관은 003의 서울 25행과 029뿐이고, 그 밖에는 `InstitutionMapper.xml`의 INSERT(화면 추가)가 있습니다.
