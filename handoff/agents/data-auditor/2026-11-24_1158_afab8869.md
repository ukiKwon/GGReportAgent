# data-auditor 보고서 (자동 보존)

> SubagentStop 훅이 에이전트의 최종 메시지를 그대로 저장했다(2026-11-24 1158 KST, agentId afab88691c1ec3fa1). 에이전트 출력이므로 사용자 결정이 아니다. 지시 내용·주제는 이 파일에 없다 — 필요하면 handoff/NEXT.md 항목이나 커밋 메시지로 찾는다.

10명을 훑었지만, 학력은 한 줄도 넣지 못했고 경력도 일부만 넣었습니다. 검색 요약이 대부분이었고 원문 페이지는 2곳만 열었기 때문입니다. 학력은 졸업 연도만 있고 입학 연도가 없어서 뺐습니다. 원문에 날짜가 직접 나온 줄이나 보도에 날짜가 분명히 적힌 줄만 넣었습니다.

| 이름 | 넣은 줄 수 | 뺀 줄 | 못 찾은 이유 |
|---|---|---|---|
| 권순기 | 경력 4 | 학력 5줄은 졸업 연도뿐이라 뺌. 경상국립대 교수는 종료일을 확인 못 해 뺌 | 경남교육청 누리집 원문을 열어 확인했고, 교육감 줄은 언론 기사를 출처로 씀 |
| 고의숙 | 0 | 교직 1991년 시작과 도의원 2022년 시작은 종료를 몰라 뺌. 교육감 취임일은 기사에서 확인 못 함 | 언론 요약만 있었고 생년월일은 1969-09-11이 한 곳에서만 나와 뺌 |
| 강미애 | 0 | 시작 연도가 있는 줄이 없음 | 교직 임용은 1988년과 1989년으로 출처끼리 다르고, 취임일은 확인 못 함 |
| 임재만 | 경력 2 | 세종대 교수(2007~)는 휴직 중이라 재직 여부가 애매해 뺌 | 학력은 졸업 연도가 없음 |
| 윤지웅 | 경력 4 | 학력은 졸업 연도뿐이라 뺌 | 생년월일 1971-02-10은 한 곳 출처라 뺌 |
| 이하운 | 경력 4 | 학력은 연도가 없어 뺌 | 재단 누리집 원문 확인. 교무처장은 날짜가 오기(2021.07~2015.07)라 뺌 |
| 최춘식 | 경력 1 | 국회의원 종료일 모름. 정당 직책은 금지어라 뺌 | 학력 연도 없음 |
| 홍원화 | 경력 1 | 경북대 총장 종료일 모름 | 학력은 연도가 졸업 연도뿐이라 뺌 |
| 박윤규 | 경력 2 | 학력 연도 없음 | 보도 요약만 있었음 |
| 김창수 | 경력 1 | 중앙대 총장은 "2016년부터 4년간"이라 종료 연도를 계산해야 해서 뺌 | 학력 연도 없음 |

- **확인 수준**: 권순기와 이하운의 2~3번째 줄은 기관 누리집 원문으로 직접 확인했습니다. 나머지는 검색 요약에 인용된 기사 기준이라 원문 대조는 못 했습니다.
- **직책 시작 연월**: 윤지웅·박윤규·최춘식·홍원화·김창수·임재만의 현직 시작 연월은 검색 요약에 적힌 취임·임기 시작일입니다. 시작일이 날짜로 나오지 않은 줄은 넣지 않았습니다.
