# 이사회 자료(수익성 파트) 요건 — 확정본 + 기획자 검토 (2026-10-30)

> 기획자(planner) 검토 보고의 핵심을 사용자 확정 사항과 함께 정리한 것. 결정은 사용자가 했다.
> 실제 양식은 없다(말로 들은 설명 기준). 관련 보고서: `../backend-dev/2026-10-30_이사회자료_구현가능성.md`, `../design-reviewer/2026-10-30_이사회자료_화면규격.md`, `../frontend-dev/2026-10-30_이사회자료_표편집_붙여넣기.md`.

## 1. 확정 요건

| 구분 | 내용 |
|---|---|
| 범위 | 이사회 자료 중 **수익성분석표를 참고하는 파트**만. 양식은 **1개 고정**(드롭다운 UI 가능), 새 양식은 나중 |
| 흐름 | 양식 선택 → 수익성분석 엑셀(.xlsx) 업로드 → 지정 약속대로 워드 양식에 전체 자동 입력 → 같은 작업 공간에서 값마다 엑셀 출처를 대조하며 **재검수** |
| 값 | **계산된 수치**(수식 문자열 아님). 엑셀의 반올림 표시값을 **그대로** 옮김. 엑셀에 차트 없음, 수식 많음 |
| 수정 | 담당자가 합계를 맞추려 워드 값을 직접 수정(업무 관행). 수정 후 엑셀로 되돌리기는 추후 협의 |
| 원본 | 원본 엑셀은 **저장하지 않음**(저장소 마련 후 저장) |
| 결재 | 팀원 작성 → 팀장 → 부장, **이사회 자료 전체 단위**(`BOARD_FINAL`) |
| 화면 | 1280px 이상만 고려. 값별 **"확인" 체크** 기능 포함 |

### 양식 구성(사용자 설명)
- page1 안건 요약: 의안명, 결의사항, 제의근거, 제의사유, 시행일, [본문]자료 붙임명, 제안자명
- page2 본문: 1.배경, 2.기관 현황 및 일정, **3.재산상 이익제공 및 기부안(매핑 A)**
- page3: 약정 간 비교 표, 4.기대효과, **5.수익성분석(매핑 B)**
- page6 붙임 수익성 분석표 **(매핑 C)**: 1.약정기간 2.명목가치 수익성 3.NPV 수익성 4.투자적정성 분석(모두 표)
- page5 세부 수익성 분석표(명목가치) **(매핑 D)** — 행 수가 가변일 수 있음

## 2. 기획자 지적 → 사용자 결정(권장안 채택)

| # | 지적 | 결정 |
|---|---|---|
| Q1 | 원본 미보관인데 출처 대조 필요 | 출처 목록(값·시트·셀 주소)만 결재 건과 함께 보관. 원본 엑셀은 계속 미저장 |
| Q2 | 확인 단계가 약함 | 담당자 "확인했음" 표시를 상신 전 필수. 값별 확인 체크 포함 |
| Q3 | 반올림 합계 불일치 | 엑셀 값 그대로 입력, 불일치 의심은 **경고만**(자동 보정 금지) |
| Q4 | 엑셀 양식 불일치 | 시트·헤더 자체가 다르면 전체 중단, 개별 셀 누락이면 성공분 입력+실패 목록 |
| Q5 | page1·비교 표·기대효과 포함 여부 | 양식 사본을 받은 뒤 항목별로 결정 |

## 3. 열린 항목(아직 사용자 답/결정 필요)

- 스냅샷(가공 JSON)+완성 워드를 결재 종료까지 DB에 두는 것의 **허용 여부와 보존 기간** (backend-dev 권장: 허용, 상신 때 DB로 확정)
- A~C 표의 행 수 고정/가변, 머리행 병합 셀 유무
- 사용자 PC에 MS 워드가 있는지
- 이 기능을 보게 할 역할·**메뉴 키 신설 여부**(`Menus.MENUS` 8개 키·골든 04·05 영향 — 기존 키의 하위 기능으로 둘지)
- 외부 링크가 있는 엑셀·숨은 시트/행: 거부 vs 경고, 캐시 없는 수식 파일의 재계산 폴백 허용 여부

## 4. 결정된 방향(양식 사본)
워드패드는 표를 만들 수 없어 **양식 사본은 POI로 코드 생성**(가상 수치, `docs/samples/`). 양식은 클래스패스 고정본으로 쓰고 로더는 인터페이스로 분리(나중 업로드 방식 교체 대비).
