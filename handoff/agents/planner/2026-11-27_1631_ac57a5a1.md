## 5. 수의계약과 입찰 없음·띠·끝난 건의 관계(규칙 충돌 후보)
| 경우 | 지금 규칙 | 수의계약이면 생기는 문제 |
|---|---|---|
| 재유치 수의계약 + 공고 상태 '입찰 없음(연장·지정)' + 국민은행 | 협약 예정 | 문제 없음 |
| **신규 수의계약** + 입찰 없음 + 지금 타행 | 끝난 건(입찰 없음)으로 세고 '준비 기록 정리 필요' 표시 | **규칙 충돌**: 국민은행이 새로 수의계약을 따는 중인데 끝난 건으로 셈 |
| 수의계약 건의 제안 준비 | 예상 공고일이 지났는데 공고 기록이 없으면 담당·팀장에게 알림 | **규칙 충돌**: 공고가 원래 없어서 알림이 계속 뜸 |
| 수의계약 건의 [제안 확정] | 공고 전이면 '아직 입찰 공고 전' 태그 | 태그가 맞지 않음 |
| 입찰 없음 + 제안 진행 중 | [계속 작성] 팝업 | 수의계약 건이면 매번 뜰 수 있음(같은 공고 기록이면 1회만 뜸) |
| 띠 5단계 | 제안 준비 → 제출 및 대기 → 협약 예정 → 완료 | 단계 이름은 그대로 써도 무리가 없음('제출' = 수의계약 제안서). 확인 필요 |
- 방식을 공고 상태에서 자동으로 판정하지 않는다. '입찰 없음(연장·지정)'은 수의계약일 수도 있고 그냥 연장일 수도 있다. 근거 없이 추정하지 않는다.
