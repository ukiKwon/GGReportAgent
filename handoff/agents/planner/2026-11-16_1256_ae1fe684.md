## 공사판 테마 문구·상수 확정안 (planner)
대상: 계획 파일 scalable-hugging-parnas.md, app.js 문구 위치(say/toast/stateLabel/JOB_LABEL/전광판/현황판), index.html, state.json의 stats.laps. 지금 세션 누적은 143바퀴이고, 세션이 언제 시작됐는지만 확인했다(하루 전체 누적값은 못 봤다). 하루 실제 누적량은 모른다. 그래서 고도 경계는 잠정값이다.

**단위·상수** (팀 결정)
| 키 | 값 | 근거 |
|---|---|---|
| unit | '공정'(칩 `n공정`, 전광판 `누적 N공정`) | 계획 대응표와 같다. 기존 '바퀴'처럼 두 글자다 |
| LAPS_PER_FLOOR | 5 | 계획 기본값. 143공정이면 28층이라 화면 안에서 바로 변화가 보인다 |
| ZONES(층) | 구름 20 / 성층권 60 / 우주 120 | 지금 세션 143공정(28층)이면 구름 구간에 이미 들어간다. 바쁜 날(약 600공정)에 우주에 닿는 정도로 잡았다. 계획 예시 30/120/300은 하루에 닿기 어려워 보인다. 하루 실제 누적을 본 뒤 조정한다 |
| 눈금 이름 | 지상 · 구름 · 성층권 · 우주 | 계획 그대로 |
| 높이 표기 | `28층 · 112m`(1층 = 4m, 연출용 환산) | 실제 고도가 아니다. 업무 데이터가 아니므로 근거 금지 원칙에 걸리지 않는다 |
| 도달 토스트 | 구름 '☁️ 구름을 뚫었다! (20층)' / 성층권 '✈️ 성층권 진입! (60층)' / 우주 '🚀 우주 도착! (120층)' | 세션당 구간마다 1회 |
