## 3. 용어 후보(권장 = 1)
- 작성 건: 상신 1회 묶음(양식 버전+입력 스냅샷+출처 목록+확인 체크), 상신 전엔 세션 / 2: 업로드 즉시 DB 초안
- 확인 완료: 값 있는 칸 전부 체크 + "확인했음" / 2: 실패·수정 칸만
- 수정됨: 자동 값과 현재 값이 다른 칸(되돌리면 해제) / 2: 한 번이라도 고친 칸
- 최종 워드: 부장 승인 뒤 스냅샷으로 생성 / 2: 상신 시점 워드
- 출처: 워드 칸 → 시트·셀 주소·표시값(+원래 값) / 2: 시트·범위 단위

## 4. 흐름 — 단계별 상태와 데이터
| # | 단계 | 화면 상태 | 저장하는 것 | 위치 |
|---|---|---|---|---|
| 1 | 양식 선택 | 빈 상태(드롭 영역) | 양식 ID·버전 고정 | 세션 |
| 2 | 엑셀 업로드 | 업로드 중 → 불일치 배너 또는 성공 | 파일명·크기·시각(본문 미저장). 검사: 확장자·크기·매크로·개인정보 | 세션(만료 있음) |
| 3 | 자동 입력 | 채워진 표, 실패 칸 점선+"읽지 못함" | 입력 스냅샷, 출처 목록, 실패 목록, 경고 | 세션 |
| 4 | 대조·수정·체크 | 필터(전체·수정됨·확인 필요·미확인), "검수 n/m" | 수정 값, 칸별 확인(누가·언제), "확인했음" | 세션 |
| 5 | (임시저장) | — | 없음("한 세션" 방침). 새로고침 시 4단계 작업 소실, 같은 엑셀 재업로드로 3단계까지 복구 | — |
| 6 | 결재 상신 | 확인 문구 | 작성 건 DB 확정 + `APPROVAL_REQUEST`(BOARD_FINAL) + `BOARD_FORM_USE` | DB(새 테이블) |
| 7 | 결재 중 | 읽기 전용, 출처 대조 유지(DB 출처 목록 기준), 칩, 회수 | 결재 단계 상태 | DB |
| 8 | 반려 | 사유 표시, 편집 재개 | 반려 건 유지, 그 스냅샷으로 새 작업 → 재상신 = 새 REQ_ID(이전 건 참조) | DB |
| 9 | 승인 → 최종 워드 | "확정" 칩, 내려받기 | 스냅샷으로 재생성(권장) 또는 docx 보관 | DB |

8단계 근거: 결재 상태에 재상신 없음 + `BOARD_FORM_USE.REQ_ID` UNIQUE → "새 요청 + 이전 건 참조"가 스키마와 충돌 없음.

## 5. 확정·열린 결정

| 최종 워드 시점 | 미결 | 초안은 언제든, "최종"은 승인 뒤 |
| 엑셀 개인정보 차단 | 적용 범위 미결 | 적용, 응답은 종류·건수만 |

## 7. 결정 질문 (권장 = 가)
1. 실제 양식 사본: (가) 지금 xlsx만 / (나) xlsx+docx / (다) 아직 못 줌 → POI 가상 엑셀로 진행. MS 워드 유무도.
2. MVP 범위: (가) 결재 없이 작성·검수·초안 워드 / (나) 결재까지
3. 작성·상신 권한: (가) `tasks` write / (나) view만으로 / (다) `tasks` 수정
4. 반려 뒤: (가) 반려 건 내용으로 이어 고쳐 새 요청 재상신 / (나) 엑셀 다시 올려 새로
5. 엑셀 예외: (가) 매크로 거부·외부 링크·숨은 영역 경고·캐시 없는 수식 "읽지 못함"·개인정보 검출 시 거부 / (나) 개인정보는 경고만 / (다) 외부 링크·숨은 시트도 거부
6. 결재 건 보존: (가) 정책 전까지 전부 보존 + 정보보호 문의 / (나) 승인 건만, 반려·취소는 기간 뒤 삭제 / (다) 최종 워드만

## 8. 이관 메모
- [디자인] 1단계 검수 화면 최종 규격(빈 상태→업로드→대조→체크→초안), 2단계 결재자 보기 칩. Q2 대기.
- [백엔드] 1단계: xlsx 업로드 API(크기·매크로·`ZipSecureFile`·`Pii.scan`, 응답은 종류·건수), `ExcelSource.rangeAt`, 카탈로그 표 단위 매핑 JSON(시트·범위→`r{행}c{순번}`), 캐시 값 우선, 세션 메모리(만료). 2단계: 작성 건 테이블(쌍, 사번, 스냅샷·출처·체크·수정, 이전 건 참조), BOARD_FINAL 상신 전환, 조회 범위=본인·결재선.
