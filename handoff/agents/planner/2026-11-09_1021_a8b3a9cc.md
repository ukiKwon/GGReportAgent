## ② 경과 판정의 현재 로직과 한계
**현재 로직**
- **날짜 결정**(`logic.js:109-116 effectiveBid`): `contractEnd`가 있으면 그 값을 쓰고, 없으면 `lastBid + term`(추측)을 씁니다.
- **남은 일수**: `daysUntil`(`logic.js:82-87`).
- **D-day 표기**(`formatDDay`, `logic.js:125-130`): 지나면 `D+n`, 당일은 `D-day`, 날짜가 없으면 `미상`입니다.
- **색**(`computeUrgency`, `logic.js:92`): 지난 건도 "6개월 이내" 빨강으로 칠해집니다. 그래서 경과 건과 임박 건이 같은 색입니다.
- **정렬**(`sortByUrgency`, `logic.js:185-190`): 음수 일수가 맨 앞으로 오므로 **TOP5를 경과 건이 먼저 차지합니다.**

**한계**
1. **칸의 의미가 섞여 있습니다.** `contractEnd`의 표시 이름은 "입찰예상일"인데, 실제로는 약정 만료일과 공고일이 섞여 있습니다.
   - "기준일=공고일" 메모가 붙은 레코드는 `institutions.js`에서 **16건 확인**했습니다.
   - 원문까지 확인한 것은 청송·청주·포항 3건뿐입니다.
   - 이 칸은 확정 결정 4("공고 예정일 = lastBid+term")와도 우선순위가 반대입니다. 코드는 `contractEnd`를 먼저 씁니다.
2. **경과의 원인을 구분하지 못합니다.** "공고가 이미 나서 진행 중", "입찰이 끝남", "예정보다 늦어짐", "추정이 틀림"이 모두 똑같이 D+n으로 보입니다. 상태 칸이 없기 때문입니다.
3. **추정 오차가 있습니다.** 청주시청은 직전 2022-09-19에서 이번 2026-07-27로, 약 2개월 차이가 날 수 있습니다. 추정값만 가진 건은 정상인데도 경과로 잡힐 수 있습니다.
4. **같은 기관이 여러 번 셀 수 있습니다.** 한 기관이 여러 구역에 나뉘어 반복 등록된 경우가 있습니다(수원 4구 등). `dedupeByInstitution`을 거치지 않으면 한 기관이 팝업에 여러 번 나옵니다.
5. **청송·청주·포항 등은 `updatedAt`이 2026-08입니다.** 이미 끝난 입찰일 가능성이 높아서, 팝업에 그대로 뜨면 "끝난 건이 경과로 보이는" 첫 사례가 됩니다.

## ③ 용어·요건 정의 후보
**"경과 건"**
- (가) 오늘이 공고 예정일 다음 날 이후인 모든 건 (D+1부터)
- (나) 유예 기간이 지난 건만. 예: D+30부터. 추정 오차 2개월을 고려하면 D+60
- (다) 확정 날짜는 D+1부터, 추정 날짜는 유예 기간 이후

**누구에게**
- 지도·지역별 수정 권한 보유자, 곧 영업팀 전원입니다(확정).
- 정할 것: 전원에게 같은 목록을 보일지, 아니면 본인이 ♥관심/★관심 지역으로 표시한 기관만 보일지. 저장소에는 `store.isInterested`·`isWatched`가 이미 있습니다.

**언제**
- (a) 로그인 직후 하루 1회
- (b) 지도·지역별 메뉴에 들어갈 때마다
- (c) 팝업은 띄우지 않고 사이드바·티커에 "경과 N건" 배지만 표시

**무엇을 보여 줄지**
- 기관명, 시·도, 공고 예정일(확정/추정과 계산 근거), 경과일 D+n, 마지막 수정일, 출처
- 각 건마다 해당 기관 편집창으로 바로 가는 링크

**확인 후 동작**
- (1) 단순 확인: 오늘은 다시 보지 않기
- (2) 건별로 상태 선택:
  - 공고 진행 중 → 공고일과 출처 입력, 이후 제안서 진행 현황으로 연결
  - 입찰 종료 → 지난 입찰일 갱신, 다음 주기로 재계산
  - 재공고·지연 대기 → 다음 확인일을 정하고 그때까지 숨김
  - 아직 확인 못함 → 계속 표시
- (3) 결과를 개인 기준으로 둘지 팀 공용으로 둘지. 공용이면 한 사람이 처리했을 때 다른 사람 화면에서도 사라집니다.

## ⑤ 사용자에게 물을 업무 질문
1. **"공고 예정일이 지났다"는 언제부터로 볼까요?** 예정일은 지난 입찰일에 주기를 더해 추정한 날짜라 1~2개월 어긋날 수 있습니다. 기준에 따라 팝업 건수가 크게 달라집니다.
   - 가) 하루라도 지나면
   - 나) 한 달 지나면
   - 다) 확정 날짜는 바로, 추정 날짜는 두 달 지나면
2. **팝업은 언제 보여 드릴까요?**
   - 가) 로그인할 때 하루 한 번
   - 나) 지도·지역별 화면에 들어갈 때마다
   - 다) 팝업 없이 메뉴 옆에 "확인 필요 N건" 표시만
3. **담당자가 확인한 뒤 고를 상태는 무엇이 필요한가요?**
   - 가) 공고 진행 중 / 입찰 종료 / 지연·재공고 대기 (세 가지)
   - 나) 확인 완료 하나만
   - 다) 가) + "해당 없음(금고 입찰 대상 아님)"
4. **한 사람이 처리하면 다른 영업팀원에게도 사라져야 하나요?** 기관마다 정해진 개인 담당자가 없어서 지금은 영업팀 전원이 같은 목록을 봅니다.
   - 가) 팀 공용: 한 명이 처리하면 모두에게서 사라짐
   - 나) 각자 따로 확인
   - 다) 팀 공용이되, 누가 처리했는지 이름을 남김
5. **팝업에 모든 지역을 보일까요, 본인이 관심 표시한 지역·기관만 보일까요?**
   - 가) 전체
   - 나) 관심 지역·기관만
   - 다) 관심 먼저, 나머지는 접어서
6. **"입찰 종료"를 고를 때 근거를 꼭 받아야 하나요?** 근거는 공고 원문 주소나 문서 번호입니다. 받지 않으면 근거 없는 데이터가 생깁니다.
   - 가) 필수
   - 나) 선택
   - 다) 종료는 필수, 진행 중은 선택
