# planner — 세션 누적 바퀴수 전광판 (2026-10-30, 그래프 F1 시험 흐름 1번 노드)

## 지시
요구 원문: "전광판에 세션 기준으로 누적 바퀴수가 있으면 좋겠어. 1만을 넘어가면 단위를 '천', '백만', '십억'으로 표현해주면 좋겠어." — 의미 정의·선택지·질문 초안(구현 설계 제외).

## 결과 (요약)
- 세션 정의: A Claude 세션 시작 시 리셋(권장) / B 페이지 로드 / C 서버 가동 기준
- 합산 대상: 청소부 포함 전원 + 같은 역할 다중 인스턴스 모두, 자연 완주만(이송 후 lapF 초기화·'+5바퀴' 점프는 영향 없음)
- 저장: state.json의 stats(새로고침·서버 재시작 후 유지, 세션 시작 때만 리셋)
- 표기: 1만 미만 전체 숫자 / 이후 `12.3천`·`1백만`·`1십억`, 소수 1자리 반올림, 경계에서 "1000천" 대신 "1백만"으로 승격
- 전광판: 누적은 스크롤에 섞지 않고 고정 줄(3줄 구성)
- 주의: 이 규모에서 1만 바퀴 이상은 거의 나오지 않을 수 있음(방어적 규칙, 과설계 금지)

## 결정 처리 (메인, 2026-10-30)
Q1~Q4는 위험이 작고 되돌리기 쉬워 권장안으로 확정하고 GATE에 올리지 않음: Q1=a(세션 시작마다 리셋), Q2=a(청소부 포함), Q3=a(사용자 원문 표기), Q4=a(유지·저장). 사용자는 결과 보고에서 뒤집을 수 있음.
