## 2. 요구 요약
**확정된 전제** (출처: 사용자 답 2026-11-09, NEXT 59·61·62)
- 결재함은 전원에게 보인다. 확정됐고 별도로 적용 중이다(62).
- **제안서**
  - 팀별로 작성한다. 각 팀 팀원은 작성한 뒤 자기 팀장에게 결재를 올린다. 이 흐름은 이미 있다.
  - 제안서 담당자는 제안서 작성 때 팀을 구성하면서 정해진다.
  - 영업팀 소속 제안서 담당자가 전 팀 작성 완료를 확인하고 제출 1차 결재를 올린다. 그 결재가 처리되면 담당자가 디자이너에게 발송할 수 있다.
  - 최종 제출 확정은 영업팀장이 한다(2차).
  - 가결 전에는 제출할 수 없고 예외도 없다(3차 답).
- **재무**
  - 이사회 자료는 값만 저장한다(원본 파일은 버림).
  - 양식별로 어떻게 저장할지는 의논해서 정한다.
  - 재무 검토는 관문이 아니다. 확장용 화면이고, 지금은 있는 흐름으로 간다.
- **과거 공고**: 이미 끝난 건은 소급하지 않는다. 제출 전인 건은 영업이 이사회 결과를 사후 등록한다(근거 메모 필수). 4차 P-A로 확정.
- **이사회 자료 권한**
  - 한 건 = 기관 + 회차.
  - 담당자 한 명이 n건을 동시에 작성할 수 있다.
  - 영업팀 전원이 열람하고, 수정은 그 기관에 배정된 직원만 한다.

**지금 시스템과의 차이**
1. '전 팀 완료 확인'을 지금은 디자이너가 **제출할 때** 서버가 자동으로 검사한다. 사용자 설명에서는 디자이너에게 **보내기 전에** 영업 담당자가 확인한다. 위치와 주체가 다르다.

3. '제안서 담당자'(사번)와 팀 구성 데이터가 없다.
4. 영업부장 결재 3곳(G 기획·이관·최종, D 최종완료)이 사용자 설명에는 나오지 않는다. 8단계 영업부장 최종결재 뒤에 9단계 영업팀장 제출 확정이 오면, 위 직급의 결재 다음에 아래 직급이 확정하는 순서가 된다(QB).

## 6. 이사회 자료 n건 동시 작성
- **관계**
  - 기관 1 : 이사회 자료 건 n(회차별)
  - 건 1 : 배정 담당자 1..m(기관 배정을 따름)
  - 건 1 : 작업본 1 + 저장 버전 k
  - 담당자 1 : 진행 중인 건 n(여러 기관·회차)
- **함의**
  - ① 지금 작성 화면은 무상태다(`BoardWriteService:22`). n건을 오가며 쓰려면 '버전 저장/검토 요청' 외에 **작업 중 저장(임시 저장)**도 필요하다. 4차 S1의 '명시적으로 눌렀을 때만'은 유지한다.
  - ② 같은 건을 배정자 두 명이 동시에 고치면 나중 저장이 앞 저장을 덮는다. 버전 번호를 확인해 거절하는 방식이 필요하다(백엔드).
- **목록·검색 화면이 필요하다**
  - 탭: '내 이사회 자료'(기본) / '영업팀 전체'(열람)
  - 칸: 기관·회차·이사회 상태·담당자·최근 저장·검토 상태
  - 필터: 기관명·지역·상태·담당자·기간
  - **재무 검토 화면(61)과 같은 목록을 쓰고 동작만 다르게 하는 것을 권장한다.** 화면 수가 늘지 않는다. 규격은 디자인이 정한다.

## 7. 양식 저장 의논안
**전제**
- 양식 버전(`BOARD_FORM_VER.SPEC_JSON`)은 고치지 않는다. 표마다 ref, 행 id, 열 id가 고정되고 지운 id는 다시 쓰지 않는다(`BoardFormJson:17-20`).
- 따라서 칸 하나의 주소 = (양식, 버전, 표 ref, 행 id, 열 id)로 영구히 유일하다.

| 비교 | A 버전 스냅샷 JSON 한 칸 | B 칸 단위 정규화(표·행·열·값 행) | **C 혼합(권장)**: 머리 칸 정규화 + 값 JSON |
|---|---|---|---|
| 쉬운 비유 | 작성한 양식을 통째로 사진 찍어 봉투에 넣고, 봉투에 양식 이름만 적음 | 모든 칸을 오려 카드에 주소를 적고 카드함에 꽂음 | 사진은 통째로 넣고, **봉투 겉면에 기관·회차·상태·담당자·날짜**를 적어 서랍에 정리 |
| 양식이 바뀔 때 | 영향 없음(버전 고정) | 영향 없음. 단 양식이 다르면 같은 뜻의 칸도 주소가 달라 기관끼리 비교가 안 됨 | 영향 없음 |
| 검색 | 기관·회차 검색 칸이 따로 없음 | 칸 값으로 검색 가능(같은 양식끼리만 의미 있음) | 목록 검색은 머리 칸으로 충분. 값 검색이 필요한 칸만 머리로 올림 |
| 재무 쌍 보기 | 이사회 JSON + 엑셀 값 JSON을 한 번에 읽음, 쉬움 | 수백 행을 모아 다시 맞춤 | A와 같음 |
| 칸별 수정 사유·확인 | JSON 안에 넣음 | 행마다 자연스럽게 | 작은 별도 기록(표 확인·수정 사유)과 함께 |

- 재무 화면과 '내 이사회 자료' 목록이 실제로 찾는 기준(기관·회차·상태·담당자·기간)은 머리 칸으로 해결한다.
