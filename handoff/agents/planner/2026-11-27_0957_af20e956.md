## 6. ③ 경로 방식(`#` 제거)으로 바꿀 때 다시 볼 것
| 항목 | 이유 |
|---|---|
| 서버가 화면 경로에서 index.html을 돌려줄지(대상 목록) | 지금은 없는 경로가 404다(frontend 보고서 §6). |
| WebLogic 컨텍스트 경로가 붙는지 | 붙으면 `fetch('/…')` 36곳과 화면 경로가 모두 영향받는다. |
| 스크립트·글꼴 상대경로 | `#/admin/users` 같은 2단 경로에서 `js/…` 기준 위치가 바뀐다. |
| 이름 겹침 재점검 | 새 API 맨 앞 경로가 화면 주소와 같아지면 안 된다. 그 시점에 표를 다시 대조한다. |
| 옛 `#/…` 즐겨찾기 | 경로 주소로 자동으로 옮겨 줄지 정해야 한다. |
| StaticCacheFilter·접근 이력 인터셉터·보안 헤더 시험 | 화면 경로가 API처럼 취급되지 않는지 본다. |
| 랜딩 앵커 `#ld-ai`·`#ld-flow` | hash 방식에서는 라우팅과 충돌하는지, 경로 방식에서는 원래 앵커로 되돌릴지 본다. |

## 7. ④ 수용 기준 (qa 체크 목록)
1. 4절 표의 모든 주소를 주소창에 넣으면 해당 화면이 열린다. 권한 있는 역할 기준이고, 준비중 자리 화면도 포함한다.
2. 화면마다 사이드바·탭·머리 단추로 열면 주소가 표와 같게 바뀐다.
3. 각 화면에서 새로고침하면 같은 화면이 다시 열린다.
4. 화면 A→B→C로 옮긴 뒤 뒤로 2번이면 A, 앞으로 1번이면 B다. 상세 팝업을 열고 닫아도 기록이 늘지 않는다.
5. 로그인 뒤 뒤로 가도 로그인 화면이 나오지 않는다. 랜딩 → [로그인] → 뒤로 가면 랜딩이 나온다.
6. 세션이 없을 때 `#/proposal-prep`을 열면 로그인 화면이 뜨고, 영업팀으로 로그인하면 제안 준비 현황이 열린다. 재무로 로그인하면 이사회 자료 작성과 권한 안내가 뜬다.
7. 권한 없는 주소(예: 재무로 `#/admin/users`)와 없는 주소(`#/abc`)는 자기 시작 화면과 안내로 간다. 서버 데이터는 노출되지 않는다.
8. 로그아웃하면 주소가 `#/login`이 된다. 뒤로 가도 내부 화면이 보이지 않는다.
9. 로그인한 채 `#/login`을 열면 시작 화면으로 간다.
