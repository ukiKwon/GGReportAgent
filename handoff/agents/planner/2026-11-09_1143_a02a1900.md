### (d) 단계와 역할 배분
- **1단계 (최소 범위, 서버 변경 없음)**: 판정 규칙(미상 제외, 중복 제거) + 지도 화면 경과 패널(보기 전용) + 요약형 로그인 팝업(하루 1회, 오늘 더 이상 보지 않기) + 사이드바 미처리 배지 + 의미 확인 중 표시.
  - 순서: design-reviewer(팝업·패널 시안, 경과와 임박 색 구분) → frontend-dev ∥ data-auditor(16건) → 메인 적용·테스트 → qa-verifier.
  - 한계: 상태가 없어 같은 건이 다음 날 다시 뜹니다. 팝업이 요약형이고 하루 1회라 견딜 만하지만, 2단계를 곧바로 이어야 합니다.
- **2단계**: 상태 처리(회차별 저장, 영업팀만 수정, 다른 팀 조회) + 담당자명·처리 일시 자동 기록 + 지연 대기 숨김(다음 확인일) + 처리됨 탭.
