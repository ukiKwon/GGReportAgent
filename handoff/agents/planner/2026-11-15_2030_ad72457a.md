## 1. 애플리케이션이 쓸 별도 추론 서버(Linux)를 배정받을 수 있습니까?

- **배경**: 이 시스템은 문서 요약·검증과 배점표 추출에 언어 모델을, 문서 검색에 임베딩(의미 검색) 모델을 씁니다. 사내 공용 API가 없고 폐쇄망이라, 모델을 직접 올리는 방식밖에 없습니다. 그런데 WebLogic 서버는 Solaris/SPARC여서 관련 소프트웨어(Linux·Windows용만 배포)를 설치할 수 없습니다. 남은 방법은 Linux 서버 한 대를 두고 애플리케이션이 그쪽을 호출하는 구성입니다.
- **ⓐ 어느 단계까지 배정이 가능한지**

  | 단계 | 사양 | 이 단계에서 제공 가능한 기능 |
  |---|---|---|
  | 1 | CPU 4코어 · RAM 8GB · 디스크 20GB | 문서 검색의 의미 검색(현재와 같은 검색 품질) |
  | 2 | CPU 16코어(AVX2 지원) · RAM 32GB · 디스크 100GB | + 배점표 자동 추출·문서 요약·검증(일괄 처리, 1건당 2분대) |
  | 3 | GPU VRAM 24GB급 · CPU 8코어 · RAM 32GB | + 대화형 질의응답 화면(1건당 수 초) |

- **ⓑ** OS는 **Linux**여야 합니다(Ubuntu 22.04 LTS 또는 RHEL 8/9). 가상 서버·컨테이너도 되고, 기존 Linux 서버의 여유 자원을 나눠 써도 됩니다.

## 2. 문서 검색에 Oracle Text를 사용할 수 있습니까?

- **확인 사항**: ⓐ 설치·라이선스 ⓑ 한글 형태소 분석기(KOREAN_MORPH_LEXER) 사용 가능 여부 ⓒ 애플리케이션 계정에 검색 인덱스 생성 권한을 줄 수 있는지.
- DB 담당 소관이면 전달 부탁드립니다.
- **왜 필요한지**: 한글 전문 검색 구현이 두 갈래로 갈립니다. 1번이 어려우면 이 검색이 유일한 검색 수단이 됩니다.
- **답에 따라 달라지는 것**: 가능하면 DB 검색 인덱스를 추가하고, 불가면 애플리케이션 자체 색인으로 구현합니다.

## 3. WebLogic 콘솔에 리소스 2개를 만들어 주실 수 있습니까?

| 종류 | 이름 | 용도 |
|---|---|---|
| DataSource | `jdbc/ggreportDS` | Oracle 접속(비밀번호는 여기에만) |
| Work Manager | `wm/ggreportWM` | 오래 걸리는 작업(문서 생성 등)을 요청 처리와 분리해 실행 |

- **확인 사항**: 누가 만드는지(신청 창구), Work Manager의 최소·최대 스레드 등 지정할 값, 이 경로를 미리 시험할 환경이 있는지.
- **왜 필요한지**: WAS에서는 애플리케이션이 스레드를 직접 만들 수 없습니다. Work Manager를 못 찾으면 요청 처리 중에 그대로 실행하는데, 그 상태로 운영하면 처리 자리가 고갈되는 장애로 이어질 수 있습니다. 저희 개발 환경에는 WebLogic이 없어 내부망에서만 검증할 수 있습니다.
- **답에 따라 달라지는 것**: 이름이 달라지면 배포 설정만 바꿉니다. 시험 환경이 없으면 운영 전 검증 일정을 따로 잡습니다.

## 4. 공통 API 게이트웨이 등록이 필요합니까? 필요하면 절차·표준·인증은 어떻습니까?

- **ⓞ** 이 시스템은 사내 직원이 브라우저로 쓰는 업무 화면입니다. 이 경우에도 API 통합관리시스템 등록 대상인지.
- **ⓐ** 등록 절차: 신청 창구·양식, 필요한 정보, 소요 기간, 환경(개발·스테이징·운영)별 등록 여부.
- **ⓑ** 공개 API 표준 규격 문서: 요청·응답 형식, 오류 코드, 이름 규칙, 페이징, 첨부 전송, 문서화 요건.
- **ⓒ** 게이트웨이가 인증을 끝내 주는지, 이 시스템도 다시 확인해야 하는지.
- **왜 필요한지**: 등록이 끝나야 연동 시험을 시작할 수 있습니다. 현재 API는 시험용 형태라 규격에 맞춰 바꿔야 합니다.
- **답에 따라 달라지는 것**: ⓞ가 "대상 아님"이면 ⓐ~ⓒ는 필요 없습니다. ⓒ가 "재확인 필요"면 인증 처리를 새로 개발합니다(통합 로그인 연결과 함께).

## 5. 첨부 원본·사진을 둘 디스크 폴더와 백업

- **확인 사항**
  - ⓐ 제안서 사전준비 첨부 원본 보관 폴더(절대경로)
  - ⓑ 기관장 사진 폴더(웹에서 직접 열리지 않는 위치)
  - ⓒ 두 폴더가 정기 백업에 들어가는지
  - ⓓ 쓸 수 있는 용량 [빈칸: 예상 용량 — 저희가 산정해 함께 드림]
- **왜 필요한지**: 첨부는 DB의 목록과 디스크의 파일이 함께 원본입니다. 둘 중 하나만 백업하면 복구할 수 없습니다.
- **답에 따라 달라지는 것**: 운영 설정 값, 백업 일정.

## 6. 운영 한도 값
