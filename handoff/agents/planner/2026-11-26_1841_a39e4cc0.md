## 2. 규칙 문장표 (상태 이름은 코드에 있는 그대로)
자리표시는 {날짜}·{n}·{월}·{은행}입니다. 값이 없을 때 지어내지 않고, 오른쪽 칸의 문장으로 바꿉니다.

| 줄 상태 | 판정 조건(화면이 이미 가진 값) | 이유 한 줄 | 값이 비었을 때 |
|---|---|---|---|
| 공고 확인 필요 | 확인 필요 표시가 있고, 예정일이 지난 날수가 있음 | 공고 예정일({날짜})이 {n}일 지났는데 공고 여부가 기록되지 않았습니다 | 예정일이 없으면: 공고 예정일이 지났는데 공고 여부가 기록되지 않았습니다 |
| 공고 중 · 마감 확인 | 단계가 공고 중이고 남은 날수가 있음 | 접수 마감까지 {n}일 남았습니다({날짜}). 0일이면: 오늘 접수 마감입니다 | 아래 '마감일 미확인' 줄로 |
| 공고 중 · 마감일 미확인 | 단계가 공고 중이고 남은 날수가 없음 | 공고는 났지만 접수 마감일이 확인되지 않았습니다 | 그대로 |
| 지연·재공고 대기 | 지연 표시가 있음 | 공고가 늦어지는 것으로 기록됐습니다. {월-일}에 다시 확인합니다 | 다음 확인일이 없으면: 공고 지연으로 기록됐고, 다음 확인일은 확인 필요 |
| 추정일 지남 | 추정일이 지났는데 판정 목록에는 없는 줄 | 추정한 공고 시기({월})가 지났고, 들어온 공고 자료가 없습니다 | 시기가 없으면 앞부분을 빼고 '들어온 공고 자료가 없습니다'만 |

| 공고 전 · 공고 예정 추정 | 공고 전, 추정이고 일정 자료에서 온 줄 | 공고 시기를 {월}쯤으로 추정합니다(확정 공고 아님) | 아래 '날짜 없음' 줄로 |
| 공고 전 · 협약 종료로 추정(국민은행) | 국민은행 금고 기관이고 협약 종료일이 있음 | 국민은행 금고 협약이 {날짜}에 끝나 {월}쯤 공고를 추정합니다 | 종료일이 없으면 이 줄에 들지 않습니다 |
| 공고 전 · 협약 종료로 추정(다른 은행) | 다른 은행 금고 기관이고 협약 종료일이 있음 | {은행} 협약이 {날짜}에 끝납니다. 데려올 기회입니다(시작화면에 이미 있는 말) | 은행 이름이 없으면 앞부분을 '다른 은행 협약이'로 |

3. 공고 중 (마감 확인 → 마감일 미확인 순)
4. 추정일 지남
5. 공고 전 (확정 예정일 → 추정 → 날짜 없음 순)

한 줄에는 문장 하나만 씁니다. 협약 종료일이 이미 지난 줄은 덧붙임 후보 '(협약 종료일 지남)'으로만 둡니다. 덧붙일지는 디자인이 정합니다.
