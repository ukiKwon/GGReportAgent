**3. 정의 (2단: 계획 문서 → 사업. 분야는 따로 엔티티를 두지 않고 사업의 칸으로 둔다)**
- **계획 문서**: 기관 하나가 낸 문서 한 권이다.
  - 필수: 기관ID, 문서명, 원천종류, 대상기간(시작·끝 연도), 출처URL, 확인일, 수집자
  - 선택: 원문 쪽 범위, 문서 단위 합계(원문 값), 비고
- **분야(장)**: 사업의 칸이다(분야번호·분야명, 원문 그대로). 중구의 '과제'처럼 단계가 하나 더 있으면 분야명에 붙인다.
- **사업 / 하위사업**:
  - 필수: 사업번호(원문 그대로 문자열, 예: "5-1", "6-1(52번)"), 사업명
  - 선택: 상위사업번호(하위사업일 때), 내용, 예산(아래 규칙), 원문 쪽, 확인상태, 진행상태(정상/완료/폐기 — 공약 원천만), 이행률(공약만), 비고
  - 사업마다 안정적인 키가 있어야 한다. 나중에 협력 후보 표시를 붙일 자리다.
- **원천종류 코드**: 4개년계획 / 주요업무계획(구정운영계획) / 예산서 / 공약이행 / 홍보물(리플릿·소식지) / 회의록 / 기타
- **확인상태 코드**(5-report·spec 07과 같음): 확인됨 / 부분확인 / 확인안됨 / 미조사. '확인안됨'은 폐기라는 뜻이 아니다(도봉 07 분류 기준).
- **예산 규칙**:
  - 원문 숫자와 원문 단위를 함께 저장한다(백만원·억원·천원). 화면에는 원문 단위로 보인다. 백만원 환산값은 비교용 파생값으로만 쓴다.
  - 예산상태: 금액 / 확인안됨 / 해당없음(타기관 소관, 중구 사례) / 원문에 없음(동대문). 원문의 "-"나 빈칸을 0으로 바꾸지 않는다.
  - 계는 원문에 있을 때만 넣는다. 연차별 금액은 있는 해만 넣는다(중구는 "일부만 표기"). 장기 금액은 따로 둔다.
  - 하위사업이 있는 상위사업에 계가 없으면 하위 합을 '계산값'으로 따로 보인다. 연차 합이 계와 다르면 경고만 하고 반입은 받는다.

**4. 반입 파일 권장안 — CSV 1개를 collector 배치에 끼운다**
- 이유: 사업은 기관당 30~125행이다. md 표는 쉼표·세로줄 때문에 깨지기 쉽다. 기관정보 md(A-2)는 그대로 쓰고, 같은 배치에 함께 싣는다.
- 파일명·형식: `{기관ID}_{확인일YYYYMMDD}_plan.csv`, UTF-8 BOM(엑셀 편집용). 1행 = 사업 1개이고, 문서 칸은 행마다 반복한다.
- 위치: manifest에 선택 섹션 `plans[]`로 참조를 둔다. v1 호환 여부는 백엔드가 확인한다.
- 거부 조건:
  - 필수 칸이 비어 있음
  - 기관ID가 INSTITUTIONS나 별칭표에 없음
  - 확인일 형식이 틀렸거나 미래 날짜임
  - 출처URL이 http(s)가 아님
  - 금액은 있는데 단위가 없거나 허용값 밖임
  - 코드값이 허용값 밖임
  - 같은 문서 안에 사업번호가 중복됨
  - 상위사업번호가 파일에 없음
- 재반입: A-2 원칙대로 덮어쓰지 않는다. 같은 문서의 새 판으로 쌓고 이전 판은 보관한다.

**5. 25구 변환 규칙**
- 따로 시드 SQL을 만들지 않는다. 각 구를 위 CSV 규격으로 변환한 뒤 같은 반입 경로로 넣는다. 그래야 검증이 한 군데에 모인다.
- 확인일은 spec 07의 조사일을 쓴다(도봉 2026-07-16). 확인상태는 spec 07과 사업명으로 맞춘다. spec 07에는 여러 사업을 한 줄에 묶은 행이 있어(도봉 '공공일자리/일자리플러스센터…') 자동 매칭이 안 되는 행은 미조사로 둔다.
- 반자동 변환 가능: 도봉·노원·광진. 장-번호와 연차 예산이 백만원 단위다.
- 수작업 확인 필요(근거는 인덱스 문구):
  - 동대문: 예산이 없다.
  - 동작: 02 '세대별' 파일이 분야 파일과 겹칠 위험이 있다.
  - 중구: 과제가 한 단계 더 있다.
  - 강북·강남07: 공약 번호, 폐기 항목, 이행률이 있다.
  - 영등포(4-7=2-5)·구로(실질 20건)·관악(07은 보충자료): 중복 제거가 필요하다.
  - 강서·양천·송파·은평·관악·영등포: 억원 단위이고 분야 배정액 중심이다.
  - 종로·구로·금천: 예산 합계를 낼 수 없다고 적혀 있다.
  - 구로: spec 06 파일이 없다.
- 건수 검산: 상위사업 수(폐기·중복 제외)를 각 구 00_인덱스의 '전체 사업 개수 검증'과 대조한다(도봉 121은 5-1~5-4를 1건으로 센 값).
  - 인덱스에 검증 절이 있는 구는 기획안이 든 5곳보다 많다: 종로·용산·은평·마포·중랑·서초·양천·송파 등.
  - 예산은 원문 장 합계가 있는 구만 '사업 계 합 대 장 합계'로 대조한다.
