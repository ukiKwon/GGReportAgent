## 0. 먼저 바로잡을 사실: 공고 관련 화면은 둘이 아니라 셋이다
- **입찰 현황판**: kbboard.js. 사이드바 '대시보드' 묶음이고 id는 `soon:현황판`이다. 올해 목표 기관과 내 관심 기관을 다룬다.

## 2. 중첩 목록과 남길 곳
1. **경과 목록**: 지도 경과 패널과 입찰 공고 현황 [공고 예정일 경과] 탭이 같은 계산(splitOverdue)과 같은 세 보기를 쓴다. **입찰 공고 현황에 남긴다.** 기록은 그 화면에서만 한다(dashboard.js 770행 "쓰는 곳은 입찰 공고 현황 하나"). 지도 쪽은 보기 전용이다.
2. **공고 진행 중 표시**: 지도 면 색 +2·툴팁·TOP5 '공고 중' 칩, 입찰 공고 현황 띠·접수 중 묶음, 현황판 링크가 겹친다. **입찰 공고 현황에 남긴다.** 지도에서는 빼거나 표식 하나로 줄인다. 사용자가 말한 "RFP 확정 건은 지도에서 제외"와 같은 방향이다.
3. **날짜 순 임박 목록**: 지도 TOP5·오른쪽 목록, 입찰 공고 현황 기간 목록, 현황판 '종료 1년 안' 세 곳이 Q2를 같은 방식(가까운 순 목록)으로 답한다. 목록은 **입찰 공고 현황에 남긴다.** 지도는 '어디에 몰려 있나'만 맡는다. 오른쪽 목록은 시군구 묶음이 지역 탐색용이라 남기고, TOP5는 지울 후보다.
4. **기간 구간 집계**: 입찰 공고 현황 막대(1·3·6개월)와 지도 카드(1개월·6개월·1년)는 비슷하지만 구간이 다르다. 새 범례를 정할 때 구간을 하나로 맞추는 것을 권장한다.
5. **관심 등록 입구**: 지도 ♥와 현황판 [관심에 넣기]는 같은 서버 자료를 쓴다. 입구가 둘인 것은 문제가 아니다(중첩 아님).

## 4. 빠진 것
1. **관심 기관의 Q1**: '내 관심·목표 기관 중 공고가 뜬 곳'만 모아 주는 곳이 없다.
   - 입찰 공고 현황 띠는 전국 대상이고 관심으로 거르지 못한다.
   - 현황판 관심 표에는 공고 상태가 없다.
   - 로그인 팝업은 '예정일 지남'만 알린다. '공고 떴음' 알림은 없다.
2. **'관심'의 정의가 넷으로 나뉘어 있다**(아래). 화면마다 쓰는 기준이 다르다. 경과 패널과 팝업은 관심 **지역**으로 먼저 정렬하고, 현황판은 관심 **기관**을 쓴다.
3. **Q1이 얼마나 최신인지 화면에 나오지 않는다**: 공고가 떴다는 판정은 사람이 기관 자료에 공고일(confirmed)을 넣어야 생긴다. 공고 자동 수집은 아직 준비중이다(nav.js 104행). 화면에 '마지막 확인일'이 약해서 "안 떴다"와 "아직 확인 안 함"이 구별되지 않는다.
4. **Q2의 근거 글**: 입찰 공고 현황 목록에는 '추정·약정 만료 기준' 글이 있지만, 지도 툴팁과 카드에는 근거가 약하다.

**'관심 있는 곳'의 저장소 정의(4종)**
- ① **내 관심 기관(♥)**: 사람별, 서버 `/my-watch`, 현황판 '관심' 탭. 남의 관심은 못 지운다(403 NOT_WATCH_OWNER). kbboard.js 7행.
- ② **올해 목표 기관**: 팀 단위, 연도별, `/bid-targets`의 GOAL. kbboard.js 3~4행.
- ③ **관심 지역(★)**: 지역 단위, PC마다 따로 저장. 전국 지역별 화면에서 지정하고 경과 패널·팝업 정렬에 쓴다. overdue.js 118·143행.
- ④ **담당 배정 기관**: 담당 영업 배정(BidAssign). 제안 작업 쪽에서 쓴다.
- 입찰 공고 현황 막대의 '목표·관심' 전환은 ①+②다(dashboard.js 382행).

## 6. 사용자에게 다시 물을 질문

**질문 1. '내가 관심 있는 곳'은 어느 범위인가요?**
- 왜 묻나: "관심 기관에 공고가 떴나"를 알려 줄 때 어느 기관을 셀지가 이것으로 정해집니다. 지금 시스템에는 관심이 네 가지로 따로 있습니다.
  - 내가 ♥로 찍은 기관(사람별)
  - 팀의 올해 목표 기관
  - 별(★)로 찍은 관심 지역(PC마다 따로)
  - 내가 담당으로 배정된 기관
- 선택지
  - (가) 내 ♥ 기관 + 팀 올해 목표 기관. **권장**. 이미 서버에 있고 입찰 공고 현황 막대도 이 기준을 씁니다.
  - (나) 내가 담당으로 배정된 기관만.
  - (다) (가)에 관심 지역 안의 기관까지 넣는다. 범위가 넓어지고, 관심 지역은 PC마다 달라 사람마다 결과가 달라집니다.

**질문 2. 세 화면을 어떻게 나눌까요?**
- 먼저 확인: 말씀하신 '입찰공고 현황'이 '입찰 공고 현황'(다가오는 입찰·경과 두 탭)인지, '입찰 현황판'(목표 기관 표)인지 알려 주세요.
- 선택지
  - (가) 현황판 = 내 기관, 입찰 공고 현황 = 전국 공고·경과 확인, 지도 = 아직 공고 전인 곳의 예상 시기. **권장**.
  - (나) 지도는 지금처럼 공고와 예상을 모두 보이고, 입찰 공고 현황은 경과 기록 업무만 맡는다.
  - (다) 입찰 공고 현황 안에 목록과 지도를 전환하는 탭을 두고, 지도 메뉴를 없앤다.

**질문 3. 예정일이 지났는데 공고가 아직 확인되지 않은 기관은 어디서 볼까요?**
- 무엇이 달라지나: 지금은 지도 왼쪽 패널과 입찰 공고 현황 [공고 예정일 경과] 탭 두 곳에 같은 목록이 있습니다. 공고 상태를 기록하는 것은 입찰 공고 현황에서만 됩니다.
- 선택지
  - (가) 입찰 공고 현황에만 둔다. 지도 패널은 없애고, 로그인 알림도 그 화면으로 보낸다. **권장**.
  - (나) 지금처럼 두 곳 모두에 둔다.
  - (다) 지도에는 '시기 지남' 색 표시만 남기고 목록은 입찰 공고 현황에만 둔다.
