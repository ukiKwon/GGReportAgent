### 설계 판단 (호출자 지시와 다른 점은 여기서 밝힘)
- **"순위별 최신 유효 행" 대신 "약정 줄(CONTRACT_NO)마다 최신 유효 행"으로 했습니다.** 법원 복수지정(창원 농협+경남)은 같은 순위(공동)에 은행이 여럿이라, 순위별 1행이면 한 은행이 사라집니다. 대신 서버가 줄마다 `term_state`(CURRENT/PAST/FUTURE)를 계산해 주고, 1금고→2금고→순위 없음→공동 순, 끝 날짜가 늦은 순으로 정렬합니다. 화면은 CURRENT를 주로 보이고, 없으면 가장 최근 PAST를 '만료'로 보이면 됩니다.
- 고치기는 같은 CONTRACT_NO에 새 REV_NO 행을 더하고, 지우기는 ACTION_CD='CANCEL' 행을 더합니다. 낙관적 잠금은 `base_rev_no`로 하고 어긋나면 409 STALE입니다.
- **수집 반입 자리**: `ORIGIN_CD`(지금은 MANUAL만)를 처음부터 둡니다. planner ④(수집값·직접 입력값 병기)와 73(입찰 결과 등록)이 나중에 같은 표에 쓰면 ALTER가 필요 없습니다.
- **필수 칸**: `TERM_TO`(약정 끝)와 `CHECKED_DATE`(확인일)를 필수로, `TERM_FROM`은 선택으로 했습니다(만료만 알려진 원문이 많음, NEXT 72 336행). 팀 결정이라 되돌리기 쉽습니다.
- **`/institutions`에 싣지 않고 별도 조회를 권장합니다.**
  - `GET /institutions`는 무가드입니다(security S3, NEXT 72 327행).
  - 서버 없는 지도 파일·내보내기에는 이력을 넣지 않는다는 팀 기본값이 있습니다(72).
  - Q1(현황판 숫자 반영)이 ⓐ면 목록 화면에는 필요 없습니다.
  - 기관 상세를 열 때 한 번 GET하는 방식이 기관장 보기와 같은 패턴입니다. 목록에 요약이 필요해지면 그때 가드를 단 `GET /bank-contracts/current`를 더합니다.

package com.kbstar.kgi.ggreport.web.service;

import com.kbstar.kgi.ggreport.web.domain.BankContract;
import com.kbstar.kgi.ggreport.web.dto.BankContractIn;
import com.kbstar.kgi.ggreport.web.support.HeadForbidden;

import java.time.DateTimeException;
import java.time.LocalDate;
import java.time.YearMonth;
import java.util.*;
import java.util.regex.Pattern;

/** 금고 약정 기록(039) 입력 검사. 오류 문구는 고정 문구뿐(입력값·내부 정보 없음). 서버는 링크를 열지 않는다. */
final class BankContractRules {

    static final String G_BANK = "BANK", G_RANK = "BANK_RANK", G_SRC = "BANK_CONTRACT_SRC";
    static final String BANK_ETC = "ETC";
    static final String RANK_FIRST = "FIRST", RANK_SECOND = "SECOND";
    static final String SRC_LINK = "LINK", SRC_DOC_NO = "DOC_NO", SRC_STAFF = "STAFF";
    static final String TYPE_LOCAL_GOV = "지자체";
    static final List<String> RANK_ORDER = Arrays.asList("FIRST", "SECOND", "NONE", "JOINT");
    private static final Pattern CODE = Pattern.compile("[A-Z0-9_]{1,30}");
    private static final Pattern TERM = Pattern.compile("\\d{4}(-\\d{2}(-\\d{2})?)?");

    interface CodeCheck { boolean enabled(String group, String code); }

    static final class Parsed {
        String rank, bank, bankEtc, termFrom, termTo, srcKind, srcUrl, srcNo, checkedDate, checkedDept, note;
    }

    private BankContractRules() { }

    /** 1·2금고는 지자체만. TYPE 이 비어 있으면(옛 시드) 막지 않는다. */
    static boolean rankAllowed(String rank, String instType) {
        boolean ranked = RANK_FIRST.equals(rank) || RANK_SECOND.equals(rank);
        String t = instType == null ? "" : instType.trim();
        return !ranked || t.isEmpty() || TYPE_LOCAL_GOV.equals(t);
    }

    static Parsed parse(BankContractIn in, String instType, LocalDate today, CodeCheck codes) {
        Parsed p = new Parsed();
        p.rank = code(in.getRankCd(), G_RANK, codes, "허용되지 않는 금고 순위입니다.");
        if (!rankAllowed(p.rank, instType)) {
            throw bad("1금고·2금고 순위는 지자체에만 쓸 수 있습니다.");
        }
        p.bank = code(in.getBankCd(), G_BANK, codes, "허용되지 않는 은행입니다.");
        String etc = text(in.getBankNameEtc(), 30, "기타 은행 이름은 30자 이내여야 합니다.");
        if (BANK_ETC.equals(p.bank)) {
            if (etc == null) throw bad("기타를 고르면 은행 이름을 적어야 합니다.");
            p.bankEtc = etc;
        } else if (etc != null) {
            throw bad("은행 이름 직접 입력은 '기타'를 고를 때만 씁니다.");
        }
        p.termFrom = term(in.getTermFrom());
        p.termTo = term(in.getTermTo());
        if (p.termTo == null) throw bad("약정 끝(YYYY, YYYY-MM 또는 YYYY-MM-DD)이 필요합니다.");
        if (p.termFrom != null && start(p.termFrom).isAfter(end(p.termTo))) throw bad("약정 시작이 끝보다 늦습니다.");

        p.srcKind = code(in.getSrcKind(), G_SRC, codes, "허용되지 않는 출처 종류입니다.");
        p.srcUrl = InstitutionEditRules.url(in.getSrcUrl());
        p.srcNo = InstitutionEditRules.notice(in.getSrcNo());
        String cd = in.getCheckedDate() == null ? null : in.getCheckedDate().trim();
        if (cd == null || cd.isEmpty()) throw bad("확인일(YYYY-MM-DD)이 필요합니다.");
        p.checkedDate = InstitutionEditRules.date(cd);
        if (LocalDate.parse(p.checkedDate).isAfter(today)) throw bad("확인일은 오늘보다 뒤일 수 없습니다.");
        p.checkedDept = text(in.getCheckedDept(), 50, "확인한 부서명은 50자 이내여야 합니다.");
        if (SRC_STAFF.equals(p.srcKind)) {
            if (p.checkedDept == null) throw bad("담당자 확인은 확인한 기관 부서명이 필요합니다.");
        } else if (p.srcUrl == null && p.srcNo == null) {
            throw bad("출처 링크 또는 문서·공고 번호가 필요합니다.");
        }
        if (SRC_LINK.equals(p.srcKind) && p.srcUrl == null) throw bad("공고·문서 링크를 고르면 링크가 필요합니다.");
        if (SRC_DOC_NO.equals(p.srcKind) && p.srcNo == null) throw bad("문서·공고 번호를 고르면 번호가 필요합니다.");
        p.note = text(in.getNote(), 100, "비고는 100자 이내여야 합니다.");
        rejectText(p.bankEtc, p.checkedDept, p.note);
        return p;
    }

    static String reason(String raw) {
        String r = text(raw, 100, "취소 사유는 100자 이내여야 합니다.");
        rejectText(r);
        return r;
    }

    static boolean same(BankContract c, Parsed p) {
        return Objects.equals(c.getRankCd(), p.rank) && Objects.equals(c.getBankCd(), p.bank)
                && Objects.equals(c.getBankNameEtc(), p.bankEtc) && Objects.equals(c.getTermFrom(), p.termFrom)
                && Objects.equals(c.getTermTo(), p.termTo) && Objects.equals(c.getSrcKind(), p.srcKind)
                && Objects.equals(c.getSrcUrl(), p.srcUrl) && Objects.equals(c.getSrcNo(), p.srcNo)
                && Objects.equals(c.getCheckedDate(), p.checkedDate) && Objects.equals(c.getCheckedDept(), p.checkedDept)
                && Objects.equals(c.getNote(), p.note);
    }

    /** CURRENT / PAST / FUTURE — 저장값이 깨져 있으면 UNKNOWN(손으로 고친 DB 대비). */
    static String termState(String from, String to, LocalDate today) {
        try {
            if (to != null && end(to).isBefore(today)) return "PAST";
            if (from != null && start(from).isAfter(today)) return "FUTURE";
            return "CURRENT";
        } catch (RuntimeException e) {
            return "UNKNOWN";
        }
    }

    static LocalDate endOrNull(String t) {
        try { return t == null ? null : end(t); } catch (RuntimeException e) { return null; }
    }

    static String term(String raw) {
        if (raw == null) return null;
        String s = raw.trim();
        if (s.isEmpty()) return null;
        if (!TERM.matcher(s).matches()) throw bad("약정 기간은 YYYY, YYYY-MM 또는 YYYY-MM-DD 형식이어야 합니다.");
        int y = Integer.parseInt(s.substring(0, 4));
        if (y < 1990 || y > 2100) throw bad("약정 기간 범위(1990~2100)를 벗어났습니다.");
        try { start(s); end(s); } catch (DateTimeException e) { throw bad("존재하지 않는 날짜입니다."); }
        return s;
    }

    static LocalDate start(String t) {
        if (t.length() == 4) return LocalDate.of(Integer.parseInt(t), 1, 1);
        if (t.length() == 7) return YearMonth.parse(t).atDay(1);
        return LocalDate.parse(t);
    }

    static LocalDate end(String t) {
        if (t.length() == 4) return LocalDate.of(Integer.parseInt(t), 12, 31);
        if (t.length() == 7) return YearMonth.parse(t).atEndOfMonth();
        return LocalDate.parse(t);
    }

    private static String code(String raw, String group, CodeCheck codes, String msg) {
        String v = raw == null ? null : raw.trim();
        if (v == null || !CODE.matcher(v).matches() || !codes.enabled(group, v)) throw bad(msg);
        return v;
    }

    /** 앞뒤 공백 제거, 빈 값은 null, 줄바꿈·제어 문자 거부, 글자 수(코드 포인트) 상한. */
    static String text(String raw, int max, String lenMsg) {
        if (raw == null) return null;
        String v = raw.trim();
        if (v.isEmpty()) return null;
        for (int i = 0; i < v.length(); i++) {
            if (Character.isISOControl(v.charAt(i))) throw bad("줄바꿈·제어 문자는 넣을 수 없습니다.");
        }
        if (v.codePointCount(0, v.length()) > max) throw bad(lenMsg);
        return v;
    }

    /** 개인정보(422 PII_BLOCKED) → 정당·전화번호(422 CONTRACT_FORBIDDEN). 응답에는 종류만. URL·번호 칸은 대상 아님. */
    static void rejectText(String... texts) {
        Map<String, Integer> pii = new LinkedHashMap<String, Integer>();
        for (String t : texts) {
            if (t == null) continue;
            for (Pii.Finding f : Pii.scanLoose(t)) {
                Integer n = pii.get(f.getKind());
                pii.put(f.getKind(), n == null ? 1 : n + 1);
            }
        }
        if (!pii.isEmpty()) {
            List<Map<String, Object>> kinds = new ArrayList<Map<String, Object>>();
            for (Map.Entry<String, Integer> e : pii.entrySet()) {
                Map<String, Object> k = new LinkedHashMap<String, Object>();
                k.put("kind", e.getKey());
                k.put("count", e.getValue());
                kinds.add(k);
            }
            throw unprocessable("PII_BLOCKED", "개인정보로 보이는 값이 있어 저장하지 않았습니다. 해당 부분을 지우고 다시 입력해 주세요.", kinds);
        }
        List<HeadForbidden.Kind> found = new ArrayList<HeadForbidden.Kind>();
        for (String t : texts) {
            if (t == null) continue;
            for (HeadForbidden.Kind k : HeadForbidden.scan(t)) {
                if ((k == HeadForbidden.Kind.PARTY || k == HeadForbidden.Kind.PHONE) && !found.contains(k)) found.add(k);
            }
        }
        if (!found.isEmpty()) {
            List<Map<String, Object>> kinds = new ArrayList<Map<String, Object>>();
            for (HeadForbidden.Kind k : found) {
                Map<String, Object> m = new LinkedHashMap<String, Object>();
                m.put("kind", k.name());
                m.put("label", k.getLabel());
                kinds.add(m);
            }
            throw unprocessable("CONTRACT_FORBIDDEN", "금고 약정 기록에 넣을 수 없는 내용(정당·전화번호)이 있습니다. 해당 부분을 지우고 다시 입력해 주세요.", kinds);
        }
    }

    private static ApiException unprocessable(String code, String msg, Object kinds) {
        Map<String, Object> d = new LinkedHashMap<String, Object>();
        d.put("code", code);
        d.put("message", msg);
        d.put("kinds", kinds);
        return ApiException.withDetail(422, d);
    }

    private static ApiException bad(String m) { return ApiException.badRequest(m); }
}

 * 저장 자격 = 기관 레코드 수정 권한 AND 영업팀·영업팀장·영업부장(NoticeRoundService.canJudge 와 같은 조합 — 그 파일에 의존하지 않으려 복제).
 * ⚠️ 수정자는 Actor(X-Emp-No 자기신고일 수 있음)로만 채운다 — 본문의 수정자 값은 받지 않는다. contractExpiry·OURS_SCOPE 는 건드리지 않는다.
 */
@Service
public class BankContractService {

    static final String ACTION_SAVE = "SAVE";
    static final String ACTION_CANCEL = "CANCEL";
    static final String ORIGIN_MANUAL = "MANUAL";
    static final int HISTORY_MAX = 200;

    private final BankContractMapper mapper;
    private final SysUserMapper users;
    private final PermissionService permissions;

    public BankContractService(BankContractMapper mapper, SysUserMapper users, PermissionService permissions) {
        this.mapper = mapper;
        this.users = users;
        this.permissions = permissions;
    }

    /** 컨트롤러 403 과 current() 의 can_edit 가 이 함수 하나를 쓴다. ⚠️ 자기신고 위의 업무 규칙(사칭 방지 아님). */
    @Transactional(readOnly = true)
    public boolean canEdit(String empNo) {
        if (empNo == null || !permissions.canEditInstitution(empNo)) return false;
        SysUser u = users.selectByEmpNo(empNo);
        return u != null && HeadRules.isSales(u.getRole());
    }

    @Transactional(readOnly = true)
    public Map<String, Object> current(String instRaw, String empNo) {
        String inst = requireInstId(instRaw);
        BankContractInst ref = mapper.selectInstitution(inst);
        if (ref == null) throw ApiException.notFound("institution not found");
        LocalDate today = LocalDate.parse(Times.todayKst());
        List<BankContract> rows = new ArrayList<BankContract>(mapper.selectLatestValid(inst));
        Collections.sort(rows, LINE_ORDER);
        List<Map<String, Object>> lines = new ArrayList<Map<String, Object>>();
        for (BankContract c : rows) lines.add(view(c, today, false));
        Map<String, Object> out = new LinkedHashMap<String, Object>();
        out.put("institution_id", inst);
        out.put("lines", lines);
        out.put("history_count", mapper.countRows(inst));
        out.put("can_edit", canEdit(empNo));
        out.put("today", today.toString());
        out.put("codes", codes(ref.getType()));
        return out;
    }

    @Transactional(readOnly = true)
    public Map<String, Object> history(String instRaw) {
        String inst = requireInstId(instRaw);
        if (mapper.selectInstitution(inst) == null) throw ApiException.notFound("institution not found");
        LocalDate today = LocalDate.parse(Times.todayKst());
        List<BankContract> rows = mapper.selectHistory(inst, new RowBounds(0, HISTORY_MAX));
        List<Map<String, Object>> items = new ArrayList<Map<String, Object>>();
        for (BankContract c : rows) items.add(view(c, today, true));
        Map<String, Object> out = new LinkedHashMap<String, Object>();
        out.put("institution_id", inst);
        out.put("items", items);
        out.put("truncated", rows.size() >= HISTORY_MAX);
        return out;
    }

    /** 호출 전에 컨트롤러가 requireInstitutionEdit 와 {@link #canEdit} 를 지난다. */
    @Transactional
    public Map<String, Object> save(String instRaw, BankContractIn in, Actor actor, BoardUiIds.Ui ui) {
        String inst = requireInstId(instRaw);
        if (in == null) throw ApiException.badRequest("저장할 내용이 없습니다.");
        // ⚠️ 첫 DB 문장은 기관 행 잠금(MySQL RR 첫 일관 읽기 — NoticeRoundService.save 와 같은 이유). 위에 SELECT 를 끼우지 않는다.
        BankContractInst ref = mapper.lockInstitution(inst);
        if (ref == null) throw ApiException.notFound("institution not found");
        LocalDate today = LocalDate.parse(Times.todayKst());
        BankContractRules.Parsed p = BankContractRules.parse(in, ref.getType(), today,
                (g, c) -> mapper.countEnabledCode(g, c) > 0);
        int contractNo;
        int rev;
        if (in.getContractNo() == null) {
            contractNo = mapper.selectMaxContractNo(inst) + 1;
            rev = 1;
        } else {
            BankContract cur = mapper.selectLatestLine(inst, in.getContractNo());
            if (cur == null) throw ApiException.notFound("contract not found");
            if (ACTION_CANCEL.equals(cur.getActionCd())) {
                throw conflict("ALREADY_CANCELLED", "이미 취소된 약정입니다. 새 약정으로 추가하세요.", cur);
            }
            if (in.getBaseRevNo() == null) throw ApiException.badRequest("고칠 때는 화면이 본 기록 번호(base_rev_no)가 필요합니다.");
            if (in.getBaseRevNo() != cur.getRevNo()) {
                throw conflict("STALE", "다른 사람이 먼저 고쳤습니다. 최신 기록을 확인하고 다시 저장하세요.", cur);
            }
            if (BankContractRules.same(cur, p)) {
                Map<String, Object> out = new LinkedHashMap<String, Object>();
                out.put("saved", false);
                out.put("code", "NO_CHANGE");
                out.put("contract_no", cur.getContractNo());
                out.put("rev_no", cur.getRevNo());
                return out;
            }
            contractNo = cur.getContractNo();
            rev = cur.getRevNo() + 1;
        }
        BankContract row = new BankContract();
        row.setInstitutionId(inst);
        row.setContractNo(contractNo);
        row.setRevNo(rev);
        row.setActionCd(ACTION_SAVE);
        row.setOriginCd(ORIGIN_MANUAL);
        row.setRankCd(p.rank);
        row.setBankCd(p.bank);
        row.setBankNameEtc(p.bankEtc);
        row.setTermFrom(p.termFrom);
        row.setTermTo(p.termTo);
        row.setSrcKind(p.srcKind);
        row.setSrcUrl(p.srcUrl);
        row.setSrcNo(p.srcNo);
        row.setCheckedDate(p.checkedDate);
        row.setCheckedDept(p.checkedDept);
        row.setNote(p.note);
        return insert(row, actor, ui, today);
    }

    @Transactional
    public Map<String, Object> cancel(String instRaw, String contractNoRaw, BankContractCancelIn in, Actor actor, BoardUiIds.Ui ui) {
        String inst = requireInstId(instRaw);
        int no = requireContractNo(contractNoRaw);
        if (in == null || in.getBaseRevNo() == null) throw ApiException.badRequest("취소할 때는 화면이 본 기록 번호(base_rev_no)가 필요합니다.");
        BankContractInst ref = mapper.lockInstitution(inst);   // 첫 DB 문장
        if (ref == null) throw ApiException.notFound("institution not found");
        BankContract cur = mapper.selectLatestLine(inst, no);
        if (cur == null) throw ApiException.notFound("contract not found");
        if (ACTION_CANCEL.equals(cur.getActionCd())) throw conflict("ALREADY_CANCELLED", "이미 취소된 약정입니다.", cur);
        if (in.getBaseRevNo() != cur.getRevNo()) {
            throw conflict("STALE", "다른 사람이 먼저 고쳤습니다. 최신 기록을 확인하고 다시 취소하세요.", cur);
        }
        String reason = BankContractRules.reason(in.getReason());
        cur.setRevNo(cur.getRevNo() + 1);   // 값은 직전 행 그대로 복사, 행동·사유·수정자만 새로
        cur.setActionCd(ACTION_CANCEL);
        cur.setOriginCd(ORIGIN_MANUAL);
        cur.setNote(reason);
        return insert(cur, actor, ui, LocalDate.parse(Times.todayKst()));
    }

    private Map<String, Object> insert(BankContract row, Actor actor, BoardUiIds.Ui ui, LocalDate today) {
        SysUser me = users.selectByEmpNo(actor.getEmpNo());
        if (me == null || !HeadRules.isSales(me.getRole())) {   // 컨트롤러 canEdit 가 막는다(방어)
            throw new ApiException(403, "이 기능을 쓸 권한이 없습니다.");
        }
        row.setEditorEmpNo(actor.getEmpNo());
        row.setEditorName(me.getName());
        row.setEmpVerified(actor.isVerified() ? 1 : 0);
        row.setScreenId(ui.getScreen());
        row.setButtonId(ui.getButton());
        row.setUiValid(ui.isValid() ? 1 : 0);
        row.setSavedAt(Times.nowIso());
        try {
            mapper.insertRow(row);
        } catch (DuplicateKeyException e) {   // 잠금이 있어 정상 경로에선 오지 않는다 — PK 가 마지막 방어선
            throw conflict("STALE", "다른 사람이 먼저 고쳤습니다. 최신 기록을 확인하고 다시 저장하세요.", null);
        }
        row.setBankName(bankNameOf(row.getBankCd()));
        Map<String, Object> out = new LinkedHashMap<String, Object>();
        out.put("saved", true);
        out.put("institution_id", row.getInstitutionId());
        out.put("contract_no", row.getContractNo());
        out.put("rev_no", row.getRevNo());
        out.put("action_cd", row.getActionCd());
        out.put("line", view(row, today, true));
        return out;
    }

    private String bankNameOf(String code) {
        for (BankContractCode c : mapper.selectCodes(BankContractRules.G_BANK)) {
            if (c.getCode().equals(code)) return c.getCodeName();
        }
        return null;
    }

    private Map<String, Object> codes(String instType) {
        Map<String, Object> m = new LinkedHashMap<String, Object>();
        m.put("banks", codeList(mapper.selectCodes(BankContractRules.G_BANK), null));
        m.put("ranks", codeList(mapper.selectCodes(BankContractRules.G_RANK), instType));
        m.put("src_kinds", codeList(mapper.selectCodes(BankContractRules.G_SRC), null));
        return m;
    }

    private static List<Map<String, Object>> codeList(List<BankContractCode> rows, String rankInstType) {
        List<Map<String, Object>> out = new ArrayList<Map<String, Object>>();
        for (BankContractCode c : rows) {
            if (rankInstType != null && !BankContractRules.rankAllowed(c.getCode(), rankInstType)) continue;
            Map<String, Object> m = new LinkedHashMap<String, Object>();
            m.put("code", c.getCode());
            m.put("name", c.getCodeName());
            out.add(m);
        }
        return out;
    }

    /** 1금고→2금고→순위 없음→공동, 같은 순위면 끝 날짜 늦은 것, 그다음 줄 번호 큰 것. */
    private static final Comparator<BankContract> LINE_ORDER = new Comparator<BankContract>() {
        @Override
        public int compare(BankContract a, BankContract b) {
            int ra = rankIdx(a.getRankCd()), rb = rankIdx(b.getRankCd());
            if (ra != rb) return ra - rb;
            LocalDate ea = BankContractRules.endOrNull(a.getTermTo()), eb = BankContractRules.endOrNull(b.getTermTo());
            if (ea != null && eb != null && !ea.equals(eb)) return eb.compareTo(ea);
            if (ea == null ^ eb == null) return ea == null ? 1 : -1;
            return b.getContractNo() - a.getContractNo();
        }
    };

    private static int rankIdx(String r) {
        int i = BankContractRules.RANK_ORDER.indexOf(r);
        return i < 0 ? 99 : i;
    }

    /** 화면용 한 줄. 사번·화면·버튼·UI_VALID 는 내보내지 않는다(감사 전용). */
    private static Map<String, Object> view(BankContract c, LocalDate today, boolean withAction) {
        Map<String, Object> m = new LinkedHashMap<String, Object>();
        m.put("contract_no", c.getContractNo());
        m.put("rev_no", c.getRevNo());
        if (withAction) m.put("action_cd", c.getActionCd());
        m.put("origin_cd", c.getOriginCd());
        m.put("rank_cd", c.getRankCd());
        m.put("bank_cd", c.getBankCd());
        m.put("bank_name", BankContractRules.BANK_ETC.equals(c.getBankCd()) ? c.getBankNameEtc() : c.getBankName());
        m.put("bank_name_etc", c.getBankNameEtc());
        m.put("term_from", c.getTermFrom());
        m.put("term_to", c.getTermTo());
        m.put("term_state", BankContractRules.termState(c.getTermFrom(), c.getTermTo(), today));
        m.put("src_kind", c.getSrcKind());
        m.put("src_url", c.getSrcUrl());
        m.put("src_no", c.getSrcNo());
        m.put("checked_date", c.getCheckedDate());
        m.put("checked_dept", c.getCheckedDept());
        m.put("note", c.getNote() == null ? "" : c.getNote());
        m.put("editor_name", c.getEditorName());
        m.put("emp_verified", c.getEmpVerified() == 1);
        m.put("saved_at", c.getSavedAt());
        return m;
    }

    private static String requireInstId(String raw) {
        if (!InstitutionHeadService.validInstId(raw)) throw ApiException.notFound("institution not found");
        return raw;
    }

    private static int requireContractNo(String raw) {
        if (raw == null || !raw.matches("[1-9][0-9]{0,8}")) throw ApiException.notFound("contract not found");
        return Integer.parseInt(raw);
    }

    private static ApiException conflict(String code, String message, BankContract cur) {
        Map<String, Object> d = new LinkedHashMap<String, Object>();
        d.put("code", code);
        d.put("message", message);
        Map<String, Object> latest = null;
        if (cur != null) {
            latest = new LinkedHashMap<String, Object>();
            latest.put("contract_no", cur.getContractNo());
            latest.put("rev_no", cur.getRevNo());
            latest.put("action_cd", cur.getActionCd());
            latest.put("editor_name", cur.getEditorName());
            latest.put("saved_at", cur.getSavedAt());
        }
        d.put("latest", latest);
        return ApiException.withDetail(409, d);
    }
}

import com.kbstar.kgi.ggreport.web.config.AccessLogInterceptor;

/**

@RestController
public class BankContractController {

    static final String VIEW_MENU = "map";   // 메뉴 키 8개 동결 — 새 키 만들지 않음
    private static final Pattern CODE = Pattern.compile("[A-Z_]{1,40}");

    private final BankContractService contracts;
    private final MenuGuard guard;

    public BankContractController(BankContractService contracts, MenuGuard guard) {
        this.contracts = contracts;
        this.guard = guard;
    }

    @GetMapping("/institutions/{institutionId}/bank-contracts")
    public Map<String, Object> current(@PathVariable String institutionId, HttpServletRequest req) {
        Actor actor = guard.require(req, VIEW_MENU);
        Map<String, Object> out = contracts.current(institutionId, actor.getEmpNo());
        req.setAttribute(AccessLogInterceptor.DETAIL, "bank-contract current n=" + ((List<?>) out.get("lines")).size());
        return out;
    }

    @GetMapping("/institutions/{institutionId}/bank-contracts/history")
    public Map<String, Object> history(@PathVariable String institutionId, HttpServletRequest req) {
        guard.require(req, VIEW_MENU);
        Map<String, Object> out = contracts.history(institutionId);
        req.setAttribute(AccessLogInterceptor.DETAIL, "bank-contract history n=" + ((List<?>) out.get("items")).size());
        return out;
    }

    @PostMapping("/institutions/{institutionId}/bank-contracts")
    public ResponseEntity<Map<String, Object>> save(@PathVariable String institutionId,
                                                    @RequestBody(required = false) BankContractIn body,
                                                    HttpServletRequest req) {
        Actor actor = requireEditor(req);
        Map<String, Object> out;
        try {
            out = contracts.save(institutionId, body, actor, InstUiIds.bankContract(req, InstUiIds.BTN_SAVE_BANK_CONTRACT));
        } catch (ApiException e) {
            req.setAttribute(AccessLogInterceptor.DETAIL, failDetail("save", e));
            throw e;
        }
        boolean saved = Boolean.TRUE.equals(out.get("saved"));
        req.setAttribute(AccessLogInterceptor.DETAIL, saved
                ? "bank-contract save no=" + out.get("contract_no") + " rev=" + out.get("rev_no")
                : "bank-contract save no-change");
        return ResponseEntity.status(saved ? HttpStatus.CREATED : HttpStatus.OK).body(out);
    }

    @PostMapping("/institutions/{institutionId}/bank-contracts/{contractNo}/cancel")
    public ResponseEntity<Map<String, Object>> cancel(@PathVariable String institutionId, @PathVariable String contractNo,
                                                      @RequestBody(required = false) BankContractCancelIn body,
                                                      HttpServletRequest req) {
        Actor actor = requireEditor(req);
        Map<String, Object> out;
        try {
            out = contracts.cancel(institutionId, contractNo, body, actor,
                    InstUiIds.bankContract(req, InstUiIds.BTN_CANCEL_BANK_CONTRACT));
        } catch (ApiException e) {
            req.setAttribute(AccessLogInterceptor.DETAIL, failDetail("cancel", e));
            throw e;
        }
        req.setAttribute(AccessLogInterceptor.DETAIL, "bank-contract cancel no=" + out.get("contract_no") + " rev=" + out.get("rev_no"));
        return ResponseEntity.status(HttpStatus.CREATED).body(out);
    }

    /** 401/403(수정 권한) → DENIED, 그다음 영업팀 계열 아니면 403 DENIED. 서비스 트랜잭션(잠금) 전에 거른다. */
    private Actor requireEditor(HttpServletRequest req) {
        Actor actor = guard.requireInstitutionEdit(req);
        if (!contracts.canEdit(actor.getEmpNo())) {
            throw guard.denied(req, new ApiException(403, "이 기능을 쓸 권한이 없습니다."));
        }
        return actor;
    }

    private static String failDetail(String op, ApiException e) {
        String code = null;
        Object d = e.getDetailObject();
        if (d instanceof Map) {
            Object c = ((Map<?, ?>) d).get("code");
            if (c instanceof String && CODE.matcher((String) c).matches()) code = (String) c;
        }
        return "bank-contract " + op + " " + e.getStatus() + (code == null ? "" : " " + code);
    }
}

## 5. 보안·위험·되돌리는 법
- **권한 경로**: `requireInstitutionEdit`(401/403 DENIED) → `canEdit`(영업팀 계열 아니면 403 DENIED) → 서비스 안 방어 403. 조회는 `require(map)`입니다. 이력 열람은 map 조회 권한이 있는 전 팀입니다(planner ② "기관 상세를 볼 수 있는 사람 전원").
- **자기신고 한계**: 수정자 사번·이름은 `X-Emp-No` 자기신고 위의 값이라 사칭할 수 있습니다. 응답 `emp_verified=false`가 그 표시입니다. 화면에서 "확인됨/검증됨" 같은 표현을 쓰면 안 됩니다. 권한 검사도 앞단 인증 전에는 보안 경계가 아니라 업무 규칙입니다.
- **접근 이력**: DETAIL에는 줄 번호·REV·상태·사유 코드만 남깁니다. 은행·비고·부서·링크·번호는 남기지 않습니다. 422 응답에도 종류·건수만 싣습니다.
- **입력**
  - 링크는 `SafeUrl.isHttp`(http/https만)로 확인하고, 서버는 링크를 열지 않습니다(SSRF 없음).
  - 줄바꿈·제어 문자를 거부하고 글자 수 상한을 둡니다.
  - 개인정보·정당·전화번호를 거릅니다. 다만 사전 기반이라 주소·상대 담당자 이름은 잡지 못합니다. 그래서 '담당자 확인'은 부서명만 받는다는 안내가 화면에 필요합니다.
- **동시성**: 기관 행 FOR UPDATE + 복합 PK. 잠금 대상이 INSTITUTIONS 행이라, 같은 기관의 공고 판정 저장(037)이나 기관 편집과 짧게 직렬화됩니다. 짧은 트랜잭션이라 영향은 작다고 봅니다.
- **남은 위험**
  - (중) 같은 순위에서 기간이 겹치는 유효 줄을 막지 않습니다. 예: 1금고 두 줄이 같은 기간. 1차에서는 표시만 하고, 점검 쿼리나 73에서 다시 보기를 제안합니다.
  - (하) `ops/integrity_check.sql`에 039 점검(줄 안 REV 결번, CANCEL 뒤 행, 코드표 밖 값)을 더해야 합니다. 그 파일은 다른 세션이 미커밋 수정 중이라 이번 패치에서 뺐습니다. 쿼리는 아래와 같습니다.
    ```sql
    SELECT INSTITUTION_ID, CONTRACT_NO FROM INST_BANK_CONTRACT GROUP BY INSTITUTION_ID, CONTRACT_NO HAVING COUNT(*) <> MAX(REV_NO);
    SELECT b.INSTITUTION_ID, b.CONTRACT_NO FROM INST_BANK_CONTRACT b WHERE b.ACTION_CD='CANCEL'
      AND EXISTS (SELECT 1 FROM INST_BANK_CONTRACT n WHERE n.INSTITUTION_ID=b.INSTITUTION_ID AND n.CONTRACT_NO=b.CONTRACT_NO AND n.REV_NO>b.REV_NO);
    SELECT b.BANK_CD, COUNT(*) FROM INST_BANK_CONTRACT b LEFT JOIN COMMON_CODE c ON c.CODE_GROUP='BANK' AND c.CODE=b.BANK_CD WHERE c.CODE IS NULL GROUP BY b.BANK_CD;
    ```
  - (하) `db/README.md`의 번호표에 039 줄을 추가해야 합니다. 이것도 다른 세션이 수정 중이라 커밋 뒤에 합니다.
- **되돌리기**
  - 코드: 새 파일 삭제 + `InstUiIds` 추가분 제거 + 시험 설정 34행 원복.
  - DB: `DROP TABLE INST_BANK_CONTRACT;` + `DELETE FROM COMMON_CODE WHERE CODE_GROUP IN ('BANK','BANK_RANK','BANK_CONTRACT_SRC');`. 운영 데이터가 생긴 뒤에는 데이터가 사라지므로 하지 않습니다.
  - 기존 `/institutions`·`contractExpiry`·`OURS_SCOPE`·`/menus`는 바꾸지 않았습니다.

## 6. 이관 메모
- [이관: 프런트] 응답 필드
  - `GET /institutions/{id}/bank-contracts` → `institution_id, lines[], history_count, can_edit, today, codes{banks[{code,name}], ranks[...], src_kinds[...]}`
  - line → `contract_no, rev_no, origin_cd, rank_cd, bank_cd, bank_name, bank_name_etc, term_from, term_to, term_state(CURRENT|PAST|FUTURE|UNKNOWN), src_kind, src_url, src_no, checked_date, checked_dept, note, editor_name, emp_verified, saved_at`
  - `GET …/history` → `items[]`(line에 `action_cd` 추가, 최신순), `truncated`
  - `POST …/bank-contracts`: 본문 `contract_no?(null=새 줄), base_rev_no, rank_cd, bank_cd, bank_name_etc, term_from, term_to, src_kind, src_url, src_no, checked_date, checked_dept, note`, 머리글 `X-Screen-Id: institution_edit`, `X-Button-Id: save_bank_contract`. 결과 201 `{saved, contract_no, rev_no, action_cd, line}`, 200 NO_CHANGE, 409 STALE/ALREADY_CANCELLED(`latest`), 422 PII_BLOCKED/CONTRACT_FORBIDDEN(`kinds`)
  - `POST …/bank-contracts/{no}/cancel`: 본문 `{base_rev_no, reason?}`, 버튼 `cancel_bank_contract`
  - file:// 모드에서는 호출하지 않습니다. `emp_verified=false`일 때 "검증됨"류 표현을 쓰지 않습니다. 오류 문구는 서버 문구를 그대로 씁니다.
  - 기다리는 것: 디자인 규격. 근거: 3-7·3-8.
- [이관: 디자인] 출처 종류별 입력 칸 표시 규칙(LINK=링크 필수, DOC_NO=번호 필수, PRESS=링크·번호 중 하나, STAFF=부서 필수, 확인일은 모두 필수). 1·2금고 선택지는 `codes.ranks`로만 그립니다. term_state PAST만 있을 때 '만료' 표기. 기다리는 것: 없음.
- [이관: 데이터] B07·B08 정식명(부산/BNK부산, 경남/BNK경남), X01·X02를 사람이 입력할 때 고를 수 있게 둘지(지금은 켜 둠), 은행 코드표에 빠진 은행(수협·SC제일 등은 지금 '기타'). 기다리는 것: 없음. 고칠 때는 COMMON_CODE CODE_NAME UPDATE 또는 새 번호 스크립트. 근거: data-auditor 2026-11-10_1728 41~54행.
- [이관: 기획] 교육청이 1·2금고를 쓰는지. 지금은 TYPE이 '지자체'(또는 빈 값)일 때만 1·2금고를 허용합니다. 같은 순위에서 기간이 겹칠 때의 규칙. 기다리는 것: 없음(구현은 진행 가능).
- [이관: 보안] 이 설계 검토(planner 이관 그대로): 담당자 확인·비고 칸의 개인정보 유입, 자기신고 수정자 이름, 이력 열람 범위(map 조회 전 팀).
- [이관: 037 담당 세션] `NoticeRoundDdlPairTest`의 표식과 037 파일 표식이 맞지 않는 것으로 보입니다(4절). `integrity_check.sql`·`db/README.md`의 039 줄은 그 세션 커밋 뒤에 덧붙입니다.
