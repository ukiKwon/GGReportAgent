### 3-1. API (응답 키 snake_case, 업로드 응답 4키는 그대로)

| 메서드·경로 | 권한 | 하는 일 |
|---|---|---|
| `GET /tasks/{id}/doc-check` | 없음(GET /files와 같음) | 요약: `task_id, file_count, unconfirmed_count, not_checked_count, partial_count, clean, files[{name,state,reason,has_images,has_embedded,order_approx,checked_at,hit_count,unconfirmed_count,acked_count}]` |
| `GET /tasks/{id}/files/{name}/doc-check` | 없음. `?with_context=true`이면 활성 사용자만 | 상세: `name,state,reason,sha256,has_images,has_embedded,order_approx,checked_at,unconfirmed_count,hits[{inst_id,inst_name,loc_kind,loc_no,count,acked,acked_by_name,acked_at[,contexts]}]`, 문맥을 못 만들면 `context_state:"UNAVAILABLE"` |
| `POST /tasks/{id}/files/{name}/doc-check` | 활성 사용자 | 다시 점검. BUSY이면 503 |
| `POST /tasks/{id}/files/{name}/doc-check/ack` | 활성 사용자 + 담당 본인(S7), 디자이너는 역할도 봄, 잠기면 409 | 본문 `{"acked":true,"sha256":"…","items":[{"inst_id","loc_kind","loc_no"}]}`(1~200건) |
| `POST /tasks/{id}/submit`(기존) | 그대로 | 성공한 **뒤** 미확인·점검 못 함·일부 점검이 있으면 `DOC_CHECK_LOG`에 `SUBMIT_OPEN` 한 줄을 남깁니다(실패해도 제출 응답은 그대로, WARN 로그만) |

상태 판정
- `clean=true`는 파일이 있고, 모두 DONE이며, 미확인이 0일 때만입니다.
- 행이 없거나 크기·수정시각·점검기 판·기관이 다르면 `NOT_CHECKED/STALE`입니다.

import java.util.concurrent.locks.ReentrantLock;
import java.util.function.Supplier;

/**
 * 같은 (작업, 파일 이름)의 디스크 쓰기·지우기·재검사와 점검 기록을 한 줄로 세운다(NEXT 106, security S13).
 * ⚠️ 한 JVM 안에서만 유효하다 — 서버를 여러 대로 늘리면 다시 본다(요약은 크기·수정시각 대조로 STALE 을 보인다).
 */
final class TaskFileLocks {

    private static final ReentrantLock[] STRIPES = new ReentrantLock[64];

    static {
        for (int i = 0; i < STRIPES.length; i++) {
            STRIPES[i] = new ReentrantLock();
        }
    }

    private TaskFileLocks() {
    }

    static <T> T with(String taskId, String name, Supplier<T> body) {
        ReentrantLock l = STRIPES[(String.valueOf(taskId) + '\u0000' + name).hashCode() & (STRIPES.length - 1)];
        l.lock();
        try {
            return body.get();
        } finally {
            l.unlock();
        }
    }
}

    private static final class Pptx {
        final List<String[]> texts = new ArrayList<String[]>();          // {부분 이름, 글}
        final List<String> sldRids = new ArrayList<String>();            // presentation.xml sldIdLst 순서

        boolean images;

    /** zip 항목 하나만 읽게 하는 덮개 — 읽은 바이트를 세고 상한·마감을 넘으면 끊는다. ZipInputStream 을 닫지 않는다. */
    private static final class Bounded extends InputStream {
        private final InputStream in;
        private final Pptx st;
        private final long deadline;
        private long size;
        String hit;

        Bounded(InputStream in, Pptx st, long deadline) {
            this.in = in;
            this.st = st;
            this.deadline = deadline;
        }

        @Override
        public int read() throws IOException {
            byte[] one = new byte[1];
            int n = read(one, 0, 1);
            return n <= 0 ? -1 : one[0] & 0xFF;
        }

        @Override
        public int read(byte[] b, int off, int len) throws IOException {
            if (hit != null) {
                throw new IOException(hit);
            }
            int n = in.read(b, off, len);
            if (n > 0) {
                size += n;
                st.total += n;
                if (size > ENTRY_MAX || st.total > TOTAL_MAX) {
                    hit = "TOO_LARGE";
                } else if (System.nanoTime() > deadline) {
                    hit = "TIMEOUT";
                }
                if (hit != null) {
                    throw new IOException(hit);
                }
            }
            return n;
        }

        void drain() throws IOException {
            byte[] buf = new byte[8192];
            while (read(buf, 0, buf.length) > 0) {
                // 세기만 한다
            }
        }

        @Override
        public void close() {
            // ZipInputStream 은 바깥이 닫는다
        }
    }

    private static Extracted pptx(byte[] d, long deadline) {
        if (d == null || !startsWith(d, PK)) {
            return Extracted.none("FORMAT_MISMATCH");
        }
        XMLInputFactory f = XMLInputFactory.newInstance();
        f.setProperty(XMLInputFactory.SUPPORT_DTD, false);
        f.setProperty(XMLInputFactory.IS_SUPPORTING_EXTERNAL_ENTITIES, false);
        Pptx st = new Pptx();
        Set<String> names = new HashSet<String>();
        try (ZipInputStream zin = new ZipInputStream(new ByteArrayInputStream(d))) {
            ZipEntry e;
            while ((e = zin.getNextEntry()) != null) {
                if (System.nanoTime() > deadline) {
                    return Extracted.none("TIMEOUT");
                }
                String name = e.getName().replace('\\', '/').toLowerCase(Locale.ROOT);
                while (name.startsWith("/")) {
                    name = name.substring(1);
                }
                if (!names.add(name)) {
                    return Extracted.none("BROKEN");                  // 중복 이름(ZipGuard·CVE-2025-31672 완화와 같은 규칙)
                }
                if (names.size() > MAX_ENTRIES) {
                    return Extracted.none("TOO_LARGE");
                }
                if (name.contains("vbaproject") || name.contains("activex") || name.contains("vbadata")) {
                    return Extracted.none(R_ACTIVE);
                }
                if (name.startsWith("ppt/media/")) {
                    st.images = true;
                }
                if (name.startsWith("ppt/embeddings/")) {
                    st.embedded = true;
                }
                Bounded in = new Bounded(zin, st, deadline);
                try {
                    String bad = part(f, name, in, st);
                    if (bad != null) {
                        return Extracted.none(bad);
                    }
                    in.drain();
                } catch (XMLStreamException | IOException x) {
                    return Extracted.none(in.hit != null ? in.hit : "BROKEN");
                }
                if (st.macro) {
                    return Extracted.none(R_ACTIVE);
                }
            }
        } catch (IOException | IllegalArgumentException x) {   // 깨진 zip·잘못된 이름 인코딩
            return Extracted.none("BROKEN");
        }
        if (names.isEmpty() || !st.presentation) {
            return Extracted.none("FORMAT_MISMATCH");
        }
        return st.result();
    }

    /** 항목 하나 처리. 이상하면 사유 코드, 정상이면 null. 글이 아닌 항목(이미지 등)은 아무것도 하지 않는다(drain 이 센다). */
    private static String part(XMLInputFactory f, String name, InputStream in, Pptx st) throws XMLStreamException {
        Matcher m;
        if ("[content_types].xml".equals(name)) {
            return contentTypes(f, in, st);
        }
        if ("ppt/presentation.xml".equals(name)) {
            st.presentation = true;
            return presentation(f, in, st);
        }
        if ("ppt/_rels/presentation.xml.rels".equals(name)) {
            return rels(f, in, st.slideRels, st);
        }
        if ((m = NOTE_RELS.matcher(name)).matches()) {
            Map<String, String> one = new HashMap<String, String>();
            String bad = rels(f, in, one, st);
            if (bad == null && !one.isEmpty()) {
                st.noteToSlide.put(m.group(1), one.values().iterator().next());
            }
            return bad;
        }
        if (SLIDE.matcher(name).matches() || NOTE.matcher(name).matches() || MASTER.matcher(name).matches()
                || META.matcher(name).matches() || OTHER.matcher(name).matches()) {
            return text(f, name, in, st);
        }
        return null;
    }

    private static String contentTypes(XMLInputFactory f, InputStream in, Pptx st) throws XMLStreamException {
        XMLStreamReader r = f.createXMLStreamReader(in);
        try {
            while (r.hasNext()) {
                int ev = r.next();
                if (ev == XMLStreamConstants.DTD) {
                    return "BROKEN";
                }
                if (ev == XMLStreamConstants.START_ELEMENT) {
                    if (++st.elements > MAX_XML_ELEMENTS) {
                        return "TOO_LARGE";
                    }
                    for (int i = 0; i < r.getAttributeCount(); i++) {
                        if (r.getAttributeValue(i).toLowerCase(Locale.ROOT).contains("macroenabled")) {
                            st.macro = true;
                        }
                    }
                }
            }
            return null;
        } finally {
            r.close();
        }
    }

    private static String presentation(XMLInputFactory f, InputStream in, Pptx st) throws XMLStreamException {
        XMLStreamReader r = f.createXMLStreamReader(in);
        try {
            while (r.hasNext()) {
                int ev = r.next();
                if (ev == XMLStreamConstants.DTD) {
                    return "BROKEN";
                }
                if (ev == XMLStreamConstants.START_ELEMENT) {
                    if (++st.elements > MAX_XML_ELEMENTS) {
                        return "TOO_LARGE";
                    }
                    if ("sldId".equals(r.getLocalName())) {
                        for (int i = 0; i < r.getAttributeCount(); i++) {
                            String ns = r.getAttributeNamespace(i);
                            if ("id".equals(r.getAttributeLocalName(i)) && ns != null && ns.contains("relationships")) {
                                st.sldRids.add(r.getAttributeValue(i));

                }
            }
            return null;
        } finally {
            r.close();
        }
    }

    private static String rels(XMLInputFactory f, InputStream in, Map<String, String> idToSlide, Pptx st)
            throws XMLStreamException {
        XMLStreamReader r = f.createXMLStreamReader(in);
        try {
            while (r.hasNext()) {
                int ev = r.next();
                if (ev == XMLStreamConstants.DTD) {
                    return "BROKEN";
                }
                if (ev == XMLStreamConstants.START_ELEMENT) {
                    if (++st.elements > MAX_XML_ELEMENTS) {
                        return "TOO_LARGE";
                    }
                    if ("Relationship".equals(r.getLocalName())) {
                        String id = r.getAttributeValue(null, "Id");
                        String target = r.getAttributeValue(null, "Target");
                        if (id != null && target != null) {
                            Matcher t = REL_SLIDE.matcher(target.replace('\\', '/').toLowerCase(Locale.ROOT));
                            if (t.find()) {
                                idToSlide.put(id, t.group(1));
                            }
                        }
                    }
                }
            }
            return null;
        } finally {
            r.close();
        }
    }

    private static String text(XMLInputFactory f, String name, InputStream in, Pptx st) throws XMLStreamException {
        boolean meta = META.matcher(name).matches();
        boolean chart = name.startsWith("ppt/charts/");
        boolean comment = name.startsWith("ppt/comments/");
        StringBuilder sb = new StringBuilder();
        int inText = 0;
        XMLStreamReader r = f.createXMLStreamReader(in);
        try {
            while (r.hasNext()) {
                int ev = r.next();
                if (ev == XMLStreamConstants.DTD) {
                    return "BROKEN";
                }
                if (ev == XMLStreamConstants.START_ELEMENT) {
                    if (++st.elements > MAX_XML_ELEMENTS) {
                        return "TOO_LARGE";
                    }
                    if (meta || textElement(r.getLocalName(), chart, comment)) {
                        inText++;
                    }
                } else if (ev == XMLStreamConstants.END_ELEMENT) {
                    String ln = r.getLocalName();
                    if (meta || textElement(ln, chart, comment)) {
                        inText--;
                        if (meta || chart || comment) {
                            sb.append('|');
                        }
                    }
                    if ("p".equals(ln) || "br".equals(ln)) {
                        sb.append('|');                       // 문단·줄 경계 — 공백 제거 뒤 낱말이 이어 붙지 않게
                    }
                } else if ((ev == XMLStreamConstants.CHARACTERS || ev == XMLStreamConstants.CDATA) && inText > 0 && !st.capped) {
                    sb.append(r.getTextCharacters(), r.getTextStart(), r.getTextLength());
                    if (st.chars + sb.length() > TEXT_CAP) {
                        st.capped = true;
                        sb.setLength((int) Math.max(0, TEXT_CAP - st.chars));
                    }
                }
            }
        } finally {
            r.close();
        }
        st.chars += sb.length();
        if (sb.length() > 0) {
            st.texts.add(new String[]{name, sb.toString()});
        }
        return null;
    }

    private static boolean textElement(String ln, boolean chart, boolean comment) {
        return "t".equals(ln) || (chart && "v".equals(ln)) || (comment && "text".equals(ln));
    }

    static int num(String digits) {
        if (digits == null || digits.isEmpty() || digits.length() > 6) {
            return -1;
        }
        try {
            return Integer.parseInt(digits);
        } catch (NumberFormatException e) {
            return -1;
        }
    }

    // ── pdf ──────────────────────────────────────────────────────────────

    private static Extracted pdf(byte[] d, long deadline) throws IOException {
        if (d == null || !startsWith(d, PDF)) {
            return Extracted.none("FORMAT_MISMATCH");
        }
        PDDocument doc;
        try {
            doc = PDDocument.load(new ByteArrayInputStream(d), MemoryUsageSetting.setupTempFileOnly());
        } catch (InvalidPasswordException e) {
            return Extracted.none("ENCRYPTED");
        } catch (IOException e) {
            return Extracted.none("BROKEN");
        }
        try {
            if (doc.isEncrypted()) {
                return Extracted.none("ENCRYPTED");
            }
            String active = pdfActive(doc, d);
            if (active != null) {
                return Extracted.none(active);                // ACTIVE_CONTENT | ATTACHMENT — 글을 뽑지 않는다(팀 결정·S10)
            }
            int pages = doc.getNumberOfPages();
            int last = Math.min(pages, MAX_PAGES);
            PDFTextStripper stripper = new PDFTextStripper();
            stripper.setLineSeparator("|");
            stripper.setParagraphEnd("|");
            List<Part> parts = new ArrayList<Part>();
            long chars = 0;
            boolean capped = false;
            boolean any = false;
            for (int p = 1; p <= last; p++) {
                if (Thread.currentThread().isInterrupted() || System.nanoTime() > deadline) {
                    return Extracted.none("TIMEOUT");
                }
                stripper.setStartPage(p);
                stripper.setEndPage(p);
                String t = stripper.getText(doc);
                if (chars + t.length() > TEXT_CAP) {
                    capped = true;
                    break;
                }
                chars += t.length();
                if (t.replace("|", "").trim().length() > 0) {
                    any = true;
                }
                parts.add(new Part("PAGE", p, t));
            }
            if (!any) {
                return Extracted.none("NO_TEXT");             // 스캔 PDF 등
            }
            String reason = capped ? "TEXT_CAP" : pages > MAX_PAGES ? "TOO_MANY_PAGES" : null;
            return new Extracted(reason == null ? DONE : PARTIAL, reason, parts, false, false, false);
        } catch (IOException e) {
            return Extracted.none("BROKEN");
        } finally {
            doc.close();
        }
    }

    /** 스크립트·실행(JavaScript·JS·Launch)이면 ACTIVE_CONTENT, 첨부(EmbeddedFile)만이면 ATTACHMENT, 없으면 null. 원문 바이트와 객체 사전을 둘 다 본다. */
    static String pdfActive(PDDocument doc, byte[] data) {
        boolean script = hasName(data, "/JavaScript") || hasName(data, "/Launch");
        boolean attach = hasName(data, "/EmbeddedFiles") || hasName(data, "/EmbeddedFile");
        if (!script) {
            for (COSObject o : doc.getDocument().getObjects()) {
                COSBase b = o.getObject();
                if (b instanceof COSDictionary) {
                    int k = dictKind((COSDictionary) b, 0);
                    script |= k == 2;
                    attach |= k == 1;
                    if (script) {
                        break;
                    }
                }
            }
        }
        if (!script) {
            int k = dictKind(doc.getDocumentCatalog().getCOSObject(), 0);
            script |= k == 2;
            attach |= k == 1;
        }
        return script ? R_ACTIVE : attach ? "ATTACHMENT" : null;
    }

    /** 0 없음, 1 첨부, 2 스크립트·실행. */
    private static int dictKind(COSDictionary d, int depth) {
        if (d.containsKey(COSName.getPDFName("JavaScript")) || d.containsKey(COSName.getPDFName("JS"))
                || d.containsKey(COSName.getPDFName("Launch"))) {
            return 2;
        }
        String s = d.getNameAsString(COSName.getPDFName("S"));
        if ("JavaScript".equals(s) || "Launch".equals(s)) {
            return 2;
        }
        int out = 0;
        if (d.containsKey(COSName.getPDFName("EmbeddedFile")) || d.containsKey(COSName.getPDFName("EmbeddedFiles"))
                || "EmbeddedFile".equals(d.getNameAsString(COSName.getPDFName("Type")))) {
            out = 1;
        }
        if (depth < 3) {
            for (String k : new String[]{"Names", "OpenAction", "AA"}) {
                COSBase child = d.getDictionaryObject(COSName.getPDFName(k));
                if (child instanceof COSDictionary) {
                    int c = dictKind((COSDictionary) child, depth + 1);
                    if (c == 2) {
                        return 2;
                    }
                    out = Math.max(out, c);
                }
            }
        }
        return out;
    }

    /** 바이트에서 PDF 이름(/X)을 찾는다 — 뒤 글자가 이름 글자가 아니어야 한다. ISO 문자열로 바꾸지 않는다(50MB → 100MB char 방지). */
    static boolean hasName(byte[] d, String token) {
        byte[] t = token.getBytes(StandardCharsets.ISO_8859_1);
        outer:
        for (int i = 0; i + t.length <= d.length; i++) {
            for (int k = 0; k < t.length; k++) {
                if (d[i + k] != t[k]) {
                    continue outer;
                }
            }
            int j = i + t.length;
            if (j >= d.length) {
                return true;
            }
            int c = d[j] & 0xFF;
            boolean nameChar = (c >= 'A' && c <= 'Z') || (c >= 'a' && c <= 'z') || (c >= '0' && c <= '9')
                    || c == '_' || c == '.' || c == '-';
            if (!nameChar) {
                return true;
            }
        }
        return false;
    }

    private static boolean startsWith(byte[] d, byte[] head) {
        if (d.length < head.length) {
            return false;
        }
        for (int i = 0; i < head.length; i++) {
            if (d[i] != head[i]) {
                return false;
            }
        }
        return true;
    }

import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

import javax.annotation.PreDestroy;

import java.util.concurrent.TimeUnit;

/**
 * 작업함 파일 추출의 문지기(NEXT 106, security S2·S3·S4). 업로드·재검사·문맥 보기가 <b>같은 자리</b>(기본 2)를 나눠 쓴다.
 * 자리가 없으면 기다리지 않고 NOT_CHECKED/BUSY. 파일 읽기(loader)는 자리를 잡은 <b>뒤에</b> 한다.
 * PDF 는 별도 스레드(대기열 없음 — 넘치면 BUSY)에서 돌고, 시간이 지나도 PDFBox 가 멈추지 않을 수 있어 자리는 그 스레드가 실제로 끝날 때 반납한다.
 */
@Component
public class DocCheckRunner {

    static final long SECONDS = 20;

    private final Semaphore permits;
    private final ThreadPoolExecutor pdfPool;

    public DocCheckRunner(@Value("${ggreport.task-files.doc-check.max-concurrent:2}") int maxConcurrent) {
        int n = Math.max(1, Math.min(4, maxConcurrent));
        this.permits = new Semaphore(n);
        this.pdfPool = new ThreadPoolExecutor(n, n, 60L, TimeUnit.SECONDS, new SynchronousQueue<Runnable>(), r -> {
            Thread t = new Thread(r, "task-doc-pdf");
            t.setDaemon(true);
            return t;
        }, new ThreadPoolExecutor.AbortPolicy());
        this.pdfPool.allowCoreThreadTimeOut(true);
    }

    /** 절대 던지지 않는다. loader 는 파싱 형식(pptx·pdf)일 때만, 자리를 잡은 뒤 한 번 부른다. */
    TaskDocExtractor.Extracted run(final String ext, Callable<byte[]> loader) {
        if (!TaskDocExtractor.parses(ext)) {
            return TaskDocExtractor.extract(ext, null, 0L);
        }
        if (!permits.tryAcquire()) {
            return TaskDocExtractor.Extracted.none(TaskDocExtractor.R_BUSY);
        }
        boolean handedOff = false;
        try {
            final byte[] data;
            try {
                data = loader.call();
            } catch (Exception e) {
                return TaskDocExtractor.Extracted.none("BROKEN");
            }
            final long deadline = System.nanoTime() + TimeUnit.SECONDS.toNanos(SECONDS);
            if (!"pdf".equals(ext)) {
                return TaskDocExtractor.extract(ext, data, deadline);   // pptx — 요청 스레드, 마감으로 끊는다
            }
            final FutureTask<TaskDocExtractor.Extracted> task =
                    new FutureTask<TaskDocExtractor.Extracted>(() -> TaskDocExtractor.extract(ext, data, deadline));
            try {
                pdfPool.execute(() -> {
                    try {
                        task.run();          // 취소된 FutureTask 도 여기까지는 온다 — 자리 반납이 새지 않는다
                    } finally {
                        permits.release();
                    }
                });
                handedOff = true;
            } catch (RejectedExecutionException full) {
                return TaskDocExtractor.Extracted.none(TaskDocExtractor.R_BUSY);
            }
            try {
                return task.get(SECONDS + 1, TimeUnit.SECONDS);
            } catch (TimeoutException e) {
                task.cancel(true);
                return TaskDocExtractor.Extracted.none("TIMEOUT");
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                task.cancel(true);
                return TaskDocExtractor.Extracted.none("TIMEOUT");
            } catch (ExecutionException | CancellationException e) {
                return TaskDocExtractor.Extracted.error();
            }
        } finally {
            if (!handedOff) {
                permits.release();
            }
        }
    }

    /** 시험용. */
    int available() {
        return permits.availablePermits();
    }

    @PreDestroy
    void shutdown() {
        pdfPool.shutdownNow();
    }
}

        String[] curPs = curRegion == null ? null : SIDO_PREFIXES.get(curRegion);
        if (curPs != null) {

                current.add(p + "청");
            }

            if (r.id == null || f.name.isEmpty()) {
                continue;
            }
            boolean sameSido = curRegion != null && curRegion.equals(trim(r.regionCode));
            boolean isCur = r.id.equals(currentId) || (sameSido && (f.sidoLevel || curSidoLevel));
            for (String v : f.variants(isCur, coreCount)) {

                }

            m.insert(v, null, true);
        }
        for (Map.Entry<String, String> e : owner.entrySet()) {
            if (!AMBIGUOUS.equals(e.getValue()) && !current.contains(e.getKey())) {
                m.insert(e.getKey(), e.getValue(), false);
            }
        }
        return m;

    private void insert(String v, String instId, boolean current) {
        Node n = root;
        for (int i = 0; i < v.length(); i++) {
            if (n.next == null) {
                n.next = new HashMap<Character, Node>();
            }
            Character c = v.charAt(i);
            Node k = n.next.get(c);
            if (k == null) {
                k = new Node();
                n.next.put(c, k);
            }
            n = k;
        }
        if (current) {
            n.current = true;
            n.instId = null;
        } else if (!n.current) {
            n.instId = instId;
        }
    }

    /** 정규화된 글에서 다른 기관 이름을 찾는다(현재 기관·현재 시도는 소비만). */
    List<Found> scan(String s) {
        List<Found> out = new ArrayList<Found>();
        int i = 0;
        int n = s.length();
        while (i < n) {
            Node node = root;
            Node best = null;
            int bestEnd = -1;
            for (int j = i; j < n && node != null; j++) {
                node = node.next == null ? null : node.next.get(s.charAt(j));
                if (node != null && (node.current || node.instId != null)) {
                    best = node;
                    bestEnd = j + 1;
                }
            }
            if (best == null) {
                i++;
                continue;
            }
            if (!best.current) {
                out.add(new Found(best.instId, i, bestEnd));
            }
            i = bestEnd;
        }
        return out;
    }

    static String normalize(String s) {
        return normalizeWithMap(s).text;
    }

    /** NFKC(한글 음절·ASCII 는 그대로) + 공백·제로폭·소프트하이픈 제거. '|' 는 남긴다. */
    static Normalized normalizeWithMap(String s) {
        String in = s == null ? "" : s;
        StringBuilder out = new StringBuilder(in.length());
        int[] map = new int[in.length() + 1];
        int n = 0;
        for (int i = 0; i < in.length(); i++) {
            char c = in.charAt(i);
            if (skip(c)) {
                continue;
            }
            if (c < 0x80 || (c >= 0xAC00 && c <= 0xD7A3)) {
                out.append(c);
                map[n++] = i;
                continue;
            }
            String t = Normalizer.normalize(String.valueOf(c), Normalizer.Form.NFKC);
            for (int k = 0; k < t.length(); k++) {
                char d = t.charAt(k);
                if (skip(d)) {
                    continue;
                }
                if (n >= map.length) {
                    map = Arrays.copyOf(map, map.length * 2);
                }
                out.append(d);
                map[n++] = i;
            }
        }
        return new Normalized(out.toString(), Arrays.copyOf(map, n));
    }

    private static boolean skip(char c) {
        return Character.isWhitespace(c) || Character.isSpaceChar(c)
                || c == '\u200B' || c == '\u200C' || c == '\u200D' || c == '\uFEFF' || c == '\u00AD';
    }

    /** 원문 기준 앞뒤 12자 문맥. 제어·서식 문자 제거, '|'→' / ', 80자 상한. 로그·DB 에 남기지 않는다(호출자 책임). */
    static String context(String raw, Normalized nz, Found f) {
        int a = nz.orig[f.start];
        int b = nz.orig[f.end - 1] + 1;
        int from = Math.max(0, a - 12);
        int to = Math.min(raw.length(), b + 12);
        String s = raw.substring(from, to).replace("|", " / ")
                .replaceAll("[\\p{Cc}\\p{Cf}]", " ").replaceAll("\\s+", " ").trim();
        s = (from > 0 ? "…" : "") + s + (to < raw.length() ? "…" : "");
        return s.length() > 80 ? s.substring(0, 80) : s;
    }

    private static String trim(String v) {
        return v == null ? null : v.trim();
    }
}

     */
    @Transactional
    public Map<String, Object> ack(String taskId, String rawName, SysUser me, Actor actor, BoardUiIds.Ui ui, DocCheckAckIn in) {
        TaskContext ctx = requireContext(taskId);
        requireAckOwner(ctx, me);
        String name = safeName(rawName);
        validate(in);
        String status = mapper.lockTask(taskId);
        if (status == null) {
            throw ApiException.notFound("task not found");
        }
        if (Teams.DESIGNER_TEAM.equals(ctx.getTeam()) && !Teams.isWorking(status)) {
            throw DesignReviewService.coded(409, "TASK_LOCKED",
                    "의견을 받는 중이거나 확정된 작업은 표시를 바꿀 수 없습니다. 먼저 [다시 수정]을 눌러 주세요.");
        }
        existing(ctx, name);
        FileView v = views(ctx, name).get(0);
        if (!v.fresh || !parsed(v.state) || !v.row.getFileSha256().equals(in.getSha256())) {
            throw DesignReviewService.coded(409, "DOC_CHECK_STALE", "점검 결과가 바뀌었습니다. 새로 고친 뒤 다시 표시해 주세요.");
        }
        Map<Key, HitView> byKey = new HashMap<Key, HitView>();
        for (HitView h : v.hits) {
            byKey.put(new Key(h.hit.getFoundInstId(), h.hit.getLocKind(), h.hit.getLocNo()), h);
        }
        boolean want = in.getAcked();
        int seq = mapper.selectMaxSeq(taskId);
        String now = Times.nowIso();
        Set<Key> seen = new HashSet<Key>();
        for (DocCheckAckIn.Item it : in.getItems()) {
            Key k = new Key(it.getInstId(), it.getLocKind(), it.getLocNo());
            if (!seen.add(k)) {
                continue;
            }
            HitView h = byKey.get(k);
            if (h == null) {
                throw ApiException.badRequest("표시할 줄을 찾을 수 없습니다.");   // 롤백 — 앞서 넣은 줄도 남지 않는다
            }
            if (h.acked == want) {
                continue;   // 이미 그 상태 — 이력을 늘리지 않는다
            }
            DocCheckLogRow r = logRow(taskId, ++seq, want ? EV_ACK : EV_UNACK, actor, me.getEmpNo(), ui, now);
            r.setFileSha256(v.row.getFileSha256());
            r.setFoundInstId(k.instId);
            r.setLocKind(k.kind);
            r.setLocNo(k.no);
            mapper.insertLog(r);
        }
        return fileDetail(views(ctx, name).get(0), false, null);
    }

    // ── 제출 감사 ────────────────────────────────────────────────────────

    /**
     * 제출이 <b>성공한 뒤</b> 미확인·점검 못 함·일부 점검이 남아 있으면 SUBMIT_OPEN 한 줄(누가·어느 화면·어느 버튼·건수).
     * 건수는 서버가 다시 센다(화면이 확인창을 띄웠는지와 무관). 계산 실패는 조용히 건너뛴다 — 제출 흐름을 바꾸지 않는다.
     */
    @Transactional
    public void recordSubmit(String taskId, Actor actor, BoardUiIds.Ui ui) {
        TaskContext ctx = tasks.selectContext(taskId);
        if (ctx == null) {
            return;
        }
        Counts c = new Counts();
        try {
            for (FileView v : views(ctx, null)) {
                c.add(v);
            }
        } catch (RuntimeException e) {
            return;   // 경로 가드 등 — 감사 줄을 못 만들 뿐 제출은 이미 끝났다
        }
        if (c.open == 0 && c.notChecked == 0 && c.partial == 0) {
            return;
        }
        if (mapper.lockTask(taskId) == null) {
            return;
        }
        DocCheckLogRow r = logRow(taskId, mapper.selectMaxSeq(taskId) + 1, EV_SUBMIT, actor, actor.getEmpNo(), ui, Times.nowIso());
        r.setOpenCount(c.open);
        r.setNotCheckedCount(c.notChecked);
        r.setPartialCount(c.partial);
        mapper.insertLog(r);
    }

    private void write(TaskContext ctx, String name, String sha, long size, long mtime,
                       TaskDocExtractor.Extracted ex, Scan scan) {
        String taskId = ctx.getTaskId();
        String key = nameKey(name);
        String state = ex.state;
        String reason = ex.reason;
        if (scan.capped) {
            state = TaskDocExtractor.PARTIAL;
            reason = "HIT_CAP";
        }
        mapper.deleteHits(taskId, key);
        mapper.deleteCheck(taskId, key);
        DocCheckRow row = new DocCheckRow();
        row.setTaskId(taskId);
        row.setNameKey(key);
        row.setFileSha256(sha);
        row.setFileSize(size);
        row.setFileMtimeMs(mtime);
        row.setInstitutionId(ctx.getInstitutionId());
        row.setStateCd(state);
        row.setReasonCd(reason);
        row.setHasImages(ex.hasImages ? 1 : 0);
        row.setHasEmbedded(ex.hasEmbedded ? 1 : 0);
        row.setOrderApprox(ex.orderApprox ? 1 : 0);
        row.setHitRows(scan.counts.size());
        row.setCheckerVer(CHECKER_VER);
        row.setCheckedAt(Times.nowIso());
        mapper.insertCheck(row);
        for (Map.Entry<Key, int[]> e : scan.counts.entrySet()) {
            DocCheckHitRow h = new DocCheckHitRow();
            h.setTaskId(taskId);
            h.setNameKey(key);
            h.setFoundInstId(e.getKey().instId);
            h.setLocKind(e.getKey().kind);
            h.setLocNo(e.getKey().no);
            h.setHitCount(e.getValue()[0]);
            mapper.insertHit(h);
        }
    }

    private static final class Scan {
        final Map<Key, int[]> counts = new LinkedHashMap<Key, int[]>();
        boolean capped;
    }

    private Scan scan(String currentInstId, TaskDocExtractor.Extracted ex) {
        InstNameMatcher m = InstNameMatcher.build(dictRows(), currentInstId);
        Scan s = new Scan();
        for (TaskDocExtractor.Part p : ex.parts) {
            for (InstNameMatcher.Found f : m.scan(InstNameMatcher.normalize(p.text))) {
                Key k = new Key(f.instId, p.kind, p.no);
                int[] c = s.counts.get(k);
                if (c == null) {
                    if (s.counts.size() >= HIT_CAP) {   // security S5
                        s.capped = true;
                        continue;
                    }
                    c = new int[1];
                    s.counts.put(k, c);
                }
                c[0]++;
            }
        }
        return s;
    }

    private Map<Key, List<String>> contexts(TaskContext ctx, String name, final File disk, FileView v) {
        final byte[][] held = new byte[1][];
        TaskDocExtractor.Extracted ex = runner.run(TaskDocExtractor.extOf(name),
                () -> held[0] = Files.readAllBytes(disk.toPath()));
        if (TaskDocExtractor.R_BUSY.equals(ex.reason)) {
            throw busy();
        }
        if (held[0] == null || !ex.parsed() || !sha256(held[0]).equals(v.row.getFileSha256())) {
            return null;   // 그사이 파일이 바뀌었거나 다시 못 읽음 — context_state UNAVAILABLE
        }
        Set<Key> wanted = new HashSet<Key>();
        for (HitView h : v.hits) {
            wanted.add(new Key(h.hit.getFoundInstId(), h.hit.getLocKind(), h.hit.getLocNo()));
        }
        InstNameMatcher m = InstNameMatcher.build(dictRows(), ctx.getInstitutionId());
        Map<Key, List<String>> out = new HashMap<Key, List<String>>();
        for (TaskDocExtractor.Part p : ex.parts) {
            InstNameMatcher.Normalized nz = InstNameMatcher.normalizeWithMap(p.text);
            for (InstNameMatcher.Found f : m.scan(nz.text)) {
                Key k = new Key(f.instId, p.kind, p.no);
                if (!wanted.contains(k)) {
                    continue;
                }
                List<String> l = out.get(k);
                if (l == null) {
                    l = new ArrayList<String>();
                    out.put(k, l);
                }
                if (l.size() < 3) {
                    l.add(InstNameMatcher.context(p.text, nz, f));
                }
            }
        }
        return out;
    }

    private List<FileView> views(TaskContext ctx, String onlyName) {
        List<String> names = new ArrayList<String>();
        if (onlyName != null) {
            names.add(onlyName);
        } else {
            for (TaskFileEntry e : listing(ctx)) {
                names.add(e.getName());
            }
        }
        if (names.isEmpty()) {
            return Collections.emptyList();
        }
        String taskId = ctx.getTaskId();
        Map<String, DocCheckRow> checks = new HashMap<String, DocCheckRow>();
        for (DocCheckRow r : mapper.selectChecks(taskId)) {
            checks.put(r.getNameKey(), r);
        }
        Map<String, List<DocCheckHitRow>> hits = new HashMap<String, List<DocCheckHitRow>>();
        for (DocCheckHitRow h : mapper.selectHits(taskId, onlyName == null ? null : nameKey(onlyName))) {
            List<DocCheckHitRow> l = hits.get(h.getNameKey());
            if (l == null) {
                l = new ArrayList<DocCheckHitRow>();
                hits.put(h.getNameKey(), l);
            }
            l.add(h);
        }
        Map<String, AckState> acks = ackStates(taskId);
        Map<String, String> instNames = instNames();
        List<FileView> out = new ArrayList<FileView>();
        for (String n : names) {
            out.add(view(ctx, n, checks, hits, acks, instNames));
        }
        return out;
    }

    private FileView view(TaskContext ctx, String name, Map<String, DocCheckRow> checks,
                          Map<String, List<DocCheckHitRow>> hits, Map<String, AckState> acks, Map<String, String> instNames) {
        FileView v = new FileView(name);
        String key = nameKey(name);
        DocCheckRow row = checks.get(key);
        File disk = TaskFiles.resolve(properties.getOutputRoot(), ctx.getInstitutionName(), ctx.getTaskId(), name);
        v.row = row;
        v.fresh = row != null && disk.isFile() && row.getFileSize() == disk.length()
                && row.getFileMtimeMs() == disk.lastModified() && row.getCheckerVer() == CHECKER_VER
                && String.valueOf(ctx.getInstitutionId()).equals(row.getInstitutionId());
        if (!v.fresh) {
            v.state = TaskDocExtractor.NOT_CHECKED;
            v.reason = "STALE";
            return v;
        }
        v.state = row.getStateCd();
        v.reason = row.getReasonCd();
        List<DocCheckHitRow> hs = hits.get(key);
        if (hs == null) {
            return v;
        }
        for (DocCheckHitRow h : hs) {
            AckState a = acks.get(ackKey(row.getFileSha256(), h.getFoundInstId(), h.getLocKind(), h.getLocNo()));
            HitView hv = new HitView(h, instNames.get(h.getFoundInstId()), a);
            v.hits.add(hv);
            if (hv.acked) {
                v.acked++;
            } else {
                v.unconfirmed++;
            }
        }
        Collections.sort(v.hits, HIT_ORDER);
        return v;
    }

    private static final Comparator<HitView> HIT_ORDER = new Comparator<HitView>() {
        @Override
        public int compare(HitView a, HitView b) {
            int k = Integer.compare(kindRank(a.hit.getLocKind()), kindRank(b.hit.getLocKind()));
            if (k != 0) {
                return k;
            }
            int n = Integer.compare(a.hit.getLocNo(), b.hit.getLocNo());
            if (n != 0) {
                return n;
            }
            return String.valueOf(a.instName).compareTo(String.valueOf(b.instName));
        }
    };

    private static int kindRank(String kind) {
        int i = KIND_ORDER.indexOf(kind);
        return i < 0 ? KIND_ORDER.size() : i;
    }

    private Map<String, Object> fileSummary(FileView v) {
        Map<String, Object> m = new LinkedHashMap<String, Object>();
        m.put("name", v.name);
        m.put("state", v.state);
        m.put("reason", v.reason);
        m.put("has_images", v.fresh && v.row.getHasImages() == 1);
        m.put("has_embedded", v.fresh && v.row.getHasEmbedded() == 1);
        m.put("order_approx", v.fresh && v.row.getOrderApprox() == 1);
        m.put("checked_at", v.fresh ? v.row.getCheckedAt() : null);
        m.put("hit_count", v.hits.size());
        m.put("unconfirmed_count", v.unconfirmed);
        m.put("acked_count", v.acked);
        return m;
    }

    private Map<String, Object> fileDetail(FileView v, boolean withContext, Map<Key, List<String>> contexts) {
        Map<String, Object> m = fileSummary(v);
        m.put("sha256", v.fresh ? v.row.getFileSha256() : null);
        if (withContext && contexts == null && !v.hits.isEmpty()) {
            m.put("context_state", "UNAVAILABLE");
        }
        List<Map<String, Object>> rows = new ArrayList<Map<String, Object>>();
        for (HitView h : v.hits) {
            Map<String, Object> r = new LinkedHashMap<String, Object>();
            r.put("inst_id", h.hit.getFoundInstId());
            r.put("inst_name", h.instName);
            r.put("loc_kind", h.hit.getLocKind());
            r.put("loc_no", h.hit.getLocNo());
            r.put("count", h.hit.getHitCount());
            r.put("acked", h.acked);
            r.put("acked_by_name", h.acked ? h.byName : null);   // 사번은 싣지 않는다(security S11)
            r.put("acked_at", h.acked ? h.at : null);
            if (contexts != null) {
                List<String> c = contexts.get(new Key(h.hit.getFoundInstId(), h.hit.getLocKind(), h.hit.getLocNo()));
                r.put("contexts", c == null ? Collections.<String>emptyList() : c);
            }
            rows.add(r);
        }
        m.put("hits", rows);
        return m;
    }

    private Map<String, AckState> ackStates(String taskId) {
        Map<String, AckState> out = new HashMap<String, AckState>();
        for (DocCheckLogRow r : mapper.selectAckLog(taskId)) {
            if (r.getLocNo() == null) {
                continue;
            }
            out.put(ackKey(r.getFileSha256(), r.getFoundInstId(), r.getLocKind(), r.getLocNo()),
                    new AckState(EV_ACK.equals(r.getEventCd()), r.getEmpName(), r.getActedAt()));   // SEQ 순 — 마지막 줄이 현재 상태
        }
        return out;
    }

    List<InstNameMatcher.Row> dictRows() {
        long now = System.currentTimeMillis();
        List<InstNameMatcher.Row> rows = dictRows;
        if (rows == null || now - dictLoadedAt > DICT_TTL_MS) {
            List<InstNameMatcher.Row> fresh = new ArrayList<InstNameMatcher.Row>();
            for (InstNameRow r : mapper.selectInstitutionRows()) {
                fresh.add(new InstNameMatcher.Row(r.getInstitutionId(), r.getNameKo(), r.getRegionCode()));

            dictRows = rows;

    }

    /** 세 팀·디자이너 공통: 담당이 내 사번이거나, 내 이름이면서 ACTIVE 사용자 중 그 이름이 유일할 때만(S7). by·X-User-Id 는 보지 않는다. */
    private void requireAckOwner(TaskContext ctx, SysUser me) {
        String a = ctx.getAssignee() == null ? "" : ctx.getAssignee().trim();
        if (a.isEmpty() || me == null) {
            throw deniedOwner();
        }
        if (a.equals(me.getEmpNo())) {
            return;
        }
        String nm = me.getName() == null ? "" : me.getName().trim();
        if (!nm.isEmpty() && a.equals(nm) && activeNamed(nm) == 1) {
            return;
        }
        throw deniedOwner();
    }

    private int activeNamed(String name) {
        int n = 0;
        for (SysUser u : users.selectAll()) {
            if ("ACTIVE".equals(u.getStatus()) && u.getName() != null && name.equals(u.getName().trim())) {

            }

    private static void validate(DocCheckAckIn in) {
        if (in == null || in.getAcked() == null) {
            throw ApiException.badRequest("표시 여부(acked)가 필요합니다.");
        }
        if (in.getSha256() == null || !SHA.matcher(in.getSha256()).matches()) {
            throw ApiException.badRequest("파일 식별값이 올바르지 않습니다.");
        }
        List<DocCheckAckIn.Item> items = in.getItems();
        if (items == null || items.isEmpty() || items.size() > ACK_MAX_ITEMS) {
            throw ApiException.badRequest("표시할 줄은 1~" + ACK_MAX_ITEMS + "개입니다.");
        }
        for (DocCheckAckIn.Item it : items) {
            if (it == null || it.getInstId() == null || !INST_ID.matcher(it.getInstId()).matches()
                    || it.getLocKind() == null || !KIND_ORDER.contains(it.getLocKind())
                    || it.getLocNo() == null || it.getLocNo() < 0 || it.getLocNo() > TaskDocExtractor.MAX_LOC_NO) {
                throw ApiException.badRequest("표시할 줄의 값이 올바르지 않습니다.");
            }
        }
    }

    static String nameKey(String name) {
        return sha256(name.getBytes(StandardCharsets.UTF_8));
    }

    static String sha256(byte[] data) {
        try {
            byte[] d = MessageDigest.getInstance("SHA-256").digest(data);
            StringBuilder sb = new StringBuilder(64);
            for (byte b : d) {
                sb.append(Character.forDigit((b >> 4) & 0xF, 16)).append(Character.forDigit(b & 0xF, 16));
            }
            return sb.toString();
        } catch (NoSuchAlgorithmException e) {
            throw new IllegalStateException(e);
        }
    }

    private static String ackKey(String sha, String inst, String kind, int no) {
        return sha + '\u0000' + inst + '\u0000' + kind + '\u0000' + no;
    }

    static final class Key {
        final String instId;
        final String kind;
        final int no;

        Key(String instId, String kind, int no) {
            this.instId = instId;
            this.kind = kind;
            this.no = no;
        }

        @Override
        public boolean equals(Object o) {
            if (!(o instanceof Key)) {
                return false;
            }
            Key k = (Key) o;
            return no == k.no && instId.equals(k.instId) && kind.equals(k.kind);
        }

        @Override
        public int hashCode() {
            return (instId.hashCode() * 31 + kind.hashCode()) * 31 + no;
        }
    }

    private static final class AckState {
        final boolean acked;
        final String byName;
        final String at;

        AckState(boolean acked, String byName, String at) {
            this.acked = acked;
            this.byName = byName;
            this.at = at;
        }
    }

    private static final class HitView {
        final DocCheckHitRow hit;
        final String instName;
        final boolean acked;
        final String byName;
        final String at;

        HitView(DocCheckHitRow hit, String instName, AckState a) {
            this.hit = hit;
            this.instName = instName;
            this.acked = a != null && a.acked;
            this.byName = a == null ? null : a.byName;
            this.at = a == null ? null : a.at;
        }
    }

    private static final class FileView {
        final String name;
        DocCheckRow row;
        boolean fresh;
        String state;
        String reason;
        final List<HitView> hits = new ArrayList<HitView>();
        int unconfirmed;
        int acked;

        FileView(String name) {
            this.name = name;
        }
    }

    private static final class Counts {
        int open;
        int notChecked;
        int partial;

        void add(FileView v) {
            if (TaskDocExtractor.PARTIAL.equals(v.state)) {
                partial++;
            } else if (!TaskDocExtractor.DONE.equals(v.state)) {
                notChecked++;   // NOT_CHECKED·ERROR·STALE
            }
            open += v.unconfirmed;
        }
    }

## 5. 보안·위험·되돌리는 법

**권한·인증**
- 인증은 `X-Emp-No` 자기신고입니다.
  - ack의 담당 비교, 감사의 EMP_NO·화면·버튼은 **업무 규칙 위의 기록이지 사칭 방지가 아닙니다.**
  - `EMP_VERIFIED=0`이 정상값입니다. 화면·보고서에 "검증됨"을 쓰지 않습니다.
- 403 경로는 모두 접근 이력에 DENIED로 남습니다(`requireActiveUser`, `designerWriteActor`, 서비스 403 → `guard.denied`). 사유는 고정 문구이고 본문·쿼리값은 넣지 않습니다.
- 디자이너 ack에서 `designerWriteActor`가 남긴 403은 컨트롤러가 다시 남기지 않습니다(try 밖에서 호출).
- 세 팀은 여전히 사번 없이 업로드할 수 있습니다(기존 NEXT 35 한계). 다만 ack는 사번이 없으면 401이고, 담당 비교도 `me` 기준입니다.

**대외비·로그**
- 파일 글·문맥은 DB·감사·로그 어디에도 없습니다. WARN 로그는 작업 키와 예외 종류만 남깁니다.
- 경로의 파일 이름은 접근 이력에 남습니다(S17, 기존 수준).

**가용성**
- 동시에 2건을 넘는 점검은 `BUSY`이고, 결과는 NOT_CHECKED입니다. 거짓 "깨끗함"은 없습니다. 사용자가 [다시 점검]을 누르면 됩니다.
- PDF가 PDFBox 안에서 멈추면 그 자리는 스레드가 끝날 때까지 묶입니다. 최악의 경우 2자리가 모두 묶여 모든 점검이 BUSY가 되고, 업로드 자체는 됩니다. 재기동하면 풀립니다.
- pptx 마감은 읽기와 이벤트 사이에서만 확인합니다. XML 하나를 파싱하는 동안은 30MB 상한이 시간을 묶습니다.
- 업로드 응답은 최대 약 20초 늦어질 수 있습니다(동기 점검).

**동시성**
- 파일 잠금은 한 JVM 안에서만 유효합니다. 서버를 여러 대로 늘리면 다시 설계해야 합니다. 그때도 요약은 크기·수정시각 대조로 STALE을 보입니다.
- ack·제출 감사의 일련번호는 TASKS FOR UPDATE 아래에서 매깁니다. 업로드 기록은 TASKS를 잠그지 않으므로 교착 고리가 없습니다.

**데이터**
- DOC_CHECK_LOG는 계속 늘어납니다(보존 기간은 미정 → 기획).
- 사전은 10분 캐시입니다. 기관 표가 바뀌면 최대 10분 뒤 반영되고, 이미 점검한 파일은 [다시 점검]으로 갱신합니다.

**되돌리기**
- 코드: `TaskFileService`·`TaskFiles`·`TaskController`·`DesignUiIds`·`BoardWriteLimitFilter` diff를 되돌리고 새 파일을 지우면 이전 동작입니다.
- DB: `DROP TABLE DOC_CHECK_LOG; DROP TABLE DOC_CHECK_HIT; DROP TABLE DOC_CHECK;`(감사 이력 소멸 — 운영 금지).
- 스위치: `ggreport.task-files.reject-unsafe`(기본 false), `ggreport.task-files.doc-check.max-concurrent`(기본 2, 1~4). 직전 설계의 `app.*` 접두는 기존 관행(`ggreport.*`, `AppProperties`)에 맞춰 바꿨습니다. 기본값이 있어서 `config/application.properties`에 키를 더하지 않아도 됩니다.
