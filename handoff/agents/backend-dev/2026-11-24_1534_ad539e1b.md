    static String lineText(Map<String, Object> it, boolean withDates) {
        String v = str(it.get("value")).trim();
        return withDates ? v + datesOf(it) : v;

    /**
     * 날짜 괄호. 저장값 YYYY / YYYY-MM(-DD) 를 연도 또는 'YYYY.MM'(일은 버림)으로. 형식 밖 값은 "확인 안 됨"으로 보아 적지 않는다.
     * 둘 다: '(A ~ B)', 같으면 '(A)' · 시작만: '(A ~ 현재)' · 끝만: '(B)' · 둘 다 없음: "".
     */
    private static String datesOf(Map<String, Object> it) {
        String from = dateText(str(it.get("from")));
        String to = dateText(str(it.get("to")));
        if (!from.isEmpty() && !to.isEmpty()) {
            return from.equals(to) ? "(" + from + ")" : "(" + from + " ~ " + to + ")";
        }
        if (!from.isEmpty()) {
            return "(" + from + " ~ 현재)";
        }
        return to.isEmpty() ? "" : "(" + to + ")";
    }

    private static String dateText(String raw) {
        String s = raw.trim();
        return s.matches("\\d{4}(-\\d{2}(-\\d{2})?)?") ? ym(s) : "";
    }

                    ByteArrayOutputStream o = new ByteArrayOutputStream();
                    byte[] buf = new byte[4096];

                    while ((n = z.read(buf)) > 0) { o.write(buf, 0, n); }
                    return new String(o.toByteArray(), StandardCharsets.UTF_8);

### 사람이 Word에서 봐야 할 것 (추정 한계)
- 실제 줄바꿈·1장 맞춤은 Word로 확인. ROW_MM/CONTENT_CAP는 보수적 추정.

## 5. 보안·위험·되돌리는 법
- 권한: 401/403/404 경로와 접근 이력·감사 기록은 run()을 그대로 사용. mode는 run() 안(영업 역할 확인 뒤)에서 검사 → 비영업은 mode 값과 무관하게 403 DENIED. 400은 INVALID로 남는다. 접근 이력에 쿼리값 없음, 오류 메시지에 입력값 안 싣는다.
- 동작 변경: 요약본이 기본이라, 화면이 파라미터 없이 부르면 오늘 아침 커밋(연도 기간 표)과 달리 날짜가 전혀 없는 문서가 나온다(사용자 결정). 프런트 배포와 순서를 맞춰야 한다. 날짜 포함 선택지가 붙을 때까지 연도가 사라진 상태로 나간다.
- 날짜 형식 밖 값은 적지 않음("확인 안 되면 적지 않는다"). 입력 검증이 YYYY/YYYY-MM만 받으므로 실제로 거의 발생하지 않음.
- 되돌리기: HeadDocBuilder·Controller 변경 되돌리면 됨. DB·응답 키·/menus·골든 04·05 건드리지 않음.
