### 1. 고친 파일과 바꾼 부분

**PrepFormApiTest.java** (`src/test/java/.../web/web/`)
- 236행 부근: 빈 단언을 `assertEquals(2, count(FORM_SAVE, OK, FORM_VER=2, form_save))`로 바꿨다.
  - 근거 `PrepFormService.java` 236·522행: `saveDraft`는 같은 내용이어도(`changed=false`) `saved()`에서 OK 줄을 쓴다. 그래서 첫 저장(ver 2)과 같은 내용 저장 두 번이 OK 2줄이다.
  - 409 stale는 `PrepFormController.run`의 `auditFailure`가 BLOCKED로 남기므로 세지 않는다.
- 271행 부근: `assertEquals(5, acts(bid, "FORM_SAVE", "DENIED"))`로 바꿨다.
  - 근거: 5명(DESIGNER·HEAD·LEAD·MEMBER·IT)은 모두 `requireWriterRole`에서 403이다. 디자이너·부장·전산은 영업이 아니라서, 팀장·비담당 영업은 활성 담당이 아니라서 걸린다.
  - `run`이 403마다 `outcomeOf(403)`=DENIED 줄을 한 번씩 쓴다. 사번 없는 401은 줄이 없다.

**InstSummaryPrefill.java**
- `seedText`: 자르기 전 `t`에 `Pii.scanLoose`를 먼저 걸어 `pii` 변수에 담는다(약 354행). 마지막 검사는 `if (pii || !Pii.scanLoose(t).isEmpty()) return BLOCKED`로 바꿨다.
- `seedYearFrom`(약 165행): `return nextYear(max)`로 바꾸고, 새 패키지 전용 정적 메서드 `nextYear(Integer)`를 추가했다. 만기 연도+1을 `Math.min(..., 2100)`으로 자른다.
  - 근거 `PrepFormService.java` 1045행: 저장 검사의 연도 상한이 2100이다.
  - 씨앗 표는 `from=to=시작 연도`이므로 2100이면 통과한다.

**HeadAudit.java**: 클래스 주석(23행)에 지시한 한 줄을 달았다. 코드는 건드리지 않았다.

**PrepFormContentTest.java** (`src/test/java/.../web/service/`): 지시에서 쓸 수 있다고 한 파일이다. `Pii` import를 추가하고 시험 2건을 넣었다.

### 추가한 시험
- `씨앗_글자는_200자_경계에_걸린_주민번호도_자르기_전_원문으로_걸러낸다`
  - 195자 + 공백 + `900101-1234567`을 만든다. 200자에서 자르면 `9001`만 남아 패턴이 안 잡힌다.
  - 이 전제를 단언한 뒤, `seedText`가 BLOCKED를 돌려주는지 확인한다.
- `연도_표_씨앗은_만기_연도_다음_해이고_2100을_넘으면_2100으로_자른다`
  - `nextYear`에 null, 2090, 2099, 2100, 9999를 넣어 null, 2091, 2100, 2100, 2100이 나오는지 본다.

### 2. 메인이 실행할 명령
`cd kgi-ggreport-web && mvn -q -o test -Dtest=PrepFormContentTest,PrepFormApiTest`
- 기대: 모두 통과. PrepFormContentTest는 2건 늘고, PrepFormApiTest는 건수가 같다.
- 마무리로 `mvn -q -o test` 전체를 한 번 돌린다.
- 8080 서버가 같은 `target/`을 쓰면 테스트 뒤에 재기동한다.
- DB 적용 변경은 없다.

### 3. 지시에서 벗어난 판단
- P3-3은 "만들지 않기 또는 2100으로 자르기" 중 2100으로 자르기를 골랐다.
  - 이유: 만들지 않으면 `explicitYears` 경로에서 `NO_CONTRACT` 409가 나는데, 약정은 있으므로 메시지가 틀린다.
  - 부작용: 만기가 2100년 이상인 약정은 시작 연도가 2100으로 보인다. 현실에서는 거의 없는 값이다.
- `nextYear`는 시험하려고 만든 새 패키지 전용 메서드다. `seedYearFrom`은 mapper가 필요한 인스턴스 메서드라 단위시험이 어렵다. 동작은 같다.
