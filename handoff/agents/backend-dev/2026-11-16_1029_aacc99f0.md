- **임박 판정은 프런트 전용이다.**
  - `frontend/js/logic.js:134-144`의 `effectiveBid`는 `contractExpiry`를 쓴다.
  - 이 값은 서버 DB에 칸이 없다(`db/mysql/029_seed_institutions_all.sql:11` "contractExpiry (DB 칸 없음)"). 프런트가 번들에서 덮어 얹는다(`logic.js:213-224` overlayExtras).
  - 진행 중 공고 제외(`dashboard.js:54`)와 기간 창(`dashboard.js:15,98-101`)도 프런트에만 있다.
  - → 서버가 같은 기준을 다시 만들면 두 판정이 갈라진다. 그래서 API ①은 "사업계획 상태 목록"만 돌려주고, 임박 목록과 기간 6개월/1년/전체 계산은 프런트가 `dash.model`·`windowItems`로 만든 뒤 `institution_id`로 붙인다.
- **조회 가드 키는 `map`으로 한다.**
  - 선례: 같은 '기관' 묶음의 입찰 현황판이 키 없는 soon 항목인데 `withKey 'map'`으로 뜬다(`nav.js:61`).
  - `map`은 모든 알려진 역할의 기본값이다(`Menus.java:85`). 영업부장은 `regions`가 꺼져 있고 `map`은 켜져 있다(`Menus.java:109-110`).
- **업로드는 AdminGuard만 쓴다.**
  - 선례 `/import`는 `requireInstitutionEdit`를 쓰는데, 영업 계열이 기본으로 통과한다(`InstitutionController.java:62-63,136-138`, security '상' 지적).
  - `AdminGuard.require`(`AdminGuard.java:29-39`)를 쓴다.
- **기존 CSV 파서의 약점**: 상한이 없고, 따옴표가 닫히지 않으면 나머지를 다 삼키며, cp949로 폴백한다(`InstitutionCsv.java:135-145,178-241`).
  - 사업계획 쪽은 엄격 UTF-8만 받는다.
  - 기관 반입 쪽 cp949 폴백은 "지우지 말 것" 주석(`InstitutionCsv.java:127`)과 기존 시험(`InstitutionImportApiTest` `cp949로_저장된_표도_읽는다`)을 지키려고 그대로 둔다.
- **URL 검사 공용화**: `InstitutionEditRules.java:268-298`의 `url()` 본체를 공용 `SafeUrl`로 옮기고, 동작은 바꾸지 않는다(`InstitutionEditRulesTest:47-62`로 확인됨).
- **감사 선례**: 서버 고정 화면·버튼(`InstUiIds.java:38-46`), 별도 감사 표(`026` `INST_HEAD_ACT`), 실패도 기록(`InstitutionHeadController.java:396-415`).
- **팀 결정 반영**:
  - 확인 상태는 사업 단위로 저장하고, 문서별로 상태별 건수를 같이 돌려준다.
  - '기간 지남'은 문서 단위만이다. 사업 행 배지는 '폐기'(공약 진행상태)뿐이다.
  - 계산값은 하위 사업이 모두 '금액' 상태이고 단위가 같을 때만 낸다. 아니면 `UNVERIFIED`를 돌려준다. 서버가 계산하고 `is_calculated`로 표시한다.
  - 예산 상태는 4종이다. 원문 단위를 그대로 저장하고, 0은 저장하지 않는다.
  - 오래됨 = 확인일이 12개월을 넘음. 기간 지남 = 대상기간 끝 연도 < 올해(서울 기준). 재반입은 새 판 INSERT만 한다.

### 3. 구현안

#### 3-1. 마이그레이션 034 (외래키 없음, INSERT·SELECT만 쓰는 표)
**판(版) 규칙**:
- 반입 1건 = `INST_PLAN_IMPORT` 1행 + 그 파일의 문서·사업 전부다.
- 기관의 현재 자료 = 그 기관의 가장 큰 `IMPORT_ID` 판 전체다. 파일 하나가 그 기관 자료 전체라는 뜻이다(열린 질문 2).

**`db/oracle/034_inst_plan.sql` (정본)**
```sql
--------------------------------------------------------------------------------
-- kgi-ggreport-web — Oracle 정본 (034) : 기관 사업계획 1단계(기획안 2026-11-16)
--   INST_PLAN_IMPORT / INST_PLAN_DOC / INST_PLAN_ITEM / INST_PLAN_ACT (+ COMMON_CODE 7그룹 26행)
-- 외래키·CHECK·UNIQUE 없음(PK 와 조회용 인덱스만). 참조는 서비스가 확인한다:
--   INSTITUTION_ID -> INSTITUTIONS, IMPORT_ID -> INST_PLAN_IMPORT, DOC_ID -> INST_PLAN_DOC, *_CD -> COMMON_CODE, *_BY·ACTOR_EMP_NO -> USERS.
-- 판 규칙: 반입 1건 = IMPORT 1행 + 그 파일의 문서·사업 전부. 고치지 않고 새 판을 INSERT 한다(UPDATE·DELETE 없음).
--   기관의 현재 자료 = 그 기관의 가장 큰 IMPORT_ID 판.
-- 예산: 원문 숫자(BUDGET_AMOUNT, 0 금지)와 원문 단위(BUDGET_UNIT_CD)를 함께 둔다. 원문의 '-'·빈칸은 BUDGET_STATE_CD 로만 적는다.
-- URL_MISSING=1 은 ORIGIN_CD='SEED_TXT'(서버 고정 시드 경로)에서만 생긴다. 바깥 반입은 출처 URL 필수.
-- 서버는 SRC_URL 을 열지 않는다(화면 링크 표시용 문자열).
-- ⚠️ 사번은 자기신고(X-Emp-No)일 수 있다. *_VERIFIED·EMP_VERIFIED=0 이면 '검증됨'으로 표시하지 않는다.
-- ⚠️ DB 권한(DBA): 앱 계정은 네 표 모두 SELECT·INSERT 만(UPDATE·DELETE 없음).
-- ⚠️ 멱등하지 않다. 016(COMMON_CODE) 이후 한 번만 돌린다.
-- 되돌리기(데이터 소멸, 운영 금지): DROP TABLE INST_PLAN_ACT; DROP TABLE INST_PLAN_ITEM; DROP TABLE INST_PLAN_DOC; DROP TABLE INST_PLAN_IMPORT;
--   DELETE FROM COMMON_CODE WHERE CODE_GROUP IN ('PLAN_SRC_KIND','PLAN_CHECK','PLAN_BUDGET_STATE','PLAN_BUDGET_UNIT',
--     'PLAN_PROGRESS','PLAN_ORIGIN','PLAN_ACTION');
--------------------------------------------------------------------------------

CREATE TABLE INST_PLAN_IMPORT (                      -- 반입 1건 = 판 1개
    IMPORT_ID         NUMBER GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    INSTITUTION_ID    VARCHAR2(64 CHAR)  NOT NULL,
    ORIGIN_CD         VARCHAR2(20 CHAR)  NOT NULL,      -- PLAN_ORIGIN(IMPORT / SEED_TXT) — 서버가 경로로 정한다
    FILE_DATE         VARCHAR2(10 CHAR)  NOT NULL,      -- 파일 이름의 날짜 = 문서 확인일 중 가장 늦은 날
    FILE_SHA256       VARCHAR2(64 CHAR)  NOT NULL,      -- 올라온 원본 바이트 해시(원래 파일 이름은 저장하지 않는다)
    FILE_BYTES        NUMBER(12)         NOT NULL,
    ITEM_COUNT        NUMBER(6)          NOT NULL,      -- 사업 행 수
    DOC_COUNT         NUMBER(4)          NOT NULL,
    WARN_COUNT        NUMBER(6)          DEFAULT 0 NOT NULL,
    BATCH_ID          VARCHAR2(64 CHAR),                -- 수집 배치 id(있으면)
    IMPORTED_BY       VARCHAR2(7 CHAR)   NOT NULL,
    IMPORTED_AT       VARCHAR2(40 CHAR)  NOT NULL,
    IMPORTED_VERIFIED NUMBER(1)          DEFAULT 0 NOT NULL,
    CONSTRAINT PK_INST_PLAN_IMPORT PRIMARY KEY (IMPORT_ID)
);
CREATE INDEX IDX_IPI_INST ON INST_PLAN_IMPORT (INSTITUTION_ID, IMPORT_ID);

CREATE TABLE INST_PLAN_DOC (                         -- 계획 문서 한 권(판 안)
    DOC_ID          NUMBER GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    IMPORT_ID       NUMBER             NOT NULL,
    INSTITUTION_ID  VARCHAR2(64 CHAR)  NOT NULL,
    DOC_SEQ         NUMBER(4)          NOT NULL,        -- 파일 안 순서
    TITLE           VARCHAR2(200 CHAR) NOT NULL,
    SRC_KIND_CD     VARCHAR2(20 CHAR)  NOT NULL,        -- PLAN_SRC_KIND
    PERIOD_FROM     NUMBER(4)          NOT NULL,
    PERIOD_TO       NUMBER(4)          NOT NULL,        -- '기간 지남' = PERIOD_TO < 올해(조회 시 계산, 저장 안 함)
    SRC_URL         VARCHAR2(1000 CHAR),                -- http/https, 계정정보 금지, 500자 검사
    URL_MISSING     NUMBER(1)          DEFAULT 0 NOT NULL,

    COLLECTED_BY    VARCHAR2(7 CHAR),                   -- 수집자 사번(시드는 NULL 가능)
    PAGE_RANGE      VARCHAR2(20 CHAR),
    NOTE            VARCHAR2(500 CHAR),
    CONSTRAINT PK_INST_PLAN_DOC PRIMARY KEY (DOC_ID)
);
CREATE INDEX IDX_IPD_IMPORT ON INST_PLAN_DOC (IMPORT_ID, DOC_SEQ);

CREATE TABLE INST_PLAN_ITEM (                        -- 사업·하위사업 1개 = 1행
    ITEM_ID          NUMBER GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    DOC_ID           NUMBER             NOT NULL,
    IMPORT_ID        NUMBER             NOT NULL,
    INSTITUTION_ID   VARCHAR2(64 CHAR)  NOT NULL,
    ROW_NO           NUMBER(6)          NOT NULL,       -- 파일 행 번호(머리행 다음 = 1)
    FIELD_NO         VARCHAR2(20 CHAR),                 -- 분야(장) 번호 원문
    FIELD_NAME       VARCHAR2(100 CHAR),
```

```java
import java.net.URI;

/** http(s) 출처 링크 글자 검사 — 기관 편집(InstitutionEditRules.url)과 사업계획 반입(PlanCsv)이 같이 쓴다(보안 검토 2026-11-16 조건 4). 서버는 이 주소를 열지 않는다. */
public final class SafeUrl {

    public static final int MAX = 500;

    private SafeUrl() {
    }

    /** v 는 앞뒤 공백을 자른 값. 제어·공백·DEL·서식 문자(U+202E·U+200B 등), http(s) 아님, 호스트 없음, 계정정보 있음이면 false. */
    public static boolean isHttp(String v) {
        if (v == null || v.isEmpty() || v.length() > MAX) {
            return false;
        }
        for (int i = 0; i < v.length(); i++) {
            char c = v.charAt(i);
            if (c <= ' ' || c == 0x7f || Character.getType(c) == Character.FORMAT) {
                return false;
            }
        }
        URI u;
        try {
            u = new URI(v);
        } catch (URISyntaxException e) {
            return false;
        }
        String sc = u.getScheme();
        return sc != null && (sc.equalsIgnoreCase("http") || sc.equalsIgnoreCase("https"))
                && u.getHost() != null && u.getUserInfo() == null;
    }
```

```java
package com.kbstar.kgi.ggreport.web.support;

import java.util.ArrayList;
import java.util.List;

/**
 * CSV 반입 상한 + RFC 4180 최소 리더 — 기관 반입(InstitutionCsv)과 사업계획 반입(PlanCsv)이 같이 쓴다(보안 검토 2026-11-16 조건 2).
 * 직접 만든 이유는 폐쇄망(라이브러리 반입 비용). 위반은 {@link InstitutionCsv.CsvFormatException}(호출부가 400) — 사유에 행 번호만 싣는다.
 */
public final class CsvLimits {

    public static final long MAX_FILE_BYTES = 5L * 1024 * 1024;
    public static final int MAX_DATA_ROWS = 5000;
    public static final int MAX_CELL_CHARS = 1000;
    public static final int MAX_COLUMNS = 64;

    /** 기관 반입: 따옴표 위치는 예전처럼 너그럽게(엑셀 산출물 호환). 미종결 따옴표·상한만 막는다. */
    public static final CsvLimits INSTITUTION = new CsvLimits(false);
    /** 사업계획 반입: 따옴표는 칸 맨 앞에서만 열고, 닫은 뒤에는 쉼표·줄바꿈만 온다. */
    public static final CsvLimits PLAN = new CsvLimits(true);

    private final boolean strictQuotes;

    private CsvLimits(boolean strictQuotes) {
        this.strictQuotes = strictQuotes;
    }

    public static void checkSize(long bytes) {
        if (bytes > MAX_FILE_BYTES) {
            throw new InstitutionCsv.CsvFormatException("파일이 너무 큽니다(5MB 이하).");
        }
    }

    /** 줄 단위가 아니라 문자 단위로 훑는다(따옴표 안 줄바꿈). 완전히 빈 줄은 행으로 세지 않는다. */
    public List<List<String>> readAll(String text) {
        List<List<String>> out = new ArrayList<>();
        List<String> record = new ArrayList<>();
        StringBuilder field = new StringBuilder();
        boolean quoted = false;
        boolean closed = false;
        boolean any = false;
        int quoteRow = -1;
        for (int i = 0; i < text.length(); i++) {
            char c = text.charAt(i);
            if (quoted) {
                if (c == '"') {
                    if (i + 1 < text.length() && text.charAt(i + 1) == '"') {
                        field.append('"');
                        i++;
                    } else {
                        quoted = false;
                        closed = true;
                    }
                } else {
                    field.append(c);
                }
                cellLimit(field, out.size());
                continue;
            }
            if (c == '"') {
                if (strictQuotes && (field.length() > 0 || closed)) {
                    throw bad(out.size(), "따옴표 위치가 올바르지 않습니다.");
                }
                quoted = true;
                any = true;
                quoteRow = out.size();
            } else if (c == ',') {
                endField(record, field, out.size());
                closed = false;
                any = true;
            } else if (c == '\r' || c == '\n') {
                if (c == '\r' && i + 1 < text.length() && text.charAt(i + 1) == '\n') {
                    continue;   // CRLF 의 CR. 단독 CR 도 줄바꿈으로 본다
                }
                endField(record, field, out.size());
                closed = false;
                endRecord(out, record);
                record = new ArrayList<>();
                any = false;
            } else {
                if (strictQuotes && closed) {
                    throw bad(out.size(), "따옴표 위치가 올바르지 않습니다.");
                }
                field.append(c);
                any = true;
                cellLimit(field, out.size());
            }
        }
        if (quoted) {
            throw bad(quoteRow, "따옴표가 닫히지 않았습니다.");
        }
        if (any || field.length() > 0) {
            endField(record, field, out.size());
            endRecord(out, record);
        }
        List<List<String>> cleaned = new ArrayList<>();
        for (List<String> r : out) {
            if (r.size() == 1 && r.get(0).trim().isEmpty()) {
                continue;
            }
            cleaned.add(r);
        }
        if (cleaned.size() > MAX_DATA_ROWS + 1) {
            throw new InstitutionCsv.CsvFormatException("행이 너무 많습니다(5,000행 이하).");
        }
        return cleaned;
    }

    private static void endField(List<String> record, StringBuilder field, int row) {
        record.add(field.toString());
        field.setLength(0);
        if (record.size() > MAX_COLUMNS) {
            throw bad(row, "열이 너무 많습니다(64열 이하).");
        }
    }

    private static void endRecord(List<List<String>> out, List<String> record) {
        out.add(record);
        if (out.size() > MAX_DATA_ROWS * 2 + 1) {   // 빈 줄 포함 원시 행 상한(메모리 방어)
            throw new InstitutionCsv.CsvFormatException("행이 너무 많습니다(5,000행 이하).");
        }
    }

    private static void cellLimit(StringBuilder f, int row) {
        if (f.length() > MAX_CELL_CHARS) {
            throw bad(row, "칸이 너무 깁니다(1,000자 이하).");
        }
    }

    static InstitutionCsv.CsvFormatException bad(int row, String m) {
        return new InstitutionCsv.CsvFormatException(row <= 0 ? "header: " + m : "row " + row + ": " + m);
    }
}
```

```java
            return srcKind + '\u0001' + from + '\u0001' + to + '\u0001' + url + '\u0001' + checkedOn + '\u0001' + collector
                    + '\u0001' + pageRange + '\u0001' + note;
        }
    }

    public static Result parse(byte[] raw, Options opt, Codes codes) {
        CsvLimits.checkSize(raw.length);
        List<List<String>> recs = CsvLimits.PLAN.readAll(decodeStrict(raw));
        if (recs.size() < 2) {
            throw new InstitutionCsv.CsvFormatException("사업 행이 없습니다.");
        }
        Map<String, Integer> col = header(recs.get(0));
        int width = recs.get(0).size();
        Map<String, Doc> docs = new LinkedHashMap<>();
        List<Warning> warns = new ArrayList<>();
        int[] warnCount = {0};
        for (int i = 1; i < recs.size(); i++) {
            List<String> r = recs.get(i);
            if (r.size() != width) {
                throw CsvLimits.bad(i, "칸 수가 머리행과 다릅니다.");
            }
            Row c = new Row(r, col, i);
            Doc d = doc(c, opt, codes);
            Doc prev = docs.get(d.title);
            if (prev == null) {
                if (docs.size() >= MAX_DOCS) {
                    throw CsvLimits.bad(i, "문서는 한 파일에 20개까지입니다.");
                }
                docs.put(d.title, d);
                prev = d;
            } else if (!prev.signature().equals(d.signature())) {
                throw CsvLimits.bad(i, "같은 문서명의 문서 칸(원천종류·기간·출처·확인일 등)이 앞 행과 다릅니다.");
            }
            Item it = item(c, prev, codes, warns, warnCount);
            if (prev.byNo.put(it.no, it) != null) {
                throw CsvLimits.bad(i, "같은 문서 안에 사업번호가 겹칩니다.");
            }
            prev.items.add(it);
        }
        String latest = null;
        for (Doc d : docs.values()) {
            for (Item it : d.items) {
                if (it.parentNo == null) {
                    continue;
                }
                Item p = d.byNo.get(it.parentNo);
                if (p == null || p == it || p.parentNo != null) {
                    throw CsvLimits.bad(it.row, "상위사업번호가 같은 문서에 없거나 2단을 넘습니다.");
                }
            }
            if (latest == null || d.checkedOn.compareTo(latest) > 0) {
                latest = d.checkedOn;
            }
        }
        if (!opt.fileDate.equals(latest)) {
            throw new InstitutionCsv.CsvFormatException("파일 이름의 날짜가 문서 확인일 중 가장 늦은 날과 다릅니다.");
        }
        return new Result(new ArrayList<>(docs.values()), recs.size() - 1, warns, warnCount[0]);
    }

    static String decodeStrict(byte[] raw) {
        int off = raw.length >= 3 && (raw[0] & 0xFF) == 0xEF && (raw[1] & 0xFF) == 0xBB && (raw[2] & 0xFF) == 0xBF ? 3 : 0;
        try {
            return StandardCharsets.UTF_8.newDecoder()
                    .onMalformedInput(CodingErrorAction.REPORT).onUnmappableCharacter(CodingErrorAction.REPORT)
                    .decode(ByteBuffer.wrap(raw, off, raw.length - off)).toString();
        } catch (CharacterCodingException e) {
            throw new InstitutionCsv.CsvFormatException("UTF-8 로 저장된 CSV 만 받습니다(엑셀: 'CSV UTF-8' 형식으로 저장).");
        }
    }

    private static Map<String, Integer> header(List<String> h) {
        Map<String, Integer> col = new HashMap<>();
        for (int i = 0; i < h.size(); i++) {
            String name = text(h.get(i), 0, 20, false, false);
            if (!HEADERS.contains(name)) {
                throw new InstitutionCsv.CsvFormatException("header: " + (i + 1) + "번째 열 이름을 알 수 없습니다.");
            }
            if (col.put(name, i) != null) {
                throw new InstitutionCsv.CsvFormatException("header: " + (i + 1) + "번째 열 이름이 겹칩니다.");
            }
        }
        for (String req : HEADERS) {   // 순서 고정 — 열 이름은 서버 고정값이라 사유에 실어도 된다
            if (REQUIRED.contains(req) && !col.containsKey(req)) {
                throw new InstitutionCsv.CsvFormatException("header: 필수 열이 없습니다(" + req + ").");
            }
        }
        return col;
    }

    private static Doc doc(Row c, Options opt, Codes codes) {
        int row = c.row;
        Doc d = new Doc();
        if (!text(c.get(H_INST), row, 64, false, true).equals(opt.institutionId)) {
            throw CsvLimits.bad(row, "기관ID가 반입 대상 기관과 다릅니다.");
        }
        d.title = required(text(c.get(H_TITLE), row, 200, false, true), row, "문서명");
        d.srcKind = code(codes, "PLAN_SRC_KIND", c.get(H_KIND), row, "원천종류", true);
        d.from = year(c.get(H_FROM), row);
        d.to = year(c.get(H_TO), row);
        if (d.from > d.to || d.to - d.from > 10) {
            throw CsvLimits.bad(row, "대상기간이 올바르지 않습니다(시작 ≤ 끝, 10년 이내).");
        }
        String url = text(c.get(H_URL), row, SafeUrl.MAX, false, false);
        if (url.isEmpty()) {
            if (!opt.seed) {
                throw CsvLimits.bad(row, "출처URL이 비어 있습니다(반입 파일은 필수).");
            }
            d.urlMissing = true;
        } else if (!SafeUrl.isHttp(url)) {
            throw CsvLimits.bad(row, "출처URL은 http 또는 https 주소(500자 이내, 계정정보 없음)여야 합니다.");
        } else {
            d.url = url;
        }
        d.checkedOn = date(c.get(H_CHECKED), row, opt.today);
        String who = text(c.get(H_COLLECTOR), row, 7, false, true);
        if (who.isEmpty()) {
            if (!opt.seed) {
                throw CsvLimits.bad(row, "수집자(사번 7자리)가 비어 있습니다.");
            }
        } else if (!MenuPerms.isEmpNo(who)) {
            throw CsvLimits.bad(row, "수집자는 사번 7자리여야 합니다.");
        } else {
            d.collector = who;
        }
        d.pageRange = pattern(c.get(H_DOC_PAGES), PAGE, row, "문서쪽범위");
        d.note = blankToNull(text(c.get(H_DOC_NOTE), row, 500, true, true));
        return d;
    }

    private static Item item(Row c, Doc d, Codes codes, List<Warning> warns, int[] warnCount) {
        int row = c.row;
        Item it = new Item();
        it.row = row;
        it.fieldNo = pattern(c.get(H_FIELD_NO), FIELD_NO, row, "분야번호");
        it.fieldName = blankToNull(text(c.get(H_FIELD), row, 100, false, true));
        it.no = pattern(c.get(H_NO), ITEM_NO, row, "사업번호");
        if (it.no == null) {
            throw CsvLimits.bad(row, "사업번호 칸이 비어 있습니다.");
        }
        it.parentNo = pattern(c.get(H_PARENT), ITEM_NO, row, "상위사업번호");
        it.name = required(text(c.get(H_NAME), row, 300, false, true), row, "사업명");
        it.content = blankToNull(text(c.get(H_CONTENT), row, 1000, true, true));
        it.note = blankToNull(text(c.get(H_NOTE), row, 500, true, true));
        it.budgetState = code(codes, "PLAN_BUDGET_STATE", c.get(H_BSTATE), row, "예산상태", true);
        String amount = text(c.get(H_AMOUNT), row, 25, false, false);
        String unit = text(c.get(H_UNIT), row, 20, false, false);
        String years = text(c.get(H_YEARS), row, 300, false, false);
        if (AMOUNT.equals(it.budgetState)) {
            if (!AMOUNT_RE.matcher(amount).matches()) {
                throw CsvLimits.bad(row, "예산금액은 원문 숫자(쉼표 허용, 소수 3자리까지)여야 합니다.");
            }
            it.amount = new BigDecimal(amount.replace(",", ""));
            if (it.amount.signum() <= 0) {
                throw CsvLimits.bad(row, "예산금액은 0보다 커야 합니다. 원문의 '-'·빈칸은 예산상태로 적으세요.");
            }
            it.budgetUnit = code(codes, "PLAN_BUDGET_UNIT", unit, row, "예산단위", true);
            if (!years.isEmpty()) {
                if (!YEARS.matcher(years).matches()) {
                    throw CsvLimits.bad(row, "연차예산 형식이 올바르지 않습니다(예: 2024:600;2025:600;장기:200).");
                }
                it.budgetYears = years;
                if (yearSumDiffers(years, it.amount)) {
                    warnCount[0]++;
                    if (warns.size() < MAX_WARNINGS) {
                        warns.add(new Warning(row, "YEAR_SUM_MISMATCH"));
                    }
                }
            }
        } else if (!amount.isEmpty() || !unit.isEmpty() || !years.isEmpty()) {
            throw CsvLimits.bad(row, "예산상태가 '금액'이 아니면 예산금액·예산단위·연차예산을 비워 두세요.");
        }
        it.page = pattern(c.get(H_PAGE), PAGE, row, "원문쪽");
        String chk = code(codes, "PLAN_CHECK", c.get(H_CHECK), row, "확인상태", false);
        it.check = chk == null ? "NOT_CHECKED" : chk;
        String prog = text(c.get(H_PROGRESS), row, 20, false, false);
        String rate = text(c.get(H_RATE), row, 5, false, false);
        if (!prog.isEmpty() || !rate.isEmpty()) {
            if (!"PLEDGE".equals(d.srcKind)) {
                throw CsvLimits.bad(row, "진행상태·이행률은 원천종류가 공약이행일 때만 적습니다.");
            }
            it.progress = code(codes, "PLAN_PROGRESS", prog, row, "진행상태", false);
            if (!rate.isEmpty()) {
                if (!RATE.matcher(rate).matches() || new BigDecimal(rate).compareTo(HUNDRED) > 0) {
                    throw CsvLimits.bad(row, "이행률은 0~100(소수 1자리)이어야 합니다.");
                }
                it.rate = new BigDecimal(rate);
            }
        }
        return it;
    }

    /** 4자리 연도 칸의 합이 계와 다르면 true(장기는 계에 들지 않는다 — 원문 '계 2022~2026 / 장기' 관례). 경고만, 반입은 받는다. */
    static boolean yearSumDiffers(String years, BigDecimal total) {
        BigDecimal sum = BigDecimal.ZERO;
        boolean any = false;
        for (String part : years.split(";")) {
            int k = part.indexOf(':');
            if (k == 4) {
                sum = sum.add(new BigDecimal(part.substring(k + 1).replace(",", "")));
                any = true;
            }
        }
        return any && sum.compareTo(total) != 0;
    }

    /** 제어(C0·C1·DEL)·서식(U+200B·U+202E·U+FEFF 등)·줄/문단 구분 문자 거부, 앞뒤 공백 자름, 길이, 수식 시작 문자 거부. */
    static String text(String raw, int row, int max, boolean multiline, boolean formula) {
        String v = raw == null ? "" : raw.replace("\r\n", "\n");
        for (int i = 0; i < v.length(); i++) {
            char ch = v.charAt(i);
            if (ch == '\n' && multiline) {
                continue;
            }
            int t = Character.getType(ch);
            if (ch < 0x20 || ch == 0x7f || (ch >= 0x80 && ch <= 0x9f) || t == Character.FORMAT
                    || t == Character.LINE_SEPARATOR || t == Character.PARAGRAPH_SEPARATOR) {
                throw CsvLimits.bad(row, "허용되지 않는 글자(제어·서식 문자)가 있습니다.");
            }
        }
        v = v.trim();
        if (v.length() > max) {
            throw CsvLimits.bad(row, "칸이 너무 깁니다(" + max + "자 이하).");
        }
        if (formula && !v.isEmpty() && "=+-@".indexOf(v.charAt(0)) >= 0) {
            throw CsvLimits.bad(row, "칸이 = + - @ 로 시작합니다(수식으로 열릴 수 있어 받지 않습니다).");
        }
        return v;
    }

    private static String pattern(String raw, Pattern p, int row, String label) {
        String v = text(raw, row, 60, false, false);
        if (v.isEmpty()) {
            return null;
        }
        if (!p.matcher(v).matches()) {
            throw CsvLimits.bad(row, label + " 형식이 올바르지 않습니다.");
        }
        return v;
    }

    private static String code(Codes codes, String group, String raw, int row, String label, boolean required) {
        String v = text(raw, row, 100, false, false);
        if (v.isEmpty()) {
            if (required) {
                throw CsvLimits.bad(row, label + " 칸이 비어 있습니다.");
            }
            return null;
        }
        String c = codes.resolve(group, v);
        if (c == null) {
            throw CsvLimits.bad(row, label + " 값이 허용값이 아닙니다.");
        }
        return c;
    }

    private static int year(String raw, int row) {
        String v = text(raw, row, 4, false, false);
        if (!v.matches("\\d{4}")) {
            throw CsvLimits.bad(row, "대상기간은 4자리 연도(2000~2100)여야 합니다.");
        }
        int y = Integer.parseInt(v);
        if (y < 2000 || y > 2100) {
            throw CsvLimits.bad(row, "대상기간은 4자리 연도(2000~2100)여야 합니다.");
        }
        return y;
    }

    private static String date(String raw, int row, LocalDate today) {
        String v = text(raw, row, 10, false, false);
        try {
            if (DATE.matcher(v).matches()) {
                LocalDate d = LocalDate.parse(v);
                if (!d.isBefore(LocalDate.of(2000, 1, 1)) && !d.isAfter(today)) {
                    return v;
                }
            }
        } catch (DateTimeException ignored) {
            // 아래 고정 문구로
        }
        throw CsvLimits.bad(row, "확인일은 오늘 이전의 YYYY-MM-DD 여야 합니다.");
    }

    private static String required(String v, int row, String label) {
        if (v.isEmpty()) {
            throw CsvLimits.bad(row, label + " 칸이 비어 있습니다.");
        }
        return v;
    }

    private static String blankToNull(String v) {
        return v == null || v.isEmpty() ? null : v;
    }

    private static final class Row {
        final List<String> cells;
        final Map<String, Integer> col;
        final int row;

        Row(List<String> cells, Map<String, Integer> col, int row) {
            this.cells = cells;
            this.col = col;
            this.row = row;
        }

        String get(String h) {
            Integer i = col.get(h);
            return i == null ? "" : cells.get(i);
        }
    }
}
```

```java
    private Map<String, Object> apply(String instId, byte[] raw, String sha, String fileDate, String origin, String batch,
                                      Actor actor, BoardUiIds.Ui ui, String action) {
        final PlanCsv.Result r;
        try {
            r = PlanCsv.parse(raw, new PlanCsv.Options(instId, fileDate, ORIGIN_SEED.equals(origin), today()), codes().resolver);
        } catch (InstitutionCsv.CsvFormatException e) {
            throw ApiException.badRequest(e.getMessage());
        }
        return tx.execute(status -> {
            if (mapper.lockInstitution(instId) == null) throw ApiException.notFound("institution not found");
            InstPlanImport last = mapper.selectLatestImport(instId);
            if (last != null && sha.equals(last.getFileSha256())) {
                throw new ApiException(409, "이미 반입된 파일과 같습니다. 새 판을 만들지 않았습니다.");
            }
            InstPlanImport imp = new InstPlanImport();
            imp.setInstitutionId(instId);
            imp.setOriginCd(origin);
            imp.setFileDate(fileDate);
            imp.setFileSha256(sha);
            imp.setFileBytes((long) raw.length);
            imp.setItemCount(r.rows);
            imp.setDocCount(r.docs.size());
            imp.setWarnCount(r.warnCount);
            imp.setBatchId(batch);
            imp.setImportedBy(actor.getEmpNo());
            imp.setImportedAt(Times.nowIso());
            imp.setImportedVerified(actor.isVerified() ? 1 : 0);
            mapper.insertImport(imp);
            int seq = 0;
            for (PlanCsv.Doc d : r.docs) {
                InstPlanDoc doc = new InstPlanDoc();
                doc.setImportId(imp.getImportId());
                doc.setInstitutionId(instId);
                doc.setDocSeq(++seq);
                doc.setTitle(d.title);
                doc.setSrcKindCd(d.srcKind);
                doc.setPeriodFrom(d.from);
                doc.setPeriodTo(d.to);
                doc.setSrcUrl(d.url);
                doc.setUrlMissing(d.urlMissing ? 1 : 0);
                doc.setCheckedOn(d.checkedOn);
                doc.setCollectedBy(d.collector);
                doc.setPageRange(d.pageRange);
                doc.setNote(d.note);
                mapper.insertDoc(doc);
                for (PlanCsv.Item it : d.items) {
                    mapper.insertItem(itemRow(doc, it));
                }
            }
            // 성공 감사는 같은 트랜잭션 — 감사 없이 판이 생기지 않는다(기록 실패면 전체 롤백·500)
            mapper.insertAct(instId, imp.getImportId(), action, "OK", r.rows, sha, actor.getEmpNo(),
                    actor.isVerified() ? 1 : 0, ui.getScreen(), ui.getButton(), 1, Times.nowIso());
            Map<String, Object> out = new LinkedHashMap<>();
            out.put("import_id", imp.getImportId());
            out.put("institution_id", instId);
            out.put("origin_cd", origin);
            out.put("doc_count", r.docs.size());
            out.put("item_count", r.rows);
            out.put("file_sha256", sha);
            out.put("warning_count", r.warnCount);
            List<Map<String, Object>> ws = new ArrayList<>();

                Map<String, Object> m = new LinkedHashMap<>();
                m.put("row", w.row);
                m.put("code", w.code);
                ws.add(m);
            }
            out.put("warnings", ws);
            return out;
        });
    }

                if (one(d.getUrlMissing())) noUrl++;

            m.put("doc_count", docs.size());
            m.put("item_count", imp.getItemCount());
            m.put("oldest_checked_on", oldest);
            m.put("stale", stale > 0);
            m.put("stale_doc_count", stale);
            m.put("period_ended", !docs.isEmpty() && ended == docs.size());

            m.put("url_missing_doc_count", noUrl);
            m.put("origin_cd", imp.getOriginCd());

    private Map<String, Object> docJson(InstPlanDoc d, List<InstPlanItem> items, LocalDate today, Map<String, String> kindNames) {
        Map<String, List<InstPlanItem>> children = new HashMap<>();
        for (InstPlanItem it : items) {
            if (it.getParentNo() != null) children.computeIfAbsent(it.getParentNo(), k -> new ArrayList<>()).add(it);
        }
        int confirmed = 0, partial = 0, unconfirmed = 0, notChecked = 0;
        Set<String> units = new HashSet<>();
        List<Map<String, Object>> rows = new ArrayList<>();
        for (InstPlanItem it : items) {
            String c = it.getCheckCd();
            if ("CONFIRMED".equals(c)) confirmed++;
            else if ("PARTIAL".equals(c)) partial++;
            else if ("UNCONFIRMED".equals(c)) unconfirmed++;
            else notChecked++;
            if (PlanCsv.AMOUNT.equals(it.getBudgetStateCd())) units.add(it.getBudgetUnitCd());
            rows.add(itemJson(it, children.get(it.getItemNo())));
        }
        Map<String, Object> m = new LinkedHashMap<>();
        m.put("doc_id", d.getDocId());
        m.put("title", d.getTitle());
        m.put("src_kind_cd", d.getSrcKindCd());
        m.put("src_kind_name", kindNames.get(d.getSrcKindCd()));
        m.put("period_from", d.getPeriodFrom());
        m.put("period_to", d.getPeriodTo());
        m.put("period_ended", periodEnded(d, today));
        m.put("src_url", d.getSrcUrl());
        m.put("url_missing", one(d.getUrlMissing()));
        m.put("checked_on", d.getCheckedOn());
        m.put("stale", isStale(d.getCheckedOn(), today));
        m.put("page_range", d.getPageRange());
        m.put("note", d.getNote());
        Map<String, Object> cc = new LinkedHashMap<>();
        cc.put("confirmed", confirmed);
        cc.put("partial", partial);
        cc.put("unconfirmed", unconfirmed);
        cc.put("not_checked", notChecked);
        m.put("check_counts", cc);
        m.put("budget_unit_cd", units.size() == 1 ? units.iterator().next() : null);   // 문서 안 금액 단위가 하나면 열 머리 표기용
        m.put("items", rows);
        return m;
    }

    private static Map<String, Object> itemJson(InstPlanItem it, List<InstPlanItem> kids) {
        Map<String, Object> m = new LinkedHashMap<>();
        m.put("item_id", it.getItemId());
        m.put("row_no", it.getRowNo());
        m.put("field_no", it.getFieldNo());
        m.put("field_name", it.getFieldName());
        m.put("item_no", it.getItemNo());
        m.put("parent_no", it.getParentNo());
        m.put("name", it.getItemName());
        m.put("content", it.getContent());
        Map<String, Object> b = new LinkedHashMap<>();
        b.put("state_cd", it.getBudgetStateCd());
        b.put("amount", plain(it.getBudgetAmount()));
        b.put("unit_cd", it.getBudgetUnitCd());
        b.put("years", it.getBudgetYears());
        m.put("budget", b);
        m.put("calculated", calculated(it, kids));
        m.put("page", it.getPageNo());
        m.put("check_cd", it.getCheckCd());
        m.put("progress_cd", it.getProgressCd());   // DROPPED = 행 배지 '폐기'(공약이행 문서만)
        m.put("exec_rate", plain(it.getExecRate()));
        m.put("note", it.getNote());
        return m;
    }

    /**
     * 하위사업 합 계산값(팀 결정 2026-11-16): 상위사업 자신의 예산이 '금액'이 아니고 하위가 있을 때만 낸다.
     * 하위가 전부 금액이고 단위가 하나면 AMOUNT·합계, 하나라도 금액이 아니거나 단위가 섞이면 UNVERIFIED. 저장하지 않는다.
     */
    static Map<String, Object> calculated(InstPlanItem parent, List<InstPlanItem> kids) {
        if (kids == null || kids.isEmpty() || PlanCsv.AMOUNT.equals(parent.getBudgetStateCd())) return null;
        String unit = null;
        BigDecimal sum = BigDecimal.ZERO;
        boolean ok = true;
        for (InstPlanItem k : kids) {
            if (!PlanCsv.AMOUNT.equals(k.getBudgetStateCd()) || k.getBudgetAmount() == null || k.getBudgetUnitCd() == null
                    || (unit != null && !unit.equals(k.getBudgetUnitCd()))) {
                ok = false;
                break;
            }
            unit = k.getBudgetUnitCd();
            sum = sum.add(k.getBudgetAmount());
        }
        Map<String, Object> c = new LinkedHashMap<>();
        c.put("is_calculated", true);
        c.put("state_cd", ok ? PlanCsv.AMOUNT : "UNVERIFIED");
        c.put("amount", ok ? plain(sum) : null);
        c.put("unit_cd", ok ? unit : null);
        c.put("child_count", kids.size());
        return c;
    }

    @Transactional(readOnly = true)
    public CsvOut missingCsv(List<String> raw) {
        if (raw == null || raw.isEmpty() || raw.size() > MISSING_MAX_IDS) {
            throw ApiException.badRequest("기관 목록은 1~1,000개여야 합니다.");
        }
        LinkedHashSet<String> ids = new LinkedHashSet<>();
        for (String s : raw) {
            if (!PlanCsv.validId(s)) throw ApiException.badRequest("기관 목록에 형식이 맞지 않는 값이 있습니다.");
            ids.add(s);
        }
        Set<String> have = new HashSet<>();
        for (InstPlanImport i : mapper.selectLatestImports()) have.add(i.getInstitutionId());
        Map<String, Map<String, Object>> byId = new HashMap<>();
        for (Map<String, Object> row : mapper.selectInstitutionsIn(new ArrayList<>(ids))) {
            byId.put(str(row.get("INSTITUTION_ID")), row);
        }
        StringBuilder sb = new StringBuilder("﻿");
        line(sb, "기관ID", "기관명", "지역코드", "기관구분", "올릴 파일 이름");
        int n = 0;
        for (String id : ids) {
            Map<String, Object> row = byId.get(id);
            if (have.contains(id) || row == null) continue;   // 자료가 있거나 없는 기관 id 는 건너뛴다(사유를 싣지 않는다)
            line(sb, id, str(row.get("NAME_KO")), str(row.get("REGION_CODE")), str(row.get("INST_TYPE")), id + "_YYYYMMDD_plan.csv");
            n++;
        }
        return new CsvOut(sb.toString().getBytes(StandardCharsets.UTF_8), n);
    }

    /** admin.csvCell(admin.js:232)과 같은 규칙 — = + - @ TAB CR 로 시작하면 ' 를 붙이고 따옴표로 감싼다(보안 조건 6ⓑ). */
    static String csvCell(String v) {
        String t = v == null ? "" : v;
        if (!t.isEmpty() && "=+-@\t\r".indexOf(t.charAt(0)) >= 0) t = "'" + t;
        return "\"" + t.replace("\"", "\"\"") + "\"";
    }

    private static void line(StringBuilder sb, String... cells) {
        for (int i = 0; i < cells.length; i++) {
            if (i > 0) sb.append(',');
            sb.append(csvCell(cells[i]));
        }
        sb.append("\r\n");
    }

    // ── 보조 ──
    static String fileDate(String instId, String original) {
        String name = original == null ? "" : original;
        int cut = Math.max(name.lastIndexOf('/'), name.lastIndexOf('\\'));
        if (cut >= 0) name = name.substring(cut + 1);
        Matcher m = PlanCsv.FILE_NAME.matcher(name);
        if (!m.matches()) throw ApiException.badRequest("파일 이름은 {기관ID}_{확인일YYYYMMDD}_plan.csv 형식이어야 합니다.");
        if (!m.group(1).equals(instId)) throw ApiException.badRequest("파일 이름의 기관ID가 반입 대상 기관과 다릅니다.");
        String d = m.group(2);
        String iso = d.substring(0, 4) + "-" + d.substring(4, 6) + "-" + d.substring(6);
        try {
            LocalDate.parse(iso);
        } catch (DateTimeException e) {
            throw ApiException.badRequest("파일 이름의 날짜가 올바르지 않습니다.");
        }
        return iso;
    }

    private static String batch(String raw) {
        if (raw == null || raw.trim().isEmpty()) return null;
        String v = raw.trim();
        if (!BATCH.matcher(v).matches()) throw ApiException.badRequest("배치 id 형식이 올바르지 않습니다.");

    private Resource seedResource(String instId) {
        Resource[] found;
        try {
            found = resources.getResources(seedLocation + instId + "_*_plan.csv");   // instId 는 [A-Za-z0-9-] 만 — 와일드카드가 끼어들 수 없다
        } catch (IOException e) {
            return null;
        }
        Resource best = null;
        String bestName = null;
        for (Resource r : found) {
            String n = r.getFilename();
            if (n == null || !n.startsWith(instId + "_") || !PlanCsv.FILE_NAME.matcher(n).matches()) continue;
            if (bestName == null || n.compareTo(bestName) > 0) {
                best = r;
                bestName = n;
            }
        }
        return best;
    }

    private static byte[] readCapped(Resource res) {
        try (InputStream in = res.getInputStream()) {
            ByteArrayOutputStream out = new ByteArrayOutputStream();
            byte[] buf = new byte[8192];
            long total = 0;
            int n;
            while ((n = in.read(buf)) > 0) {
                total += n;
                if (total > CsvLimits.MAX_FILE_BYTES) throw tooLarge();
                out.write(buf, 0, n);
            }
            return out.toByteArray();
        } catch (IOException e) {
            throw new IllegalStateException("plan seed unreadable");
        }
    }

    private CodeTable codes() {
        final Map<String, Map<String, String>> lookup = new HashMap<>();
        Map<String, Map<String, String>> names = new HashMap<>();
        for (Map<String, Object> row : mapper.selectPlanCodes()) {
            String g = str(row.get("CODE_GROUP")), c = str(row.get("CODE")), n = str(row.get("CODE_NAME"));
            Map<String, String> m = lookup.computeIfAbsent(g, k -> new HashMap<>());
            m.put(c, c);
            if (n != null) {
                m.putIfAbsent(n, c);
                names.computeIfAbsent(g, k -> new HashMap<>()).put(c, n);
            }
        }
        return new CodeTable((group, raw) -> {
            Map<String, String> m = lookup.get(group);
            return m == null || raw == null ? null : m.get(raw.trim());
        }, names);
```

### 5. 보안·위험·되돌리는 법
**security 조건 대응**:
1. 조회 GET 3종은 `guard.require(req,"map")`, 반입·시드는 `AdminGuard.require`만 쓴다.
2. 파일 5MB 이중 검사, 5,000행, 칸 1,000자, 64열, 미종결 따옴표 400, 파일 이름 정규식. 원래 파일 이름은 저장하지 않는다.
3. 엄격 UTF-8(폴백 없음), 제어·서식·줄구분 문자 거부.
4. URL은 `SafeUrl` 공용 검사를 쓴다.
5. 화면 몫이다(프런트로 이관).
6. ⓐ 글 칸이 `= + - @`로 시작하면 거부한다(경고가 아니라 거부). ⓑ 서버 CSV는 `csvCell`로 내보낸다.
7. INSERT만 한다. 판 행에 반입자·시각·SHA-256·행 수·batch_id를 남기고, 화면·버튼은 서버 고정값이다. 실패도 ACT에 남긴다.
8. URL 없음은 `ORIGIN_SEED`(서버 고정 위치 파일)일 때만 허용한다.
9. 한 트랜잭션 + 기관 행 잠금. 사업번호는 NO 정규식으로 검사하고, 사유에는 행 번호만 싣는다.

### 6. 25구 변환기 설계 (`kgi-ggreport-web/tools/db/convert-plan-txt.mjs`)
- **선례**: `gen-seed-institutions.mjs`를 따른다.
  - Node 22, 외부 패키지 없음, 순수 함수 export + `*.test.mjs`(`node --test`).
  - 시각·난수가 없어 같은 입력이면 같은 바이트를 낸다.
  - URL 검사는 그 파일의 `checkUrl`을 import해 서버와 같은 기준으로 쓴다.
- **입출력**:
  - 입력: `corpus/institutions/{id}/spec/*.txt`
  - 출력: `kgi-ggreport-web/src/main/resources/plan-seed/{id}_{YYYYMMDD}_plan.csv` (UTF-8 BOM, CRLF, `PlanCsv.HEADERS` 순서)
- **옵션**: `--district dobong|nowon|gwangjin`, `--checked-on YYYY-MM-DD`(필수, spec 07 조사일을 사람이 넣는다 — 추측 금지), `--check`(쓰지 않고 요약), `--strict`(경고가 있으면 실패), `--out-dir`.
- **문서 칸**: 01 개요 첫 줄을 문서명으로 쓴다. 대상기간은 `(YYYY-YYYY)`에서, 출처URL은 `출처: https?://…` 줄에서 `checkUrl`이 통과할 때만 가져온다(도봉 01:3에 있음). 원천종류는 '4개년계획' → FOUR_YEAR, '주요업무계획·구정운영계획' → WORK_PLAN.
- **분야·사업**:
  - 장 파일 첫 줄 `N장. 이름 (`에서 분야번호·분야명을 뽑는다. 광진처럼 장 번호가 없으면 파일 순서를 쓴다.
  - 사업: `^\d+\. ` 줄은 상위 사업, `^\s+\d+-\d+\. ` 줄은 하위 사업(상위사업번호 연결)이다.
  - `- 내용:` 줄과 그 밖의 `- 키: 값` 줄(위치·기간·사업기간·총사업비·성과)은 앞의 `- `를 떼고 "키: 값" 여러 줄로 내용에 넣는다. 수식 시작 문자를 피하기 위해서다.
  - 내용이 1,000자를 넘으면 자르지 않고 오류로 멈춘다(사람이 고친다).
- **예산 (단위 추측 금지)**:
  - 금액(AMOUNT)으로 넣는 경우: 그 줄에 단위가 붙어 있을 때(`13백만원`, `5,134억원`), 또는 장 머리에 `예산(백만원` 단위가 명시돼 있고 사업 줄이 `계 N (…)`일 때.
  - 범위(`1억원~4억원`)나 화살표(`2022:3,636→2026:5,645`)처럼 숫자 하나로 정할 수 없는 값은 UNVERIFIED로 두고, 비고에 `예산 원문: …`을 남긴다.
  - 원문이 `미표기`면 NOT_IN_SOURCE다.
  - 연차예산은 `YYYY:n` 쌍이 쉼표로 나열되고 화살표가 없을 때만 만든다. `-`인 해는 뺀다.
- **원문쪽**: 사업 줄·블록에 쪽 번호가 명시된 경우에만 넣는다. 장 단위 범위를 사업마다 복사하지 않는다(design A: 쪽이 없는 행은 '미확인'으로 보인다).
- **확인상태**: spec 07의 사업명과 정규화(공백·괄호 제거) 후 **완전 일치**할 때만 확인됨·부분확인·확인안됨을 넣는다. 나머지는 빈칸(=미조사)이다. 여러 사업을 한 줄에 묶은 행은 매칭하지 않는다.
- **검산**: 장별 상위 사업 수를 장 머리의 "(N개 사업"과, 전체를 `00_인덱스.txt` '전체 사업 개수 검증'과 대조한다(도봉 121은 5-1~5-4를 1건으로 센 값). 어긋나면 `--strict`에서 실패한다. 예산 합 대조는 원문에 장 합계가 있는 구만 한다.
- **수작업 목록 (planner 5절 그대로)**: 동대문(예산 없음), 동작(02 세대별 중복), 중구(과제 단계 → 분야명에 붙임), 강북·강남07(공약·폐기·이행률 → PLEDGE 문서), 영등포·구로·관악(중복 제거), 강서·양천·송파·은평·관악·영등포(억원·분야 배정액), 종로·구로·금천(합계 불가), 구로(spec 06 없음). 이 구들은 변환기가 문서 칸과 사업명·번호만 뽑아 초안을 만들고, 예산은 전부 UNVERIFIED로 두며, 데이터 담당이 손으로 확정한다.
- **시드 반입 경로**:
  1. 변환 → `--check` 요약 → data-auditor가 건수·단위·중복을 검수한다.

  - 같은 파일을 다시 부르면 409라 중복 판이 생기지 않는다.
  - 시드 SQL을 따로 만들지 않아 검증이 PlanCsv 한 곳에 모인다(planner 5절).

### 10. 열린 질문 (사용자가 답하면 진행되는 것)
1. **수집자 칸**: 반입 파일의 '수집자'를 회사 사번 7자리로만 받게 했다. 이름 같은 개인정보를 남기지 않으려는 것이다. 폐쇄망 밖 수집 담당이 사번이 없는 외부 인력이면 이 칸을 비워 두게 할지(선택 칸), 사번을 계속 요구할지 정해야 한다.
2. **판의 의미**: 기관별 파일 하나가 그 기관 자료 전체라고 보고, 새 파일을 올리면 이전 판 전체가 보관으로 내려가게 했다. planner는 "같은 문서의 새 판"(문서 단위 교체)으로 적었다. 문서 단위로 바꾸려면 문서 식별 규칙과 문서 폐기 방법이 더 필요하다. 사용자 확인이 필요하다(PM·planner 경유).
