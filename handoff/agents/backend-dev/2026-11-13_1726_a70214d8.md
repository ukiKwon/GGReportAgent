# 기관 전체 DB 이관(029) 설계 — backend-dev (읽기 전용·미실행)

## 0. 10줄 요약
1. 새 번호는 **029_seed_institutions_all.sql**(mysql·oracle 쌍). 028 뒤라 apply-mysql.mjs가 그대로 이어 적용한다(이미 028까지 적용한 DB는 `--status` → 대기 1개 → 실행). 021~023은 비어 있으니 건드리지 않는다.
2. 데이터는 손으로 옮기지 않고 **생성기** `kgi-ggreport-web/tools/db/gen-seed-institutions.mjs`가 두 js를 `node:vm`으로 실행해 읽고(지자체 파일은 루프·IIFE로 레코드를 만든다) SQL 두 벌을 쓴다. 시각·난수가 없어 같은 입력이면 바이트 단위로 같은 결과다.
3. **ID**: 서울 25구는 Oracle 003의 기존 id를 파싱해 그대로(mapo 등). 그 밖의 지자체는 `lg-<시도2자리>-<sha1(시도|이름) 앞 10hex>`. 지자체 외는 `org-<orgCode>` → `g2b-<g2bCode>` → `nm-<hash10>` 순이다. 같은 기관의 여러 블록(창원 5·안양 2)은 한 행이 된다.
4. **채우는 칸**: REGION_CODE(=region), TYPE(=type 그대로), CONTRACT_END(=contractEnd), LAST_BID(=lastBid), TERM(=term), STAGE=1. GIGANLIST_DIR는 서울 25구만 003이 채웠고 새 행은 NULL이다.
5. **DB에 칸이 없어 안 넣는 값**: subRegion·orgCode·g2bCode·parentOrgCode·followsCourt·bank·bidKind·courtKind·opStatus·openDate·**contractExpiry**. 지자체 외 172곳은 대부분 contractExpiry에 의존하므로 DB에는 LAST_BID+TERM만 들어간다. 칸 추가는 별도 제안(§6)이다.
6. **"없으면 넣고 있으면 빈 칸만 채움"**: Oracle은 MERGE(MATCHED 때 `COALESCE(t.X, s.X)`), MySQL은 INSERT…ON DUPLICATE KEY UPDATE `COALESCE(NULLIF(old,''), VALUES(X))`(TERM만 NULLIF 없음). NAME_KO와 STAGE는 기존 행에서 절대 안 건드린다.
7. 테스트(`mvn -o test`)는 `spring.sql.init.data-locations`가 파일을 **명시 나열**한다(`src/test/resources/application.properties:38`). 029는 거기 없으므로 골든 00·04·05와 InstitutionSeedTest(25건 단언)는 영향이 없다. 단 이 목록에 029를 넣으면 안 된다.
8. 추가 테스트: Java `InstitutionSeedAllPairTest`(두 SQL의 행 값 동일·ID 유일·서울 25 ID 불변·COMMIT 규칙), node `gen-seed-institutions.test.mjs`(ID·병합·이스케이프·결정성).
9. 위험 1순위는 **서울 25구 id 불변**이다. 생성기가 25개를 못 맞추면 오류로 멈춘다. 둘째는 "이미 로컬 DB에 `new-…` id로 이관된 같은 이름 행이 있으면 이름이 겹친다"이므로 적용 전 사전 점검 SELECT를 한다(§5).
10. 실행은 호출자가 한다. 나는 node를 못 돌려서 **생성 결과는 실제 생성물이 아니라 형식 예시**다. 해시 부분은 `<h10>`으로 표기했다. 적용 전 `--check`로 경고 목록을 꼭 본다.

## 2. 요구·근거 요약
- INSTITUTIONS 칸: INSTITUTION_ID(64)·NAME_KO(100)·REGION_CODE(20)·TYPE(50)·CONTRACT_END(30)·LAST_BID(30)·TERM(SMALLINT)·STAGE(기본 1)·GIGANLIST_DIR·RFP_PATH·PPTX_PATH (`db/mysql/001_schema.sql:25-38`). 키는 PK 하나뿐이고 NAME_KO에 유일 제약이 없다.
- 정본 규칙: Oracle이 정본, MySQL은 미러다(`db/*/003_seed_institutions.sql` 머리말). 003의 "있으면 빈 지역·구분만 채운다" 성질을 029가 이어받는다.
- 서울 DB 이름은 `마포구`, 데이터 이름은 `마포구청`이다(`institutions.js:504`는 `gu + '청'`). 그래서 서울은 이름 끝 `청`을 떼서 Oracle 003의 이름→id 표로 짝짓는다(서울 region '11' & 지자체 한정, 25개가 다 맞아야 통과).
- 지자체 블록은 같은 이름이 여러 레코드로 나온다(경남 `institutions.js:1914-1916`에서 창원시청 5번, 코드만 다르다). subRegion은 DB에 칸이 없고 NEXT 76도 "지도 키로만 쓰고 번호로는 못 쓴다"고 했으니 ID에 넣지 않는다.
- 지자체 레코드에는 orgCode가 없다(비지자체 파일만 `orgCode`, 일부 `g2bCode`). 그래서 지자체 ID는 해시다. NEXT 76이 정할 "행정표준 기관코드" 번호는 **별도 칸(ORG_CODE)** 으로 들어오는 것이 맞고, ID는 불투명한 키로 두는 편이 안전하다. 76이 ID를 바꾸라고 하면 기관장·이사회 참조가 깨진다.
- `contractEnd`는 "지금 뜬 공고만"(`institutions.js:15`), `contractExpiry`는 비지자체 전용(`institutions_nonmuni.js:3`)이다. 지도 색 기준은 지금 그대로다.

## 3. 구현안

### 3-1. ID·칸 매핑 규칙

| 항목 | 규칙 |
|---|---|
| 서울 25구 | 기존 id(`mapo` 등) 유지. name은 DB 쪽 이름(`마포구`)을 쓴다. 25개 미만이면 생성 실패. |
| 기타 지자체 | `lg-<region>-<sha1(NFC(region + '\|' + name)) 앞 10hex>`. 예: `lg-26-<h10>`. 같은 id의 블록은 합친다. |
| 지자체 외 | `org-<orgCode 7자리>` > `g2b-<g2bCode>` > `nm-<hash10(type\|region\|name)>`. |
| 충돌 | 같은 id에 이름이 다르면(= 같은 orgCode) 첫 이름으로 합치고 경고한다. 해시 충돌(다른 이름·같은 hash id)은 오류다. |
| REGION_CODE | region(2자리). 비면 NULL + 경고. |
| TYPE | 데이터 type 문자열 그대로(`지자체`·`교육청`·`법원`·`공공기관`·`지방공기업`·`대학`·`병원`). 접기는 `logic.kindOf`가 한다. |
| LAST_BID / CONTRACT_END | `YYYY-MM-DD` 형식만. 아니면 NULL + 경고. |
| TERM | 정수 1~30만. 아니면 NULL + 경고. |
| STAGE | 1(기본). 기존 행의 STAGE는 건드리지 않는다. |
| 블록 병합 | 필드별로 **먼저 나온 비어 있지 않은 값**을 쓰고, 다른 값이 오면 경고(`--strict`면 오류). |
| 안전 검사 | name 100자 초과·제어문자·`--`·`/*` 포함은 오류다(DdlRulesTest 주석 제거가 `--`를 지우므로). 이름이 겹치면 경고(`--strict`면 오류). |

**이름 겹침이 왜 문제인가**: `/inbox` 반입이 `NAME_KO`로 기관을 찾는다(`InstitutionMapper.selectIdByName`, NEXT 72 S2). 같은 이름이 두 행이면 엉뚱한 행을 갱신한다.

### 3-2. 생성기 전문 — 새 파일 `kgi-ggreport-web/tools/db/gen-seed-institutions.mjs`

```js
const CODE_RE = /^[A-Za-z0-9_-]{1,40}$/;
const CHUNK_MYSQL = 100;
const CHUNK_ORACLE = 50;

// ---------- 순수 함수 (단위 시험 대상) ----------

export const sha10 = (s) => createHash('sha1').update(String(s).normalize('NFC'), 'utf8').digest('hex').slice(0, 10);
export const sha256n = (text) => createHash('sha256').update(String(text).replace(/\r\n/g, '\n'), 'utf8').digest('hex');

/** 데이터 파일(window.xxx = [...] 형태, 루프·IIFE 포함)을 샌드박스에서 실행해 레코드 배열을 얻는다. */
export function loadRecords(code, key, filename = 'data.js') {
  const win = {};
  const ctx = vm.createContext({ window: win });
  vm.runInContext(code, ctx, { filename, timeout: 5000 });
  const arr = win[key];
  if (!Array.isArray(arr)) throw new Error(`${filename}: window.${key} 배열이 없습니다`);
  return JSON.parse(JSON.stringify(arr)); // 샌드박스 객체 → 평범한 객체
}

/** Oracle 003 정본에서 '이름 → id' (서울 25구). */
export function parseSeoulIds(oracle003Text) {
  const m = new Map();
  const re = /SELECT\s+'([a-z]+)'(?:\s+AS\s+INSTITUTION_ID)?\s*,\s*'([^']+)'/g;
  let r;
  while ((r = re.exec(oracle003Text))) m.set(r[2], r[1]);
  if (m.size !== SEOUL_COUNT) throw new Error(`Oracle 003 에서 서울 ${SEOUL_COUNT}구 id 를 읽지 못했습니다(${m.size}개)`);
  return m;
}

const blank = (v) => v === undefined || v === null || String(v).trim() === '';

/** 레코드 하나의 기관 id. kind: 'muni' | 'nonmuni' */
export function makeId(rec, kind, seoul) {
  const name = String(rec.name).normalize('NFC').trim();
  const region = blank(rec.region) ? '' : String(rec.region).trim();
  if (kind === 'muni') {
    if (region === '11' && name.endsWith('청') && seoul.has(name.slice(0, -1))) return seoul.get(name.slice(0, -1));
    return `lg-${region || 'xx'}-${sha10(`${region}|${name}`)}`;
  }
  if (!blank(rec.orgCode)) {
    const c = String(rec.orgCode).trim();
    if (!CODE_RE.test(c)) throw new Error(`orgCode 형식 오류: ${name}`);
    return `org-${c}`;
  }
  if (!blank(rec.g2bCode)) {
    const c = String(rec.g2bCode).trim();
    if (!CODE_RE.test(c)) throw new Error(`g2bCode 형식 오류: ${name}`);
    return `g2b-${c}`;
  }
  return `nm-${sha10(`${rec.type || ''}|${region}|${name}`)}`;
}

/**
 * 두 레코드 목록 → { rows, warnings }. rows 는 id 순 정렬(결정적).
 * 같은 id 의 레코드는 한 행으로 합친다(필드별로 먼저 나온 값).
 */
export function buildRows(muni, nonmuni, seoul) {
  const warnings = [];
  const byId = new Map();
  const add = (rec, kind) => {
    if (blank(rec.name)) throw new Error('이름이 없는 레코드가 있습니다');
    const id = makeId(rec, kind, seoul);
    const name = (kind === 'muni' && seoul.has(id) ? null : null) || String(rec.name).normalize('NFC').trim();
    const cur = byId.get(id);
    const val = {
      name,
      region: blank(rec.region) ? null : String(rec.region).trim(),
      type: blank(rec.type) ? null : String(rec.type).trim(),
      contractEnd: blank(rec.contractEnd) ? null : String(rec.contractEnd).trim(),
      lastBid: blank(rec.lastBid) ? null : String(rec.lastBid).trim(),
      term: blank(rec.term) ? null : rec.term,
    };
    if (!cur) { byId.set(id, { id, seoulName: null, ...val }); return; }
    for (const k of ['name', 'region', 'type', 'contractEnd', 'lastBid', 'term']) {
      if (cur[k] === null) cur[k] = val[k];
      else if (val[k] !== null && String(val[k]) !== String(cur[k])) {
        if (k === 'name' && id.startsWith('lg-')) throw new Error(`해시 id 충돌: ${id} (${cur.name} / ${val.name})`);
        warnings.push(`${id} ${k}: '${cur[k]}' ≠ '${val[k]}' — 먼저 나온 값 사용`);
      }
    }
  };
  muni.forEach((r) => add(r, 'muni'));
  nonmuni.forEach((r) => add(r, 'nonmuni'));

  // 서울 25구: DB 쪽 이름('마포구')을 쓴다. 25개가 모두 있어야 한다.
  const idToSeoulName = new Map([...seoul].map(([n, i]) => [i, n]));
  let seoulHit = 0;
  for (const row of byId.values()) {
    if (idToSeoulName.has(row.id)) { row.name = idToSeoulName.get(row.id); seoulHit++; }
  }
  if (seoulHit !== SEOUL_COUNT) throw new Error(`서울 ${SEOUL_COUNT}구 중 ${seoulHit}개만 데이터와 짝지어졌습니다 — id 불변 조건 위반`);

  const rows = [...byId.values()].sort((a, b) => (a.id < b.id ? -1 : a.id > b.id ? 1 : 0));
  const seenName = new Map();
  for (const r of rows) {
    if (r.name.length > 100) throw new Error(`NAME_KO 100자 초과: ${r.id}`);
    if (/[\u0000-\u001f]/.test(r.name) || r.name.includes('--') || r.name.includes('/*')) throw new Error(`이름에 쓸 수 없는 문자열이 있습니다: ${r.id}`);
    if (r.id.length > 64) throw new Error(`id 64자 초과: ${r.id}`);
    if (r.region !== null && !/^\d{2}$/.test(r.region)) { warnings.push(`${r.id} region 형식 불량 '${r.region}' → NULL`); r.region = null; }
    if (r.region === null) warnings.push(`${r.id} region 비어 있음`);
    for (const k of ['contractEnd', 'lastBid']) {
      if (r[k] !== null && !DATE_RE.test(r[k])) { warnings.push(`${r.id} ${k} 형식 불량 '${r[k]}' → NULL`); r[k] = null; }
    }
    if (r.term !== null) {
      const n = Number(r.term);
      if (Number.isInteger(n) && n >= 1 && n <= 30) r.term = n;
      else { warnings.push(`${r.id} term 불량 '${r.term}' → NULL`); r.term = null; }
    }
    if (seenName.has(r.name)) warnings.push(`이름 겹침: '${r.name}' — ${seenName.get(r.name)} / ${r.id} (반입이 이름 키라 구분 필요)`);
    else seenName.set(r.name, r.id);
    r.type = r.type === null ? null : r.type;
  }
  return { rows, warnings };
}

// ---------- SQL 출력 ----------

const qMy = (s) => (s === null ? 'NULL' : `'${String(s).replace(/\\/g, '\\\\').replace(/'/g, "''")}'`);
const qOr = (s, len) => (s === null
  ? `CAST(NULL AS VARCHAR2(${len}))`
  : `'${String(s).replace(/'/g, "''").replace(/&/g, "'||CHR(38)||'")}'`);

const header = (dialect, meta) => `-- ---------------------------------------------------------------------------
-- kgi-ggreport-web — ${dialect === 'oracle' ? 'Oracle 정본' : 'MySQL 8.0 미러'} (${meta.number}) : 기관 전체 시드(지자체 + 지자체 외)
--
-- ⚠️ 이 파일은 tools/db/gen-seed-institutions.mjs 가 만든다 — 손으로 고치지 않는다.
--    ${dialect === 'oracle' ? 'db/mysql 쪽이 미러다.' : '정본은 db/oracle 쪽이다. 값이 갈리면 정본을 따른다.'}
-- 원본(frontend/data) 해시: institutions.js ${meta.muniSha.slice(0, 12)} · institutions_nonmuni.js ${meta.nonSha.slice(0, 12)}
-- 행 ${meta.count}개(서울 25구 id 는 003 그대로, 나머지는 lg-/org-/g2b-/nm- 접두 id).
--
-- 규칙: 없으면 넣고, 있으면 **비어 있는** REGION_CODE·TYPE·CONTRACT_END·LAST_BID·TERM 만 채운다.
--       사람이 넣은 값·NAME_KO·STAGE 는 덮지 않는다. 여러 번 돌려도 같다(적용 도구는 한 번만 돌린다).
-- 넣지 않는 값: subRegion·orgCode·g2bCode·parentOrgCode·followsCourt·bank·bidKind·court*·contractExpiry (DB 칸 없음).
-- 데이터가 바뀌면 이 파일을 고치지 말고 새 번호로 다시 생성한다(--number).
-- ---------------------------------------------------------------------------
`;

export function renderMysql(rows, meta) {
  const out = [header('mysql', meta)];
  for (let i = 0; i < rows.length; i += CHUNK_MYSQL) {
    const vals = rows.slice(i, i + CHUNK_MYSQL).map((r) =>
      `    (${qMy(r.id)}, ${qMy(r.name)}, ${qMy(r.region)}, ${qMy(r.type)}, ${qMy(r.contractEnd)}, ${qMy(r.lastBid)}, ${r.term === null ? 'NULL' : r.term}, 1)`);
    out.push(`INSERT INTO INSTITUTIONS
    (INSTITUTION_ID, NAME_KO, REGION_CODE, TYPE, CONTRACT_END, LAST_BID, TERM, STAGE)
VALUES
${vals.join(',\n')}
ON DUPLICATE KEY UPDATE
    REGION_CODE  = COALESCE(NULLIF(INSTITUTIONS.REGION_CODE, ''),  VALUES(REGION_CODE)),
    TYPE         = COALESCE(NULLIF(INSTITUTIONS.TYPE, ''),         VALUES(TYPE)),
    CONTRACT_END = COALESCE(NULLIF(INSTITUTIONS.CONTRACT_END, ''), VALUES(CONTRACT_END)),
    LAST_BID     = COALESCE(NULLIF(INSTITUTIONS.LAST_BID, ''),     VALUES(LAST_BID)),
    TERM         = COALESCE(INSTITUTIONS.TERM, VALUES(TERM));
`);
  }
  return out.join('\n');
}

export function renderOracle(rows, meta) {
  const out = [header('oracle', meta)];
  for (let i = 0; i < rows.length; i += CHUNK_ORACLE) {
    const sel = rows.slice(i, i + CHUNK_ORACLE).map((r, j) => {
      const a = (n) => (j === 0 ? ` AS ${n}` : '');
      const term = r.term === null ? 'CAST(NULL AS NUMBER(5))' : String(r.term);
      return `    SELECT ${qOr(r.id, 64)}${a('INSTITUTION_ID')}, ${qOr(r.name, 100)}${a('NAME_KO')}, ${qOr(r.region, 20)}${a('REGION_CODE')}, ${qOr(r.type, 50)}${a('TYPE')}, ${qOr(r.contractEnd, 30)}${a('CONTRACT_END')}, ${qOr(r.lastBid, 30)}${a('LAST_BID')}, ${term}${a('TERM')} FROM DUAL`;
    });
    out.push(`MERGE INTO INSTITUTIONS t
USING (
${sel.join(' UNION ALL\n')}
) s
ON (t.INSTITUTION_ID = s.INSTITUTION_ID)
WHEN MATCHED THEN UPDATE SET
    t.REGION_CODE  = COALESCE(t.REGION_CODE,  s.REGION_CODE),
    t.TYPE         = COALESCE(t.TYPE,         s.TYPE),
    t.CONTRACT_END = COALESCE(t.CONTRACT_END, s.CONTRACT_END),
    t.LAST_BID     = COALESCE(t.LAST_BID,     s.LAST_BID),
    t.TERM         = COALESCE(t.TERM,         s.TERM)
WHEN NOT MATCHED THEN INSERT
    (INSTITUTION_ID, NAME_KO, REGION_CODE, TYPE, CONTRACT_END, LAST_BID, TERM, STAGE)
VALUES
    (s.INSTITUTION_ID, s.NAME_KO, s.REGION_CODE, s.TYPE, s.CONTRACT_END, s.LAST_BID, s.TERM, 1);
`);
  }
  out.push('COMMIT;\n');
  return out.join('\n');
}

export function parseArgs(argv) {
  const here = path.dirname(fileURLToPath(import.meta.url));
  const root = path.resolve(here, '../../..'); // 저장소 루트
  const o = { check: false, strict: false, help: false, number: '029', name: 'seed_institutions_all',

    outDir: path.resolve(here, '../../src/main/resources/db') };
  const val = (i, f) => { if (i + 1 >= argv.length || argv[i + 1].startsWith('--')) throw new Error(`${f} 뒤에 값이 필요합니다`); return argv[i + 1]; };
  for (let i = 0; i < argv.length; i++) {
    const a = argv[i];
    switch (a) {
      case '--help': case '-h': o.help = true; break;
      case '--check': o.check = true; break;
      case '--strict': o.strict = true; break;
      case '--number': o.number = val(i++, a); break;
      case '--name': o.name = val(i++, a); break;
      case '--muni': o.muni = path.resolve(val(i++, a)); break;
      case '--nonmuni': o.nonmuni = path.resolve(val(i++, a)); break;
      case '--oracle003': o.oracle003 = path.resolve(val(i++, a)); break;
      case '--out-dir': o.outDir = path.resolve(val(i++, a)); break;

  }
```

```java
public class InstitutionSeedAllPairTest {

    private static final Path DB = Paths.get("src/main/resources/db");
    private static final String FILE = "029_seed_institutions_all.sql";
    /** 한 값: 'text' | NULL | CAST(NULL AS ...) | 숫자 */
    private static final Pattern TOKEN = Pattern.compile(
            "'(?:[^']|'')*'|CAST\\(NULL AS [A-Z0-9]+(?:\\(\\d+\\))?\\)|NULL|\\d+");

    private static String read(String dialect, String file) throws IOException {
        Path f = DB.resolve(dialect).resolve(file);
        assertTrue(f + " 가 없다 — 작업 디렉터리가 kgi-ggreport-web/ 인지 확인", Files.exists(f));
        return new String(Files.readAllBytes(f), StandardCharsets.UTF_8).replace("\r\n", "\n");
    }

    /** 값 8개짜리 행(INSTITUTION_ID..TERM[, STAGE]) 목록을 '|' 로 이은 문자열로. */
    private static List<String> mysqlRows() throws IOException {
        List<String> out = new ArrayList<>();
        for (String line : read("mysql", FILE).split("\n")) {
            if (!line.startsWith("    ('")) continue;
            out.add(normalize(line));
        }
        return out;
    }

    private static List<String> oracleRows() throws IOException {
        List<String> out = new ArrayList<>();
        for (String line : read("oracle", FILE).split("\n")) {
            if (!line.startsWith("    SELECT ")) continue;
            // 행 끝의 ' FROM DUAL' 앞까지, TERM 뒤에 STAGE 1 을 붙여 MySQL 행과 맞춘다.
            String body = line.substring("    SELECT ".length(), line.indexOf(" FROM DUAL"))
                    .replaceAll(" AS [A-Z_]+", "").replace("'||CHR(38)||'", "&");
            out.add(normalize(body) + "|1");
        }
        return out;
    }

    private static String normalize(String s) {
        s = s.replace("'||CHR(38)||'", "&");
        Matcher m = TOKEN.matcher(s);
        List<String> t = new ArrayList<>();
        while (m.find()) {
            String v = m.group();
            if (v.startsWith("'")) v = v.substring(1, v.length() - 1).replace("''", "'").replace("\\\\", "\\");
            else if (v.startsWith("CAST(NULL") || v.equals("NULL")) v = "∅";
            t.add(v);
        }
        return String.join("|", t);
    }

    @Test
    public void 두_파일의_행이_순서까지_같다() throws IOException {
        List<String> my = mysqlRows();
        List<String> or = oracleRows();
        assertTrue("행이 있어야 한다", my.size() >= 400);
        // MySQL 행은 STAGE(1)까지 이미 포함, Oracle 행은 normalize 뒤 |1 을 붙였다.
        assertEquals(my, or);

            assertTrue("id 길이: " + id, id.length() <= 64);
            assertTrue("id 중복: " + id, ids.add(id));
        }
    }

        Set<String> seoul = new HashSet<>();

        assertEquals(25, seoul.size());

        }

    }

    @Test
    public void 덮어쓰지_않는_규칙이_두_파일에_있다() throws IOException {
        String my = read("mysql", FILE);
        String or = read("oracle", FILE);
        assertTrue(my.contains("COALESCE(NULLIF(INSTITUTIONS.LAST_BID, ''),"));
        assertFalse("NAME_KO·STAGE 갱신 금지", my.contains("NAME_KO    ") && my.contains("NAME_KO = VALUES"));
        assertTrue(or.contains("t.LAST_BID     = COALESCE(t.LAST_BID,"));
```

## 5. 적용 절차(사용자가 apply-mysql.mjs 실행 — 비밀번호 입력)
1. 로컬 MySQL(3306)이 떠 있는지 확인한다(`netstat -ano | findstr :3306`, 꺼져 있으면 `C:devmysql-start.cmd`).
2. **사전 점검(읽기 전용)**, mysql 클라이언트로 한 번:
   ```sql
   SELECT INSTITUTION_ID, NAME_KO FROM INSTITUTIONS WHERE INSTITUTION_ID NOT IN
     ('dobong','dongdaemun','dongjak','eunpyeong','gangbuk','gangdong','gangnam','gangseo','geumcheon','guro','gwanak','gwangjin','jongno','jung','jungnang','mapo','nowon','seocho','seodaemun','seongbuk','seongdong','songpa','yangcheon','yeongdeungpo','yongsan');
   ```
   25구 밖 행이 이미 있으면(`new-…` id 등) 그 이름이 029의 이름과 겹치는지 본다. 겹치면 029를 적용하기 전에 정리 방법을 정한다(이름 겹침을 두 행으로 만들지 않기 위해).
3. `node kgi-ggreport-web\tools\db\apply-mysql.mjs --status` → 029만 대기인지 확인. `--dry-run` → 목록 확인.
4. `node kgi-ggreport-web\tools\db\apply-mysql.mjs` (비밀번호는 한 번 묻는다, 화면에 안 보인다).
5. 확인 쿼리:
   ```sql
   SELECT TYPE, COUNT(*) FROM INSTITUTIONS GROUP BY TYPE;
   SELECT NAME_KO, COUNT(*) FROM INSTITUTIONS GROUP BY NAME_KO HAVING COUNT(*) > 1;   -- 0행이어야 한다
   SELECT COUNT(*) FROM INSTITUTIONS;                                                 -- 생성기가 찍은 행 수와 같아야 한다
   ```

6. 중간에 실패하면 apply-mysql은 기록하지 않고 멈춘다. 029는 멱등이라 원인을 고친 뒤 같은 명령을 다시 실행하면 된다(README §5-3의 "DDL은 롤백 안 됨" 경고는 시드라 해당이 적다).
7. 새 PC에서는 git clone 후 README §5-3 순서(001~029가 번호순)로 끝난다. 생성기 재실행은 필요 없다. 029 SQL이 저장소에 커밋돼 있기 때문이다.

## 6. 보안·위험·되돌리는 법
- **서울 25구 id 불변**: 기관장(026~027)·이사회·준비·배정 표가 INSTITUTION_ID를 키로 갖고 있다(FK는 없지만 조인한다: BidAssignmentMapper:58, BoardMaterialMapper:17, PrepMapper:18, InstitutionHeadMapper:26~30). 생성기가 003에서 id를 읽고 25개를 못 맞추면 실패하고, Java 쌍 테스트가 이를 다시 막는다.
- **id 안정성의 한계**: 지자체 `lg-` id는 이름이 바뀌면 달라진다(예: `…시청`이 `…특별시청`). 그래서 이름 바꾸기·합병은 id를 새로 만들지 말고 NEXT 76의 별칭·이력 표로 다뤄야 한다. 이번 설계는 id를 불투명한 키로 보고 의미를 안 싣는다는 전제다. 대안(subRegion 폴리곤 코드로 지자체 id를 만들기)은 NEXT 76이 "폴리곤 키라 번호로 못 쓴다"고 했으므로 택하지 않았다. 결정은 기획·data-auditor가 확인한다.
- **DB에 없는 값이 늘 때**: ORG_CODE·G2B_CODE·CONTRACT_EXPIRY·BANK·SUB_REGION 등은 칸 추가가 필요하다. 별도 제안으로, 이번 029와 같이 하지 않는다. 지자체 외는 `LAST_BID+TERM`만으로 "임박도"를 계산하면 법원·교육청의 `contractExpiry` 규칙(NEXT 72 사용자 결정 11-13)과 어긋난다. **화면은 당분간 데이터 파일을 그대로 써야 한다**.
- **GET /institutions 응답이 25 → 약 450건**으로 늘고 `ConsistencyMapper`의 점검 목록(BID_CASES가 없어도 LEFT JOIN으로 나온다)에도 450행이 나온다. 응답 키·`/menus` 계약은 안 바뀐다. 화면이 이 목록을 어떻게 쓰는지(지도·랭킹이 REGION_CODE·TYPE에 의존하는지, 서울 외 `type`이 `교육청`·`법원`이어도 되는지)는 프런트가 확인할 일이다(NEXT 72 S3: 기관장 정보를 이 목록에 붙이지 않는다는 규칙도 그대로).
- 권한·접근 이력: 이번 변경은 SQL·도구뿐이라 새 API·403 경로가 없다. 자기신고(`X-Emp-No`) 인증을 바꾸지 않는다. 생성 SQL에는 실제 인물·비밀번호가 없고 기관명·공공 코드·날짜뿐이다(데이터 파일이 가상이 아니라 공개 자료라는 점은 data 쪽 책임).
- 되돌리는 법: 029를 적용한 뒤 되돌리려면 `DELETE FROM INSTITUTIONS WHERE INSTITUTION_ID LIKE 'lg-%' OR LIKE 'org-%' OR LIKE 'g2b-%' OR LIKE 'nm-%'` + `DELETE FROM SCHEMA_MIGRATION WHERE VERSION='029'`. 서울 25구의 빈 칸에 채워진 LAST_BID·CONTRACT_END·TERM은 되돌릴 수 없다(전에 NULL이었는지 모른다). 그러려면 적용 전 `mysqldump`로 INSTITUTIONS만 백업해 두기를 권한다. 데이터 파괴 위험은 낮다(덮어쓰는 칸이 없다).

## 7. 이관 메모
- [이관: 프런트] DB 기관 목록이 25→약 450으로 늘면 지도·랭킹·현황판이 DB 목록과 데이터 파일을 어떻게 합치는지(서울 `마포구` ↔ `마포구청` 이름 차이, 지자체 외의 type·region) 확인 — 029 적용 뒤 — 근거: DB NAME_KO는 서울이 `…구`, 새 행은 `…시청`·`…구청`.
- [이관: 데이터] 지자체 264곳 중 같은 이름 다른 기관·접두사 사례(경남 `고성군청`)가 `--check`의 "이름 겹침" 경고에 나오는지, 블록 간 값 충돌이 없는지 — 호출자가 `--check` 실행 뒤 — 근거: 반입이 이름 키(NEXT 72 S2).
- [이관: 기획] ① 지자체 id를 해시로 쓰고 76의 행정표준 번호는 별도 칸으로 넣는 것에 동의하는지 ② 지자체 외의 contractExpiry·bank·orgCode·parentOrgCode·bidKind·courtKind·opStatus·openDate·subRegion을 담을 칸(예: `ORG_CODE`·`CONTRACT_EXPIRY`·…)을 언제 어떤 번호(030)로 추가할지 — 현재 DB에는 그 값이 없어 새 기관의 임박도를 DB만으로는 못 그린다 — 근거: institutions_nonmuni.js:3-8.
- [이관: 기획] 서울 25구 이외의 NAME_KO를 데이터 이름(`창원시청`)으로 두는 것이 맞는지, 아니면 서울처럼 `…시`로 통일할지 — 이름 규칙이 정해지면 새 번호로 정정 — 근거: 서울만 `청`이 없다.
