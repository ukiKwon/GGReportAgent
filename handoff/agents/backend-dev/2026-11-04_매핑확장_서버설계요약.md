# NEXT 37 확정 매핑 구현 — 서버 설계 요약 (backend-dev, 2026-11-04)
전문은 세션 기록에만 있고 이 파일은 핵심 요약이다. 근거 매핑: `handoff/agents/planner/2026-11-04_확정매핑표.md`.

## 설계 원칙
1. **구역(area)**: 같은 시트에서 '2.세부 산출표'(detail), '3.투자…'(calc 계산표·judge 판단 기준표)를 제목·머리글(`header_has`)로 구분. 구역 안에서만 행·열을 찾는다.
2. **행은 라벨 경로(구분 1~4열)의 꼬리 일치**로 찾는다. 후보가 정확히 `count`(기본 1)개가 아니면 `ROW_AMBIGUOUS`/`ROW_NOT_FOUND`/`ROW_COUNT_MISMATCH`로 실패(추측 금지). 병합은 상속 규칙.
3. **열은 이름**(사업초기·1~4년·계)으로 찾고 5년 열은 정의하지 않아 읽히지 않는다.
4. **칸 키는 카탈로그에서 유도**(`lines`: "카탈로그 행 R의 매핑 칸을 왼쪽부터"). C-3 열 추가·C-5 병합으로 순번이 달라져도 손으로 안 맞춘다.
5. **레거시(range+labels+A1 cells) 공존**: `excel-map.json` v2(`mapping_ver` 2, `catalog_ver` 2)는 같은 파일 안 다른 표 형식.
- 라벨 정규화: NFKC → 첫 '=' 이후 제거 → 공백·`·`·`,`·`.` 제거 → 소문자. 접두 일치는 `*` opt-in.
- 연산: `sum`(합산 후 ÷100 한 번, 둘째 자리 HALF_UP), `paren`("5.00 (1.00)"), `as_is`, `manual`(기관명, `MANUAL_INPUT`), `derive:sum`(표 A 합계 = 표시값 합).
- 단위: `백만원→억원`(÷100)만 허용, 아니면 기동 실패. `UNIT_MISMATCH` 경고.

## 카탈로그 변경
`CATALOG_VER` 1→2. C-3에 사업초기 열 추가(7열), C-5 신규(9열, 25행×6=150칸, 맨 뒤 추가). 매핑 칸 95→250. 저장 양식은 `BoardFormJson.migrate`로 읽을 때 C-3 키를 한 칸씩 이전(DB 스크립트 없음). `draft-docx`에 `catalog_ver`를 되돌려 받아 다르면 409 `STALE_CATALOG`.

## 적용 순서(단계마다 서버 전체 초록)
S1 `BoardLabel`·`BoardNumber` → S2 위치 해석(`BoardExcelResolve`, 병합 색인·상한) → S3 지도 v2 파서(레거시 공존) → S4 `BoardExcelFill` v2 분기·응답 확장 → S5 카탈로그(C-3·C-5·버전·migrate) → S6 `excel-map.json` v2 컷오버+가상 원본 픽스처 재작성 → S7 C-5 매핑 → S8(선택) 레거시 삭제. 서버 테스트 600 → 약 715.

## 보안 점검거리(security 설계 검토 대상)
수식은 캐시값만, 부품 단위 숨김 경고, 병합 색인은 범위로 자르고 총수 10,000 상한, 개인정보 거부 범위가 표별 range→시트 범위로 넓어짐(더 엄격), 오류 응답에 업로드 텍스트 미포함, `STALE_CATALOG`는 비교만.

## 가상 엑셀 위험(사본 대조 전 가정 8가지)
시트 이름·제목 글자 / 구분 칸 병합 여부(빈 칸이면 경로가 짧아져 모호) / 소계 행 글자 / 미회수 투자액 '계' 칸 유무 / 3-1 값 행 위치(머리글 바로 아래 가정) / 환산 기준(원값) / 단위 표기 위치 / 숫자 문자열 여부.

## 결정(기획 선, 사용자에게 묻지 않음)
표 A 합계=표시값(억원 둘째 자리) 합 / 환산은 셀 원값 기준 / 억원은 소수 2자리 고정. 음수 표기만 사용자 확인.

## security 설계 검토 반영 항목 (2026-11-04, 상 없음·중 4·하 4) — 구현 시 설계에 포함
- **중(S1·S4)**: 합산·괄호 병기·`derive:sum`의 부품이 비었거나 오류(EMPTY·NO_CACHED_VALUE·EXCEL_ERROR)면 결과 칸을 failed로(0으로 치지 않음). 단위 미확인(`UNIT_MISMATCH`)은 칸을 review로 내림(경고만 두지 않음).
- **중(S2)**: 병합 상속은 라벨 열에만. 값 칸은 병합 좌상단만 읽고, 병합이 겹치면 구조 실패, 총수 10,000 초과 거부.
- **중(S5)**: `catalog_ver` 없는 요청은 409(`STALE_CATALOG`), 양식 저장 경로에도 같은 검사. `BoardFormJson.migrate`는 JSON의 `catalog_ver`가 1일 때만(두 번 밀림 방지).
- **중(S3·S4)**: 응답에 실리는 칸은 모두 개인정보 거부 범위 안, 출처 격자 2,000칸 상한 유지·비고 열은 격자에서 제외, `ROW_*` 오류에는 실제 라벨 글자 없이 좌표와 기대 경로만. 주민번호 정규식이 원 단위 큰 숫자에 오탐할 수 있음(추정) — 사본으로 확인.
- **하**: 행 루프는 실제 행만(0~lastRowNum 금지)·구역 행 상한 1,000·행당 정규화 1회 저장 / 정규화 결과가 빈 문자열이면 일치 금지·소문자화 `Locale.ROOT`·접두 `*`는 정규화 후 2자 이상·꼬리 일치는 "지도 경로가 실제 경로의 접미" 한 방향 / 찾은 행·구역 제목·열 머리 칸이 숨김이면 결과 칸 경고 / 부품 수식에 `[`(외부 참조)가 있으면 그 칸에도 경고.
