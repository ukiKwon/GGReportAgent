## 2. 요구·현황 요약 (근거 파일:줄)
- **라벨 칸이 없다**: 화자는 `참석자 N`의 번호만 저장한다(TranscriptParser.java:17, 047 UTTER.SPEAKER_NO). 응답도 `"speaker": "참석자 " + N`으로 고정이다(BoardMinutesService.java:372).
- **R14**: "자유 입력으로 화자 이름을 바꾸는 기능도 두지 않는다"(security 1019:99-101). 사용자 11-20 결정은 이 규칙의 예외지만 범위는 직책·역할로 한정된다.
- **옵션 파트가 작다**: options는 16KB 상한이다(BoardMinutesController.java:55). 발언 하나만 고쳐도 최대 2만 자라서 options에 수정분을 실을 수 없다. 수정분은 따로 `edits` 파트로 받는 것이 맞다.
- **preview_digest는 원문 파일 기준이다**: 가리기 전 내용으로 계산하고(MinutesParse.java:183,197-202) CONTENT_DIGEST(중복 검사 키)로 저장된다(Service:782, 814).
- **저장 후 발언 수정 경로는 이미 있다**: `PUT /board-minutes/{id}/utterances/{seq}`.
  - 가릴 것이 남아 있으면 저장 대신 422 MASK_REQUIRED로 거부한다(requireClean, Service:915).
  - rev를 확인하고, REV에 이전 글(현재 규칙으로 다시 가림)→새 글, LOG에 EDIT를 남긴다(Service:883-961).
  - 권한은 `d.edit`이다. 부장급·영업팀장(DEFAULT)·기한 안의 등록자가 해당한다(Access:110-119).
- **047 열은 재사용할 수 없다**:
  - ITEM에 KIND_CD='SPEAKER'를 넣으면 기존 `PUT items/{no}`로 라벨 검증을 우회할 수 있고, item_cnt가 틀어진다.
  - SCOPE의 GRANT_TYPE을 쓰면 공개범위 목록(selectScope)에 섞인다.
  - 그래서 **새 표 058**을 둔다.

```java
package com.kbstar.kgi.ggreport.web.minutes;

import java.util.Arrays;
import java.util.Collections;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.regex.Pattern;

/**
 * 발화자 역할 라벨 — 사용자 11-20 결정(직책·역할만, 실명 금지)으로 security R14 의 좁은 예외. 자유 글은 받지 않는다.
 * 형식: [소속 ' '] 역할 [' ' 번호 1~9]. '측' 은 소속이 있어야 한다. 어휘 목록은 기획 확정 대상(이관).
 * 오류에는 화자 번호·종류만 싣고 받은 값은 싣지 않는다.
 */
public final class SpeakerLabels {
    public static final int MAX_CHARS = 20;
    public static final int MAX_ENTRIES = 100;
    public static final int MAX_ORDINAL = 9;
    public static final String SIDE = "측";
    public static final List<String> AFFILIATIONS = Collections.unmodifiableList(Arrays.asList("기관", "은행", "외부"));
    public static final List<String> ROLES = Collections.unmodifiableList(Arrays.asList(
            SIDE, "기관장", "구청장", "시장", "군수", "도지사", "교육감", "총장", "병원장", "이사장", "이사", "감사",
            "위원장", "위원", "의원", "실장", "국장", "과장", "팀장", "주무관", "본부장", "영업부장", "영업팀장", "부장",
            "차장", "대리", "행장", "지점장", "담당자", "직원", "사회자", "발표자", "관계자"));
    private static final Pattern WS = Pattern.compile("\\s+");
    private static final Pattern ORD = Pattern.compile("[1-9]");

    private SpeakerLabels() {
    }

    static MinutesException invalid(int speakerNo, String kind) {
        Map<String, Integer> k = new LinkedHashMap<String, Integer>();
        k.put(kind, Integer.valueOf(1));
        return new MinutesException(422, "LABEL_INVALID", "speaker_label", 0, speakerNo, k);
    }

    /** 정규화한 라벨. 비었으면 null(라벨 없음 = '참석자 N'). 형식이 아니면 422 LABEL_INVALID{form}. */
    public static String normalize(String raw, int speakerNo) {
        if (raw == null) {
            return null;
        }
        if (raw.length() > MAX_CHARS * 4) {
            throw invalid(speakerNo, "form");
        }
        String t = WS.matcher(MinutesText.fold(raw)).replaceAll(" ").trim();
        if (t.isEmpty()) {
            return null;
        }
        if (t.length() > MAX_CHARS) {
            throw invalid(speakerNo, "form");
        }
        String[] p = t.split(" ");
        int i = 0;
        boolean affil = false;
        if (p.length > 1 && AFFILIATIONS.contains(p[0])) {
            affil = true;
            i = 1;
        }
        if (i >= p.length || !ROLES.contains(p[i]) || (SIDE.equals(p[i]) && !affil)) {
            throw invalid(speakerNo, "form");
        }
        i++;
        if (i < p.length && ORD.matcher(p[i]).matches()) {
            i++;
        }
        if (i != p.length) {
            throw invalid(speakerNo, "form");
        }
        return t;
    }

    /** 직원 명단 이름·PII·성+직함에 걸리면 422 LABEL_INVALID{kinds}. 어휘 안에서는 걸리지 않아야 한다(단위 시험이 전 조합을 확인). */
    public static void requireClean(MinutesMasker masker, String label, int speakerNo, MinutesBudget budget) {
        Map<String, Integer> kinds = masker.check(label, budget);
        if (!kinds.isEmpty()) {
            throw new MinutesException(422, "LABEL_INVALID", "speaker_label", 0, speakerNo, kinds);
        }
    }
}
```

```java
    private static Map<Integer, String> prepareEdits(TranscriptParser.Result tr, Map<Integer, String> raw) {
        Map<Integer, String> out = new TreeMap<Integer, String>();
        if (raw.isEmpty()) {
            return out;
        }
        Map<Integer, String> orig = new HashMap<Integer, String>();
        for (TranscriptParser.Utterance u : tr.utterances) {
            orig.put(Integer.valueOf(u.seqNo), u.body);
        }
        for (Map.Entry<Integer, String> e : raw.entrySet()) {
            int seq = e.getKey().intValue();
            String o = orig.get(e.getKey());
            if (o == null) {
                throw new MinutesException(422, "EDIT_SEQ_UNKNOWN", "edit", 0, seq, null);
            }
            String t;
            try {
                t = MinutesText.normalizeText(e.getValue(), "edit").trim();
            } catch (MinutesException x) {
                throw new MinutesException(x.getStatus(), x.getCode(), "edit", x.getLine(), seq, null);
            }
            if (t.isEmpty() || t.length() > EDIT_MAX_CHARS) {
                throw new MinutesException(422, "LIMIT_EDIT_LEN", "edit", 0, seq, null);
            }
            String[] ls = t.split("\n", -1);
            for (int i = 0; i < ls.length; i++) {
                if (ls[i].length() > MinutesText.MAX_LINE_CHARS) {
                    throw new MinutesException(422, "LIMIT_LINE", "edit", i + 1, seq, null);
                }
            }
            if (!t.equals(o)) {   // 원문과 같으면 고친 것으로 치지 않는다
                out.put(e.getKey(), t);
            }
        }
        return out;
    }

    private static Map<Integer, String> prepareLabels(TranscriptParser.Result tr, Map<Integer, String> raw, MinutesMasker masker,
                                                      MinutesMasker.Session s, MinutesBudget budget) {
        Map<Integer, String> out = new TreeMap<Integer, String>();
        if (raw.isEmpty()) {
            return out;
        }
        Set<Integer> speakers = new HashSet<Integer>();
        for (TranscriptParser.Utterance u : tr.utterances) {
            speakers.add(Integer.valueOf(u.speakerNo));
        }
        for (Map.Entry<Integer, String> e : raw.entrySet()) {
            int no = e.getKey().intValue();
            if (!speakers.contains(e.getKey())) {
                throw new MinutesException(422, "LABEL_SPEAKER_UNKNOWN", "speaker_label", 0, no, null);
            }
            String l = SpeakerLabels.normalize(e.getValue(), no);
            if (l == null) {
                continue;
            }
            SpeakerLabels.requireClean(masker, l, no, budget);
            if (s.hitsTerm(l)) {
                throw SpeakerLabels.invalid(no, "term");
            }
            out.put(e.getKey(), l);
        }
        return out;
    }

    /** 수정분 확인값 — 가리기 전 정규화 라벨·수정글. 없으면 null. 화면이 본 결과와 저장 결과를 맞추는 용도(보안 검사는 저장 때 전부 다시 한다). */
    private static String editsDigest(Map<Integer, String> labels, Map<Integer, String> edits) {
        if (labels.isEmpty() && edits.isEmpty()) {
            return null;
        }
        char sep = '\u0001';
        StringBuilder sb = new StringBuilder("e1:").append(MinutesMasker.RULE_VER).append(sep);
        for (Map.Entry<Integer, String> e : labels.entrySet()) {
            sb.append(e.getKey()).append(sep).append(e.getValue()).append(sep);
        }
        sb.append('\u0002');
        for (Map.Entry<Integer, String> e : edits.entrySet()) {
            sb.append(e.getKey()).append(sep).append(e.getValue()).append(sep);
        }
        return sha256Hex(sb.toString());
    }
```

```java
    /** 발화자 역할 라벨 하나(저장 후) — 고정 어휘만, 빈 값이면 지운다. 버전을 올리고 이력(이전→이후)·LOG 를 남긴다. 권한은 고치기와 같다. */
    public Map<String, Object> editSpeaker(final SysUser me, final Actor actor, BoardMinutes head, BoardMinutesAccess.Decision d,
                                           String speakerNo, BoardMinutesIn.SpeakerIn in) {
        requireView(head, d, d != null && d.edit);
        Integer no = parseNo(speakerNo);
        if (no == null || no.intValue() > TranscriptParser.MAX_SPEAKER_NO) {
            throw notFound();
        }
        if (in == null) {
            throw coded(400, "BAD_REQUEST", "요청 내용이 없습니다.");
        }
        final int revNo = requireRev(in.getRevNo());
        final int sp = no.intValue();
        final String label = SpeakerLabels.normalize(in.getLabel(), sp);   // 형식 밖 → 422 LABEL_INVALID{form}
        if (label != null) {
            SpeakerLabels.requireClean(masker(), label, sp, MinutesBudget.standard());   // 직원 명단·PII → 422{name|pii|title}
        }
        final long id = head.getMinutesId().longValue();
        final String now = Times.nowIso();
        return tx.execute(s -> {
            BoardMinutes h = mapper.lockHead(id);
            if (h == null || h.isDeleted()) {
                throw notFound();
            }
            if (h.getRevNo() != revNo) {
                throw revChanged(h.getRevNo());
            }
            if (mapper.countUtterBySpeaker(id, sp) == 0) {
                throw notFound();
            }
            String old = mapper.selectSpeakerLabel(id, sp);
            Map<String, Object> out = new LinkedHashMap<String, Object>();
            out.put("speaker_no", Integer.valueOf(sp));
            out.put("label", label);
            if (old == null ? label == null : old.equals(label)) {
                out.put("changed", Boolean.FALSE);
                out.put("rev_no", Integer.valueOf(h.getRevNo()));
                return out;
            }
            int next = h.getRevNo() + 1;
            if (mapper.bumpRev(id, h.getRevNo(), next, me.getEmpNo(), now) != 1) {
                throw revChanged(h.getRevNo());
            }
            mapper.deleteSpeaker(id, sp);
            if (label != null) {
                mapper.insertSpeaker(id, sp, label);
            }
            rev(id, next, "SPEAKER", Integer.valueOf(sp), "LABEL", old, label, me, now);
            log(id, h.getMaterialId().longValue(), "EDIT", Integer.valueOf(next), "SPEAKER", Integer.valueOf(sp), null, null, me, actor);
            out.put("changed", Boolean.TRUE);
            out.put("rev_no", Integer.valueOf(next));
            return out;
        });
    }
```

- 응답 키는 추가만 했다.
- 단, 시험 DB가 058을 읽지 못하면 상세·원문 시험이 모두 실패한다(properties 수정 필수).

## 5. 보안·위험·되돌리는 법 (security가 다시 볼 지점)
1. **R14 예외 범위**: 자유 글이 없고 서버 고정 어휘만 받는다. 다만 "구청장"처럼 그 회의에 한 명뿐인 역할은 **사실상 특정인의 발언을 모아 보이게 한다**(R13이 걱정한 '이어 붙이기'). 사용자 결정으로 받아들인 위험이지만 security가 어휘 범위를 확인해야 한다. 번호(1~9)는 구분용이지 신원이 아니다.
2. **저장 전 수정은 '가림'이고 저장 후 수정은 '거부'다**:
   - 저장 전에는 해제한 이름이 수정 글에서도 그대로 남는다(원문 처리와 같음).
   - 저장 후에는 requireClean으로 422가 난다(기존).
   - 이 비대칭이 의도대로인지 확인이 필요하다.
3. **고치기 전 원래 글은 저장하지 않는다**: 저장 전 수정에는 REV가 없다(R6). 감사는 UPLOAD의 ACT(누가·화면·버튼)와 LOG UPLOAD, 행의 EDITED_YN, 접근 이력의 건수로 남는다. 저장 후 라벨 변경은 REV(이전→이후) + LOG EDIT + ACT EDIT_LABEL로 남는다.
4. **파싱 순서**: edits JSON(최대 512KB)은 컨트롤러 `readUpload`에서 **권한 확인 전에** 읽힌다. options도 지금 그렇다. 비용은 작지만, 엄격히 하려면 문자열만 들고 있다가 `requireUploader` 뒤에 Jackson으로 파싱하도록 옮긴다. `toEdits`(내용 처리)는 이미 권한 확인 뒤에 있다.
5. **edits_digest의 성격**: 화면 일관성용이다. 안전은 저장 때 전부 다시 검사하는 데서 나온다. 403 경로는 기존 `exec`가 처리한다(403 → ACCESS_LOG DENIED + ACT DENIED).
6. **인증**: X-Emp-No·X-Screen-Id·X-Button-Id는 **자기신고**다. 운영은 enabled=false, require-verified=true가 기본이다.
7. **이력 열람**: 라벨도 REV에 들어가므로 부장급·등록자만 본다. 읽을 때 현재 규칙으로 다시 가린다.
8. **되돌리기**:
   - 코드 커밋을 되돌린다.
   - `DROP TABLE BOARD_MINUTES_SPEAKER;` 하면 라벨이 사라진다.
   - 이미 저장된 수정 본문(가린 글)과 EDITED_YN=1은 남는다. 무해하다.
