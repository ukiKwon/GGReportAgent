### 설계 결정 (되돌리기 쉬운 것은 팀 결정으로 정했다)
1. **권한과 이사회 숫자.**
   - 대본을 만들 수 있는 사람은 `PrepService.requireVisible`을 통과한 사람이고, 못 보면 404다.
   - 다만 사전준비를 보는 사람은 이사회 자료를 보는 사람보다 넓다. 영업팀 전원은 CONFIRMED 건을 보고, 비담당 영업팀장도 본다. 반면 이사회 자료는 담당자와 영업부장만 본다(`BoardAccess.canViewCase`).
   - 그래서 이사회 숫자(표 A·B)는 **`BoardAccess.canViewCase`가 참일 때만** 쓴다. 아니면 "자료 없음"과 같은 괄호 표시가 나온다.
   - 이것은 fail-closed 선택이다. 부장·담당자 외에는 금액이 비어 나온다. 기획이 다르게 정하면 `canViewCase` 한 줄을 바꾸면 된다.
2. **요약 양식 값**(staff, budget, current_bank, effect)은 `PrepFormMapper`로 직접 읽는다. 확정 판이 있으면 확정 판, 없으면 현재 판이다. `PrepFormService`는 고치지 않는다.
   - 읽기 규칙은 사전준비 열람자 기준이라 양식 열람 규칙보다 넓다. 기관장 이름·생년월일은 읽지 않는다.
   - 저장본 해시는 다시 확인하지 않는다. 대본은 기록물이 아니라 초안 도우미다.
3. **`draft` 표시** = !(이사회 확정 숫자를 쓰고 && 요약 양식도 확정 판). 하나라도 확정이 아니거나 비면 제목에 `[확정 전 초안] `이 붙는다. 응답 헤더 `X-Script-Draft: Y|N`도 준다(프런트의 한 줄 안내용).
4. **기관 유형**: "지자체·교육청"만 금고 문장이다. 비어 있어도 "그 밖"으로 보아 주거래은행 문장과 괄호 표시가 나온다(보수적). 문구는 `BoardScriptDocBuilder` 상단 상수에 모아 두었다.
   - 회계 문장은 두 곳이다. 이행사항의 "세입 및 세출…" 문장은 금고 외에서 괄호 표시로 두었다. 기타사항의 "○○으로 회계처리"는 `accounting`(기본 무형자산)을 모든 유형에 쓴다. 기획 확인이 필요하다(§7).
5. **숫자**
   - 표 B 순이익은 소수 2자리 고정, 천 단위 쉼표다(예: 10.14억원).
   - 승인 총액(표 A)은 끝자리 0을 떼어 "6억원", "99.5억원", "1,234억원"으로 쓴다. 표 A 칸이 소수 2자리 고정인 것과 다르게 읽히지만 샘플 문장("99억원")에 맞춘 것이다. `fmtAmount` 한 곳만 바꾸면 된다.
   - `EXCL_IT`에서 출연금·예비비 중 하나라도 비면 합산하지 않고 괄호 표시를 쓴다(0으로 치지 않는다). `TOTAL`은 표 A의 합계 칸 값을 그대로 쓴다.
6. **staff·budget**은 사람이 쓴 문자열이라 단위를 붙이지 않고 그대로 쓴다. 문장은 "임직원 수 {staff}, 예산규모는 {budget}이며,"다. "이며"를 써서 으로/로 받침 문제를 피했다.
7. **조사**: "「기관명」" 뒤 은/는과 "회계처리" 앞 으로/로는 받침으로 정한다(한글·숫자 읽기 기준, `KoreanJosa`). 받침을 알 수 없으면 "은(는)", "(으)로"로 쓴다. 샘플의 어색한 "」 는" 띄어쓰기는 붙였다.
8. **'<n페이지>'** 는 뺐고 굵은 줄 소제목(제안 배경입니다. 등)으로 바꿨다. 샘플의 "기타사항 입니다"는 "기타사항입니다"로 띄어쓰기를 고쳤다.
9. **meeting 값**은 `BOARD`(이사회, 기본) 또는 `COMMITTEE`(출연금심의위원회)다. 한글 이름 "이사회", "출연금심의위원회"도 받는다.
10. **round(차수)** 는 숫자 1~3자리만 받는다("10"이면 "제10차"). **agenda_no**는 쓴 그대로 "의안번호 {값}"으로 나온다. **review_when**도 쓴 그대로이므로 화면 예시에 "10월 중"처럼 '중'까지 쓰게 안내해야 한다.
11. **지역 이름**은 짧은 이름이라 "인천 내 기관영업 거점을…"으로 나온다. 코드에 없으면 〔지역 확인 필요〕다.
12. **기대효과 맺음 문장**은 샘플의 지역 특화 문장을 만들 수 없어 고정 문장 "이를 통해 당행의 기관영업 입지를 확대해나가고자 합니다."로 뒀다.

```java
package com.kbstar.kgi.ggreport.web.docout;

/** 받침에 따른 조사 고르기(순수 함수). 한글은 받침 유무, 숫자는 읽는 소리(영·삼·육=받침, 일·칠·팔=ㄹ받침) 기준. 영문자·판단 불가는 UNKNOWN. */
public final class KoreanJosa {

    public static final int NONE = 0;
    public static final int RIEUL = 1;
    public static final int FINAL = 2;
    public static final int UNKNOWN = 3;

    private KoreanJosa() {
    }

    /** 끝에서부터 한글·숫자·영문자가 나올 때까지 건너뛰어(공백·괄호·」·〕 등) 받침 종류를 돌려준다. */
    public static int last(String s) {
        if (s == null) {
            return UNKNOWN;
        }
        for (int i = s.length() - 1; i >= 0; i--) {
            char c = s.charAt(i);
            if (c >= 0xAC00 && c <= 0xD7A3) {
                int jong = (c - 0xAC00) % 28;
                return jong == 0 ? NONE : jong == 8 ? RIEUL : FINAL;
            }
            if (c >= '0' && c <= '9') {
                switch (c) {
                    case '0': case '3': case '6':
                        return FINAL;
                    case '1': case '7': case '8':
                        return RIEUL;
                    default:
                        return NONE;
                }
            }
            if ((c >= 'A' && c <= 'Z') || (c >= 'a' && c <= 'z')) {
                return UNKNOWN;
            }
        }
        return UNKNOWN;
    }

    /** 은/는 */
    public static String eunNeun(String s) {
        int k = last(s);
        return k == NONE ? "는" : k == UNKNOWN ? "은(는)" : "은";
    }

    /** 으로/로 (ㄹ받침은 '로') */
    public static String euroRo(String s) {
        int k = last(s);
        return k == FINAL ? "으로" : k == UNKNOWN ? "(으)로" : "로";
    }
}
```

```java
    private static String amountText(BoardScriptInput in) {
        BigDecimal v = AMOUNT_TOTAL.equals(in.amountMode) ? in.amountTotal : in.amountExclIt;
        if (v != null) {
            return fmtAmount(v) + "억원";
        }
        return mark(in.boardMissing ? NO_BOARD : "이사회 자료 표 A 확인 필요");
    }

    /** 승인 총액 — 끝자리 0을 뗀다(6, 99.5, 1,234). */
    static String fmtAmount(BigDecimal v) {
        BigDecimal s = v.setScale(2, RoundingMode.HALF_UP).stripTrailingZeros();
        if (s.scale() < 0) {
            s = s.setScale(0);
        }
        String pat = s.scale() == 0 ? "#,##0" : s.scale() == 1 ? "#,##0.0" : "#,##0.00";
        return format(s, pat);
    }

    /** 표 B 순이익 — 소수 2자리 고정(이사회 자료와 같다). */
    static String fmtFixed2(BigDecimal v) {
        return format(v.setScale(2, RoundingMode.HALF_UP), "#,##0.00");
    }

    private static String format(BigDecimal v, String pattern) {
        DecimalFormat df = new DecimalFormat(pattern, DecimalFormatSymbols.getInstance(Locale.ROOT));
        df.setRoundingMode(RoundingMode.HALF_UP);
        return df.format(v);
    }

    /** YYYY-MM-DD → "2027년 1월 1일". 형식이 아니거나 없으면 괄호 표시. */
    static String dateText(String iso) {
        if (iso != null && iso.matches("[0-9]{4}-[0-9]{2}-[0-9]{2}")) {
            return Integer.parseInt(iso.substring(0, 4)) + "년 " + Integer.parseInt(iso.substring(5, 7)) + "월 "
                    + Integer.parseInt(iso.substring(8, 10)) + "일";
        }
        return mark("약정 시작일 확인 필요");
    }

    private static boolean blank(String s) {
        return s == null || s.trim().isEmpty();
    }

    static String mark(String what) {
        return "〔" + what + "〕";
    }

    private static String orMark(String v, String what) {
        return blank(v) ? mark(what) : v.trim();
    }

    private static DocModel.Para line(String text) {
        return DocModel.Para.plain(text);
    }

    /** 문단 소제목 — 굵게(샘플의 '<n페이지>' 자리). */
    private static DocModel.Para sub(String text) {
        return DocModel.Para.of(DocModel.Bullet.NONE, 0, DocModel.Run.bold(text)).withSpacing(10, 2);
    }

        for (String s : lines) {
            if (!blank(s)) {
                b.add(line(s.trim()));
            }
        }
    }
```

**`.../service/BoardScriptFigures.java`** (이사회 자료 표 A·B에서 금액 찾기 — 라벨 글자로 칸을 찾는 순수 클래스)
```java
package com.kbstar.kgi.ggreport.web.service;

import com.kbstar.kgi.ggreport.web.boarddoc.BoardDocSpec;

import java.math.BigDecimal;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.regex.Pattern;

/**
 * 이사회 자료(양식 구조 + 저장 값)에서 발표 대본에 쓸 억원 값을 찾는다 — 표 A '재산상 이익제공 및 기부금(안)'의 출연금·예비비·합계,
 * 표 B '수익성 분석'의 명목가치 행 '순이익'. 사용자가 양식 구조를 바꿀 수 있어 칸 key 를 고정하지 않고 라벨 글자로 찾는다.
 * 못 찾거나 값이 숫자가 아니면 null(0 으로 치지 않는다). 순수 클래스 — DB 없음.
 */
final class BoardScriptFigures {

    private static final Pattern NUM = Pattern.compile("-?[0-9]{1,13}(\\.[0-9]{1,2})?");

    final BigDecimal exclIt;   // 출연금 + 예비비 (둘 다 있을 때만)
    final BigDecimal total;    // 합계 칸
    final BigDecimal profit;   // 표 B 명목가치 순이익

    private BoardScriptFigures(BigDecimal exclIt, BigDecimal total, BigDecimal profit) {
        this.exclIt = exclIt;
        this.total = total;
        this.profit = profit;
    }

    static BoardScriptFigures of(BoardDocSpec.Doc doc, Map<String, Map<String, String>> values) {
        BigDecimal contrib = null;
        BigDecimal reserve = null;
        BigDecimal total = null;
        BigDecimal profit = null;
        BoardDocSpec.Table a = table(doc, "A");
        if (a != null) {
            Map<String, String> cells = cells(values, "A");
            contrib = labeled(a, cells, "출연금");
            reserve = labeled(a, cells, "예비비");
            total = labeled(a, cells, "합계");
        }
        BoardDocSpec.Table b = table(doc, "B");
        if (b != null) {
            profit = profitOf(b, cells(values, "B"));
        }
        BigDecimal excl = contrib != null && reserve != null ? contrib.add(reserve) : null;
        return new BoardScriptFigures(excl, total, profit);
    }

    private static BoardDocSpec.Table table(BoardDocSpec.Doc doc, String id) {
        if (doc == null) {
            return null;
        }
        for (BoardDocSpec.Table t : doc.getTables()) {
            if (id.equals(t.getId())) {
                return t;
            }
        }
        return null;
    }

    private static Map<String, String> cells(Map<String, Map<String, String>> values, String ref) {
        Map<String, String> c = values == null ? null : values.get(ref);
        return c == null ? new HashMap<String, String>() : c;
    }

    /** 라벨 칸(머리·값 칸이 아닌 글자 칸)을 찾고, 같은 행에서 그 뒤 첫 값 칸의 저장 값을 숫자로 읽는다. */
    private static BigDecimal labeled(BoardDocSpec.Table t, Map<String, String> cells, String label) {
        for (List<BoardDocSpec.Cell> row : t.getRows()) {
            for (int i = 0; i < row.size(); i++) {
                BoardDocSpec.Cell c = row.get(i);
                if (!c.isHeader() && !c.isMapped() && !c.isInput() && label.equals(trim(c.getText()))) {
                    for (int j = i + 1; j < row.size(); j++) {
                        BoardDocSpec.Cell v = row.get(j);
                        if ((v.isMapped() || v.isInput()) && v.getKey() != null) {
                            return num(cells.get(v.getKey()));
                        }
                    }
                    return null;
                }
            }
        }
        return null;
    }

    /** 머리 '순이익'의 열 id × 행 '명목가치'의 행 id 로 칸 key 를 만든다. */
    private static BigDecimal profitOf(BoardDocSpec.Table t, Map<String, String> cells) {
        String colId = null;
        String rowId = null;
        for (List<BoardDocSpec.Cell> row : t.getRows()) {
            for (BoardDocSpec.Cell c : row) {
                if (colId == null && c.isHeader() && "순이익".equals(trim(c.getText()))) {
                    colId = c.getColId();
                }
                if (rowId == null && !c.isHeader() && "명목가치".equals(trim(c.getText()))) {
                    rowId = c.getRowId();
                }
            }
        }
        if (colId == null || rowId == null) {
            return null;
        }
        return num(cells.get(BoardDocSpec.cellKey(rowId, colId)));
    }

    private static String trim(String s) {
        return s == null ? "" : s.trim();
    }

    /** 쉼표를 뗀 뒤 정수부 13자리·소수 2자리 이내의 숫자만. 아니면 null(옛 '5.00 (1.00)' 같은 값 포함). */
    static BigDecimal num(String raw) {
        if (raw == null) {
            return null;
        }
        String s = raw.trim().replace(",", "");
        return NUM.matcher(s).matches() ? new BigDecimal(s) : null;
    }
}
```

```java
    private static void applyHand(BoardScriptInput x, SysUser me, PrepScriptIn in) {

    private static String meeting(String raw) {
        String v = raw == null ? "" : raw.trim();
        if (v.isEmpty() || "BOARD".equals(v) || "이사회".equals(v)) {
            return BoardScriptDocBuilder.MEETING_BOARD;
        }
        if ("COMMITTEE".equals(v) || "출연금심의위원회".equals(v)) {
            return BoardScriptDocBuilder.MEETING_COMMITTEE;
        }
        throw bad("meeting", "회의 종류가 올바르지 않습니다.");
    }

    private static String amountMode(String raw) {
        String v = raw == null ? "" : raw.trim();
        if (v.isEmpty() || BoardScriptDocBuilder.AMOUNT_EXCL_IT.equals(v)) {
            return BoardScriptDocBuilder.AMOUNT_EXCL_IT;
        }
        if (BoardScriptDocBuilder.AMOUNT_TOTAL.equals(v)) {
            return BoardScriptDocBuilder.AMOUNT_TOTAL;
        }
        throw bad("amount_mode", "승인 금액 기준이 올바르지 않습니다.");
    }

    /** 한 줄 칸 — null·빈 글자는 null. 제어·서식 문자는 400, 길이 초과는 400. */
    static String line(String raw, int max, String key, String label) {
        if (raw == null) {
            return null;
        }
        for (int i = 0; i < raw.length(); ) {
            int cp = raw.codePointAt(i);
            i += Character.charCount(cp);
            int type = Character.getType(cp);
            if (type == Character.CONTROL || type == Character.SURROGATE || type == Character.LINE_SEPARATOR
                    || type == Character.PARAGRAPH_SEPARATOR || type == Character.FORMAT
                    || cp == 0xFFFE || cp == 0xFFFF
                    || (cp >= 0x2066 && cp <= 0x2069) || cp == 0x061C) {   // BoardDocSpec.clean 과 같은 규칙(방향 격리 문자 포함)
                throw bad(key, label + "에 쓸 수 없는 문자가 있습니다.");
            }
        }
        String s = raw.trim();
        if (s.isEmpty()) {
            return null;
        }
        if (s.length() > max) {
            throw bad(key, label + "은(는) " + max + "자 이하로 입력해 주세요.");
        }
        return s;
    }

    /** 여러 줄 칸 — 줄바꿈으로만 나눈다(탭 등 다른 제어문자는 거부). 12줄·줄당 300자·합계 1,000자. */
    static List<String> lines(String raw, String key, String label) {
        List<String> out = new ArrayList<String>();
        if (raw == null || raw.trim().isEmpty()) {
            return out;
        }
        if (raw.length() > MAX_FREE_RAW) {
            throw bad(key, label + "이(가) 너무 깁니다. 줄여 주세요.");
        }
        int total = 0;
        for (String part : raw.replace("\r\n", "\n").replace('\r', '\n').split("\n", -1)) {
            String s = line(part, MAX_FREE_LINE, key, label);
            if (s != null) {
                out.add(s);
                total += s.length();
            }
        }
        if (out.size() > MAX_FREE_LINES || total > MAX_FREE_TOTAL) {
            throw bad(key, label + "은(는) " + MAX_FREE_LINES + "줄, " + MAX_FREE_TOTAL + "자 이하로 입력해 주세요.");
        }
        return out;
    }

    /** DB 값 정리 — 쓸 수 없으면 오류 없이 null(손 입력이 아니라 저장된 값이다). */
    private static String lenient(String raw, int max) {
        try {
            return line(raw, max, "x", "x");
        } catch (ApiException e) {
            return null;
        }
    }

    private static ApiException bad(String key, String message) {
        Map<String, Object> d = new LinkedHashMap<String, Object>();
        d.put("code", "BAD_VALUE");
        d.put("message", message);
        d.put("key", key);
        return ApiException.withDetail(400, d);
    }

    /** RFP 협약 개시일 — SAVE 인 연도별 최신 행. 이사회 연도가 있으면 같은 목표 연도 행만, 없으면 가장 큰 목표 연도 행. 없으면 null. */
    private String termStart(String institutionId, Integer wantYear) {
        String best = null;
        int bestYear = -1;
        for (BidTerm t : targets.selectTermsOf(institutionId)) {
            if (!ACTION_SAVE.equals(t.getActionCd()) || t.getTermStart() == null) {
                continue;
            }
            if (wantYear != null) {
                if (t.getTargetYear() == wantYear.intValue()) {
                    return t.getTermStart();
                }
            } else if (t.getTargetYear() > bestYear) {
                bestYear = t.getTargetYear();
                best = t.getTermStart();
            }
        }
        return best;
    }

    private static JsonNode parse(String json) {
        try {
            return JSON.readTree(json);
        } catch (IOException e) {
            return null;
        }
    }

    private static String text(JsonNode n) {
        return n != null && n.isTextual() && !n.asText().trim().isEmpty() ? n.asText().trim() : null;
    }

    /** 저장 JSON → {표 ref: {칸 key: 값}} (BoardMaterialService.tablesOf 와 같은 읽기). 못 읽으면 빈 맵. */
    private static Map<String, Map<String, String>> valuesOf(String json) {
        Map<String, Map<String, String>> out = new LinkedHashMap<String, Map<String, String>>();
        JsonNode root = json == null ? null : parse(json);
        if (root == null) {
            return out;
        }
        Iterator<Map.Entry<String, JsonNode>> it = root.path("tables").fields();
        while (it.hasNext()) {
            Map.Entry<String, JsonNode> e = it.next();
            Map<String, String> cells = new LinkedHashMap<String, String>();
            Iterator<Map.Entry<String, JsonNode>> ci = e.getValue().fields();
            while (ci.hasNext()) {
                Map.Entry<String, JsonNode> c = ci.next();
                cells.put(c.getKey(), c.getValue().asText());
            }
            out.put(e.getKey(), cells);
        }
        return out;
    }
```

## 5. 보안·위험·되돌리는 법
- **권한**
  - 사번이 없으면 401로 `ACCESS_LOG`에만 남고, 비활성·미등록 403은 `BID_PREP_ACT`에 DENIED로 남는다(기존 `run` 틀).
  - 사전준비를 못 보는 사람은 건이 있든 없든 404이고 HIDDEN 줄이 남는다. 디자이너는 비담당이면 404다(`PrepService.canSee`가 영업 계열·부장만 통과시킨다). 보안은 디자이너 포함 여부를 따로 판단해 달라는 planner 메모가 있다. 지금 구현은 "상세와 같은 범위"다.
  - 이사회 숫자는 담당자·영업부장만 받는다. 비담당 영업팀장·영업팀원은 금액 자리가 괄호 표시로 나온다.
- **감사**
  - 내려받기마다 `BID_PREP_ACT` 한 줄이다(`SCRIPT_DOCX`, `TASK_CD=T6`, 사번, 화면 `prep_detail`, 버튼 `script_docx`, `UI_VALID`).
  - 접근 이력(`ACCESS_LOG.DETAIL`)은 `prep case=… state=… code=SCRIPT_DOCX`뿐이다. 손 입력 본문·쿼리값·이름은 어디에도 싣지 않는다. 오류 메시지(400)에는 고정 문구와 key만 들어가고 입력값은 없다.
  - 화면·버튼 식별자는 거절(400)하지 않고 `UNKNOWN`으로 감사한다(기존 `PrepController`와 같다).
- **자기신고 인증의 한계**: `X-Emp-No`, `X-Screen-Id`, `X-Button-Id`는 모두 클라이언트 자기신고다. 이 권한 검사는 사칭 방지가 아니라 업무 규칙이다.
- **입력과 Word 삽입**
  - 손 입력은 `Run` 일반 글자로만 들어가고 필드·하이퍼링크·URL을 만들지 않는다.
  - 제어문자·서식 문자(방향 바꿈 포함)·짝 없는 서로게이트는 400이다(`BoardDocSpec.clean`과 같은 규칙). 길이는 칸별 상한이다.
  - 본문은 32KB를 넘으면 `BoardWriteLimitFilter`가 413으로 끊는다. 끊기 전에 실제 읽은 바이트도 센다.
  - 파일 이름은 기관명에서 영숫자·한글 외를 `_`로 바꾸고 `filename*=UTF-8''` 인코딩이다(기존 양식 내려받기와 같다).
- **운영 위험**
  - 숫자는 사람이 입력·확정한 이사회 자료와 요약 양식 값이다. 대본의 승인 금액은 사람이 쓴 칸을 합친 값이다(§2의 5). 확정 판이 없으면 제목에 `[확정 전 초안]`이 붙는다.
  - 사용자가 양식 구조(라벨 글자)를 바꾸면 숫자를 못 찾아 괄호 표시가 나온다. 틀린 숫자를 쓰는 쪽보다 안전하다.
  - 같은 `BOARD_MATERIAL`에 여러 연도가 있으면 확정 판 중 연도·번호가 가장 큰 것을 쓴다.
  - 요약 양식 확정 판의 저장본 해시는 이 경로에서 다시 확인하지 않는다(대본은 기록물이 아님).
- **되돌리는 법**: 새 파일 8개와 시험 4개를 지우고, `PrepController`·`PrepUiIds`·`BoardWriteLimitFilter`·`PrepAuditIsolationTest`의 패치를 되돌린다. DB는 바꾸지 않았으므로 되돌릴 데이터가 없다. 이미 남은 `SCRIPT_DOCX` 감사 줄은 그대로 둔다(추가 전용).

  - 이사회 숫자를 담당자·영업부장에게만 주는 것(비담당 영업팀장·영업팀은 괄호 표시)이 맞는지.
  - 이행사항의 회계 문장은 금고 외에서 괄호 표시로 두었고, 기타사항의 "○○으로 회계처리"는 모든 유형에 `accounting`(기본 무형자산)을 쓴다. 이 구분이 맞는지, 금고 외도 기타사항을 괄호로 둘지.
  - 기관 유형이 비어 있을 때 "그 밖(주거래은행 문장)"으로 보는 것이 맞는지.
  - 승인 총액 표기("6억원", "99.5억원")와 표 B 순이익 표기("10.14억원")의 자릿수 규칙.
  - 시·도는 "인천"처럼 짧은 이름이다. "인천광역시"로 쓰려면 이름 표가 필요하다.
  - 발표자 이름·직함은 비우면 내려받는 사람 값이 기본이고, 소속은 시스템에 없어 손 입력만 받는다.
- **[이관: 프런트]** 대본 만들기 창과 7단계 단추. 기다리는 것: 디자인 규격.
  - 끝점은 `POST /bidcases/{id}/prep/board-script-docx`다. 헤더는 `X-Screen-Id: prep_detail`, `X-Button-Id: script_docx`를 보낸다.
  - 본문 키는 snake_case다: `meeting`, `round`, `agenda_no`, `speaker_dept`, `speaker_name`, `speaker_title`, `term_years`, `review_when`, `intro`, `status_note`, `effect`, `profit_note`, `accounting`, `amount_mode`. 모두 선택이다.
  - `round`는 숫자만 받는다. `review_when`은 쓴 그대로 문장에 들어가므로 예시를 "10월 중"으로 안내한다. `intro`, `status_note`, `effect`, `profit_note`는 줄바꿈으로 줄을 나누고 12줄·1,000자 이하다.
  - 응답 헤더 `X-Script-Draft: Y`면 "확정 전 초안" 안내를 보여 준다. 응답은 docx 바이트이고 오류는 `{"detail":{"code":"BAD_VALUE","key":…,"message":…}}`다.
  - 별도의 "현재 상태 조회" 끝점은 만들지 않았다. 미리 채울 자동 값(기관·직위 등)이 필요하면 알려 달라(읽기 전용 GET은 작게 추가 가능).
- **[이관: 디자인]** 〔… 확인 필요〕·〔… 입력 필요〕 괄호 표시를 눈에 띄게(색·음영) 하려면 `DocxKit` 변경이 필요하다. 이는 e4 세션 몫이라 지금은 건드리지 않았다.
- **[이관: 보안]** 위 §5의 두 가지를 설계 단계에서 봐 달라. 이사회 숫자의 열람 범위(`BoardAccess.canViewCase`로 제한)와, 사전준비 열람자와 요약 양식 열람자의 범위 차이(요약 양식 값을 사전준비 열람자에게 그대로 쓴다)다. 자기신고 인증 위의 업무 규칙임을 전제로 한다.
- **[이관: 데이터]** 요약 양식 `current_bank`가 1·2금고 기관에서 은행 둘을 어떻게 담는지 확인해 달라. 지금은 그 문자열을 "현재 금고 약정 은행은 {값}입니다."에 그대로 넣는다.
- **[이관: 프런트·e4 세션]** `DocxKit`·`DocModel`은 고치지 않았다. 고쳐야 하는 경우는 위 디자인 항목뿐이다.

3. 기타사항의 "○○으로 회계처리하겠습니다"를 금고 외 기관에서도 쓸지, 괄호 표시로 둘지. 기본 구현은 "쓴다"이다.
