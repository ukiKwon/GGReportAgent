### 2. main이 실행할 명령
1. 8080 서버가 `target/`을 쓰고 있으면 먼저 확인한다.
2. 범위 시험:
   `cd kgi-ggreport-web && mvn -q -o test -Dtest="MinutesTextTest,MinutesMaskerTest,MinutesParseTest,TranscriptParserTest,TimelineParserTest,SummaryParserTest,SegmentLinkerTest,MinutesRealSampleTest,DocxKitTest,InstitutionHeadDocxApiTest,InstitutionHeadDocxAuditFailureTest"`
3. 전체: `mvn -q -o test`. 기대는 전부 통과이고, `MinutesRealSampleTest`는 `-Dminutes.realDir` 없이는 건너뛴다.
4. 실제 샘플 건수(A12): `mvn -q -o test -Dtest=MinutesRealSampleTest -Dminutes.realDir=../data/boardOfDirectors`. 건수 한 줄이 출력되고, 기존 단언(발언 59·구간 10·주제 4·할 일 4)은 그대로 통과해야 한다.
5. DB 적용은 없다. 047은 주석만 바뀌었다. 이미 적용한 DB에는 영향이 없고, 적용 전이면 번호 순서대로 한 번만 실행한다.

### 3. 지시에서 벗어났거나 내가 판단한 것
- **`RULE_VER`를 m1에서 m2로 올렸다.** 규칙과 digest 의미가 바뀌었기 때문이다. 저장된 데이터가 아직 없는 새 코드라 영향이 없고, m1 값이 필요하면 되돌려도 된다.
- **A10의 "문장 모양" 조건을 이렇게 해석했다.** 공백이 둘 이상이고 글자·공백 외 문자(숫자·문장부호)가 섞인 경우다. "Kim Young Soo" 같은 글자·공백뿐인 이름은 머리줄로 둔다. 지시를 더 넓게 해석(공백 2개만)하려면 `sentenceLike`의 `mixed` 조건을 빼면 된다.
- **B2 판정은 `head_empty`와 별개다.** 서비스는 사진이 있으면 비지 않았다고 본다. 컨트롤러는 권한대행 밖 확정 칸·학력·경력이 없으면 409를 낸다.
- **보이지 않는 문자를 시험 소스에 쓰는 방식을 바꿨다.** 편집 도구가 `\uXXXX`를 실제 글자로 바꿔 저장하는 것을 확인했다(보이지 않는 글자가 소스에 박힌다). 그래서 신규 시험은 `cp(int)`와 `(char)` 캐스트로 숫자로 적었다. 이 때문에 `MinutesTextTest`는 기존의 보이지 않는 리터럴(양방향 문자, 폭 없는 문자)까지 같은 방식으로 바꿔 파일을 다시 썼다. 의미는 같다. `MinutesMaskerTest`의 기존 줄 78(폭 없는 문자 리터럴)은 손대지 않았다.
- **지시 목록에 없던 파일이 있다.** 한 파일을 쓰려고 `MinutesTestSupport`에 `cp`를 추가했고, `MinutesMaskerTest`·`DocxKitTest`는 시험 반영 과정에서 고쳤다.
- **`DocxKit.clean`은 LRM·RLM(200E·200F)도 뺀다.** 지시한 양방향 목록보다 조금 넓다.
- **D2는 컨트롤러 계층 시험이다.** 실제 HTTP 500의 본문은 `ApiExceptionHandler`의 고정 문구 JSON 한 줄이다(docx 바이트 0). 완전한 통합 시험은 `@MockBean`이 `AppTest` 단일 컨텍스트를 깨서 쓰지 않았다.
- M3에서 항목 길이 초과는 자르지 않고 422(`LIMIT_ITEM_LEN`)로 거절하는 기존 동작을 그대로 뒀다.

### 4. 이관 메모
- [이관: 4단계 서비스 구현] 수정 저장은 `requireClean`이 돌려준 정규화 글을 저장해야 한다. 받은 원문을 그대로 저장하면 검사한 글과 저장한 글이 달라진다.
- [이관: 4단계 서비스 구현] REV의 OLD/NEW_TEXT는 현재 규칙으로 다시 가린 글만 넣고, 이력 열람은 부장급·등록자로 제한한다(047 주석 참조).
- [이관: S2 이후 호출부] `Groups.yearColumns`의 `IllegalArgumentException`을 호출부가 400(`ApiException.badRequest`)으로 감싸야 한다.
- [이관: 기획] 빈 발언 고정 본문 "(내용 없음)"의 문구가 현업이 보기에 맞는지 확인이 필요하다.
- 보이지 않는 문자는 Cf 전부를 지우므로 이모지 결합자(ZWJ)도 사라진다. 회의록 용도로는 문제없다고 판단했다.
