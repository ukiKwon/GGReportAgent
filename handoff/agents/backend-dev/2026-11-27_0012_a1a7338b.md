## 요약
1. **권한**: `BoardAccess.canViewCase`(담당 영업 또는 영업부장)에 건 상태 조건(`PrepService.TASK_STATES`)을 더합니다. 순서는 404(못 보는 건) → 403 → 409 → 503입니다. 비담당 영업팀장은 403, 확정·개설 대기·중단 건은 409입니다.
2. **2칸으로 축소**: AI가 쓰는 칸은 `intro`·`effect`뿐입니다. AI에 넘기는 자료에서 조직현황·MMDA·이사회 연도를 뺐고, 7자리 숫자(사번 모양)는 버립니다. 칸마다 허용 숫자 집합을 따로 둡니다. 응답의 `basis.draft`가 '확정 전 자료 기준'인지 알려 줍니다.
3. **security 반영**:
   - 어댑터는 `LlmClient`를 구현하지 않고 `@Primary`도 뺐습니다.
   - 확정 이사회 숫자를 보내기 **전에** BOARD_MATERIAL_ACT `SCRIPT_AI_SEND` 줄을 씁니다. 이 기록이 실패하면 LLM을 부르지 않습니다.
   - 동시 1건과 사번별 쿨다운(기본 60초)은 감사보다 앞에서 확인합니다. 전체 마감을 넘기면 감시 타이머가 요청을 끊습니다.
   - 폴백 모델 기능은 아예 뺐습니다.
   - probe(Ollama 상태 조회)는 영업 계열만 할 수 있습니다.
4. **ai_fields**: 대본 Word 요청에 `ai_fields`를 받습니다. 칸마다 BID_PREP_ACT 한 줄(`SCRIPT_DOCX_AI_INTRO`/`_EFFECT`)을 남기고, 접근 이력에 ` ai=intro,effect`를 붙입니다. 손댈 기존 파일은 PrepController·PrepScriptIn·BoardUiIds(+시험) 3개이고, 모두 '6e 협의 필요'입니다. DB 마이그레이션은 없습니다.
5. **공고문**:
   - 건 단위로 DB에 있는 공고 정보는 공고명(`BID_CASES.TITLE`), 입찰 대상(`BID_SUBJECT_CD`), 요약서의 `bid_kind`, 요약서 2쪽 평가 기준표(`tables.scoring` — 사람이 옮겨 저장한 경우만)입니다.
   - **공고 원문 글은 DB·파일 어디에도 저장되지 않습니다.** 첨부 원본 파일만 있어서, 쓰려면 다시 읽어야 합니다.
   - 6가지 기대 내용 중 '개요·사업 형태·배점'은 일부 채울 수 있습니다. '보유 상품·비즈니스 방식·제약 요건'은 지금 저장된 곳이 없습니다.

    private static void put(Facts f, String k, String v, Set<String>... allow) {
        if (v == null || v.isEmpty()) return;
        f.data.put(k, safe(v));
        for (Set<String> a : allow) ScriptDraftService.collect(v, a);
    }

    private static void putList(Facts f, String k, List<String> v, Set<String> allow) {
        if (v.isEmpty()) return;

        }
        f.data.put(k, out);

    private static String safe(String s) { return s.replace('<', '＜').replace('>', '＞'); }

    public Plan prepare(SysUser me, String bid) {
        BidPrep p = prep.requireVisible(me, bid);                                  // 404 — 존재 은닉이 먼저
        if (!boardAccess.canViewCase(me.getEmpNo(), p.getBidCaseId())) {

        }

    public String reserve(String empNo) {
        long now = System.nanoTime();
        Long last = lastStart.get(empNo);
        if (cooldownNs > 0 && last != null && now - last < cooldownNs) return "COOLDOWN";
        if (!gate.tryAcquire()) return "BUSY";
        lastStart.put(empNo, now);
        if (lastStart.size() > 256) {
            lastStart.entrySet().removeIf(e -> now - e.getValue() >= cooldownNs);
        }
        return null;
    }

    public void release() { gate.release(); }

    public Result call(Plan plan) {
        OllamaLlmClient c = ollama.getIfAvailable();
        long t0 = System.nanoTime();
        if (c == null) return empty(plan, "LLM_ERROR", false, 0L);
        LlmResponse<ScriptDraftOut> r;
        try {
            r = c.draft(LlmRequest.of(plan.prompt, ScriptDraftOut.class));
        } catch (LlmException e) {
            String why = reasonOf(e);
            return empty(plan, why, !"BUSY".equals(why), (System.nanoTime() - t0) / 1_000_000L);
        }
        return finish(plan, r.getValue(), r.getModel(), (System.nanoTime() - t0) / 1_000_000L);
    }

    static Set<String> askable(ScriptDraftBasisReader.Basis b) {
        Set<String> s = new LinkedHashSet<String>();
        if (b.instName != null && (!b.overview.isEmpty() || b.supervisor != null || b.staff != null
                || b.budget != null || b.currentBank != null)) s.add("intro");
        if (!b.effect.isEmpty() || !b.competition.isEmpty()) s.add("effect");   // 이사회 숫자만으로는 묻지 않는다
        return s;
    }

    static Result finish(Plan plan, ScriptDraftOut out, String model, long ms) {
        Map<String, String> fields = new LinkedHashMap<String, String>();
        Map<String, String> why = new LinkedHashMap<String, String>();
        boolean any = false;
        for (String k : FIELDS) {
            String v = "";
            String reason;
            if (!plan.ask.contains(k)) {
                reason = "NO_BASIS";
            } else {
                String s = tidy(out == null ? null : out.get(k));
                if (s.isEmpty()) reason = "EMPTY_OUTPUT";
                else if (!numbersAllowed(s, plan.facts.allowed.get(k))) reason = "NUMBER_NOT_IN_BASIS";
                else if (!Pii.scan(s).isEmpty()) reason = "PII";
                else { v = s; reason = null; any = true; }
            }
            fields.put(k, v);
            if (reason != null) why.put(k, reason);
        }
        return new Result(any ? "OK" : "EMPTY", any ? null : "ALL_BLANKED", fields, why, plan, model, ms, true);
    }

    private static Result empty(Plan plan, String reason, boolean called, long ms) {
        Map<String, String> fields = new LinkedHashMap<String, String>();
        Map<String, String> why = new LinkedHashMap<String, String>();
        for (String k : FIELDS) {
            fields.put(k, "");
            why.put(k, reason);
        }
        return new Result("EMPTY", reason, fields, why, plan, null, ms, called);
    }

    static void collect(String s, Set<String> out) {

        }
    }

package com.kbstar.kgi.ggreport.web.service;

import com.kbstar.kgi.ggreport.web.web.ApiException;

import java.util.*;

/**
 * 대본 Word 요청의 ai_fields(AI 초안에서 온 칸 키 목록, 사용자 11-26 A-5) — 감사 기록 전용, Word 에는 표시하지 않는다.
 * 허용 키 intro·effect 만. null·빈 목록 → 빈 목록. 모르는 키·3개 이상 → 400 BAD_VALUE(key=ai_fields). 중복은 하나로.
 * ⚠️ 화면의 자기신고 — 사람이 고쳐 쓴 정도는 알 수 없다("AI 초안을 넣은 적이 있는 칸"까지만).
 */
public final class ScriptAiFields {

    public static final List<String> KEYS = Collections.unmodifiableList(Arrays.asList("intro", "effect"));

    private ScriptAiFields() {
    }

    public static List<String> parse(List<String> raw) {
        if (raw == null || raw.isEmpty()) return Collections.emptyList();
        if (raw.size() > KEYS.size()) throw bad();
        Set<String> seen = new LinkedHashSet<String>();
        for (String s : raw) {
            String k = s == null ? "" : s.trim();
            if (!KEYS.contains(k)) throw bad();
            seen.add(k);
        }
        List<String> out = new ArrayList<String>();
        for (String k : KEYS) if (seen.contains(k)) out.add(k);   // 고정 순서
        return out;
    }

    /** BID_PREP_ACT.ACTION_CD — SCRIPT_DOCX_AI_INTRO(20자) · SCRIPT_DOCX_AI_EFFECT(21자) ≤ 30. */
    public static String actionOf(String key) {
        return "SCRIPT_DOCX_AI_" + key.toUpperCase(Locale.ROOT);
    }

    private static ApiException bad() {
        Map<String, Object> d = new LinkedHashMap<String, Object>();
        d.put("code", "BAD_VALUE");
        d.put("message", "AI 초안 표시 값이 올바르지 않습니다. 창을 닫았다가 다시 여세요.");
        d.put("key", "ai_fields");
        return ApiException.withDetail(400, d);
    }
}

## 6. 보안·위험·되돌리는 법
- **403 경로**: 비담당 영업팀장, 옛 담당자(중단 건), 비활성 사번이 해당합니다. 판정 순서가 404 → 403이라 건이 있는지가 드러나지 않습니다. 403은 `guard.denied`로 접근 이력에도 남습니다.
- **감사 순서(하-3)**:
  - 보내기 전 `SCRIPT_AI_SEND` 줄이 커밋된 뒤에만 LLM을 부릅니다.
  - 호출 중 서버가 죽으면 SEND 한 줄만 남습니다. 이는 '보냈을 수 있음'을 뜻합니다.
  - 결과 줄 기록이 실패하면 500입니다(초안은 나가지 않음).
- **한계(그대로)**:
  - X-Emp-No, 화면, 버튼, ai_fields는 모두 자기신고입니다. 사번을 위조하면 쿨다운을 돌아갈 수 있습니다(사번마다 60초).
  - 이름은 정규식으로 못 거릅니다. 그래서 칸 단위로 뺐습니다(A-3).
  - ai_fields는 "AI 글을 넣은 적이 있는 칸"까지만 알려 줍니다. 사람이 얼마나 고쳤는지는 모릅니다.
  - Tomcat 스레드는 요청 1건당 최대 약 8분 잡힙니다(동시 1건).
- **되돌리는 법**:
  - `enabled=false` 후 재기동하면 503이 됩니다.
  - 완전히 걷어내려면 새 파일을 지웁니다. ②가 적용돼 있다면 그 블록과 ① 필드도 함께 지웁니다. ③은 남겨도 해가 없습니다.
  - DB 변경은 없습니다.

## 7. 사용자 답이 필요한 것 (업무 언어)
