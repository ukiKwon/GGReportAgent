## 2. 요구/원인 요약과 설계 변경점
설계(a3977783)에서 실소스를 읽고 바꾼 것이다.
- **반입 응답은 200이 아니라 201**이다. `plans/import`(InstitutionPlanController.java:80)가 201이라 맞춘다.
- **Oracle 060은 IDENTITY 문법**을 쓴다. oracle 034:20과 같고 H2 시험 스키마에서 돈다. `ROW_NO`는 `NUMBER(6)`이다. 빈 줄이 원시 행 번호에 들어가 `NUMBER(3)`이면 넘칠 수 있다.
- **분야 5종은 COMMON_CODE에 넣지 않고 `NewsCsv` 상수로 둔다.**
  - 새 코드 그룹은 `CommonCodeSchemaTest`(NOT IN 목록 하드코딩)를 깨뜨린다.
  - 값 5개는 계약으로 고정이다.
  - 대신 `PLAN_ACTION/NEWS_IMPORT` 1행만 060에 넣는다. PLAN_ACTION 그룹은 그 시험에서 이미 제외돼 있다.
- **중2는 DDL 없이 `CLOSE_REASON='NEWS'`로 처리한다.** 칸 추가 대신 이 방식을 택한 이유는 셋이다.
  - 045는 이미 적용된 표라 ALTER가 필요 없다.
  - 의미가 `STATUS_CD='APPLIED'`일 때만 있다. 자유 글은 FAILED·EXCLUDED에만 쓰이므로 값이 섞이지 않는다.
  - 칸은 이미 있어 DBA 권한 추가가 없다(CLOSE_REASON UPDATE는 045에 허가돼 있음).
- **plan_state 정의**: 사업계획 판이 하나라도 있으면 `PLAN_FOUND`다(origin 무관). 없고 뉴스 판이 있으면 `NEWS_ONLY`, 둘 다 없으면 `NOT_FOUND`다. 설계서 D5(IMPORT만)와 §5(아무 판)가 엇갈려서 §5를 따랐다.
- **감사**:
  - 뉴스 반입은 `INST_PLAN_ACT`의 `ACTION_CD='NEWS_IMPORT'`다.
  - 요청 닫힘은 `COLLECT_APPLY`/`OUTCOME='NEWS'`다.
  - `IMPORT_ID`의 뜻은 060 머리글에 적는다.

```java
        }
        Map<String, Integer> col = header(recs.get(0));
        if (recs.size() - 1 > MAX_ROWS) {   // 행 검사(개인정보 검사)보다 먼저 — 최대 5,000행을 돌리지 않는다(security 하6)
            throw CsvLimits.bad(parsed.rawRows.get(MAX_ROWS + 1), "뉴스는 한 파일에 " + MAX_ROWS + "건까지입니다.");
        }
        int width = recs.get(0).size();
        long deadline = System.nanoTime() + PII_BUDGET_NANOS;
        List<Row> out = new ArrayList<>();
        Set<String> urls = new HashSet<>();
        Set<String> titles = new HashSet<>();
        String latest = null;
        for (int i = 1; i < recs.size(); i++) {
            List<String> r = recs.get(i);
            int rawRow = parsed.rawRows.get(i);
            if (r.size() != width) {
                throw CsvLimits.bad(rawRow, "칸 수가 머리행과 다릅니다.");
            }
            Row it = row(new Cells(r, col), rawRow, opt, deadline);
            if (!urls.add(it.url.toLowerCase(Locale.ROOT))) {
                throw CsvLimits.bad(rawRow, "같은 출처URL이 앞 행에 있습니다.");
            }
            if (!titles.add(it.title.toLowerCase(Locale.ROOT))) {
                throw CsvLimits.bad(rawRow, "같은 제목이 앞 행에 있습니다.");
            }
            if (latest == null || it.checkedOn.compareTo(latest) > 0) {
                latest = it.checkedOn;
            }
            out.add(it);
        }
        if (!opt.fileDate.equals(latest)) {
            throw new InstitutionCsv.CsvFormatException("파일 이름의 날짜가 확인일 중 가장 늦은 날과 다릅니다.");
        }
        return new Result(out);
    }

    private static Map<String, Integer> header(List<String> h) {
        Map<String, Integer> col = new HashMap<>();
        for (int i = 0; i < h.size(); i++) {
            String name = PlanCsv.text(h.get(i), 0, 20, false, false);
            if (!HEADERS.contains(name)) {
                throw new InstitutionCsv.CsvFormatException("header: " + (i + 1) + "번째 열 이름을 알 수 없습니다.");
            }
            if (col.put(name, i) != null) {
                throw new InstitutionCsv.CsvFormatException("header: " + (i + 1) + "번째 열 이름이 겹칩니다.");
            }
        }
        for (String req : HEADERS) {   // 9열 모두 필수 — 열 이름은 서버 고정값이라 사유에 실어도 된다
            if (!col.containsKey(req)) {
                throw new InstitutionCsv.CsvFormatException("header: 필수 열이 없습니다(" + req + ").");
            }
        }
        return col;
    }

    private static Row row(Cells c, int row, Options opt, long deadline) {
        Row it = new Row();
        it.row = row;
        String csvInst = PlanCsv.text(c.get(H_INST), row, 64, false, true);
        if (!PlanCsv.validId(csvInst) || !csvInst.equalsIgnoreCase(opt.institutionId)) {
            throw CsvLimits.bad(row, "기관ID가 반입 대상 기관과 다릅니다.");
        }
        it.fieldCd = field(c.get(H_FIELD), row);
        it.title = required(PlanCsv.text(c.get(H_TITLE), row, 200, false, true), row, "제목");
        it.press = required(PlanCsv.text(c.get(H_PRESS), row, 60, false, true), row, "언론사");
        it.checkedOn = PlanCsv.date(c.get(H_CHECKED), row, opt.today);
        it.publishedOn = published(c.get(H_PUBLISHED), row, LocalDate.parse(it.checkedOn));
        String url = PlanCsv.text(c.get(H_URL), row, SafeUrl.MAX, false, false);
        if (url.isEmpty() || !SafeUrl.isHttp(url)) {
            throw CsvLimits.bad(row, "출처URL은 http 또는 https 주소(500자 이내, 계정정보 없음)여야 합니다.");
        }
        it.url = url;
        String agent = PlanCsv.text(c.get(H_COLLECTOR), row, 60, false, false);
        if (agent.isEmpty() || !PlanCsv.AGENT.matcher(agent).matches()) {
            throw CsvLimits.bad(row, "수집자는 수집 프로그램 식별자(영문자로 시작, 예 news-collector/1.0)여야 합니다.");
        }
        it.collectorAgent = agent;
        it.summary = summary(PlanCsv.text(c.get(H_SUMMARY), row, CsvLimits.MAX_CELL_CHARS, true, true), row, it.title);
        pii(it.title, row, deadline);
        pii(it.press, row, deadline);
        pii(it.summary, row, deadline);
        return it;
    }

    private static String field(String raw, int row) {
        String v = PlanCsv.text(raw, row, 100, false, false);
        if (v.isEmpty()) {
            throw CsvLimits.bad(row, "분야 칸이 비어 있습니다.");
        }
        if (FIELDS.containsKey(v)) {
            return v;
        }
        for (Map.Entry<String, String> e : FIELDS.entrySet()) {
            if (e.getValue().equals(v)) {
                return e.getKey();
            }
        }
        throw CsvLimits.bad(row, "분야 값이 허용값이 아닙니다.");
    }

    /** 확인일 − 1년 ≤ 보도일 ≤ 확인일. */
    private static String published(String raw, int row, LocalDate checked) {
        String v = PlanCsv.text(raw, row, 10, false, false);
        try {
            if (DATE.matcher(v).matches()) {
                LocalDate d = LocalDate.parse(v);
                if (!d.isBefore(checked.minusYears(1)) && !d.isAfter(checked)) {
                    return v;
                }
            }
        } catch (DateTimeException ignored) {
            // 아래 고정 문구로
        }
        throw CsvLimits.bad(row, "보도일은 확인일 이전 1년 안의 YYYY-MM-DD 여야 합니다.");
    }

    /** 빈 줄을 뺀 1~3줄, 줄바꿈을 뺀 글자 합 300자 이내. 제목과 같은 문장 거부. 저장 값 = 줄마다 앞뒤 공백을 자르고 '\n' 으로 이은 것. */
    private static String summary(String raw, int row, String title) {
        List<String> lines = new ArrayList<>();
        for (String ln : raw.split("\n")) {
            String t = ln.trim();
            if (!t.isEmpty()) {
                lines.add(t);
            }
        }
        if (lines.isEmpty()) {
            throw CsvLimits.bad(row, "요약 칸이 비어 있습니다.");
        }
        if (lines.size() > MAX_SUMMARY_LINES) {
            throw CsvLimits.bad(row, "요약은 " + MAX_SUMMARY_LINES + "줄 이내여야 합니다.");
        }
        int chars = 0;
        String st = squash(title);
        for (String ln : lines) {
            chars += ln.length();
            if (!st.isEmpty() && st.equals(squash(ln))) {
                throw CsvLimits.bad(row, "요약이 제목과 같습니다. 직접 쓴 요약을 적으세요.");
            }
        }
        if (chars > MAX_SUMMARY_CHARS) {
            throw CsvLimits.bad(row, "요약은 " + MAX_SUMMARY_CHARS + "자 이내여야 합니다.");
        }
        return String.join("\n", lines);
    }

    private static void pii(String text, int row, long deadline) {
        try {
            if (!Pii.scanExternal(text, deadline).isEmpty()) {
                throw CsvLimits.bad(row, PII_MSG);
            }
        } catch (Pii.ScanTimeoutException e) {
            throw CsvLimits.bad(row, PII_MSG);   // 확인하지 못하면 받지 않는다(PlanCollectService.reason 선례)
        }
        String f = fold(text);
        if (AGE.matcher(f).find() || BIRTH.matcher(f).find() || PAREN_AGE.matcher(f).find()) {
            throw CsvLimits.bad(row, PII_MSG);
        }
    }

    /** NFKC(전각 숫자·괄호·NBSP 접힘) 뒤 비ASCII 십진 숫자(아랍-인도 등)를 ASCII 로. 검사용 사본이며 저장은 원문이다. */
    private static String fold(String text) {
        String s = Normalizer.normalize(text, Normalizer.Form.NFKC);
        StringBuilder b = new StringBuilder(s.length());
        for (int i = 0; i < s.length(); ) {
            int cp = s.codePointAt(i);
            i += Character.charCount(cp);
            if (Character.getType(cp) == Character.DECIMAL_DIGIT_NUMBER) {
                b.append((char) ('0' + Character.digit(cp, 10)));
            } else {
                b.appendCodePoint(cp);
            }
        }
        return b.toString();
    }

    /** 글자·숫자만 남긴 비교용 값(대소문자·공백·문장부호 차이로 '같은 문장'을 피하지 못하게). */
    private static String squash(String s) {
        String n = Normalizer.normalize(s, Normalizer.Form.NFKC).toLowerCase(Locale.ROOT);
        StringBuilder b = new StringBuilder(n.length());
        for (int i = 0; i < n.length(); ) {
            int cp = n.codePointAt(i);
            i += Character.charCount(cp);
            if (Character.isLetterOrDigit(cp)) {
                b.appendCodePoint(cp);
            }
        }
        return b.toString();
    }

    private static String required(String v, int row, String label) {
        if (v.isEmpty()) {
            throw CsvLimits.bad(row, label + " 칸이 비어 있습니다.");
        }
        return v;
    }

    private static final class Cells {
        final List<String> cells;
        final Map<String, Integer> col;

        Cells(List<String> cells, Map<String, Integer> col) {
            this.cells = cells;
            this.col = col;
        }

        String get(String h) {
            Integer i = col.get(h);
            return i == null ? "" : cells.get(i);
        }
    }
}
```
- 먼저 거르는 순서:
  - 파일 크기 → UTF-8 → 머리행
  - 행 수(11행 이상이면 즉시 400, 하6)
  - 행 검사(개인정보 검사는 마지막)
- 우회 대응(중3):
  - `Pii.scanExternal`을 그대로 쓴다.
  - 나이·생년·괄호 나이는 접은 사본에 건다.
  - NBSP 우회는 NFKC가 막는다.
- 오탐: 보안 제안 목록에 `트`(세트)·`포`와 생년 `산`(생산)을 더했다. `scanExternal`에는 금액처럼 숫자가 긴 문자열이 전화로 읽히는 알려진 오탐이 있다(Pii.java:40). 제목·요약에 긴 숫자열을 넣지 않도록 SCHEMA에 한 줄 적는다.
- `scanExternal`은 가린 이메일(`a***@x.kr`)을 통과시킨다. 뉴스 요약에는 그런 값이 없어야 하지만 서버가 막지는 않는다. 표본 검수로 넘긴다.

```java
import org.springframework.stereotype.Service;
import org.springframework.transaction.PlatformTransactionManager;

import org.springframework.transaction.support.TransactionTemplate;
import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;

/**
 * 기관 관련 뉴스(060, NEXT 107) — 사업계획을 못 찾은 기관의 대체 자료 반입·조회.
 * 구조는 InstitutionPlanService.apply 와 같다: 검증은 트랜잭션 밖(NewsCsv), 안에서는 기관 잠금 → 같은 파일(409 MSG_SAME) → 이른 날짜(409 MSG_OLDER)
 * → 판·항목 INSERT → 감사(NEWS_IMPORT/OK) → 열린 수집 요청 닫기(onNewsImported)를 한 트랜잭션으로. 실패(400·404·409·413·500)도 INST_PLAN_ACT 에 남긴다.
 * 409 문구는 InstitutionPlanService.MSG_SAME·MSG_OLDER 상수를 그대로 쓴다 — PlanInboxService.classify 가 글자 비교로 ALREADY·OLDER 를 가른다(security 하2).
 * 감사·조회에 제목·요약·URL·언론사는 싣지 않는다. 반입자 사번·SHA 는 조회 응답에 내보내지 않는다.
 * ⚠️ 사번은 X-Emp-No 자기신고일 수 있다. 관리자 검사는 업무 규칙이지 사칭 방지가 아니다.
 */
@Service
public class InstitutionNewsService {

    private static final Logger LOG = LoggerFactory.getLogger(InstitutionNewsService.class);
    public static final String ACTION_NEWS_IMPORT = "NEWS_IMPORT";
    public static final String PLAN_FOUND = "PLAN_FOUND";
    public static final String NEWS_ONLY = "NEWS_ONLY";
    public static final String NOT_FOUND = "NOT_FOUND";
    private static final ZoneId SEOUL = ZoneId.of("Asia/Seoul");

    private final InstitutionPlanService plans;
    private final InstitutionPlanMapper planMapper;
    private final InstitutionNewsMapper mapper;
    private final PlanAudit audit;
    private final PlanCollectService collect;
    private final TransactionTemplate tx;

    public InstitutionNewsService(InstitutionPlanService plans, InstitutionPlanMapper planMapper, InstitutionNewsMapper mapper,
                                  PlanAudit audit, PlanCollectService collect, PlatformTransactionManager txm) {
        this.plans = plans;
        this.planMapper = planMapper;
        this.mapper = mapper;
        this.audit = audit;
        this.collect = collect;
        this.tx = new TransactionTemplate(txm);
    }

    LocalDate today() { return LocalDate.now(SEOUL); }

    // ── 반입(관리자) ──
    /** 파일 올리기(multipart). 원래 파일 이름은 날짜 판정에만 쓰고 저장하지 않는다. */
    public Map<String, Object> importUpload(String instId, MultipartFile file, String batchRaw, Actor actor) {
        BoardUiIds.Ui ui = PlanUiIds.newsUpload();
        String inst = null;   // 감사 기관ID — canonical 이 성공한 뒤에만 채운다(실패하면 NONE)
        String sha = null;
        try {
            inst = canonical(instId);
            if (file == null || file.isEmpty()) throw ApiException.badRequest("파일을 선택하세요.");
            if (file.getSize() > CsvLimits.MAX_FILE_BYTES) throw InstitutionPlanService.tooLarge();
            String fileDate = fileDate(inst, file.getOriginalFilename());
            String batch = InstitutionPlanService.batch(batchRaw);
            byte[] raw;
            try { raw = file.getBytes(); } catch (IOException e) { throw ApiException.badRequest("파일을 읽을 수 없습니다."); }
            if (raw.length > CsvLimits.MAX_FILE_BYTES) throw InstitutionPlanService.tooLarge();
            sha = InstitutionPlanService.sha256(raw);
            return apply(inst, raw, sha, fileDate, batch, actor, ui);
        } catch (ApiException e) {
            failed(inst, HeadAudit.outcomeOf(e.getStatus()), sha, actor, ui);
            throw e;
        } catch (RuntimeException e) {
            failed(inst, "ERROR", sha, actor, ui);
            throw e;
        }
    }

    /** 서버 폴더 반입(PlanInboxService) — 이름·바이트는 호출자가 설정 폴더에서 읽은 값. */
    public Map<String, Object> importFile(String fileName, byte[] raw, String batchRaw, Actor actor, BoardUiIds.Ui ui) {
        Matcher fm = NewsCsv.FILE_NAME.matcher(fileName == null ? "" : fileName);
        String rawId = fm.matches() ? fm.group(1) : null;
        String inst = null;
        String sha = null;
        try {
            if (rawId == null) throw ApiException.badRequest("파일 이름은 {기관ID}_{확인일YYYYMMDD}_news.csv 형식이어야 합니다.");
            inst = canonical(rawId);
            if (raw == null) throw ApiException.badRequest("파일을 읽을 수 없습니다.");
            if (raw.length > CsvLimits.MAX_FILE_BYTES) throw InstitutionPlanService.tooLarge();
            String fileDate = fileDate(inst, fileName);
            String batch = InstitutionPlanService.batch(batchRaw);
            sha = InstitutionPlanService.sha256(raw);
            return apply(inst, raw, sha, fileDate, batch, actor, ui);
        } catch (ApiException e) {
            failed(inst, HeadAudit.outcomeOf(e.getStatus()), sha, actor, ui);
            throw e;
        } catch (RuntimeException e) {
            failed(inst, "ERROR", sha, actor, ui);
            throw e;
        }
    }

    /** 폴더 확인(읽기 전용, DB·파일 무변경) — InstitutionPlanService.inspect 와 같은 순서(같은 SHA → IMPORTED, 이른 날짜 → OLDER, 그다음 내용 검사). */
    public Map<String, Object> inspect(String fileName, Supplier<byte[]> reader) {
        Map<String, Object> m = new LinkedHashMap<>();
        m.put("file_name", fileName);
        m.put("institution_id", null);
        m.put("name_ko", null);
        m.put("file_date", null);
        Matcher fm = NewsCsv.FILE_NAME.matcher(fileName == null ? "" : fileName);
        if (!fm.matches()) return status(m, "BAD_NAME");
        String inst = plans.canonicalOrNull(fm.group(1));
        if (inst == null) return status(m, "NO_INSTITUTION");
        m.put("institution_id", inst);
        m.put("name_ko", planMapper.selectInstitutionName(inst));
        String fileDate;
        try {
            fileDate = fileDate(inst, fileName);
        } catch (ApiException e) {
            return status(m, "BAD_DATE");
        }
        m.put("file_date", fileDate);
        byte[] raw;
        try {
            raw = reader.get();
        } catch (InstitutionPlanService.FileProblem e) {
            return status(m, e.getCode());
        }
        if (mapper.countImportBySha(inst, InstitutionPlanService.sha256(raw)) > 0) return status(m, "IMPORTED");
        InstNewsImport last = mapper.selectLatestImport(inst);
        if (last != null && last.getFileDate() != null && fileDate.compareTo(last.getFileDate()) < 0) return status(m, "OLDER");
        try {
            NewsCsv.Result r = NewsCsv.parse(raw, new NewsCsv.Options(inst, fileDate, today()));
            m.put("item_count", r.rows.size());
            return status(m, "READY");
        } catch (InstitutionCsv.CsvFormatException e) {
            m.put("message", e.getMessage());
            return status(m, "INVALID");
        }
    }

    private Map<String, Object> apply(String instId, byte[] raw, String sha, String fileDate, String batch, Actor actor, BoardUiIds.Ui ui) {
        final NewsCsv.Result r;
        try {
            r = NewsCsv.parse(raw, new NewsCsv.Options(instId, fileDate, today()));
        } catch (InstitutionCsv.CsvFormatException e) {
            throw ApiException.badRequest(e.getMessage());
        }
        return tx.execute(status -> {
            if (planMapper.lockInstitution(instId) == null) throw ApiException.notFound("institution not found");
            InstNewsImport last = mapper.selectLatestImport(instId);
            if (last != null && sha.equals(last.getFileSha256())) throw new ApiException(409, InstitutionPlanService.MSG_SAME);
            if (mapper.countImportBySha(instId, sha) > 0) throw new ApiException(409, InstitutionPlanService.MSG_SAME);   // 예전 판 내용으로 되돌리지 않는다(폴더 반입 멱등)
            if (last != null && last.getFileDate() != null && fileDate.compareTo(last.getFileDate()) < 0) {
                throw new ApiException(409, InstitutionPlanService.MSG_OLDER);
            }
            InstNewsImport imp = new InstNewsImport();
            imp.setInstitutionId(instId);
            imp.setFileDate(fileDate);
            imp.setFileSha256(sha);
            imp.setFileBytes((long) raw.length);
            imp.setItemCount(r.rows.size());
            imp.setBatchId(batch);
            imp.setImportedBy(actor.getEmpNo());
            imp.setImportedAt(Times.nowIso());
            imp.setImportedVerified(actor.isVerified() ? 1 : 0);
            mapper.insertImport(imp);
            for (NewsCsv.Row n : r.rows) {
                InstNewsItem it = new InstNewsItem();
                it.setImportId(imp.getImportId());
                it.setInstitutionId(instId);
                it.setRowNo(n.row);
                it.setFieldCd(n.fieldCd);
                it.setTitle(n.title);
                it.setPress(n.press);
                it.setPublishedOn(n.publishedOn);
                it.setSrcUrl(n.url);
                it.setSummary(n.summary);
                it.setCheckedOn(n.checkedOn);
                it.setCollectorAgent(n.collectorAgent);
                mapper.insertItem(it);
            }
            // 성공 감사는 같은 트랜잭션 — 감사 없이 판이 생기지 않는다(기록 실패면 전체 롤백·500)
            planMapper.insertAct(instId, imp.getImportId(), ACTION_NEWS_IMPORT, "OK", r.rows.size(), sha, actor.getEmpNo(),
                    actor.isVerified() ? 1 : 0, ui.getScreen(), ui.getButton(), 1, Times.nowIso());
            // 열린 수집 요청 닫기(팀 결정 11-24: 뉴스 반입이 요청을 닫는다) — onImported 와 별개 경로(중2)
            collect.onNewsImported(instId, imp.getImportId(), actor, ui);
            Map<String, Object> out = new LinkedHashMap<>();
            out.put("import_id", imp.getImportId());
            out.put("institution_id", instId);
            out.put("item_count", r.rows.size());
            out.put("file_sha256", sha);
            return out;
        });
    }

    // ── 조회 ──
    /** 기관의 현재(가장 큰 IMPORT_ID) 뉴스 판. 판이 없으면 200 + has_news=false. 반입자 사번·SHA 는 싣지 않는다. */
    @Transactional(readOnly = true)
    public Map<String, Object> detail(String instId) {
        String inst = plans.canonicalOrNull(instId);
        if (inst == null) throw ApiException.notFound("institution not found");
        LocalDate today = today();
        InstNewsImport imp = mapper.selectLatestImport(inst);
        String planState = planMapper.selectLatestImport(inst) != null ? PLAN_FOUND : imp != null ? NEWS_ONLY : NOT_FOUND;
        Map<String, Object> out = new LinkedHashMap<>();
        out.put("institution_id", inst);
        out.put("name_ko", planMapper.selectInstitutionName(inst));
        out.put("today", today.toString());
        out.put("stale_months", InstitutionPlanService.STALE_MONTHS);
        out.put("plan_state", planState);
        out.put("has_news", imp != null);
        List<Map<String, Object>> items = new ArrayList<>();
        if (imp == null) {
            out.put("import_id", null);
            out.put("file_date", null);
            out.put("checked_on", null);
            out.put("window_from", null);
            out.put("window_to", null);
            out.put("item_count", 0);
            out.put("stale", false);
        } else {
            LocalDate checked = LocalDate.parse(imp.getFileDate());
            out.put("import_id", imp.getImportId());
            out.put("file_date", imp.getFileDate());
            out.put("checked_on", imp.getFileDate());
            out.put("window_from", checked.minusYears(1).toString());
            out.put("window_to", imp.getFileDate());
            out.put("item_count", imp.getItemCount());
            out.put("stale", InstitutionPlanService.isStale(imp.getFileDate(), today));
            for (InstNewsItem it : mapper.selectItemsOfImport(imp.getImportId())) {
                Map<String, Object> m = new LinkedHashMap<>();
                m.put("news_id", it.getNewsId());
                m.put("field_cd", it.getFieldCd());
                m.put("field_name", NewsCsv.fieldName(it.getFieldCd()));
                m.put("title", it.getTitle());
                m.put("press", it.getPress());
                m.put("published_on", it.getPublishedOn());
                m.put("url", it.getSrcUrl());
                m.put("summary", it.getSummary());
                m.put("checked_on", it.getCheckedOn());
                m.put("collector_agent", it.getCollectorAgent());
                m.put("stale", InstitutionPlanService.isStale(it.getCheckedOn(), today));
                items.add(m);
            }
        }
        out.put("items", items);
        return out;
    }

    // ── 보조 ──
    private String canonical(String raw) {
        String c = plans.canonicalOrNull(raw);
        if (c == null) throw ApiException.notFound("institution not found");
        return c;
    }

    private static Map<String, Object> status(Map<String, Object> m, String code) {
        m.put("status_cd", code);
        return m;
    }

    /** 파일 이름 → 확인일(ISO). 이름 형식·기관ID(대소문자 무시)·실제 달력 날짜를 본다. 원래 이름은 어디에도 저장하지 않는다. */
    static String fileDate(String instId, String original) {
        String name = original == null ? "" : original;
        int cut = Math.max(name.lastIndexOf('/'), name.lastIndexOf('\\'));
        if (cut >= 0) name = name.substring(cut + 1);
        Matcher m = NewsCsv.FILE_NAME.matcher(name);
        if (!m.matches()) throw ApiException.badRequest("파일 이름은 {기관ID}_{확인일YYYYMMDD}_news.csv 형식이어야 합니다.");
        if (!m.group(1).equalsIgnoreCase(instId)) throw ApiException.badRequest("파일 이름의 기관ID가 반입 대상 기관과 다릅니다.");
        String d = m.group(2);
        String iso = d.substring(0, 4) + "-" + d.substring(4, 6) + "-" + d.substring(6);
        try {
            LocalDate.parse(iso);
        } catch (DateTimeException e) {
            throw ApiException.badRequest("파일 이름의 날짜가 올바르지 않습니다.");
        }
        return iso;
    }

    private void failed(String instId, String outcome, String sha, Actor actor, BoardUiIds.Ui ui) {
        try {
            audit.record(instId, null, ACTION_NEWS_IMPORT, outcome, null, sha, actor, ui);
        } catch (RuntimeException ex) {
            LOG.error("inst-news audit failed outcome={}", outcome);   // 값·파일 이름 없음
        }
    }
}
```

```java
/**
 * 기관 관련 뉴스(060, NEXT 107). 조회 = 사업계획 조회와 같은 권한(map 키, 팀 결정 11-24). 반입 = {@link AdminGuard#require} 만(사업계획 반입과 같음).
 * 거부: 401(사번 없음)·403 은 AdminGuard/MenuGuard 가 접근 이력 DENIED 로 남기고, 반입 403 은 INST_PLAN_ACT 에도 NEWS_IMPORT/DENIED 로 남긴다.
 * ⚠️ 사번은 X-Emp-No 자기신고다. 앞단 인증 전에는 이 권한 검사도 보안 경계가 아니다.
 */
@RestController
public class InstitutionNewsController {

    private final InstitutionNewsService news;
    private final MenuGuard guard;
    private final AdminGuard admin;
    private final PlanAudit audit;

    public InstitutionNewsController(InstitutionNewsService news, MenuGuard guard, AdminGuard admin, PlanAudit audit) {
        this.news = news;
        this.guard = guard;
        this.admin = admin;
        this.audit = audit;
    }

    @GetMapping("/institutions/{institutionId}/news")
    public Map<String, Object> detail(@PathVariable String institutionId, HttpServletRequest req) {
        guard.require(req, InstitutionPlanController.VIEW_MENU);
        return news.detail(institutionId);
    }

    /** multipart {@code file}(이름 {기관ID}_{YYYYMMDD}_news.csv), {@code batch_id?}. 본문 상한은 BoardWriteLimitFilter + 서비스 이중 검사. */
    @PostMapping("/institutions/{institutionId}/news/import")
    public ResponseEntity<Map<String, Object>> importCsv(@PathVariable String institutionId,
                                                         @RequestParam(name = "file", required = false) MultipartFile file,
                                                         @RequestParam(name = "batch_id", required = false) String batchId,
                                                         HttpServletRequest req) {
        Actor actor = requireAdmin(req, institutionId, PlanUiIds.newsUpload());
        Map<String, Object> out = news.importUpload(institutionId, file, batchId, actor);
        req.setAttribute(AccessLogInterceptor.DETAIL, "inst-news import items=" + out.get("item_count"));
        return ResponseEntity.status(HttpStatus.CREATED).body(out);
    }

    private Actor requireAdmin(HttpServletRequest req, String inst, BoardUiIds.Ui ui) {
        try {
            return admin.require(req);   // 401/403 은 AdminGuard 가 DENIED 로 접근 이력에 남긴다
        } catch (ApiException e) {
            Actor a = Actor.of(req);
            if (a.isKnown()) {   // 사번 없는 401 은 감사 표를 늘리지 않는다(Plan·Head 선례)
                try {
                    audit.record(inst, null, InstitutionNewsService.ACTION_NEWS_IMPORT, "DENIED", null, null, a, ui);
                } catch (RuntimeException ignored) {
                    // 감사 실패가 원래 응답을 덮지 않게
                }
            }
            throw e;
        }
    }
}
```

```java
public class NewsDdlPairTest {

    private static String read(String d) throws IOException {

    private static List<String> inserts(String d) throws IOException {
        List<String> out = new ArrayList<>();
        boolean in = false;
        for (String line : Files.readAllLines(DB.resolve(d).resolve(FILE), StandardCharsets.UTF_8)) {
            if (line.contains("[INSERT 블록 시작")) in = true;
            else if (line.contains("[INSERT 블록 끝")) in = false;
            else if (in && line.startsWith("INSERT INTO COMMON_CODE")) out.add(line);
        }
        return out;
    }

    private static List<String> columns(String d, String table) throws IOException {
        List<String> out = new ArrayList<>();
        Set<String> skip = new HashSet<>(Arrays.asList("PRIMARY", "KEY", "CONSTRAINT", "UNIQUE", "INDEX", "FOREIGN", "CHECK"));
        Pattern word = Pattern.compile("^([A-Z][A-Z0-9_]*)\\b.*");
        boolean in = false;
        for (String raw : Files.readAllLines(DB.resolve(d).resolve(FILE), StandardCharsets.UTF_8)) {
            String line = raw.trim();
            if (line.startsWith("CREATE TABLE " + table + " (")) { in = true; continue; }
            if (!in) continue;
            if (line.startsWith(")")) break;
            Matcher m = word.matcher(line);
            if (m.matches() && !skip.contains(m.group(1))) out.add(m.group(1));
        }
        return out;
    }
```

## 5. 보안·위험·되돌리는 법

**security 반영 표**

| 항목 | 반영 |
|---|---|
| 중1 | 필터 `PLAN_IMPORT`를 `(plans\|news)`로 넓히고 시험을 추가했다(§3-11, 4-2) |
| 중2 | `onNewsImported`를 새로 만들었다. `APPLIED_IMPORT_ID` NULL, `CLOSE_REASON='NEWS'`(DDL 없음, 근거는 §2), 감사 `COLLECT_APPLY/NEWS`, 쪽지 '관련 뉴스로 대체' |
| 중3 | `Pii.scanExternal` 재사용 + NFKC 접은 사본에 나이·생년·괄호 나이. 시험은 우회 10종 + 오탐 8종 |
| 하1 | `failed()`에 action을 넣었다. 뉴스 파일 실패는 `NEWS_IMPORT`다 |
| 하2 | `MSG_SAME`·`MSG_OLDER` 상수 재사용(§3-7) |
| 하3 | 060 머리글에 `IMPORT_ID` 의미와 `CLOSE_REASON='NEWS'`를 적었다 |
| 하4 | 필터 `PLAN_COLLECT`에 `inbox/import`를 더했다(16KB) |
| 하5 | 열 이름 매핑, SCHEMA에 '순서 자유·9열 필수'. 예시는 표 순서로 맞췄다 |
| 하6 | 머리행 직후 `recs.size()-1 > 10`이면 즉시 400이다 |
| 하7 | 프런트 이관(텍스트로만 그리기) |

- **권한 검사**:
  - 반입은 `AdminGuard.require`만 쓴다. 비관리자는 403이고 접근 이력 DENIED와 `INST_PLAN_ACT(NEWS_IMPORT/DENIED)`가 남는다.
  - 사번 없는 401은 감사 표를 늘리지 않는다.
  - 조회는 `guard.require(req, "map")`이고, 사업계획 조회와 같은 권한이다.
  - **`X-Emp-No`는 자기신고**다. `IMPORTED_VERIFIED=0`이고 응답에 사번을 싣지 않는다. 서버 권한 검사는 업무 규칙이지 사칭 방지가 아니다.
- **접근 이력·감사**: SHA·행 수·결과 코드만 남는다. 제목·요약·URL·언론사·파일 이름은 안 남는다. 폴더 반입의 접근 이력 DETAIL은 건수뿐이다.
- **남은 위험**:
  - 요약이 원문 복사인지, 일반인 이름이 있는지는 서버가 못 가린다(data-auditor 표본 검수). 결정적으로 막는 것은 3줄·300자·제목과 같은 문장·PII 패턴뿐이다.
  - `scanExternal`은 가린 이메일(`a***@x.kr`)을 통과시킨다.
  - '65세 이상' 같은 정책 문구는 거부된다. '고령층' 등으로 바꾸게 SCHEMA에 안내했다(기획 확인 필요).
  - `(10)` 같은 괄호 숫자가 한글 바로 뒤에 오면 오탐이 난다(예: `청년(25)`). 한 파일 전체가 거부되므로 첫 표본에서 빈도를 본다.
  - 폴더 확인 예산(최신 100개·64MB·20초)을 두 종류가 나눠 쓴다. 100개에 도달하는 날은 qa가 본다.
  - 100파일을 한 번에 올리는 uploader의 multipart 합계 상한은 설정이 정한다(§3-12).
  - 폴더 반입 DENIED 감사의 `ACTION_CD`는 `IMPORT` 고정이다(종류를 모르는 단계).
- **되돌리는 법**:
  - 서버: 신규 파일(NewsCsv, InstitutionNewsService, InstitutionNewsController, InstitutionNewsMapper(+xml), 도메인 2개)을 지운다.
  - 서버: PlanInboxService는 이전 커밋으로 되돌린다.
  - 서버: PlanCollectService의 `onNewsImported`·`NEWS` 상수와 mapper `applyOpenNews`를 지운다.
  - 서버: 필터·PlanUiIds·PlanCsv 가시성 변경을 되돌린다.
  - DB: `DROP TABLE INST_NEWS_ITEM; DROP TABLE INST_NEWS_IMPORT; DELETE FROM COMMON_CODE WHERE CODE_GROUP='PLAN_ACTION' AND CODE='NEWS_IMPORT';`
  - 이미 `CLOSE_REASON='NEWS'`로 닫힌 요청은 되돌려도 `APPLIED` 상태로 남는다.
  - 기존 `/approvals`·`/tasks/{id}/approve`·`/menus`·골든 04·05·`Menus.MENUS`·`roles.js`·Python `server/`는 건드리지 않았다.

## 6. 이관 메모
- `[이관: 기획]` 뉴스로 닫힌 요청을 요청자 화면 `recent_applied`('new' 7일 배지)에 넣을지, 별도 표시로 뺄지 — 기다리는 것: 팀 판단(되돌리기 쉬움) — 근거: PlanCollectService.status 422~433행. 지금은 뉴스로 닫혀도 'new'로 뜬다. 서버는 `CLOSE_REASON='NEWS'`로 구분만 해 둔다.
- `[이관: 기획]` 요약에 '65세 이상' 같은 정책 문구를 허용할지(지금은 거부, 우회 안내만) — 근거: §5 남은 위험.

  - 규칙: 응답 문자열은 `esc()` 뒤에만 줄바꿈 처리하고, 링크는 `logic.safeHttpUrl`+`rel="noopener noreferrer"`를 쓴다(plans.js 103~111행 선례).
  - 폴더 확인 응답의 `items[].kind`·결과 `results[].kind`가 새로 생겼다. `max_import`가 50에서 100이 됐다(`frontend/js/plancollect.js`가 50을 하드코딩했는지 확인 필요 — 이 파일은 읽지 않았다).
  - 뉴스로 닫힌 요청은 `close_reason:'NEWS'`로 내려온다. 처리 화면이 'NEWS'를 그대로 보이지 않게 해야 한다.
- `[이관: 데이터]` 첫 표본에서 원문 복사·일반인 이름·기관장 나이·'(65)'·전각 숫자 혼입을 검수하고, 분야 5종 분류 일관성과 보도일이 기관과 무관한 기사인지 본다 — 근거: security 중3·설계 D7.
- `[이관: uploader security]` 100파일 일괄 시 multipart 요청 상한 설정 확인 — 값은 사용자가 확인.
- `[이관: main]` 060 번호는 확정이라고 받았다. 다른 세션이 060을 만들면 충돌하므로 적용 직전에 `ls db/mysql`로 한 번 확인한다.
