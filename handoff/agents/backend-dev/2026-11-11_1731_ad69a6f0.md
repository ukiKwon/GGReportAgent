팀 기본값 Q1(충돌 없는 후보는 영업팀 누구나 확정), Q2(본인 = 후보를 낸 사람), Q4(사진 교체는 누구나, 옛 사진 보관)는 그대로 유지합니다.

**끄면 404인 이유(503이 아닌 이유)**
1. 503은 M2의 "사진 처리 대기열 가득 참"에 씁니다. 같은 코드를 쓰면 모니터링에서 일시 과부하와 의도한 꺼짐을 구분하지 못합니다.
2. 503은 클라이언트·프록시가 다시 시도하는 신호입니다. 꺼짐은 오래 유지되는 설정입니다.
3. 꺼진 상태에서는 **DB를 건드리지 않고**(ACT 기록 포함) 경로가 없는 것처럼 답합니다. 그래서 Oracle에 DBA가 DDL을 적용하기 전에도 코드를 배포할 수 있습니다. 접근 이력(ACCESS_LOG)은 인터셉터가 404로 남깁니다.

### 3-3. ops 점검 쿼리 Q18 (`db/oracle/ops/integrity_check.sql`·`db/mysql/ops/integrity_check.sql` 맨 끝에 같은 문장)
```sql
-- Q18 기관장(026): 사번별 하루 열람 50 초과(건수만, 날짜는 UTC 기준 LOGGED_AT 앞 10자) / 기관당 CURRENT 둘 이상 / 머리당 ACTIVE 사진 둘 이상 / 기관 없음 / 머리 없는 칸
SELECT a.ACTOR_EMP_NO, SUBSTR(a.LOGGED_AT, 1, 10) AS DAY_UTC, COUNT(*) AS VIEWS
  FROM INST_HEAD_ACT a
 WHERE a.ACTION_CD IN ('VIEW', 'PHOTO_VIEW', 'UNMATCHED_VIEW') AND a.OUTCOME = 'OK'
 GROUP BY a.ACTOR_EMP_NO, SUBSTR(a.LOGGED_AT, 1, 10) HAVING COUNT(*) > 50;
SELECT h.INSTITUTION_ID, COUNT(*) AS N FROM INST_HEAD h WHERE h.STATUS_CD = 'CURRENT' GROUP BY h.INSTITUTION_ID HAVING COUNT(*) > 1;
SELECT p.HEAD_ID, COUNT(*) AS N FROM INST_HEAD_PHOTO p WHERE p.STATE_CD = 'ACTIVE' GROUP BY p.HEAD_ID HAVING COUNT(*) > 1;
SELECT h.HEAD_ID FROM INST_HEAD h WHERE h.INSTITUTION_ID IS NOT NULL
   AND NOT EXISTS (SELECT 1 FROM INSTITUTIONS i WHERE i.INSTITUTION_ID = h.INSTITUTION_ID);
SELECT t.ITEM_ID FROM INST_HEAD_ITEM t WHERE NOT EXISTS (SELECT 1 FROM INST_HEAD h WHERE h.HEAD_ID = t.HEAD_ID);
```

static <T> T runBounded(ThreadPoolExecutor pool, Callable<T> task, AtomicReference<ImageReader> holder, long timeoutMs) {
    Future<T> f;
    try { f = pool.submit(task); }
    catch (RejectedExecutionException e) { throw coded(503, "PHOTO_BUSY", "사진 처리 요청이 많습니다. 잠시 뒤 다시 올려 주세요."); }
    try { return f.get(timeoutMs, TimeUnit.MILLISECONDS); }
    catch (TimeoutException e) {
        ImageReader r = holder.get(); if (r != null) r.abort();   // cancel(true) 만으로는 디코드가 멈추지 않는다
        f.cancel(true); pool.remove((Runnable) f);                // 대기열에 남았으면 실행하지 않는다
        throw coded(400, "FILE_REJECTED", "사진을 처리하는 데 시간이 너무 오래 걸려 올릴 수 없습니다.");
    } catch (ExecutionException e) {
        if (e.getCause() instanceof ApiException) throw (ApiException) e.getCause();
        throw coded(400, "IMAGE_UNREADABLE", "사진을 읽을 수 없습니다. 일반 JPG/PNG로 다시 저장해 올려 주세요.");
    } catch (InterruptedException e) { Thread.currentThread().interrupt(); f.cancel(true);
        throw coded(400, "FILE_REJECTED", "사진 처리가 중단되었습니다. 다시 시도해 주세요."); }
}

private static BufferedImage decode(String fmt, byte[] data, AtomicReference<ImageReader> holder) throws IOException {
    ImageReader reader = jdkReader(fmt);                 // com.sun.imageio.plugins.* 만(외부 플러그인 배제)
    holder.set(reader);
    try (ImageInputStream iis = new MemoryCacheImageInputStream(new ByteArrayInputStream(data))) {  // 전역 setUseCache 금지
        reader.setInput(iis, true, true);                // 앞으로만 읽기, 메타데이터 무시
        int w = reader.getWidth(0), h = reader.getHeight(0);   // 머리글만 읽는다
        if (w > 6000 || h > 6000 || (long) w * h > 25_000_000L) throw coded(400, "IMAGE_TOO_LARGE_DIM", "사진의 가로·세로가 너무 큽니다.");
        if (w < 120 || h < 160) throw coded(400, "IMAGE_TOO_SMALL", "사진이 너무 작습니다(가로 120·세로 160 이상).");
        ImageReadParam p = reader.getDefaultReadParam();
        int s = subsample(w, h); if (s > 1) p.setSourceSubsampling(s, s, 0, 0);   // 메모리 상한
        BufferedImage src = reader.read(0, p);
        if (src == null) throw coded(400, "IMAGE_UNREADABLE", "사진을 읽을 수 없습니다.");
        return fit(src, w, h);
    } catch (IIOException e) {                            // CMYK·손상 등
        throw coded(400, "IMAGE_UNREADABLE", "사진을 읽을 수 없습니다. 일반 JPG/PNG로 다시 저장해 올려 주세요.");
    } finally { reader.dispose(); }
}
static int subsample(int w, int h) {
    double scale = Math.min(1.0, Math.min(600.0 / w, 800.0 / h));
    return Math.max(1, (int) Math.floor(1.0 / scale / 2.0));     // 목표 크기의 2배 해상도는 남긴다
}
static BufferedImage fit(BufferedImage src, int ow, int oh) {   // RGB(sRGB), 투명은 흰색, 600x800 안, 확대 없음
    double scale = Math.min(1.0, Math.min(600.0 / ow, 800.0 / oh));
    int tw = Math.max(1, (int) Math.round(ow * scale)), th = Math.max(1, (int) Math.round(oh * scale));
    BufferedImage dst = new BufferedImage(tw, th, BufferedImage.TYPE_INT_RGB);
    Graphics2D g = dst.createGraphics();
    try { g.setRenderingHint(RenderingHints.KEY_INTERPOLATION, RenderingHints.VALUE_INTERPOLATION_BILINEAR);
          g.setColor(Color.WHITE); g.fillRect(0, 0, tw, th); g.drawImage(src, 0, 0, tw, th, null); }
    finally { g.dispose(); }
    return dst;
}
static byte[] encode(BufferedImage rgb) throws IOException {
    ImageWriter w = jdkWriter("jpeg");
    ByteArrayOutputStream bos = new ByteArrayOutputStream();
    try (ImageOutputStream ios = new MemoryCacheImageOutputStream(bos)) {
        w.setOutput(ios);
        ImageWriteParam p = w.getDefaultWriteParam();
        p.setCompressionMode(ImageWriteParam.MODE_EXPLICIT); p.setCompressionQuality(0.85f);
        w.write(null, new IIOImage(rgb, null, null), p);      // 스트림·이미지 메타데이터 null
    } finally { w.dispose(); }
    byte[] out = bos.toByteArray();
    requireCleanJpeg(out);                                 // 자기 출력 검사 — 실패면 500, 저장 안 함
    return out;
}

**5-2. 마커 허용 목록과 EOI 뒤 0바이트 (M4 — 운영 코드와 테스트가 같은 함수를 씀)**

private static final Set<Integer> HEADER_OK = new HashSet<>(Arrays.asList(0xE0, 0xDB, 0xC0, 0xC4, 0xDA)); // APP0 DQT SOF0 DHT SOS
static void requireCleanJpeg(byte[] b) {
    if (b.length < 4 || (b[0] & 0xFF) != 0xFF || (b[1] & 0xFF) != 0xD8) throw dirty();
    int i = 2; boolean app0 = false, sos = false;
    while (i + 4 <= b.length) {
        if ((b[i] & 0xFF) != 0xFF) throw dirty();
        int m = b[i + 1] & 0xFF;
        if (!HEADER_OK.contains(m)) throw dirty();          // APP1(EXIF·XMP)·APP2(ICC)·APP13(IPTC)·COM 등 모두 거부
        int len = ((b[i + 2] & 0xFF) << 8) | (b[i + 3] & 0xFF);
        if (len < 2 || i + 2 + len > b.length) throw dirty();
        if (m == 0xE0) { if (app0 || len < 7 || b[i+4] != 'J' || b[i+5] != 'F' || b[i+6] != 'I' || b[i+7] != 'F' || b[i+8] != 0) throw dirty(); app0 = true; }
        i += 2 + len;
        if (m == 0xDA) { sos = true; break; }
    }
    if (!sos || !app0) throw dirty();
    for (; i + 1 < b.length; i++) {                        // 엔트로피 데이터: FF00(채움)·RSTn 만 허용
        if ((b[i] & 0xFF) != 0xFF) continue;
        int m = b[i + 1] & 0xFF;
        if (m == 0x00 || (m >= 0xD0 && m <= 0xD7)) { i++; continue; }
        if (m == 0xD9 && i + 2 == b.length) return;          // EOI 이고 그 뒤 0바이트
        throw dirty();
    }
    throw dirty();
}
private static ApiException dirty() { return new ApiException(500, "사진을 처리하지 못했습니다."); }

    int n = s.codePointCount(0, s.length());
    if (n == 0) return "";
    if (n == 1) return "*";

static String key(String s) {                     // NFKC + 공백·서식문자·가운뎃점 제거("국민 의힘" 우회 차단)

    StringBuilder b = new StringBuilder(n.length());
    for (int i = 0; i < n.length(); ) { int cp = n.codePointAt(i); i += Character.charCount(cp);
        if (Character.isWhitespace(cp) || Character.getType(cp) == Character.FORMAT || cp == 0x00B7 || cp == 0x30FB) continue;
        b.appendCodePoint(cp); }
    return b.toString();
}
public static List<Kind> scan(String text) {
    List<Kind> out = new ArrayList<>();
    if (text == null || text.isEmpty()) return out;
    String k = key(text);
    if (containsAny(k, PARTY_NAMES) || PARTY_WORDS.matcher(k).find() || partyRole(k)) out.add(Kind.PARTY);
    if (CRIME.matcher(k).find()) out.add(Kind.CRIME);
    if (HEALTH.matcher(k).find()) out.add(Kind.HEALTH);
    if (RELIGION.matcher(k).find()) out.add(Kind.RELIGION);
    if (FAMILY.matcher(k).find()) out.add(Kind.FAMILY);
    if (EVENT.matcher(k).find()) out.add(Kind.EVENT);
    String f = Pii.foldLoose(text);                  // 전각 숫자·대시류·'.' 구분자 정규화
    if (LANDLINE.matcher(f).find() || REP_NUMBER.matcher(f).find()) out.add(Kind.PHONE);
    return out;
}
private static boolean partyRole(String k) {

        if (!exempt) return true; }
    return false;
}

```java
// conflict: 단일 칸 후보 X 가 같은 머리의 확정값과 compareKey 가 다르거나, 같은 칸의 다른 열린 후보와 다르면 true(잠금 뒤 계산).
// owners: 충돌 상대 확정값의 {CREATED_BY, DECIDED_BY}(머리 단위는 현 CURRENT 머리의 두 값). proposer: X(또는 후보 머리)의 CREATED_BY.
static String blockCode(Action a, String role, String actor, String proposer, Set<String> owners, boolean conflict) {
    boolean lead = "영업팀장".equals(role) || "영업부장".equals(role);
    boolean self = actor.equals(proposer);
    if (a == Action.REJECT && self) return null;           // 본인 후보 회수는 언제나 가능
    if (!conflict) return null;                            // Q1: 충돌 없으면 영업팀 누구나(본인 포함, LOG SELF_FLAG=1)
    if (!lead) return "LEAD_ONLY";
    if (a == Action.CONFIRM && self) return "SELF_RESOLVE";      // 본인이 낸 값은 본인이 확정 못 함
    if (a == Action.REJECT && owners.contains(actor)) return "OWN_VALUE_GUARD";   // 자기 확정값 지키기 차단
    return null;                                           // 확정값 입력자가 남의 후보를 '확정'(자기 값 양보)하는 것은 허용
}
```

- "팀장이 없을 때만" 조건은 두지 않습니다. 부재 여부를 서버가 알 수 없고, 해소할 사람이 없어 막히는 쪽이 더 나쁘기 때문입니다.

## 10. 보안·위험·되돌리는 법
- **자기신고 인증(B1, 사용자가 위험을 수용함)**:
  - `X-Emp-No`만 바꾸면 누구나 영업팀장·부장으로 행세해 충돌 해소, 원문 열람, 사진 교체·복원을 할 수 있습니다. 권한표는 실수를 막는 업무 규칙이지 사칭을 막지 못합니다.
  - security 권장(SSO 전 기본 꺼짐)과 달리 사용자 결정으로 **기본값은 켬**입니다. 감사 사번은 자기신고이므로 `*_VERIFIED`/`EMP_VERIFIED=0`이면 화면에 '검증됨'을 표시하지 않습니다.
  - 끄는 법: `ggreport.inst-head.enabled=false` 후 재기동. 데이터는 그대로 남습니다.
- **403 경로**: 모든 403은 `MenuGuard.denied`로 ACCESS_LOG DENIED에 남고 ACT에도 DENIED로 남습니다. 사유는 고정 문구·코드뿐입니다. 대상이 없거나 다른 기관 것이면 404 HIDDEN입니다(id 존재를 숨김).
- **기록 원칙**: 접근 이력·ACT·LOG에는 id·코드·역할만 남깁니다. 이름·칸 값·쿼리값·파일 이름은 남기지 않고, 경로에는 숫자 id와 기관 id만 싣습니다. REASON은 개인정보·금지 패턴 검사를 거친 사유 문장뿐입니다.
- **디코더**:
  - 운영 JDK 8 업데이트 번호를 확인해야 합니다(2D·ImageIO 패치는 분기 CPU마다 나옴).
  - WAR로 배포하면(WebLogic·WebSphere) `java.awt.headless`가 자동으로 켜지지 않을 수 있습니다. JVM 옵션에 `-Djava.awt.headless=true`를 권장합니다.
  - 축소 읽기 덕분에 디코드 한 건의 메모리는 목표 크기의 약 4배 화소 수준이지만, 머리글 상한(2,500만 화소)은 그대로 둡니다.
- **금지 패턴의 한계**: 사전 기반이라 새 정당명·은어·외국어는 빠질 수 있고, 일반 단어 오탐도 남습니다(테스트 표로 고정). 주소·계좌·여권은 여전히 검출하지 못합니다(허용 칸 60자 한 줄로 위험을 줄임).
- **표시용 가림**: A3·U2는 영업 전원에게 원문을 줍니다. 대량 열람은 막지 않고 기록·WARN·Q18로 사후 점검합니다.
- **보존**: 옛 사진·FORMER·SUPERSEDED는 삭제 작업 없이 쌓입니다(설정 자리 -1). 사진 폴더는 백업 대상입니다.
- **되돌리기**:
  - 코드: 새 파일 삭제, 필터 패턴 두 줄과 분기 제거, `Pii.foldLoose` 제거. 기존 API·`/menus`·골든 04·05는 건드리지 않습니다.
  - DB: 머리말의 DROP·DELETE는 데이터가 사라지므로 운영에서 금지합니다. 운영에서는 스위치로 끕니다.
