## 3. 구현안

### 묶음 1 — 대시보드(NEXT 102)

**결정한 것** (팀 결정. 되돌리기 쉽다)

**행**
- `BID_PREP` 기준으로 기관당 한 줄만 둔다.
- 활성 건(CONFIRMED~WRITING)이 우선이다.
- `include_ended=true`일 때만, 활성 건이 없는 기관의 최신 CANCELLED 건을 보인다(확정 취소·중단).

**손 체크 권한**: 그 건의 **활성 담당자만** 체크한다(과제 체크 `setTask`와 같은 규칙).
- 영업팀장·영업부장은 담당자가 아니면 읽기만 한다(403).
- 담당자로 지명된 팀장은 체크할 수 있다.
- 이유: 쓰기 판정을 한 곳에 둔다. 담당자가 아닌 팀장이 손대면 기록과 업무 책임이 갈라진다. 사전준비 체크 규칙과도 같아진다.
- 팀장에게도 열지는 기획이 정한다(이관 참조).

**열 대상 사람**: `/preps`와 같다(영업팀·영업팀장·영업부장·디자이너).
- 디자이너에게는 손 칸의 `by_name`(체크한 사람)을 주지 않는다.

**손 칸 값과 날짜 규칙**
- `status_cd` ∈ {NONE(비움·되돌림), IN_PROGRESS(진행 중), DONE(완료), NA(해당 없음)}, 그리고 `done_date`(YYYY-MM-DD).
- DONE: 날짜가 반드시 있어야 하고 오늘(KST) 이전이어야 한다.
- IN_PROGRESS: 날짜는 선택이고 오늘 이전이어야 한다.
- NA·NONE: 날짜가 없어야 한다.
- 2000-01-01보다 앞선 날짜는 받지 않는다.

**동시 수정**: 본문의 `base_rev`가 지금 개정 번호와 다르면 409 `STALE_CHECK`.

**이력과 감사**
- 기록은 추가 전용 표 하나(`BID_PREP_CHECK`)에 둔다. 현재 값은 최대 REV_NO인 줄이다(037 NOTICE_ROUND_LOG와 같은 방식).
- 성공 감사 줄은 **업무 데이터와 같은 트랜잭션**에 쓴다. NEXT 70의 열린 하 (c)를 이 새 경로에서는 처음부터 지킨다.
- 실패 줄은 컨트롤러가 따로 커밋한다.

**PrepService는 고치지 않는다.** 읽기 창 3줄만 연다(아래 1-a). 판정 규칙을 복제하지 않으려는 것이다. 049와 겹치지 않게 PrepController는 건드리지 않고 새 컨트롤러를 둔다.

    @Transactional(readOnly = true)
    public Map<String, Object> list(SysUser me, boolean includeEnded) {

            }
        }
        Map<String, Map<String, Object>> notice = new HashMap<>();
        Object items = notices.current(me.getEmpNo()).get("items");
        if (items instanceof List) {
            for (Object o : (List<?>) items) {
                @SuppressWarnings("unchecked") Map<String, Object> n = (Map<String, Object>) o;

        Map<String, Map<String, PrepBoardCheck>> checks = new HashMap<>();
        for (PrepBoardCheck c : mapper.selectCurrent()) {
            Map<String, PrepBoardCheck> m = checks.get(c.getBidCaseId());
            if (m == null) { m = new HashMap<>(); checks.put(c.getBidCaseId(), m); }
            m.put(c.getColCd(), c);
        }
        String today = Times.todayKst();
        List<Map<String, Object>> rows = new ArrayList<>();
        for (BidPrep p : pick.values()) {
            rows.add(row(me, designer, p, notice.get(p.getInstitutionId()),
                    checks.containsKey(p.getBidCaseId()) ? checks.get(p.getBidCaseId()) : Collections.<String, PrepBoardCheck>emptyMap(),
                    today));
        }
        Map<String, Object> out = new LinkedHashMap<>();
        out.put("columns", columns());
        out.put("groups", PrepBoardColumns.GROUPS);

    private Map<String, Object> row(SysUser me, boolean designer, BidPrep p, Map<String, Object> notice,
                                    Map<String, PrepBoardCheck> checks, String today) {
        String bid = p.getBidCaseId();
        List<BidPrepTask> ts = preps.selectTasks(bid);
        Map<String, String> st = ts.isEmpty() ? Collections.<String, String>emptyMap() : prep.taskStatesForBoard(p, ts);
        boolean assignee = assignments.isActiveAssignee(bid, me.getEmpNo());
        List<String> names = new ArrayList<>();
        for (BidAssigneeView v : assignMapper.selectActiveAssignees(bid)) { names.add(v.getName()); }
        SysUser confirmer = p.getConfirmedBy() == null ? null : users.selectByEmpNo(p.getConfirmedBy());
        String board = null;
        for (String rc : preps.selectBoardResults(bid)) {
            if (rc != null && !rc.trim().isEmpty()) { board = rc.trim(); break; }
        }
        Map<String, Object> m = new LinkedHashMap<>();
        m.put("bid_case_id", bid);
        m.put("institution_id", p.getInstitutionId());
        m.put("institution_name", p.getInstitutionName());
        String due = p.getContractEnd();
        m.put("bid_expected_date", due == null || due.trim().isEmpty() ? null : due.trim());
        m.put("state_cd", p.getStateCd());
        m.put("state_name", PrepService.stateNameForBoard(p));
        m.put("ended", PrepService.CANCELLED.equals(p.getStateCd()));
        m.put("confirmed_at", p.getConfirmedAt());
        m.put("confirmed_by_name", confirmer == null ? null : confirmer.getName());   // 사번은 싣지 않는다
        m.put("assignee_names", names);
        m.put("current_banks", currentBanks(p.getInstitutionId(), today));
        m.put("board_result", board);
        m.put("can_view", prep.canSeeForBoard(me, p));
        m.put("can_check", assignee && PrepService.TASK_STATES.contains(p.getStateCd()));
        Map<String, Object> cells = new LinkedHashMap<>();
        for (PrepBoardColumns.Col c : PrepBoardColumns.ALL) {
            cells.put(c.cd, PrepBoardColumns.AUTO.equals(c.kind)
                    ? autoCell(c.cd, p, ts, st, notice, board) : manualCell(checks.get(c.cd), designer));
        }
        m.put("cells", cells);
        return m;

    private Map<String, Object> autoCell(String cd, BidPrep p, List<BidPrepTask> ts, Map<String, String> st,
                                         Map<String, Object> notice, String board) {
        if ("NOTICE_CHECK".equals(cd)) {   // 공고 상태 기록(037) 지금 회차의 최신 판정이 있으면 확인함 — 매핑은 data 확인 대상
            if (notice == null) { return cell(NONE, null, "AUTO", null); }
            String at = String.valueOf(notice.get("handled_at"));
            return cell(DONE, at.length() >= 10 ? at.substring(0, 10) : null, "AUTO", (String) notice.get("status_cd"));
        }
        if ("INST_ANALYSIS".equals(cd)) { return taskCell(ts, st, "T1", null); }
        if ("PROFIT".equals(cd)) { return taskCell(ts, st, "T3", null); }
        if ("BOARD".equals(cd)) { return taskCell(ts, st, "T5", board); }        // 부결이어도 완료(사용자 11-11 ④), 꼬리표는 detail
        if ("SUBMIT_DOCS".equals(cd)) { return taskCell(ts, st, "T4", null); }   // RFP 없으면 NA
        if ("PROPOSAL".equals(cd)) {
            for (TaskSummary t : tasks.selectSummaries(p.getBidCaseId())) {
                if (Teams.DESIGNER_TEAM.equals(t.getTeam()) && Teams.FINAL_STATUS.equals(t.getStatus())) {
                    return cell(DONE, null, "AUTO", null);
                }
            }
            return cell(PrepService.WRITING.equals(p.getStateCd()) ? IN_PROGRESS : NONE, null, "AUTO", null);
        }
        return cell(NONE, null, "AUTO", null);
    }

    private static Map<String, Object> taskCell(List<BidPrepTask> ts, Map<String, String> st, String taskCd, String detail) {
        String s = st.get(taskCd);
        if ("DONE".equals(s)) {
            String at = null;
            for (BidPrepTask t : ts) {
                if (taskCd.equals(t.getTaskCd()) && t.getDoneAt() != null && t.getDoneAt().length() >= 10) { at = t.getDoneAt().substring(0, 10); }
            }
            return cell(DONE, at, "AUTO", detail);
        }
        if ("NOT_APPLICABLE".equals(s)) { return cell(NA, null, "AUTO", detail); }
        return cell(NONE, null, "AUTO", s == null ? "NOT_OPENED" : s);   // 개설 전·잠김·할 일·준비 중
    }

    private static Map<String, Object> manualCell(PrepBoardCheck c, boolean designer) {
        Map<String, Object> m = cell(c == null ? NONE : c.getStatusCd(), c == null ? null : c.getDoneDate(), "MANUAL", null);
        m.put("rev_no", c == null ? 0 : c.getRevNo());
        m.put("by_name", c == null || designer ? null : c.getActorName());
        m.put("emp_verified", c != null && c.getEmpVerified() == 1);   // false = 자기신고
        m.put("saved_at", c == null ? null : c.getSavedAt());
        return m;
    }

    private static Map<String, Object> cell(String status, String date, String source, String detail) {
        Map<String, Object> m = new LinkedHashMap<>();
        m.put("status_cd", status);
        m.put("done_date", date);
        m.put("source", source);
        m.put("detail_cd", detail);
        return m;
    }

    private List<Map<String, Object>> currentBanks(String inst, String today) {
        List<Map<String, Object>> out = new ArrayList<>();
        for (BankContract c : banks.selectLatestValid(inst)) {
            if (c.getTermTo() == null || c.getTermTo().compareTo(today) < 0) { continue; }   // 약정이 끝난 줄은 '현 금고'가 아니다
            Map<String, Object> b = new LinkedHashMap<>();
            b.put("rank_cd", c.getRankCd());
            b.put("bank_name", c.getBankName() != null ? c.getBankName() : c.getBankNameEtc());

            out.add(b);
        }
        return out;
    }

    // ── 손 체크 저장 ──────────────────────────────────────────────────
    /**
     * 순서(security F4·F5 틀): 담당자(403) → 열 형식·존재(404) → 손 칸·1단계(409 NOT_MANUAL·COLUMN_NOT_OPEN) → 입력(400) →
     * 건 잠금(404·409 STATE_CHANGED) → 개정 번호(409 STALE_CHECK) → 같은 값이면 저장 없이 saved=false → 추가 + 감사(같은 트랜잭션).
     */
    @Transactional
    public Map<String, Object> save(SysUser me, Actor actor, BoardUiIds.Ui ui, String bidCaseId, String colRaw,
                                    PrepBoardIn.Check in) {
        if (!assignments.isActiveAssignee(bidCaseId, me.getEmpNo())) {
            throw new ApiException(403, "이 입찰 건의 담당자만 체크할 수 있습니다.");
        }
        PrepBoardColumns.Col col = PrepBoardColumns.byCode(colRaw);
        if (col == null) {
            throw ApiException.notFound("board column not found");
        }
        if (!PrepBoardColumns.MANUAL.equals(col.kind)) {
            throw coded(409, "NOT_MANUAL", "시스템 기록으로 채워지는 칸이라 직접 체크할 수 없습니다.");
        }
        if (col.phase != 1) {
            throw coded(409, "COLUMN_NOT_OPEN", "아직 체크를 열지 않은 칸입니다.");
        }
        String status = in == null || in.getStatusCd() == null ? "" : in.getStatusCd().trim();
        if (!STATUSES.contains(status)) {
            throw coded(400, "BAD_STATUS", "상태는 진행 중·완료·해당 없음·비움 중 하나여야 합니다.");
        }
        String date = checkedDate(status, in.getDoneDate());
        Integer base = in.getBaseRev();
        if (base == null || base.intValue() < 0) {
            throw coded(400, "BAD_VALUE", "base_rev가 필요합니다.");
        }
        String state = preps.selectStateForUpdate(bidCaseId);   // 건 행 잠금 — 같은 건의 동시 저장을 줄 세운다
        if (state == null) {
            throw ApiException.notFound("prep not found");
        }
        if (!PrepService.TASK_STATES.contains(state)) {
            throw coded(409, "STATE_CHANGED", "그 사이 상태가 바뀌었습니다. 새로 고친 뒤 다시 시도하세요.");
        }
        PrepBoardCheck cur = mapper.selectCurrentOne(bidCaseId, col.cd);
        int curRev = cur == null ? 0 : cur.getRevNo();
        if (curRev != base.intValue()) {
            throw coded(409, "STALE_CHECK", "다른 사람이 먼저 바꿨습니다. 새로 고친 뒤 다시 시도하세요.");
        }
        String curStatus = cur == null ? NONE : cur.getStatusCd();
        String curDate = cur == null ? null : cur.getDoneDate();
        boolean same = curStatus.equals(status) && (curDate == null ? date == null : curDate.equals(date));
        String now = Times.nowIso();
        PrepBoardCheck saved = cur;
        if (!same) {
            PrepBoardCheck c = new PrepBoardCheck();
            c.setBidCaseId(bidCaseId); c.setColCd(col.cd); c.setRevNo(curRev + 1);
            c.setStatusCd(status); c.setDoneDate(date); c.setPrevStatusCd(cur == null ? null : curStatus); c.setPrevDoneDate(curDate);
            c.setActorEmpNo(me.getEmpNo()); c.setActorName(me.getName() == null ? "" : me.getName());
            c.setEmpVerified(BoardMaterialService.verified(actor));
            c.setScreenId(ui.getScreen()); c.setButtonId(ui.getButton()); c.setUiValid(ui.isValid() ? 1 : 0); c.setSavedAt(now);
            try {
                mapper.insertCheck(c);
            } catch (DuplicateKeyException e) {   // 잠금을 지나친 동시 저장의 마지막 방어선
                throw coded(409, "STALE_CHECK", "다른 사람이 먼저 바꿨습니다. 새로 고친 뒤 다시 시도하세요.");
            }
            saved = c;
        }
        audit.record(bidCaseId, ACTION, "OK", state, PrepBoardColumns.AUDIT_PREFIX + col.cd, actor, ui);   // 같은 트랜잭션 — 저장이 되돌아가면 감사도 되돌아간다
        Map<String, Object> out = new LinkedHashMap<>();
        out.put("bid_case_id", bidCaseId);
        out.put("col_cd", col.cd);
        out.put("saved", !same);
        out.put("cell", manualCell(saved, false));
        return out;
    }

    /** DONE 은 날짜 필수, IN_PROGRESS 는 선택, NA·NONE 은 날짜 없음. 날짜는 실제 달력 날짜, 2000-01-01~오늘(KST). */
    private static String checkedDate(String status, String raw) {
        String d = raw == null ? "" : raw.trim();
        if (NA.equals(status) || NONE.equals(status)) {
            if (!d.isEmpty()) { throw coded(400, "BAD_DATE", "해당 없음·비움에는 날짜를 넣지 않습니다."); }
            return null;
        }
        if (d.isEmpty()) {
            if (DONE.equals(status)) { throw coded(400, "BAD_DATE", "완료에는 날짜가 필요합니다."); }
            return null;
        }
        LocalDate v;
        try {
            v = LocalDate.parse(d);   // ISO_LOCAL_DATE 는 STRICT — 2026-02-30 은 예외
        } catch (DateTimeParseException e) {
            throw coded(400, "BAD_DATE", "날짜는 YYYY-MM-DD 형식이어야 합니다.");
        }
        if (v.isBefore(MIN_DATE) || v.isAfter(LocalDate.parse(Times.todayKst()))) {
            throw coded(400, "BAD_DATE", "날짜는 오늘 이전이어야 합니다.");
        }
        return v.toString();
    }

    private static List<Map<String, Object>> columns() {
        List<Map<String, Object>> out = new ArrayList<>();
        for (PrepBoardColumns.Col c : PrepBoardColumns.ALL) {
            Map<String, Object> m = new LinkedHashMap<>();
            m.put("col_cd", c.cd); m.put("label", c.label); m.put("group", c.group);
            m.put("kind", c.kind); m.put("phase", c.phase); m.put("editable", c.editable());
            out.add(m);
        }
        return out;
    }

    private static Map<String, String> statusNames() {
        Map<String, String> m = new LinkedHashMap<>();
        m.put(NONE, "기록 없음"); m.put(IN_PROGRESS, "진행 중"); m.put(DONE, "완료"); m.put(NA, "해당 없음");
        return m;
    }

    private static String role(SysUser u) { return u.getRole() == null ? "" : u.getRole().trim(); }

    private static ApiException coded(int status, String code, String message) {
        Map<String, Object> d = new LinkedHashMap<>();
        d.put("code", code);
        d.put("message", message);
        return ApiException.withDetail(status, d);
    }
}

            LOG.error("대시보드 체크 실패(응답 500): case={} cause={}", auditBid, e.getClass().getSimpleName());

    private void fail(String bid, String outcome, String before, String col, Actor actor, BoardUiIds.Ui ui) {

            LOG.warn("대시보드 실패 감사를 남기지 못했다: outcome={} cause={}", outcome, ex.getClass().getSimpleName());
        }
    }

    private static String caseKey(String bid) {
        String b = bid == null ? "" : bid.trim();
        return b.matches("[A-Za-z0-9._-]{1,64}") ? b : NO_CASE;
    }

### 묶음 2 — 개설 신청 '승인할 팀장' 칸

**규칙**
- 본문 `approver_emp_no`는 **선택 칸**이다.
  - 비우면 지금처럼 결재 체인으로 정한다. 그래서 기존 시험·지금 화면이 그대로 돈다.
  - 값이 있으면 다음을 모두 만족해야 한다. 아니면 400 `APPROVER_INVALID`이고, 문구 하나로 응답해 어느 조건에서 걸렸는지 드러내지 않는다.
    - 사번 형식
    - 사용 중(ACTIVE)
    - 역할이 영업팀장
    - 지명자가 아님
    - 신청자보다 직급이 엄격히 높음(`Ranks.mayApprove`)
- **팀장이 관련되면 부장 규칙은 유지한다.** 신청자가 팀장이거나 지명자에 팀장이 있는 경우다.
  - 이때 칸에 값을 넣으면 **400 `HEAD_APPROVES`**로 돌려보낸다. 조용히 부장에게 보내지 않는다.
  - 화면은 그 조건이면 칸을 숨기거나 비운다.

**유지를 권장하는 이유**
- ① `applyOpen:451`이 승인 순간에 같은 규칙을 다시 검사한다. 규칙을 빼면 두 군데를 고쳐야 하고, 이미 올라간 신청과 어긋난다.
- ② 팀장이 같은 직급 팀장을 담당자로 지명하고 그 팀장(또는 동료 팀장)이 승인하면 이해 충돌이 된다. 팀장이 신청자일 때는 `Ranks.mayApprove`가 같은 직급 승인을 원래 막는다(`Ranks.java:62-64`).
- ③ 담당자 변경 결재(019)와 같은 규칙이다.

**화면이 쓸 팀장 목록**: 새 API 없이 `GET /assignment-candidates`를 재사용한다.

- 이 목록은 영업팀·팀장·부장만 받는다. 신청자는 영업팀·팀장이라 열람 범위가 같다.

## 5. 보안·위험·되돌리는 법 (security가 볼 점)

1. **403 경로**

   - 저장: 담당자 검사가 건·열 조회보다 먼저 온다(F4). 그래서 없는 건과 남의 건이 같은 403이다. 형식 밖·모르는 열은 404이고 감사 TASK_CD는 NULL이다(F5).
   - 401(사번 없음)은 ACCESS_LOG에만 남긴다.
2. **자기신고 한계**: X-Emp-No·화면·버튼은 위조할 수 있다.
   - BID_PREP_CHECK·ACT의 `EMP_VERIFIED=0`을 "검증됨"으로 표시하지 않는다.
   - 응답 `emp_verified`도 사실만 준다.
   - 담당자만 체크하게 한 규칙은 실수 방지이지 사칭 방지가 아니다.
3. **기록하지 않는 것**: 접근 이력과 감사에는 상태값·날짜·이름·쿼리값(`include_ended`)을 넣지 않는다. 업무 값은 BID_PREP_CHECK에만 둔다.
4. **열람 범위(검토 요청)**: 손 칸 값(위원회 진행·날짜)과 체크한 사람 이름이 영업팀 **전원**에게 보인다. 지금 엑셀이 팀 공유라는 전제를 기획이 확인해야 한다. 디자이너에게는 이름을 뺐다.
5. **감사 트랜잭션**: 성공 ACT를 저장과 같은 트랜잭션에 넣었다(NEXT 70 열린 하 (c)를 이 경로에서는 해소). 감사가 실패하면 저장도 되돌아가고 500을 낸다.
6. **동시성**
   - 건 행 FOR UPDATE + `base_rev` + PK가 세 겹으로 막는다.
   - 목록은 사실 판정을 다시 맞추지 않는다. T3·T5 값은 상세를 열 때까지 늦게 반영될 수 있다(`/preps`와 같은 성질).
7. **목록 비용**: 행마다 질의가 5번 정도 나간다(과제·담당·금고·이사회·작업). 수십 건이면 문제없다. 수백 건이 되면 묶음 질의로 바꾼다.
8. **묶음 2**
   - 결재자를 클라이언트가 고르게 되므로 서버 검증이 유일한 방어선이다. 활성·역할·직급·지명자 제외를 서버가 다시 보고, 대결 불가(NO_PROXY)와 `applyOpen` 재검사는 그대로다.
   - 오류는 문구 하나라서 "그 사번이 있는지"를 따로 알려 주지 않는다. 다만 후보 목록 자체가 영업팀에 공개되어 있어 위험은 낮다.
9. **되돌리기**
   - 묶음 2: 코드만 되돌린다. payload의 `approver_pick`은 옛 서버가 무시한다. 대기 중인 신청은 결재선 행대로 처리된다.
   - 묶음 1: 새 파일을 지우고 1-a 3줄·1-h를 되돌린다. DB는 `DROP TABLE BID_PREP_CHECK`(데이터 소멸)이고, 운영에서는 표를 남겨 두고 서버만 내리는 쪽을 권장한다.
