## 2. 요구/원인 요약

**연도별 유치 기록 — 새 표 없이 039로 된다(결론)**
- 039는 기관별 약정 줄을 추가 전용으로 쌓는다. 키는 `(INSTITUTION_ID, CONTRACT_NO, REV_NO)`이고 기간·순위·은행·출처가 있다(`db/oracle/039_bank_contract.sql:3-5,26-56`).
- 과거 기간도 받는다:
  - 기간 검사는 1990~2100 범위만 본다. 과거를 막는 규칙이 없다(`BankContractRules.java:115-124`).
  - 겹침 검사는 같은 순위끼리 기간이 겹칠 때만이다(`:73-92`). 지난 약정과 현재 약정은 공존한다.
  - 출처는 담당자 확인(STAFF)이면 링크가 없어도 된다(`:165`).
- 화면도 이미 `term_state=PAST` 줄을 '만료' 묶음으로 나눠 보인다(`frontend/js/bankcontract.js:129,191`).
- 그래서 **'지난 약정 줄'을 쌓으면 그것이 기관별 연도별 유치 기록이다.** 연도별 '국민은행(B02) 유치 여부'는 서버가 계산해 내보낸다(새 순수 클래스 `BankYears`).
- 초기 적재는 하지 않는다:
  - LOFIN_2026·KB_VERIFIED는 **화면 자료 파일**이다(`frontend/data/kb-verified.js:1-9`). 서버 DB에는 없다.
  - 내용도 2026.1.1. 기준 '현재' 약정뿐이라 과거 연도 근거가 되지 못한다.
  - 근거 없는 행 자동 생성 금지 원칙에 따라 서버 시드로 줄을 만들지 않는다. 과거 연도 행안부 파일 반입은 열린 질문 Q1이다.
- '기록 없음'은 '국민은행 아님'이 아니다. 연도 상태는 셋으로 구분한다: `KB` / `OTHER`(기록된 줄은 있으나 국민은행 없음) / `NO_RECORD`.

**태그 기본값은 화면이 판정해 보낸다(권장)**
- 판정 근거인 LOFIN_2026·KB_VERIFIED가 화면에만 있다.
- 서버의 039 줄은 아직 드물다. 서버가 판정하면 불완전한 근거로 '신규유치'를 잘못 기본 선택한다.
- 서버는 두 가지를 한다:
  - 태그 코드를 코드표로 검사한다.
  - 목록 응답의 `bank.kb_now`(039 기준 KB/OTHER/NO_RECORD)를 같이 내준다. 화면은 직접 입력 줄 > LOFIN 순으로 합친다(`kbboard.js:121`의 direct 우선과 같음).

**권한**
- 읽기: `map` 조회. 모든 역할의 기본값이 켜짐이다(`Menus.java:85`). 디자이너는 보기만 된다.
- 쓰기: 기관 레코드 수정 권한(`MenuGuard.requireInstitutionEdit`, `MenuGuard.java:49`) **그리고** `HeadRules.isSales`(`HeadRules.java:30`). 039와 같은 두 겹이다(`BankContractService.java:54-58`).
- 빼기: 사용자 답("누구나 넣고 뺌")에 따라 **영업 계열 누구나**다. 039의 '본인·팀장만 취소'와 다르다.

**덤 — NEXT 94①도 해소된다**

package com.kbstar.kgi.ggreport.web.service;

import com.kbstar.kgi.ggreport.web.support.HeadForbidden;
import com.kbstar.kgi.ggreport.web.support.Pii;
import com.kbstar.kgi.ggreport.web.web.ApiException;
import java.util.*;

/** 자유 글 칸 검사(043 메모·취소 사유, 044 메모). 개인정보 → 422 PII_BLOCKED, 정당·전화번호 → 422 {forbiddenCode}.
 *  응답에는 종류·개수만(입력값 없음). BankContractRules.Screen 과 같은 기준 — 나중에 하나로 합칠 것. */
final class MemoScreen {
    private final String forbiddenCode, forbiddenMsg;
    private final Map<String, Integer> pii = new LinkedHashMap<String, Integer>();
    private final List<HeadForbidden.Kind> forb = new ArrayList<HeadForbidden.Kind>();

    MemoScreen(String forbiddenCode, String forbiddenMsg) { this.forbiddenCode = forbiddenCode; this.forbiddenMsg = forbiddenMsg; }

    MemoScreen free(String t) {
        if (t == null) return this;
        for (Pii.Finding f : Pii.scanLoose(t)) bump(f.getKind());
        for (HeadForbidden.Kind k : HeadForbidden.scan(t)) {
            if ((k == HeadForbidden.Kind.PHONE || k == HeadForbidden.Kind.PARTY) && !forb.contains(k)) forb.add(k);
        }
        return this;
    }

    MemoScreen name(String t) { if (t != null && BankContractRules.hasPersonName(t)) bump("NAME"); return this; }

    void throwIfAny() {
        if (!pii.isEmpty()) {
            List<Map<String, Object>> kinds = new ArrayList<Map<String, Object>>();
            for (Map.Entry<String, Integer> e : pii.entrySet()) {
                Map<String, Object> k = new LinkedHashMap<String, Object>();
                k.put("kind", e.getKey()); k.put("count", e.getValue()); kinds.add(k);
            }
            String msg = "개인정보로 보이는 값이 있어 저장하지 않았습니다. 해당 부분을 지우고 다시 입력해 주세요.";
            if (pii.containsKey("NAME")) msg += " 사람 이름은 적지 말아 주세요.";
            throw unprocessable("PII_BLOCKED", msg, kinds);
        }
        if (!forb.isEmpty()) {
            List<Map<String, Object>> kinds = new ArrayList<Map<String, Object>>();
            for (HeadForbidden.Kind k : forb) {
                Map<String, Object> m = new LinkedHashMap<String, Object>();
                m.put("kind", k.name()); m.put("label", k.getLabel()); kinds.add(m);
            }
            throw unprocessable(forbiddenCode, forbiddenMsg, kinds);
        }
    }

    private void bump(String k) { Integer n = pii.get(k); pii.put(k, n == null ? 1 : n + 1); }

    private static ApiException unprocessable(String code, String msg, Object kinds) {
        Map<String, Object> d = new LinkedHashMap<String, Object>();
        d.put("code", code); d.put("message", msg); d.put("kinds", kinds);
        return ApiException.withDetail(422, d);
    }
}

package com.kbstar.kgi.ggreport.web.service;

import com.kbstar.kgi.ggreport.web.domain.BidTarget;

/** 올해 목표 기관(043) 입력 검사 — 순수 로직. 오류 문구는 고정 문구뿐(입력값·내부 정보 없음). 글자 규칙은 BankContractRules.text 와 같다. */
final class BidTargetRules {

    static final String G_TAG = "TARGET_TAG", G_CANCEL = "TARGET_CANCEL_REASON", CANCEL_ETC = "ETC";
    static final int YEARS_AHEAD = 2;
    private static final Pattern CODE = Pattern.compile("[A-Z0-9_]{1,20}");
    static final Pattern EMP_NO = Pattern.compile("[0-9]{7}");
    static final String FORBIDDEN_MSG = "목표 기관 기록에 넣을 수 없는 내용(정당·전화번호)이 있습니다. 해당 부분을 지우고 다시 입력해 주세요.";

    static final class Parsed { int year; String tag, memo, owner; }
    static final class CancelParsed { String reasonCd, reasonEtc; }

    private BidTargetRules() { }

    static boolean yearSelectable(int y, int thisYear) { return y >= thisYear && y <= thisYear + YEARS_AHEAD; }

    /** keepYear = 고치기일 때 지금 목표 연도(넣기면 null). 안 보내면 넣기는 올해, 고치기는 그대로. 그대로 두는 연도는 지난해여도 허용(1월에 메모만 고치기). */
    static Parsed parse(BidTargetIn in, int thisYear, Integer keepYear, BankContractRules.CodeCheck codes) {
        Parsed p = new Parsed();
        Integer y = in.getTargetYear() != null ? in.getTargetYear() : (keepYear != null ? keepYear : Integer.valueOf(thisYear));
        boolean unchanged = keepYear != null && y.intValue() == keepYear.intValue();
        if (!unchanged && !yearSelectable(y, thisYear)) throw bad("목표 연도는 올해부터 2년 뒤까지 고를 수 있습니다.");
        p.year = y;
        p.tag = code(in.getTagCd(), G_TAG, codes, "태그를 목록에서 골라 주세요.");
        p.memo = BankContractRules.text(in.getMemo(), 100, "메모는 100자 이내여야 합니다.");
        String o = in.getOwnerEmpNo() == null ? null : in.getOwnerEmpNo().trim();
        if (o != null && o.isEmpty()) o = null;
        if (o != null && !EMP_NO.matcher(o).matches()) throw bad(BidTargetService.OWNER_MSG);
        p.owner = o;
        new MemoScreen("TARGET_FORBIDDEN", FORBIDDEN_MSG).free(p.memo).throwIfAny();
        return p;
    }

    static CancelParsed parseCancel(BidTargetCancelIn in, BankContractRules.CodeCheck codes) {
        CancelParsed c = new CancelParsed();
        c.reasonCd = code(in.getCancelReasonCd(), G_CANCEL, codes, "빼는 사유를 목록에서 골라 주세요.");
        String etc = BankContractRules.text(in.getCancelReasonEtc(), 50, "기타 사유는 50자 이내여야 합니다.");
        if (CANCEL_ETC.equals(c.reasonCd)) {
            if (etc == null) throw bad("기타를 고르면 사유를 적어야 합니다.");
            c.reasonEtc = etc;
        } else if (etc != null) {
            throw bad("사유 직접 입력은 '기타'를 고를 때만 씁니다.");
        }
        new MemoScreen("TARGET_FORBIDDEN", FORBIDDEN_MSG).free(c.reasonEtc).name(c.reasonEtc).throwIfAny();
        return c;
    }

    static boolean same(BidTarget c, Parsed p) {
        return c.getTargetYear() == p.year && Objects.equals(c.getTagCd(), p.tag)
                && Objects.equals(c.getMemo(), p.memo) && Objects.equals(c.getOwnerEmpNo(), p.owner);
    }

    private static String code(String raw, String group, BankContractRules.CodeCheck codes, String msg) {
        String v = raw == null ? null : raw.trim();
        if (v == null || !CODE.matcher(v).matches() || !codes.enabled(group, v)) throw bad(msg);
        return v;
    }

    private static ApiException bad(String m) { return ApiException.badRequest(m); }
}

 */
final class BankYears {
    static final String KB_BANK = "B02";   // 039 코드표 'KB국민은행'
    static final String KB = "KB", OTHER = "OTHER", NO_RECORD = "NO_RECORD";
    static final int MAX_SPAN = 40, DEFAULT_BACK = 16, DEFAULT_AHEAD = 4;

    private BankYears() { }

    static Integer yearOf(String t) {
        if (t == null || t.length() < 4) return null;
        for (int i = 0; i < 4; i++) { char ch = t.charAt(i); if (ch < '0' || ch > '9') return null; }
        return Integer.valueOf(t.substring(0, 4));
    }

    static boolean covers(String from, String to, int year) {
        Integer t = yearOf(to);
        if (t == null) return false;
        Integer f = from == null ? t : yearOf(from);
        return f != null && f <= year && year <= t;
    }

    static String yearState(List<BankContract> lines, int year) {
        boolean any = false;
        for (BankContract c : safe(lines)) {
            if (!covers(c.getTermFrom(), c.getTermTo(), year)) continue;
            if (KB_BANK.equals(c.getBankCd())) return KB;
            any = true;
        }
        return any ? OTHER : NO_RECORD;
    }

    /** 오늘 기준(039 termState CURRENT 와 같은 판정). */
    static String nowState(List<BankContract> lines, LocalDate today) {
        boolean any = false;
        for (BankContract c : safe(lines)) {
            if (!"CURRENT".equals(BankContractRules.termState(c.getTermFrom(), c.getTermTo(), today))) continue;
            if (KB_BANK.equals(c.getBankCd())) return KB;
            any = true;
        }
        return any ? OTHER : NO_RECORD;
    }

    /** 국민은행 줄의 가장 늦은 끝 해(없으면 null). '예전엔 국민은행'(되찾기) 표시는 kb_now≠KB 이고 이 값 < 올해일 때 — 판단은 화면. */
    static Integer lastKbYear(List<BankContract> lines) {
        Integer max = null;
        for (BankContract c : safe(lines)) {
            if (!KB_BANK.equals(c.getBankCd())) continue;
            Integer y = yearOf(c.getTermTo());
            if (y != null && (max == null || y > max)) max = y;
        }
        return max;
    }

    static Map<String, Object> summary(List<BankContract> lines, LocalDate today) {
        Map<String, Object> m = new LinkedHashMap<String, Object>();
        m.put("kb_now", nowState(lines, today));
        m.put("last_kb_year", lastKbYear(lines));
        List<Map<String, Object>> now = new ArrayList<Map<String, Object>>();
        for (BankContract c : safe(lines)) {
            if ("CURRENT".equals(BankContractRules.termState(c.getTermFrom(), c.getTermTo(), today))) now.add(line(c, true));
        }
        m.put("lines_now", now);
        m.put("record_count", safe(lines).size());
        return m;
    }

    static List<Map<String, Object>> table(List<BankContract> lines, int from, int to) {
        List<Map<String, Object>> out = new ArrayList<Map<String, Object>>();
        for (int y = from; y <= to; y++) {
            List<Map<String, Object>> banks = new ArrayList<Map<String, Object>>();
            for (BankContract c : safe(lines)) if (covers(c.getTermFrom(), c.getTermTo(), y)) banks.add(line(c, false));
            Map<String, Object> m = new LinkedHashMap<String, Object>();
            m.put("year", y);
            m.put("state", yearState(lines, y));
            m.put("banks", banks);
            out.add(m);
        }
        return out;
    }

    private static Map<String, Object> line(BankContract c, boolean withTerm) {
        Map<String, Object> m = new LinkedHashMap<String, Object>();
        m.put("contract_no", c.getContractNo());
        m.put("rank_cd", c.getRankCd());
        m.put("bank_cd", c.getBankCd());
        m.put("bank_name", BankContractRules.BANK_ETC.equals(c.getBankCd()) ? c.getBankNameEtc() : c.getBankName());
        if (withTerm) { m.put("term_from", c.getTermFrom()); m.put("term_to", c.getTermTo()); }
        return m;
    }

    private static List<BankContract> safe(List<BankContract> l) { return l == null ? Collections.<BankContract>emptyList() : l; }
}

    private Map<String, Object> insert(BidTarget row, Actor actor, BoardUiIds.Ui ui) {
        SysUser me = users.selectByEmpNo(actor.getEmpNo());
        if (me == null || !HeadRules.isSales(me.getRole())) throw new ApiException(403, DENIED_MSG);   // 컨트롤러가 먼저 막는다(방어)
        row.setEditorEmpNo(actor.getEmpNo());
        row.setEditorName(me.getName());
        row.setEmpVerified(actor.isVerified() ? 1 : 0);
        row.setScreenId(ui.getScreen());
        row.setButtonId(ui.getButton());
        row.setUiValid(ui.isValid() ? 1 : 0);
        row.setSavedAt(Times.nowIso());
        try {
            mapper.insertRow(row);
        } catch (DuplicateKeyException e) {   // 잠금이 있어 정상 경로에선 오지 않는다 — PK 가 마지막 방어선
            throw conflict("STALE", "다른 사람이 먼저 고쳤습니다. 최신 기록을 확인하고 다시 저장하세요.", null);
        }
        BidTarget saved = mapper.selectLatestTarget(row.getInstitutionId(), row.getTargetNo());   // 조인값(이름·태그 이름·처음 입력자)
        Map<String, Object> out = new LinkedHashMap<String, Object>();
        out.put("saved", true);
        out.put("institution_id", row.getInstitutionId());
        out.put("target_no", row.getTargetNo());
        out.put("rev_no", row.getRevNo());
        out.put("action_cd", row.getActionCd());

    private static ApiException conflict(String code, String message, BidTarget cur) {
        Map<String, Object> d = new LinkedHashMap<String, Object>();
        d.put("code", code);
        d.put("message", message);
        Map<String, Object> latest = null;
        if (cur != null) {
            latest = new LinkedHashMap<String, Object>();
            latest.put("target_no", cur.getTargetNo());
            latest.put("rev_no", cur.getRevNo());
            latest.put("action_cd", cur.getActionCd());
            latest.put("target_year", cur.getTargetYear());
            latest.put("editor_name", cur.getEditorName());
            latest.put("saved_at", cur.getSavedAt());
        }
        d.put("latest", latest);
        return ApiException.withDetail(409, d);
    }

## 5. 보안·위험·되돌리는 법

**권한**
- 쓰기 403 경로는 두 겹이다. ① `requireInstitutionEdit`(map·regions 수정) ② `isSales`. 둘 다 서비스 트랜잭션(기관 행 잠금) 전에 컨트롤러에서 막고 DENIED로 남긴다. `insert()`에도 방어 검사가 있다.
- 빼기 권한은 '영업 계열 누구나'다. 한 사람이 남의 목표를 빼는 것을 막지 않는다. 대신 이력에 누가·화면·버튼·사유가 남고, 다시 넣으면 새 번호로 복구된다.

**자기신고 인증의 한계**
- 사번(X-Emp-No)·화면·버튼은 모두 자기신고다. 위조할 수 있고, 권한 검사는 실수 방지용 업무 규칙이지 보안 경계가 아니다.
- `EMP_VERIFIED=0`을 '검증됨'으로 보이면 안 된다.

**접근 이력**
- DETAIL에는 건수·번호·REV·상태·오류 코드만 남긴다.
- 메모·연도 쿼리값·사번·은행 이름은 넣지 않는다. 거부 사유는 고정 문구다.

**응답 노출**
- 수정자 사번·화면·버튼은 응답에 싣지 않는다.
- 주 담당 사번은 쓰기 자격자(영업 계열)에게만 싣는다. 같은 사람들이 이미 `/assignment-candidates`에서 사번을 본다.
- `/bank-contracts/summary`는 039 줄을 전 기관 단위로 묶어 map 조회자에게 보인다. 기관별 `GET /institutions/{id}/bank-contracts`와 같은 노출 범위다.

**입력**
- 기관 ID: `validInstId` 형식 검사 → 잠금 행이 없으면 404. 위조된 ID는 행을 만들지 못한다.
- 코드는 코드표 ENABLED=1만 받는다.
- 자유 글: 제어·서식 문자 거부, 글자 수 상한, PII·정당·전화번호 422(값 미반환).

**동시성**: INSTITUTIONS FOR UPDATE가 039와 같은 행 잠금이다. 같은 기관의 약정 저장과 목표 저장이 서로 기다릴 수 있지만 짧은 트랜잭션이다. 복합 PK가 마지막 방어선이다.

**위험**
- `BankContractRules`의 package-private 정적 멤버 5개에 의존한다. 다른 세션이 이름을 바꾸면 컴파일이 깨진다(즉시 드러남).
- `/bank-contracts/summary`는 5000줄 상한에서 마지막 기관이 잘릴 수 있다(`truncated`로 표시).

**되돌리기**
- 코드 커밋을 되돌린다.
- DB:
  - MySQL: `DROP TABLE INST_BID_TARGET; DELETE FROM COMMON_CODE WHERE CODE_GROUP IN ('TARGET_TAG','TARGET_CANCEL_REASON');`
  - Oracle: 같은 문장(운영 데이터 소멸 주의).
  - 044: `DROP TABLE BID_BRIEFING_BANK; DROP TABLE BID_BRIEFING;`

**Q1. 예전 국민은행 유치 기록을 처음에 어떻게 채울까요?**
- 무엇인가: 기관 상세의 '금고 약정' 칸에 지난 약정(예: 2019~2022 국민은행 1금고)을 줄로 남기면 연도별 유치 기록이 된다. 새 표는 필요 없다.

  - (A) **담당자가 아는 지난 약정을 출처(공고 번호·기사·담당자 확인)와 함께 하나씩 입력한다 — 권장.** 지금 바로 되고 근거가 남는다. 입력 전 연도는 '기록 없음'으로 보인다.
