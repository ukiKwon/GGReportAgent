## 5. 보안·위험·되돌리는 법 (security 확인 포인트)
- base.mask(t) 결과는 비교에만 쓰이고 저장·응답·감사에 실리지 않습니다. 저장 본문은 본 세션이 따로 가립니다. 가린 글끼리 비교해도 원문이 새는 길은 새로 열리지 않습니다.
- 가릴 단어를 지우고 같은 단어를 다시 타이핑하면 mask(t)가 [이름]으로 바꿔 개수가 같고, 저장은 가려진 글입니다.
- 토큰 글자를 직접 타이핑해 개수를 맞추는 것은 기존 한계이고, 시험 ③이 "개수 검사"로 고정합니다. 원문을 되살리는 길은 아닙니다. removed 값은 종류별 빠진 수만 싣습니다.
- 토큰 일부를 깨는 입력으로 비교 쪽 토큰이 줄어드는 경우는 찾지 못했지만 실행해 확인하지는 못했습니다.
- 권한(403)·접근 이력 형식은 바뀌지 않습니다. 인증은 X-Emp-No 자기신고이고, SCREEN_ID도 X-Screen-Id 자기신고 값을 기록한 것이지 검증된 값이 아닙니다.
- 되돌리기: `base.mask(t)`를 `t`로 되돌립니다. 시험 ①②는 그때 실패하는 것이 정상입니다. DB 스크립트 변경은 없습니다.
