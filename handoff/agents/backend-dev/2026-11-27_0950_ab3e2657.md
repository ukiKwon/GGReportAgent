## 2. 확인한 것
- **067의 선행은 054입니다.**
  - 054에 BID_PREP_CHECK 표와 DASH_MARK 4코드가 있습니다. 코드는 DONE, IN_PROGRESS, NA, NONE이고 SORT_NO가 1~4라 5·6과 겹치지 않습니다.
  - 067은 COMMON_CODE INSERT만 하므로 066에 기대지 않습니다. 066이 없어도 시험은 뜨고 멈출 이유가 없습니다.
  - 시험 properties에서 054는 060 앞에 이미 있어 067보다 앞입니다.
- **다시 실행해도 안전한지:** 둘 다 멱등하지 않습니다(apply-mysql은 파일당 1회).
  - 065를 다시 돌리면 칸 중복 오류입니다.
  - 067을 다시 돌리면 PK 중복 오류입니다.
  - 둘 다 헤더에 적었고, 아래 사전 조회가 적용 여부를 가려줍니다.
- **기존 행 백필:** 065는 설계대로 백필이 없고 기존 행이 모두 NULL입니다. 067은 값 입력뿐이라 백필이 없습니다.
- **apply-mysql 스크립트:** `setup-local-win.ps1`은 번호별로 `${n}_*.sql`을 고릅니다. 066이 비어 있는 동안에도 065·067은 순서와 상관없이 적용됩니다. 066을 붙일 때 번호 목록이 필요한지는 확인하지 않았습니다.
- **CommonCodeSchemaTest:** 제외 목록에 DASH_MARK와 TARGET_AIM_RANK가 이미 있어 바꾸지 않았습니다. 065·067은 새 코드 그룹을 만들지 않습니다.
- **DASH_MARK 건수를 단언하는 기존 시험:** `src/test` grep으로는 `PrepBoardDdlPairTest`(054 파일만, 4코드 contains)뿐이라 영향이 없습니다.

## 3. 설계와 달라진 점·판단
1. 지시문의 "067(PROPOSAL_SUBMIT 체크 칸 등)"은 설계 원문과 다릅니다. 설계 067은 코드표 WON·LOST 2행뿐이고 PROPOSAL_SUBMIT 칸은 서버 코드 `PrepBoardColumns`에만 있습니다(표 변경 없음). 설계 원문대로 만들었습니다.
2. 보완판 헤더에는 `066 뒤 한 번만`이라고 적혀 있었습니다. 최종판 방침인 "054 뒤 한 번만, 번호 순서 실행 규칙상 066 다음에 돌린다"로 바꾸고 "066에 기대지 않는다"를 덧붙였습니다.
3. 설계 헤더에 없는 것을 더했습니다. 065에는 OTHER 이름은 목표 건에만 두고 OTHER 코드표 행은 066이 더한다는 설명을 넣었습니다. 사전 조회와 확인 SQL 줄은 065·067 모두에 넣었습니다.
4. 068 예약 언급은 무시했습니다.

## 5. DB 적용 순서
- MySQL 로컬: 065, 067(순서 무관)을 파일당 한 번씩 돌립니다. 066은 ca가 만든 뒤 번호 순서대로 끼웁니다.
- Oracle은 정본까지만이고 적용은 DBA 몫입니다.

## 6. 사용자가 적용 전 돌릴 읽기 전용 사전 조회
- 065 (MySQL): 0이어야 합니다.
  ```sql
  SELECT COUNT(*) FROM information_schema.COLUMNS WHERE TABLE_SCHEMA = DATABASE() AND TABLE_NAME = 'BID_CASES' AND COLUMN_NAME = 'BID_RANK_CD';
  ```
- 065 (Oracle): 0이어야 합니다.
  ```sql
  SELECT COUNT(*) FROM USER_TAB_COLUMNS WHERE TABLE_NAME = 'BID_CASES' AND COLUMN_NAME = 'BID_RANK_CD';
  ```
- 067: 0줄이어야 합니다.
  ```sql
  SELECT CODE FROM COMMON_CODE WHERE CODE_GROUP = 'DASH_MARK' AND CODE IN ('WON', 'LOST');
  ```
- 적용 뒤 확인
  - 065: `SELECT COUNT(*) FROM BID_CASES WHERE BID_RANK_CD IS NOT NULL;`은 0이어야 합니다.
  - 067: DASH_MARK가 6줄이어야 합니다.
- 066의 PK 중복 조회, RESULT 칸 기존 값 조회, 점검 ④는 066 몫이라 이번 범위 밖입니다. 설계는 1737 보완판 3절과 1802 최종판 6절에 있습니다.
