- 기존 칸으로 충분한 이유:
  - "처리했나"는 `INST_PLAN_IMPORT(INSTITUTION_ID, FILE_SHA256)`로 판정한다.
  - 한 번 누른 반입의 묶음은 `BATCH_ID`(형식 `[A-Za-z0-9_-]{1,64}`)에 남긴다.
  - 파일 단위 감사는 기존 `INST_PLAN_ACT`(IMPORT, sha, 결과)에 남는다.
  - 목록 집합의 해시는 `INST_PLAN_ACT.FILE_SHA256`에 넣는다. `PlanAudit`가 64자리 hex 형식을 검사한다.

    public Map<String, Object> importFile(String fileName, byte[] raw, String batchRaw, Actor actor, BoardUiIds.Ui ui) {
        Matcher fm = PlanCsv.FILE_NAME.matcher(fileName == null ? "" : fileName);
        String instId = fm.matches() ? fm.group(1) : null;
        String sha = null;
        try {
            if (instId == null) throw ApiException.badRequest("파일 이름은 {기관ID}_{확인일YYYYMMDD}_plan.csv 형식이어야 합니다.");
            instId = canonicalId(instId);

    public Map<String, Object> inspect(String fileName, java.util.function.Supplier<byte[]> reader) {
        Map<String, Object> m = new LinkedHashMap<>();
        m.put("file_name", fileName);
        m.put("institution_id", null);
        m.put("name_ko", null);
        m.put("file_date", null);
        Matcher fm = PlanCsv.FILE_NAME.matcher(fileName == null ? "" : fileName);
        if (!fm.matches()) return withStatus(m, "BAD_NAME");
        String inst;
        try { inst = canonicalId(fm.group(1)); } catch (ApiException e) { return withStatus(m, "NO_INSTITUTION"); }
        m.put("institution_id", inst);
        m.put("name_ko", mapper.selectInstitutionName(inst));
        String fileDate;
        try { fileDate = fileDate(inst, fileName); } catch (ApiException e) { return withStatus(m, "BAD_DATE"); }
        m.put("file_date", fileDate);
        InstPlanImport last = mapper.selectLatestImport(inst);
        if (last != null && last.getFileDate() != null && fileDate.compareTo(last.getFileDate()) < 0) return withStatus(m, "OLDER");
        byte[] raw;
        try { raw = reader.get(); } catch (FileProblem e) { return withStatus(m, e.getCode()); }
        if (mapper.countImportBySha(inst, sha256(raw)) > 0) return withStatus(m, "IMPORTED");
        try {
            PlanCsv.Result r = PlanCsv.parse(raw, new PlanCsv.Options(inst, fileDate, false, today()), codes().resolver);
            m.put("doc_count", r.docs.size());
            m.put("item_count", r.rows);
            m.put("warning_count", r.warnCount);
            return withStatus(m, "READY");
        } catch (InstitutionCsv.CsvFormatException e) {
            m.put("message", e.getMessage());
            return withStatus(m, "INVALID");
        }
    }

    private static Map<String, Object> withStatus(Map<String, Object> m, String code) { m.put("status_cd", code); return m; }

            Comparator.comparing(PlanInboxService::dateOf).thenComparing(Comparator.naturalOrder());

    private final InstitutionPlanService plans;
    private final PlanAudit audit;
    private final String location;
    private final AtomicBoolean busy = new AtomicBoolean(false);

    public PlanInboxService(InstitutionPlanService plans, PlanAudit audit,
                            @Value("${ggreport.plan-inbox.location:}") String location) {
        this.plans = plans;
        this.audit = audit;
        this.location = location == null ? "" : location.trim();
    }

    public boolean enabled() { return !location.isEmpty(); }

    /** 설정 폴더의 실제 경로. 꺼짐 503 OFF, 없음·폴더 아님 503 BAD_CONFIG — 경로는 응답·로그에 싣지 않는다. */
    Path root() {
        if (location.isEmpty()) {
            throw PlanCollectService.err(503, OFF, "사업계획 반입 폴더가 설정되지 않았습니다. 파일 올리기로 반입해 주세요.");
        }
        try {
            Path real = Paths.get(location).toRealPath();
            if (!Files.isDirectory(real)) throw new IOException("not a directory");
            return real;
        } catch (IOException | InvalidPathException e) {
            LOG.error("plan-inbox root unavailable code={}", BAD_CONFIG);
            throw PlanCollectService.err(503, BAD_CONFIG, "사업계획 반입 폴더를 읽을 수 없습니다. 개발부서 설정을 확인해 주세요.");
        }
    }

    /** 폴더 확인 — DB·파일 무변경. 형식 밖 이름은 개수만(이름을 되돌려 주지 않는다). */
    public Map<String, Object> scan() {
        Path root = root();
        List<String> names = new ArrayList<>();
        int ignored = 0, seen = 0;
        boolean truncated = false;
        try (DirectoryStream<Path> ds = Files.newDirectoryStream(root)) {
            for (Path p : ds) {
                if (++seen > MAX_ENTRIES) { truncated = true; break; }
                String n = p.getFileName().toString();
                if (PlanCsv.FILE_NAME.matcher(n).matches()) names.add(n); else ignored++;
            }
        } catch (IOException | DirectoryIteratorException e) {
            LOG.error("plan-inbox list failed code={}", BAD_CONFIG);
            throw PlanCollectService.err(503, BAD_CONFIG, "사업계획 반입 폴더를 읽을 수 없습니다. 개발부서 설정을 확인해 주세요.");
        }
        names.sort(NEWEST_FIRST);
        if (names.size() > MAX_LIST) { truncated = true; names = new ArrayList<>(names.subList(0, MAX_LIST)); }
        final long[] budget = {SCAN_BUDGET};
        List<Map<String, Object>> items = new ArrayList<>();
        Map<String, Integer> counts = new TreeMap<>();
        for (final String n : names) {
            Map<String, Object> it = plans.inspect(n, () -> readSafe(root, n, budget));
            items.add(it);
            counts.merge(String.valueOf(it.get("status_cd")), 1, Integer::sum);
        }
        Map<String, Object> out = new LinkedHashMap<>();
        out.put("items", items);
        out.put("status_counts", counts);
        out.put("ignored_count", ignored);
        out.put("truncated", truncated);
        out.put("max_import", MAX_IMPORT);
        return out;
    }

    /** 고른 파일 반입. 파일별 결과 IMPORTED·ALREADY·OLDER·INVALID(message)·NOT_FOUND·TOO_LARGE·UNSAFE·GONE·UNREADABLE·CONFLICT·ERROR. 오류가 있어도 200. */
    public Map<String, Object> importFiles(List<String> raw, Actor actor, BoardUiIds.Ui ui) {
        List<String> names;
        Path root;
        try {
            names = names(raw);
            root = root();
        } catch (ApiException e) {
            failed(null, e.getStatus() == 503 ? "INBOX_OFF" : "INVALID", actor, ui);
            throw e;
        }
        if (!busy.compareAndSet(false, true)) {
            failed(null, "BUSY", actor, ui);
            throw PlanCollectService.err(409, "BUSY", "다른 반입이 진행 중입니다. 잠시 후 다시 눌러 주세요.");
        }
        try {
            String batch = "inbox-" + LocalDateTime.now(SEOUL).format(STAMP);
            List<Map<String, Object>> rs = new ArrayList<>();
            int ok = 0, already = 0, err = 0;
            for (String n : names) {
                String idOfName = n.substring(0, n.length() - 18);   // FILE_NAME 통과값: {id}_{8}_plan.csv
                Map<String, Object> r = new LinkedHashMap<>();
                r.put("file_name", n);
                r.put("institution_id", idOfName);
                try {
                    Map<String, Object> out = plans.importFile(n, readSafe(root, n, null), batch, actor, ui);
                    r.put("institution_id", out.get("institution_id"));
                    r.put("result_cd", "IMPORTED");
                    r.put("import_id", out.get("import_id"));
                    r.put("item_count", out.get("item_count"));
                    r.put("warning_count", out.get("warning_count"));
                    ok++;
                } catch (InstitutionPlanService.FileProblem e) {
                    r.put("result_cd", e.getCode());
                    failed(idOfName, e.getCode(), actor, ui);
                    err++;
                } catch (ApiException e) {   // importFile 이 감사를 남겼다
                    String code = classify(e);
                    r.put("result_cd", code);
                    if ("INVALID".equals(code)) r.put("message", String.valueOf(e.getDetailObject()));   // 'row n: 고정 문구' 또는 이름·날짜 문구
                    if ("ALREADY".equals(code)) already++; else err++;
                } catch (RuntimeException e) {
                    if (PlanCollectService.isOutage(e)) throw e;   // DB 장애면 멈춘다(500, 앞선 파일은 커밋 유지 — requestBatch 선례)
                    LOG.warn("plan-inbox import error code=ERROR err={}", e.getClass().getSimpleName());
                    r.put("result_cd", "ERROR");
                    err++;
                }
                rs.add(r);
            }
            Map<String, Object> out = new LinkedHashMap<>();
            out.put("batch_id", batch);
            out.put("imported_count", ok);
            out.put("already_count", already);
            out.put("error_count", err);
            out.put("results", rs);
            return out;
        } finally {
            busy.set(false);
        }
    }

    static List<String> names(List<String> raw) {
        if (raw == null || raw.isEmpty() || raw.size() > MAX_IMPORT) {
            throw PlanCollectService.err(400, "BAD_FILES", "파일은 1~" + MAX_IMPORT + "개여야 합니다.");
        }
        LinkedHashSet<String> out = new LinkedHashSet<>();
        for (String s : raw) {
            if (s == null || !PlanCsv.FILE_NAME.matcher(s).matches()) {
                throw PlanCollectService.err(400, "BAD_FILES", "파일 이름 형식이 올바르지 않습니다.");
            }
            out.add(s);
        }
        List<String> list = new ArrayList<>(out);
        list.sort(OLDEST_FIRST);   // 같은 기관 여러 날짜면 이른 것부터 — 늦은 것이 먼저 들어가 이른 것이 OLDER 로 막히지 않게
        return list;
    }

    /** name 은 FILE_NAME 통과값(구분자·'..'·':' 없음). 링크·폴더·장치 거부, 실제 경로의 부모가 root 여야 한다. 하드링크는 막지 못한다(알려진 한계). */
    static byte[] readSafe(Path root, String name, long[] budget) {
        Path p = root.resolve(name);
        BasicFileAttributes a;
        Path real;
        try {
            a = Files.readAttributes(p, BasicFileAttributes.class, LinkOption.NOFOLLOW_LINKS);
            if (!a.isRegularFile()) throw new InstitutionPlanService.FileProblem("UNSAFE");
            real = p.toRealPath();
        } catch (NoSuchFileException e) {
            throw new InstitutionPlanService.FileProblem("GONE");
        } catch (IOException e) {
            throw new InstitutionPlanService.FileProblem("UNREADABLE");
        }
        if (!root.equals(real.getParent()) || !real.getFileName().toString().equalsIgnoreCase(name)) {
            throw new InstitutionPlanService.FileProblem("UNSAFE");
        }
        if (a.size() > CsvLimits.MAX_FILE_BYTES) throw new InstitutionPlanService.FileProblem("TOO_LARGE");
        if (budget != null) {
            if (budget[0] < a.size()) throw new InstitutionPlanService.FileProblem("NOT_CHECKED");
            budget[0] -= a.size();
        }
        try (InputStream in = Files.newInputStream(p, LinkOption.NOFOLLOW_LINKS)) {
            ByteArrayOutputStream out = new ByteArrayOutputStream((int) Math.min(a.size() + 16, CsvLimits.MAX_FILE_BYTES + 16));
            byte[] buf = new byte[8192];
            long total = 0;
            int r;
            while ((r = in.read(buf)) > 0) {
                total += r;
                if (total > CsvLimits.MAX_FILE_BYTES) throw new InstitutionPlanService.FileProblem("TOO_LARGE");   // 확인 뒤 커진 파일
                out.write(buf, 0, r);
            }
            return out.toByteArray();
        } catch (IOException e) {
            throw new InstitutionPlanService.FileProblem("UNREADABLE");
        }
    }

    static String classify(ApiException e) {
        Object d = e.getDetailObject();
        switch (e.getStatus()) {
            case 400: return "INVALID";
            case 404: return "NOT_FOUND";
            case 413: return "TOO_LARGE";
            case 409: return InstitutionPlanService.MSG_SAME.equals(d) ? "ALREADY"
                    : InstitutionPlanService.MSG_OLDER.equals(d) ? "OLDER" : "CONFLICT";
            default: return "ERROR";
        }
    }

    static String dateOf(String n) { return n.substring(n.length() - 17, n.length() - 9); }

    private void failed(String inst, String outcome, Actor actor, BoardUiIds.Ui ui) {
        try {
            audit.record(inst, null, InstitutionPlanService.ACTION_IMPORT, outcome, null, null, actor, ui);
        } catch (RuntimeException ex) {
            LOG.error("plan-inbox audit failed outcome={}", outcome);
        }
    }
}

### C) RPA 대비 (지금은 화면 버튼만)
- **권장은 서버 주기 반입**이다. RPA 계정이 화면 버튼을 누르게 하려면 그 계정에 admin 키를 줘야 하는데, 그러면 `/sysadmin` 전체 권한이 열린다. 그래서 RPA는 uploader 업로드까지만 맡기고, 웹은 타이머로 반입한다. 사용자 입장에서는 "RPA가 반입까지 한다"는 결과가 같다.
- **바뀌는 것은 actor와 ui뿐이다**. `importFiles`가 그대로 진입점이다. 자동으로 전환할 때 더할 것:
  1. `PlanInboxService.importReady(actor, ui)`: `scan()` 결과 중 `READY`만 골라 최대 50개를 `importFiles`로 넘긴다.
  2. `@EnableScheduling`과 `@Scheduled(cron="${ggreport.plan-inbox.cron:-}", zone="Asia/Seoul")`. 값이 `-`이면 꺼진다. 예: 목요일 10~18시 매시.
  3. 시스템 주체: `IMPORTED_BY VARCHAR(7) NOT NULL`이라 예약 사번 `0000000`을 USERS에 '시스템'·**LOCKED**로 등록한다(그때 060 이후 쌍 스크립트). LOCKED라서 누가 `X-Emp-No`로 그 사번을 자기신고해도 모든 가드가 거부한다. 감사 화면·버튼은 `plan_inbox_auto`·`scheduler`로 사람이 누른 반입과 구분한다.
  4. 실패 알림: 한 번 돌 때 `error_count>0`이면 `IT_INBOXES`(전산팀·전산팀장)에 쪽지 1통(`[사업계획 반입 확인 필요] n건을 반입하지 못했습니다. 처리 화면 [폴더 확인]에서 확인해 주세요.`). 파일 이름·기관명은 싣지 않는다. 같은 실패 집합(해시)이면 다시 보내지 않는다(메모리 또는 ACT 조회). 요청자 쪽지는 기존 `onImported`가 보낸다.
  5. 서버가 여러 대(WebLogic 다중 노드)면 같은 타이머가 노드마다 돈다. 기관 잠금과 `MSG_SAME` 409 덕분에 판이 중복으로 생기지는 않지만 ALREADY 감사가 늘어난다. 한 노드에서만 켠다(설정).

## 5. 보안·위험·되돌리는 법
- **자기신고 인증의 한계**: 모든 검사는 `X-Emp-No` 자기신고 위에서 돈다. 전산팀장 사번만 알면 반출할 수 있다. 업무 규칙일 뿐 사칭 방지가 아니며, SSO 전에는 보안 경계가 아니다(NEXT 35).
- **경로**: 설정 한 곳만 쓰고 요청에서 경로를 받지 않는다. 이름은 FILE_NAME 정규식(`[A-Za-z0-9-]`·`_`·숫자·`_plan.csv`)뿐이라 `..`·구분자·`:`(ADS)가 끼어들 수 없다. NOFOLLOW 정규 파일만 받고, 실제 경로의 부모가 root와 같아야 한다.
  - 남는 한계: 하드링크, 확인과 읽기 사이 교체(TOCTOU). 폴더에 쓸 수 있는 쪽(uploader·RPA)은 신뢰 경계 안으로 본다.
  - root 자체가 심볼릭 링크·junction이면 그 실제 경로를 받아들인다. 관리자 설정이기 때문이다.
- **자원**: 응답은 100파일, 폴더는 2,000항목까지 센다. 확인 한 번에 64MB 읽기 예산, 반입 50파일·파일당 5MB, 동시 반입 1건(JVM).
  - UNC 공유 폴더가 느리면 GET이 오래 걸릴 수 있다. 타임아웃은 아직 없다(security 검토 지점).
- **정보 노출**:
  - 형식 밖 파일 이름은 되돌려 주지 않는다. 오류 문구는 `row n: 고정 문구`뿐이고, 503 문구에 경로가 없다.
  - 로그는 코드·예외 종류만 남긴다. 접근 이력 DETAIL은 건수만 남기고 파일 이름·기관ID는 싣지 않는다.
  - `X-Plan-Export-Sha256`은 기관ID 집합의 해시로, 비밀이 아니고 대조용이다.
- **동작 변경 1건**: `apply`가 IMPORT에서 "예전 어느 판과 같은 내용"이면 409를 낸다. 기존 `/plans/import`에도 적용된다. 영향은 같은 날짜 예전 판의 재업로드가 거부되는 것뿐이다. SCHEMA ⑪-5에 반영한다.
- **반출 권한 축소**: 전산팀원은 더 이상 내려받을 수 없다. 화면이 `can_export`로 버튼을 막아야 한다(프런트).
- **security 검토 지점**:
  1. readSafe의 링크·부모 대조와 Windows 대소문자
  2. 확인 GET의 읽기 예산·타임아웃
  3. INVALID message 노출 범위
  4. 반출 403 경로와 DENIED 이중 기록
  5. C의 예약 사번 `0000000` LOCKED 방식
- **되돌리기**:
  - 폴더 기능 끄기: 설정 키를 비우면 503이다. 코드를 빼려면 새 서비스·끝점 2개·PlanUiIds 한 줄을 지운다.
  - 반출 권한 되돌리기: `requireExporter` → `requireAdmin` 한 줄.
  - apply 가드: `countImportBySha` 조건을 지운다.
  - DB 변경이 없어 되돌릴 데이터가 없다(반입된 판은 기존과 같은 판이다).
