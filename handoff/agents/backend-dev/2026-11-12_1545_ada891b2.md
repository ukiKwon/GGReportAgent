## 2. 설계 판단 (실측 반영)
- **ca_extra = 중간 CA만 허용.** 로더가 PEM 안의 인증서를 해석해 조건을 확인한다: cA=TRUE, 자체 서명이 아님, 3개 이하. 개인키·인증서가 아닌 블록이 있으면 거부한다. `VERIFY_X509_PARTIAL_CHAIN`은 끈다(3.13 기본값에 대비). 이렇게 하면 신뢰의 끝은 늘 시스템 공개 루트로 남는다. security가 말한 "GPKI 루트를 ca_extra에" 넣는 방식은 이 규칙으로 막힌다. 루트가 필요한 경우가 생기면 그때 따로 판단한다.
- **pin_sha256은 유효기간도 검사하고, 만료를 무시하는 플래그는 두지 않는다(금지가 맞다고 판단).** 이유는 세 가지다.
  - 만료된 인증서는 운영자가 관리하지 않는다는 신호다.
  - 만료 뒤에는 키가 유출돼도 폐기할 방법이 없다.
  - 고정은 "정상이던 인증서를 지킨다"는 뜻인데, 만료를 무시하면 "검증 끄기"에 가까워진다.
  - 따라서 서울 도봉·중구·강남 3곳은 예외 없이 실패를 유지하고 기록 필드만 단다. 재검토일이 지나면 경고가 뜨고, 공고는 다른 출처로 보완한다.
- **핸드셰이크 오류(인증서 검증 실패가 아닌 `ssl.SSLError`)** 는 `FetchTlsHandshakeError`(FetchTlsError의 하위 클래스)로 분리했다. http 강등은 그대로 막히고, 30초 뒤 1회만 재시도한다. 인증서 검증 오류(`SSLCertVerificationError`, 고정 지문 불일치 포함)는 재시도하지 않는다. ciphers 완화 기능은 넣었지만 지금 쓰는 호스트는 0곳이다.
- **재시도 위치는 eminwon `_fetch`다.** HttpClient는 한 번만 시도하므로 g2b 동작은 바뀌지 않는다.
  - 시간 초과·연결 실패(`FetchConnError`)는 최대 2회, 간격 30초·90초로 재시도한다.
  - 4xx/5xx·그 밖의 오류는 재시도하지 않는다. security는 5xx 1회 재시도를 권했지만 지시대로 넣지 않았다.
  - 요청 하나의 최악 시간은 45×3+120 = 255초다.
  - 2nd pass는 시간 상한을 지키려고 재시도 없이 1회만 돈다. 12곳이 다 실패하면 대략 1시간 남짓이다.
- **pin 검증은 `HTTPSConnection.connect` 직후, 요청을 보내기 전에 한다(본문을 읽기 전).** 순서는 지문 → 호스트명(SAN, SAN이 없을 때만 CN, 와일드카드는 한 단계) → 유효기간이다. 서명은 검증하지 않는다. 지문 일치가 곧 서버 확인이기 때문이다.

```python
"""인증서(DER) 최소 해석 — 표준 라이브러리만(security 11-12).

pin_sha256 호스트의 직접 검증(지문·호스트명·유효기간)과 ca_extra 파일 검사(중간 CA만)에 쓴다.
서명은 검증하지 않는다(지문 고정은 공개키 지문 일치로 서버를 확인). 해석 실패는 ValueError.
"""

from __future__ import annotations

import datetime
import hashlib
import re
import ssl
from dataclasses import dataclass

_OID_CN = b"\x55\x04\x03"
_OID_SAN = b"\x55\x1d\x11"
_OID_BC = b"\x55\x1d\x13"
_PEM_RE = re.compile(r"-----BEGIN CERTIFICATE-----\s+[A-Za-z0-9+/=\s]+?-----END CERTIFICATE-----")
PIN_RE = re.compile(r"^[0-9a-f]{64}$")


@dataclass(frozen=True)
class CertInfo:
    spki_sha256: str
    dns_names: tuple[str, ...]
    common_names: tuple[str, ...]
    not_before: datetime.datetime
    not_after: datetime.datetime
    is_ca: bool
    self_issued: bool


def _tlv(buf: bytes, i: int, limit: int | None = None):
    limit = len(buf) if limit is None else limit
    if i + 2 > limit:
        raise ValueError("DER 길이 오류")
    tag, ln, j = buf[i], buf[i + 1], i + 2
    if ln & 0x80:
        n = ln & 0x7F
        if not 1 <= n <= 4 or j + n > limit:
            raise ValueError("DER 길이 오류")
        ln, j = int.from_bytes(buf[j:j + n], "big"), j + n
    if j + ln > limit:
        raise ValueError("DER 길이 오류")
    return tag, j, j + ln


def _children(buf: bytes, start: int, end: int):
    """[(tag, tlv_start, value_start, value_end)]"""
    out, i = [], start
    while i < end:
        tag, vs, ve = _tlv(buf, i, end)
        out.append((tag, i, vs, ve))
        i = ve
    return out


def _time(der: bytes, tag: int, vs: int, ve: int) -> datetime.datetime:
    s = der[vs:ve].decode("ascii")
    if tag == 0x17 and len(s) == 13:                       # UTCTime: 50 미만 20xx(RFC 5280)
        yy = int(s[:2])
        s = f"{2000 + yy if yy < 50 else 1900 + yy}{s[2:]}"
    elif not (tag == 0x18 and len(s) == 15):
        raise ValueError("인증서 시각 형식")
    return datetime.datetime.strptime(s, "%Y%m%d%H%M%SZ").replace(tzinfo=datetime.timezone.utc)


def _text(der: bytes, tag: int, vs: int, ve: int) -> str:
    raw = der[vs:ve]
    return raw.decode("utf-16-be") if tag == 0x1E else raw.decode("utf-8", errors="replace")


def _common_names(der: bytes, vs: int, ve: int) -> tuple[str, ...]:
    out = []
    for _t, _s, rvs, rve in _children(der, vs, ve):            # RDN SET
        for _t2, _s2, avs, ave in _children(der, rvs, rve):     # AttributeTypeAndValue
            kids = _children(der, avs, ave)
            if len(kids) == 2 and der[kids[0][2]:kids[0][3]] == _OID_CN:
                out.append(_text(der, kids[1][0], kids[1][2], kids[1][3]))
    return tuple(out)


def parse_cert(der: bytes) -> CertInfo:
    try:
        tag, cvs, cve = _tlv(der, 0)
        if tag != 0x30 or cve != len(der):
            raise ValueError("인증서 아님")
        ttag, _ts, tvs, tve = _children(der, cvs, cve)[0]
        if ttag != 0x30:
            raise ValueError("TBSCertificate 아님")
        f = _children(der, tvs, tve)
        k = 1 if f[0][0] == 0xA0 else 0
        issuer, validity, subject, spki = f[k + 2], f[k + 3], f[k + 4], f[k + 5]
        times = _children(der, validity[2], validity[3])
        not_before = _time(der, times[0][0], times[0][2], times[0][3])
        not_after = _time(der, times[1][0], times[1][2], times[1][3])
        dns: list[str] = []
        is_ca = False
        for wrap in f[k + 6:]:
            if wrap[0] != 0xA3:
                continue
            seq = _children(der, wrap[2], wrap[3])[0]
            for _t, _s, evs, eve in _children(der, seq[2], seq[3]):
                kids = _children(der, evs, eve)
                oid, val = der[kids[0][2]:kids[0][3]], kids[-1]
                if val[0] != 0x04:
                    raise ValueError("확장 값 형식")
                if oid == _OID_SAN:
                    san = _children(der, val[2], val[3])[0]
                    dns += [der[s:e].decode("ascii") for t, _i, s, e in _children(der, san[2], san[3]) if t == 0x82]
                elif oid == _OID_BC:
                    bc = _children(der, val[2], val[3])[0]
                    inner = _children(der, bc[2], bc[3])
                    is_ca = bool(inner) and inner[0][0] == 0x01 and der[inner[0][2]:inner[0][3]] not in (b"", b"\x00")
        return CertInfo(
            spki_sha256=hashlib.sha256(der[spki[1]:spki[3]]).hexdigest(),
            dns_names=tuple(dns), common_names=_common_names(der, subject[2], subject[3]),
            not_before=not_before, not_after=not_after, is_ca=is_ca,
            self_issued=der[issuer[1]:issuer[3]] == der[subject[1]:subject[3]])
    except (ValueError, IndexError) as exc:
        raise ValueError("인증서를 해석할 수 없습니다") from exc


def host_matches(host: str, names) -> bool:
    host = host.lower().rstrip(".")
    for name in names:
        n = name.strip().lower().rstrip(".")
        if n == host:
            return True
        if n.startswith("*.") and "*" not in n[2:] and n.count(".") >= 2:
            left, _, tail = host.partition(".")
            if left and tail == n[2:]:
                return True
    return False


def check_pinned(der: bytes | None, pins, host: str, now: datetime.datetime | None = None) -> CertInfo:
    """지문 고정 호스트의 직접 검증. 실패는 ssl.SSLCertVerificationError(재시도·http 강등 없음).
    만료 인증서는 지문이 맞아도 거부한다 — 무시 플래그 없음(backend-dev 11-12 판단)."""
    if not der:
        raise ssl.SSLCertVerificationError("서버 인증서가 없습니다")
    try:
        info = parse_cert(der)
    except ValueError:
        raise ssl.SSLCertVerificationError("서버 인증서를 해석할 수 없습니다") from None
    if info.spki_sha256 not in pins:
        raise ssl.SSLCertVerificationError("인증서 지문 불일치(pin_sha256)")
    if not host_matches(host, info.dns_names or info.common_names):
        raise ssl.SSLCertVerificationError("인증서 호스트명 불일치")
    now = now or datetime.datetime.now(datetime.timezone.utc)
    if not info.not_before <= now <= info.not_after:
        raise ssl.SSLCertVerificationError("인증서 유효기간 밖(만료 포함) — 지문 고정도 허용하지 않음")
    return info


def pem_certs(text: str) -> list[bytes]:
    """PEM의 CERTIFICATE 블록만 DER로. 개인키·다른 블록(TRUSTED CERTIFICATE 등)이 있으면 ValueError."""
    if "PRIVATE KEY" in text:
        raise ValueError("개인키가 들어 있습니다")
    blocks = _PEM_RE.findall(text)
    if not blocks or text.count("-----BEGIN ") != len(blocks):
        raise ValueError("인증서 블록만 허용합니다")
    return [ssl.PEM_cert_to_DER_cert(b) for b in blocks]
```

### 3-2. `c:\github\GGReportAgent\collector\httpclient.py` — 파일 전체를 바꾼다(old = 현재 76행 전체)
```python
"""표준 라이브러리 HTTP 클라이언트. TLS 검증은 항상 ON — 검증 끄기는 지원하지 않는다(security 11-12).

호스트별 TLS 예외는 TlsPolicy 하나로만: 중간 CA 추가(ca_file)·암호 묶음 허용 목록(ciphers)·공개키 지문 고정(pins).
재시도는 하지 않는다(소스가 FetchConnError·FetchTlsHandshakeError를 보고 결정).
"""

from __future__ import annotations

import functools
import http.client
import ssl
import time
import urllib.error
import urllib.parse
import urllib.request
from dataclasses import dataclass
from pathlib import Path

from collector.tlscert import check_pinned

UA = ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
      "(KHTML, like Gecko) Chrome/124.0 Safari/537.36")
TLS_MSG_LEN = 160          # 자체 서명 종류를 구분할 수 있게 80→160(security 11-12)
ALLOWED_CIPHERS = frozenset({"DEFAULT:@SECLEVEL=1"})   # @SECLEVEL=0·min_tls(TLS1.0/1.1)는 미지원


class FetchError(Exception):
    pass


class FetchHttpError(FetchError):
    """서버가 응답한 오류(4xx/5xx) — 스킴을 바꿔 재시도해도 소용없다."""


class FetchTlsError(FetchError):
    """인증서·TLS 오류 — http로 내려가 재시도하면 안 된다(중간자 강등 방지, security 7d2ac90 지적)."""


class FetchTlsHandshakeError(FetchTlsError):
    """인증서 검증이 아닌 핸드셰이크 실패(SSLV3_ALERT_HANDSHAKE_FAILURE·EOF 등). 부하분산 뒤 일부 서버 설정 차이로
    간헐 발생(메인 실측 11-12) — 소스가 1회까지 재시도할 수 있다. http 강등은 여전히 금지."""


class FetchConnError(FetchError):
    """시간 초과·연결 실패 — 소스가 백오프 후 재시도할 수 있다."""


@dataclass(frozen=True)
class TlsPolicy:
    ca_file: Path | None = None
    ciphers: str | None = None
    pins: tuple[str, ...] = ()

    @property
    def relaxed(self) -> bool:
        return bool(self.ca_file or self.ciphers or self.pins)


def build_context(tls: TlsPolicy | None = None) -> ssl.SSLContext:
    ctx = ssl.create_default_context()
    if ctx.verify_flags & ssl.VERIFY_X509_PARTIAL_CHAIN:      # 3.13+ 기본값 — 추가 중간 CA가 신뢰 앵커가 되지 않게
        ctx.verify_flags ^= ssl.VERIFY_X509_PARTIAL_CHAIN
    if tls is None:
        return ctx
    if tls.ciphers is not None:
        if tls.ciphers not in ALLOWED_CIPHERS:
            raise ValueError("허용하지 않는 ciphers")
        ctx.set_ciphers(tls.ciphers)
    if tls.pins:
        if tls.ca_file is not None:
            raise ValueError("pins와 ca_file은 함께 쓸 수 없습니다")
        ctx.check_hostname = False
        ctx.verify_mode = ssl.CERT_NONE        # 검증은 _PinnedHTTPSConnection이 지문·호스트명·유효기간으로 직접
    elif tls.ca_file is not None:
        ctx.load_verify_locations(cafile=str(tls.ca_file))   # 이 호스트 컨텍스트에만
    return ctx


def _tls_error(exc: Exception) -> FetchTlsError:
    msg = f"TLS 오류: {str(exc)[:TLS_MSG_LEN]}"
    if isinstance(exc, ssl.SSLCertVerificationError):      # = ssl.CertificateError
        return FetchTlsError(msg)
    return FetchTlsHandshakeError(msg)


def _origin(url: str):
    p = urllib.parse.urlsplit(url)
    return (p.scheme, p.hostname, p.port or (443 if p.scheme == "https" else 80))


class _SameHostRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        newurl = urllib.parse.urljoin(req.full_url, newurl)
        if _origin(newurl) != _origin(req.full_url):
            raise urllib.error.HTTPError(req.full_url, code, "다른 출처(스킴·호스트·포트)로의 리다이렉트 차단", headers, fp)
        return super().redirect_request(req, fp, code, msg, headers, newurl)


class _PinnedHTTPSConnection(http.client.HTTPSConnection):
    def __init__(self, *args, pins: tuple[str, ...], **kwargs):
        super().__init__(*args, **kwargs)
        self._pins = pins

    def connect(self):
        super().connect()
        try:   # 요청을 보내기 전(=응답 본문을 읽기 전)에 지문·호스트명·유효기간 대조
            check_pinned(self.sock.getpeercert(binary_form=True), self._pins, self.host)
        except ssl.SSLCertVerificationError:
            self.close()
            raise


class _PinnedHTTPSHandler(urllib.request.HTTPSHandler):
    def __init__(self, context: ssl.SSLContext, pins: tuple[str, ...]):
        super().__init__(context=context)
        self._pins = pins

    def https_open(self, req):
        return self.do_open(functools.partial(_PinnedHTTPSConnection, pins=self._pins), req, context=self._context)


class HttpClient:
    def __init__(self, timeout: float = 20.0, max_bytes: int = 20 * 1024 * 1024,
                 delay: float = 1.0, sleep=time.sleep) -> None:
        self.timeout, self.max_bytes, self.delay, self._sleep = timeout, max_bytes, delay, sleep
        self._first = True
        self._contexts: dict = {}

    def _context(self, tls: TlsPolicy | None) -> ssl.SSLContext:
        if tls not in self._contexts:
            self._contexts[tls] = build_context(tls)
        return self._contexts[tls]

    def get(self, url: str, verify: bool = True, tls: TlsPolicy | None = None) -> tuple[bytes, str | None]:
        if urllib.parse.urlsplit(url).scheme not in ("http", "https"):
            raise FetchError("http/https만 허용합니다")
        if not verify:
            raise FetchTlsError("TLS 검증 끄기는 지원하지 않습니다(설정 오류)")
        try:
            ctx = self._context(tls)
        except (ValueError, ssl.SSLError, OSError) as exc:
            raise FetchTlsError(f"TLS 설정 오류: {type(exc).__name__}") from exc
        if not self._first:
            self._sleep(self.delay)        # 기관 서버에 부담을 주지 않는 간격
        self._first = False
        https = (_PinnedHTTPSHandler(ctx, tls.pins) if tls is not None and tls.pins
                 else urllib.request.HTTPSHandler(context=ctx))
        opener = urllib.request.build_opener(_SameHostRedirect, https)
        req = urllib.request.Request(url, headers={
            "User-Agent": UA, "Accept": "*/*", "Accept-Language": "ko-KR,ko;q=0.9"})
        try:
            with opener.open(req, timeout=self.timeout) as resp:   # http.client = HTTP/1.1
                data = resp.read(self.max_bytes + 1)
                charset = resp.headers.get_content_charset()
        except urllib.error.HTTPError as exc:          # URLError보다 먼저
            raise FetchHttpError(f"HTTP {exc.code}") from exc
        except urllib.error.URLError as exc:
            if isinstance(exc.reason, ssl.SSLError):
                raise _tls_error(exc.reason) from exc
            raise FetchConnError(f"연결 실패: {type(exc).__name__} {str(exc.reason)[:80]}") from exc
        except ssl.SSLError as exc:
            raise _tls_error(exc) from exc
        except http.client.HTTPException as exc:       # 응답이 중간에 끊김 등
            raise FetchError(f"응답 오류: {type(exc).__name__}") from exc
        except OSError as exc:                         # socket.timeout = TimeoutError ⊂ OSError
            raise FetchConnError(f"연결 실패: {type(exc).__name__} {str(getattr(exc, 'reason', exc))[:80]}") from exc
        if len(data) > self.max_bytes:
            raise FetchError("응답이 너무 큽니다")
```

```python
        exts.append(_d(0x30, _d(0x06, b"\x55\x1d\x11"), _d(0x04, _d(0x30, *[_d(0x82, s.encode()) for s in sans]))))
    exts.append(_d(0x30, _d(0x06, b"\x55\x1d\x13"), _d(0x01, b"\xff"),
                   _d(0x04, _d(0x30, *([_d(0x01, b"\xff")] if ca else [])))))
    tbs = _d(0x30, _d(0xA0, _d(0x02, b"\x02")), _d(0x02, b"\x01"), sha, _name(issuer_cn),
             _d(0x30, _d(0x18, not_before.encode()), _d(0x18, not_after.encode())),
             _name(cn), spki, _d(0xA3, _d(0x30, *exts)))
    return _d(0x30, tbs, sha, _d(0x03, b"\x00sig")), hashlib.sha256(spki).hexdigest()
```

## 5. 보안·위험·되돌리는 법
- 검증 끄기 경로(`_create_unverified_context`)는 코드에서 완전히 없앴다. 설정 쪽은 로더가 막고, 코드 쪽은 HttpClient가 막는다. `tls_verify: "false"` 같은 문자열도 거부한다. 지금 코드는 `bool("false")`가 True가 되는 구멍이 있었는데, 이것도 함께 막힌다.
- 완화를 적용한 호스트는 백신 판정이 항상 "사용자 확인"이다. 따라서 체인 누락 6곳은 공개 루트까지 검증되는데도 반입 전에 확인을 받아야 한다. 지시대로이며, 운영 부담이 조금 늘어난다.
- 위험 1: 2nd pass와 백오프 때문에 주간 실행 시간이 늘어난다. 최악의 경우 1시간 남짓이다. `run_weekly.cmd`에 시간 제한이 있다면 맞춰야 한다. 나는 그 파일을 확인하지 않았다.
- 위험 2: 직접 만든 DER 해석기는 서명을 검증하지 않는다. 그러나 결과를 쓰는 곳은 두 곳뿐이다.
  - pin: 공개키 지문이 일치해야 하므로 서명 검증이 필요 없다.
  - ca_extra 파일 검사: 실제 검증은 OpenSSL이 한다.
- 되돌리는 법: 파일 단위로 `git checkout`한다. 그다음 JSON에 붙인 TLS 필드를 지운다. JSON 필드만 지우면 6곳이 다시 실패할 뿐 다른 동작은 그대로다.
