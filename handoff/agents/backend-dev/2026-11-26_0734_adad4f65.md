중-1과 하-1을 고쳤다. security 보고서(2026-11-26 최신)는 읽지 못했고 지시문의 위치만 보고 고쳤다. 빌드와 테스트는 하지 않았다.

**고친 줄**
- `service/PrepFormService.java` 1178줄. 검사에 `rs > rn || cs > cn`을 더하고 `(long) r + rs > rn || (long) k + cs > cn`으로 바꿨다. r·c 음수 거절과 rs·cs ≥ 1 검사는 이미 있었다.
- `docout/InstSummaryDocBuilder.java` 340줄. 같은 방식으로 상한 검사와 long 계산을 넣었다.
- `support/ScoringTable.java` 327~330줄:
  - `colCursor = (int) Math.min((long) MAX_COLS, (long) c0 + ccs)`로 바꿨다.
  - 칸을 담는 조건에 `rr >= 0 && c0 >= 0`을 더했다.
  - colSpan·rowSpan을 1~상한으로 자르는 코드(307~308줄)는 이미 있어 그대로 뒀다.
  - colAddr가 int 최대일 때 `c0 + ccs`가 넘쳐 음수가 되어 다음 칸이 `c0 < MAX_COLS`를 통과하던 문제를 막는다.

**추가한 시험**
- `PrepFormContentTest.평가표_병합_수가_int_최대여도_넘침_없이_BAD_SCORING이다`: r=1, c=1, rs=cs=2147483647이면 400 BAD_SCORING.
- `InstSummaryDocBuilderTest.v3_평가표_칸_병합_수가_int_최대여도_넘침_없이_IllegalArgumentException이다`
- `ScoringTableMergeTest.colAddr가_int_최대인_칸_뒤에_주소_없는_칸이_와도_모든_칸이_범위_안이다`: 모든 칸이 r·c ≥ 0, rs·cs ≥ 1이고 col_count ≤ 12.
