## 메인이 실행할 명령
1. `cd kgi-ggreport-web && mvn -q -o test`
   - 기대 결과는 기존 380건과 새 테스트 약 15건이 모두 통과하는 것입니다.
   - 8080 서버가 같은 `target/`을 쓰면 테스트 뒤에 재기동합니다.
   - 기존 테스트는 FK에 기대지 않으므로 깨질 것으로 보지 않습니다. `OrchestratorCoreTest`가 쓰는 UNIQUE는 그대로 있습니다.
2. 로컬 MySQL(`ggreportdb`)에는 한 세션만 쓰는 조건으로, 번호 순서대로 한 번씩 적용합니다.
   ```
   mysql -u root -p ggreportdb < src/main/resources/db/mysql/015_drop_foreign_keys.sql
   mysql -u root -p ggreportdb < src/main/resources/db/mysql/016_common_code.sql
   mysql -u root -p ggreportdb < src/main/resources/db/mysql/017_seed_common_codes.sql
   mysql -u root -p ggreportdb < src/main/resources/db/mysql/018_notice_followup.sql
   ```
   015는 `DELIMITER`를 쓰므로 `mysql` CLI로 실행해야 합니다.
3. 015 적용 뒤 확인합니다.
   - `SELECT TABLE_NAME, CONSTRAINT_NAME FROM information_schema.TABLE_CONSTRAINTS WHERE TABLE_SCHEMA='ggreportdb' AND CONSTRAINT_TYPE='FOREIGN KEY';`는 0행이어야 합니다.
   - `SHOW INDEX FROM BID_CASES`, `SHOW INDEX FROM MESSAGES`에 `IDX_BID_CASES_INST`·`IDX_MESSAGES_TASK`가 있어야 합니다.
   - MySQL 버전이 8.0 이상인지도 확인해 주세요(`RENAME INDEX` 때문입니다).
4. 016·017·018이 처음 적용되는 것이므로, 그 뒤에 `ops/integrity_check.sql`을 한 번 돌려 전부 0행인지 봅니다.

## 지시에서 벗어난 판단
- 보고서 3-8의 Q 쿼리 가운데 Q6 UNION의 두 번째 칼럼을 숫자 키도 문자로 맞췄습니다. Oracle은 `TO_CHAR(r.REQ_ID)`를 썼고, 보고서 원문에서 빠져 있던 `REQ_ID` 쪽에도 변환을 넣었습니다. 집계 칼럼에는 `AS N`을 붙였습니다.
- Oracle 017 끝에 `COMMIT;`을 넣었습니다(SQL*Plus로 돌릴 때 필요). H2 init에서는 무해합니다. MySQL 017에는 넣지 않았습니다.
- 017은 일반 INSERT라 멱등하지 않습니다(보고서와 같습니다). 그래서 test properties에 "컨텍스트가 하나로 캐시되는 전제" 주석을 달았습니다.
- 018 Oracle 주석에서 따옴표(`''`·`""`)가 든 인라인 주석을 풀어 썼습니다. 스크립트 분할기가 따옴표 상태를 잘못 추적할 위험을 피하려는 것입니다.
- 다음 파일에도 짧은 헤더 안내를 넣었습니다(보고서 지시는 FK 제거 중심이었습니다). 모두 주석이라 동작에는 영향이 없습니다.
  - Oracle 008·010·012
  - MySQL 001·006·008·010·012·014
- README의 "담긴 것" 표에는 "11 테이블" 제목을 그대로 두고 행만 추가했습니다. 제목과 숫자가 현재 테이블 수와 맞지 않는 기존 문제는 건드리지 않았습니다.

## 이관 메모
- **[이관: 메인]** Oracle 정본 001~014를 제자리 수정했으므로 DBA에게 보낼 때는 수정본을 보내고, 이미 적용된 DB가 있는지는 D2 회신을 기다려야 합니다. 그 전에는 Oracle 015 실행 여부를 알 수 없습니다.
- **[이관: 기획]** CONTRACT_KIND 시드는 기획 확정 뒤 018 다음 번호로 붙입니다. 협약 구분의 세 번째 값과 `NOTICE_STATUS.IN_PROGRESS`의 의미 겹침도 기획이 정해야 합니다(U3).
- **[이관: 보안]** 2단계(Mapper·Service, `RefChecks`·`CodeService`, 경과 처리 쓰기 API)는 security 설계 검토 뒤에 진행합니다. 이번에는 서버 Java 코드를 건드리지 않았습니다.
