## 2. 요구/원인 요약 (근거)
- 지금 POI 방어는 `ZipSecureFile`의 전역 entry 하나 100MB와 비율 0.01뿐이다(`config/PoiLimitsConfig.java:19-27`). 압축 해제 총량 상한과 중복 entry 검사가 없다. 그래서 열기 전에 실제로 풀어 보며 바이트를 세는 `ZipGuard`를 새로 넣는다.
- 오류 처리기는 `ApiException`과 내부 예외 4종만 잡는다(`web/ApiExceptionHandler.java:43-60`). 그래서 `MaxUploadSizeExceededException`은 500이나 Spring 기본 본문으로 나간다.
- 접근 이력은 `detail`에 늘 `null`을 넣는다(`config/AccessLogInterceptor.java:47-48`). 결과 코드를 남길 통로가 없다. 그래서 요청 속성 `ggreport.access.detail`로 받게 한다.
- `PermissionService`에는 `canEdit`만 있다(`service/PermissionService.java:148-164`). 역할 기본 행은 write를 `false`로 만든다(같은 파일 `:291`). 그래서 사용자 예외 행 또는 관리자만 작성할 수 있는 `canWrite`를 새로 둔다.
- `BoardFormService.load`는 숫자 id만 받는다(`:240-247`, `parseId`). `default_doc`은 따로 처리해야 한다.
- `Pii.scan`은 문자열 정규식이다(`support/Pii.java:60`). `#,##0` 서식이 붙은 13자리 숫자는 표시값("9,001,011,234,567")으로는 걸리지 않는다. 그래서 원값(정수 표현)도 함께 검사한다.
- multipart 한도는 전역 50MB이다(`config-envs/*/application.properties`의 max-file-size=50MB). 이건 유지한다.

## 3. 구현안

### 3.1 계약 (요약에서 바뀐 점만)
- **새 오류 코드**(모두 `{"detail":{code,message,…}}`, 값·파일명·POI 메시지 없음):

| 상태 | code | 언제 |
|---|---|---|
| 422 | `TOO_LARGE_UNPACKED` | 실제로 푼 entry 하나가 20MB를 넘거나, 합계가 40MB를 넘거나, entry가 2,000개를 넘을 때 |
| 422 | `DUPLICATE_ENTRY` | entry 이름이 중복될 때(대소문자 무시, 앞 `/` 무시) |
| 413 | `FILE_TOO_LARGE` (`max_mb`) | 업로드 경로에서 Content-Length가 한도+1MB를 넘을 때, 또는 전역 50MB를 넘을 때 |
| 413 | `LENGTH_REQUIRED` | 업로드 경로에 Content-Length가 없을 때 |
| 413 | `BODY_TOO_LARGE` (`max_kb`) | 초안 JSON 본문이 256KB를 넘을 때 |
| 400 | `BAD_REQUEST` · `BAD_VALUE` | 초안 입력이 규칙에 어긋날 때 |

- **개인정보 처리**:
  - 응답 범위(지도 파일의 모든 표 range, 매핑 칸과 sources 격자 포함) 안에서 걸리면 422 `PII_DETECTED`를 낸다. 실리는 것은 `kinds:[{kind,count}]`, `count`, `cells:["기부금!C3",…]`(최대 20)뿐이고 값은 없다.
  - 범위 밖(숨은 시트 포함)에서 걸리면 200을 주고 최상위 `warnings`에 `{code:"PII_OUTSIDE_RANGE",kinds,count,cells}`를 싣는다.
  - 시트 이름 자체에 개인정보가 있으면 좌표를 `#3!A1`처럼 순번으로 쓴다.
  - count는 "걸린 칸 수"다.
- **최상위 `warnings`**에는 `EXTERNAL_LINK`도 들어간다. 칸별 주의(`HIDDEN_*`·`SUM_MISMATCH`)는 지금처럼 각 칸의 `warnings`에 둔다.
- **처리 순서**: 확장자 → 크기 → 세마포어 → OLE2/PK 시그니처 → ZipGuard → 매크로 → POI 열기 → 칸 수 → 개인정보 → 구조 → 값.
- **draft-docx**: 입력 값에 `Pii.scan`을 돌린다. 걸리면 422 `PII_DETECTED`(kinds만)로 거부한다.

```java
package com.kbstar.kgi.ggreport.web.docfill;

import java.io.ByteArrayInputStream;
import java.io.ByteArrayOutputStream;
import java.io.IOException;
import java.util.LinkedHashSet;
import java.util.Locale;
import java.util.Set;
import java.util.zip.ZipEntry;
import java.util.zip.ZipInputStream;

/**
 * OOXML(zip)을 POI 로 열기 전에 실제로 풀어 보며 검사한다. 헤더의 크기 필드는 믿지 않고 읽은 바이트를 센다.
 * 중복 entry 이름(대소문자·앞 '/' 무시)은 거부한다 — CVE-2025-31672 완화(POI 5.2.3 은 중복을 막지 않는다).
 * POI 의 OPCPackage.open(InputStream) 도 로컬 헤더를 순서대로 읽으므로 같은 entry 집합을 본다.
 */
public final class ZipGuard {

    public static final int MAX_ENTRIES = 2000;

    private ZipGuard() {
    }

    public static final class Result {
        public final Set<String> names;      // 소문자로 정규화
        public final byte[] contentTypes;    // [Content_Types].xml, 없으면 null
        public final long unpacked;

        Result(Set<String> names, byte[] contentTypes, long unpacked) {
            this.names = names;
            this.contentTypes = contentTypes;
            this.unpacked = unpacked;
        }
    }

    /** code: TOO_LARGE_UNPACKED | DUPLICATE_ENTRY | BROKEN. 메시지·스택 없음. */
    public static final class Rejected extends Exception {
        public final String code;

        Rejected(String code) {
            super(code, null, false, false);
            this.code = code;
        }
    }

    public static Result check(byte[] zip, long maxEntry, long maxTotal) throws Rejected {
        Set<String> names = new LinkedHashSet<>();
        byte[] ct = null;
        long total = 0;
        byte[] buf = new byte[8192];
        try (ZipInputStream in = new ZipInputStream(new ByteArrayInputStream(zip))) {
            ZipEntry e;
            while ((e = in.getNextEntry()) != null) {
                String name = e.getName().replace('\\', '/').toLowerCase(Locale.ROOT);
                while (name.startsWith("/")) {
                    name = name.substring(1);
                }
                if (!names.add(name)) {
                    throw new Rejected("DUPLICATE_ENTRY");
                }
                if (names.size() > MAX_ENTRIES) {
                    throw new Rejected("TOO_LARGE_UNPACKED");
                }
                ByteArrayOutputStream kept = "[content_types].xml".equals(name) ? new ByteArrayOutputStream() : null;
                long size = 0;
                int n;
                while ((n = in.read(buf)) > 0) {
                    size += n;
                    total += n;
                    if (size > maxEntry || total > maxTotal) {
                        throw new Rejected("TOO_LARGE_UNPACKED");
                    }
                    if (kept != null) {
                        kept.write(buf, 0, n);
                    }
                }
                if (kept != null) {
                    ct = kept.toByteArray();
                }
            }
        } catch (IOException | IllegalArgumentException ex) {   // 깨진 zip·잘못된 이름 인코딩
            throw new Rejected("BROKEN");
        }
        if (names.isEmpty()) {
            throw new Rejected("BROKEN");
        }
        return new Result(names, ct, total);
    }
}
```

**`src/main/java/com/kbstar/kgi/ggreport/web/docfill/XlsxBook.java`**
```java
package com.kbstar.kgi.ggreport.web.docfill;

import com.kbstar.kgi.ggreport.web.support.Pii;
import org.apache.poi.openxml4j.opc.OPCPackage;
import org.apache.poi.ss.usermodel.Cell;
import org.apache.poi.ss.usermodel.CellStyle;
import org.apache.poi.ss.usermodel.CellType;
import org.apache.poi.ss.usermodel.DataFormatter;
import org.apache.poi.ss.usermodel.Row;
import org.apache.poi.ss.usermodel.Sheet;
import org.apache.poi.ss.util.CellRangeAddress;
import org.apache.poi.ss.util.CellReference;
import org.apache.poi.xssf.usermodel.XSSFCell;
import org.apache.poi.xssf.usermodel.XSSFWorkbook;

import java.io.ByteArrayInputStream;
import java.io.Closeable;
import java.math.BigDecimal;
import java.nio.charset.StandardCharsets;
import java.util.*;

/**
 * 업로드된 .xlsx 를 <b>캐시값만</b> 읽는다(재계산·외부 함수 실행 없음, WorkbookFactory 미사용 → HSSF 경로 없음).
 * 열기 전에 {@link ZipGuard} 로 실제 압축 해제량·중복 entry 를 검사하고, 매크로는 zip 이름·[Content_Types].xml 로 거른다.
 * 거부는 코드만 담는다 — POI 메시지·임시 경로는 밖으로 내보내지 않는다(cause 는 예외 클래스 단순 이름, 로그용).
 */
public final class XlsxBook implements Closeable {

    public static final int GRID_CLIP = 200;

    public static final class Limits {
        final long maxEntry;
        final long maxTotal;
        final int maxCells;

        public Limits(long maxEntry, long maxTotal, int maxCells) {
            this.maxEntry = maxEntry;
            this.maxTotal = maxTotal;
            this.maxCells = maxCells;
        }
    }

    public static final class Rejected extends Exception {
        public final int status;
        public final String code;
        public final String cause;

        Rejected(int status, String code, String cause) {
            super(code, null, false, false);
            this.status = status;
            this.code = code;
            this.cause = cause;
        }
    }

    /** display = 서식 적용 표시값(응답에 싣는 것), raw = 원값(숫자는 정수/평문 표현). problem 이 있으면 값 없음. */
    public static final class Value {
        static final Value EMPTY = new Value("", "", null);
        public final String display;
        public final String raw;
        public final String problem;

        Value(String display, String raw, String problem) {
            this.display = display;
            this.raw = raw;
            this.problem = problem;
        }
    }

    public static final class PiiHit {
        public final String sheet;
        public final int row;
        public final int col;
        public final String label;
        public final String kind;

        PiiHit(String sheet, int row, int col, String label, String kind) {
            this.sheet = sheet;
            this.row = row;
            this.col = col;
            this.label = label;
            this.kind = kind;
        }

        public String ref() {
            return row < 0 ? label + "!(시트 이름)" : label + "!" + new CellReference(row, col).formatAsString();
        }
    }

    private final OPCPackage pkg;
    private final XSSFWorkbook wb;
    private final boolean externalLinks;
    private final DataFormatter fmt = new DataFormatter(Locale.KOREA);

    private XlsxBook(OPCPackage pkg, XSSFWorkbook wb, boolean externalLinks) {
        this.pkg = pkg;
        this.wb = wb;
        this.externalLinks = externalLinks;
    }

    public static XlsxBook open(byte[] data, Limits lim) throws Rejected {
        if (isOle2(data) || !isZip(data)) {
            throw new Rejected(415, "NOT_XLSX", null);         // .xls·암호 걸린 xlsx(OLE2)·기타
        }
        ZipGuard.Result z;
        try {
            z = ZipGuard.check(data, lim.maxEntry, lim.maxTotal);
        } catch (ZipGuard.Rejected e) {
            throw new Rejected(422, e.code, null);
        }
        if (macro(z)) {
            throw new Rejected(422, "MACRO", null);
        }
        boolean ext = false;
        for (String n : z.names) {
            ext |= n.startsWith("xl/externallinks/");
        }
        OPCPackage pkg = null;
        try {
            pkg = OPCPackage.open(new ByteArrayInputStream(data));
            XlsxBook b = new XlsxBook(pkg, new XSSFWorkbook(pkg), ext);
            if (b.cellCount(lim.maxCells) > lim.maxCells) {
                b.close();
                throw new Rejected(422, "TOO_MANY_CELLS", null);
            }
            return b;
        } catch (Rejected r) {
            throw r;
        } catch (Exception e) {                                // InvalidFormat·IO·POIXML·Runtime
            if (pkg != null) {
                pkg.revert();
            }
            throw new Rejected(422, "BROKEN", e.getClass().getSimpleName());
        }
    }

    public boolean hasExternalLinks() { return externalLinks; }

    public Sheet sheet(String name) { return wb.getSheet(name); }

    public boolean isHidden(Sheet s) {
        int i = wb.getSheetIndex(s);
        return wb.isSheetHidden(i) || wb.isSheetVeryHidden(i);
    }

    public static boolean rowHidden(Sheet s, int row) {
        Row r = s.getRow(row);
        return r != null && r.getZeroHeight();
    }

    public Value value(Sheet s, int row, int col) {
        Row r = s.getRow(row);
        return valueOf(r == null ? null : r.getCell(col));
    }

    Value valueOf(Cell c) {
        if (c == null) {
            return Value.EMPTY;
        }
        CellType t = c.getCellType();
        if (t == CellType.FORMULA) {
            if (!((XSSFCell) c).getCTCell().isSetV()) {
                return new Value("", "", "NO_CACHED_VALUE");
            }
            t = c.getCachedFormulaResultType();
        }
        switch (t) {
            case NUMERIC:
                double d = c.getNumericCellValue();
                CellStyle st = c.getCellStyle();
                return new Value(fmt.formatRawCellContents(d, st.getDataFormat(), st.getDataFormatString()), raw(d), null);
            case STRING:
                String s = c.getRichStringCellValue().getString();
                return new Value(s, s, null);
            case BOOLEAN:
                String b = c.getBooleanCellValue() ? "TRUE" : "FALSE";
                return new Value(b, b, null);
            case ERROR:
                return new Value("", "", "EXCEL_ERROR");
            default:
                return Value.EMPTY;
        }
    }

    /** 숫자 원값 — 정수면 정수 표현(서식에 가려진 13자리도 그대로), 아니면 평문 소수. */
    static String raw(double d) {
        if (Double.isNaN(d) || Double.isInfinite(d)) {
            return "";
        }
        if (d == Math.rint(d) && Math.abs(d) < 1e15) {
            return Long.toString((long) d);
        }
        return BigDecimal.valueOf(d).stripTrailingZeros().toPlainString();
    }

    /** 통합문서 전체(숨은 시트 포함). 칸마다 표시값·원값 둘 다 검사하고, 종류별로 칸당 1건. 시트 이름도 검사. */
    public List<PiiHit> scanPii() {
        List<PiiHit> hits = new ArrayList<>();
        for (int i = 0; i < wb.getNumberOfSheets(); i++) {
            Sheet s = wb.getSheetAt(i);
            Set<String> nameKinds = kinds(s.getSheetName(), null);
            String label = nameKinds.isEmpty() ? s.getSheetName() : "#" + (i + 1);
            for (String k : nameKinds) {
                hits.add(new PiiHit(s.getSheetName(), -1, -1, label, k));
            }
            for (Row r : s) {
                for (Cell c : r) {
                    Value v = valueOf(c);
                    for (String k : kinds(v.display, v.raw)) {
                        hits.add(new PiiHit(s.getSheetName(), r.getRowNum(), c.getColumnIndex(), label, k));
                    }
                }
            }
        }
        return hits;
    }

    private static Set<String> kinds(String a, String b) {
        Set<String> out = new LinkedHashSet<>();
        for (Pii.Finding f : Pii.scan(a)) {
            out.add(f.getKind());
        }
        if (b != null && !b.equals(a)) {
            for (Pii.Finding f : Pii.scan(b)) {
                out.add(f.getKind());
            }
        }
        return out;
    }

    /** 출처 격자: 범위 안 표시값(칸당 200자 자름)·병합. */
    public Map<String, Object> grid(String sheetName, CellRangeAddress range) {
        Sheet s = wb.getSheet(sheetName);
        List<String> cols = new ArrayList<>();
        for (int c = range.getFirstColumn(); c <= range.getLastColumn(); c++) {
            cols.add(CellReference.convertNumToColString(c));
        }
        List<List<String>> rows = new ArrayList<>();
        for (int r = range.getFirstRow(); r <= range.getLastRow(); r++) {
            List<String> row = new ArrayList<>();
            for (int c = range.getFirstColumn(); c <= range.getLastColumn(); c++) {
                Value v = value(s, r, c);
                String d = v.problem == null ? v.display : "";
                row.add(d.length() > GRID_CLIP ? d.substring(0, GRID_CLIP) : d);
            }
            rows.add(row);
        }
        List<String> merges = new ArrayList<>();
        for (CellRangeAddress m : s.getMergedRegions()) {
            if (range.intersects(m)) {
                merges.add(m.formatAsString());
            }
        }
        Map<String, Object> out = new LinkedHashMap<>();
        out.put("sheet", sheetName);
        out.put("range", range.formatAsString());
        out.put("first_row", range.getFirstRow() + 1);
        out.put("cols", cols);
        out.put("rows", rows);
        out.put("merges", merges);
        return out;
    }

    private int cellCount(int max) {
        int n = 0;
        for (Sheet s : wb) {
            for (Row r : s) {
                n += r.getPhysicalNumberOfCells();
                if (n > max) {
                    return n;
                }
            }
        }
        return n;
    }

    private static boolean macro(ZipGuard.Result z) {
        for (String n : z.names) {
            if (n.endsWith("vbaproject.bin") || n.startsWith("xl/macrosheets/")
                    || n.startsWith("xl/dialogsheets/") || n.startsWith("xl/activex/")) {
                return true;
            }
        }
        String ct = z.contentTypes == null ? ""
                : new String(z.contentTypes, StandardCharsets.UTF_8).toLowerCase(Locale.ROOT);
        return ct.contains("macroenabled") || ct.contains("vbaproject");
    }

    private static boolean isZip(byte[] d) {
        return d.length >= 4 && d[0] == 'P' && d[1] == 'K' && d[2] == 3 && d[3] == 4;
    }

    private static boolean isOle2(byte[] d) {
        int[] sig = {0xD0, 0xCF, 0x11, 0xE0, 0xA1, 0xB1, 0x1A, 0xE1};
        if (d.length < sig.length) {
            return false;
        }
        for (int i = 0; i < sig.length; i++) {
            if ((d[i] & 0xFF) != sig[i]) {
                return false;
            }
        }
        return true;
    }

    @Override
    public void close() {
        pkg.revert();                                          // 스트림으로 연 패키지 — 저장 없이 버린다
    }
}
```

```java
package com.kbstar.kgi.ggreport.web.boarddoc;

import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.apache.poi.ss.util.CellRangeAddress;
import org.apache.poi.ss.util.CellReference;
import org.springframework.core.io.ClassPathResource;
import org.springframework.stereotype.Component;

import java.io.IOException;
import java.io.InputStream;
import java.util.*;

/** 엑셀→양식 매핑. 기동 시 검증(카탈로그 매핑 칸 집합과 정확히 일치·범위 안·범위 합 2,000칸 이하) — 실패면 기동 실패. */
@Component
public class BoardExcelMap {

    public static final String RESOURCE = "boarddoc/excel-map.json";
    public static final int MAX_RANGE_CELLS = 2000;

    public static final class Sum {
        private final List<String> of;
        private final String total;

        Sum(List<String> of, String total) { this.of = of; this.total = total; }

        public List<String> getOf() { return of; }
        public String getTotal() { return total; }
    }

    public static final class TableMap {
        private final String ref;
        private final String sheet;
        private final CellRangeAddress range;
        private final Map<String, String> labels;
        private final Map<String, CellReference> cells;
        private final List<Sum> sums;

        TableMap(String ref, String sheet, CellRangeAddress range, Map<String, String> labels,
                 Map<String, CellReference> cells, List<Sum> sums) {
            this.ref = ref; this.sheet = sheet; this.range = range;
            this.labels = labels; this.cells = cells; this.sums = sums;
        }

        public String getRef() { return ref; }
        public String getSheet() { return sheet; }
        public CellRangeAddress getRange() { return range; }
        public Map<String, String> getLabels() { return labels; }
        public Map<String, CellReference> getCells() { return cells; }
        public List<Sum> getSums() { return sums; }
    }

    private final int mappingVer;
    private final Map<String, TableMap> tables = new LinkedHashMap<>();

    public BoardExcelMap() {
        this(read());
    }

    BoardExcelMap(JsonNode root) {
        mappingVer = root.path("mapping_ver").asInt(0);
        if (mappingVer < 1 || root.path("catalog_ver").asInt(-1) != BoardDocSpec.CATALOG_VER) {
            bad("version");
        }
        int rangeCells = 0;
        for (JsonNode t : root.path("tables")) {
            String ref = t.path("ref").asText();
            BoardDocSpec.Table cat = BoardDocSpec.catalogTable(ref, false);
            String sheet = t.path("sheet").asText();
            if (cat == null || tables.containsKey(ref) || sheet.isEmpty() || sheet.length() > 31) {
                bad("table " + ref);
            }
            CellRangeAddress range = CellRangeAddress.valueOf(t.path("range").asText());
            rangeCells += range.getNumberOfCells();
            Map<String, CellReference> cells = new LinkedHashMap<>();
            Iterator<Map.Entry<String, JsonNode>> it = t.path("cells").fields();
            while (it.hasNext()) {
                Map.Entry<String, JsonNode> e = it.next();
                put(cells, e.getKey(), new CellReference(e.getValue().asText()), range, ref);
            }
            for (JsonNode b : t.path("blocks")) {
                CellReference from = new CellReference(b.path("from").asText());
                for (int i = 0; i < b.path("rows").asInt(); i++) {
                    for (int j = 0; j < b.path("cols").asInt(); j++) {
                        put(cells, BoardDocSpec.cellKey(b.path("key_row").asInt() + i, b.path("seq").asInt() + j),
                                new CellReference(from.getRow() + i, from.getCol() + j), range, ref);
                    }
                }
            }
            if (!mappedKeys(cat).equals(cells.keySet())) {
                bad("cells " + ref);
            }
            Set<String> addrs = new HashSet<>();
            for (CellReference c : cells.values()) {
                addrs.add(c.formatAsString());
            }
            Map<String, String> labels = new LinkedHashMap<>();
            it = t.path("labels").fields();
            while (it.hasNext()) {
                Map.Entry<String, JsonNode> e = it.next();
                CellReference c = new CellReference(e.getKey());
                if (!range.isInRange(c.getRow(), c.getCol()) || addrs.contains(c.formatAsString())) {
                    bad("label " + ref);
                }
                labels.put(c.formatAsString(), e.getValue().asText());
            }
            List<Sum> sums = new ArrayList<>();
            for (JsonNode s : t.path("sums")) {
                List<String> of = new ArrayList<>();
                for (JsonNode k : s.path("of")) {
                    of.add(k.asText());
                }
                String total = s.path("total").asText();
                if (of.isEmpty() || !cells.keySet().containsAll(of) || !cells.containsKey(total)) {
                    bad("sum " + ref);
                }
                sums.add(new Sum(of, total));
            }
            tables.put(ref, new TableMap(ref, sheet, range, labels, cells, sums));
        }
        if (tables.isEmpty() || rangeCells > MAX_RANGE_CELLS) {
            bad("size");
        }
    }

    public int getMappingVer() { return mappingVer; }
    public TableMap table(String ref) { return tables.get(ref); }
    public Collection<TableMap> tables() { return tables.values(); }

    /** 응답에 실리는 범위(어느 표의 range 든) 안인가. */
    public boolean covers(String sheet, int row, int col) {
        for (TableMap t : tables.values()) {
            if (t.sheet.equals(sheet) && row >= 0 && t.range.isInRange(row, col)) {
                return true;
            }
        }
        return false;
    }

    private static void put(Map<String, CellReference> cells, String key, CellReference c,
                            CellRangeAddress range, String ref) {
        if (!range.isInRange(c.getRow(), c.getCol()) || cells.put(key, c) != null) {
            bad("cell " + ref + " " + key);
        }
    }

    private static Set<String> mappedKeys(BoardDocSpec.Table t) {
        Set<String> out = new LinkedHashSet<>();
        for (int r = 0; r < t.getRows().size(); r++) {
            for (int i = 0; i < t.getRows().get(r).size(); i++) {
                if (t.getRows().get(r).get(i).isMapped()) {
                    out.add(BoardDocSpec.cellKey(r, i));
                }
            }
        }
        return out;
    }

    private static JsonNode read() {
        try (InputStream in = new ClassPathResource(RESOURCE).getInputStream()) {
            return new ObjectMapper().readTree(in);
        } catch (IOException e) {
            throw new IllegalStateException("excel-map missing");
        }
    }

    private static void bad(String why) {
        throw new IllegalStateException("excel-map invalid: " + why);
    }
}
```

```java
package com.kbstar.kgi.ggreport.web.boarddoc;

import com.kbstar.kgi.ggreport.web.docfill.XlsxBook;
import org.apache.poi.ss.usermodel.Sheet;
import org.apache.poi.ss.util.CellReference;

import java.math.BigDecimal;
import java.util.*;

/** 구조 검사(머리글 라벨) → 값 채우기(캐시값) → 합계 주의. 개인정보 검사는 이 앞에서 끝났다(호출자 몫). */
public final class BoardExcelFill {

    static final int MAX_REASONS = 20;
    static final int ACTUAL_CLIP = 40;

    private BoardExcelFill() {
    }

    public static List<Map<String, Object>> structure(XlsxBook b, BoardExcelMap m, List<String> refs) {
        List<Map<String, Object>> out = new ArrayList<>();
        for (String ref : refs) {
            BoardExcelMap.TableMap t = m.table(ref);
            Sheet s = b.sheet(t.getSheet());
            if (s == null) {
                out.add(reason(ref, t.getSheet(), null, null, null));
                continue;
            }
            for (Map.Entry<String, String> l : t.getLabels().entrySet()) {
                CellReference c = new CellReference(l.getKey());
                String actual = norm(b.value(s, c.getRow(), c.getCol()).display);
                if (!norm(l.getValue()).equals(actual)) {
                    out.add(reason(ref, t.getSheet(), l.getKey(), l.getValue(),
                            actual.length() > ACTUAL_CLIP ? actual.substring(0, ACTUAL_CLIP) : actual));
                }
                if (out.size() >= MAX_REASONS) {
                    return out;
                }
            }
        }
        return out;
    }

    public static Map<String, Object> fill(XlsxBook b, BoardExcelMap m, BoardDocSpec.Doc doc) {
        List<Map<String, Object>> tables = new ArrayList<>();
        List<Map<String, Object>> sources = new ArrayList<>();
        List<String> unmapped = new ArrayList<>();
        int total = 0, filled = 0, failed = 0, warns = 0;
        for (BoardDocSpec.Table dt : doc.getTables()) {
            BoardExcelMap.TableMap t = m.table(dt.getId());
            if (t == null) {
                unmapped.add(dt.getId());
                continue;
            }
            Sheet s = b.sheet(t.getSheet());
            boolean hiddenSheet = b.isHidden(s);
            Map<String, XlsxBook.Value> vals = new HashMap<>();
            Map<String, Map<String, Object>> byKey = new LinkedHashMap<>();
            for (Map.Entry<String, CellReference> e : t.getCells().entrySet()) {
                CellReference at = e.getValue();
                XlsxBook.Value v = b.value(s, at.getRow(), at.getCol());
                vals.put(e.getKey(), v);
                String shown = v.display.trim();
                String reason = v.problem != null ? v.problem : shown.isEmpty() ? "EMPTY"
                        : shown.length() > BoardDocSpec.MAX_CELL ? "TOO_LONG" : null;
                List<Map<String, Object>> w = new ArrayList<>();
                if (hiddenSheet) w.add(code("HIDDEN_SHEET"));
                if (XlsxBook.rowHidden(s, at.getRow())) w.add(code("HIDDEN_ROW"));
                if (s.isColumnHidden(at.getCol())) w.add(code("HIDDEN_COLUMN"));
                Map<String, Object> source = new LinkedHashMap<>();
                source.put("sheet", t.getSheet());
                source.put("cell", at.formatAsString());
                source.put("display", reason == null ? shown : "");
                Map<String, Object> c = new LinkedHashMap<>();
                c.put("key", e.getKey());
                c.put("value", reason == null ? shown : "");
                c.put("status", reason == null ? "filled" : "failed");
                c.put("reason", reason);
                c.put("source", source);
                c.put("warnings", w);
                byKey.put(e.getKey(), c);
            }
            for (BoardExcelMap.Sum sm : t.getSums()) {
                BigDecimal acc = BigDecimal.ZERO;
                boolean ok = true;
                for (String k : sm.getOf()) {
                    BigDecimal x = num(vals.get(k));
                    ok &= x != null;
                    acc = x == null ? acc : acc.add(x);
                }
                BigDecimal tot = num(vals.get(sm.getTotal()));
                if (ok && tot != null && acc.compareTo(tot) != 0) {
                    Map<String, Object> w = code("SUM_MISMATCH");
                    w.put("expected", acc.toPlainString());
                    warnings(byKey.get(sm.getTotal())).add(w);
                }
            }
            for (Map<String, Object> c : byKey.values()) {
                total++;
                if ("filled".equals(c.get("status"))) filled++; else failed++;
                warns += warnings(c).size();
            }
            Map<String, Object> tm = new LinkedHashMap<>();
            tm.put("ref", t.getRef());
            tm.put("cells", new ArrayList<>(byKey.values()));
            tables.add(tm);
            Map<String, Object> src = new LinkedHashMap<>();
            src.put("ref", t.getRef());
            src.putAll(b.grid(t.getSheet(), t.getRange()));
            sources.add(src);
        }
        Map<String, Object> summary = new LinkedHashMap<>();
        summary.put("total", total);
        summary.put("filled", filled);
        summary.put("failed", failed);
        summary.put("warnings", warns);
        Map<String, Object> out = new LinkedHashMap<>();
        out.put("summary", summary);
        out.put("tables", tables);
        out.put("sources", sources);
        out.put("unmapped_tables", unmapped);
        return out;
    }

    @SuppressWarnings("unchecked")
    private static List<Map<String, Object>> warnings(Map<String, Object> cell) {
        return (List<Map<String, Object>>) cell.get("warnings");
    }

    private static BigDecimal num(XlsxBook.Value v) {
        if (v == null || v.problem != null || v.raw.isEmpty()) {
            return null;
        }
        try {
            return new BigDecimal(v.raw);
        } catch (NumberFormatException e) {
            return null;
        }
    }

    private static Map<String, Object> code(String c) {
        Map<String, Object> m = new LinkedHashMap<>();
        m.put("code", c);
        return m;
    }

    private static Map<String, Object> reason(String ref, String sheet, String cell, String expected, String actual) {
        Map<String, Object> m = new LinkedHashMap<>();
        m.put("ref", ref);
        m.put("code", cell == null ? "SHEET_MISSING" : "LABEL_MISMATCH");
        m.put("sheet", sheet);
        m.put("cell", cell);
        m.put("expected", expected);
        m.put("actual", actual);
        return m;
    }

    private static String norm(String s) {
        return s == null ? "" : s.trim().replaceAll("\\s+", " ");
    }
}
```

```java
package com.kbstar.kgi.ggreport.web.service;

import com.kbstar.kgi.ggreport.web.boarddoc.BoardDocSpec;
import com.kbstar.kgi.ggreport.web.boarddoc.BoardExcelFill;
import com.kbstar.kgi.ggreport.web.boarddoc.BoardExcelMap;
import com.kbstar.kgi.ggreport.web.docfill.XlsxBook;
import com.kbstar.kgi.ggreport.web.dto.BoardWriteIn;
import com.kbstar.kgi.ggreport.web.support.Pii;
import com.kbstar.kgi.ggreport.web.web.ApiException;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;
import java.util.*;
import java.util.concurrent.Semaphore;

/**
 * 이사회 자료 작성(무상태): 엑셀 업로드 → 매핑 칸 값, 화면 값 → 초안 워드. 원본 바이트는 요청 끝에 버린다.
 * 개인정보: 응답에 실리는 범위(지도 range) 안에서 걸리면 거부, 밖이면 경고(종류·칸 수·좌표만, 값 없음) — 2026-11-02 확정.
 * 로그에는 예외 클래스 이름만 남긴다(POI 메시지·경로 없음).
 */
@Service
public class BoardWriteService {

    private static final Logger log = LoggerFactory.getLogger(BoardWriteService.class);
    static final long MB = 1024L * 1024;
    static final int MAX_DRAFT_TABLES = 20;
    static final int MAX_DRAFT_CELLS = 500;
    static final int MAX_PII_CELLS = 20;

    private final BoardFormService forms;
    private final BoardExcelMap map;
    private final int maxMb;
    private final int concurrency;
    private final XlsxBook.Limits limits;
    private final Semaphore slots;

    public BoardWriteService(BoardFormService forms, BoardExcelMap map,
                             @Value("${ggreport.board-write.max-mb:5}") int maxMb,
                             @Value("${ggreport.board-write.max-unpacked-entry-mb:20}") int entryMb,
                             @Value("${ggreport.board-write.max-unpacked-total-mb:40}") int totalMb,
                             @Value("${ggreport.board-write.max-cells:200000}") int maxCells,
                             @Value("${ggreport.board-write.concurrency:2}") int concurrency) {
        this.forms = forms;
        this.map = map;
        this.maxMb = maxMb;
        this.concurrency = concurrency;
        this.limits = new XlsxBook.Limits(entryMb * MB, totalMb * MB, maxCells);
        this.slots = new Semaphore(concurrency);
    }

    public int getMaxMb() { return maxMb; }

    int availableSlots() { return slots.availablePermits(); }

    int getConcurrency() { return concurrency; }

    public Map<String, Object> excelMap() {
        List<Map<String, Object>> tables = new ArrayList<>();
        for (BoardExcelMap.TableMap t : map.tables()) {
            Map<String, Object> m = new LinkedHashMap<>();
            m.put("ref", t.getRef());
            m.put("sheet", t.getSheet());
            m.put("range", t.getRange().formatAsString());
            tables.add(m);
        }
        Map<String, Object> out = new LinkedHashMap<>();
        out.put("mapping_ver", map.getMappingVer());
        out.put("max_mb", maxMb);
        out.put("tables", tables);
        return out;
    }

    public Map<String, Object> upload(String empNo, String id, String version, MultipartFile file) {
        BoardFormService.WriteTarget target = forms.formForWrite(empNo, id, version);
        if (file == null || file.isEmpty()) {
            throw fail(400, "EMPTY_FILE", "빈 파일입니다. 엑셀(.xlsx) 파일을 골라 주세요.");
        }
        if (file.getSize() > maxMb * MB) {
            Map<String, Object> d = detail("FILE_TOO_LARGE", "파일이 너무 큽니다. " + maxMb + "MB 이하만 올릴 수 있습니다.");
            d.put("max_mb", maxMb);
            throw ApiException.withDetail(413, d);
        }
        String name = file.getOriginalFilename() == null ? "" : file.getOriginalFilename().toLowerCase(Locale.ROOT);
        if (name.endsWith(".xlsm")) {
            throw fail(422, "MACRO", "매크로가 든 파일은 올릴 수 없습니다. 매크로 없는 .xlsx 로 저장해 주세요.");
        }
        if (!name.endsWith(".xlsx")) {
            throw fail(415, "NOT_XLSX", "엑셀(.xlsx) 파일만 올릴 수 있습니다. 암호가 걸린 파일은 암호를 풀고 저장해 주세요.");
        }
        byte[] data;
        try {
            data = file.getBytes();
        } catch (IOException e) {
            throw fail(422, "BROKEN", MSG_BROKEN);
        }
        if (!slots.tryAcquire()) {
            throw fail(503, "BUSY", "다른 작업을 처리하고 있습니다. 잠시 후 다시 시도해 주세요.");
        }
        try {
            try (XlsxBook book = open(data)) {
                return process(target, book);
            }
        } finally {
            slots.release();
        }
    }

    private XlsxBook open(byte[] data) {
        try {
            return XlsxBook.open(data, limits);
        } catch (XlsxBook.Rejected r) {
            if (r.cause != null) {
                log.warn("엑셀 열기 실패: {}", r.cause);
            }
            throw fail(r.status, r.code, message(r.code));
        }
    }

    private Map<String, Object> process(BoardFormService.WriteTarget target, XlsxBook book) {
        List<XlsxBook.PiiHit> inside = new ArrayList<>();
        List<XlsxBook.PiiHit> outside = new ArrayList<>();
        for (XlsxBook.PiiHit h : book.scanPii()) {
            (map.covers(h.sheet, h.row, h.col) ? inside : outside).add(h);
        }
        if (!inside.isEmpty()) {
            throw ApiException.withDetail(422, pii(detail("PII_DETECTED",
                    "작성에 쓰는 칸에 개인정보로 보이는 값이 있어 처리하지 않았습니다. 해당 칸을 지우고 다시 올려 주세요."), inside));
        }
        List<String> refs = new ArrayList<>();
        for (BoardDocSpec.Table t : target.getDoc().getTables()) {
            if (map.table(t.getId()) != null) {
                refs.add(t.getId());
            }
        }
        List<Map<String, Object>> reasons = BoardExcelFill.structure(book, map, refs);
        if (!reasons.isEmpty()) {
            Map<String, Object> d = detail("STRUCTURE_MISMATCH", "엑셀 양식이 예상한 모양과 다릅니다.");
            d.put("reasons", reasons);
            throw ApiException.withDetail(422, d);
        }
        Map<String, Object> filled = BoardExcelFill.fill(book, map, target.getDoc());
        List<Map<String, Object>> warnings = new ArrayList<>();
        if (book.hasExternalLinks()) {
            warnings.add(detail("EXTERNAL_LINK", "다른 파일을 참조하는 연결이 있습니다. 값은 마지막으로 저장된 값입니다."));
        }
        if (!outside.isEmpty()) {
            warnings.add(pii(detail("PII_OUTSIDE_RANGE",
```

```java
import javax.servlet.http.HttpServletResponse;

/**
 * 작성 경로 전용 본문 크기 사전 차단 — multipart 해석(전역 50MB)·JSON 파싱 <b>전에</b> Content-Length 로 413.
 * 엑셀: 한도(5MB)+여유 1MB, 초안 JSON: 256KB. 길이가 없으면(chunked) 413 LENGTH_REQUIRED.
 * ⚠️ 이미 해석된 MultipartHttpServletRequest(MockMvc 전용 — 실제 컨테이너에선 이 시점에 없다)는 통과시킨다.
 * ⚠️ getParameter 를 부르지 않는다(부르면 컨테이너가 본문을 해석한다). 응답에 Connection: close 를 붙여 남은 본문을 읽지 않는다.
 */
@Component
@Order(Ordered.HIGHEST_PRECEDENCE + 1)
public class BoardWriteLimitFilter implements Filter {

    static final long MB = 1024L * 1024;
    static final long SLACK = MB;
    static final long DRAFT_MAX = 256L * 1024;
    private static final Pattern EXCEL = Pattern.compile("^/board-forms/[^/]+/excel$");
    private static final Pattern DRAFT = Pattern.compile("^/board-forms/[^/]+/draft-docx$");

    private final AccessLogService accessLog;
    private final int maxMb;

    public BoardWriteLimitFilter(AccessLogService accessLog, @Value("${ggreport.board-write.max-mb:5}") int maxMb) {
        this.accessLog = accessLog;
        this.maxMb = maxMb;
    }

    @Override
    public void init(FilterConfig filterConfig) {
    }

    @Override
    public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain)
            throws IOException, ServletException {
        if (!(request instanceof HttpServletRequest) || request instanceof MultipartHttpServletRequest
                || !"POST".equals(((HttpServletRequest) request).getMethod())) {
            chain.doFilter(request, response);
            return;
        }
        HttpServletRequest req = (HttpServletRequest) request;
        String path = req.getRequestURI().substring(req.getContextPath().length());
        boolean excel = EXCEL.matcher(path).matches();
        long limit = excel ? maxMb * MB + SLACK : DRAFT.matcher(path).matches() ? DRAFT_MAX : -1;
        long len = req.getContentLengthLong();
        if (limit < 0 || (len >= 0 && len <= limit)) {
            chain.doFilter(request, response);
            return;
        }
        String code = len < 0 ? "LENGTH_REQUIRED" : excel ? "FILE_TOO_LARGE" : "BODY_TOO_LARGE";
        String extra = excel ? ",\"max_mb\":" + maxMb : ",\"max_kb\":" + (DRAFT_MAX / 1024);
        HttpServletResponse res = (HttpServletResponse) response;
        res.setStatus(413);
        res.setHeader("Connection", "close");
        res.setContentType("application/json;charset=UTF-8");
        res.getOutputStream().write(("{\"detail\":{\"code\":\"" + code + "\"" + extra + "}}")
                .getBytes(StandardCharsets.UTF_8));
        accessLog.record(Actor.of(req), "API", req.getMethod(), req.getRequestURI(), 413,
                req.getRemoteAddr(), req.getHeader("User-Agent"), null,
                "board-write code=" + code + " size=" + len);
    }

    @Override
    public void destroy() {
    }
}
```

## 5. 보안·위험·되돌리는 법
- **권한**:
  - 업로드와 초안은 `requireWrite`를 거친다. 401·403은 DENIED로 경로만 남는다.
  - 크기 사전 차단 필터는 권한 판정 전에 동작한다. 그래서 권한이 없어도 413을 받는다. 정보 노출은 없다.
  - 인증은 X-Emp-No 자기신고이고, SSO가 붙기 전에는 보안 경계가 아니다.
- **접근 이력**: detail은 `board-write code=… pii_kinds=N size=…` 형식이다. 파일명·값·본문은 넣지 않는다. 필터 거부도 따로 기록한다.
- **잔여 위험 1, 메모리**: XSSF DOM은 40MB로 푼 XML에서도 수백 MB 힙을 쓸 수 있다. 동시 2건 상한과 함께 운영 힙에 맞춰 `max-unpacked-total-mb`를 낮출 수 있다.
- **잔여 위험 2, 413 응답 수신**: Tomcat은 남은 본문이 maxSwallowSize(2MB)를 넘으면 연결을 끊는다. 이때 브라우저는 413 대신 네트워크 오류를 볼 수 있다. 화면이 `max_mb`로 사전 검사하는 것이 1차 방어다.
- **잔여 위험 3, 오탐**: `0` 서식의 13자리 숫자(사업자·계좌번호 등)가 주민번호 패턴에 맞으면, 응답 범위 안에서는 거부된다. 사용자가 확정한 정책이다.
- **잔여 위험 4, 검사 범위**: 수식 문자열·메모·문서 속성은 검사하지 않는다. 응답에 싣지 않는 값들이다.
- **MockMvc 예외**: 필터는 이미 해석된 `MultipartHttpServletRequest`를 통과시킨다. MockMvc 전용이고, 실제 컨테이너에서는 이 시점에 그런 요청 객체가 없다.
- **POI 5.4.x 상향(영향 분석만, 이번 패치에서 제외)**:
  - 중복 entry를 거부하는 CVE-2025-31672 수정은 5.4.1에 들어 있다. 이번 패치는 ZipGuard로 같은 효과를 앞단에서 낸다.
  - 상향하면 poi, poi-ooxml, poi-ooxml-lite, xmlbeans, commons-compress, commons-io, commons-codec, log4j-api 등의 전이 버전이 함께 바뀐다(추정). 폐쇄망 반입 목록(`dependencies.txt`)과 README §9 절차를 다시 해야 한다. 이 두 파일은 읽지 않았다.
  - JDK 1.8 호환은 반입 전에 `mvn dependency:tree`와 각 jar의 Java 기준 버전으로 확인해야 한다.
  - 회귀 위험은 POI가 쓰는 기존 테스트(BoardDocDocx, PptxBuilder, docfill)에 있다.
  - 취약점 영향 판단은 security 몫이다(사용자 결정).
- **되돌리는 법**:
  - 새 파일 8개와 테스트를 삭제하고, 기존 파일 7개의 변경을 되돌린다.
  - DB 변경이 없어 마이그레이션 되돌림은 필요 없다.
  - 기능만 끄려면 `BoardWriteController` 하나만 빼도 된다(지도·서비스는 독립).
