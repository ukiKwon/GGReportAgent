NEXT 90 HWP 묶음을 적용했습니다. 빌드와 시험은 돌리지 못했습니다(Bash가 없습니다). 아래 컴파일 불확실 항목과 mvn 결과를 메인이 확인해 주세요.

1. 고친 파일 3개 (모두 kgi-ggreport-web/ 아래)
   - pom.xml: poi-ooxml 뒤에 hwplib 1.1.9를 넣었습니다.
   - src/main/java/com/kbstar/kgi/ggreport/web/service/ExtCheckInspector.java: HWP 검사 구간(inspectHwp 등)을 넣었고, inspect()와 run()을 fmt 문자열 기준으로 바꿨습니다.
   - src/test/java/com/kbstar/kgi/ggreport/web/service/ExtCheckInspectorTest.java: 94~96줄을 고치고, 합성 HWP 시험과 실물 폴더 회귀 시험을 끝에 추가했습니다.

2. 2번 반영
   - HWP_SCRIPT_SHA256을 Map<String, Set<String>>로 바꿔 알려주신 해시 6개를 넣었습니다.
   - _LinkDoc은 UTF-16LE로 읽고 NUL을 지운 뒤 scanText(위치 meta)로 검사합니다. 크기는 HWP_SMALL_MAX입니다.
   - IMAGE_EXT에는 gif·wmf·emf가 이미 있어 추가하지 않았고 주석만 달았습니다. HWPX와 같이 쓰는 집합이라 영향은 없습니다.

3. 4번 반영
   - 실물_폴더_회귀 시험은 -Dextcheck.realDir가 없으면 Assume으로 건너뜁니다. 있으면 *.hwp·*.hwpx를 모두 검사해 PASS와 "hwp:사유@위치" 건수만 출력합니다. 파일명과 값은 출력하지 않습니다.

4. 지시서와 다른 곳
   - 합성_HWP_Scripts_이름만_같고_내용이_다르면_SCRIPT 시험을 새로 넣었습니다.
   - 합성 시험 이름을 합성_HWP_본문_미리보기_요약정보_연결문서의_번호로 바꿨고, _LinkDoc 번호 검사를 넣었습니다.
   - IMAGE_ONLY 시험에 gif·wmf 사례를 추가했습니다.
   - 지시서가 정리하라던 시험 군더더기 두 곳(합성_HWP_구조_거부의 삼항 줄, 끝의 new Hwp(0).base("x"))은 지웠습니다.
   - hwplib 통과 시험의 첫 assertTrue에 실패 메시지를 붙였습니다.

5. 컴파일 불확실
   - hwplib 메서드 시그니처는 jar에서 확인하지 못해 지시서 그대로 썼습니다. 대상은 HWPReader.fromFile(String), TextExtractor.extract(HWPFile, TextExtractMethod.InsertControlTextBetweenParagraphText), BlankFileMaker.make(), HWPWriter.toFile(HWPFile, String), 그리고 getBodyText().getSectionList().get(0).getParagraph(0).getText().addString입니다. 고칠 곳은 inspectHwp 3단계와 시험의 blankHwp 두 군데뿐입니다.
   - POI 5.2.3 기준으로 POIFSFileSystem(File, boolean), DirectoryNode.createDocumentInputStream(Entry), fs.createDirectory가 맞는지도 컴파일로 확인이 필요합니다.
   - FileHeader 속성 비트 9·10·13·14는 기억 기반입니다(틀려도 더 많이 거부하는 쪽).

6. 실행할 명령과 기대 결과
   - cd kgi-ggreport-web && mvn -q -o test -Dtest=ExtCheckInspectorTest
     기대 결과는 모두 통과이고, 실물_폴더_회귀는 skip입니다. hwplib로_만든_HWP는_통과…가 실패하면 먼저 API 이름을 의심하세요.
   - 이어서 mvn -q -o test 로 전체를 돌립니다.
   - 실물 회귀는 -Dtest=ExtCheckInspectorTest#실물_폴더_회귀 -Dextcheck.realDir=<폴더> 로 돌립니다.
   - pom에 의존성이 늘었으므로 -o 실행 시 ~/.m2에 hwplib 1.1.9가 있어야 합니다. jar가 있다고 하셨으니 pom도 확인 대상입니다.
