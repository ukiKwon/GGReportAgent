## 완성 시험 코드 3종 (읽기 전용·미컴파일. 도우미 이름은 HeadApiTestBase 에서 확인해 그대로 썼다)

확인한 사실:
- HeadDocBuilder.hasContent 는 `public static boolean hasContent(Map<String,Object>)` 이다. 같은 패키지가 아니어도 호출되지만 `docout` 패키지에 새 파일을 만든다.
- 이미 적용된 HeadText 에 requireBirthDate 가 있다.
- InstHeadDdlPairTest 의 `inserts(String dialect, String file)` 는 private static 이다. 같은 클래스 안이라 그대로 호출된다.
- HeadApiTestBase 의 도우미는 addHeadOk(inst, emp, name, position), addItemOk(inst, emp, body, status), itemDate(head, field, date), postJson(path, emp, body), getAs(path, emp), headPath, headsPath, act(action, outcome), count(sql, args...), itemState, reason, source(), json, text, code, as 다. 상수는 T1·T2·L1·D1·DESIGNER·INST·INST2 다.
- 날짜 경계는 `LocalDate.parse(Times.todayKst()).minusYears(18)` 로 계산한다(HeadText 와 같은 식).
- 서비스는 던진 오류 앞에서 쓴 행을 되돌리지 않고 같은 칸에 다른 날짜를 또 넣으면 충돌 후보(202)가 된다. 그래서 유효값 경계는 시험 메서드를 나눴고, 400 경계만 한 메서드에서 반복한다.
- "생년월일만 남음" 시험은 NAME·POSITION 행만 골라 void 한다. 기존 voidAll 은 확정 칸을 전부 무효로 만들기 때문에 쓰지 않았다.

    private static String documentXml(byte[] docx) throws Exception {
        try (ZipInputStream z = new ZipInputStream(new ByteArrayInputStream(docx))) {
            ZipEntry e;
            while ((e = z.getNextEntry()) != null) {
                if ("word/document.xml".equals(e.getName())) {
                    ByteArrayOutputStream o = new ByteArrayOutputStream();
                    byte[] buf = new byte[4096];
                    int n;
                    while ((n = z.read(buf)) > 0) {
                        o.write(buf, 0, n);
                    }
                    return new String(o.toByteArray(), StandardCharsets.UTF_8);
                }
            }
        }
        return "";
