## 2. 요구·결정 요약
- 현재 코드는 `InboxService.importExternalChecks`가 검사·제외·`corpus/ext_check` 보관까지만 하고 DB는 쓰지 않습니다(`ExtCheckImporter.java:33`). `Result.response`에는 통과 check의 `check_key`·`stored_name`만 있고 저장에 필요한 값(상태·시각·제목 등, 첨부 sha·크기)은 없습니다. 그래서 `Result`에 저장용 객체를 더합니다.
- **결정(보수적)**
  - **같은 batch_id 재반입**
    - 저장 전에 `EXT_CHECK`·`EXT_CHECK_EXCL`에서 `BATCH_ID`를 조회합니다. 이미 있으면 **422 `BATCH_ALREADY_IMPORTED`**를 돌려주고 아무것도 지우거나 옮기지 않습니다(`originals_deleted:false`).
    - 동시 반입으로 UQ가 뒤늦게 걸리면(`DuplicateKeyException`) 방금 보관한 `ext_check/<key>` 폴더를 지우고 같은 422로 끝냅니다.
    - 일부만 통과한 배치도 같은 batch_id로 다시 올리면 거부됩니다. 고친 파일은 새 batch_id로 보내야 합니다.
  - **저장 실패**: 500 고정 문구입니다. 보관 폴더는 되돌립니다.
  - **묶음 거부**(SHA 불일치 등)와 `EXCLUDE_PER_CHECK=false` 거부: DB에는 아무것도 쓰지 않습니다. 제외 이력도 남기지 않고, 이유는 보관 manifest에만 남습니다.
  - **EXT_CHECK_EXCL**
    - 사유·위치·건수·순번만 담습니다(check당 최대 100행).
    - v3의 `FILE_SHA256`은 뺐습니다. 지시가 "사유·위치·건수만"이었고, 그 값은 자기신고였기 때문입니다. 필요하면 후속 마이그레이션으로 더합니다.
  - **press 제목·발행처**: 열 이름을 `TITLE`·`ITEM_NO`·`PUBLISHER`·`POSTED_AT`·`DEADLINE_AT`·`SRC_URL`로 일반화해 notice와 press가 같이 담깁니다. v2의 `NOTICE_*` 이름 대신입니다.
- **열람 API**
  - `GET /ext-checks?institution_id=` 응답은 `{institution_id, notice, last_error_at, history, history_limit}`입니다.
    - `notice`: 그 기관의 notice 중 **found·not_found만** 본 최신 1건입니다. 없으면 null입니다.
    - `last_error_at`: 같은 기관·notice에서 error의 최근 `checked_at`입니다. 따로 담으므로 error가 표시값을 덮지 않습니다.
    - `history`: 모든 종류·상태를 최신순 20건으로 담습니다.
    - 각 항목에는 `files:[{seq, format, size, download_path}]`가 들어갑니다. `stored_name`·sha는 내지 않습니다.
  - `GET /ext-checks/{check_key}/files/{seq}`: 파일 한 건을 내려받습니다.
- **정렬 한계**: `CHECKED_AT`은 ISO 문자열이라 사전순 정렬입니다. 수집기가 `+09:00`을 고정해 보낸다는 전제입니다(스키마가 offset을 허용하므로 다른 offset이 오면 틀어질 수 있음). 시각 비교는 프런트가 하게 두고, 서버는 `error_after_notice` 같은 파생값을 만들지 않았습니다.
- **역할**: `InboxController.SALES_TEAM_ROLES`(영업팀·영업팀장·영업부장)를 그대로 재사용합니다. 역할을 넓혀야 할 이유는 발견하지 못했습니다.
- **번호**: 042는 `apply-mysql`의 번호 연속성과 `DdlPair` 시험을 따릅니다. 041은 데이터뿐이라 충돌이 없습니다.

    private static final Pattern STORED_RE = Pattern.compile("[0-9a-f]{32}/[A-Za-z0-9_-]{1,40}_[0-9]{1,3}\\.(?:pdf|hwp|hwpx)");

    private final ExtCheckMapper mapper;

    public static final class Download {
        private final String name;
        private final byte[] bytes;

        Download(String name, byte[] bytes) {
            this.name = name;
            this.bytes = bytes;

        public String getName() { return name; }
        public byte[] getBytes() { return bytes; }

    @Transactional(readOnly = true)
    public Map<String, Object> list(String institutionId) {
        if (institutionId == null || institutionId.trim().isEmpty() || institutionId.length() > 64 || hasControl(institutionId)) {
            throw ApiException.badRequest("institution_id 가 필요합니다.");     // 받은 값은 싣지 않는다
        }
        if (institutions.selectById(institutionId) == null) {
            throw ApiException.notFound("기관을 찾을 수 없습니다.");
        }
        List<ExtCheck> latest = mapper.selectLatestResolved(institutionId, "notice", new RowBounds(0, 1));
        String lastError = mapper.selectLastErrorAt(institutionId, "notice");
        List<ExtCheck> history = mapper.selectHistory(institutionId, new RowBounds(0, HISTORY_LIMIT));

        List<String> keys = new ArrayList<String>();
        for (ExtCheck c : history) {
            keys.add(c.getCheckKey());
        }
        for (ExtCheck c : latest) {
            if (!keys.contains(c.getCheckKey())) {
                keys.add(c.getCheckKey());
            }
        }
        Map<String, List<ExtCheckFile>> filesByKey = new LinkedHashMap<String, List<ExtCheckFile>>();
        if (!keys.isEmpty()) {
            for (ExtCheckFile f : mapper.selectFilesByKeys(keys)) {
                List<ExtCheckFile> l = filesByKey.get(f.getCheckKey());
                if (l == null) {
                    l = new ArrayList<ExtCheckFile>();
                    filesByKey.put(f.getCheckKey(), l);
                }
                l.add(f);
            }
        }
        List<Map<String, Object>> hist = new ArrayList<Map<String, Object>>();
        for (ExtCheck c : history) {
            hist.add(item(c, filesByKey.get(c.getCheckKey())));
        }
        Map<String, Object> out = new LinkedHashMap<String, Object>();
        out.put("institution_id", institutionId);
        out.put("notice", latest.isEmpty() ? null : item(latest.get(0), filesByKey.get(latest.get(0).getCheckKey())));
        out.put("last_error_at", lastError);
        out.put("history", hist);
        out.put("history_limit", HISTORY_LIMIT);
        return out;
    }

    private static Map<String, Object> item(ExtCheck c, List<ExtCheckFile> files) {
        Map<String, Object> m = new LinkedHashMap<String, Object>();
        m.put("check_key", c.getCheckKey());
        m.put("source_kind", c.getSourceKind());
        m.put("source_slug", c.getSourceSlug());
        m.put("status", c.getStatusCd());
        m.put("checked_at", c.getCheckedAt());
        m.put("imported_at", c.getImportedAt());
        m.put("error_code", c.getErrorCd());
        if (c.getMatchConf() != null) {
            Map<String, Object> match = new LinkedHashMap<String, Object>();
            match.put("confidence", c.getMatchConf());
            match.put("basis", c.getMatchBasis() == null || c.getMatchBasis().isEmpty()
                    ? Collections.<String>emptyList() : Arrays.asList(c.getMatchBasis().split(",")));
            m.put("match", match);
        } else {
            m.put("match", null);
        }
        m.put("title", c.getTitle());
        m.put("number", c.getItemNo());
        m.put("publisher", c.getPublisher());
        m.put("posted_at", c.getPostedAt());
        m.put("deadline_at", c.getDeadlineAt());
        m.put("url", c.getSrcUrl());
        List<Map<String, Object>> fs = new ArrayList<Map<String, Object>>();
        if (files != null) {
            for (ExtCheckFile f : files) {                    // stored_name·sha256 은 내보내지 않는다
                Map<String, Object> x = new LinkedHashMap<String, Object>();
                x.put("seq", f.getFileSeq());
                x.put("format", f.getFormatCd());
                x.put("size", f.getFileSize());
                x.put("download_path", "/ext-checks/" + c.getCheckKey() + "/files/" + f.getFileSeq());
                fs.add(x);
            }
        }
        m.put("files", fs);
        return m;
    }

    /** 형식이 틀리거나 DB 에 없거나 파일이 루트 밖·없음이면 모두 같은 404(고정 문구). */
    @Transactional(readOnly = true)
    public Download download(String checkKey, String seq) {
        if (checkKey == null || !KEY_RE.matcher(checkKey).matches() || seq == null || !SEQ_RE.matcher(seq).matches()) {
            throw ApiException.notFound(NOT_FOUND);
        }
        ExtCheckFile f = mapper.selectFile(checkKey, Integer.parseInt(seq));
        if (f == null || f.getStoredName() == null || !STORED_RE.matcher(f.getStoredName()).matches()
                || !f.getStoredName().startsWith(checkKey + "/")) {
            throw ApiException.notFound(NOT_FOUND);
        }
        try {
            Path root = Paths.get(properties.getExtCheckRoot()).toRealPath();
            Path p = root.resolve(f.getStoredName());
            BasicFileAttributes a = Files.readAttributes(p, BasicFileAttributes.class, LinkOption.NOFOLLOW_LINKS);
            if (!a.isRegularFile() || a.size() > MAX_FILE_BYTES) {
                throw ApiException.notFound(NOT_FOUND);
            }
            Path real = p.toRealPath();
            Path dir = real.getParent();
            if (!real.startsWith(root) || dir == null || dir.getFileName() == null
                    || !dir.getFileName().toString().equalsIgnoreCase(checkKey) || !root.equals(dir.getParent())) {
                throw ApiException.notFound(NOT_FOUND);
            }
            String name = f.getStoredName().substring(f.getStoredName().indexOf('/') + 1);   // 서버 생성명
            return new Download(name, Files.readAllBytes(real));
        } catch (IOException e) {
            throw ApiException.notFound(NOT_FOUND);
        }
    }

    private static boolean hasControl(String s) {
        for (int i = 0; i < s.length(); i++) {
            if (Character.isISOControl(s.charAt(i))) {
                return true;
            }
        }
        return false;
    }

     * 통과 check·첨부·제외 이력을 DB 에 저장한다(한 트랜잭션). 파일을 먼저 보관하고 DB 를 나중에 쓰므로 실패하면 보관 폴더를 지운다.
     * 동시에 같은 batch_id 가 들어와 UQ 가 걸리면(DuplicateKeyException) 422, 그 밖은 500(고정 문구) — 값·SQL 은 응답·로그에 싣지 않는다.

     */
    private void persist(ExtCheckImporter.Result r, String batchId, JsonNode manifest) {
        if (r.saves.isEmpty() && r.excls.isEmpty()) {
            return;
        }
        String code;
        ApiException failure;
        try {
            extStore.save(r.saves, r.excls);
            return;
        } catch (DuplicateKeyException e) {
            code = "BATCH_ALREADY_IMPORTED";
            failure = ApiException.withDetail(422, Collections.singletonMap("errors",
                    Collections.singletonList(code + ": 이미 반입한 배치입니다")));
        } catch (RuntimeException e) {
            log.error("외부 확인 저장 실패 batch_id={} {}", batchId, e.getClass().getSimpleName());
            code = "PERSIST_FAILED";
            failure = new ApiException(500, "외부 확인 결과를 저장하지 못했습니다.");
        }
        for (Path d : r.storedDirs) {
            ExtCheckImporter.deleteTree(d);
        }
        r.archiveManifest = extChecks.failedArchive(manifest, code);
        r.failure = failure;
    }

    private static final Path DB = Paths.get("src/main/resources/db");

    private static String read(String dialect) throws IOException {
        Path f = DB.resolve(dialect).resolve(FILE);
        assertTrue(f + " 가 없다 — 작업 디렉터리가 kgi-ggreport-web/ 인지 확인", Files.exists(f));

    /** 표 이름 → ["열1,열2,...", "PK:..", "UQ:.."] */
    private static Map<String, List<String>> tables(String sql) {
        Map<String, List<String>> out = new LinkedHashMap<String, List<String>>();
        Matcher m = Pattern.compile("CREATE TABLE (\\w+) \\(\n(.*?)\n\\)", Pattern.DOTALL).matcher(sql);
        while (m.find()) {
            StringBuilder cols = new StringBuilder();
            for (String raw : m.group(2).split("\n")) {
                String line = raw.replaceAll("--.*$", "").trim();
                if (line.isEmpty() || line.startsWith("PRIMARY") || line.startsWith("UNIQUE")
                        || line.startsWith("KEY") || line.startsWith("CONSTRAINT")) {
                    continue;
                }
                cols.append(cols.length() == 0 ? "" : ",").append(line.split("\\s+")[0]);
            }
            String body = m.group(2);
            List<String> v = new ArrayList<String>();
            v.add(cols.toString());
            Matcher pk = Pattern.compile("PRIMARY KEY \\(([A-Z_, ]+)\\)").matcher(body);
            v.add("PK:" + (pk.find() ? pk.group(1).replace(" ", "") : ""));
            Matcher uq = Pattern.compile("UNIQUE (?:KEY \\w+ )?\\(([A-Z_, ]+)\\)").matcher(body);
            v.add("UQ:" + (uq.find() ? uq.group(1).replace(" ", "") : ""));
            out.put(m.group(1), v);
        }
        return out;
    }

## 5. 보안·위험·되돌리는 법
- **권한**
  - 영업팀·영업팀장·영업부장만 통과합니다. 디자이너·마스터·전산팀·관리자·미등록·비활성은 403이고, 사번이 없으면 401입니다.
  - 이 가드는 입력 형식 검사와 DB 조회보다 먼저입니다. 그래서 권한 없는 호출자에게 키 형식·존재 여부를 알리지 않습니다.
  - 403·401은 `MenuGuard`가 `DENIED`로 남깁니다(고정 문구, 질의·본문 없음).
  - 성공·404는 `AccessLogInterceptor`가 `API`로 남깁니다. 경로(`check_key`·`seq`), 상태, 사번(자기신고 여부 포함), 요약(`ext_check list n=…`, `ext_check file bytes=…`)만 들어가고, 쿼리의 `institution_id` 값은 들어가지 않습니다.
- **자기신고 한계**: `X-Emp-No` 자기신고라 영업팀 사번을 아는 사람은 열람할 수 있습니다. 업무 규칙이지 보안 경계가 아닙니다. `check_key`가 추측 불가이긴 해도, 목록을 열 수 있는 사람에게는 키가 그대로 나옵니다.
- **다운로드**
  - 파일 경로는 클라이언트 입력에서 만들지 않습니다. DB의 `STORED_NAME`을 정규식으로 한 번 더 확인합니다.
  - 그다음 `NOFOLLOW`로 일반 파일인지 보고, `toRealPath`가 루트 아래 `<키>/` 폴더 안인지 봅니다.
  - 실패는 모두 같은 404(고정 문구)입니다.
  - `Content-Type`은 `octet-stream`이라 브라우저가 문서로 열지 않고 저장합니다. 보관된 파일은 2단계 검사를 통과한 사본입니다.
- **저장 순서 위험**: 파일을 먼저 보관하고 DB를 나중에 씁니다.
  - DB 실패 시 보관 폴더를 지웁니다.
  - 프로세스가 도중에 죽으면 `ext_check/<키>/`만 남을 수 있습니다. DB에 참조가 없어 열리지 않고, 정리는 운영 몫입니다.
- **미반영·의도된 한계**
  - 묶음 거부(SHA 불일치 등)에는 제외 이력이 남지 않습니다(보관 manifest에만 있음).
  - 부분 통과 배치를 같은 batch_id로 다시 올릴 수 없습니다(새 batch_id 필요).
  - `CHECKED_AT`은 문자열 정렬입니다.
- **`.gitignore`**: v3 §4가 말한 `corpus/inbox/`·`corpus/inbox/batches/`·`corpus/ext_check/` 항목이 있는지 호출자가 확인해 주세요. 저는 열어 보지 못했습니다.
- **되돌리는 법**
  - 코드: 신규 파일(도메인 3, `ExtCheckMapper`+XML, `ExtCheckStore`, `ExtCheckQueryService`, `ExtCheckController`, 두 시험)을 지우고, `ExtCheckImporter`·`InboxService`·`InboxController`·시험 설정·`apply-mysql.mjs`의 위 hunk를 되돌립니다. 이러면 2단계 상태(DB 미저장)로 돌아갑니다.
  - DB: 헤더의 `DROP TABLE` 3줄입니다(데이터 소멸, 운영 금지). 보관 파일은 따로 지웁니다.
  - `/menus` 응답·골든 04·05·`Menus.MENUS`·`roles.js`·기존 `/approvals`는 건드리지 않았습니다.
