## 2. 원인·결정 (근거)

### RFP 협약 개시일은 지금 DB에 없습니다
- `NOTICE_ROUND.TARGET_TERM_YEAR`(`037:26`, "대상 약정 시작 연도")가 유일한 후보입니다. 하지만 연도만 있고, mapper `roundCols`에서 읽기만 할 뿐 **어디서도 쓰지 않습니다**(`NoticeRoundService.save:239`의 `insertRound`에 값을 넘기지 않음).
- `BID_CASES`에는 일정·공고 칸만 있고 협약 기간이 없습니다.
- `INST_BANK_CONTRACT.TERM_FROM`(039)은 *결과* 약정의 개시일이라, 등록되기 전에는 판정 시점을 알려 주지 못합니다.

### 공고 회차(NOTICE_ROUND)에 칸을 붙이지 않고 새 표로 둔 이유
- 회차 행은 첫 판정을 저장할 때만 생깁니다(`037:4`). 공고 판정 없이 개시일만 적을 수 없습니다.
- `NOTICE_ROUND` UPDATE는 칸 단위 DBA 권한이라(`037:14`) 칸을 추가하면 권한 변경까지 필요합니다.
- 회차에는 '입찰한 해(목표 연도)' 칸이 없습니다. 개시일과 목표 연도를 이을 수 없습니다.
- 목표 표(INST_BID_TARGET)에 넣으면 개시일을 적는 것도 목표 변경이 되어 결재 대상이 됩니다.

### 새 표 `INST_BID_TERM`
- 키: (기관, 목표 연도 = 입찰한 해, REV). 추가 전용이고 039와 같은 감사 칸을 둡니다.
- 쓰기: 영업 계열 누구나, 결재 없음(RFP에 적힌 사실이라 금고 약정 기록과 같은 취급).
- 이 표가 **회차(공고 연도)↔약정을 잇는 값**입니다. 칸 이름: `INST_BID_TERM.TERM_START`, 키 `(INSTITUTION_ID, TARGET_YEAR)`, 현재 값 = 최대 REV이면서 `ACTION_CD='SAVE'`.

### 귀속 규칙 (a) — `ResultYearRules.yearOf(termFrom, starts)`, 새 파일·105 소유
1. 그 기관에 기록된 개시일과 약정 시작이 같으면 그 개시일의 목표 연도로 봅니다. 예: 2026 목표의 개시일이 2027-03-01이고 약정이 2027-03-01 시작이면 2026으로 봅니다(05가 짚은 틈이 메워짐).
2. 같은 것이 없거나 여러 해와 겹치면 104의 지금 추정(`TargetResultRules.targetYearOf`: 1월 개시는 전년도)을 그대로 씁니다.
3. 개시일이 하나도 기록되지 않았으면 104와 결과가 **완전히 같습니다**.

### 판정 시점 (b)
- 판정일 = 그 목표 연도 Y의 기록된 개시일입니다.
- 기록이 없으면 **Y+1년의 `default-start`(기본 01-01)**를 개시일로 봅니다.
- 판정일 전에는 보류합니다(이월하지 않고, 이미 한 이월은 거둡니다). 판정일 뒤에는 국민은행 = 달성, 다른 은행 = FAIL → 관심, 약정 없음 = 미달성 → Y+1 목표로 넘깁니다.

### 개시일이 없을 때 Y+1-01-01로 둔 근거
- 104 판정 주석(`TargetResultRules.java:12-13`): "금고 약정은 보통 입찰 다음 해 1월에 시작".
- '그해 공고가 안 떴으면 목표 연도가 끝난 뒤 이월'과 같은 날짜가 됩니다. 입찰 없음을 따로 판별하지 않아도 됩니다.
- 실제 개시일이 나중에 기록되면 판정일이 미뤄져, 이미 한 이월이 자동 취소되고 개시일 뒤에 다시 판정합니다(자동 취소 규칙 유지).

### 설정 키
- `ggreport.bid-target.carry.after` → **`ggreport.bid-target.carry.default-start=01-01`**로 바꿉니다. 뜻은 "개시일 기록이 없을 때 목표 연도 다음 해의 이 날을 개시일로 본다"입니다.

### 다루는 목표 연도
- Y ∈ {작년, 올해}만 봅니다(이월 연도 Y+1 = 올해~내년). 더 오래된 목표는 다루지 않습니다.

### 3-3. 새 `service/ResultYearRules.java` — 105·104가 같이 쓸 귀속 정본
```java
package com.kbstar.kgi.ggreport.web.service;

import com.kbstar.kgi.ggreport.web.domain.BankContract;
import java.util.*;

/**
 * 약정 → 귀속 목표 연도(입찰한 해, 사용자 11-20). 정본 한 곳 — 105 이월과 104 성과가 같이 쓴다.
 * ① 그 기관에 기록된 RFP 협약 개시일(INST_BID_TERM, 목표 연도 → YYYY-MM-DD)과 약정 시작이 같으면 그 목표 연도.
 * ② 아니면(기록 없음·여러 해와 겹침) 104 추정 TargetResultRules.targetYearOf(1월 개시 = 전년도) — 기록이 없으면 104 와 결과가 같다.
 */
final class ResultYearRules {
    private static final List<String> RANK_ORDER = Arrays.asList("FIRST", "SECOND", "JOINT", "NONE");   // TargetResultRules 와 같은 순서
    private ResultYearRules() { }

    static Integer yearOf(String termFrom, Map<Integer, String> starts) {
        if (termFrom == null) return null;
        if (starts != null) {
            Integer hit = null;
            for (Map.Entry<Integer, String> e : starts.entrySet()) {
                String d = e.getValue();
                if (d == null) continue;
                boolean match = termFrom.length() >= 10 ? d.equals(termFrom.substring(0, 10)) : d.startsWith(termFrom);
                if (!match) continue;
                if (hit != null && !hit.equals(e.getKey())) return TargetResultRules.targetYearOf(termFrom);   // 모호 — 추정으로
                hit = e.getKey();
            }
            if (hit != null) return hit;
        }
        return TargetResultRules.targetYearOf(termFrom);
    }

    /** TargetResultRules.resultLines 와 같은 선택(순위마다 시작이 가장 이른 줄, 같으면 번호 큰 쪽), 귀속만 yearOf. */
    static List<BankContract> linesOf(List<BankContract> all, int year, Map<Integer, String> starts) {
        Map<String, BankContract> byRank = new HashMap<String, BankContract>();
        if (all != null) for (BankContract c : all) {
            Integer ty = yearOf(c.getTermFrom(), starts);
            if (ty == null || ty.intValue() != year) continue;
            String k = c.getRankCd() == null ? "" : c.getRankCd();
            BankContract cur = byRank.get(k);
            if (cur == null) { byRank.put(k, c); continue; }
            int r = c.getTermFrom().compareTo(cur.getTermFrom());
            if (r < 0 || (r == 0 && c.getContractNo() > cur.getContractNo())) byRank.put(k, c);
        }
        List<BankContract> out = new ArrayList<BankContract>(byRank.values());
        Collections.sort(out, new Comparator<BankContract>() {
            public int compare(BankContract a, BankContract b) {
                int x = RANK_ORDER.indexOf(a.getRankCd()), y = RANK_ORDER.indexOf(b.getRankCd());
                return (x < 0 ? 99 : x) - (y < 0 ? 99 : y);
            }
        });
        return out;
    }

    /** 판정일이 지난 뒤의 결과 — 줄 없음 = UNREGISTERED, 국민은행 줄 = SUCCESS, 그 밖 = FAIL(TargetResultRules.judge 와 같은 코드값). */
    static String verdict(List<BankContract> all, Map<Integer, String> starts, int year) {
        List<BankContract> ls = linesOf(all, year, starts);
        if (ls.isEmpty()) return TargetResultRules.UNREGISTERED;
        for (BankContract c : ls) if (BankYears.KB_BANK.equals(c.getBankCd())) return TargetResultRules.SUCCESS;
        return TargetResultRules.FAIL;
    }
}
```

### 3-4. `service/CarryRules.java` (전체 교체)
```java
package com.kbstar.kgi.ggreport.web.service;

import com.kbstar.kgi.ggreport.web.domain.BankContract;
import com.kbstar.kgi.ggreport.web.domain.BidTarget;
import java.time.LocalDate;
import java.time.MonthDay;
import java.util.*;

/**
 * 자동 이월 판정(NEXT 105, 사용자 11-20). 목표 연도 Y 의 판정일 = RFP 협약 개시일(INST_BID_TERM), 없으면 (Y+1)년 기본일.
 * 판정일 전 = 보류(이월 안 함, 이미 한 이월은 거둠). 판정일 뒤: SUCCESS = 없음, FAIL = Y+1 관심, 그 밖 = Y+1 목표. 귀속은 ResultYearRules.
 */
final class CarryRules {
    static final class Decision {
        String verdict, carryKind; Integer carryYear; boolean due; LocalDate judgeFrom;
        final List<BidTarget> revoke = new ArrayList<BidTarget>();
        boolean isEmpty() { return carryKind == null && revoke.isEmpty(); }
    }
    private CarryRules() { }

    static String neededKind(String verdict) {
        if (verdict == null || TargetResultRules.SUCCESS.equals(verdict)) return null;
        if (TargetResultRules.FAIL.equals(verdict)) return BidTargetRules.KIND_WATCH;
        return BidTargetRules.KIND_GOAL;
    }

    static LocalDate judgeFrom(int year, Map<Integer, String> starts, MonthDay dflt) {
        String d = starts == null ? null : starts.get(year);
        return d != null ? LocalDate.parse(d) : dflt.atYear(year + 1);
    }

    /** 살아 있는 목표 중 목표 연도가 fromYear~toYear(연도·번호 순). */
    static List<BidTarget> sourcesOf(List<BidTarget> latest, int fromYear, int toYear) {
        List<BidTarget> out = new ArrayList<BidTarget>();
        for (BidTarget t : latest) {
            if (BidTargetRules.KIND_GOAL.equals(BidTargetRules.kindOf(t)) && !BidTargetService.ACTION_CANCEL.equals(t.getActionCd())
                    && t.getTargetYear() != null && t.getTargetYear() >= fromYear && t.getTargetYear() <= toYear) out.add(t);
        }
        Collections.sort(out, new Comparator<BidTarget>() {
            public int compare(BidTarget a, BidTarget b) {
                int c = a.getTargetYear().compareTo(b.getTargetYear());
                return c != 0 ? c : a.getTargetNo() - b.getTargetNo();
            }
        });
        return out;
    }

    static boolean isCarryOf(BidTarget t, int fromNo) {
        return BidTargetService.ACTION_CARRY.equals(t.getFirstActionCd()) && t.getFirstCarryFromNo() != null
                && t.getFirstCarryFromNo().intValue() == fromNo;
    }
    static boolean autoRevoked(BidTarget t) {
        return BidTargetService.ACTION_CANCEL.equals(t.getActionCd()) && BidTargetService.CANCEL_CARRY_REVOKED.equals(t.getCancelReasonCd());
    }

    static Decision decide(BidTarget source, List<BidTarget> latest, List<BankContract> lines, Map<Integer, String> starts,
                           LocalDate today, MonthDay dflt) {
        Decision d = new Decision();
        int y = source.getTargetYear().intValue(), thisYear = today.getYear();
        d.judgeFrom = judgeFrom(y, starts, dflt);
        d.due = !today.isBefore(d.judgeFrom);
        d.verdict = d.due ? ResultYearRules.verdict(lines, starts, y) : null;
        String need = neededKind(d.verdict);   // 보류면 null → 손 안 탄 이월은 거둔다
        boolean blocked = false;
        for (BidTarget t : latest) {
            if (t.getTargetNo() == source.getTargetNo()) continue;   // 원천 자신(올해 목표면 '현재'라 막지 않게)
            boolean alive = !BidTargetService.ACTION_CANCEL.equals(t.getActionCd());
            if (isCarryOf(t, source.getTargetNo())) {
                String kind = BidTargetRules.KIND_WATCH.equals(t.getFirstKindCd()) ? BidTargetRules.KIND_WATCH : BidTargetRules.KIND_GOAL;
                if (alive && BidTargetService.ACTION_CARRY.equals(t.getActionCd()) && !kind.equals(need)) { d.revoke.add(t); continue; }
                if (kind.equals(need) && !autoRevoked(t)) blocked = true;
            }
            if (alive && BidTargetRules.isCurrent(t, thisYear)) blocked = true;
        }
        if (need != null && !blocked) {
            d.carryKind = need;
            d.carryYear = BidTargetRules.KIND_GOAL.equals(need) ? Integer.valueOf(y + 1) : null;
        }
        return d;
    }
}
```
`decide` 안의 `judge(...)` 호출은 `ResultYearRules.verdict`로 바뀌었습니다. 105가 104 판정 코드를 직접 부르지 않고, 귀속 함수 하나를 공유합니다(4-이관).
