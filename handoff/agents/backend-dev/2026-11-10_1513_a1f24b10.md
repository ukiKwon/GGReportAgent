## 2. 요구 요약과 설계 결정
| 정책 | 구현 |
|---|---|
| 자료 1건 = 기관+연도, 내부 번호 자동 | `BOARD_MATERIAL.MATERIAL_ID` 자동. (입찰 건, 연도)에 UNIQUE 없음(n건 허용) |
| 값은 '버전 저장' 때만, 원본 xlsx 없음 | `BOARD_MATERIAL_SNAP`(불변·추가 전용)에 값 JSON만. 파일명·xlsx·docx·범위 밖 칸 칸 자체 없음 |
| 쓰기는 배정된(ACTIVE) 사람만, 예외 없음 | `BoardAccess.canWriteCase` = `isActiveAssignee` ∧ USERS `ACTIVE` ∧ 영업 계열(영업팀·영업팀장)(security 하-4). 관리자·마스터 예외 없음 |
| 임시 허용 종료 | `/board-forms/{id}/excel`·`/draft-docx`의 `requireWrite`를 `bid_case_id` 기반 `canWriteCase`로 교체. 목록 `can_write`도 배정 여부로 바꾼다 |
| 비담당에게는 목록·상세 모두 안 보임 | 목록은 SQL에서 내 배정 건만(영업부장은 전체). 상세·이력·버전은 보이지 않으면 **존재하지 않는 id와 같은 404** |
| 영업부장은 열람만 | `canViewCase` = `canWriteCase` ∨ (ACTIVE ∧ 영업부장). 쓰기는 403 |
| 빠진 담당자의 작성본은 새 담당자에게 인계, 이력 | 자료는 입찰 건 소속(남은·새 담당자가 이어 씀). `OWNER_EMP_NO`(현재 작성 책임자)를 두고, `applyChange`에서 해제 대상이 owner인 자료마다 owner를 새 담당자로 바꾼다. `BID_ASSIGN_LOG`에 `HANDOVER`(from→to, 자료 번호, 결재 번호) 행과 `BOARD_MATERIAL_LOG` 행을 같은 트랜잭션에 남긴다 |
| 외래키 없음 | DDL에 FK·CHECK·UNIQUE 없음. 서비스가 저장 전에 확인 |

인계 대상 규칙(결정, 권장안으로 두었음): 같은 변경에서 **추가된 사람 중 첫 번째**, 추가가 없으면 **남은 담당자 중 먼저 배정된 사람**. 남는 담당자가 0명인 변경은 019에서 이미 400이다.

  JOIN BID_CASES b ON b.BID_CASE_ID = m.BID_CASE_ID
 WHERE b.INSTITUTION_ID <> m.INSTITUTION_ID;
SELECT m.MATERIAL_ID FROM BOARD_MATERIAL m
 WHERE NOT EXISTS (SELECT 1 FROM BID_ASSIGN_CASE c WHERE c.BID_CASE_ID = m.BID_CASE_ID);
SELECT m.MATERIAL_ID, m.OWNER_EMP_NO FROM BOARD_MATERIAL m

-- Q15 이사회 자료 버전·이력: 자료 없음 / CUR_SNAP 이 실제 최대 번호와 다름 / 버전 결번 / 사번이 USERS 에 없음

SELECT MATERIAL_ID, COUNT(*) AS N, MAX(SNAP_NO) AS MX FROM BOARD_MATERIAL_SNAP
 GROUP BY MATERIAL_ID HAVING COUNT(*) <> MAX(SNAP_NO);

 WHERE NOT EXISTS (SELECT 1 FROM BOARD_MATERIAL m WHERE m.MATERIAL_ID = l.MATERIAL_ID);

     * 순서: 보임(404) → 쓰기 자격(403) → 닫힘(409 MATERIAL_CLOSED) → 입력(400) → 개인정보(422) → 크기(400) → 충돌(409).
     */
    @Transactional
    public Map<String, Object> saveSnapshot(SysUser me, Actor actor, String id, BoardMaterialIn.Save in) {
        BoardMaterial m = loadVisible(me, id);
        requireWriter(me, m);
        if (TERMINAL.contains(m.getStatusCd())) {
            throw coded(409, "MATERIAL_CLOSED", "가결 또는 부결된 자료는 더 저장할 수 없습니다.");
        }
        if (in == null || in.getBaseSnapNo() == null || in.getBaseSnapNo() < 0) {
            throw coded(400, "BAD_REQUEST", "기준 버전(base_snap_no)이 필요합니다.");
        }
        String note = blankToNull(in.getNote());
        if (note != null) {
            note = note.trim();
            if (note.length() > MAX_NOTE) {
                throw coded(400, "BAD_VALUE", "메모는 " + MAX_NOTE + "자 이하로 입력해 주세요.");
            }
            if (!Pii.scan(note).isEmpty()) {
                throw coded(422, "PII_DETECTED", "메모에 개인정보로 보이는 값이 있어 저장하지 않았습니다.");   // 검출값은 싣지 않는다
            }
        }
        String json = toJson(checkedValues(me.getEmpNo(), m, in.getTables()));
        if (json.getBytes(StandardCharsets.UTF_8).length > MAX_JSON_BYTES) {
            throw coded(400, "BAD_VALUE", "저장할 내용이 너무 큽니다.");
        }
        if (in.getBaseSnapNo() != m.getCurSnap()) {
            throw coded(409, "CONFLICT", "다른 사람이 먼저 저장했습니다. 새로 고친 뒤 다시 저장해 주세요.");
        }
        if (m.getCurSnap() > 0) {
            BoardMaterialSnap cur = mapper.selectSnap(m.getMaterialId(), m.getCurSnap());
            if (cur != null && json.equals(cur.getValuesJson())) {
                Map<String, Object> same = new LinkedHashMap<>();
                same.put("material_id", m.getMaterialId());
                same.put("snap_no", m.getCurSnap());
                same.put("changed", false);
                return same;
            }
        }
        if (m.getCurSnap() >= MAX_SNAPS) {
            throw coded(400, "TOO_MANY_VERSIONS", "저장 이력이 너무 많아 더 저장할 수 없습니다.");
        }
        int next = m.getCurSnap() + 1;
        String now = Times.nowIso();
        if (mapper.updateCurSnap(m.getMaterialId(), m.getCurSnap(), next, me.getEmpNo(), now) != 1) {

        }

        s.setValuesJson(json);
        s.setNote(note);
        s.setSavedBy(me.getEmpNo());
        s.setSavedAt(now);
        mapper.insertSnap(s);
        Map<String, Object> out = new LinkedHashMap<>();
        out.put("material_id", m.getMaterialId());
        out.put("snap_no", next);
        out.put("changed", true);

    /** 상태 변경 — 담당자만, 앞으로만(PREP→DRAFT→SUBMITTED→SCHEDULED→PASSED|REJECTED). 의결 예정은 개최일 필수. */

    public Map<String, Object> changeStatus(SysUser me, Actor actor, String id, BoardMaterialIn.Status in) {
        BoardMaterial m = loadVisible(me, id);
        requireWriter(me, m);
        if (in == null || blankToNull(in.getTo()) == null) {
            throw coded(400, "BAD_REQUEST", "바꿀 상태(to)가 필요합니다.");
        }
        String to = in.getTo().trim();
        List<String> allowed = NEXT.get(m.getStatusCd());
        if (allowed == null || !allowed.contains(to)) {
            throw coded(409, "BAD_TRANSITION", "이 상태에서는 선택한 상태로 바꿀 수 없습니다.");   // 입력값은 되돌려 싣지 않는다
        }
        String meeting = null;
        if (SCHEDULED.equals(to)) {
            meeting = optDate(in.getMeetingDate());
            if (meeting == null) {
                throw coded(400, "MEETING_DATE_REQUIRED", "의결 예정으로 바꾸려면 개최일을 입력하세요.");
            }
        }
        String now = Times.nowIso();
        if (mapper.updateStatus(m.getMaterialId(), m.getStatusCd(), to, meeting, me.getEmpNo(), now) != 1) {
            throw coded(409, "CONFLICT", "다른 사람이 먼저 상태를 바꿨습니다. 새로 고친 뒤 다시 시도해 주세요.");
        }
        mapper.insertLog(m.getMaterialId(), "STATUS", m.getStatusCd(), to, meeting, null, null, me.getEmpNo(),
                verified(actor), now);
        return detail(me, id);
    }

    /** 저장 JSON → [{ref, cells:{칸키:값}}]. 읽을 수 없으면 서버 결함(500). */
    private static List<Map<String, Object>> tablesOf(String json) {
        List<Map<String, Object>> out = new ArrayList<>();
        try {
            JsonNode t = JSON.readTree(json).path("tables");
            java.util.Iterator<Map.Entry<String, JsonNode>> it = t.fields();
            while (it.hasNext()) {
                Map.Entry<String, JsonNode> e = it.next();
                Map<String, Object> cells = new LinkedHashMap<>();
                java.util.Iterator<Map.Entry<String, JsonNode>> ci = e.getValue().fields();
                while (ci.hasNext()) {
                    Map.Entry<String, JsonNode> c = ci.next();
                    cells.put(c.getKey(), c.getValue().asText());
                }
                Map<String, Object> table = new LinkedHashMap<>();
                table.put("ref", e.getKey());
                table.put("cells", cells);
                out.add(table);
            }
        } catch (IOException e) {
            throw new IllegalStateException("stored board material is not valid");
        }
        return out;
    }

    /**
     * 저장할 값 검증·정규화: 표 수·칸 수 한도 → 칸 길이(개인정보 정규식은 길이에 비례해 느리므로 먼저) → 개인정보(422) →
     * 양식 구조 대조(BoardDocSpec.withValues: 값 칸이 아닌 키·모르는 표는 거부, 제어문자·trim) → 값이 있는 칸만 추출.
     */
    private Map<String, Map<String, String>> checkedValues(String empNo, BoardMaterial m, List<BoardWriteIn.TableIn> tables) {
        if (tables == null || tables.size() > MAX_TABLES) {
            throw coded(400, "BAD_REQUEST", "표 목록(tables)이 올바르지 않습니다.");
        }
        Map<String, Map<String, String>> raw = new LinkedHashMap<>();
        Map<String, Integer> kinds = new LinkedHashMap<>();
        for (BoardWriteIn.TableIn t : tables) {
            if (t == null || t.getRef() == null || raw.containsKey(t.getRef())
                    || (t.getCells() != null && t.getCells().size() > MAX_CELLS)) {
                throw coded(400, "BAD_REQUEST", "표 목록(tables)이 올바르지 않습니다.");
            }
            Map<String, String> cells = t.getCells() == null ? new LinkedHashMap<String, String>() : t.getCells();
            for (String v : cells.values()) {
                if (v != null && v.length() > BoardDocSpec.MAX_CELL) {
                    throw coded(400, "BAD_VALUE", "칸 값은 " + BoardDocSpec.MAX_CELL + "자 이하로 입력해 주세요.");
                }
                for (Pii.Finding f : Pii.scan(v)) {
                    Integer n = kinds.get(f.getKind());
                    kinds.put(f.getKind(), n == null ? 1 : n + 1);
                }
            }
            raw.put(t.getRef(), cells);
        }
        if (!kinds.isEmpty()) {
            Map<String, Object> d = new LinkedHashMap<>();
            d.put("code", "PII_DETECTED");
            d.put("message", "개인정보로 보이는 값이 있어 저장하지 않았습니다. 해당 칸을 지우고 다시 저장해 주세요.");
            List<Map<String, Object>> ks = new ArrayList<>();
            for (Map.Entry<String, Integer> e : kinds.entrySet()) {
                Map<String, Object> k = new LinkedHashMap<>();
                k.put("kind", e.getKey());
                k.put("count", e.getValue());
                ks.add(k);
            }
            d.put("kinds", ks);   // 종류·건수만 — 검출된 값은 싣지 않는다
            throw ApiException.withDetail(422, d);
        }
        BoardDocSpec.Doc filled;
        try {
            filled = BoardDocSpec.withValues(forms.docForStored(empNo, m.getFormId(), m.getFormVer()), raw);
        } catch (BoardDocSpec.EditException e) {
            throw coded(400, "BAD_VALUE", e.getMessage());
        }
        Map<String, Map<String, String>> out = new LinkedHashMap<>();
        for (BoardDocSpec.Table t : filled.getTables()) {
            for (List<BoardDocSpec.Cell> row : t.getRows()) {
                for (BoardDocSpec.Cell c : row) {
                    if ((c.isMapped() || c.isInput()) && c.getText() != null && !c.getText().isEmpty()) {
                        Map<String, String> cells = out.get(t.getId());
                        if (cells == null) {
                            cells = new LinkedHashMap<>();
                            out.put(t.getId(), cells);
                        }
                        cells.put(c.getKey(), c.getText());
                    }
                }
            }
        }
        return out;
    }

    private static String toJson(Map<String, Map<String, String>> values) {

        root.put("v", 1);
        root.put("tables", values);

    private static int verified(Actor actor) {
        return actor != null && actor.isVerified() ? 1 : 0;

    private static String blankToNull(String s) {
        return s == null || s.trim().isEmpty() ? null : s;
    }

    /** LIKE 검색어 — 앞뒤 공백 제거, 80자 상한(초과 400), ! % _ 를 '!' 로 이스케이프. 비면 null. */
    private static String like(String s) {
        String t = blankToNull(s) == null ? null : s.trim();
        if (t == null) {
            return null;
        }
        if (t.length() > 80) {
            throw new ApiException(400, "검색어는 80자 이하로 입력해 주세요.");
        }
        return t.replace("!", "!!").replace("%", "!%").replace("_", "!_");
    }

    private static Integer parseYear(String s, boolean required) {
        if (blankToNull(s) == null) {
            if (required) {
                throw new ApiException(400, "연도를 입력하세요.");
            }
            return null;
        }
        Long n = parseId(s.trim());
        if (n == null || n < YEAR_MIN || n > YEAR_MAX) {
            throw new ApiException(400, "연도는 " + YEAR_MIN + "~" + YEAR_MAX + " 사이여야 합니다.");
        }
        return n.intValue();
    }

    /** yyyy-MM-dd 만(실재하는 날짜, 2000~2100). 비면 null. */
    private static String optDate(String s) {
        if (blankToNull(s) == null) {
            return null;
        }
        String t = s.trim();
        try {
            LocalDate d = LocalDate.parse(t);
            if (t.length() != 10 || d.getYear() < YEAR_MIN || d.getYear() > YEAR_MAX) {
                throw new DateTimeParseException("range", t, 0);
            }
        } catch (DateTimeParseException e) {
            throw new ApiException(400, "날짜는 yyyy-MM-dd 형식이어야 합니다.");
        }
        return t;
    }

    private static Long parseId(String s) {
        if (s == null || s.isEmpty() || s.length() > 15) {
            return null;
        }
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) < '0' || s.charAt(i) > '9') {
                return null;
            }
        }
        return Long.valueOf(s);
    }

    private static ApiException coded(int status, String code, String message) {
        Map<String, Object> d = new LinkedHashMap<>();
        d.put("code", code);
        d.put("message", message);
        return ApiException.withDetail(status, d);

## 6. 보안·위험·되돌리는 법
- **403 경로와 404 경로를 나눴다.** 쓰기 자격이 없으면 403이고 DENIED로 남는다(고정 문구, 본문·쿼리값 없음). 보이지 않는 자료는 404로 "없음"과 같게 한다(존재 은닉, 사용자 확정).
  - 사이드 채널: 영업부장은 쓰기 403으로 "존재함"을 알지만 열람 자격이 있으므로 문제없다.
  - 비담당 영업팀원이 POST create로 입찰 건 존재 여부를 알아낼 수 없다. 자격 확인을 입찰 건 확인보다 먼저 한다(security 하-5와 같은 취지).
- **자기신고 인증의 한계(가리지 않는다).** `X-Emp-No`는 위조할 수 있다. 담당자 사번을 아는 사람이 헤더를 바꾸면 그 사람의 자료를 쓸 수 있다. 이 판정은 실수 방지용 업무 규칙이다. 이력의 `emp_verified=false`는 "자기신고"이고, 화면은 '검증됨'이라고 쓰지 않는다.
- **접근 이력에 값·메모·사번·이름을 넣지 않는다.** 자료 번호·입찰 건 번호·코드·버전 번호뿐이다. 개인정보는 422로 막고 검출값을 응답에 싣지 않는다. 원본 xlsx·파일명·docx는 DB에 칸이 없다.
- **비활성 사용자가 작성 책임자로 남을 수 있다.** USERS를 비활성으로 만들면 그 사람은 쓰지도 보지도 못하지만, 배정 행·`OWNER_EMP_NO`는 남는다. 관리자는 직접 인계할 수 없다(예외 없음 정책). 풀려면 영업팀장이 담당자 변경(그 사람 해제)을 상신해 승인받으면 인계가 자동으로 된다. 점검 쿼리 Q14 네 번째가 이런 건을 잡는다. 운영 안내가 필요하다(이관: 기획).
- **칸 값 길이**: A13 권장은 300자였으나 구현은 기존 `BoardDocSpec.MAX_CELL`(100자, `BoardDocSpec.java:271`·`withValues`가 강제)을 쓴다. 300자로 늘리려면 `withValues`에 길이 인자를 받는 오버로드가 필요하다(열린 질문 3).
- **동시성**: 버전 저장은 `UPDATE … WHERE CUR_SNAP=base`(낙관적, 1행이어야 진행) 뒤에 SNAP을 넣는다 — 두 사람이 동시에 같은 base로 저장하면 한쪽만 성공하고 나머지는 409다. 상태 변경은 `WHERE STATUS_CD=from`이다. 인계는 `WHERE OWNER_EMP_NO=from`이고 같은 승인 트랜잭션이다. 019의 승인·취소 경합(security 중-1)은 별개로 남아 있다.
- **영업팀장 열람 문제(열린 질문 1)**: 정책 글자대로 비담당 영업팀장에게도 안 보인다. 이는 제출 2차 결재자(NEXT 59)가 자료를 못 보는 상황을 만든다.
- **되돌리는 법**: 코드는 git revert. DB는 각 SQL 헤더의 되돌리기 문장(데이터 소멸, 운영 금지). 코드만 되돌릴 때 새 표·칸·코드값은 남아도 무해하다(기존 코드가 읽지 않는다). 단 `BidAssignLogView` 변경을 되돌리면 새 칸은 무시된다.
- 임시 허용 종료 효과: 020을 올리는 순간부터 기존 CAN_WRITE로는 작성할 수 없다. 배정을 먼저 해 두지 않으면 현업 작성이 막힌다(운영 순서: 배정 → 020 코드 배포).

## 7. 이관 메모
- `[이관: 프런트]` 작성 화면을 `bid_case_id` 기반으로 바꾼다. 업로드(`/excel`)와 초안(`/draft-docx`)에 `bid_case_id`를 싣고, 400 `BID_CASE_REQUIRED`·403을 처리한다. 버튼 표시는 `GET /board-forms`의 `can_write`(이제 "담당 건이 있는가")를 쓴다. 저장·목록·이력 화면은 `/board-materials` 새 API. 화면 동작: ① '버전 저장'을 눌러야만 저장된다(자동 저장 없음) ② `base_snap_no`를 들고 있다가 409 `CONFLICT`면 "다른 사람이 먼저 저장" 안내 후 새로 고침 ③ 200 `changed:false`면 "바뀐 내용이 없습니다" ④ 422 `PII_DETECTED`는 `kinds`만 안내(값 없음) ⑤ 목록의 `material_id`는 라우팅용이고 화면 주요 열·검색에는 노출하지 않는다(기관·연도·상태·개최일·담당자). ⑥ 사유·이름·메모는 `esc()`로 출력, `emp_verified=false`는 '자기신고' 꼬리표(검증됨 표기 금지) ⑦ 영업부장은 `viewer.can_write=false`라 입력·저장·상태 버튼을 숨기거나 비활성화 ⑧ 이력에서 `HANDOVER`는 "작성본 인계(전 작성자→새 담당자)"로 표시, 담당자 변경 이력 화면(`/bidcases/{id}/assignments/history`)에도 같은 행이 나온다 ⑨ 영업부장의 양식 구조 조회(`/board-forms/{id}`)는 팀 범위 때문에 404일 수 있다 — 저장본 값은 `/board-materials/{id}`로 받고, 표 구조가 필요하면 별도 확인(이관: 기획·백엔드 후속). — 기다리는 것: design-reviewer 규격 → 착수 — 근거: 이 보고서 §4
- `[이관: 기획]` 아래 열린 질문 1~5의 정책(영업팀장 열람·상태 되돌리기·값 길이·종결 뒤 수정·인계 대상)과, 비활성 사용자가 작성 책임자로 남을 때의 운영 절차(담당자 변경 상신)를 정해 달라. — 기다리는 것: 사용자 답 — 근거: §6
- `[이관: 데이터]` 해당 없음(레코드 값·출처를 건드리지 않았다).
- `[이관: 보안]` 구현 후 `security` 점검 권장: 쓰기 403 경로·404 은닉·인계 트랜잭션·접근 이력. 019 security 중-1(승인·취소 경합)은 인계가 같은 승인 트랜잭션에 얹혀 있어 먼저 닫는 편이 안전하다. — 기다리는 것: 적용·테스트 — 근거: security 1233

## 8. 열린 질문(사용자가 답하면 진행되는 것만)
1. **영업팀장(담당이 아닌 경우)도 이사회 자료를 볼 수 있어야 하나요?** 지금 정책은 "담당이 아니면 보이지 않는다, 영업부장만 열람"입니다. 그런데 팀장님은 담당자를 배정·변경 승인하고, 제출 때는 2차 결재자(최종 확정)가 됩니다. 결재하려면 내용을 봐야 합니다. 권장: 영업팀장·영업부장은 담당이 아니어도 보기만(쓰기 불가). 바꾸는 곳은 `BoardAccess.canViewCase`·`isViewAll` 두 곳이고 코드 한 줄 수준이다. 답이 없으면 정책 글자대로(영업부장만) 구현한다.
2. **상태를 되돌릴 수 있어야 하나요?**(예: 실수로 '안건 제출'을 눌렀을 때) 지금 구현은 앞으로만 갑니다. 이전 확정(NEXT A11)은 "불가, 영업팀장 예외"인데, 이번 정책이 "쓰기는 담당자만, 예외 없음"이라 영업팀장 예외를 그대로 둘 수 없습니다. 선택지: ⓐ되돌리기 없음(권장 안 함 — 실수 복구가 막힘) ⓑ담당자가 '의결 예정' 전까지 한 단계 뒤로, 이력에 남김(권장) ⓒ영업팀장(비담당)만 되돌림(예외 없음 정책과 충돌). 답이 없으면 ⓐ로 구현해 두고 ⓑ로 바꾼다.
3. **칸에 쓰는 글자 수 한도**: 기존 이사회 자료 초안 화면은 칸당 100자입니다. 확정안 13번 권장은 300자인데, 구현 위치가 100자로 잠겨 있어 300자로 쓰려면 초안 만들기와 함께 바뀝니다. 권장: 지금은 100자 유지(기존 화면과 같게), 현업이 부족하다고 하면 300자로 함께 확대.
4. **'안건 제출'·'의결 예정' 상태에서도 값을 고쳐 새 버전을 저장할 수 있게 둘까요?** 지금은 가결·부결 뒤에만 잠급니다. 권장: 그대로(의결 전까지 고칠 수 있고 버전으로 남음). 안건 제출 뒤 잠그면 021 제출 흐름과 같이 정해야 합니다.
5. **담당에서 빠진 사람의 작성본을 누구에게 넘길까요?** 권장: 같은 변경에서 새로 추가된 첫 번째 사람, 추가가 없으면 남은 담당자 중 먼저 배정된 사람(이름은 이력에 남음). 영업팀장이 따로 받을 사람을 고르게 하려면 담당자 변경 신청서에 '인계 받을 사람' 칸이 늘어납니다(추가 설계 필요).
