`RawStore` 클래스 앞(`safe_name` 다음)에 추가:
```python
def _restore(final: Path, bak: Path) -> None:
    """교체 실패 시 .bak을 제자리로. 복구 자체가 실패하면 .bak을 남겨 다음 실행이 복구한다."""
    try:
        if bak.exists() and not final.exists():
            bak.rename(final)
    except OSError:
        pass
```
- 마지막 `return final`(도달 안 하는 코드)은 제거했습니다.
- 재시도 6회와 대기(0.5×n초)는 그대로입니다.
- 재시도 중에도 `.bak`을 지우지 않습니다. 복구가 실패해도 원문은 `.bak`에 남습니다.

def test_real_host_config_schemes():
    from collector.sources.eminwon import DEFAULT_HOSTS_FILE, load_hosts
    hosts = {h.host: h for h in load_hosts(DEFAULT_HOSTS_FILE)}
    http_ok = {h for h, e in hosts.items() if "http" in e.schemes}
