## 2. 요구·핵심 사실 (근거)
- 입찰 결과 표는 없다. 판정은 039 약정 줄로만 한다. 근거: planner 4-2절 표, `BidTargetRules.java:122`(CONTRACT_DECIDED = 시작 전 줄).
- **PREP_NOBID_ACK(048)는 판정 근거로 쓰지 않는다.** PK가 `(EMP_NO, INSTITUTION_ID, ROUND_SEQ, NOTICE_HANDLED_AT)`(048_prep_nobid_ack.sql:24)라, 개인이 알림을 확인한 행위 기록일 뿐 계약 사실이 아니다. 입찰 없음 보조 표시는 공고 상태 근거 `BASIS_NO_BID`(`BidTargetRules.bidClosedBasis`)를 쓴다. 이 값은 올해 공고에서만 나온다.
- 연중에 뺀 곳은 새 표 없이 `INST_BID_TARGET` 이력(추가 전용, 044)에서 복원한다.
  - 같은 `(기관, TARGET_NO)`에 KIND=GOAL·TARGET_YEAR=Y인 REV가 한 번이라도 있었는데 최신 REV가 "살아 있는 Y 목표"가 아니면 '뺀 곳'이다.
  - 뺀 방식은 CANCEL(이유 코드 WRONG/DUP/DROPPED/ETC), 관심으로 옮김(MOVE, WATCH), 목표 연도 바꿈(SAVE로 연도 수정) 세 가지다. 취소 행은 직전 값을 그대로 복사하므로(`BidTargetService.java:348`) 연도가 남는다.
- **DB 변경은 필요 없다.** 새 스크립트도 없다. 기존 `IDX_IBT_KIND`와 PK로 충분하다(연 목표 수백 건 규모 가정). Oracle 쌍·번호·적용 순서 문제가 생기지 않는다.
- `portal.js`의 `isKb`는 은행 이름이 /국민/에 맞는지 본다(73행). 서버는 `BankYears.KB_BANK = "B02"` 코드로 본다. 기타(ETC, 직접 입력)에 '국민은행'이라 쓴 줄은 화면은 KB, 서버는 KB 아님으로 갈린다. 서버 규칙은 B02만 인정하는 쪽을 권한다. 이관 메모에 적었다.

## 3. 구현안

### 3-1. 판정 규칙 (서버 단일 규칙, 이 보고서 전용)
- 결과 줄(R) = 그 기관의 최신 유효 039 줄 중 TERM_FROM이 있고, 시작 연도가 [Y, Y+1]인 줄이다. 순위(RANK_CD)마다 시작이 가장 이른 한 줄을 고른다(같으면 약정 번호가 큰 쪽).
  - 시작을 모르는 줄(TERM_FROM null)은 결과로 세지 않는다. 추정 금지.
  - 창 [Y, Y+1]은 "목표 연도 = 입찰 해"라는 가정이다(`CLOSED_MSG`의 '올해 입찰'과 043 연도 범위 근거). 기획 확인 대상이다.
- 결과 코드
  - R 안에 B02 줄이 하나라도 있으면 `SUCCESS`. 순위는 불문이라 1금고, 2금고, 공동 모두 성공이다(`BankYears.yearState`와 같은 관례). 수의계약으로 국민은행이 연장된 경우도 R에 KB 줄이 있으니 성공이다.
  - R은 있고 KB가 없으면 `FAIL`.
  - R이 없으면 두 가지로 나눈다.
    - `UNREGISTERED`(결과 미등록): Y < 올해, 또는 Y = 올해이고 입찰 끝남 근거(`bidClosedBasis` 중 하나)가 있는 경우.
    - `PENDING`(결과 대기): 그 밖의 경우. Y > 올해이거나, 올해인데 아직 끝났다는 근거가 없는 경우.
  - 구분 기준은 "입찰이 끝났을 수 있는가"다. 끝났는데 약정이 없으면 사람이 등록할 차례(미등록), 아직 안 끝났으면 기다림(대기)이다.
- 성공 안의 재유치/신규
  - 우선 근거는 이긴 줄과 같은 순위의 직전 약정(이긴 줄보다 먼저 시작한 줄 중 TERM_TO가 가장 늦은 것)이다. 그 줄이 B02면 `RETAIN`, 아니면 `NEW`다. `win_kind_basis = "PRIOR_CONTRACT"`.
  - 직전 약정이 없으면 목표 구분(TAG_CD RETAIN/NEW)을 쓰고 `win_kind_basis = "TARGET_TAG"`로 드러낸다. 그래서 재유치 x + 신규 y = 성공 a가 항상 맞는다.
- **portal.js `P.decided`와의 맞춤 — 서버 단일 규칙을 권장하되 `P.decided`는 그대로 둔다.**
  - 질문이 다르다. `P.decided`는 오늘 기준 "다음 은행 태그"이고, 이 보고서는 연도 Y 입찰의 성적표다. 코드를 하나로 합치지 않는다.
  - 대신 같은 입력에서 같은 결론이 나오는 대응표를 두 곳(서버 단위 시험, 프런트 `frontend/test`)에 같은 이름의 시험으로 둔다.

| P.decided 태그 | 보고서 판정 |
|---|---|
| kept(지금 KB + 시작 전 KB 줄) | SUCCESS/RETAIN. 단 그 줄의 시작 연도가 [Y,Y+1]일 때 |
| won, 시작 전 KB 줄 있음 | SUCCESS/NEW |
| won, KB_NEXT 기사만 있음(kind==='next') | **다름.** 보고서는 039 줄이 없으면 성공이 아니다 → PENDING 또는 UNREGISTERED |
| next(시작 전 줄이 다른 은행) | FAIL |
| ended(공고 종료·입찰 없음) | 올해 끝남 근거가 있으면 UNREGISTERED. 근거가 없으면 PENDING |

### 3-3. 권한·감사
- **Menus 새 키는 만들지 않는다.** `Menus.MENUS` 8개 키 동결을 지킨다(`BidTargetController` 29행과 같은 이유). `guard.requireUser(req, "map")`으로 map 보기 권한(401/403 DENIED)을 확인한다.
- 그 위에 역할 확인을 둔다. `TargetResultService.canView(role)`은 `Teams.ROLES`에 있고 '예산'으로 시작하지 않는 역할만 통과시킨다. 그래서 영업팀·영업팀장·영업부장·디자이너(영업 소속 보기 전용, 기존 원칙)·전산팀·전산팀장(11-19 '시스템 전체 보기 전용')은 보고, 예산팀·예산팀장과 모르는 역할은 403이다.
- 전산팀(개발부서)을 넣을지는 사용자 문구 "영업부서 전원"과 어긋날 수 있어 기획 확인으로 남긴다. 빼려면 `canView` 한 줄이다.
- 403은 `guard.denied(req, ...)`로 DENIED 기록(본문·쿼리값 없음). 접근 이력은 기존 인터셉터가 모든 API를 남긴다. DETAIL은 `target-result n=<행수> removed=<건수>`만이고 연도(쿼리값)·기관명·사번은 넣지 않는다.
- **자기신고 인증의 한계**: `X-Emp-No`는 위조될 수 있다. 이 권한은 사칭 방지가 아니라 업무 규칙이다. 앞단 인증 전에는 보안 경계가 아니다. 응답이 영업 실적이므로 '검증된 사용자만 본다'는 식으로 문구화하지 않는다.

```java
package com.kbstar.kgi.ggreport.web.service;

import com.kbstar.kgi.ggreport.web.domain.BankContract;
import java.time.LocalDate;
import java.util.*;

/** 협약 성과(NEXT 104) 판정 — 금고 약정(039) 줄만 근거. 추정 없음. 규칙 전문은 설계 보고서 3-1. */
final class TargetResultRules {
    static final String SUCCESS = "SUCCESS", FAIL = "FAIL", PENDING = "PENDING", UNREGISTERED = "UNREGISTERED";
    static final String RETAIN = "RETAIN", NEW = "NEW", BASIS_PRIOR = "PRIOR_CONTRACT", BASIS_TAG = "TARGET_TAG";
    static final int WINDOW_AHEAD = 1;   // 결과 약정 시작 연도 ∈ [목표 연도, +1] — 기획 확인 대상
    private static final List<String> RANK_ORDER = Arrays.asList("FIRST", "SECOND", "JOINT", "NONE");

    static final class Verdict {
        String resultCd, winKind, winKindBasis;
        List<BankContract> lines = Collections.<BankContract>emptyList();
        BankContract kbLine, evidence;
    }

    private TargetResultRules() { }

    static Verdict judge(List<BankContract> all, String tagCd, int year, int thisYear, Map<String, Object> bidClosed) {
        List<BankContract> src = all == null ? Collections.<BankContract>emptyList() : all;
        Verdict v = new Verdict();
        v.lines = resultLines(src, year);
        if (v.lines.isEmpty()) {
            boolean ended = year < thisYear || (year == thisYear && bidClosed != null);
            v.resultCd = ended ? UNREGISTERED : PENDING;
            return v;
        }
        for (BankContract c : v.lines) if (BankYears.KB_BANK.equals(c.getBankCd())) { v.kbLine = c; break; }
        if (v.kbLine == null) { v.resultCd = FAIL; v.evidence = v.lines.get(0); return v; }
        v.resultCd = SUCCESS;
        v.evidence = v.kbLine;
        Boolean prior = priorWasKb(src, v.kbLine);
        if (prior != null) { v.winKind = prior ? RETAIN : NEW; v.winKindBasis = BASIS_PRIOR; }
        else { v.winKind = "RETAIN".equals(tagCd) ? RETAIN : NEW; v.winKindBasis = BASIS_TAG; }
        return v;
    }

    /** 순위마다 시작이 가장 이른 줄(같으면 번호 큰 쪽). 시작을 모르거나 창 밖이면 제외. 순위 순서 정렬. */
    static List<BankContract> resultLines(List<BankContract> all, int year) {
        Map<String, BankContract> byRank = new HashMap<String, BankContract>();
        for (BankContract c : all) {
            Integer fy = BankYears.yearOf(c.getTermFrom());
            if (fy == null || fy < year || fy > year + WINDOW_AHEAD) continue;
            String k = c.getRankCd() == null ? "" : c.getRankCd();
            BankContract cur = byRank.get(k);
            if (cur == null) { byRank.put(k, c); continue; }
            int r = c.getTermFrom().compareTo(cur.getTermFrom());
            if (r < 0 || (r == 0 && c.getContractNo() > cur.getContractNo())) byRank.put(k, c);
        }
        List<BankContract> out = new ArrayList<BankContract>(byRank.values());
        Collections.sort(out, new Comparator<BankContract>() {
            public int compare(BankContract a, BankContract b) {
                int x = RANK_ORDER.indexOf(a.getRankCd()), y = RANK_ORDER.indexOf(b.getRankCd());
                return (x < 0 ? 99 : x) - (y < 0 ? 99 : y);
            }
        });
        return out;
    }

    /** 이긴 줄과 같은 순위에서 먼저 시작한 줄 중 끝이 가장 늦은 줄이 국민은행이었나. 근거 없으면 null. */
    static Boolean priorWasKb(List<BankContract> all, BankContract win) {
        LocalDate ws = startOf(win.getTermFrom());
        if (ws == null) return null;
        BankContract best = null; LocalDate bestEnd = null;
        for (BankContract c : all) {
            if (c == win || !Objects.equals(c.getRankCd(), win.getRankCd())) continue;
            LocalDate cs = startOf(c.getTermFrom() != null ? c.getTermFrom() : c.getTermTo());
            LocalDate ce = BankContractRules.endOrNull(c.getTermTo());
            if (cs == null || ce == null || !cs.isBefore(ws)) continue;
            if (bestEnd == null || ce.isAfter(bestEnd)) { best = c; bestEnd = ce; }
        }
        return best == null ? null : Boolean.valueOf(BankYears.KB_BANK.equals(best.getBankCd()));
    }

    static LocalDate startOf(String t) {
        if (t == null || t.length() < 4) return null;
        try {
            int y = Integer.parseInt(t.substring(0, 4));
            int m = t.length() >= 7 ? Integer.parseInt(t.substring(5, 7)) : 1;
            int d = t.length() >= 10 ? Integer.parseInt(t.substring(8, 10)) : 1;
            return LocalDate.of(y, m, d);
        } catch (RuntimeException e) { return null; }
    }
}
```

```java
package com.kbstar.kgi.ggreport.web.service;

import com.kbstar.kgi.ggreport.web.domain.*;
import com.kbstar.kgi.ggreport.web.mapper.BidTargetMapper;
import com.kbstar.kgi.ggreport.web.mapper.TargetResultMapper;

import org.springframework.transaction.annotation.Transactional;
import java.time.LocalDate;
import java.util.*;

/** 협약 성과(NEXT 104) — 목표 연도별 성공·실패·대기·미등록·뺀 곳. 읽기 전용. ⚠️ 역할은 X-Emp-No 자기신고 위의 업무 규칙. */
@Service
public class TargetResultService {
    public static final String DENIED_MSG = "협약 성과는 영업부서와 허용된 부서만 볼 수 있습니다.";
    static final int TARGET_MAX = 2000, LINE_MAX = 20000;
    private static final String FINANCE_PREFIX = "예산";

    private final TargetResultMapper mapper;
    private final BidTargetMapper targets;   // selectNoticeLastForYear 읽기만(다른 세션 소유 — 수정 없음)

    public TargetResultService(TargetResultMapper mapper, BidTargetMapper targets) {
        this.mapper = mapper;
        this.targets = targets;
    }

    /** 알려진 역할 중 예산(재무) 계열 제외. 전산팀 포함 여부는 기획 확인. */
    public static boolean canView(String role) {
        String r = HeadRules.roleOf(role);
        return Teams.ROLES.contains(r) && !r.startsWith(FINANCE_PREFIX);
    }

    @Transactional(readOnly = true)
    public Map<String, Object> report(String yearRaw) {
        LocalDate today = LocalDate.parse(Times.todayKst());
        int thisYear = today.getYear();
        int year = BidTargetService.yearParam(yearRaw, thisYear);

        List<BidTarget> rows = mapper.selectGoalRows(year, new RowBounds(0, TARGET_MAX + 1));
        boolean truncated = rows.size() > TARGET_MAX;
        if (truncated) rows = rows.subList(0, TARGET_MAX);
        List<BankContract> lineRows = mapper.selectLinesForYear(year, new RowBounds(0, LINE_MAX + 1));
        if (lineRows.size() > LINE_MAX) throw new ApiException(409, "집계할 약정 기록이 너무 많습니다. 담당자에게 알려 주세요.");
        Map<String, List<BankContract>> lines = new HashMap<String, List<BankContract>>();
        for (BankContract c : lineRows) {
            List<BankContract> l = lines.get(c.getInstitutionId());
            if (l == null) { l = new ArrayList<BankContract>(); lines.put(c.getInstitutionId(), l); }
            l.add(c);
        }
        Map<String, NoticeRoundView> notices = new HashMap<String, NoticeRoundView>();
        if (year == thisYear) {
            for (NoticeRoundView n : targets.selectNoticeLastForYear(year)) if (!notices.containsKey(n.getInstitutionId())) notices.put(n.getInstitutionId(), n);
        }
        Map<String, BidPrep> preps = new HashMap<String, BidPrep>();   // 기관별 최신(쿼리가 UPDATED_AT 내림차순)
        for (BidPrep p : mapper.selectPrepsForYear(year, String.valueOf(year))) if (!preps.containsKey(p.getInstitutionId())) preps.put(p.getInstitutionId(), p);
        Map<String, String> rankNames = names("BANK_RANK"), srcNames = names("BANK_CONTRACT_SRC");

        Set<String> activeInst = new HashSet<String>();
        for (BidTarget t : rows) if (isActive(t, year)) activeInst.add(t.getInstitutionId());

        int[] n = new int[12];   // 0 target 1 success 2 retain 3 new 4 first 5 second 6 fail 7 pending 8 unreg 9 removed
        List<Map<String, Object>> items = new ArrayList<Map<String, Object>>();
        List<Map<String, Object>> removed = new ArrayList<Map<String, Object>>();
        for (BidTarget t : rows) {
            String inst = t.getInstitutionId();
            if (!isActive(t, year)) {
                if (activeInst.contains(inst)) continue;   // 취소 뒤 같은 해에 다시 넣음 — 살아 있는 쪽만
                removed.add(removedView(t, year)); n[9]++;
                continue;
            }
            List<BankContract> l = lines.get(inst);
            Map<String, Object> basis = year == thisYear ? BidTargetRules.bidClosedBasis(notices.get(inst), l, today) : null;
            TargetResultRules.Verdict v = TargetResultRules.judge(l, t.getTagCd(), year, thisYear, basis);
            n[0]++;
            if (TargetResultRules.SUCCESS.equals(v.resultCd)) {
                n[1]++;
                if (TargetResultRules.RETAIN.equals(v.winKind)) n[2]++; else n[3]++;
                if ("FIRST".equals(v.kbLine.getRankCd())) n[4]++; else if ("SECOND".equals(v.kbLine.getRankCd())) n[5]++;
            } else if (TargetResultRules.FAIL.equals(v.resultCd)) n[6]++;
            else if (TargetResultRules.PENDING.equals(v.resultCd)) n[7]++;
            else n[8]++;
            items.add(itemView(t, v, basis, year == thisYear, preps.get(inst), rankNames, srcNames));
        }
        Map<String, Object> sum = new LinkedHashMap<String, Object>();
        sum.put("target_n", n[0]); sum.put("success_n", n[1]); sum.put("success_retain_n", n[2]); sum.put("success_new_n", n[3]);
        sum.put("success_first_n", n[4]); sum.put("success_second_n", n[5]); sum.put("fail_n", n[6]);
        sum.put("pending_n", n[7]); sum.put("unregistered_n", n[8]); sum.put("removed_n", n[9]);
        int den = n[1] + n[6];
        sum.put("success_rate", den == 0 ? null : Double.valueOf(Math.round(n[1] * 1000.0 / den) / 10.0));
        sum.put("rate_numerator", n[1]); sum.put("rate_denominator", den);

        Map<String, Object> rule = new LinkedHashMap<String, Object>();
        rule.put("judged_by", "금고 약정 기록(039)");
        rule.put("start_window", "목표 연도~다음 해");
        Map<String, Object> out = new LinkedHashMap<String, Object>();
        out.put("year", year); out.put("today", today.toString()); out.put("truncated", truncated);
        out.put("rule", rule); out.put("summary", sum); out.put("items", items); out.put("removed_items", removed);
        return out;
    }

    private static boolean isActive(BidTarget t, int year) {
        return BidTargetRules.KIND_GOAL.equals(BidTargetRules.kindOf(t)) && !BidTargetService.ACTION_CANCEL.equals(t.getActionCd())
                && t.getTargetYear() != null && t.getTargetYear().intValue() == year;
    }

    private Map<String, String> names(String group) {
        Map<String, String> m = new HashMap<String, String>();
        for (BankContractCode c : mapper.selectCodes(group)) m.put(c.getCode(), c.getCodeName());
        return m;
    }

    private static Map<String, Object> head(BidTarget t) {
        Map<String, Object> m = new LinkedHashMap<String, Object>();
        m.put("institution_id", t.getInstitutionId()); m.put("institution_name", t.getInstitutionName());
        m.put("region_code", t.getRegionCode()); m.put("target_no", t.getTargetNo());
        m.put("tag_cd", t.getTagCd()); m.put("tag_name", t.getTagName()); m.put("owner_name", t.getOwnerName());
        return m;
    }

    private static Map<String, Object> removedView(BidTarget t, int year) {
        Map<String, Object> m = head(t);
        String kind = BidTargetRules.KIND_WATCH.equals(BidTargetRules.kindOf(t)) ? "MOVE_TO_WATCH"
                : (t.getTargetYear() == null || t.getTargetYear().intValue() != year ? "YEAR_CHANGED" : "CANCEL");
        m.put("removed_kind", kind);
        boolean cancel = "CANCEL".equals(kind);
        m.put("reason_cd", cancel ? t.getCancelReasonCd() : null);
        m.put("reason_name", cancel ? (BidTargetRules.CANCEL_ETC.equals(t.getCancelReasonCd()) ? t.getCancelReasonEtc() : t.getCancelReasonName()) : null);
        m.put("removed_at", t.getSavedAt());
        return m;
    }

    private static Map<String, Object> itemView(BidTarget t, TargetResultRules.Verdict v, Map<String, Object> basis, boolean thisYear,
                                                BidPrep p, Map<String, String> rankNames, Map<String, String> srcNames) {
        Map<String, Object> m = head(t);
        Map<String, Object> prep = new LinkedHashMap<String, Object>();
        prep.put("kind", p == null ? "NONE" : ("CANCELLED".equals(p.getStateCd()) ? "CANCELLED" : "ACTIVE"));
        prep.put("state_cd", p == null ? null : p.getStateCd());
        prep.put("state_name", p == null ? null : p.getStateName());
        m.put("prep", prep);
        m.put("result_cd", v.resultCd);
        m.put("win_kind", v.winKind);
        m.put("win_kind_basis", v.winKindBasis);
        m.put("win_rank_cd", v.kbLine == null ? null : v.kbLine.getRankCd());
        m.put("win_rank_name", v.kbLine == null ? null : rankNames.get(v.kbLine.getRankCd()));
        List<Map<String, Object>> banks = new ArrayList<Map<String, Object>>();
        for (BankContract c : v.lines) {
            Map<String, Object> b = new LinkedHashMap<String, Object>();
            b.put("rank_cd", c.getRankCd()); b.put("rank_name", rankNames.get(c.getRankCd()));
            b.put("bank_cd", c.getBankCd());
            b.put("bank_name", BankContractRules.BANK_ETC.equals(c.getBankCd()) ? c.getBankNameEtc() : c.getBankName());
            b.put("is_kb", BankYears.KB_BANK.equals(c.getBankCd()));
            b.put("term_from", c.getTermFrom()); b.put("term_to", c.getTermTo());
            banks.add(b);
        }
        m.put("banks", banks);
        if (v.evidence == null) m.put("evidence", null);
        else {
            Map<String, Object> e = new LinkedHashMap<String, Object>();
            e.put("contract_no", v.evidence.getContractNo()); e.put("src_kind_cd", v.evidence.getSrcKind());
            e.put("src_kind_name", srcNames.get(v.evidence.getSrcKind())); e.put("checked_date", v.evidence.getCheckedDate());
            m.put("evidence", e);
        }
        m.put("bid_basis", basis);
        m.put("no_bid", thisYear ? Boolean.valueOf(basis != null && BidTargetRules.BASIS_NO_BID.equals(basis.get("basis_cd"))) : null);
        return m;
    }
}
```

## 5. 보안·위험·되돌리는 법
- 권한: 401(사번 없음)과 403(map 보기 없음·역할 불허)을 모두 DENIED로 남기고 본문·쿼리값은 없다. 쓰기 경로가 없다(INSERT/UPDATE/DELETE 없음). 예외 메시지에 내부 정보는 없다(409는 고정 문구).
- **자기신고 인증의 한계**: 위에 적은 대로 사칭 방지가 아니다. 화면 문구에 '인증됨'을 쓰지 않는다.
- 판정의 한계(화면에 드러낼 것). 모두 3-1 규칙의 약점이다.
  - 약정을 사람이 등록해야 성공·실패가 나온다. 미등록은 '추정 없음'을 지킨 결과다.
  - 결과 창 [Y,Y+1]은 가정이다.
  - 4번째 줄의 '재유치/신규'는 직전 약정이 없을 때 목표 구분으로 대신한다. `win_kind_basis`로 드러난다.
  - 프런트 `isKb`(이름에 '국민')와 서버(B02 코드)가 기타 입력 줄에서 갈린다.
- 성능: 목표 2000건·약정 20000줄 상한으로 메모리를 막는다. 쿼리 4개는 연 1회 단위 조회이며 부하는 작다.
- 되돌리는 법: 새 파일 5개(Mapper 인터페이스·XML, Rules, Service, Controller)와 시험 파일을 지우면 끝이다. DB·기존 코드가 바뀌지 않았다.
