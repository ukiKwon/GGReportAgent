## 요구·근거 요약
- **Ollama 호출 형식의 근거**
  - Python은 langchain `ChatOpenAI`로 OpenAI 호환 `http://localhost:11434/v1`를 부릅니다(`agent/llm.py:27,193-206`). 설치 목록은 `GET {root}/api/tags`의 `{"models":[{"name":…}]}`입니다(`agent/model_select.py:86-102`).
  - 저장소 실측 기록은 **네이티브 `/api/chat`**에 `format`=JSON 스키마, `think:false`, `options={"temperature":0,"seed":0}`을 실어 불렀고 `prompt_eval_count`, `eval_count`, `done_reason`을 읽었다고 적었습니다(항목 5 문서 `:88-95`, `:141-146`). OpenAI 호환 `/v1/chat/completions`에는 `think`와 `num_ctx` 자리가 없다는 것도 이 PC에서 확인돼 있습니다(`:88-91`).
  - 그래서 **네이티브 `/api/chat`**을 씁니다. temp 0과 seed 고정이어야 재현된다는 실측(`:105-109`)도 근거입니다.
  - **저장소 근거가 없어 '확인 필요'인 것**: `"stream": false`(네이티브 기본은 스트리밍), 응답 본문 경로 `message.content`, 네이티브 404의 의미. 아래 ⑥의 curl 1회로 확인합니다.
- **입력 묶음**: 기존 대본은 손 입력 칸과 자동 값을 합칩니다(`PrepScriptService.java:271-365`). 그런데 `loadAuto`가 `private`이라 호출할 수 없습니다. 그래서 같은 열람 규칙으로 새 리더가 다시 읽습니다(④ 참고).
  - 열람 규칙은 `requireVisible`(못 보면 404), `canReadForm`(요약 양식), `canViewCase`(이사회 숫자)입니다.
- **4칸 제한**: 12줄, 줄당 300자, 합계 1,000자입니다(`PrepScriptService.java:49-52,221-242`). 칸 키는 `intro`, `status_note`, `effect`, `profit_note`입니다(`preptask.js:725-728`).
- **감사 틀**: BID_PREP_ACT는 `ACTION_CD VARCHAR(30)`(`024_bid_prep.sql:87`), BOARD_MATERIAL_ACT는 `VARCHAR(20)`(`020_board_material.sql:73`)입니다. `SCRIPT_AI_DRAFT`는 15자라 **스크립트를 고칠 필요가 없습니다.** 대본 Word 만들기도 DB 코드 등록이 없습니다(grep 0건).
- **본문 상한 필터**: 경로가 맞지 않으면 통과시킵니다(`BoardWriteLimitFilter.java:147-151`). 새 초안 API는 **본문을 받지 않으므로** 필터를 고치지 않습니다.
- ⚠️ **`@ConditionalOnMissingBean` 순서 함정**: `NotYetMigratedLlmClient.Registration`은 컴포넌트 스캔으로 잡히는 일반 `@Configuration`입니다(`:59-66`). 이 조건은 평가 순서에 따라 결과가 달라질 수 있어, 새 빈이 기존 빈을 "자동으로 밀어낸다"는 주석(`:56-57`)을 믿을 수 없습니다. 그래서 새 빈에 `@Primary`를 붙입니다.

### 2. `llm/OllamaGuard.java`
```java
package com.kbstar.kgi.ggreport.web.llm;

import java.net.URI;
import java.net.URISyntaxException;
import java.util.Locale;
import java.util.regex.Pattern;

/**
 * 로컬 Ollama 를 켜도 되는가 — 판정은 여기 한 곳. 사유 코드만 돌려준다(주소·모델명은 로그·화면에 싣지 않는다).
 * 내부망 신호: 데이터소스가 JNDI 이거나 MySQL·H2 가 아니면(=Oracle) enabled=true 여도 BAD_CONFIG(INTERNAL_ENV).
 * 주소: http + 127.0.0.1|localhost + 명시 포트, 경로·쿼리·계정정보 금지. localhost 는 127.0.0.1 로 고정해 이름 해석을 타지 않는다.
 */
public final class OllamaGuard {

    public enum State { OFF, READY, BAD_CONFIG }

    static final int MIN_TIMEOUT_MS = 500;
    static final int MAX_CONNECT_MS = 10_000;
    static final int MAX_READ_MS = 600_000;
    static final int MIN_BODY = 1_024;
    static final int MAX_BODY = 1_048_576;
    static final int MAX_NUM_CTX = 131_072;
    private static final Pattern MODEL = Pattern.compile("[A-Za-z0-9][A-Za-z0-9._:/-]{0,99}");

    public static final class Check {
        private final State state;
        private final String reason;
        private final URI chat;
        private final URI tags;

        Check(State state, String reason, URI chat, URI tags) {
            this.state = state;
            this.reason = reason;
            this.chat = chat;
            this.tags = tags;
        }

        public State getState() { return state; }
        public String getReason() { return reason; }
        URI getChat() { return chat; }
        URI getTags() { return tags; }

        @Override
        public String toString() { return "Check[" + state + "," + reason + "]"; }   // 주소 없음
    }

    private OllamaGuard() {
    }

    public static Check check(OllamaProperties p, String datasourceUrl, String jndiName) {
        if (p == null || !p.isEnabled()) {
            return new Check(State.OFF, "DISABLED", null, null);
        }
        String ds = trim(datasourceUrl).toLowerCase(Locale.ROOT);
        if (!trim(jndiName).isEmpty() || !(ds.startsWith("jdbc:mysql:") || ds.startsWith("jdbc:h2:"))) {
            return bad("INTERNAL_ENV");
        }
        String model = trim(p.getModel());
        if (model.isEmpty()) return bad("NO_MODEL");
        if (!MODEL.matcher(model).matches()) return bad("MODEL_FORMAT");
        String fb = trim(p.getFallbackModel());
        if (!fb.isEmpty() && !MODEL.matcher(fb).matches()) return bad("MODEL_FORMAT");
        if (p.getConnectTimeoutMs() < MIN_TIMEOUT_MS || p.getConnectTimeoutMs() > MAX_CONNECT_MS
                || p.getReadTimeoutMs() < MIN_TIMEOUT_MS || p.getReadTimeoutMs() > MAX_READ_MS) {
            return bad("TIMEOUT_RANGE");
        }
        if (p.getMaxResponseBytes() < MIN_BODY || p.getMaxResponseBytes() > MAX_BODY) return bad("BODY_RANGE");
        if (p.getNumCtx() < 0 || p.getNumCtx() > MAX_NUM_CTX) return bad("NUM_CTX_RANGE");
        URI uri;
        try {
            uri = new URI(trim(p.getBaseUrl()));
        } catch (URISyntaxException e) {
            return bad("URL_SYNTAX");
        }
        if (!"http".equals(lower(uri.getScheme()))) return bad("URL_SCHEME");
        if (uri.getRawUserInfo() != null || uri.getRawQuery() != null || uri.getRawFragment() != null) return bad("URL_EXTRA");
        String path = uri.getRawPath();
        if (path != null && !path.isEmpty() && !"/".equals(path)) return bad("URL_PATH");
        String host = lower(uri.getHost());
        if (!"127.0.0.1".equals(host) && !"localhost".equals(host)) return bad("NOT_LOOPBACK");
        int port = uri.getPort();
        if (port < 1 || port > 65535) return bad("URL_PORT");
        try {
            return new Check(State.READY, null,
                    new URI("http", null, "127.0.0.1", port, "/api/chat", null, null),
                    new URI("http", null, "127.0.0.1", port, "/api/tags", null, null));
        } catch (URISyntaxException e) {
            return bad("URL_SYNTAX");
        }
    }

    private static Check bad(String reason) { return new Check(State.BAD_CONFIG, reason, null, null); }
    private static String trim(String s) { return s == null ? "" : s.trim(); }
    private static String lower(String s) { return s == null ? "" : s.toLowerCase(Locale.ROOT); }
}
```

public class OllamaLlmClient implements LlmClient, DisposableBean {

    static final int POOL_MS = 1_000;
    static final int PROBE_MS = 2_000;

    public static final class Probe {
        private final boolean reachable;

        Probe(boolean reachable, boolean modelReady) {

            this.modelReady = modelReady;
        }

    private final String model;

    private final int readMs;

    private final Semaphore gate = new Semaphore(1);

    public OllamaLlmClient(OllamaProperties p, OllamaGuard.Check check) {
        this.check = check;
        this.model = trim(p.getModel());
        this.fallbackModel = trim(p.getFallbackModel());

        this.readMs = p.getReadTimeoutMs();

        this.thinkOff = p.isThinkOff();

        this.http = ready ? build(connectMs, readMs) : null;

        }
    }

    public OllamaGuard.State state() { return check.getState(); }

    @Override
    public <T> LlmResponse<T> structured(LlmRequest<T> request) {
        if (http == null) {
            throw new LlmCallException(LlmCallException.OFF, 0);
        }
        if (!gate.tryAcquire()) {
            throw new LlmCallException(LlmCallException.BUSY, 0);
        }
        try {
            try {
                return new LlmResponse<T>(call(model, request), model, false);
            } catch (LlmException e) {
                if (fallbackModel.isEmpty() || fallbackModel.equals(model) || !FallbackPolicy.shouldFallback(e)) {
                    throw e;
                }
                return new LlmResponse<T>(call(fallbackModel, request), fallbackModel, true);
            }
        } finally {
            gate.release();
        }
    }

    private <T> T call(String name, LlmRequest<T> req) {
        byte[] payload = payload(name, req);
        HttpPost post = new HttpPost(check.getChat());
        post.setHeader(HttpHeaders.ACCEPT, "application/json");
        post.setEntity(new ByteArrayEntity(payload, ContentType.APPLICATION_JSON));
        long t0 = System.nanoTime();
        long deadline = t0 + (long) (connectMs + readMs) * 1_000_000L;
        int status = -1;
        byte[] raw;
        try (CloseableHttpResponse res = http.execute(post)) {
            status = res.getStatusLine().getStatusCode();
            HttpEntity e = res.getEntity();
            if (status == 404) {
                post.abort();
                throw new LlmModelUnavailableException(LlmCallException.MODEL_MISSING, 404, name);
            }
            if (status == 401 || status == 403) {
                post.abort();
                throw new LlmAuthException(LlmCallException.AUTH, status);
            }
            if (status < 200 || status >= 300) {
                post.abort();
                throw new LlmCallException(LlmCallException.HTTP, status);
            }
            if (e == null || e.getContentLength() > maxBody) {
                post.abort();
                throw new LlmCallException(LlmCallException.BAD_OUTPUT, status);
            }
            raw = readCapped(e.getContent(), maxBody, deadline);
            if (raw == null) {
                post.abort();
                throw new LlmCallException(LlmCallException.BAD_OUTPUT, status);
            }
        } catch (LlmException ex) {
            throw ex;
        } catch (InterruptedIOException ex) {           // 연결·응답 시간 초과(ConnectTimeout·SocketTimeout·풀 대기)
            post.abort();
            throw new LlmCallException(LlmCallException.TIMEOUT, 0);
        } catch (IOException | RuntimeException ex) {    // 연결 거부 등 — 예외 메시지는 남기지 않는다(주소가 섞일 수 있다)
            post.abort();
            throw new LlmCallException(LlmCallException.UNREACHABLE, 0);
        } finally {
            LOG.info("local-llm call model={} http={} ms={}", name, status, (System.nanoTime() - t0) / 1_000_000L);
        }
        return parse(raw, req.getSchema(), status);
    }

    private byte[] payload(String name, LlmRequest<?> req) {

        body.put("model", name);
        ObjectNode msg = body.putArray("messages").addObject();

        if (a == null) {
            return null;
        }
        try {

            return n != null && n.isObject() ? n : null;
        } catch (IOException e) {
            throw new LlmCallException(LlmCallException.BAD_REQUEST, 0);
        }
    }

    private <T> T parse(byte[] raw, Class<T> schema, int status) {
        JsonNode root;
        try {
            root = json.readTree(raw);
        } catch (IOException e) {
            throw new LlmCallException(LlmCallException.BAD_OUTPUT, status);
        }
        if (root == null || !root.isObject() || root.hasNonNull("error")) {
            throw new LlmCallException(LlmCallException.BAD_OUTPUT, status);
        }
        if ("length".equals(root.path("done_reason").asText(""))) {   // 출력이 잘림 — 반쪽 JSON 을 쓰지 않는다
            throw new LlmCallException(LlmCallException.TRUNCATED, status);
        }
        JsonNode content = root.path("message").path("content");        // ⚠️ 경로는 실측 확인 필요(보고서 ⑥)
        if (!content.isTextual()) {
            throw new LlmCallException(LlmCallException.BAD_OUTPUT, status);
        }
        String text = content.asText();
        if (schema == String.class) {
            return schema.cast(text);
        }
        String block = jsonBlock(text);
        if (block == null) {
            throw new LlmCallException(LlmCallException.BAD_OUTPUT, status);
        }
        try {
            return json.readValue(block, schema);
        } catch (IOException e) {
            throw new LlmCallException(LlmCallException.BAD_OUTPUT, status);
        }
    }

    /** 응답 글에서 첫 '{' ~ 마지막 '}' — 모델이 ```json 울타리·앞뒤 말을 붙여도 받는다. */
    static String jsonBlock(String text) {
        int a = text.indexOf('{');
        int b = text.lastIndexOf('}');
        return a >= 0 && b > a ? text.substring(a, b + 1) : null;
    }

    /** GET /api/tags — 2초 제한. 설치 목록은 돌려주지 않고 "닿는가·설정 모델이 있는가" 둘만. */
    public Probe probe() {
        if (http == null) {
            return new Probe(false, false);
        }
        HttpGet get = new HttpGet(check.getTags());
        get.setConfig(RequestConfig.custom().setConnectTimeout(PROBE_MS).setSocketTimeout(PROBE_MS)
                .setConnectionRequestTimeout(POOL_MS).setRedirectsEnabled(false)
                .setCookieSpec(CookieSpecs.IGNORE_COOKIES).build());
        try (CloseableHttpResponse res = http.execute(get)) {
            int st = res.getStatusLine().getStatusCode();
            HttpEntity e = res.getEntity();
            if (st < 200 || st >= 300 || e == null) {
                get.abort();
                return new Probe(true, false);
            }
            byte[] raw = readCapped(e.getContent(), PROBE_MAX_BODY, System.nanoTime() + PROBE_MS * 1_000_000L);
            if (raw == null) {
                get.abort();
                return new Probe(true, false);
            }
            boolean ready = false;
            for (JsonNode m : json.readTree(raw).path("models")) {     // agent/model_select.py installed_models 와 같은 모양
                String n = m.path("name").asText("");
                if (n.equals(model) || n.startsWith(model)) {
                    ready = true;
                    break;
                }
            }
            return new Probe(true, ready);
        } catch (IOException | RuntimeException ex) {
            get.abort();
            return new Probe(false, false);
        }
    }

    /** max 를 넘으면 null(호출자가 abort). 마감을 넘으면 SocketTimeoutException(→ TIMEOUT). */
    static byte[] readCapped(InputStream in, int max, long deadlineNanos) throws IOException {
        if (in == null) {
            return new byte[0];
        }
        ByteArrayOutputStream out = new ByteArrayOutputStream();
        byte[] buf = new byte[4096];
        int total = 0;
        int n;
        while ((n = in.read(buf)) > 0) {
            total += n;
            if (total > max) {
                return null;
            }
            if (System.nanoTime() - deadlineNanos > 0) {
                throw new SocketTimeoutException("deadline");
            }
            out.write(buf, 0, n);
        }
        return out.toByteArray();
    }

```java
            return null;

        StringBuilder sb = new StringBuilder(raw.length());

            int cp = raw.codePointAt(i);
            i += Character.charCount(cp);

            boolean bad = t == Character.CONTROL || t == Character.FORMAT || t == Character.SURROGATE
                    || t == Character.LINE_SEPARATOR || t == Character.PARAGRAPH_SEPARATOR
                    || t == Character.PRIVATE_USE || t == Character.UNASSIGNED;
            sb.appendCodePoint(bad ? ' ' : cp);
        }
        String s = sb.toString().replaceAll("\\s+", " ").trim();
        if (s.isEmpty()) {
            return null;
        }
        if (s.length() > max) {
            int end = Character.isHighSurrogate(s.charAt(max - 1)) ? max - 1 : max;
            s = s.substring(0, end).trim();
        }
        if (!Pii.scan(s).isEmpty()) {
            if (b != null) {
                b.piiDropped++;
            }
            return null;
        }
        return s;
```

```java
    static Result finish(ScriptDraftBasisReader.Basis b, Set<String> ask, Set<String> allowed, ScriptDraftOut out,
                         String model, boolean fellBack, long ms) {
        Map<String, String> fields = new LinkedHashMap<String, String>();
        Map<String, String> why = new LinkedHashMap<String, String>();
        boolean any = false;
        for (String k : FIELDS) {
            String v = "";
            String reason;

                else if (!Pii.scan(s).isEmpty()) reason = "PII";
                else { v = s; reason = null; any = true; }
            }
            fields.put(k, v);
            if (reason != null) why.put(k, reason);
        }

    private static Result empty(ScriptDraftBasisReader.Basis b, String reason, boolean called, long ms) {

        Map<String, String> why = new LinkedHashMap<String, String>();

            fields.put(k, "");

    /** 줄바꿈만 남기고 제어문자 제거 → 12줄·줄당 300자·합계 1,000자(PrepScriptService.lines 와 같은 상한 — 넘으면 자른다). */
    static String tidy(String raw) {
        if (raw == null) return "";
        String norm = raw.replace("\r\n", "\n").replace('\r', '\n');
        StringBuilder clean = new StringBuilder();
        for (int i = 0; i < norm.length(); ) {
            int cp = norm.codePointAt(i);
            i += Character.charCount(cp);
            int t = Character.getType(cp);
            boolean bad = cp != '\n' && (t == Character.CONTROL || t == Character.FORMAT || t == Character.SURROGATE
                    || t == Character.LINE_SEPARATOR || t == Character.PARAGRAPH_SEPARATOR || t == Character.PRIVATE_USE
                    || t == Character.UNASSIGNED || (cp >= 0x2066 && cp <= 0x2069) || cp == 0x061C);
            clean.appendCodePoint(bad ? ' ' : cp);
        }
        List<String> lines = new ArrayList<String>();
        int total = 0;
        for (String part : clean.toString().split("\n", -1)) {
            String s = part.replaceAll("[ \\t]+", " ").trim();
            if (s.isEmpty()) continue;
            if (s.length() > MAX_LINE) s = cut(s, MAX_LINE);
            if (total + s.length() > MAX_TOTAL) s = cut(s, MAX_TOTAL - total);
            if (s.isEmpty()) break;
            lines.add(s);
            total += s.length();
            if (lines.size() >= MAX_LINES || total >= MAX_TOTAL) break;
        }
        StringBuilder sb = new StringBuilder();
        for (String s : lines) {
            if (sb.length() > 0) sb.append('\n');
            sb.append(s);
        }
        return sb.toString();
    }

    private static String cut(String s, int n) {
        if (n <= 0) return "";
        if (s.length() <= n) return s;
        int end = Character.isHighSurrogate(s.charAt(n - 1)) ? n - 1 : n;
        return s.substring(0, end).trim();
    }

    static Set<String> allowedNumbers(Map<String, Object> facts) {
        Set<String> out = new HashSet<String>();
        for (Object v : facts.values()) {
            if (v instanceof String) collect((String) v, out);
            else if (v instanceof List) for (Object o : (List<?>) v) if (o instanceof String) collect((String) o, out);
        }
        return out;
    }

    private static void collect(String s, Set<String> out) {
        Matcher m = NUMBER.matcher(s);
        while (m.find()) {
            String n = norm(m.group());
            if (n != null) out.add(n);
        }
    }

    static boolean numbersAllowed(String s, Set<String> allowed) {
        Matcher m = NUMBER.matcher(s);
        while (m.find()) {
            String n = norm(m.group());
            if (n == null || !allowed.contains(n)) return false;
        }
        return true;
    }

    static String norm(String raw) {
        try {
            return new BigDecimal(raw.replace(",", "")).stripTrailingZeros().toPlainString();
        } catch (NumberFormatException e) {
            return null;
        }
    }

    static String reasonOf(LlmException e) {
        if (e instanceof LlmModelUnavailableException) return "MODEL_MISSING";
        if (e instanceof LlmCallException) {
            String c = ((LlmCallException) e).getCode();
            if (LlmCallException.BUSY.equals(c)) return "BUSY";
            if (LlmCallException.TIMEOUT.equals(c)) return "TIMEOUT";
            if (LlmCallException.UNREACHABLE.equals(c)) return "UNREACHABLE";
            if (LlmCallException.BAD_OUTPUT.equals(c) || LlmCallException.TRUNCATED.equals(c)) return "BAD_OUTPUT";
        }
        return "LLM_ERROR";
    }

        d.put("message", "이 PC에서 AI 초안 기능이 꺼져 있습니다.");
        return ApiException.withDetail(503, d);
    }
```

```java
        String outcome = r.outcome();
        try {
            audit.record(auditBid, ACTION, outcome, before, TASK, actor, ui);
        } catch (RuntimeException e) {
            LOG.error("AI 초안 감사를 남기지 못했다(응답 500): case={} cause={}", auditBid, e.getClass().getSimpleName());
            throw e;
        }
        ScriptDraftBasisReader.Basis b = r.getBasis();
        if (r.boardAuditNeeded()) {
            try {
                boardAudit.record(boardAudit.before(String.valueOf(b.getBoardId())), ACTION, "OK".equals(outcome) ? "OK" : "ERROR", actor, ui);
            } catch (RuntimeException e) {
                LOG.error("이사회 자료 감사(AI 초안)를 남기지 못했다(응답 500): cause={}", e.getClass().getSimpleName());
                throw e;                                // fail-closed — 초안을 내보내지 않는다
            }
        }
        req.setAttribute(AccessLogInterceptor.DETAIL, "prep case=" + auditBid + " state=" + before + " code=" + ACTION
                + " result=" + r.getState() + "/" + (r.getReason() == null ? "-" : r.getReason())
                + " board=" + (b.getBoardId() == null ? "-" : b.getBoardId())
                + " snap=" + (b.getBoardSnap() == null ? "-" : b.getBoardSnap())
                + " form_ver=" + (b.getFormVer() == null ? "-" : b.getFormVer())
                + " ms=" + r.getMs());
        return r.toMap();
    }

    private void auditFailure(String bid, String outcome, String before, Actor actor, BoardUiIds.Ui ui) {
        try {
            String st = before != null ? before : NO_CASE.equals(bid) ? NO_CASE : prep.stateOf(bid);
            audit.record(bid, ACTION, outcome, st, TASK, actor, ui);
        } catch (RuntimeException ex) {
            LOG.warn("AI 초안 실패 감사를 남기지 못했다: outcome={} cause={}", outcome, ex.getClass().getSimpleName());
        }
    }

    private static String caseKey(String bid) {
        String b = bid == null ? "" : bid.trim();
        return b.matches("[A-Za-z0-9._-]{1,64}") ? b : NO_CASE;
    }
}
```

### API 계약 요약
**`POST /bidcases/{id}/prep/board-script-draft`**: 본문 없음. 헤더 `X-Emp-No`, `X-Screen-Id: prep_detail`, `X-Button-Id: script_ai_draft`를 씁니다.

|---|---|---|

## ⑤ 보안 검토에 넘길 점
1. **켜는 조건**: 명시 키 + 루프백 + 외부망 데이터소스 신호(MySQL·H2, JNDI 없음). 데이터소스로 판정하는 것은 우회 가능한 신호입니다(외부망 로컬을 Oracle로 바꾸면 꺼지고, 내부망에 MySQL을 쓰면 켜질 수 있음). 받아들일 수 있는지 판단이 필요합니다.
2. **localhost 고정**: localhost를 127.0.0.1로 고정해 hosts 파일과 DNS 해석을 타지 않습니다. 시스템 프록시를 따르지 않고, 리다이렉트와 재시도가 없습니다.
3. **같은 PC의 다른 프로세스가 11434를 먼저 잡으면** 그 프로세스가 프롬프트(기관 사실과 확정 이사회 숫자)를 받습니다. 시범 PC라 허용하는지 판단이 필요합니다.
4. **개인정보**
   - 막은 것: 기관장 이름·직함, 소재지는 넣지 않습니다. 값과 출력 모두 `Pii.scan`(정규식)으로 거릅니다.
   - 한계: **요약서 자유 글(추진 배경, 경쟁은행 동향)에 사람 이름을 적으면 못 거릅니다.** 규칙으로 막을지 판단이 필요합니다.
5. **가짜 숫자 차단**: 출력의 모든 아라비아 숫자는 자료 숫자 집합 안에 있어야 합니다. 한계: '육억'처럼 한글로 쓴 숫자는 못 잡습니다. 다른 기관 이름을 섞는 것도 막지 않습니다(③ DocCheck 규칙 재사용은 후보).
6. **프롬프트 주입**: 요약서 글은 사람이 입력합니다. 영향 범위는 자기 화면의 칸 초안뿐이고, 저장하지 않으며, 사람이 고칩니다. `<자료>` 블록을 닫는 문자는 전각으로 바꿉니다.
7. **감사**
   - BID_PREP_ACT는 모든 결과를 남깁니다.
   - BOARD_MATERIAL_ACT는 확정 자료의 숫자를 LLM에 보냈을 때만 남기고, 기록에 실패하면 500으로 초안을 내보내지 않습니다(fail-closed).

   - `org.apache.http.wire`와 `headers`가 WARN으로 유지되는지 확인이 필요합니다. 그 설정이 풀리면 프롬프트가 로그로 나갑니다.
8. **자기신고 인증의 한계**: X-Emp-No, 화면, 버튼은 자기신고입니다. 막을 수 있는 것은 업무 규칙(열람 판정)까지입니다.
9. **자원 고갈**: 동시 1건(BUSY)이지만 요청마다 Tomcat 스레드를 최대 5분 잡습니다. 시범 PC라 허용했습니다.

- **CPU 소요 시간**: 4칸 한 번에 몇 초가 걸리는지 모릅니다(9b 배점표 실측은 249초). 300초 기본값이 맞는지 첫 실행으로 봅니다.
- **`Pii.scan`**: 시간 제한 없는 판으로 썼고, 300자 이하 입력에서의 성능은 확인하지 않았습니다.
- **프런트 상수와 서버 버튼 목록 대조 시험**이 있는지 확인하지 못했습니다. 있으면 `script_ai_draft`를 더해야 합니다.
