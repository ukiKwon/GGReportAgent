## 4. 표(투자가부결정기준)가 없을 때 처리 선택지
현재는 `IRR_RULE_UNREADABLE`이 나오고 칸은 빈 채로 "failed"가 됩니다. 사용자 답(숫자는 늘 올린 표에 있음)에 맞춘 선택지입니다.
- 선택지 A(권장, 지금 동작 유지): 빈 칸과 failed로 두어 사람이 직접 입력합니다. 근거는 표 없이 숫자를 만들면 틀린 값이 문서에 들어갈 수 있다는 점입니다. 추가 코드는 없습니다.
- 선택지 B: 기본 문구(`IRR_RULE_DEFAULT`, 숫자 없음)를 그대로 두고 "올린 표를 확인하세요" 안내만 화면에 더합니다. 이 안내는 프런트 몫입니다.
- 선택지 C: 서버 설정값으로 대체 할인율을 둡니다. 비권장입니다. 사용자가 "늘 같음"이라 했지만 고정값을 다시 들이면 이번 정리와 반대 방향이고, 설정 키가 PC마다 달라질 수 있습니다.

## 5. 패치안 초안(선택, 샘플 숫자만 정리하려는 경우)
- 가림 상수를 없애려면 `EXAMPLE_DISCOUNT`를 지웁니다. 1147행은 샘플 문구를 `{"…"}` 같은 정수 배열로 직접 적고, 1166-1170행은 현재가치 샘플 배열을 직접 적습니다. 숫자 배열은 기획·데이터 확인 후에 정해야 하고, 지금은 제가 만들 근거가 없습니다.
- 이 패치는 `sample=false` 출력에 영향이 없습니다. 급하지 않은 정리라서 이번 변경 없이 두고 NEXT에 남기는 편을 권합니다.
- 테스트는 변경하지 않습니다. 굳이 추가한다면 `sample=false`에서 C-2·C-3 값 칸이 모두 빈 문자열인지 확인하는 단언 한 개를 `BoardDocSpecTest`에 더할 수 있습니다.
