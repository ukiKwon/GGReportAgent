## 보충 — Word '요약' 모드에는 날짜가 한 글자도 나가지 않게 못 박음

조정자 지시를 반영해 이전 보고의 설계와 시험 목록에 아래를 더한다. 나머지 내용은 그대로다.

### 1. 설계 규칙
- **요약 모드에는 날짜 정보가 하나도 나가지 않는다.** '현재', '미상', 연도, 연-월, 날짜 괄호 모두 해당한다(사용자 재강조).
- 이 규칙은 `HeadDocBuilder.lineText`에서 지킨다. `withDates=false`면 `v`(내용)만 돌려준다(현 `HeadDocBuilder.java:503-506`).
- 이번 패치는 `datesOf`·`isCurrent`·`sortKey`만 바꾼다. `lineText`의 요약 분기는 건드리지 않는다.
- 요약 모드에서 `current`가 바꾸는 것은 **순서뿐**이다(현직 맨 위, 미상은 시작 연월 자리). 1장 맞춤 높이 추정(`contentsOf`)도 같은 `lineText`를 쓰므로 날짜가 끼지 않는다.
- 아래 문장을 `lineText` 주석에 한 줄 더한다.
```java
// old
    /** 한 줄 글자('■ ' 제외). 요약본은 내용만, 날짜 포함은 내용 + 괄호(앞 공백 없음) — 사용자 11-24 '마산공업고등학교 졸업(2026.01)'. */
// new
    /** 한 줄 글자('■ ' 제외). 요약본은 내용만 — '현재'·'미상'·연도·연월·괄호를 한 글자도 붙이지 않는다(사용자 11-24·11-25 재확인). 날짜 포함은 내용 + 괄호(앞 공백 없음) — 사용자 11-24 '마산공업고등학교 졸업(2026.01)'. */
```
- 한계: 사용자가 **내용 글자 자체에** 연도를 적은 경우(예: '2018 ○○위원')는 내용이라 그대로 나간다. 날짜 칸에서 온 글자만 막는다. 그래서 시험 데이터 내용에는 숫자를 넣지 않는다.
- 경력은 시작 연도 필수 그대로다(사용자 ⓐ). `HeadText.requireStart`를 바꾸지 않는다.

### 2. 추가 시험 ① `HeadDocBuilderDatesTest` (단위)
```java
    @Test
    public void 요약본은_현직_미상_변경_뒤에도_학력_경력_줄에_날짜_글자가_전혀_없다() throws Exception {
        List<Map<String, Object>> edu = new ArrayList<Map<String, Object>>(Arrays.asList(
                item("가람고등학교 졸업", "2010", null),          // 시작만 있는 학력(날짜 포함이면 '(2010 ~ 미상)')
                item("나래대학교 졸업", null, null)));             // 연도 없는 학력
        List<Map<String, Object>> career = new ArrayList<Map<String, Object>>(Arrays.asList(
                cur(item("가람구청장", "2026-07", null)),          // 현직(날짜 포함이면 '(2026.07 ~ 현재)')
                item("가람시 기획관", "2018", null)));             // 끝 모름(날짜 포함이면 '(2018 ~ 미상)')
        Map<String, Object> d = detail(edu, career);
        String x = render(d, false);
        assertFalse("현재 없음", x.contains("현재"));
        assertFalse("미상 없음", x.contains("미상"));
        for (String v : new String[]{"가람고등학교 졸업", "나래대학교 졸업", "가람구청장", "가람시 기획관"}) {
            java.util.regex.Matcher m = Pattern.compile("<w:t[^>]*>(" + Pattern.quote(v) + "[^<]*)</w:t>").matcher(x);
            assertTrue(v + " 줄이 있다", m.find());
            String line = m.group(1);
            assertEquals(v + " 줄은 내용만(괄호·날짜 없음)", v, line);
            assertFalse(v + " 줄 안 4자리 연도 없음", Pattern.compile("\\d{4}").matcher(line).find());
        }
        assertFalse("문서 전체 저장 형식·표기 형식 날짜 없음", Pattern.compile("\\d{4}[-.]\\d{2}").matcher(x).find()
                || x.contains("2010") || x.contains("2018") || x.contains("2026"));
        assertTrue("요약본도 현직이 맨 위", x.indexOf("가람구청장") < x.indexOf("가람시 기획관"));
        assertTrue("대조: 날짜 포함 모드에는 나온다", squareLine(render(d, true), "가람구청장(2026.07 ~ 현재)")
                && squareLine(render(d, true), "가람시 기획관(2018 ~ 미상)") && squareLine(render(d, true), "가람고등학교 졸업(2010 ~ 미상)"));
    }
```
- 이 시험의 `detail()`에는 임기·첫 취임일·생년월일이 없다. 그래서 문서 전체 연도 단언도 성립한다.
- `cur()`·`render()`·`squareLine()`은 이전 보고 4절의 패치와 기존 도우미를 쓴다.

### 3. 추가 시험 ② `InstitutionHeadDocxSourcePhotoApiTest` (API 끝까지)
```java
    @Test
    public void 요약본_Word에는_현직_미상_학력_연도가_한_글자도_없다() throws Exception {
        long head = addHeadOk(INST, L1, "홍길동", "구청장");
        addItemOk(INST, L1, currentCareer(head, "가람구청장", "2026-07"), 201);
        addItemOk(INST, L1, periodItem(head, "CAREER", "가람시 기획관", "2018", null), 201);
        addItemOk(INST, L1, periodItem(head, "EDU", "가람고등학교 졸업", "2010", null), 201);
        addItemOk(INST, L1, "{\"head_id\":" + head + ",\"field_cd\":\"EDU\",\"value\":\"나래대학교 졸업\",\"source\":" + source() + "}", 201);
        MvcResult r = docx();   // 기본 = 요약본
        assertEquals(text(r), 200, r.getResponse().getStatus());
        String xml = documentXml(bytes(r));
        assertFalse(xml.contains("현재") || xml.contains("미상"));
        for (String v : new String[]{"가람구청장", "가람시 기획관", "가람고등학교 졸업", "나래대학교 졸업"}) {
            assertTrue(v, squareLine(xml, v + "</w:t>"));   // 내용 바로 뒤에서 run 이 끝난다 = 괄호·날짜 없음
        }
        assertFalse("학력·경력 날짜 없음", xml.contains("2010") || xml.contains("2018") || xml.contains("2026.07") || xml.contains("2026-07"));
    }
```
- 이 시험의 머리에는 임기·취임일·생년월일 칸을 넣지 않았다. 그래서 '2018'·'2010' 단언이 성립한다.
- 4번째 줄(연도 없는 학력)은 4bae43b3 뒤로 201이 돼야 정상이다.
