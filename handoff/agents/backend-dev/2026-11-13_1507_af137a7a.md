## ① 설계

**왜 g2b 확장인가.** 결과·계약은 공고번호로 이어지는 같은 서비스키·같은 호스트이고, 새 소스로 하면 `NoticeRef`·state·배치가 두 벌이 된다. 기관 레코드 하나에 "공고→결과→계약"이 붙어야 하므로 같은 원문 폴더의 `meta.json`에 얹는 쪽이 낫다. 재추출(`extract_and_pack(redo_all=True)`)만으로 후보가 다시 만들어지는 현재 구조도 그대로 쓴다.

**흐름** (`fetch_raw` 안, 근거 `g2b.py:189`)
1. `item = KEEP_FIELDS만` (기존). `opengDt` 날짜가 오늘보다 앞일 때만 진행한다. 개찰 전에는 결과가 없어 호출을 아낀다.
2. `ResultLookup.lookup(bidNtceNo, bidNtceOrd)`:
   - 낙찰목록 `getScsbidListSttusServc` 1회 → 일치 항목이 있으면 `award`.
   - 없으면 개찰결과 `getOpengResultListInfoServc` 1회 → `progrsDivCdNm`(유찰 등)만 `opening`에 남긴다.
   - `award`가 있으면 계약목록 `getCntrctInfoListServc` 1회 → `ntceNo` 일치 항목을 `contract`(허용 칸+업체명)로.
3. 실패(상한·형식·오류 07/08)는 `fetch_raw`를 멈추지 않고 `meta["g2b_result_error"]`에 문구(URL·키 없음)만 남긴다. 실패 요청은 `record_failure`(redact_url)로 기록한다.
4. `build.py`: `meta["g2b_result"].award`가 있고 종류가 계획/재공고이면 `kind="결과"`로 올리고 후보를 만든다. 취소·변경('기타')은 올리지 않는다. 낙찰자 없는 유찰은 `evidence_note`에만 한 줄 쓴다.

**호출 수 추정.** 공고당 평균 약 2회(낙찰 있음=2~3, 유찰=2, 개찰 전=0). 주간 14일 창의 새 공고가 수십 건이면 주 100회 이하다. 한 번 실행에 150회를 넘으면 `SourceError`를 받아 `g2b_result_error`로 남기고 다음 실행에 이어가지 않는다(알려진 한계, ⑤).

```python
"""나라장터 낙찰·개찰·계약 조회(NEXT 79) — 공고번호로 결과와 계약을 찾는다.

보안: 인증키(serviceKey)는 요청 URL에만 쓰고 원문·배치·로그·오류에 싣지 않는다(g2b.py와 같은 규칙).
개인정보: 허용 목록(KEEP)에 있는 칸만 남긴다 — 연락처·대표자·주소·사업자번호·자유 글(opengRsltNtcCntnts)·
개찰 업체 목록(opengCorpInfo)은 이름이 바뀌거나 늘어도 보관되지 않는다. 계약 업체 목록(corpList)은 업체명 칸 하나만 읽는다.
조회는 호스트를 g2b 설정 주소의 호스트로 고정한다(다른 호스트로 키가 나가지 않게).
"""

from __future__ import annotations

import json
import re
from urllib.parse import quote, urlsplit

from collector.httpclient import FetchError
from collector.sources.base import SourceError

SCSBID_OP = "as/ScsbidInfoService/getScsbidListSttusServc"
OPENG_OP = "as/ScsbidInfoService/getOpengResultListInfoServc"
CNTRCT_OP = "ao/CntrctInfoService/getCntrctInfoListServc"
# 단건(공고번호) 조회 파라미터 — 미확인(시험 호출로 확정, 보고서 ③). {no}=공고번호.
SCSBID_BY_NO = "inqryDiv=3&bidNtceNo={no}"
OPENG_BY_NO = "inqryDiv=3&bidNtceNo={no}"
CNTRCT_BY_NO = "inqryDiv=4&ntceNo={no}"

SCSBID_KEEP = ("bidNtceNo", "bidNtceOrd", "bidNtceNm", "dminsttNm", "dminsttCd", "bidwinnrNm", "fnlSucsfDate",
               "rlOpengDt", "prtcptCnum")
OPENG_KEEP = ("bidNtceNo", "bidNtceOrd", "opengDt", "progrsDivCdNm", "prtcptCnum")
CNTRCT_KEEP = ("ntceNo", "untyCntrctNo", "cntrctNm", "cntrctInsttNm", "cntrctCnclsDate", "cntrctDate", "cntrctPrd",
               "wbgnDate", "ttalScmpltDate", "thtmScmpltDate", "lngtrmCtnuDivNm")
NO_DATA_CODES = ("03",)      # 자료 없음


def corp_name(corp_list) -> str | None:
    """corpList('[1^주계약업체^단독^업체명^대표자^…]…')에서 업체명 칸만 읽는다 — 대표자 등 나머지는 버린다."""
    if not isinstance(corp_list, str):
        return None
    rows = [r.split("^") for r in re.findall(r"\[([^\]]*)\]", corp_list)]
    rows = [r for r in rows if len(r) > 3 and r[3].strip()]
    main = [r for r in rows if "주계약" in r[1]] or rows
    return main[0][3].strip()[:60] if main else None


class ResultLookup:
    def __init__(self, http, endpoint_base: str, key: str, report=None, max_calls: int = 150) -> None:
        p = urlsplit(endpoint_base)
        if p.scheme != "https" or not p.netloc:
            raise SourceError("나라장터 주소는 https여야 합니다")
        self.root = f"https://{p.netloc}/1230000"
        self.http, self.key, self.report, self.max_calls, self.calls = http, key, report, max_calls, 0

    def _call(self, op: str, query: str, purpose: str, key_field: str, want: str) -> list[dict]:
        if self.calls >= self.max_calls:
            raise SourceError(f"결과 조회 호출 상한({self.max_calls})에 닿았습니다 — 하루 1000회 한도 보호")
        self.calls += 1
        url = f"{self.root}/{op}?serviceKey={quote(self.key, safe='')}&numOfRows=100&pageNo=1&{query}&type=json"
        try:
            data, _ = self.http.get(url, verify=True)
        except FetchError as exc:
            if self.report is not None:
                self.report.record_failure(url, purpose, 1, exc, host="g2b")
            raise SourceError(f"나라장터 결과 조회 실패: {exc}") from None
        try:
            doc = json.loads(data.decode("utf-8"))
            if "response" not in doc:        # 오류 응답 {"nkoneps.com.response.ResponseError":{"header":…}}
                header = next(iter(doc.values()))["header"]
                code = header.get("resultCode")
                if code in NO_DATA_CODES:
                    return []
                raise SourceError(f"나라장터 오류 {code}: {str(header.get('resultMsg'))[:80]}")
            resp = doc["response"]
            if resp["header"].get("resultCode") != "00":
                raise SourceError(f"나라장터 오류 {resp['header'].get('resultCode')}: {str(resp['header'].get('resultMsg'))[:80]}")
            items = resp["body"].get("items") or []
            if isinstance(items, dict):
                items = items.get("item") or []
            items = items if isinstance(items, list) else [items]
        except SourceError:
            raise
        except (ValueError, KeyError, TypeError, AttributeError, StopIteration):
            raise SourceError("나라장터 응답 형식이 다릅니다(키 만료·서비스 변경 확인)") from None
        # 필터를 무시하는 응답이어도 남의 공고가 섞이지 않게 번호가 정확히 같은 항목만 받는다
        return [i for i in items if isinstance(i, dict) and str(i.get(key_field)) == want]

    @staticmethod
    def _keep(item: dict, keep: tuple) -> dict:
        return {k: item[k] for k in keep if k in item and item[k] not in (None, "")}

    def lookup(self, bid_no: str, bid_ord: str | None = None) -> dict:
        no = quote(str(bid_no), safe="")
        out: dict = {"award": None, "opening": None, "contract": None}

        def pick(rows):          # 차수가 같은 항목 우선, 없으면 가장 마지막 차수
            same = [r for r in rows if bid_ord is None or str(r.get("bidNtceOrd")) == str(bid_ord)]
            return (same or sorted(rows, key=lambda r: str(r.get("bidNtceOrd"))))[-1] if rows else None

        win = pick([r for r in self._call(SCSBID_OP, SCSBID_BY_NO.format(no=no), f"낙찰 {bid_no}", "bidNtceNo", str(bid_no))
                    if r.get("bidwinnrNm")])
        if win:
            out["award"] = self._keep(win, SCSBID_KEEP)
        else:
            op = pick(self._call(OPENG_OP, OPENG_BY_NO.format(no=no), f"개찰 {bid_no}", "bidNtceNo", str(bid_no)))
            if op:
                out["opening"] = self._keep(op, OPENG_KEEP)
        if out["award"]:
            rows = self._call(CNTRCT_OP, CNTRCT_BY_NO.format(no=no), f"계약 {bid_no}", "ntceNo", str(bid_no))
            if rows:
                c = self._keep(rows[-1], CNTRCT_KEEP)
                name = corp_name(rows[-1].get("corpList"))
                if name:
                    c["corp_name"] = name
                out["contract"] = c
        return out
```

```python
            notes.append(f"나라장터 개찰결과: {res['opening']['progrsDivCdNm']}")   # (notes는 아래에서 선언 — 선언 뒤로 옮길 것)
```
※ `notes`가 아래 줄(`notes: list[str] = []`)에서 선언되므로, 위 `elif`의 notes 호출은 `pending_note` 변수에 담았다가 `notes` 선언 직후 `notes.append`하도록 적용 시 옮긴다(메인 적용 때 순서만 맞추면 됨). 그리고
```python
# old
    candidate = build_candidate(kind, meta.get("posted_at"), texts) if is_candidate_kind(kind) else None
# new
    candidate = build_candidate(kind, meta.get("posted_at"), texts, g2b_result) if is_candidate_kind(kind) else None
```
`g2b_result_error`가 있으면 `notes`에 "결과 조회 실패: …"로 한 줄 더한다(`mask_contacts` 통과 — 마지막 줄이 이미 처리).

## ③ 메인이 돌릴 시험 호출 (4회, 읽기 전용)
공고번호는 `data/collector/_raw/g2b/g2b/*/meta.json` 중 개찰일이 지난 금고·주거래 공고 하나를 쓴다(결과가 있을 법한 것). 키는 `.env.local` 그대로, 출력에서 키는 가린다. 응답은 `resultCode`·`totalCount`·필드 이름과 bidNtceNo 일치 여부만 본다.
1. 낙찰: `…/as/ScsbidInfoService/getScsbidListSttusServc?serviceKey=…&numOfRows=10&pageNo=1&inqryDiv=3&bidNtceNo=<번호>&type=json` — 07/08이면 `inqryDiv=4`로 같은 호출을 한 번 더 한다(기간 칸을 요구하면 `inqryBgnDt/EndDt`를 개찰일 하루로 붙인다).
2. 개찰결과: 1번에서 맞은 `inqryDiv`로 `…/getOpengResultListInfoServc`(낙찰이 없던 공고로 하면 유찰 표기도 본다).
3. 계약: `…/ao/CntrctInfoService/getCntrctInfoListServc?…&inqryDiv=<?>&ntceNo=<번호>` — 문서에 따라 `inqryDiv=4`(공고번호?)를 먼저. 안 맞으면 응답 07/08 문구로 필수 칸을 읽는다.
4. 3번이 단건을 못 받으면: 같은 계약 호출을 `inqryDiv=1`(체결일)로 낙찰일 +1~30일 중 **하루** 범위로 하고 `ntceNo`로 직접 찾아보되, 건수(`totalCount`)가 100을 넘는지 본다(넘으면 계약 조회는 단건 방식 외에는 비용상 불가).
결과에 맞춰 `g2b_results.py` 상단 상수 3개만 고친다.

## ④ security가 볼 점
- 키: 요청 URL(`_call`)에만 존재, 오류 문구는 `exc`에 URL이 없는 `FetchError`뿐, 실패 기록은 `record_failure`의 `redact_url`. `str(exc)[:120]`로 `meta`에 들어가는 문구에 URL이 섞일 경로가 없는지(기존 `FetchError` 문구가 URL을 싣지 않는다는 전제).
- 호스트: 결과 조회는 `G2B_ENDPOINT_URL`의 호스트로만 나간다(경로는 상수). `.env.local`이 바뀌어도 https만.
- 허용 목록 vs 개인정보: `bidwinnrTelNo·CeoNm·Adrs·Bizno`, `fnlSucsfCorpOfcl`, `cntrctInstt*Ofcl*`, `opengCorpInfo`, `opengRsltNtcCntnts`는 KEEP에 없다. `corp_name`은 4번째 칸 하나만 읽는다 — 칸 순서가 바뀌어 대표자 이름이 들어올 위험(응답 형식 변화)이 있으니 시험 호출 때 실제 순서를 확인할 것.
- 번호 일치 필터: API가 필터를 무시해도 다른 기관 낙찰이 이 기관 레코드에 붙지 않는다(테스트 `OTHER`). 계약은 업체명까지 낙찰자와 맞아야 쓴다.
- 데이터 신뢰: 자동 값은 `status="후보"`, 근거 문장 포함. `bank_status` 문구는 결정사항("우선협상, 계약 미확인")과 같다.
- 호출 상한: 결과 조회 150 + 목록 200 = 실행당 350, 한도 1000.
- 접근 이력·자기신고 인증은 이 변경과 무관(서버 코드 아님).

## ⑤ 위험·되돌림·한계
- 되돌림: 새 파일과 diff 3곳을 되돌리면 된다. `meta`의 `g2b_result*` 칸은 이전 `build.py`가 무시한다. 배치 스키마 변경 없음(`kind="결과"`는 `NOTICE_KINDS` 허용값, `bank` 등 추가 칸은 basis만 있으면 통과 — `batch_schema.py:141-144`).
- **옛 공고 갱신 불가**: `pipeline.collect`는 seen 키를 건너뛴다. 27곳 보강은 (a) `--since`를 낮추고 state의 해당 키를 지우는 일회성 작업이거나, (b) state의 `with_raw("g2b")` 중 `g2b_result`가 없거나 `opening`뿐인 항목을 돌며 `meta.json`을 덧쓰는 `python -m collector g2b-results` 서브명령(cli·state 구조를 못 읽어 이번 diff에서 제외). 시험 호출 결과를 본 뒤 (b)를 설계하는 것을 권한다.
- 개찰 전 공고는 호출하지 않으므로 낙찰이 늦게 올라오면 다음 주간 실행에서도 못 잡는다 — (b)의 이유이기도 하다.
- 낙찰자가 곧 우선협상대상자인지는 은행 선정 공고마다 다를 수 있다. 그래서 문구를 "낙찰(우선협상) 확인"으로 두고 계약이 없으면 '계약 미확인'으로 낮춘다.
