**B2 (결과 기억 무게)**
- `support/ScoringCache.java`의 `len(s)`를 `24L + (s == null ? 0 : s.length())`로 바꿨다. 클래스 주석과 `weigh` 주석도 "글자 수 + 문자열마다 24"로 고쳤다.
- `service/PrepAttachService.java` 상수 주석을 "무게 800만(글자 수 + 문자열마다 24, Java 8 기준 약 16MB + 객체 부담) · 한 건 무게 100만 초과 시 기억 안 함"으로 고쳤다.
- `support/ScoringCacheTest.java` 기대값을 가중치 24에 맞춰 다시 계산했다.
  - 무게 계산은 `res(3,9)`가 3×(24+9)=99이다.
  - 예산 시험은 한 건 무게 90을 만들려고 `res(1,66)`을 쓴다. 9건이면 810이 되어 800을 넘고, `b`가 밀려난다.
  - 한 건 상한 경계는 `res(1,76)`이 무게 100이라 기억하고, `res(1,77)`이 101이라 기억하지 않는 것으로 단언한다. 그 뒤 `edge`를 null로 덮어써 총 무게를 0으로 만들고 `get("big")==null`·`totalChars()==0`을 확인한다.
  - 같은 키 재삽입은 73이던 것이 33이 된다.
