2. `kgi-ggreport-web/tools/db/apply-mysql.test.mjs`
   - 기존 `SCHEMA_PROBES` 시험(164~172줄) 바로 뒤에 시험 2건을 추가했다.
   - 첫째는 047 이후 SQL 파일마다 검사가 있는지, 파일의 CREATE TABLE 표 이름이 검사에 모두 들어 있는지 본다.
   - 둘째는 `planMark`가 047, 052, 060을 대상으로 잡는지 본다.
   - import는 `readdirSync`, `readFileSync`, `path`, `fileURLToPath`, `planMark`가 이미 있어 추가하지 않았다.
