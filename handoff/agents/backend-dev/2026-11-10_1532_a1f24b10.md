- 한글이 든 파일은 PowerShell로 재작성하지 말고 Edit/Write로 적용한다.

## 2. 상태 전이표
### 2-1. 두 축
- 흐름(`STATUS_CD`, COMMON_CODE `BOARD_STATUS`): `PREP` 준비 중 → `DRAFT` 작성 중 → `SUBMITTED` 제출(결재 중) → `CONFIRMED` 확정.
- 결과(`RESULT_CD`, COMMON_CODE `BOARD_RESULT`): 비어 있음 / `SCHEDULED` 의결 예정 / `PASSED` 가결 / `REJECTED` 부결. 확정 뒤에만 값이 생긴다.
- `PREP→DRAFT`는 첫 '버전 저장' 때 자동이다(별도 버튼 없음, 이력 STATUS_AUTO 대신 로그에 남기지 않고 버전 이력이 곧 기록).

### 2-2. 누가·어느 상태에서·무엇을
| 행위 | 누가 | 허용 상태 | 결과 | 거부 |
|---|---|---|---|---|
| 자료 만들기 | 그 입찰 건 활성 담당자 | - | PREP | 비담당 403 |
| 값 저장(버전) | 활성 담당자 전원 | PREP·DRAFT | 새 버전, PREP이면 DRAFT로 | SUBMITTED·CONFIRMED 409 `MATERIAL_LOCKED` |

| 회수 | 활성 담당자 **누구나**(상신자가 아니어도) | SUBMITTED이고 결재 요청이 PENDING | DRAFT, 요청 CANCELLED | 그 외 409 |
| 승인 | 결재선의 영업팀장(팀장이 관련되면 영업부장) — `/approval-requests/{id}/decide`(기존) | SUBMITTED | CONFIRMED, `CONFIRMED_SNAP`=제출한 버전 | 결재자가 담당자면 403, 팀장 관련 건을 팀장이 승인하려 하면 409 `APPROVER_ROLE_MISMATCH` |
| 반려 | 결재자 — 기존 `decide`(REJECT, 의견 필수) | SUBMITTED | DRAFT | - |
| 재작성 요구 | **영업부장만**(관리자·영업팀장 불가) | SUBMITTED, CONFIRMED(결과가 있어도) | DRAFT. SUBMITTED였으면 결재 요청 REJECTED, 결과·개최일·확정 정보 해제. 사유 필수(1~200자) | PREP·DRAFT 409 `NOT_APPLICABLE`(되돌릴 것이 없음) |

| 열람(상세·버전·이력) | 활성 담당자 | 모든 상태 | - | 그 외 404 |

### 2-3. 영업부장 열람 범위 — 해석을 정했다(질문 Q1 참고)
"비담당은 열람 불가, 단 결재자는 결재 중인 자료를 결재 경로로 열람"을 이렇게 읽었다. 영업부장은 결재선 상위이자 '어느 상태든 반려·재작성 요구' 권한자이므로 **제출 이후(SUBMITTED·CONFIRMED) 자료만** 검토 열람한다. 준비 중·작성 중 자료는 부장도 못 본다.

### 2-4. 결재자 결정(019와 같은 규칙 재사용)
상신자의 결재 체인에서 처음 만나는 활성 영업팀장, 없으면 활성 영업팀장이 정확히 1명일 때만 그 사람(아니면 400 `APPROVER_NOT_RESOLVED`). 다음 중 하나라도 해당하면 **영업부장**: 상신자가 영업팀장 / 현 활성 담당자 중 영업팀장이 있음. 대결 불가(`NO_PROXY`). 승인 때 다시 확인한다(결재자가 담당자면 403, 팀장 관련인데 결재자가 부장이 아니면 409).

                    WHERE a.BID_CASE_ID = m.BID_CASE_ID AND a.ACTIVE_YN = 1 AND u.STATUS = 'ACTIVE'
                      AND TRIM(u.ROLE) IN ('영업팀', '영업팀장'));

    OR (m.RESULT_CD IS NOT NULL
        AND NOT EXISTS (SELECT 1 FROM COMMON_CODE c WHERE c.CODE_GROUP = 'BOARD_RESULT' AND c.CODE = m.RESULT_CD));

SELECT m.MATERIAL_ID FROM BOARD_MATERIAL m
 WHERE m.STATUS_CD = 'SUBMITTED'

SELECT s.MATERIAL_ID, s.SNAP_NO FROM BOARD_MATERIAL_SNAP s
 WHERE NOT EXISTS (SELECT 1 FROM BOARD_MATERIAL m WHERE m.MATERIAL_ID = s.MATERIAL_ID);
SELECT m.MATERIAL_ID FROM BOARD_MATERIAL m

SELECT MATERIAL_ID, COUNT(*) AS N, MAX(SNAP_NO) AS MX FROM BOARD_MATERIAL_SNAP
 GROUP BY MATERIAL_ID HAVING COUNT(*) <> MAX(SNAP_NO);
SELECT l.LOG_ID FROM BOARD_MATERIAL_LOG l

SELECT a.ACT_ID FROM BOARD_MATERIAL_ACT a

package com.kbstar.kgi.ggreport.web.service;

import com.kbstar.kgi.ggreport.web.domain.SysUser;
import com.kbstar.kgi.ggreport.web.mapper.SysUserMapper;
import com.kbstar.kgi.ggreport.web.support.MenuPerms;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

/**
 * 이사회 자료 접근 판정(020). 쓰기·열람 = 그 입찰 건의 현재 담당자(배정 ACTIVE_YN=1) ∧ USERS ACTIVE ∧ 영업 계열(영업팀·영업팀장).
 * 관리자·마스터·영업팀장(비담당)·영업부장 예외 없음 — 메뉴 권한(CAN_WRITE)은 보지 않는다.
 * 결재자(팀장·부장)의 열람은 이 클래스가 아니라 BoardMaterialService.review 경로(결재 경로 열람)다.
 *
 * <p>⚠️ 호출자 사번은 X-Emp-No 자기신고일 수 있다(Actor). 이 판정은 업무 규칙(실수 방지)이지 사칭 방지가 아니다.
 * 담당이 해제되면 다음 요청부터 바로 false 다.
 */
@Component
public class BoardAccess {

    private final SysUserMapper users;
    private final BidAssignmentService assignments;

    public BoardAccess(SysUserMapper users, BidAssignmentService assignments) {
        this.users = users;
        this.assignments = assignments;
    }

    @Transactional(readOnly = true)
    public boolean canWriteCase(String empNo, String bidCaseId) {
        SysUser u = activeUser(empNo);
        return u != null && isSalesLine(u) && assignments.isActiveAssignee(bidCaseId, empNo);
    }

    /** 열람 = 쓰기 가능(담당자). 결재 경로 열람은 별도. */
    @Transactional(readOnly = true)
    public boolean canViewCase(String empNo, String bidCaseId) {
        return canWriteCase(empNo, bidCaseId);
    }

    /** 목록을 조회할 수 있는 사람(활성 영업 계열). 아니면 SQL 을 부르지 않고 빈 목록을 돌려준다(security P6). */
    @Transactional(readOnly = true)
    public boolean isSalesWriter(String empNo) {
        SysUser u = activeUser(empNo);
        return u != null && isSalesLine(u);
    }

    /** 화면 '이 양식으로 작성' 버튼 표시용 — 쓸 수 있는 입찰 건이 하나라도 있는가. */
    @Transactional(readOnly = true)
    public boolean hasAnyWriteCase(String empNo) {
        return isSalesWriter(empNo) && !assignments.mine(empNo).isEmpty();
    }

    SysUser activeUser(String empNo) {
        if (!MenuPerms.isEmpNo(empNo)) {
            return null;
        }
        SysUser u = users.selectByEmpNo(empNo);
        return u != null && "ACTIVE".equals(u.getStatus()) ? u : null;
    }

    static String role(SysUser u) {
        return u.getRole() == null ? "" : u.getRole().trim();
    }

    static boolean isSalesLine(SysUser u) {
        return BidAssignmentService.MEMBER_ROLE.equals(role(u)) || BidAssignmentService.LEAD_ROLE.equals(role(u));
    }

    static boolean isHead(SysUser u) {
        return BidAssignmentService.HEAD_ROLE.equals(role(u));
    }
}

    public static final String H_SCREEN = "X-Screen-Id";
    public static final String H_BUTTON = "X-Button-Id";

            "snapshot_open", "history_open", "review_open", "acts_open")));

    }

        private final String button;
        private final boolean valid;

            this.screen = screen;
            this.button = button;
            this.valid = valid;

        public String getButton() { return button; }

    public Map<String, Object> list(SysUser me, String q, String status, String year, String assignee,
                                    String meetingFrom, String meetingTo) {
        String st = blankToNull(status);
        if (st != null && !STATUSES.contains(st)) {
            throw new ApiException(400, "상태 값이 올바르지 않습니다.");
        }
        Integer y = parseYear(year, false);
        String from = optDate(meetingFrom);
        String to = optDate(meetingTo);
        String like1 = like(q);
        String like2 = like(assignee);
        Map<String, Object> out = new LinkedHashMap<>();
        if (!access.isSalesWriter(me.getEmpNo())) {
            out.put("items", new ArrayList<Map<String, Object>>());
            out.put("truncated", false);
            return out;
        }
        List<BoardMaterial> rows = mapper.selectList(me.getEmpNo(), like1, st, y, from, to, like2,
                new RowBounds(0, LIST_CAP + 1));
        boolean truncated = rows.size() > LIST_CAP;
        if (truncated) {
            rows = new ArrayList<>(rows.subList(0, LIST_CAP));
        }
        Map<String, List<Map<String, Object>>> byCase = assigneesByCase(rows);
        List<Map<String, Object>> items = new ArrayList<>();
        for (BoardMaterial m : rows) {
            Map<String, Object> it = header(m);
            List<Map<String, Object>> as = byCase.get(m.getBidCaseId());
            it.put("assignees", as == null ? new ArrayList<Map<String, Object>>() : as);
            it.put("can_write", Boolean.TRUE);   // 목록 SQL 이 내 담당 건만 고른다
            items.add(it);
        }
        out.put("items", items);
        out.put("truncated", truncated);
        return out;
    }

    /** 자료 만들기 — 그 입찰 건의 현재 담당자만(403, 입찰 건 존재 여부는 알리지 않는다). 첫 문장이 배정 머리 잠금(security P3). */
    @Transactional
    public Map<String, Object> create(SysUser me, Actor actor, BoardMaterialIn.Create in) {
        if (in == null) {
            throw new ApiException(400, "요청 내용이 없습니다.");
        }
        String bid = in.getBidCaseId() == null ? "" : in.getBidCaseId().trim();
        if (bid.isEmpty() || bid.length() > 64) {
            throw new ApiException(400, "입찰 건을 지정하세요.");
        }
        mapper.lockAssignCase(bid);
        if (!access.canWriteCase(me.getEmpNo(), bid)) {
            throw new ApiException(403, WRITE_DENIED);
        }
        Integer year = parseYear(in.getYear() == null ? null : String.valueOf(in.getYear()), true);
        String inst = mapper.selectCaseInstitution(bid);
        if (inst == null) {
            throw ApiException.notFound(NOT_FOUND);
        }
        String formId = blankToNull(in.getFormId()) == null ? BoardDocSpec.DEFAULT_ID : in.getFormId().trim();
        BoardFormService.WriteTarget target = forms.formForWrite(me.getEmpNo(), formId,
                in.getFormVersion() == null ? null : String.valueOf(in.getFormVersion()));
        String now = Times.nowIso();
        BoardMaterial m = new BoardMaterial();
        m.setBidCaseId(bid);
        m.setInstitutionId(inst);
        m.setBoardYear(year);
        m.setStatusCd(PREP);
        m.setFormId(String.valueOf(target.getId()));
        m.setFormVer(target.getVersion() == null ? 0 : target.getVersion());
        m.setCreatedBy(me.getEmpNo());
        m.setCreatedAt(now);
        m.setUpdatedBy(me.getEmpNo());
        m.setUpdatedAt(now);
        mapper.insertMaterial(m);
        mapper.insertLog(m.getMaterialId(), "CREATE", null, PREP, null, null, null, null, null, null, null,
                me.getEmpNo(), verified(actor), now);
        return detail(me, String.valueOf(m.getMaterialId()));
    }

    /**
     * 버전 저장 — 담당자만. 순서: 보임(404) → 쓰기 자격(403) → 잠김(409 MATERIAL_LOCKED) → 입력(400) → 개인정보(422) → 크기(400) → 충돌(409).
     * base_snap_no 가 현재와 다르면 409 CONFLICT, 같은 값이면 새 버전 없이 changed=false. PREP 이면 첫 저장 때 DRAFT 로 간다.
     */
    @Transactional
    public Map<String, Object> saveSnapshot(SysUser me, Actor actor, String id, BoardMaterialIn.Save in) {
        BoardMaterial m = loadVisible(me, id);
        requireWriter(me, m);
        if (!PREP.equals(m.getStatusCd()) && !DRAFT.equals(m.getStatusCd())) {
            throw coded(409, "MATERIAL_LOCKED", "제출했거나 확정된 자료는 값을 고칠 수 없습니다.");
        }
        if (in == null || in.getBaseSnapNo() == null || in.getBaseSnapNo() < 0) {
            throw coded(400, "BAD_REQUEST", "기준 버전(base_snap_no)이 필요합니다.");
        }
        String note = checkedText(in.getNote(), MAX_NOTE, "메모", false);
        String json = toJson(checkedValues(me.getEmpNo(), m, in.getTables()));
        if (json.getBytes(StandardCharsets.UTF_8).length > MAX_JSON_BYTES) {
            throw coded(400, "BAD_VALUE", "저장할 내용이 너무 큽니다.");
        }
        if (in.getBaseSnapNo() != m.getCurSnap()) {
            throw coded(409, "CONFLICT", "다른 사람이 먼저 저장했습니다. 새로 고친 뒤 다시 저장해 주세요.");
        }
        if (m.getCurSnap() > 0) {
            BoardMaterialSnap cur = mapper.selectSnap(m.getMaterialId(), m.getCurSnap());
            if (cur != null && json.equals(cur.getValuesJson())) {
                Map<String, Object> same = new LinkedHashMap<>();
                same.put("material_id", m.getMaterialId());
                same.put("snap_no", m.getCurSnap());
                same.put("changed", false);
                return same;
            }
        }
        if (m.getCurSnap() >= MAX_SNAPS) {
            throw coded(400, "TOO_MANY_VERSIONS", "저장 이력이 너무 많아 더 저장할 수 없습니다.");
        }
        int next = m.getCurSnap() + 1;
        String now = Times.nowIso();
        if (mapper.updateCurSnap(m.getMaterialId(), m.getCurSnap(), next, me.getEmpNo(), now) != 1) {
            throw coded(409, "CONFLICT", "다른 사람이 먼저 저장했거나 자료가 제출되었습니다. 새로 고친 뒤 다시 확인해 주세요.");
        }
        if (PREP.equals(m.getStatusCd())) {
            mapper.updateStartDraft(m.getMaterialId(), me.getEmpNo(), now);
        }
        BoardMaterialSnap s = new BoardMaterialSnap();
        s.setMaterialId(m.getMaterialId());
        s.setSnapNo(next);
        s.setValuesJson(json);
        s.setNote(note);
        s.setSavedBy(me.getEmpNo());
        s.setSavedAt(now);
        mapper.insertSnap(s);
        Map<String, Object> out = new LinkedHashMap<>();
        out.put("material_id", m.getMaterialId());
        out.put("snap_no", next);
        out.put("changed", true);
        out.put("saved_at", now);
        return out;
    }

    /** 결과 변경(의결 예정·가결·부결·개최일) — 확정된 자료에서 담당자만. 값(버전)은 건드리지 않는다. */
    @Transactional
    public Map<String, Object> changeResult(SysUser me, Actor actor, String id, BoardMaterialIn.Result in) {
        BoardMaterial m = loadVisible(me, id);
        requireWriter(me, m);
        if (!CONFIRMED.equals(m.getStatusCd())) {
            throw coded(409, "NOT_CONFIRMED", "확정된 자료만 의결 결과를 입력할 수 있습니다.");
        }
        if (in == null || blankToNull(in.getResult()) == null || !RESULTS.contains(in.getResult().trim())) {
            throw coded(400, "BAD_REQUEST", "의결 결과(result)가 올바르지 않습니다.");
        }
        String to = in.getResult().trim();
        String meeting = optDate(in.getMeetingDate());
        if (SCHEDULED.equals(to) && meeting == null) {
            throw coded(400, "MEETING_DATE_REQUIRED", "의결 예정이면 개최일을 입력하세요.");
        }
        String now = Times.nowIso();
        if (mapper.updateResult(m.getMaterialId(), m.getResultCd(), to, meeting, me.getEmpNo(), now) != 1) {
            throw coded(409, "CONFLICT", "다른 사람이 먼저 바꿨습니다. 새로 고친 뒤 다시 시도해 주세요.");
        }
        mapper.insertLog(m.getMaterialId(), "RESULT", null, null, m.getResultCd(), to, meeting, null, null, null, null,
                me.getEmpNo(), verified(actor), now);
        return detail(me, id);
    }

    /** 제출 계획 — 검증과 결재자 계산(쓰기 없음). */
    public static final class SubmitPlan {
        private final BoardMaterial material;
        private final SysUser approver;

        SubmitPlan(BoardMaterial material, SysUser approver) {
            this.material = material;
            this.approver = approver;
        }

        public BoardMaterial getMaterial() { return material; }
        public SysUser getApprover() { return approver; }

    /** 제출 검증: 보임(404) → 담당자(403) → 상태·버전(409) → 결재자(400 APPROVER_NOT_RESOLVED). */
    @Transactional(readOnly = true)
    public SubmitPlan planSubmit(String id, SysUser me) {
        BoardMaterial m = loadVisible(me, id);
        requireWriter(me, m);
        if (SUBMITTED.equals(m.getStatusCd())) {
            throw coded(409, "ALREADY_SUBMITTED", "이미 제출해 결재 중인 자료입니다.");
        }
        if (CONFIRMED.equals(m.getStatusCd())) {
            throw coded(409, "MATERIAL_LOCKED", "이미 확정된 자료입니다.");
        }
        if (!DRAFT.equals(m.getStatusCd()) || m.getCurSnap() < 1) {
            throw coded(409, "NO_SNAPSHOT", "저장한 버전이 있어야 제출할 수 있습니다. 먼저 '버전 저장'을 하세요.");
        }
        boolean leadInvolved = BidAssignmentService.LEAD_ROLE.equals(BoardAccess.role(me))
                || assignments.anyActiveLead(m.getBidCaseId());
        return new SubmitPlan(m, assignments.resolveApprover(me, leadInvolved));
    }

    /** 결재 요청 행을 만든 뒤 호출 — 자료를 SUBMITTED 로 선점한다. 0행이면 409(호출 트랜잭션이 요청 행째 롤백). */
    @Transactional
    public void claimSubmit(SubmitPlan plan, Long reqId, SysUser me, Actor actor) {
        BoardMaterial m = plan.getMaterial();
        String now = Times.nowIso();
        if (mapper.claimSubmit(m.getMaterialId(), m.getCurSnap(), reqId, me.getEmpNo(), now) != 1) {
            throw coded(409, "CONFLICT", "자료가 그 사이 바뀌어 제출하지 못했습니다. 새로 고친 뒤 다시 시도해 주세요.");
        }
        mapper.insertLog(m.getMaterialId(), "SUBMIT", DRAFT, SUBMITTED, null, null, null, null, null, reqId, null,
                me.getEmpNo(), verified(actor), now);
    }

    /** 회수 검증: 담당자(누구나) ∧ SUBMITTED. 돌려주는 값은 취소할 결재 요청 번호. */
    @Transactional(readOnly = true)
    public Long planWithdraw(String id, SysUser me) {
        BoardMaterial m = loadVisible(me, id);
        requireWriter(me, m);
        if (!SUBMITTED.equals(m.getStatusCd()) || m.getSubmitReqId() == null) {
            throw coded(409, "NOT_SUBMITTED", "결재 중인 자료만 회수할 수 있습니다.");
        }
        return m.getSubmitReqId();
    }

    /** 회수·취소·반려 공통 후처리: SUBMITTED + 그 요청 → DRAFT. 0행이면 409(호출 트랜잭션 롤백). */
    @Transactional
    public void afterSubmitEnded(Long reqId, String materialId, String event, String actorEmp, int verified) {
        Long mid = parseId(materialId);
        String now = Times.nowIso();
        if (mid == null || mapper.backToDraftByReq(mid, reqId, actorEmp, now) != 1) {
            throw coded(409, "CONFLICT", "이미 처리된 요청입니다.");
        }
        mapper.insertLog(mid, event, SUBMITTED, DRAFT, null, null, null, null, null, reqId, null, actorEmp, verified, now);
    }

    /** 승인 후처리(같은 트랜잭션 — 예외를 던지면 승인까지 되돌아간다). */
    @Transactional
    public String applyConfirm(ApprovalRequest r, SysUser decider, Actor actor) {

        if (m == null) {
            throw coded(409, "CONFLICT", "이미 처리된 요청입니다.");
        }
        String d = decider.getEmpNo();
        String dRole = BoardAccess.role(decider);
        if ((!BidAssignmentService.LEAD_ROLE.equals(dRole) && !BidAssignmentService.HEAD_ROLE.equals(dRole))
                || assignments.isActiveAssignee(m.getBidCaseId(), d)) {
            throw new ApiException(403, "이 이사회 자료 제출을 승인할 수 없습니다.");   // 승인자=담당자 방어
        }
        SysUser requester = ApprovalLookup.requester(requests, r);
        boolean leadInvolved = requester == null || BidAssignmentService.LEAD_ROLE.equals(BoardAccess.role(requester))
                || assignments.anyActiveLead(m.getBidCaseId());
        if (leadInvolved && !BidAssignmentService.HEAD_ROLE.equals(dRole)) {
            throw coded(409, "APPROVER_ROLE_MISMATCH",
                    "영업팀장이 관련된 제출은 영업부장만 승인할 수 있습니다. 반려하거나 취소하고 다시 제출하세요.");
        }
        String now = Times.nowIso();
        if (mapper.confirm(m.getMaterialId(), r.getReqId(), d, now) != 1) {
            throw coded(409, "CONFLICT", "이미 처리된 요청입니다.");
        }
        mapper.insertLog(m.getMaterialId(), "CONFIRM", SUBMITTED, CONFIRMED, null, null, null, null, null, r.getReqId(),
                null, d, verified(actor), now);
        return "이사회 자료 확정";
    }

    /** 저장 JSON → [{ref, cells:{칸키:값}}]. 읽을 수 없으면 서버 결함(500). */
    private static List<Map<String, Object>> tablesOf(String json) {
        List<Map<String, Object>> out = new ArrayList<>();
        try {
            java.util.Iterator<Map.Entry<String, JsonNode>> it = JSON.readTree(json).path("tables").fields();
            while (it.hasNext()) {
                Map.Entry<String, JsonNode> e = it.next();
                Map<String, Object> cells = new LinkedHashMap<>();
                java.util.Iterator<Map.Entry<String, JsonNode>> ci = e.getValue().fields();
                while (ci.hasNext()) {
                    Map.Entry<String, JsonNode> c = ci.next();
                    cells.put(c.getKey(), c.getValue().asText());
                }
                Map<String, Object> table = new LinkedHashMap<>();
                table.put("ref", e.getKey());
                table.put("cells", cells);
                out.add(table);
            }
        } catch (IOException e) {
            throw new IllegalStateException("stored board material is not valid");
        }
        return out;
    }

    /**
     * 저장할 값 검증·정규화: 표 수·칸 수 한도 → 칸 길이(개인정보 정규식은 길이에 비례해 느리므로 먼저) → 개인정보(422, NFKC 정규화 뒤 검사 —
     * 전각 숫자로 피하지 못하게) → 숫자 칸 검증(연결 칸: {@link #canonNumber}) → 양식 구조 대조(BoardDocSpec.withValues: 값 칸이 아닌 키·
     * 모르는 표는 거부, 제어문자·trim·100자) → 값이 있는 칸만 추출. 칸 값은 다른 담당자·결재자 화면에 그려지므로 화면은 esc 만 써야 한다.
     */
    private Map<String, Map<String, String>> checkedValues(String empNo, BoardMaterial m, List<BoardWriteIn.TableIn> tables) {
        if (tables == null || tables.size() > MAX_TABLES) {
            throw coded(400, "BAD_REQUEST", "표 목록(tables)이 올바르지 않습니다.");
        }
        Map<String, Map<String, String>> raw = new LinkedHashMap<>();
        Map<String, Integer> kinds = new LinkedHashMap<>();
        for (BoardWriteIn.TableIn t : tables) {
            if (t == null || t.getRef() == null || raw.containsKey(t.getRef())
                    || (t.getCells() != null && t.getCells().size() > MAX_CELLS)) {
                throw coded(400, "BAD_REQUEST", "표 목록(tables)이 올바르지 않습니다.");
            }
            Map<String, String> cells = t.getCells() == null ? new LinkedHashMap<String, String>() : t.getCells();
            for (String v : cells.values()) {
                if (v != null && v.length() > BoardDocSpec.MAX_CELL) {
                    throw coded(400, "BAD_VALUE", "칸 값은 " + BoardDocSpec.MAX_CELL + "자 이하로 입력해 주세요.");
                }
                for (Pii.Finding f : Pii.scan(v == null ? null : Normalizer.normalize(v, Normalizer.Form.NFKC))) {
                    Integer n = kinds.get(f.getKind());
                    kinds.put(f.getKind(), n == null ? 1 : n + 1);
                }
            }
            raw.put(t.getRef(), new LinkedHashMap<>(cells));
        }
        if (!kinds.isEmpty()) {
            Map<String, Object> d = new LinkedHashMap<>();
            d.put("code", "PII_DETECTED");
            d.put("message", "개인정보로 보이는 값이 있어 저장하지 않았습니다. 해당 칸을 지우고 다시 저장해 주세요.");
            List<Map<String, Object>> ks = new ArrayList<>();
            for (Map.Entry<String, Integer> e : kinds.entrySet()) {
                Map<String, Object> k = new LinkedHashMap<>();
                k.put("kind", e.getKey());
                k.put("count", e.getValue());
                ks.add(k);
            }
            d.put("kinds", ks);   // 종류·건수만 — 검출된 값은 싣지 않는다
            throw ApiException.withDetail(422, d);
        }
        BoardDocSpec.Doc base = forms.docForStored(empNo, m.getFormId(), m.getFormVer());
        for (BoardDocSpec.Table t : base.getTables()) {    // 연결(숫자) 칸은 숫자 검증·정규화
            Map<String, String> cells = raw.get(t.getId());
            if (cells == null) {
                continue;
            }
            for (List<BoardDocSpec.Cell> row : t.getRows()) {
                for (BoardDocSpec.Cell c : row) {
                    String v = c.isMapped() ? cells.get(c.getKey()) : null;
                    if (v != null && !v.trim().isEmpty()) {
                        cells.put(c.getKey(), canonNumber(v));
                    }
                }
            }
        }
        BoardDocSpec.Doc filled;
        try {
            filled = BoardDocSpec.withValues(base, raw);
        } catch (BoardDocSpec.EditException e) {
            throw coded(400, "BAD_VALUE", e.getMessage());
        }
        Map<String, Map<String, String>> out = new LinkedHashMap<>();
        for (BoardDocSpec.Table t : filled.getTables()) {
            for (List<BoardDocSpec.Cell> row : t.getRows()) {
                for (BoardDocSpec.Cell c : row) {
                    if ((c.isMapped() || c.isInput()) && c.getText() != null && !c.getText().isEmpty()) {
                        Map<String, String> cells = out.get(t.getId());
                        if (cells == null) {
                            cells = new LinkedHashMap<>();
                            out.put(t.getId(), cells);
                        }
                        cells.put(c.getKey(), c.getText());
                    }
                }
            }
        }
        return out;
    }

    /** 숫자 칸 정규화: 앞뒤 공백 제거 → 천 단위 쉼표 허용(올바른 묶음만) → 정수부 13자리·소수 2자리 → 쉼표 없는 표준형. 아니면 400(입력값 비노출). */
    static String canonNumber(String raw) {
        String v = raw.trim();
        if (!NUM.matcher(v).matches()) {
            throw coded(400, "BAD_VALUE", "숫자 칸에는 숫자(정수부 " + NUM_INT_DIGITS + "자리, 소수 " + NUM_FRAC_DIGITS
                    + "자리 이내)만 입력할 수 있습니다.");
        }
        BigDecimal d = new BigDecimal(v.replace(",", ""));
        if (d.signum() == 0) {
            return "0";
        }
        return d.stripTrailingZeros().toPlainString();
    }

    /** 메모·사유: trim, 제어·서식·방향 문자 거부(security P5), 길이, 개인정보(NFKC 뒤 검사, 422·값 비노출). 비면 null(required 면 400). */
    static String checkedText(String raw, int max, String label, boolean required) {
        String t = raw == null ? "" : raw.trim();
        if (t.isEmpty()) {
            if (required) {
                throw coded(400, "BAD_VALUE", label + "를 입력하세요.");
            }
            return null;
        }
        for (int i = 0; i < t.length(); ) {
            int cp = t.codePointAt(i);
            i += Character.charCount(cp);
            int ty = Character.getType(cp);
            if (cp != '\n' && (ty == Character.CONTROL || ty == Character.FORMAT || ty == Character.SURROGATE
                    || ty == Character.LINE_SEPARATOR || ty == Character.PARAGRAPH_SEPARATOR
                    || (cp >= 0x2066 && cp <= 0x2069) || cp == 0x061C)) {
                throw coded(400, "BAD_VALUE", label + "에 쓸 수 없는 문자가 있습니다.");
            }
        }
        if (t.length() > max) {
            throw coded(400, "BAD_VALUE", label + "는 " + max + "자 이하로 입력해 주세요.");
        }
        if (!Pii.scan(Normalizer.normalize(t, Normalizer.Form.NFKC)).isEmpty()) {
            throw coded(422, "PII_DETECTED", label + "에 개인정보로 보이는 값이 있어 저장하지 않았습니다.");
        }
        return t;
    }

    /** LIKE 검색어 — 앞뒤 공백 제거, 80자 상한(초과 400), ! % _ 를 '!' 로 이스케이프. 비면 null. */
    private static String like(String s) {

    private static Integer parseYear(String s, boolean required) {
        if (blankToNull(s) == null) {
            if (required) {
                throw new ApiException(400, "연도를 입력하세요.");
            }
            return null;
        }
        Long n = parseId(s.trim());
        if (n == null || n < YEAR_MIN || n > YEAR_MAX) {
            throw new ApiException(400, "연도는 " + YEAR_MIN + "~" + YEAR_MAX + " 사이여야 합니다.");
        }
        return n.intValue();
    }

    /** yyyy-MM-dd 만(실재하는 날짜, 2000~2100). 비면 null. */
    private static String optDate(String s) {
        if (blankToNull(s) == null) {
            return null;
        }
        String t = s.trim();
        try {
            LocalDate d = LocalDate.parse(t);
            if (t.length() != 10 || d.getYear() < YEAR_MIN || d.getYear() > YEAR_MAX) {
                throw new DateTimeParseException("range", t, 0);
            }
        } catch (DateTimeParseException e) {
            throw new ApiException(400, "날짜는 yyyy-MM-dd 형식이어야 합니다.");
        }
        return t;
    }

    static Long parseId(String s) {
        if (s == null || s.isEmpty() || s.length() > 15) {
            return null;
        }
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) < '0' || s.charAt(i) > '9') {
                return null;
            }
        }
        return Long.valueOf(s);
    }

 * 호출이 끝난 뒤 {@link #record} 한다. 컨트롤러에는 트랜잭션이 없으므로 이 기록은 서비스 실패와 무관하게 따로 커밋된다.
 * 성공한 읽기는 응답을 돌려주기 <b>전에</b> 기록한다 — 기록이 실패하면 500 이고 데이터는 나가지 않는다(fail-closed).
 * 쓰기는 이미 커밋된 뒤라 기록 실패가 쓰기를 되돌리지 못한다(서버 로그에는 값 없이 남긴다) — §5 위험 참고.
 * ⚠️ 사번·화면·버튼은 모두 클라이언트 자기신고다. 값·메모·사유·본문은 기록하지 않는다.

@Service
public class BoardMaterialAudit {

    private final BoardMaterialMapper mapper;

    public BoardMaterialAudit(BoardMaterialMapper mapper) {
        this.mapper = mapper;
    }

    /** 행위 직전의 자료 상태 — 확정 자료가 아니면(또는 없으면) null. */
    public static final class Ctx {
        private final Long materialId;
        private final String bidCaseId;
        private final String resultCd;
        private final Integer snapNo;

        Ctx(Long materialId, String bidCaseId, String resultCd, Integer snapNo) {
            this.materialId = materialId;
            this.bidCaseId = bidCaseId;
            this.resultCd = resultCd;
            this.snapNo = snapNo;
        }
    }

    @Transactional(readOnly = true)
    public Ctx before(String id) {
        Long n = BoardMaterialService.parseId(id);
        BoardMaterial m = n == null ? null : mapper.selectOne(n);
        if (m == null || !BoardMaterialService.CONFIRMED.equals(m.getStatusCd())) {
            return null;
        }
        return new Ctx(m.getMaterialId(), m.getBidCaseId(), m.getResultCd(), m.getConfirmedSnap());
    }

    /** ctx 가 null 이면 아무것도 하지 않는다. outcome: OK/DENIED/HIDDEN/BLOCKED/INVALID/ERROR. */
    @Transactional
    public void record(Ctx ctx, String action, String outcome, Actor actor, BoardUiIds.Ui ui) {
        if (ctx == null) {
            return;
        }
        BoardMaterialAct a = new BoardMaterialAct();
        a.setMaterialId(ctx.materialId);
        a.setBidCaseId(ctx.bidCaseId);
        a.setActionCd(action);
        a.setOutcome(outcome);
        a.setStatusCd(BoardMaterialService.CONFIRMED);
        a.setResultCd(ctx.resultCd);
        a.setSnapNo(ctx.snapNo);
        a.setActorEmpNo(actor != null && actor.isKnown() ? actor.getEmpNo() : null);
        a.setEmpVerified(actor != null && actor.isVerified() ? 1 : 0);
        a.setScreenId(ui.getScreen());
        a.setButtonId(ui.getButton());
        a.setUiValid(ui.isValid() ? 1 : 0);
        a.setLoggedAt(Times.nowIso());
        mapper.insertAct(a);
    }
}

            return "BLOCKED";

## 6. 020/021 분할 제안
- **DDL은 020 한 번에 전부**(제출·확정·결과·감사 칸까지) 넣는다. 지금 나누면 `ALTER`가 늘고, 코드를 나눠 올려도 DDL은 영향이 없다.
- **코드는 020a → 020b → 021 세 걸음**(작은 것부터, 각 걸음에 테스트·security 점검).
  1. **020a**(저장·열람·인계·감사): `BoardAccess`, `BoardMaterialService`의 list·detail·snapshots·history·create·saveSnapshot, `BoardMaterialAudit`·`BoardUiIds`, 기존 경로 전환, 인계. 이 단계에서 `PREP`/`DRAFT`만 쓰인다.
  2. **020b**(제출·확정·재작성·결과): `BOARD_SUBMIT` 유형, `ApprovalRequestService`의 제출·회수·재작성·후크, `review`·`acts`, `changeResult`. 020a 위에 얹는다(DDL 변경 없음).
  3. **021**(남은 것만): NEXT 59의 **진행 현황 꼬리표**(자료 `status_cd`·`result_cd` 읽기), **제안서 최종 제출 게이트**(가결 판정 `BoardDecisionGate`: 확정 ∧ 최신 건 `RESULT_CD=PASSED`일 때만 제안서 최종 제출 허용 — A12 '최신 건 기준'), 과거 건 사후 등록, `/complete` 닫기 흐름. 이사회 자료의 '제출'은 020b가 담았으므로 021의 `FINAL_SUBMIT` 재사용은 **제안서 제출**(사내 제출 프로세스)에만 남는다.
- 이유: 020a는 `FINAL_SUBMIT`과 무관하게 독립이고, 020b는 결재 체계의 후크를 건드려 기존 `/approvals`·`decide`에 가까우므로 회귀 테스트를 따로 돌리는 편이 안전하다.

### 숫자 칸 판단 근거(요구 4)
- 금액: 천원 단위 정수로 9,999조 원 = 9,999,000,000,000천원 = **13자리**. 부호 포함이라 `-` 1자 추가.
- 소수 필요 여부: 기존 양식 코드가 비율·환산 값을 소수로 다룬다(`BoardDocSpec.java:1059` 샘플 `%,.2f`, `BoardExcelNamedFill`의 `BoardNumber.format`이 단위 환산 값을 다룸). 그래서 정수만 받으면 기존 연결 칸이 거부될 위험이 있어 **소수 2자리까지 허용**했다(상수 `NUM_FRAC_DIGITS`). 금액 칸이 정수뿐이라는 확인이 오면 0으로 줄인다.
- 적용 칸: 엑셀 **연결(mapped) 칸**만 숫자 검증한다. 직접 입력(input) 칸은 텍스트 100자 그대로다.
- **위험(확인 필요)**: 연결 칸 값이 순수 숫자 문자열(쉼표 허용)이 아니라 단위·% 기호가 붙은 표시 문자열이면 400이 난다. 프런트가 보내는 값의 모양을 §10 이관 메모로 확인한다.

- **403 경로 / 404 경로**: 쓰기 자격이 없으면 403(DENIED, 고정 문구), 보이지 않으면 404(없는 번호와 같은 본문). 영업부장·영업팀장(비담당)은 일반 상세에서도 404다. 결재자 열람은 별도 `/review`다.
- **자기신고 인증의 한계**: `X-Emp-No`·`X-Screen-Id`·`X-Button-Id`는 위조할 수 있다. 사번을 아는 사람이 헤더를 바꾸면 그 담당자 자료를 쓸 수 있고, 화면·버튼 식별자도 거짓으로 보낼 수 있다. 이 규칙·기록은 실수 방지·사후 추적용이며 '검증됨'이 아니다(`emp_verified=false`는 자기신고).
- **접근 이력**: ACCESS_LOG에는 자료 번호·입찰 건 번호·코드·버전·요청 번호만. 값·메모·사유·사번·이름·본문·쿼리 없음. 감사 표(`BOARD_MATERIAL_ACT`)도 값을 담지 않는다.
- **위험**
  1. 감사 기록 실패: 읽기는 fail-closed(500)이지만 쓰기는 커밋 뒤 기록이라 실패하면 쓰기만 남는다 → LOG가 보완.
  2. 숫자 칸 검증이 연결 칸의 실제 값 모양과 다르면 저장이 막힌다 — 첫 화면 연결 시 즉시 드러난다(§7 위험).
  3. 새 걸림돌: 승인이 `NO_HANDOVER_TARGET`으로 막히면 담당자 추가를 먼저 해야 한다(운영 안내 필요).
  4. 비활성 사용자가 만든 자료는 담당자 전원 공유라 그대로 이어서 쓸 수 있다(OWNER 삭제의 부수 효과로 이전의 "비활성 owner 자료" 문제는 없어짐).
  5. 확정 건 열람마다 ACT가 1행씩 늘어난다(정상 사용량이면 문제없음, 정리 정책은 후속).
  6. 영업부장이 부장 아닌 사람에게 자료 정보를 넘기는 경로는 없다(`/review`는 본인 화면에만).
- **되돌리는 법**: 코드는 git revert. DB는 SQL 헤더의 되돌리기 문장(데이터 소멸, 운영 금지). 코드만 되돌릴 때 새 표·칸·코드값은 남아도 무해하다(기존 코드가 읽지 않음). 단 `BOARD_SUBMIT` 요청이 남은 상태로 `ApprovalTypes`만 되돌리면 그 요청의 유형명을 모르는 결재 화면이 있을 수 있어, 되돌리기 전에 진행 중인 `BOARD_SUBMIT`을 취소·정리한다.
- **임시 허용 종료 효과**: 020a를 올리는 순간부터 기존 CAN_WRITE로는 작성할 수 없다. 배정을 먼저 해 두지 않으면 현업 작성이 막힌다(운영 순서: 배정 → 020a 배포).

## 11. 남은 업무 질문(업무 언어 + 권장안)
1. **영업부장은 어느 시점부터 이사회 자료를 볼 수 있나요?** 지금은 "담당이 아니면 못 봄"인데, 영업부장은 어느 상태든 반려·재작성 요구를 할 수 있어야 합니다. 그러려면 내용을 봐야 합니다. 선택지: ⓐ제출 이후(결재 중·확정)만 봄(권장 — 작성 중 초안은 담당자만) ⓑ모든 상태를 봄 ⓒ결재선에 명시된 건만 봄. 영업팀장은 결재자로 지정된 건만 봅니다(권장 그대로). 답이 없으면 ⓐ.
2. **영업부장이 '재작성 요구'를 가결·부결까지 끝난 자료에도 할 수 있나요?** 말씀은 "어느 상태든"이었는데, 가결된 자료를 되돌리면 이미 이사회가 의결한 사실과 시스템 기록이 어긋납니다. 선택지: ⓐ가결·부결 자료도 가능(그대로 구현, 결과·개최일은 해제되고 이력에 남음) ⓑ의결 예정까지만 가능하고 가결·부결은 불가(권장 — 의결이 끝난 사실을 시스템이 지우지 않게) ⓒ가결·부결 뒤에는 부장 승인으로 별도 정정. 지금은 ⓐ로 구현해 둡니다.
3. **금액 칸에 소수점이 필요한가요?** 천원 단위 금액은 정수(13자리)로 받습니다. 그런데 이사회 자료의 일부 칸(비율·환산 값)은 소수가 나옵니다. 지금은 소수 2자리까지 받도록 열어 두었습니다. 금액 칸이 모두 정수이고 비율 칸은 별도 규칙이라면 칸마다 알려 주세요. 권장: 지금처럼 소수 2자리까지 허용하고, 현업이 정수만 쓰겠다고 하면 0자리로 줄임.
4. **'준비 중'과 '작성 중'의 경계**: 지금은 처음 값을 저장하면 자동으로 '작성 중'이 됩니다(별도 버튼 없음). 수익성 분석이 확정되기 전에는 '준비 중'에 머문다는 뜻(NEXT 59)이었는데, 서버는 수익성 확정 여부를 아직 모릅니다. 권장: 지금처럼 첫 저장 때 자동 전환하고, 수익성 확정 흐름(별도 기능)이 생기면 그때 조건을 붙임.
5. **제출 때 결재자가 정해지지 않으면?** 영업팀장이 두 명이고 상신자의 결재선에 영업팀장이 없으면 결재자를 정하지 못해 제출이 막힙니다(019 담당자 변경과 같은 규칙). 권장: 그대로 막고 "시스템 관리자에게 상위 결재자 지정을 요청"을 안내.
6. **담당자가 바뀔 때 '작성본 인계' 기록이 다른 영업팀원에게도 보여도 되나요?** 담당자 변경 이력은 영업팀 전원이 볼 수 있는 화면이고, 인계 기록이 남으면 "그 입찰 건에 작성본이 있었다"는 사실이 드러납니다(자료 번호·내용은 안 보임). 지시하신 "변경 이력에 남긴다"를 그대로 따른 것입니다. 권장: 그대로(내용이 아닌 사실만 보임). 더 숨기려면 인계 기록을 자료 이력에만 두고 배정 이력에는 안 남깁니다.
7. **화면·버튼 식별자를 서버가 강제할 범위**: 지금은 모든 쓰기에 식별자 필수, 읽기는 없어도 통과하되 'UNKNOWN'으로 기록합니다. 읽기도 필수로 하면 감사는 더 엄격하지만 화면·도구(예: 담당자가 아닌 시험 도구)가 헤더를 못 붙일 때 확정 자료를 못 봅니다. 권장: 지금처럼(쓰기 필수·읽기 기록). 식별자가 화면 쪽 자기신고라는 한계는 같습니다.
