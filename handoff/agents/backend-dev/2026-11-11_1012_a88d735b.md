## 3. 지시에서 벗어난 판단

1. `BoardExcelNamedFill.Eval` 을 `private static final class` 에서 `static final class` 로 바꿨고, `applyUnit` 도 package-private `static` 이다. 순수 단위 테스트를 위해서다.
2. 목록에 없던 테스트 파일들을 위 "연쇄로 고친 테스트" 대로 고쳤다.
   - `BoardNamedMapFixture` 의 A row1 `{'op':'manual'}` 제거는 필수다. 안 지우면 기동 검증이 실패한다.
   - `excel-map-legacy.json` 의 `"r1c0":"A2"` 제거도 같은 이유다.
3. 보고서는 `Cell` 이 응답에 직접 직렬화되지 않는다고 했지만, `/board-docs/{id}` 는 `BoardDocController` 가 Doc 을 그대로 내보낸다. 새 getter 때문에 JSON 에 `unit`, `paren`, `dec`, `sub_key` 가 자동으로 실린다.
   - `dec` 는 이 경로에서 `-1`(없음)로 나가고, `/board-forms` 의 `tablesView` 는 `null` 로 나간다.
   - 필요하면 `Cell.getDec` 에 `@JsonIgnore` 를 붙이거나 화면 쪽에서 `-1` 을 없음으로 취급해야 한다. 판단은 하지 않았다.
4. 복제한 정식 양식은 A 기관명의 text 가 `""` 이다.
   - 이전에는 연결 칸이라 샘플 모드에서 `대한민국 기관` 이 보였다. 지금은 입력 칸이라 저장 문구가 그대로 나온다.
   - 보고서 §6 계약(`text:""`)과 일치해서 테스트를 `""` 로 바꿨다.
   - 사용자가 기본 양식의 샘플 문구를 원한다면 기획 확인이 필요하다.

## 4. 확신이 부족한 곳

- `BoardProfitSampleTest.java:260` 과 361~365줄
  - 샘플 엑셀의 C-4 값 문자열(`3.4년`, 내부수익률 `%` 값)이 단위만 붙은 숫자인지 확인하지 못했다.
  - 다른 글자가 섞여 있으면 `CELL_UNIT_TEXT` 로 `review` 가 되어 `filled 249` 단언이 깨진다.
- `BoardMaterialApiTest` 신규 `기관명_r1_c0…` 테스트
  - `담당 900101-1234567` 이 `Pii.scanLoose` 에서 실제로 검출되는지는 실행으로 확인해야 한다.
  - 같은 번호의 구분자 변형은 기존 테스트가 이미 422 를 기대한다.
- `BoardDocEditTest` 의 `asV1` 수정: A r1 행 `cells[0]` 이 r1_c0 이라는 가정이다. `toJson` 순서가 그대로라면 맞다.
- `BoardStructureTest` 등 `BoardStructureFixture` 로 A 구조를 다시 만드는 테스트는, r1_c0 이 입력 칸으로 유지되는 쪽으로 통과할 것으로 본다. 실행 전에는 확인하지 못했다.
