## 3. 구현안

### 3-0. 규칙 요약

**결재 유형**
- `TARGET_CHANGE` "목표 기관 변경": 대결 불가(NO_PROXY), 영업팀 내부 정보(관리자 전체 목록·관리자 취소에서 제외).
- 결재선은 1단계: 팀원 → 영업팀장, 팀장 → 영업부장.

**엔드포인트**
- `POST /bid-targets/changes` 한 곳(체크박스 일괄 1~20건, 한 요청에 같은 기관은 한 번).
- 요청자가 영업부장이면 결재 없이 바로 반영(`mode: DIRECT`), 아니면 결재 요청(`mode: APPROVAL`).
- 스위치 `ggreport.bid-target.approval.enabled=false`면 영업 계열 전원이 DIRECT입니다(되돌리기용).

**항목 동작 `op_cd`**: `ADD` · `EDIT` · `CANCEL` · `TO_WATCH` · `TO_GOAL`

**단건 직접 경로 차단**
- 단건 경로: `POST /institutions/{id}/bid-targets`(목표), 목표 `/cancel`, `/move`.
- 영업부장이 아니면 모든 검사가 끝난 뒤 쓰기 직전에 **403 `APPROVAL_REQUIRED`**.

**결재 중 잠금**
- 그 기관에 PENDING 항목이 있으면 그 기관의 모든 쓰기(관심 포함·영업부장 직접·이월)가 **409 `CHANGE_PENDING`**입니다. 이월은 그 기관을 건너뜁니다.
- 잠금은 요청 상태로 계산하므로 반려·취소·승인 때 따로 풀 일이 없습니다.

**반영**
- 전부 반영하거나 하나도 안 합니다.
- 오류는 409 `ITEM_CHANGED` · `ITEM_INVALID` · `YEAR_PASSED` · `REQUESTER_INACTIVE` · `INST_BID_CLOSED`이고 detail에 `item_no`·`institution_name`이 들어갑니다.

**감사**
- 반영 행: 수정자 = 결재자, 화면·버튼 = 결재 화면(`PrepUiIds`: approvals_inbox/approve 등), `APPROVAL_REQ_ID`.
- 상신·결재·반려·취소: `INST_BID_TARGET_REQ_ACT` 1행씩.

```java
    private volatile boolean carryEnabled;

    public BidTargetSettings(@Value("${ggreport.bid-target.approval.enabled:true}") boolean approvalRequired,
                             @Value("${ggreport.bid-target.carry.enabled:true}") boolean carryEnabled,
                             @Value("${ggreport.bid-target.carry.after:03-01}") String carryAfter) {

        this.carryEnabled = carryEnabled;
        this.carryAfter = parse(carryAfter);

        if (!s.matches("[0-9]{2}-[0-9]{2}")) throw new IllegalStateException("ggreport.bid-target.carry.after must be MM-DD");
        try { return MonthDay.parse("--" + s); }
        catch (DateTimeParseException e) { throw new IllegalStateException("ggreport.bid-target.carry.after must be a valid MM-DD"); }
    }

    public boolean isCarryEnabled() { return carryEnabled; }
    public MonthDay getCarryAfter() { return carryAfter; }
    /** "MM-DD" */
    public String carryAfterText() { return carryAfter.toString().substring(2); }
    /** 오늘이 올해 등록 기한 이후인가(켜져 있을 때만). */
    public boolean carryOpen(LocalDate today) { return carryEnabled && !today.isBefore(carryAfter.atYear(today.getYear())); }
```

### 3-7. 새 `service/CarryRules.java` (순수 로직)
```java
package com.kbstar.kgi.ggreport.web.service;

import com.kbstar.kgi.ggreport.web.domain.BankContract;
import com.kbstar.kgi.ggreport.web.domain.BidTarget;
import java.util.ArrayList;
import java.util.List;

/**
 * 자동 이월 판정(NEXT 105, 사용자 11-20 ②④). 달성 판정은 104 와 같은 TargetResultRules.judge.
 * SUCCESS → 넘기지 않음, FAIL(다른 은행 약정) → 다음 해 '관심', 그 밖(UNREGISTERED·PENDING) → 올해 '목표'.
 */
final class CarryRules {
    static final class Decision {
        String verdict, carryKind;
        final List<BidTarget> revoke = new ArrayList<BidTarget>();
        boolean isEmpty() { return carryKind == null && revoke.isEmpty(); }
    }

    private CarryRules() { }

    static String neededKind(String verdict) {
        if (TargetResultRules.SUCCESS.equals(verdict)) return null;
        if (TargetResultRules.FAIL.equals(verdict)) return BidTargetRules.KIND_WATCH;
        return BidTargetRules.KIND_GOAL;
    }

    /** 작년 살아 있는 목표(번호가 가장 작은 것). 같은 해 목표는 DUP_TARGET 으로 하나뿐이다. */
    static BidTarget sourceOf(List<BidTarget> latest, int lastYear) {
        for (BidTarget t : latest) {
            if (BidTargetRules.KIND_GOAL.equals(BidTargetRules.kindOf(t)) && !BidTargetService.ACTION_CANCEL.equals(t.getActionCd())
                    && t.getTargetYear() != null && t.getTargetYear().intValue() == lastYear) return t;
        }
        return null;
    }

    static boolean isCarryOf(BidTarget t, int fromNo) {
        return BidTargetService.ACTION_CARRY.equals(t.getFirstActionCd()) && t.getFirstCarryFromNo() != null
                && t.getFirstCarryFromNo().intValue() == fromNo;
    }

    static boolean autoRevoked(BidTarget t) {
        return BidTargetService.ACTION_CANCEL.equals(t.getActionCd()) && BidTargetService.CANCEL_CARRY_REVOKED.equals(t.getCancelReasonCd());
    }

    /**
     * latest = 그 기관 모든 기록의 최신 행(뺀 것 포함). 
     * ① 이 원천에서 넘어온 기록 중 사람 손을 안 탄 것(최신 행이 CARRY)이 지금 판정과 구분이 다르면 거둔다.
     * ② 넘길 구분이 있고, 거둘 것 말고 '현재' 기록(관심 또는 올해 이후 목표, S6)이 없고, 같은 원천·같은 구분의 이월이
     *    자동 취소 말고는 없으면(사람이 뺀 이월은 다시 넘기지 않음) 새로 넘긴다.
     */
    static Decision decide(BidTarget source, List<BidTarget> latest, List<BankContract> lines, int lastYear, int thisYear) {
        Decision d = new Decision();
        d.verdict = TargetResultRules.judge(lines, source.getTagCd(), lastYear, thisYear, null).resultCd;
        String need = neededKind(d.verdict);
        boolean blocked = false;
        for (BidTarget t : latest) {
            boolean alive = !BidTargetService.ACTION_CANCEL.equals(t.getActionCd());
            if (isCarryOf(t, source.getTargetNo())) {
                String kind = BidTargetRules.KIND_WATCH.equals(t.getFirstKindCd()) ? BidTargetRules.KIND_WATCH : BidTargetRules.KIND_GOAL;
                if (alive && BidTargetService.ACTION_CARRY.equals(t.getActionCd()) && !kind.equals(need)) {
                    d.revoke.add(t);
                    continue;
                }
                if (kind.equals(need) && !autoRevoked(t)) blocked = true;
            }
            if (alive && BidTargetRules.isCurrent(t, thisYear)) blocked = true;
        }
        if (need != null && !blocked) d.carryKind = need;
        return d;
    }
}
```

```java
            if (mapper.lockInstitution(inst) == null) throw item(404, "NOT_FOUND", "기관을 찾을 수 없습니다.", seen.get(inst));
        }
    }

    private static void shape(TargetChangeIn.Item it, int no) {
        String inst = it.getInstitutionId() == null ? null : it.getInstitutionId().trim();
        if (!InstitutionHeadService.validInstId(inst)) throw item(404, "NOT_FOUND", "기관을 찾을 수 없습니다.", no);
        it.setInstitutionId(inst);
        String op = it.getOpCd() == null ? "" : it.getOpCd().trim();
        if (!OPS.contains(op)) throw item(400, "BAD_VALUE", "동작을 목록에서 골라 주세요.", no);
        it.setOpCd(op);
        boolean add = OP_ADD.equals(op), edit = OP_EDIT.equals(op), cancel = OP_CANCEL.equals(op);
        if (add ? (it.getTargetNo() != null || it.getBaseRevNo() != null) : (it.getTargetNo() == null || it.getBaseRevNo() == null)) {
            throw item(400, "BAD_VALUE", add ? "새로 넣을 때는 기록 번호를 보내지 않습니다." : "바꿀 기록 번호와 화면이 본 기록 번호(base_rev_no)가 필요합니다.", no);
        }
        boolean values = it.getTagCd() != null || it.getMemo() != null || it.getOwnerEmpNo() != null;
        boolean cancelVals = it.getCancelReasonCd() != null || it.getCancelReasonEtc() != null;
        boolean yearOk = add || edit || OP_TO_GOAL.equals(op);
        if ((values && !(add || edit)) || (cancelVals && !cancel) || (it.getTargetYear() != null && !yearOk)) {
            throw item(400, "BAD_VALUE", "이 동작에 쓰지 않는 값이 들어 있습니다.", no);
        }
    }

    /** reasonRequired = 결재 요청(영업부장 바로 반영은 사유를 받지 않는다 — 저장할 곳이 없다). */
    @Transactional
    public Plan plan(TargetChangeIn in, boolean reasonRequired) {
        Plan plan = new Plan();
        if (reasonRequired) {
            plan.reason = BoardMaterialService.checkedText(in.getReason(), REASON_MAX, "사유", true);   // 제어문자 400·개인정보 422(S1)
            new MemoScreen("TARGET_FORBIDDEN", BidTargetRules.FORBIDDEN_MSG).free(plan.reason).throwIfAny();
        }
        LocalDate today = LocalDate.parse(Times.todayKst());
        BankContractRules.CodeCheck codes = targets.codeCheck();
        int no = 0;
        for (TargetChangeIn.Item it : in.getItems()) {
            no++;
            try { plan.items.add(planItem(no, it, today, codes)); }
            catch (ApiException e) { throw withItem(e, no, null); }
        }
        return plan;
    }

    private Planned planItem(int no, TargetChangeIn.Item it, LocalDate today, BankContractRules.CodeCheck codes) {
        int thisYear = today.getYear();
        Planned p = new Planned();
        p.itemNo = no; p.inst = it.getInstitutionId(); p.op = it.getOpCd();
        if (mapper.countPendingByInst(p.inst) > 0) throw BidTargetService.pendingConflict(null);
        if (OP_ADD.equals(p.op)) {
            BidTargetRules.Parsed v = BidTargetRules.parse(asIn(it), thisYear, null, codes);
            fill(p, v, targets.ownerName(v.owner, null));
            targets.checkOverlap(p.inst, 0, false, p.toYear, thisYear, BidTargetService.GOAL_DUP_MSG);
            if (p.toYear.intValue() == thisYear) p.warnCd = warn(targets.closedCheck(p.inst, today));
            return p;
        }
        BidTarget cur = mapper.selectLatestTarget(p.inst, it.getTargetNo());
        if (cur == null) throw ApiException.notFound("target not found");
        if (BidTargetService.ACTION_CANCEL.equals(cur.getActionCd())) throw BidTargetService.conflict("ALREADY_CANCELLED", "이미 목표에서 뺀 기록입니다.", cur);
        if (it.getBaseRevNo().intValue() != cur.getRevNo()) throw BidTargetService.conflict("STALE", "다른 사람이 먼저 고쳤습니다. 최신 기록을 확인하고 다시 올려 주세요.", cur);
        p.cur = cur;
        boolean goal = BidTargetRules.KIND_GOAL.equals(BidTargetRules.kindOf(cur));
        if (OP_TO_GOAL.equals(p.op) ? goal : !goal) {
            throw ApiException.badRequest(OP_TO_GOAL.equals(p.op) ? "이미 목표인 기록입니다." : "목표 기록만 결재로 바꿉니다. 관심 기록은 바로 고칠 수 있습니다.");
        }
        switch (p.op) {
            case OP_EDIT: {
                BidTargetRules.Parsed v = BidTargetRules.parse(asIn(it), thisYear, cur.getTargetYear(), codes);
                if (BidTargetRules.same(cur, v)) throw ApiException.badRequest("바뀐 내용이 없습니다.");
                fill(p, v, targets.ownerName(v.owner, cur));
                if (!p.toYear.equals(cur.getTargetYear())) {
                    targets.checkOverlap(p.inst, cur.getTargetNo(), false, p.toYear, thisYear, BidTargetService.GOAL_DUP_MSG);
                    if (p.toYear.intValue() == thisYear) p.warnCd = warn(targets.closedCheck(p.inst, today));
                }
                return p;
            }
            case OP_CANCEL: {
                BidTargetCancelIn c = new BidTargetCancelIn();
                c.setBaseRevNo(it.getBaseRevNo()); c.setCancelReasonCd(it.getCancelReasonCd()); c.setCancelReasonEtc(it.getCancelReasonEtc());
                BidTargetRules.CancelParsed cp = BidTargetRules.parseCancel(c, codes);
                p.cancelCd = cp.reasonCd; p.cancelEtc = cp.reasonEtc;
                return p;
            }
            case OP_TO_WATCH:
                targets.checkOverlap(p.inst, cur.getTargetNo(), true, null, thisYear, BidTargetService.GOAL_OTHER_MSG);
                return p;
            default: {   // TO_GOAL
                p.toYear = BidTargetRules.moveYear(it.getTargetYear(), false, thisYear);
                targets.checkOverlap(p.inst, cur.getTargetNo(), false, p.toYear, thisYear, BidTargetService.GOAL_DUP_MSG);
                if (p.toYear.intValue() == thisYear) p.warnCd = warn(targets.closedCheck(p.inst, today));
                return p;
            }
        }
    }

    /** 결재자·제목·payload. payload = 사유 + 기관 id·동작만(이름·메모 없음, S5 바이트 검사). */
    public void prepare(Plan plan, SysUser me) {
        boolean lead = HeadRules.ROLE_LEAD.equals(HeadRules.roleOf(me.getRole()));
        plan.approver = assignments.resolveApprover(me, lead);   // 팀원 → 영업팀장, 영업팀장 → 영업부장
        Map<String, Object> payload = new LinkedHashMap<String, Object>();
        payload.put("reason", plan.reason);
        payload.put("n", plan.items.size());
        List<Map<String, Object>> xs = new ArrayList<Map<String, Object>>();
        for (Planned p : plan.items) {
            Map<String, Object> x = new LinkedHashMap<String, Object>();
            x.put("institution_id", p.inst); x.put("op_cd", p.op); xs.add(x);
        }
        payload.put("items", xs);
        String json;
        try { json = JSON.writeValueAsString(payload); } catch (IOException e) { throw new ApiException(500, "요청 내용을 저장할 수 없습니다."); }
        if (json.getBytes(StandardCharsets.UTF_8).length > PAYLOAD_MAX_BYTES) {
            throw ApiException.badRequest("한 번에 올리기에 내용이 너무 깁니다. 사유를 줄이거나 나눠서 요청해 주세요.");
        }
        plan.payload = json;
        String first = mapper.selectInstitutionName(plan.items.get(0).inst);
        first = first == null ? "" : (first.length() > 100 ? first.substring(0, 100) : first);
        int n = plan.items.size();
        plan.title = "목표 기관 변경 — " + first + (n > 1 ? " 외 " + (n - 1) + "곳" : "");
    }

    /** 결재 항목 행 + 상신 감사 1행(누가·어느 화면·버튼, S11 ①). */

    /** 영업부장(또는 결재 스위치 끔) — 같은 검사를 지난 항목을 바로 쓴다. 행: 수정자 = 본인, 버튼 = submit_target_change. */

    /** ApprovalRequestService.applyApproved 가 같은 트랜잭션에서 부른다. 전부 반영하거나 하나도 안 함(S12 재검사 포함). */
    @Transactional
    public String apply(ApprovalRequest r, SysUser decider, Actor actor, BoardUiIds.Ui ui) {
        List<BidTargetReqItem> items = mapper.selectReqItems(r.getReqId());
        if (items.isEmpty()) throw new ApiException(409, "요청 항목을 찾을 수 없습니다.");
        SysUser requester = users.selectByEmpNo(r.getRequesterEmpNo());
        boolean reqLead = requester != null && HeadRules.ROLE_LEAD.equals(HeadRules.roleOf(requester.getRole()));
        String dr = decider == null ? "" : HeadRules.roleOf(decider.getRole());
        if (!(HeadRules.ROLE_HEAD.equals(dr) || (!reqLead && HeadRules.ROLE_LEAD.equals(dr)))) {
            throw new ApiException(403, "이 요청을 결재할 수 없습니다.");   // 방어 — eligibility 가 먼저 막는다
        }
        if (requester == null || !"ACTIVE".equals(requester.getStatus()) || !HeadRules.isSales(requester.getRole())) {
            Map<String, Object> d = new LinkedHashMap<String, Object>();
            d.put("code", "REQUESTER_INACTIVE");
            d.put("message", "요청자가 더 이상 영업부서 사용자가 아니어서 반영할 수 없습니다. 반려해 주세요.");
            throw ApiException.withDetail(409, d);
        }
        TreeSet<String> insts = new TreeSet<String>();
        for (BidTargetReqItem x : items) insts.add(x.getInstitutionId());
        for (String inst : insts) mapper.lockInstitution(inst);
        LocalDate today = LocalDate.parse(Times.todayKst());
        BankContractRules.CodeCheck codes = targets.codeCheck();
        List<Planned> plans = new ArrayList<Planned>();
        for (BidTargetReqItem x : items) {
            try { plans.add(replan(x, today, codes)); }
            catch (ApiException e) { throw withItem(e, x.getItemNo(), x.getInstitutionName()); }
        }
        for (Planned p : plans) write(p, actor, ui, r.getReqId());
        return "목표 기관 변경 반영: " + plans.size() + "건";
    }

    private Planned replan(BidTargetReqItem x, LocalDate today, BankContractRules.CodeCheck codes) {
        int thisYear = today.getYear();
        Planned p = new Planned();
        p.itemNo = x.getItemNo(); p.inst = x.getInstitutionId(); p.op = x.getOpCd();
        if (!OP_ADD.equals(p.op)) {
            BidTarget cur = mapper.selectLatestTarget(p.inst, x.getTargetNo());
            if (cur == null || BidTargetService.ACTION_CANCEL.equals(cur.getActionCd()) || x.getBaseRevNo() == null
                    || cur.getRevNo() != x.getBaseRevNo().intValue() || !BidTargetRules.kindOf(cur).equals(x.getBaseKindCd())) {
                throw BidTargetService.conflict("ITEM_CHANGED", CHANGED_MSG, cur);
            }
            p.cur = cur;
        }
        switch (p.op) {
            case OP_ADD:
            case OP_EDIT: {
                if (x.getTagCd() == null || !codes.enabled(BidTargetRules.G_TAG, x.getTagCd())) throw invalid("태그가 더 이상 쓰이지 않습니다.", p.cur);
                p.toYear = x.getToYear(); p.tag = x.getTagCd(); p.memo = x.getMemo(); p.owner = x.getOwnerEmpNo();
                try { p.ownerName = targets.ownerName(p.owner, p.cur); }   // 새로 고른 주 담당만 다시 검사(활성 영업)
                catch (ApiException e) { throw invalid("주 담당이 더 이상 영업부서 활성 사용자가 아닙니다.", p.cur); }
                if (p.cur == null || !p.toYear.equals(p.cur.getTargetYear())) {
                    if (p.toYear.intValue() < thisYear) throw BidTargetService.conflict("YEAR_PASSED", YEAR_PASSED_MSG, p.cur);
                    targets.checkOverlap(p.inst, p.cur == null ? 0 : p.cur.getTargetNo(), false, p.toYear, thisYear, BidTargetService.GOAL_DUP_MSG);
                    if (p.toYear.intValue() == thisYear) targets.closedCheck(p.inst, today);
                }
                return p;
            }
            case OP_CANCEL:
                if (x.getCancelReasonCd() == null || !codes.enabled(BidTargetRules.G_CANCEL, x.getCancelReasonCd())) throw invalid("빼는 사유가 더 이상 쓰이지 않습니다.", p.cur);
                p.cancelCd = x.getCancelReasonCd(); p.cancelEtc = x.getCancelReasonEtc();
                return p;
            case OP_TO_WATCH:
                targets.checkOverlap(p.inst, p.cur.getTargetNo(), true, null, thisYear, BidTargetService.GOAL_OTHER_MSG);
                return p;
            default: {   // TO_GOAL
                p.toYear = x.getToYear();
                if (p.toYear == null || p.toYear.intValue() < thisYear) throw BidTargetService.conflict("YEAR_PASSED", YEAR_PASSED_MSG, p.cur);
                targets.checkOverlap(p.inst, p.cur.getTargetNo(), false, p.toYear, thisYear, BidTargetService.GOAL_DUP_MSG);
                if (p.toYear.intValue() == thisYear) targets.closedCheck(p.inst, today);
                return p;
            }
        }
    }

    /** 한 항목을 INST_BID_TARGET 한 행으로. 같은 요청에 같은 기관은 한 번이라 MAX+1 이 겹치지 않는다. */
    private Map<String, Object> write(Planned p, Actor actor, BoardUiIds.Ui ui, Long reqId) {
        BidTarget row;
        if (OP_ADD.equals(p.op)) {
            row = new BidTarget();
            row.setInstitutionId(p.inst);
            row.setTargetNo(mapper.selectMaxTargetNo(p.inst) + 1);
            row.setRevNo(1);
        } else {
            row = p.cur;
            row.setRevNo(p.cur.getRevNo() + 1);
        }
        if (row.getTargetNo() > BidTargetService.NO_MAX || row.getRevNo() > BidTargetService.NO_MAX) {
            throw BidTargetService.conflict("LIMIT", BidTargetService.LIMIT_MSG, p.cur);
        }
        row.setCancelReasonCd(null); row.setCancelReasonEtc(null);
        if (OP_ADD.equals(p.op) || OP_EDIT.equals(p.op)) {
            row.setActionCd(BidTargetService.ACTION_SAVE); row.setKindCd(BidTargetRules.KIND_GOAL); row.setTargetYear(p.toYear);
            row.setTagCd(p.tag); row.setMemo(p.memo); row.setOwnerEmpNo(p.owner); row.setOwnerName(p.ownerName);
        } else if (OP_CANCEL.equals(p.op)) {
            row.setActionCd(BidTargetService.ACTION_CANCEL); row.setCancelReasonCd(p.cancelCd); row.setCancelReasonEtc(p.cancelEtc);
        } else if (OP_TO_WATCH.equals(p.op)) {
            row.setActionCd(BidTargetService.ACTION_MOVE); row.setKindCd(BidTargetRules.KIND_WATCH); row.setTargetYear(null);
        } else {
            row.setActionCd(BidTargetService.ACTION_MOVE); row.setKindCd(BidTargetRules.KIND_GOAL); row.setTargetYear(p.toYear);
        }
        return targets.insert(row, actor, ui, reqId);
    }

    static ApiException withItem(ApiException e, int itemNo, String instName) {

        Object o = e.getDetailObject();

            for (Map.Entry<?, ?> x : ((Map<?, ?>) o).entrySet()) d.put(String.valueOf(x.getKey()), x.getValue());
        } else {

            d.put("message", e.getMessage());
        }
        d.put("item_no", itemNo);
        if (instName != null) d.put("institution_name", instName);
        return ApiException.withDetail(e.getStatus(), d);
    }
```

```java
    public Map<String, Object> submitTargetChange(TargetChangeIn in, Actor actor, BoardUiIds.Ui ui) {
```

## 5. 보안·위험·되돌리는 법

- **자기신고 인증(S0)**: `X-Emp-No`로 영업부장 사번을 대면 결재를 건너뛰고, 결재선 밖 반려·취소도 할 수 있습니다. 이 기능은 업무 절차를 강제할 뿐 보안 경계가 아닙니다. 사후 추적 근거는 행·REQ_ACT의 `EMP_VERIFIED`와 ACCESS_LOG뿐입니다.
- **403 경로**
  - `APPROVAL_REQUIRED`(역할 거절)는 403이고 `guard.denied`로 ACCESS_LOG DENIED에 남습니다.
  - 상태 충돌(`CHANGE_PENDING`·`ITEM_CHANGED`·`ITEM_INVALID`·`YEAR_PASSED`·`REQUESTER_INACTIVE`·`CARRY_DISABLED`)은 409이고 failDetail(`409 CODE item=n`)에만 남습니다.
  - 결재 403은 기존 `ApprovalLineController.audited`가 DENIED로 남깁니다.
- **접근 이력에 넣지 않는 것**: 방식·건수·요청 번호·오류 코드·항목 번호만 남깁니다. 사유·메모·연도·사번은 넣지 않습니다.
- **동시성**
  - 상신·바로 반영·단건 쓰기·이월은 기관 잠금이 첫 문장입니다.
  - 승인 경로는 잠금 앞에 일관 읽기가 있지만, 결재 중 잠금 때문에 그 사이 바뀐 행이 없고 PK가 막습니다.
  - 이월은 기관마다 트랜잭션이라 두 탭이 동시에 들어와도 두 번째가 잠금 뒤 다시 판정해 아무것도 하지 않습니다.
- **운영 위험**
  - ① 영업부장에게 map/regions **수정 권한**이 없으면 직접 반영·일괄 엔드포인트가 403입니다(`requireEditor`). 결재 승인은 권한이 없어도 됩니다.
  - ② 결재가 오래 걸리면 그 기관의 관심·직접 수정·이월이 묶입니다. 해소 경로는 요청자 취소와 영업부장 반려·취소입니다.
  - ③ 등록 기한 기본값 `03-01`이 실제와 다르면 미등록 이월이 일찍 생기지만, 국민은행 약정이 등록되면 자동 취소됩니다.
  - ④ 약정 줄을 넣었다 빼는 조작은 자동 취소·재이월을 반복시키지만, 매번 행으로 남아 추적됩니다.
- **되돌리는 법**
  - 결재만 끄기: `ggreport.bid-target.approval.enabled=false`(재빌드 없이)
  - 이월만 끄기: `ggreport.bid-target.carry.enabled=false`
  - 코드 되돌리기: 056 칸은 null로 남아 무해합니다. 표 삭제는 056 헤더의 순서대로 합니다. 이미 생긴 CARRY 행은 옛 코드에서도 살아 있는 기록으로 읽힙니다.
