## 3. backend 설계 조건
**C1. 수정 권한 (①)**
- 은행·약정 쓰기는 서버 `requireInstitutionEdit`(또는 전용 메뉴 키)로 막는다. 화면에서 버튼을 숨기는 것만으로는 안 된다.
- 이력 행에 입력자 사번·IP·UA를 남기고 "자기신고 사번(미검증)"이라고 표기한다. SSO가 붙은 뒤 verified로 바꾼다(35).

**C2. 추가 전용 이력**
- 이력 표에는 INSERT 매퍼만 둔다. UPDATE·DELETE 매퍼는 만들지 않는다.
- Oracle 운영 계정에는 그 표에 INSERT·SELECT만 GRANT한다.
- 정정은 `supersedes_id`가 붙은 새 행으로 남긴다. 현재 값은 시퀀스 최신 행으로 정한다(시각 기준이 아님).

**C3. 기관 키 (⑤)**
- 이관·반입·추가 어디서도 이름을 키로 쓰지 않는다.
- 1회 이관은 번들 행 → 기관 ID 대응표로 한다. 기존 시드 25행은 같은 ID를 재사용한다(BID_CASES 참조 보존).
- 반입 CSV는 `기관ID` 열을 필수로 하거나, 이름+지역+subRegion으로 맞추되 **애매하면 그 행을 거부**한다. 서해·검단처럼 subRegion을 공유하는 곳도 거부 대상이다.
- 이관은 dry-run 대조표를 먼저 내고, data-auditor 대조를 거친 뒤 적용한다. 전체를 한 트랜잭션으로 묶는다.

**C4. 출처 URL (②)**
- 서버에서 `java.net.URI`로 파싱하고, 스킴은 소문자 `http`/`https`만 허용한다(`javascript:`·`data:`·`file:`·`vbscript:` 거부).
- 제어문자·공백이 있으면 거부하고, 길이는 2,000자 이하로 둔다.
- 화면에서는 `textContent`와 `setAttribute('href')`로 넣고 `rel="noopener noreferrer"`를 붙인다.
- 출처 메모(전화 확인 등) 칸은 `Pii.scanLoose`로 검사해 걸리면 거부하고, 응답에는 종류·건수만 돌려준다.

**C5. 기관장·법원 인물 (③)**
- 칸은 허용 목록 구조로만 둔다: 성명·직위·재임 시작일(·종료일)·출처 URL·확인일. **자유 서술 칸은 두지 않는다.** 경조사를 막는 1차 장치는 이 구조 자체다.
- 보조 장치로 반입 시 금칙어 경고(부고·별세·결혼·○○상·조문 등)를 띄우고, data-auditor 원문 대조를 거친다.
- 이 정보는 별도 표·별도 API에 두고 권한을 검사한다. `GET /institutions`에는 싣지 않는다(S3).
- 보존 기간과 퇴임 처리는 35 결정을 따른다. 조회 감사는 68 방식으로 남긴다.

**C6. 반입 (④)**
- `/inbox` 두 경로에 반입 권한 가드를 단다(권한자는 Q6).
- 트랜잭션은 별도 빈이나 public 메서드로 옮겨 실제로 적용되게 한다.
- 링크 거부(`NOFOLLOW_LINKS`), 확장자 허용 목록(pdf·hwp·hwpx·csv·md), 파일별·배치별 크기 상한, manifest의 파일 목록과 sha256 대조, 미등록 파일 거부를 넣는다.
- CSV 칸 길이·행 수 상한과 `Pii.scanLoose`를 적용한다. 단 기관장 성명 칸은 검사 대상에서 빼고, 전화·이메일·주민번호가 나오면 거부한다.
- 보관본은 덮지 않고 접미사를 붙여 남긴다. 반입한 사람·시각·배치 해시를 감사에 남긴다.
- 웹 수집 값은 '후보'로만 들어간다. 사람이 고친 값은 덮지 않고, 후보를 현재 값으로 올리는 것도 권한 검사를 거친다.

**C7. 화면 사본 내보내기 (⑥)**
- 허용 목록 DTO로만 직렬화한다: 이름·종류·지역·subRegion·좌표·현재 은행 요약·확정 여부·공개 출처.
- 이력·입력자·IP·기관장은 빼는 것이 기본이다(Q4).
- `<`·U+2028·U+2029를 이스케이프하고, 내보내기를 접근 이력에 남긴다.

**C8. 값 충돌 (⑦)**
- 73 결과와 사람 수정값이 다르면 충돌 상태로 남기고 자동으로 덮지 않는다.
- 해소는 서버에서 역할을 검사한다(Q5). 자기가 낸 값을 자기가 해소하는 것은 금지한다(64의 본인결재 금지와 같은 원칙).
- 해소도 새 기록으로 남기고 해소자·사유를 함께 적는다(68).
