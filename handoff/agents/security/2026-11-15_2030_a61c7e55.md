## 3. 권장 조치 순서
1. 잔존물 대응. 다음 두 가지 중 하나 또는 둘 다:
   - 진행 중인 임시 폴더를 모듈 전역 Set에 등록하고, `process.on('SIGINT'|'SIGTERM'|'SIGHUP')`과 `process.on('exit')`에서 `rmSync`로 동기 삭제한다.
   - 시작할 때 본인 TEMP의 `apply-mysql-*` 가운데 오래된 것을 지운다.
2. 삭제에 실패하면 경로만 담은 경고를 stderr로 출력한다(값은 넣지 않는다).
3. 실제 mysql로 1회 수동 확인: 비밀번호에 `" \ # ; '`와 공백을 넣은 계정으로 접속에 성공하는지 본다.
4. (선택) README §5-3에 "TEMP를 공용 폴더로 바꾸지 말 것"을 한 줄 덧붙인다.
