- **감사**: 연결 REV는 `insert`가 수정자·자기신고 여부·화면·버튼을 남긴다. 접근 이력 DETAIL은 번호·REV·코드만 남긴다. 실패도 `failDetail`로 남는다. BID_CASES 순위 UPDATE는 같은 트랜잭션의 목표 REV로 대신한다(11-26 수용). 확인.
- **입력 검증**: 기타 대상 이름 1~50자(text 제어문자 + MemoScreen 금칙어), 코드는 `[A-Z0-9_]{1,20}`에 코드표 ENABLED 검사, 건 ID `[A-Za-z0-9._-]{1,64}`, 목표 번호 `[1-9][0-9]{0,8}`, 기관 ID는 validInstId로 본다. 지시의 '1~30자'는 기타 *금고 방식* 이름(aimEtc)이다. 오류 문구에 입력값은 없다. 확인.
