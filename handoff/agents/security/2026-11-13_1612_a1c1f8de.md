### 3. 권장 조치 순서
1. 법원 설정 파일과 로더부터 만든다(정확 일치 호스트, cbub_code 숫자 6자리, https 고정, known_failing). `load_hosts` 검증을 재사용한다.
2. `_guard`(정확 일치)와 고정 경로 URL 생성기를 만든다. seqnum·fid는 문자 검사를 거친다.
3. 인코딩 허용 목록과 S6 판정어, HTML 2MB 상한을 둔다.
4. 실행당 요청 상한, 직렬 처리 간격, max_run_sec를 둔다.
5. 첨부·마스킹·백신은 scourt.py 경로를 재사용하되 백신의 relaxed는 호스트 설정과 연동한다.
6. 시험: 와일드카드 호스트 거부, 목록 href 속 외부 호스트 무시, `cbub_code="000530&x=1"` 거부, 요청 상한 초과 시 멈춤, euc-kr 본문 복원, tls_verify false 거부.

### 4. backend-dev 설계 체크리스트
- [ ] 허용 호스트는 정확 일치 집합이고 설정 파일에서 읽는다. 와일드카드·접미사 비교가 없다.
- [ ] 호스트 정규식은 한 단계 하위 도메인 `.scourt.go.kr`, cbub_code는 `^\d{6}$`이고 중복을 거부한다.
- [ ] https 고정이다. `verify=True`, http 강등 없음, TLS 예외는 ca_extra/pin/ciphers만 쓰고 tls_reason·measured·review_by가 필수다.
- [ ] 실패 호스트는 known_failing(since·kind·review_by)으로 표시하고, 종류가 다르면 새 실패로 본다.
- [ ] URL = 설정 호스트 + 고정 경로 + 검증된 질의(gubun 상수, cbub_code, seqnum 숫자)다. 읽어 온 링크는 URL로 쓰지 않는다.
- [ ] 첨부 다운로드 호스트를 실측해 정확 일치 목록에 넣는다. fid는 FID_RE를 통과한 값만 쓴다.
- [ ] HTML 응답은 2MB 이하, 첨부는 20MB 이하이고 확장자와 서명을 검사한다. hwpx는 마스킹하고 hwp·pdf는 unmaskable로 둔다.
- [ ] 인코딩은 cp949/euc-kr/utf-8 허용 목록에서만 고른다. 대체문자로 떨어지면 warnings에 남긴다.
- [ ] 실행당 총 요청 상한, 1초 이상 간격, 직렬 처리, 시간 초과만 재시도, max_run_sec를 둔다.
- [ ] 본문·purpose·오류 문구에 mask_contacts를 적용한다. 연락처 칸은 보관하지 않는다.
- [ ] vaccine_policy(url, relaxed=호스트 TLS 예외 여부)로 판정한다.
- [ ] 리다이렉트는 기존 `_SameHostRedirect`(같은 출처만)를 그대로 쓴다.

### 5. 사용자에게 물어야 할 경우(실측 뒤에만 해당)
- https가 안 되는 법원(http만 열림)이 나올 때: http 수집을 허용할지, 그 법원을 제외할지. 보안 권장은 제외(known_failing)다.
- 인증서가 회사 망 프록시·사설 CA 때문에 막히는 법원이 나올 때: 중간 CA 추가(ca_extra)나 지문 고정(pin)을 승인할지. 이 경우 백신 생략 조건에서 빠져 "사용자 확인"으로 바뀐다.
- 첨부를 scourt.go.kr 밖의 호스트에서 받아야 하는 법원이 나올 때: 그 호스트를 허용할지.
