**3. 권장 조치 순서**
1. 지금: 이번 범위 그대로 커밋한다.
2. woff2를 싣기로 하면 먼저 할 것(3단계):
   - 원본 TTF 4개와 WOFF2 4개의 SHA-256, `wawoff2@2.0.1` 버전과 package-lock 무결성 값을 NEXT 130이나 보고서에 기록한다.
   - 가능하면 OTS(`ots-sanitize`)나 fontTools로 한 번 열어 검사 통과를 확인한다. 이미 확인한 되풀이 변환 길이 일치에 더해, 풀어 낸 결과와 원본 TTF의 표별 해시도 비교한다.
   - 운영 반입 때는 해시가 바뀌지 않았는지 대조한다.
3. 선택: 운영 배포물에서 `frontend/test/`를 빼는 것을 검토한다(기존 건).

**4. 이관 메모**
- [이관: 기획] KB금융체 웹 글꼴 재배포 사용권(사내 웹서버에 WOFF2로 올리는 것, 저장소 포함) 확인 — 사용자 답 대기 중인 'woff2 싣기' 결정과 함께 — 보안 판단 대상이 아니다. 윤디자인 제작·KB 배포 조건은 확인하지 못했다.
- [이관: 백엔드] 운영 정적 배포물에서 `frontend/test/` 제외 여부 — 급하지 않음 — `static-locations=file:../frontend/`(out-local `application.properties`:33)
- [이관: 백엔드] 운영 Spring Boot/Spring Framework 패치 버전이 정적 자원 경로 조작 관련 공지(CVE)에 해당하는지 확인 필요 — 급하지 않음 — 버전을 직접 확인하지 못함
