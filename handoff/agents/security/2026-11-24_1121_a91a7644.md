## 4. 권장 조치 순서
1. (하, 선택) `structuralLead`가 비활성 팀장을 돌려준 경우의 처리를 정합니다. 패치 후보는 두 가지입니다.
   - `salesTeamEmpNos`의 팀원 분기에서 `l != null && !ApproverRules.active(l)`이면 null을 돌려줍니다. 그러면 `team_resolved:false`로 안내가 나갑니다.
   - 또는 비활성 팀장을 건너뛰고 결재선의 다음 팀장을 찾습니다. 다른 팀으로 넘어갈 수 있다는 점은 기획 판단이 필요합니다.
2. (하) 감사 판독 문서·주석에 적습니다. 패치 후보: Controller 25-27행 머리 주석에 "거부·실패 줄 TASK_CD = 요청 범위(형식 맞을 때만), 성공 줄 = 적용 범위"를 한 줄 더합니다.
3. (하) 규모가 커지면 다시 봅니다. 패치 후보: `selectEndedEverAssignees`를 범위에 든 사번(`team ∪ {me}`)으로 걸러 IN 조건으로 바꿉니다. 지금은 손대지 않아도 됩니다.
4. (참고) `team_resolved`·`scope_default`는 그대로 둬도 됩니다. 소속 묶음을 추론할 수 있다는 점은 업무상 문제가 없다고 봅니다.
