## 3. 권장 조치 순서
1. (하, 선택) http(s) 링크 판정과 링크 HTML을 공용 함수 `logic.safeHttpUrl(s)` 하나로 모으고, dashboard.js:349·583과 render.js:858이 이를 쓰게 한다. 패치 후보 한 줄: `logic.safeHttpUrl = s => { const t = String(s == null ? '' : s).trim(); return /^https?:\/\/\S+$/i.test(t) ? t : null; };`
2. (하, 이번 범위 밖) render.js:614를 `logic.esc(name) + '지역 정보를 …'`로 바꾼다.
3. (참고) 수집기가 `institutions_nonmuni.js`를 자동으로 쓰게 될 때는 JSON 직렬화(`json.dumps(..., ensure_ascii=False)`)로만 쓴다는 규칙을 `collector/SCHEMA.md`에 적는다.
