**확인해서 문제가 없던 항목**
- **SQL 주입**: 매퍼 XML에 `${}`가 0건입니다.
- **경로 이동**: 저장 파일 이름은 서버가 만든 32자리 16진수만 씁니다. 경로를 정규화하고 저장 루트 아래인지 재확인합니다. 원래 파일 이름은 DB에만 남습니다.
- **다운로드 헤더**: `filename*=`는 URLEncoder로 인코딩하고, octet-stream·no-store·nosniff를 붙입니다. 헤더 주입이 불가능합니다.
- **권한**:
  - 개설 승인은 지명자가 스스로 승인할 수 없고(403), 영업팀장이 관련된 건은 영업부장만 승인합니다.
  - 사전준비 결재는 대결이 안 되고(NO_PROXY), 회수는 신청자 본인만 됩니다.
  - 관리자 전체 목록에서 사전준비 결재는 빠집니다.
  - 쓰기 검사가 건 조회보다 먼저 돌고, 열람 불가 건은 404로 존재를 감춥니다.
- **입력 검증**: 결재 의견에 제어문자 400·개인정보 422 검사가 걸립니다. 화면·버튼 식별자는 허용 목록 밖이면 UNKNOWN으로 바꿉니다. 과제 코드 형식 검사도 확인했습니다.
- **XSS**:
  - `prep.js`는 서버 값을 모두 `esc` 처리합니다. 수치는 Number로 바꿉니다.
  - `dashboard.js`의 출처 링크는 `https?://`만 href로 씁니다.
  - `render.js`의 색 값은 `_safeColor`로 거릅니다.
  - 결재 카드의 지명자·의견도 esc 처리합니다.
- **비밀값**: 테스트 설정은 H2 메모리 DB(`sa`/빈 비밀번호)라 비밀이 없습니다. `frontend/data`에는 전화·이메일·주민번호 패턴이 0건입니다. URL의 `key=`는 공개 게시판 글 번호입니다. 첨부 폴더는 `.gitignore`에 있고 `kgi-ggreport-web/data/`는 비어 있습니다.
