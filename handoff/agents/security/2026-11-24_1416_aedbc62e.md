## 4. 패치 후보 (한 줄씩, 커밋 뒤 처리해도 된다)
- **하A**: PAREN_AGE를 `[가-힣A-Za-z]\s*\(\s*[1-9][0-9]\s*(?:[·,]\s*[가-힣]{1,2}\s*)?\)`로 넓힌다. `(65·여)`·`A(65)` 시험을 추가한다.
- **하B**: AGE와 BIRTH의 `\s?`를 `\s{0,3}`으로, BIRTH의 `년(?:생` 앞에 `\s?`를 둔다. 오탐 표본도 다시 돌린다.
- **하C**: 데이터·기획에 `100세 시대` 거부를 받아들일지 묻는다. 받아들이지 않으면 `100세\s?시대`만 예외로 둔다.
- **하D**: uploader 화면 문구에 "한 번에 200MB까지"를 쓰거나 운영 설정 값을 확인한다. 설정 값은 사용자가 확인한다.
