## security 검토: 020a 이사회 자료 화면(미커밋 프런트) + 201bb7d 서버 후속

### 1. 대상·방법·못 본 것
- **대상**: `frontend/js/board-material.js`(신규, 전체), `frontend/js/board.js`(matCtl·writeCtl·mount·renderActions 주변), `frontend/js/board-write.js`(020a 저장·오류·카드·셀 HTML), `frontend/index.html` #bd-root 마크업과 script 순서. 201bb7d는 `Pii.java` scanLoose·fold, `BoardMaterialController.run`, `BidAssignmentService.history` HANDOVER 필터만 짧게 봤습니다.
- **방법**: innerHTML·insertAdjacentHTML·href·data-*·aria-label에 들어가는 문자열을 하나씩 따라가 esc()를 거치는지 봤습니다. 감사 헤더가 어디서 오는지, 읽기 전용 분기, console과 저장소 사용도 grep으로 확인했습니다.
- **못 본 것**: git diff를 직접 보지 못했습니다(읽기 전용이라 실행 불가). 그래서 board.js와 board-write.js는 "이번에 바뀐 줄"이 아니라 020a와 관련된 경로를 기준으로 봤습니다. 브라우저 실행이나 실제 공격 문자열로 재현하지는 않았습니다. `logic.esc` 본문도 확인하지 않았습니다. board-material.js의 대체 esc는 5문자를 모두 이스케이프한다는 점만 확인했습니다.

**결론**: 상·중은 없습니다. 서버나 사용자 값이 이스케이프 없이 innerHTML·속성·href로 들어가는 경로는 찾지 못했습니다. 감사 헤더는 상수이고, console 출력은 0건입니다(board*.js에서 `console.`·`localStorage`·`sessionStorage` 0건).
