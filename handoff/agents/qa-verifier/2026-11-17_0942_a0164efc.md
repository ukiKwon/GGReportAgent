## 4. 테스트 공백과 추가 제안
1. current가 이력보다 늦게 오는 경우: 이력 ok → current ok(can_edit true) 순서일 때 `#db-rec`에 `id="db-rec-save"`가 나타나야 합니다. DOM 흉내나 함수 분리가 필요합니다.
2. 사번 교체: A 초안 저장 → 사번 B로 교체 → 같은 기관을 그리면 초안이 비어 있어야 합니다.
3. `nr.save` 헤더: confirmed=true일 때 `X-Button-Id: save_confirmed`, false일 때 `save`, `X-Screen-Id: bid_notice`(가짜 fetch로 확인).
4. `ov.count`·`ov.waiting`·`paintNavBadge`: 배지가 `data-nav=NOTICE_ID` 항목에 붙고 'map' 항목에서는 지워지는지. state가 loading이면 배지가 없는지. parts.pending 수와 같은지. 지금은 이 셋 모두 테스트가 없습니다(grep 결과 0건).
5. `ov.onLogin` 보류: canLoad가 true면 false를 돌려주고, load가 끝난 뒤 미처리 0이면 팝업을 띄우지 않는지. 받는 동안 세션이 사라지면 띄우지 않는지.
6. `currentOf`: rounds=[{seq 5, open, stale}, {seq 4, NO_BID 닫힘}]일 때 기대값을 정해 고정(P3-1의 결정이 필요).
7. 배지 수와 경과 탭 [미처리] 수가 같은 입력에서 일치하는지 확인하는 교차 테스트(P2-3).
