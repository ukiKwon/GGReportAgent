# qa-verifier — 세션 누적 바퀴수 전광판 검증 (2026-10-30, 그래프 F1 시험 흐름 5번 노드)

## 지시
fmt.js·app.js·hook.js(session)·statefile.js·serve.js 적용분을 독립 검토. 요구 ①자연 완주만 ②새로고침 유지 ③새 세션만 리셋 ④표기 ⑤전광판 3줄.

## 결과: 조건부 통과 — P1 없음, 되돌림 없음
- 확인: 8x 전원 시작 → 선수 7명 완주분과 일치, '+5바퀴'·'바퀴 초기화'는 누적 불변, 새로고침 후 값 유지, 표기 경계(9,999 / 10천 / 12.3천 / 999.9천 / 1백만 / 1.1백만 / 999.9백만 / 1십억 / 상한), 전광판 3줄 겹침 없음, 콘솔 에러 0
- 코드 확인: 증가 지점은 run 분기 한 곳(nl>lastLap), 25바퀴 이송 중 이중 집계 없음, 구 세션 since의 POST는 서버가 거부
