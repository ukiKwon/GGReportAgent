### 확인된 것 (볼 것 ①~⑤)
- **① 서버 계약과 맞음**
  - 경로: `/llm/script-draft/status`, `/bidcases/{id}/prep/board-script-draft`
  - 헤더: `prep_detail`·`script_ai_draft`가 ScriptDraftUiIds·BoardUiIds 짝과 같습니다. X-Emp-No는 app.js의 fetch 덮개가 붙입니다.
  - 상태코드: 401·403·404·409·503을 모두 따로 받습니다.
  - 응답 본문: state=EMPTY는 reason에 따라 나뉩니다. BUSY·COOLDOWN·TIMEOUT·BASIS_CHANGED·UNREACHABLE·MODEL_MISSING은 '실패', NO_BASIS·ALL_BLANKED는 '전부 빔'입니다. 본문을 읽지 못하면 aiErr500입니다.
  - 시간: 화면은 9분을 기다립니다(서버 읽기 마감 480초보다 깁니다). AbortController로 끊고, 끊으면 TIMEOUT 문구가 나옵니다.
- **② 회귀 없음**
  - 단추 조건(aiGate)을 못 넘는 사람은 상태 조회 없이 바로 열립니다(prep.js:2057).
  - 꺼짐·조회 실패·5초 초과는 모두 `false`가 되어 AI 요소 없이 열립니다.
  - 창을 닫을 때 확인을 묻는 조건(isDirty)은 AI가 없으면 늘 거짓이라, 이전처럼 확인 없이 닫힙니다.
- **③ 서버 글이 그대로 화면에 들어가는 경로 없음**: 화면에 그리는 모든 곳(aiLineHtml·aiBasisHtml·aiSlotHtml)이 `esc`를 거치고, 칸에 넣을 때는 `ta.value`만 씁니다. 서버의 reason은 문구표를 찾는 데만 쓰입니다.
- **④ 창을 닫거나 다시 열 때 상태가 꼬이지 않음**
  - 실행 번호(run)와 dead 표시로 늦게 온 응답을 버립니다.
  - aiEnd가 타이머 둘을 다 풉니다.
  - 닫는 모든 길(dropScript, closeAll, Word 성공 뒤 닫기)이 onClose → aiClose로 요청을 끊습니다.
  - dlg.open이 opts를 참조로 들고 있어 dirtyText getter가 동작합니다.
- **⑤ 회의 종류 제거가 서버와 맞음**: scriptBody는 SCRIPT_FIELDS만 돌기 때문에, 메모리에 옛 `vals.meeting`이 남아 있어도 서버로 가지 않습니다. 서버는 빈 값을 BOARD로 받습니다(PrepScriptService.java:175). 저장소(localStorage)에 남는 값은 없습니다.

### 시험 공백 (가짜 fetch·DOM을 넣은 동작 시험 제안)
- status가 500·`{enabled:false}`·5초를 넘김 → `#bs-ai-go` 없음, 창은 열림
- 도착 전에 창 닫기 → aiDone이 아무것도 바꾸지 않음, 타이머 0
- 그만두기 뒤 응답이 옴 → 줄이 'stopped' 그대로
- 넣지 않은 초안이 있을 때 Word 성공 → `#bs-dlg`가 남고 `#bs-busy`에 aiWordDone
- 옛 `vals.meeting='COMMITTEE'` → scriptReqBody에 meeting 키 없음

### 사용자 확인 절차
**AI를 켜지 않은 상태**
1. 7단계 [대본 Word 만들기…]를 엽니다. 회의 고르기가 없고 AI 단추도 없는지 봅니다.
2. Word를 만듭니다. 창이 바로 닫히고 받은 파일 첫 줄이 '이사회'인지 봅니다.
3. 담당이 아닌 사번으로 열 때 지연 없이 바로 열리는지 봅니다.

**AI를 켠 상태**
1. 담당 영업 사번으로 [AI 초안 만들기]를 누릅니다. 경과 시간이 1초마다 바뀌고, 그동안 다른 칸에 적을 수 있는지 봅니다.
2. 도착하면 점선 상자가 생깁니다. [칸에 넣기] → [되돌리기], 글이 있는 칸이면 [뒤에 붙이기]를 해 봅니다.
3. 넣지 않은 초안을 둔 채 Word를 만듭니다. 창이 그대로 있고 안내 줄이 나오는지 봅니다.
4. 만드는 중에 [취소]를 누릅니다. 확인 상자 → '버리고 닫기' → 다시 열었을 때 넣은 칸의 표시만 남는지 봅니다.
5. [그만두기]를 누르고 곧바로 다시 누릅니다. 쿨다운 문구가 나오는지 봅니다.
