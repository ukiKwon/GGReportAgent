### 4. 테스트 공백과 추가 제안
- 다음 '입력 → 기대' 케이스가 시험에 없습니다.
  - `tagNote`: 기본값은 없지만 은행이 알려진 경우(행안부 자료가 다른 은행) → P2-2 결정에 맞는 문구.

  - `laneCellHtml`: `closed`·`open` 종류의 막대 위치와 읽기용 문장.

- DOM 동작(메뉴 키보드·Tab, 저장 중 닫기, focusNext, gretry 뒤 포커스)은 소스 정규식으로만 검사합니다. 예: `"const ok = gs.st === 'ok' && !!gs.data, can = ok && !!gs.data.can_edit;"`, `"gs.focusNext = { inst: m.inst.id };"` 같은 문자열 그대로를 단언합니다.
  - 구현 세부와 과하게 묶여 있어, 같은 동작으로 리팩터해도 시험이 깨집니다.
  - 동작 자체는 검증하지 못합니다.
- 기존 단언 '제안 진행 단계 구획의 [다시 시도]…'가 죽은 문구를 고정합니다(P3-9).
