### 4. 시험 공백과 추가 제안 (입력 → 기대값)
1. **status probe 성공 경로(컨트롤러)**: `PrepScriptDraftFlowTest`에서 `isSalesWriter = true`, `client.probe()`가 `Probe(true, true)`를 돌려주게 두고 `GET /llm/script-draft/status?probe=1` → `reachable: true`·`model_ready: true` 키가 있음, `probe()` 1회 호출. 부장(`isViewAll = true`)도 같은 결과. 지금은 무시 갈래(`:322`)와 꺼짐 갈래(ApiTest `:145`)만 있습니다.
2. **BUSY 갈래(컨트롤러)**: 서비스의 자리를 먼저 잡아 둔 상태에서 draft → 200 `reason: BUSY`, BID_PREP_ACT는 BLOCKED, SEND 0건, `client.draft` 0회, 그리고 `release` 호출이 없어야 함(잡지 않은 자리를 돌려주면 세마포어가 2가 되는 회귀를 막기 위함).
3. **before() null(P2 #2)**: 확정 basis + `before()` null → (수정 후) LLM 0회 + ERROR.
4. **RuntimeException(P3 #5)**: `client.draft`가 `IllegalStateException`을 던짐 → `SCRIPT_AI_DRAFT` 감사 1줄.
5. **리더 `read()` 통합(P2 #4)**: AppTest + H2. 요약서 content_json에 head_name="홍길동"·org_note·mmda_basis·address·staff="1234567"을 넣고 `ScriptDraftPrompt.build(facts(read(...)))` → 프롬프트에 그 값이 없고 `piiDropped ≥ 1`. 확정판·현재판이 둘 다 있으면 확정판 값이 쓰이고, 이사회 자료가 여러 개면 BOARD_YEAR가 큰 것이 쓰여야 함.
6. **NoticeBasisSource 빈이 있을 때**: 공고 줄에 '3곳' → 프롬프트에 실리고, AI가 '3곳'을 쓰면 (경쟁 동향에 3이 없을 경우) `NUMBER_NOT_IN_BASIS`. 21줄·3,001자 → 20줄·3,000자에서 잘림.
7. **숫자 우회(P2 #3)**: 전각 숫자·한글 수사·단위 바꿔치기 → 기대값은 기획 결정에 따라 정합니다.
8. **`basis.summary` 표시**: 요약서 값이 전부 PII로 버려져도 `summarySent = formVer != null`이라 "CURRENT"로 표시되는지 확인. 의도인지 확인이 필요합니다.
