### 4. 테스트 공백과 추가 제안
1. (P1 고정) 포커스 복원 규칙을 순수 함수로 빼서 단언합니다.
   - 입력 `{tag:'INPUT', id:'hb-q', 속성 없음}` → 기대: 복원 대상 없음(null), 또는 id 'hb-q'로 복원.
   - 지금 구조 단언(c54.test 1881)은 동작을 고정하지 않습니다.
2. `sortBy(rows,'due','desc')` → 기대값을 정해 단언합니다(입찰 종료 줄의 위치). 지금 제목이 단언보다 많이 약속합니다(1611).
3. `outcome(409 ALREADY_GOAL, 'move')` → 옮기기 맥락의 문장을 단언합니다(지금은 add와 같은 hint).
4. 팝업 inert 단언이 `/pop\.removeAttribute|rt\.removeAttribute\('inert'\)/` 대안 정규식이라 약합니다. `closePop` 본문에 removeAttribute('inert')가 있는지 정확히 보고, unmount·onProfileChange가 closePop을 부르는지(현재 있음)도 고정하기를 권합니다.
5. 옛 서버: `goalTableHtml`/`goalRows`에 `watch_items` 없는 응답 → 관심 0, 예외 없음을 단언합니다.
6. 목표를 추가한 뒤 거르기 상태: (P2-2 처리 방향이 정해지면) `submitAdd` 성공 시 gs.f 초기화 여부를 구조 단언합니다.
