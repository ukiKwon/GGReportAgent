  - 표시 쪽은 바뀌지 않았습니다. headcard.js:192 `if (f) return f + '~현재'`, HeadDocBuilder.java:518-519 `"(" + from + " ~ 현재)"`.
  - 그래서 입학 연도만 알고 졸업 연도를 몰라 끝을 비우면, 카드·편집 목록·Word(날짜 포함)에 "재학 중"처럼 나옵니다.

  2. 내용 "가람대학교 졸업", 시작 1999, 끝은 비운 채 저장합니다.
  3. 기대: 연도 미상이 드러남(예: '1999~' 또는 '(1999)'). 실제: 카드 '1999~현재', Word '(1999 ~ 현재)'.

**P3-2 null 경로는 모두 안전함 (요청 1·2)**

- Word:
  - str(null)이 ""를 돌려줍니다(HeadDocBuilder.java:607).
  - 둘 다 null이면 괄호 없이 내용만 나옵니다. 이미 시험이 있습니다(HeadDocBuilderDatesTest:104,107,127).
  - sortKey는 "0000-00|"이 되어 맨 아래로 갑니다. 'null'이나 '~현재'는 찍히지 않습니다.
- 다른 경로:
  - 학력·경력은 addItem에서 바로 CONFIRMED가 됩니다(826-827). 확정·기각·무효는 날짜를 다시 검사하지 않습니다.
  - conflictOf는 목록 칸이면 바로 false를 돌려줍니다(246).
  - fillValue를 부르는 곳은 addItem 하나뿐입니다(794).
  - 엑셀 내보내기와 InstSummary*는 education을 쓰지 않습니다(grep 결과 없음).
