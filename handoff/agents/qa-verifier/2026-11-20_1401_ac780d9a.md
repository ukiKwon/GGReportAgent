## 4. 테스트 공백과 추가 제안
- dlg.test.js에는 순수 함수 3개와 소스 문자열 단언만 있다. open·close·requestClose·스택·inert·Esc·Tab·click·확인 상자·invalid·clearInvalid는 검증 0건이다. 저장소 관례(designer.test.js:313, jsdom 없이 최소 스텁)대로 추가할 수 있다.
  1. 순서대로 쌓기: open(A) → open(B). 기대: z가 '30'·'31', depth 2. keydown Esc 한 번 뒤 B만 닫히고 A의 z는 그대로.
  2. 빈 스택: keydown Esc에서 preventDefault·stopPropagation이 불리지 않는다.
  3. click: target이 다른 덮개면 depth 그대로. target이 맨 위 덮개면 닫힌다. mousedown이 상자 안이면 닫히지 않는다(P2-1 수정 뒤).
  4. inert: open 뒤 덮개를 뺀 body 자식이 inert. 미리 inert였던 노드는 close 뒤에도 inert 유지. 나머지는 복원.
  5. isDirty 참: requestClose → `.dlg-cf` 1개, `.dlg-acts`·`.dlg-foot` 단추 disabled. 다시 requestClose해도 cf는 1개. Esc를 누르면 cf가 사라지고 단추가 풀린다. [버리고 닫기]를 누르면 닫히고 onClose가 1회 불린다.
  6. isDirty가 예외를 던지면 그냥 닫힌다. onClose가 예외를 던져도 inert 복원과 포커스 복귀는 일어난다.
  7. opener가 DOM에서 빠졌으면(isConnected false) focus를 부르지 않는다.
  8. invalid·clearInvalid: id 있는 칸(`x-ferr`)에서 1회·2회 호출해도 줄은 1개. id 없는 칸에서 2회 호출 뒤 clear하면 줄 0개(P2-4). 기존 aria-describedby 'h1'은 clear 뒤에도 'h1'으로 남는다.
- 테스트가 취약한 곳: dlg.test.js:53의 `indexOf('</div>\n</div>')`. index.html이 CRLF로 체크아웃되면 -1이 되어, 파일 끝까지 잘라 #edit-modal의 `modal-box`와 맞물려 실패한다. `\r?\n` 정규식이 안전하다. 37줄 테스트는 제목이 "다른 화면 스크립트보다 먼저"인데 knowledge.js 하나만 비교한다. plans.js도 root.dlg를 쓰므로 함께 단언하길 권한다.
