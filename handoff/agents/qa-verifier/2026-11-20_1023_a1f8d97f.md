## 4. 시험 공백과 추가 제안 (입력 → 기대값)
1. 생년월일만 남은 빈 머리에 BIRTH_DATE 칸 입력 → 409 NO_HEAD, 행이 늘지 않음.
2. 위 P2 흐름(빈 머리 → [기관장 추가]) → 결정된 동작대로 `birth_date`가 유지되거나 null. voided_head_id 확인.
3. 사진 + BIRTH_DATE만 남은 머리에서 사진 무효 → REPLACED 사진을 복원하지 않고 응답 `head_empty:true`(HeadPhotoService:269).
4. 같은 날짜로 BIRTH_DATE 다시 입력 → 201 CONFIRMED, 앞 행은 SUPERSEDED, 대기열에 충돌 없음.
5. 다른 날짜 후보를 팀장이 확정(A6) → 대체되고 `birth_date`가 새 값. 영업팀원이 확정하면 403 LEAD_ONLY.
6. 후보 머리(A8)에 같은 BIRTH_DATE 후보가 서로 다르게 2개 → 409 HEAD_ITEMS_CONFLICT.
7. 윤년 경계: 오늘이 2044-02-29이면 상한은 2026-02-28이어야 한다. Times를 고정할 수 없어 지금은 시험할 수 없다. requireBirthDate(v, today)를 단위 시험할 수 있는 형태가 필요하다.
8. Word 시험 보강: 출처 절에 "생년월일" 라벨이 없다는 것은 이미 :222에서 본다. 상세 대신 docx를 받는 경로에서 VIEW 감사가 추가로 남지 않는지(HEAD_DOCX만 남는지) 단언을 더한다.

## 6. 이관 메모
- [이관: 프런트] headcard.js:26-35 `hc.FIELDS`에 BIRTH_DATE(kind: date)가 없다. 그래서 확정된 생년월일이 편집 목록(:727)에 나오지 않아 화면에서 무효 처리를 할 수 없다. 후보 행·대기열에는 라벨이 원문 코드 "BIRTH_DATE"로 보인다(:89). EMPTY_IGNORE_FIELDS(:52)에도 BIRTH_DATE를 더해야 한다. 서버만 먼저 배포해도 막히는 것은 없지만 위 표시 결함이 생긴다.
