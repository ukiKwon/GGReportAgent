### 4. 시험 공백과 추가 제안
DOM 동작 시험이 0건이다. 가짜 document를 쓰는 node 시험으로 다음을 제안한다(입력 → 기대값).
1. 저장소 비움 + landing.js 실행 → `#landing-view.hidden === false`. DOMContentLoaded 뒤 `#login-view`에 `inert` 있음, `#ld-open`의 부모 `hidden === false`.
2. 저장소에 `{"mode":"guest"}` → 랜딩이 hidden 그대로.
3. `[data-go=login]` 클릭 → 랜딩 hidden, login-view의 inert 제거, `document.activeElement.id === 'login-id'`.
4. `#login-view`에 class `hidden` 추가 → 다음 마이크로태스크 뒤 랜딩 hidden. clearTimeout·disconnect·removeEventListener 호출 수를 센다.
5. `#ld-open` 클릭 → 랜딩 보임, activeElement가 `ld-main`.
6. (P2-1을 고친다면) 랜딩 표시 중 → `body > header`와 `#shell` 모두 inert.
7. hide() 뒤 setTimeout을 대기 중인 수가 0(장면 타이머가 새지 않음).
