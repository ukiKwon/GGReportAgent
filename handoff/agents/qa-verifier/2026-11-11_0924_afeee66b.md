## 3. 발견 목록

**P1-1 기본 양식 + 실제 엑셀이면 업로드 직후 저장할 수 없다(4칸 손 수정이 필수이고, 그 과정에서 정보가 사라진다)**
- **원인**: 서버는 `mapped` 칸을 모두 숫자로만 받는다(`BoardMaterialService.java:742-762`, `canonNumber` :861). 그런데 엑셀 채우기는 B 출연금(예비비) 칸에 "5.00 (1.00)"을, C-4 칸에 "3.4년", "0.74%"를 그대로 넣는다. 클라이언트 `bw.numberProblems`(board-write.js:1626)가 같은 규칙으로 저장을 막는다.
- **재현**: 김영업으로 노원구 2026 → 엑셀 고르기에서 `docs/samples/수익성분석표_샘플_가짜값.xlsx` → 아무 칸이나 수정 → [버전 저장].
  - 기대: 메모 줄이 열린다.
  - 실제: "숫자 칸 4곳의 값이 저장 형식에 맞지 않습니다." 이 칸들을 고치려면 칸마다 "그래도 고치기" 확인도 거쳐야 한다.
- **영향**: 괄호 안 예비비(1.00)는 저장할 방법이 없어 사라진다. 년·% 단위도 빠진다.
- **확인할 곳**: B 출연금(예비비) 칸의 양식 정의(복합값 칸으로 둘지, 칸 두 개로 나눌지), C-4 칸이 숫자 칸이어야 하는지, 업로드 때 단위와 괄호를 정규화할지.

**P2-1 A표 '기관명'(r1_c0)이 mapped=true라 텍스트를 저장할 수 없다**
- **근거**: GET /board-materials/1의 form.tables[0]에서 r1_c0은 `"mapped":true,"input":false`인데, 화면에는 "직접 입력"으로 보인다. "노원구"처럼 이름을 넣고 저장하면 "숫자 칸 1곳…"으로 막힌다.
- **영향**: 기관명이 늘 비게 되고, 읽기 전용 화면에도 "—"로 나온다.
- **확인할 곳**: 기본 양식 정의(BoardDocSpec 또는 기본 양식 리소스). 이 칸은 `input:true, mapped:false`여야 하는지 확인한다.

**P2-2 기본 양식에 텍스트로 입력할 수 있는 칸이 하나도 없다(input 칸 0개)**
- **결과**: 칸 단위 PII 422 경로(saveError 'pii', board-write.js:1742-1746)를 실제 화면에서는 탈 수 없다. 클라이언트가 숫자 오류로 먼저 막기 때문이다.
- 서버 경로 자체는 정상이다(직접 POST로 확인). 화면 메시지는 P2-1이 고쳐진 뒤 다시 검증해야 한다.

**P3-1 저장하면 소수 자릿수가 사라진다**
- "5.10"이 "5.1", "1.00"이 "1", "-1.10"이 "-1.1"로 바뀐다(`canonNumber` stripTrailingZeros, :870). 업로드 직후 화면(2자리 고정)과 저장본, 읽기 전용 화면의 표기가 달라진다.
- 409 뒤 다시 저장한 칸은 화면에 "4.70"으로 남아 있어서, 같은 화면 안에서도 표기가 섞인다.
- 워드 초안에서 어떻게 나오는지는 확인하지 못했다.

**P3-2 '수정됨' 필터 수와 상단 수정 수가 다르다**
- 저장본 상태에서 칸 하나를 고치면 상단은 "저장하지 않은 수정 1칸"인데 필터는 "수정됨0"이다. 필터는 엑셀 원본 대비 수정만 세는 것으로 보인다. 사용자에게는 이 차이가 혼란스럽다.

**P3-3 작업 이력에 버전 저장과 준비 중→작성 중 전환이 남지 않는다**
- `insertLog`는 CREATE, RESULT, SUBMIT, CONFIRM, REWORK에서만 호출된다(BoardMaterialService.java:281, 365, 413, 436, 465, 514). 버전 이력이 따로 있다는 걸 감안해도, 상태 전환이 기록되지 않는다.

**P3-4 안내 문구가 버튼 상태와 맞지 않는다**
- 엑셀을 올린 뒤 [수익성 분석표 보기]가 켜져 있는데도 옆에 "엑셀을 올리면 볼 수 있습니다."가 계속 보인다(업로드 직후 스냅샷 e385/e386).

**참고(결함 아님)**: v3에서 출연금 5.1 + 예비비 1.2 + 전산 4.7 = 11.0인데 합계는 10.5다. 합계 칸은 다시 계산되지 않고 경고도 없다. 저장본 상태에서는 '합계 차이' 표시가 사라진다.

## 4. 테스트 공백과 추가 제안
- **기본 양식 + 샘플 엑셀 통합**: 업로드 결과 → `numberProblems` 결과가 0개여야 한다. 지금은 4개이고, P1-1을 고치면 통과해야 한다.
- **양식 정의 단언**: default_doc A.r1_c0 → `input===true && mapped===false`.
- **서버**: 텍스트 칸 PII 저장 → 422 PII_DETECTED, `kinds`에 칸 위치 포함, 값 비노출. P2-1을 고친 뒤 UI 경로로도 확인한다.
- **saveBody 뒤 표시 정규화**: 저장 응답 후 화면 값 == 서버 정규형("4.70" → "4.7")이거나, 반대로 2자리 고정 표시로 정책을 통일한다.
- **eventText**: 'SAVE' 같은 이벤트를 추가한다면 문구 단언을 함께 넣는다.
