## 3. 봐 달라고 한 ①~⑥ 결과 (실측)
- **① 클릭 위임** — 정상
  - `app.js:969-974`의 `closest('.stab')` → `closest('.stab-x')` 순서가 새 마크업에서도 맞다.

  - 키보드도 맞다: 탭에서 Enter를 누르면 화면이 바뀌고(aria-selected·tabindex 0이 옮겨 감), ×에서 Enter를 누르면 닫히며 포커스는 이웃 탭으로 간다.
- **② 다시 그린 뒤 포커스 복원** — 충돌 구조 없음
  - drawTabs는 포커스가 이미 `#tab-list` 안에 있을 때만 되돌린다(`:794`). 그래서 화면 쪽이 같은 흐름 안에서 포커스를 먼저 옮겼든, 비동기로 나중에 옮겼든 화면 쪽이 이긴다.

## 4. 발견 목록
- **P3-1 — `.stab:has()`에 기대는 포커스 링** (`index.html:192-193`)
  - `.stab-tab:focus-visible { outline:none }`로 단추 자체의 링을 끄고, 링은 `:has()`로 감싼 상자에만 그린다.
  - `:has()`를 모르는 브라우저(Chrome·Edge 105 미만)에서는 탭에 포커스 링이 전혀 없다(KWCAG 2.4.7).
  - 폐쇄망 PC의 브라우저 버전을 확인해야 한다. 105 미만이 있다면 `@supports selector(:has(*))` 안에서만 outline:none을 걸어야 한다.
- **P3-2 — tablist 안에 button 역할이 섞임**
  - 접근성 트리: `tablist > tab, tab, button "전국 지도 닫기"`.
  - ARIA상 tablist의 직접 자식은 tab이어야 한다. axe 같은 자동 검사기가 aria-required-children 계열로 잡을 수 있다.
  - 동작은 문제없고, 닫을 수 있는 탭 구현에서 흔한 절충이다. 자동 검사 보고서를 낼 일이 있으면 미리 알아 둔다.
- **P3-3 — 고정 탭의 접근 가능한 이름이 "시작화면 , 고정 탭"**
  - span 경계 때문에 쉼표 앞에 공백이 하나 생긴다. 낭독에는 영향이 거의 없다.
- **P3-4 — 선택되지 않은 탭의 ×는 Tab으로 닿지 않음**
  - 화살표로 다른 탭에 가 있으면 그 탭의 ×는 tabindex -1이라 Tab으로 갈 수 없다. 닫는 수단은 Delete뿐이다.
  - 사용자가 이를 알 단서(title·설명)가 없다. 의도된 설계라면 DESIGN.md:136의 서술로 충분하다.
- **(참고, 이번 변경 아님) `.pin` 클래스 충돌** (`index.html:1008`)
  - 지도 핀용 전역 `.pin` 규칙이 시작화면 탭(`.stab.pin`)에 그대로 먹는다. 글자 12px(다른 탭은 14px), 파란 바탕·테두리.
  - 11-19 고정 탭이 도입될 때부터 있던 것으로 보인다.
- **(재현 안 됨) 일회성 관찰**
  - 첫 시도에서 탭 3개([시작화면, 지도, 현황판*])를 연 직후 활성 탭이 시작화면으로 바뀌어 있었다. 이어서 ←와 Delete를 누른 뒤에는 시작화면 탭 하나만 남았다.
  - 같은 절차를 다시 해 보니 정상이었다: 활성이 아닌 지도 탭을 Delete로 닫으면 포커스가 현황판으로 가고 tabindex가 -1,0,0이 됐다.
  - 포커스가 혼자 `.pt-k`나 `MAIN`으로 옮겨 간 일도 두 번 있었다. focus를 가로채 호출 위치를 찍어 보니 Playwright 실행 경로만 남아, 이번 코드 탓으로 보지 않는다.

## 5. 테스트 공백과 추가 제안
`a11y-kwcag.test.js`는 전부 소스 문자열을 정규식으로 찾는 방식이다. 줄바꿈이나 따옴표만 바꿔도 깨지고, 동작은 검증하지 않는다. 아래 동작 케이스를 제안한다(jsdom 등 DOM 하네스가 있다면).
- drawTabs([pin*, map]): `.stab-tab` 2개, aria-selected=[true,false], tabindex=[0,-1], `.stab-x` 1개(pin에는 없음).
- 활성 탭이 없으면 첫 탭만 tabindex 0이어야 한다.
- 포커스가 map의 ×에 있는 상태에서 drawTabs → 포커스는 여전히 map의 ×. 포커스가 목록 밖이면 → 포커스를 건드리지 않는다.
- closeNavTab(활성 아님, 가운데) → 포커스는 다음 탭. 맨 끝 탭 → 앞 탭. 마지막 닫을 수 있는 탭 → 시작화면 탭, 시작화면 탭도 없으면 `#tab-btn-map`.
- keydown: 마지막 탭에서 ArrowRight → 첫 탭으로 돌아감. 고정 탭에서 Delete → 아무 일 없음. ×에서 ArrowRight → 무시.
- 탭 라벨에 `"<b>"&` → aria-label이 이스케이프돼 있어야 한다(`esc` 경로).
