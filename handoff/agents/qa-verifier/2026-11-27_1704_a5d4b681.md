### 시험 공백
1. **시간표 → 마크업/CSS 역방향 대조가 없다.** test:67과 :97은 마크업·CSS → 시간표 방향만 본다. 그래서 mA 규칙을 지워도 통과한다. 추가 제안: boardmap·minutes의 각 토큰이 마크업 `data-*="tok"`이나 CSS `data-on~="tok"`에 최소 1회 있는지 단언.
2. **`[style*="--dx"]` 조건이 단언되지 않는다.** 이 조건이 빠지면 측정 전에 값이 (0,0)에서 나타난다. 추가 제안: css에 `.bx-tok[data-g="A"][style*="--dx"]`가 있는지 확인.
3. **onResize 재측정이 고정돼 있지 않다.** 추가 제안: onResize 본문에 `measureFlights`가 있는지 확인.
4. **CSS에 ld-bm이 남았는지 보지 않는다.** test:256은 markup만 본다. 추가 제안: `css.indexOf('ld-bm') < 0`.
