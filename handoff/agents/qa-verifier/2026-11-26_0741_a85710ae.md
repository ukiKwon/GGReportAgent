## 3. 발견 목록
**P2-1 결재함 카드에 구분 "null" 표시** — `tchange.js:735, 742-743, 749, 752`
- 원인: `logic.esc`가 `String(s)`라서(logic.js:7) `esc(null)`이 `"null"`이 된다. 이번 변경으로 구분 없는 넣기(ADD)와 구분 null 줄이 처음 생겼다.
- 재현:
  1. 결재 모드 계정(영업부장 아님, 스위치 켬)으로 [목표 기관 추가]를 연다.
  2. 구분을 '정하지 않음' 그대로 두고 [결재 요청 쓰기]로 요청을 올린다.
  3. 결재함 카드의 '이후' 칸을 본다.
  - 기대: "2026 목표 · -" 또는 "구분 정하지 않음".
  - 실제: "2026 목표 · null".
- 같은 원인: 구분 null 목표 줄을 '다음 회차 목표로'로 결재 요청하면 '이전' 칸도 "null"이다. 관심 쪽 beforeCell은 "관심 기관 · null"이 된다.

## 4. 테스트 공백과 추가 제안
각 줄은 "입력 → 기대값"이다.
- 관심 탭에 금고 방식 칸이 없음: `goalTableHtml({...base, tab:'watch'})` → '금고 방식' 없음. `watchRowHtml(r)` → `class="aim"` 없음. 패치 6번에 있던 항목인데 aim-rank.test.js에 빠졌다.
- 구분 null 줄에서 금고 방식만 바꾼 EDIT: `entryOfRow(mk({tagCd:'',tagName:''}))`에 `setOp(EDIT,{tag:'',aim:'FIRST'})` → 본문 `tag_cd:''`, `aim_rank_cd:'FIRST'`, validate ok.
- 다시 읽은 뒤 대기 정리: 대기 aim 'FIRST' 상태에서 entry.aimCd를 'FIRST'로 바꾸고 `pruneDrafts` → 그 id가 빠지고 `d` = {}.
- 대기 없이 원래 값을 고름: `setAimDraft(d,row,'','')`(원래 '') → false, `d` 그대로 {}.
- 결재함 카드(P2-1 회귀 방지): `cardItemsHtml([{op_cd:'ADD', to_year:2026, tag_name:null, …}])` → 'null' 없음. EDIT before/after 둘 다 tag_name null인 경우도 같다.
- `pendCellHtml({tagCd:'',tagName:'',pend:true})` → '구분 정하지 않음'.
- `rowTips({tagCd:'',prevYear:2019})` → '되찾기 후보' 포함.
- `afterBlockHtml` ADD에 `add.tagName:''` → '구분 정하지 않음'.
- `aimCellHtml` 결재 중 줄에 값 '1금고' → span에 '1금고', 버튼 없음.
- 결합도: 시험 8·9와 hb-prep-1125.test.js의 고정 줄은 소스 문자열 단언이라 함수명이나 공백만 바꿔도 깨진다. 동작 시험으로 대체할 수 없는 배선 확인에만 남기기를 권한다.
