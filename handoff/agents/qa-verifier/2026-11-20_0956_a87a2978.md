### 4. 테스트 공백과 추가 제안
- **document `keydown`·`input` 리스너를 시험하지 않습니다.** 리스너는 require 시점에 `document`가 있을 때만 등록되는데, 시험은 document 없이 require합니다(`head-card.test.js:11`). 추가할 케이스:
  - 번호 칸 Enter → docx 요청 1회
  - Esc → `dl.open=false`
  - input '7' → `[data-hc-title]`가 "참고자료 7. …"로 바뀌고 `fieldErr`가 지워짐
- **팝업 Esc 결합**(P2-1): dashboard.js dmKey와 함께 확인해야 합니다. 번호 칸에서 Esc → `dm.cur`가 그대로이고 `hc.view().dl.open===false`.
- **docxErrText 누락 분기**
  - 401 → `TEXT.login`
  - 400(코드 없음) → '처리하지 못했습니다 (400)'
  - 403 → 기획이 정한 문구(P3-4 결정 뒤)
- **받는 중 기관 전환**: docx 응답 전에 `paneSection('11011')`을 부르면 saveBlob은 1회 실행되고 새 `V.dl`은 null이어야 합니다.
- **sessionStorage 재사용**: 5로 받은 뒤 다시 열면 `dl.ref==='5'`인지 봅니다.
- **409로 none이 되는 경우**: 재조회 응답이 head:null이면 `status==='none'`이고 카드에 `docx-open`이 없어야 합니다.
- **'값이 없는 칸' 시험(910)**: 미확인 칩(`pop-unk">미확인`)이 날짜 3칸에 있는지는 확인하지 않습니다.
- **구현 세부에 과하게 결합된 시험(1180)**: 소스 전체에 `window.open` 문자열이 없는지를 검사하므로 주석 낱말에도 깨집니다. main의 ③(주석 낱말 교체)이 그 증거입니다.
